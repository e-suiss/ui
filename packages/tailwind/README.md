# @esuiss/tailwind

Tailwind CSS variants, animations, and utilities used by esuiss-ui components. Installed by `npx @esuiss/ui@latest init`.

```css
@import "tailwindcss";
@import "@esuiss/tailwind";
```

Theme colors stay in your own stylesheet under `:root` and `.dark`. Requires Tailwind CSS 4.2 or later.
