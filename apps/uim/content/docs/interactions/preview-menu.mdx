Long pressing a `PreviewMenuTrigger` measures it, then animates its content from its place on screen into a larger preview, up to 360 points wide. The rest of the screen fades behind a scrim, and a menu of actions zooms in below the preview.

The original trigger is hidden while lifted, so the preview appears to rise out of it. Pressing outside closes the menu and the preview returns to the trigger. Use it for photos, messages or cards that benefit from a closer look before acting.

## Usage

<Code lang="tsx" code={"import { PreviewMenu, PreviewMenuTrigger, PreviewMenuContent, PreviewMenuItem, PreviewMenuSeparator } from \"@/components/interactions/preview-menu\""} />

<Code lang="tsx" code={"<PhotoGrid openIndex={1} />"} />

Put a `PreviewMenuTrigger` with the element and a `PreviewMenuContent` with `PreviewMenuItem`s inside `PreviewMenu`. By default the preview repeats the trigger's children; pass `preview` to show different content, such as a larger image.

Set `aspectRatio` to size the preview, for example `4 / 3`. The menu can be uncontrolled or controlled with `open`, `defaultOpen` and `onOpenChange`. `usePreviewMenu` returns `open`, `lifted` and `frame`.

## Accessibility

- The trigger has a `longpress` accessibility action, so screen reader users can open the menu without holding.
- The trigger exposes `expanded` and `disabled` states.
- The preview is hidden from screen readers; focus goes to the menu.

## Notes

- A medium impact haptic plays when the menu opens, if the app provides an adapter through `HapticsProvider`.
- The menu uses `bg-surface-raised` with a border that is stronger in dark mode, and the backdrop uses `bg-scrim`.
- The preview stays within the top and bottom safe areas, leaving room for the menu.
- Animations respect the system reduce motion setting.
- On iOS the content renders in a full-window overlay so it appears above native screens.
