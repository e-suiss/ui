`ReorderList` renders its `ReorderListItem`s in the order given by `value`. Dragging a row's `ReorderListHandle` lifts the row: a raised surface with a shadow fades in behind it and, outside an inset group, the row grows slightly. It follows the finger while the other rows spring out of the way.

On release the row springs into its new slot and `onValueChange` receives the new order. Rows can have different heights. Use it for ordering favorites, playlists or priorities.

## Usage

<Code lang="tsx" code={"import { ReorderList, ReorderListItem, ReorderListHandle } from \"@/components/interactions/reorder-list\""} />

<Code lang="tsx" code={"<ReorderDemo />"} />

`ReorderList` is controlled: pass `value` as an array of item keys and update it in `onValueChange`. Give each `ReorderListItem` a `value` matching its key, and place a `ReorderListHandle` anywhere inside it, at the start or end. Place the list inside an `ItemGroup` with the `inset` variant for a rounded group; the lifted row then keeps the group's shape.

Only the handle starts a drag, so the rest of the row can still be pressed or scrolled.

## Accessibility

- The handle has the `button` role and offers `moveUp` and `moveDown` accessibility actions, so screen reader users can reorder without dragging.
- Move up is omitted on the first row and move down on the last.

## Notes

- Haptics play when the drag starts (medium impact), each time the target slot changes (selection) and on release (light impact), if the app provides an adapter through `HapticsProvider`.
- The dragged row shows a `bg-surface-raised` layer with a shadow, rounded inside an inset group.
- The lift scale is skipped inside an inset group and when reduce motion is on; springs respect the system reduce motion setting.
