`ReorderList` renders its `ReorderListItem`s in the order given by `value`. Dragging a row's `ReorderListHandle` lifts the row with a raised surface and shadow, and it follows the finger while the other rows slide out of the way.

On release the row settles into its new slot and `onValueChange` receives the new order. Rows can have different heights. Use it for ordering favorites, playlists or priorities.

## Usage

<Code lang="tsx" code={"import { ReorderList, ReorderListItem, ReorderListHandle } from \"@/components/interactions/reorder-list\""} />

<Code lang="tsx" code={"<ReorderDemo />"} />

`ReorderList` is controlled: pass `value` as an array of item keys and update it in `onValueChange`. Give each `ReorderListItem` a `value` matching its key, and place a `ReorderListHandle` anywhere inside it, at the start or end.

Only the handle starts a drag, so the rest of the row can still be pressed or scrolled.

## Accessibility

- The handle has the `button` role and offers `moveUp` and `moveDown` accessibility actions, so screen reader users can reorder without dragging.
- Move up is omitted on the first row and move down on the last.

## Notes

- Haptics play when the drag starts (medium impact), each time the target slot changes (selection) and on release (light impact), if the app provides an adapter through `HapticsProvider`.
- Rows use `bg-surface`; the dragged row uses `bg-surface-raised` with a shadow.
