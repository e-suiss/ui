`SearchReveal` is a scroll view that starts scrolled just past its `SearchRevealField`, so the list shows first and the field is out of view. Pulling down reveals the field, which fades in as it appears, and the scroll snaps either fully open or fully hidden.

Focusing the field scrolls it into view. While there is a query, snapping is turned off so the field stays visible. Use it for notes, mail or settings lists where search should be close but not take space.

## Usage

<Code lang="tsx" code={"import { SearchReveal, SearchRevealField, SearchRevealContent } from \"@/components/interactions/search-reveal\""} />

<Code lang="tsx" code={"<NotesExample count={12} />"} />

Put a `SearchRevealField` first, then the list inside a `SearchRevealContent`, all inside `SearchReveal`. The field is controlled: pass `value` and update it in `onValueChange`, then filter your list with it.

`SearchRevealContent` is at least as tall as the scroll view, so the field can be hidden even when the list is short. Other `ScrollView` props, except `onScroll`, pass through to `SearchReveal`, and other `TextInput` props pass through to the field.

## Accessibility

- The input has the `searchbox` role and is labelled by `placeholder`.
- The clear button is labelled `Clear search` and returns focus to the input.

## Notes

- The field uses `bg-control` with `label-secondary` placeholder and icons.
- Autocorrect and autocapitalization are off, and the return key reads `search`.
- Taps on the list work while the keyboard is open.
