`PullToRefresh` is a `ScrollView` with a native `RefreshControl`. Pulling down past the top starts a refresh: a light impact haptic plays, the spinner shows, and `onRefresh` runs.

The spinner stays for at least 600 ms, even when `onRefresh` resolves sooner, so it does not flicker. It also hides if `onRefresh` throws or rejects. Use `PullToRefreshControl` to add the same behavior to a `FlatList` or `SectionList`.

## Usage

<Code lang="tsx" code={"import { PullToRefreshControl, PullToRefresh } from \"@/components/interactions/pull-to-refresh\""} />

<Code lang="tsx" code={"<View className=\"flex-1\">\n  <Feed />\n</View>"} />

Pass an `onRefresh` that returns a promise, or nothing for synchronous work. All other `ScrollView` props pass through to `PullToRefresh`.

For lists, pass `<PullToRefreshControl onRefresh={...} />` as the list's `refreshControl`. It manages its own refreshing state; pass `refreshing` to override it. Other `RefreshControl` props pass through.

## Accessibility

- `PullToRefresh` exposes a `busy` state while refreshing.
- `PullToRefreshControl` is labelled `Refreshing` while active.

## Notes

- The haptic plays only if the app provides an adapter through `HapticsProvider`.
- The spinner uses the `label-secondary` color, and on Android its background uses `surface-raised`, so both follow light and dark mode.
