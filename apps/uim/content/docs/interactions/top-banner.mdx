`TopBannerProvider` shows banners requested with `show` from `useTopBanner`. Each banner slides down below the top safe area with a title, an optional description, icon and action button, and hides after 4 seconds by default.

Banners queue and appear one at a time, with a short pause between them. Swiping a banner up past a small distance, or flicking it up, dismisses it; dragging pauses the timer. Use it for brief confirmations and status updates, such as a copied link or a restored connection.

## Usage

<Code lang="tsx" code={"import { TopBannerProvider } from \"@/components/interactions/top-banner\""} />

<Code lang="tsx" code={"<TopBannerProvider>\n  <Triggers />\n</TopBannerProvider>"} />

Wrap the app in `TopBannerProvider`, then call `show({ title, description?, icon?, action?, timeout? })` from `useTopBanner`. `show` returns an id that you can pass to `dismiss`; calling `dismiss()` with no id dismisses the current banner.

`icon` is a Phosphor icon component. `action` is `{ label, onPress }`; pressing it runs `onPress` and dismisses the banner. Pass a `timeout` of `0` or `Infinity` to keep a banner until dismissed.

## Accessibility

- The banner has the `alert` role and is a polite live region.
- A string title is announced when the banner appears.
- The banner has a `dismiss` accessibility action.

## Notes

- Banners are up to 384 points wide and centered.
- The card uses `bg-surface-raised`, or `bg-surface-secondary` in dark mode, with a `border-separator` outline; the icon uses `text-link`.
- Slide animations respect the system reduce motion setting.
