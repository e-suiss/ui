`SwipeActions` wraps a row so it can be dragged left or right to reveal `SwipeAction` buttons on the leading or trailing side. The buttons stretch to fill the revealed space, and opening one row closes any other open row.

When an action has `fullSwipe`, dragging past 60% of the row width expands that action over the others with a medium impact haptic. Releasing there slides the row off, collapses its height, then runs the action, which suits delete or archive. Use it for mail, message or task lists.

## Usage

<Code lang="tsx" code={"import { SwipeActions, SwipeActionsContent, SwipeActionsActions, SwipeAction } from \"@/components/interactions/swipe-actions\""} />

<Code lang="tsx" code={"<View>\n  <Inbox />\n</View>"} />

Put the row in `SwipeActionsContent`, and the buttons in one `SwipeActionsActions` per side, with `side` set to `leading` or `trailing` (the default). Leading actions are on the left in left-to-right layouts and on the right in right-to-left layouts.

Pressing an action runs `onPress` and closes the row. For a full-swipe action, `onPress` runs after the row collapses, so remove the item from your data there. `useSwipeActions` returns `close` for closing the row from inside it. `swipeActionVariants` is also exported.

## Accessibility

- Every action is offered as an accessibility action on `SwipeActionsContent`, labelled by its `accessibilityLabel` or text, so screen reader users can run it without swiping.
- Hidden actions are removed from the accessibility tree until their side is open.
- The row has the `group` role and each action the `button` role.

## Notes

- The full-swipe haptic plays only if the app provides an adapter through `HapticsProvider`.
- Action colors use `bg-accent`, `bg-danger`, `bg-purple` and `bg-gray` with `text-on-accent` labels and icons; the content uses `bg-surface`.
