Composes `Screen`, `Avatar`, `Message`, `Bubble` with `BubbleReactions`, `MessageScroller`, `Attachment`, `InputGroup`, `Button` and `BottomBar`. Double-tapping a bubble toggles a heart, the attach button adds a sample photo preview that can be removed before sending, and each sent message gets a sample reply after a typing indicator.
