`ActionMenu` is a thin layer over `AlertSheet`. `ActionMenuContent` groups its items into one rounded block and appends a separate Cancel button below it.

Use it when a button should offer a short list of choices, such as share, duplicate or delete, without leaving the screen.

## Usage

<Code lang="tsx" code={"import { ActionMenu, ActionMenuTrigger, ActionMenuContent, ActionMenuLabel, ActionMenuItem, ActionMenuSeparator } from \"@/components/patterns/action-menu\""} />

<Code lang="tsx" code={"<ActionMenuDemo defaultOpen />"} />

Wrap a pressable in `ActionMenuTrigger` and list `ActionMenuItem`s inside `ActionMenuContent`. Add an `ActionMenuLabel` first to show a title.

The menu can be uncontrolled or controlled with `open`, `defaultOpen` and `onOpenChange`. Set `variant="destructive"` on an item for actions that delete or remove.

## Accessibility

- When `dismissible` is `false`, the sheet uses the alert dialog primitive instead of the dialog primitive.
- Disabled items are styled with `text-label-quaternary`.

## Notes

- Item text uses `text-link`, or `text-danger` for the `destructive` variant.
- On iOS the sheet renders in a full-window overlay so it appears above native screens.
