`ContextActions` turns any content into a long-press target. Holding `ContextActionsTrigger` for 500 ms opens an `AlertSheet` with the actions grouped in one block and a separate Cancel button below.

Use it for secondary actions on photos, messages or list rows that should not take up space on screen.

## Usage

<Code lang="tsx" code={"import { ContextActions, ContextActionsTrigger, ContextActionsContent, ContextActionsLabel, ContextActionsItem, ContextActionsSeparator } from \"@/components/patterns/context-actions\""} />

<Code lang="tsx" code={"<ContextActions>\n  <ContextActionsTrigger\n    accessibilityLabel=\"Photo\"\n    className=\"h-40 items-center justify-center gap-2 rounded-2xl bg-surface-secondary active:opacity-80\"\n  >\n    <Icon as={ImageIcon} className=\"size-8 text-label-secondary\" />\n    <Text className=\"text-sm text-label-secondary\">Long press</Text>\n  </ContextActionsTrigger>\n  <ContextActionsContent>\n    <ContextActionsLabel>Photo</ContextActionsLabel>\n    <ContextActionsItem>Copy</ContextActionsItem>\n    <ContextActionsItem>Share</ContextActionsItem>\n    <ContextActionsItem variant=\"destructive\">Delete</ContextActionsItem>\n  </ContextActionsContent>\n</ContextActions>"} />

Wrap the target in `ContextActionsTrigger` and list `ContextActionsItem`s in `ContextActionsContent`. Add a `ContextActionsLabel` first to show a title.

The open state is managed internally; use `onOpenChange` to react to it. `ContextActionsTrigger` accepts every `Pressable` prop, so `onPress` still works for a normal tap, and your own `onLongPress` runs before the sheet opens. Change the hold time with `delayLongPress`.

## Accessibility

- The trigger has the hint "Long press for actions".
- It adds `longpress` and `showActions` ("Show actions") accessibility actions, so screen reader users can open the sheet without holding.
- Your own `accessibilityActions` and `onAccessibilityAction` are kept.

## Notes

- Item text uses `text-link`, or `text-danger` for the `destructive` variant.
- On iOS the sheet renders in a full-window overlay so it appears above native screens.
