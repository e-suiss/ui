`SegmentPicker` composes `Select`: a `SelectTrigger` showing the current option and a `SelectContent` popup listing every option, with a check mark on the selected one.

Use it for a view or period switch where the options would not fit side by side on a phone.

## Usage

<Code lang="tsx" code={"import { SegmentPicker, SegmentPickerItem } from \"@/components/patterns/segment-picker\""} />

<Code lang="tsx" code={"<SegmentPicker defaultValue=\"week\" accessibilityLabel=\"Period\" className=\"w-40\">{periods}</SegmentPicker>"} />

List `SegmentPickerItem`s as children. Each item's visible text is its `label`, then its `accessibilityLabel`, then a string child, then its `value`.

Use it uncontrolled with `defaultValue`, or controlled with `value` and `onValueChange`.

## Notes

- The popup uses `bg-surface-raised`, fades in and out, and respects the system reduce motion setting.
- On iOS the popup renders in a full-window overlay so it appears above native screens.
