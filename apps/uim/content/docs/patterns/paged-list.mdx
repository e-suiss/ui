`PagedList` takes the full `items` array and renders only the first `pageSize` items. When the user scrolls near the end, or presses the Load more button in the footer, the next page is appended.

The button disappears once every item is shown. Use it for long local lists where rendering everything at once is not needed.

## Usage

<Code lang="tsx" code={"import { PagedList } from \"@/components/patterns/paged-list\""} />

<Code lang="tsx" code={"<PagedList<Topic> items={topics} pageSize={10} getKey={(topic: Topic) => topic.id} renderItem={(topic: Topic) => <TopicRow topic={topic} />} />"} />

Pass `items`, `renderItem` and a `getKey` that returns a stable key for each item. `renderItem` receives the item and its index, not the `FlatList` info object.

Other `FlatList` props pass through, except `data`, `keyExtractor`, `onEndReached` and `ListFooterComponent`, which the list manages. Use `listClassName` to style the content container.

## Accessibility

- The Load more button is a `Button`, so screen reader users can load the next page without scrolling to the end.

## Notes

- The next page loads when the scroll position is within half a screen of the end (`onEndReachedThreshold` of `0.5`).
- The footer is a full-width `secondary` button.
