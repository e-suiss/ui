`Modal` wraps `Drawer` with the swipe handle turned on, and `ModalContent` shows a close button by default. It slides up from the bottom of the screen and can be swiped down or closed with the button.

Use it for a self-contained task, such as a short form, that the user completes or cancels before returning to the screen.

## Usage

<Code lang="tsx" code={"import { Modal, ModalTrigger, ModalContent, ModalHeader, ModalBody, ModalFooter, ModalTitle, ModalDescription, ModalClose } from \"@/components/patterns/modal\""} />

<Code lang="tsx" code={"<ModalDemo defaultOpen />"} />

Wrap a button in `ModalTrigger`, then put a `ModalHeader`, `ModalBody` and `ModalFooter` inside `ModalContent`. `ModalFooter` stacks its buttons in reverse order, so the first button in code appears at the bottom.

The modal can be uncontrolled or controlled with `open`, `defaultOpen` and `onOpenChange`. Pass `showCloseButton={false}` on `ModalContent` to hide the close button.
