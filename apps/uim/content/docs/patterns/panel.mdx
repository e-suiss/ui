`Panel` wraps `Drawer` with the swipe handle turned on, and `PanelContent` shows a close button by default. It slides up from the bottom of the screen and can be swiped down or closed with the button.

Use it for supporting content, such as details or settings, that sits alongside the current screen.

## Usage

<Code lang="tsx" code={"import { Panel, PanelTrigger, PanelContent, PanelHeader, PanelTitle, PanelDescription, PanelBody, PanelFooter, PanelClose } from \"@/components/patterns/panel\""} />

<Code lang="tsx" code={"<PanelDemo defaultOpen />"} />

Wrap a button in `PanelTrigger`, then compose `PanelHeader`, `PanelBody` and `PanelFooter` inside `PanelContent`. Use `PanelClose` for a button that dismisses it.

The panel can be uncontrolled or controlled with `open`, `defaultOpen` and `onOpenChange`. Pass `showCloseButton={false}` on `PanelContent` to hide the close button.
