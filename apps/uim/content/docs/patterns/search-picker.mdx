`SearchPicker` renders a field-style `DrawerTrigger` with the selected label and an up-down caret. Pressing it opens a `Drawer` with a search input and a scrollable list of options.

Typing filters options by label, case-insensitively. Options with a `group` are shown under a group heading. Choosing an option selects it, closes the drawer and clears the search. Use it when the list is too long to scan, such as countries, cities or frameworks.

## Usage

<Code lang="tsx" code={"import { SearchPicker } from \"@/components/patterns/search-picker\""} />

<Code lang="tsx" code={"<SearchPicker items={frameworks} placeholder=\"Select a framework\" searchPlaceholder=\"Search frameworks...\" emptyText=\"No framework found.\" accessibilityLabel=\"Framework\" className=\"w-56\" />"} />

Pass `items` as an array of `{ value, label, group?, disabled? }`. The `SearchPickerItem` type is exported.

Use it uncontrolled with `defaultValue`, or controlled with `value` and `onValueChange`; the value is a string or `null`. `emptyText` shows when nothing matches.

## Accessibility

- Each option is a button that exposes `selected` and `disabled` states.
- Each group has the `group` role and is labelled by its name.
- The search input is labelled by `searchPlaceholder`.
- Without a `title`, the drawer is labelled by the placeholder or `accessibilityLabel`.

## Notes

- The list stays between 40% and 60% of the window height, and taps work while the keyboard is open.
- The field uses `bg-control`, `border-danger` with a `bg-danger` tint when invalid, and `bg-control-disabled` when disabled; the tint is stronger in dark mode.
- The search input disables autocorrect and autocapitalization.
