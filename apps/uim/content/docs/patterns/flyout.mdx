`Flyout` wraps `Drawer` with the swipe handle turned on. It slides up from the bottom of the screen and can be swiped down to close.

Use it for a few related controls, such as dimensions or filters, that should appear next to the content without opening a new screen.

## Usage

<Code lang="tsx" code={"import { Flyout, FlyoutTrigger, FlyoutContent, FlyoutHeader, FlyoutTitle, FlyoutDescription, FlyoutBody, FlyoutClose } from \"@/components/patterns/flyout\""} />

<Code lang="tsx" code={"<FlyoutDemo defaultOpen />"} />

Wrap a button in `FlyoutTrigger`, then put a `FlyoutHeader` with `FlyoutTitle` and `FlyoutDescription`, and a `FlyoutBody` inside `FlyoutContent`. Use `FlyoutClose` for a button that dismisses it.

The flyout can be uncontrolled or controlled with `open`, `defaultOpen` and `onOpenChange`. Triggers and close buttons accept a `render` prop to use a `Button`.
