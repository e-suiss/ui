`Picker` composes `Select`: a `SelectTrigger` showing the current value and a `SelectContent` popup with the options. The selected option shows a check mark.

Use it to choose one value from a short or grouped list in a form.

## Usage

<Code lang="tsx" code={"import { Picker, PickerGroup, PickerItem, PickerSeparator } from \"@/components/patterns/picker\""} />

<Code lang="tsx" code={"<PickerDemo />"} />

List `PickerItem`s as children, optionally inside `PickerGroup`s separated by `PickerSeparator`. The picker collects the items from its children to show the selected label, or you can pass `items` directly.

Use it uncontrolled with `defaultValue`, or controlled with `value` and `onValueChange`. `placeholder` shows while nothing is selected.

## Accessibility

- Give the picker an `accessibilityLabel` or `accessibilityLabelledBy`, since the trigger shows only the value.

## Notes

- The popup uses `bg-surface-raised` with a subtle border that is stronger in dark mode.
- The popup fades in and out, and respects the system reduce motion setting.
- On iOS the popup renders in a full-window overlay so it appears above native screens.
