`Toggle` is a `Pressable` with an on and off state. When on, it shows a selected background and its text turns to the link color; it scales down slightly while pressed. It has two variants, `default` and `outline`, and three sizes.

`ToggleIcon` is an `Icon` sized for use inside a toggle.

## Usage

<Code lang="tsx" code={"import { Toggle, ToggleIcon } from \"@/components/ui/toggle\""} />

<Code lang="tsx" code={"<View className=\"flex-row\">\n  <ToggleDemo accessibilityLabel=\"Toggle bold\">\n    <ToggleIcon as={TextBIcon} />\n  </ToggleDemo>\n</View>"} />

Control the state with `pressed` and `onPressedChange(pressed, details)`, or leave it uncontrolled with `defaultPressed`. Put text in a `Text` and icons in `ToggleIcon`.

Icon-only toggles need an `accessibilityLabel`. To group toggles with single or multiple selection, use Toggle Group. `toggleVariants`, `toggleStateClassName` and `toggleTextClassName` are exported for reuse in custom components.

## Accessibility

- Uses the `togglebutton` role and reports `checked` and `disabled` in `accessibilityState`.
- Inside a single-select Toggle Group, it uses the `radio` role instead.
- Icon-only toggles need an `accessibilityLabel`.

## Notes

- Changing the state triggers a selection haptic when a haptics adapter is provided through `HapticsContext`.
- Uses the `bg-item-selected`, `bg-item-pressed`, `bg-control-disabled`, `text-link` and `border-separator` tokens.
- Light and dark colors follow the system appearance.
