`Dialog` opens a centered card over a dimmed scrim. `DialogContent` renders through a portal (inside a full-window overlay on iOS), scales and fades in, and shows a round close button in the top-right corner by default. Tapping the scrim closes the dialog.

Use it for short forms and information that the user can dismiss freely. When the user must make an explicit choice, use Alert Dialog instead.

## Usage

<Code lang="tsx" code={"import { DialogOverlay, DialogContent, DialogHeader, DialogFooter, DialogTitle, DialogDescription } from \"@/components/ui/dialog\""} />

<Code lang="tsx" code={"<View className=\"items-start\">\n  <Dialog defaultOpen>\n    <DialogTrigger render={<Button variant=\"outline\" />}>\n      <Text>Edit profile</Text>\n    </DialogTrigger>\n    <EditProfileContent />\n  </Dialog>\n</View>"} />

Compose `DialogTrigger` and `DialogContent` with a `DialogHeader` (`DialogTitle`, `DialogDescription`), your content, and a `DialogFooter`. Footer buttons stack vertically with the first child at the bottom, and sit in a row aligned to the end on wider screens. Use `DialogClose` with `render` to turn any `Button` into a close button.

Set `showCloseButton={false}` on the content to hide the corner button, or pass `closeLabel` to show a text button such as "Done" instead of the icon. The header adds end padding so the title does not run under it. `DialogFooter` takes `showCloseButton` to append a secondary Close button.

Use `open` and `onOpenChange` for controlled state, or `defaultOpen` for uncontrolled.

## Accessibility

- The popup has the `dialog` role, is labelled by the title and is marked as modal for VoiceOver.
- Focus moves to the title when the dialog opens.
- The Android back button and the VoiceOver escape gesture close it.
- The icon close button is labelled "Close".

## Notes

- On iOS the content is wrapped in a full-window overlay so it appears above native navigation.
- Animations respect the system Reduce Motion setting.
- Uses `bg-surface-raised`, `bg-scrim` and `bg-surface-tertiary` tokens; light and dark follow the system appearance.
