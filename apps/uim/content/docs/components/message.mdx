`Message` is a horizontal `View` that places an avatar next to a column of bubbles. Its `align` prop puts the row on the leading (`start`) or trailing (`end`) side and passes the alignment to any `Bubble` inside through context.

`MessageGroup` stacks several messages into a conversation. `MessageHeader` and `MessageFooter` hold small secondary text, such as a sender name or a timestamp.

## Usage

<Code lang="tsx" code={"import { MessageGroup, Message, MessageAvatar, MessageContent, MessageHeader, MessageFooter } from \"@/components/ui/message\""} />

<Code lang="tsx" code={"<Message align=\"start\">\n  <MessageAvatar>\n    <Avatar>\n      <AvatarFallback>MK</AvatarFallback>\n    </Avatar>\n  </MessageAvatar>\n  <MessageContent>\n    <Bubble variant=\"muted\">\n      <BubbleContent>Are we still on for lunch tomorrow?</BubbleContent>\n    </Bubble>\n  </MessageContent>\n</Message>"} />

Put a `MessageAvatar` and a `MessageContent` inside each `Message`, and place `Bubble` components, a `MessageHeader` and a `MessageFooter` in `MessageContent`.

Plain strings in `MessageHeader` and `MessageFooter` are wrapped in `Text` for you, so you can pass text directly or mix it with an `Icon`.

When `MessageContent` contains a `MessageFooter`, the avatar shifts up so it lines up with the last bubble instead of the footer.

## Accessibility

- Messages are plain `View` and `Text` elements, so screen readers read the header, bubble text and footer in order.
- Give avatars without visible text, such as images, an `accessibilityLabel`.

## Notes

- Header and footer text use `text-xs text-label-secondary`, with icons at `size-3.5`.
- The avatar slot uses `bg-surface-secondary`.
- Light and dark colors follow the system appearance.
