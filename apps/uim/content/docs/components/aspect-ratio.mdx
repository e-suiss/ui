`AspectRatio` is a `View` that sets the `aspectRatio` style from its `ratio` prop. Its height follows from the width it is given, so the content keeps its shape at any screen size.

Use it for images, video thumbnails and placeholders that must not stretch.

## Usage

<Code lang="tsx" code={"<View className=\"w-full overflow-hidden rounded-lg\">\n  <AspectRatio ratio={16 / 9}>\n    <Image source={{ uri: imageUri }} className=\"h-full w-full\" />\n  </AspectRatio>\n</View>"} />

Pass `ratio` as width divided by height, such as `16 / 9`. It defaults to `1`. Size the content inside with `h-full w-full`, and put rounding or clipping on a parent view.
