`Button` is a `Pressable` with the `button` role. It supports eight visual variants, five text sizes and five icon-only sizes, and an optional `block` mode that fills the width of its container.

Use the `default` variant for the primary action on a screen, `secondary`, `tinted` or `outline` for supporting actions, `ghost` and `plain` for low-emphasis actions, and `destructive` for actions that delete or remove. To join several buttons into one control, use Button Group.

## Usage

<Code lang="tsx" code={"import { Button } from \"@/components/ui/button\""} />

<Code lang="tsx" code={"<View className=\"items-start\">\n  <Button>\n    <Text>Button</Text>\n  </Button>\n</View>"} />

Put the label in a `Text` and icons in an `Icon`. The button passes its text color and icon size down through context, so children pick them up without extra classes.

Use an `icon` size, such as `icon` or `icon-sm`, for buttons that contain only an icon, and give them an `accessibilityLabel`.

`buttonVariants` and `buttonTextVariants` are also exported if you need the classes on another element.

## Accessibility

- Renders a `Pressable` with `role="button"`, so VoiceOver and TalkBack announce it as a button.
- `disabled` is announced and blocks presses.
- Icon-only buttons need an `accessibilityLabel`.

## Notes

- Colors come from semantic tokens such as `bg-accent`, `bg-control`, `bg-accent-surface` and `bg-danger-surface`, each with pressed and disabled states.
- Light and dark colors follow the system appearance.
