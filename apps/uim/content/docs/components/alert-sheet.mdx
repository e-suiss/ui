`AlertSheet` presents a set of choices related to the current context. `AlertSheetContent` renders through a portal (inside a full-window overlay on iOS), slides up from the bottom over a dimmed scrim, and respects the safe-area insets.

Actions sit in an `AlertSheetGroup`, a rounded card that draws a hairline between each child, and `AlertSheetCancel` sits below it as its own card with bold text. Use it for two to a few actions; for a single decision that needs confirmation, use Alert Dialog.

## Usage

<Code lang="tsx" code={"import { AlertSheet, AlertSheetOverlay, AlertSheetContent, AlertSheetGroup, AlertSheetHeader, AlertSheetTitle, AlertSheetDescription, AlertSheetAction, AlertSheetCancel } from \"@/components/ui/alert-sheet\""} />

<Code lang="tsx" code={"<View className=\"items-start\">\n  <AlertSheet defaultOpen>\n    <AlertSheetTrigger render={<Button variant=\"outline\" />}>\n      <Text>Show sheet</Text>\n    </AlertSheetTrigger>\n    <SheetBody />\n  </AlertSheet>\n</View>"} />

Compose `AlertSheetTrigger` and `AlertSheetContent`. Inside the content, put an `AlertSheetGroup` with an optional `AlertSheetHeader` (`AlertSheetTitle`, `AlertSheetDescription`) followed by `AlertSheetAction`s, then an `AlertSheetCancel`.

Every action closes the sheet when pressed. String children are wrapped in `Text` automatically. Use `variant="destructive"` on an action that deletes or removes, and `disabled` to dim and block it.

By default the sheet is dismissible and a tap on the scrim closes it. Set `dismissible={false}` to require an explicit choice.

## Accessibility

- When dismissible the popup has the `dialog` role, otherwise `alertdialog`; it is labelled by the title and marked as modal for VoiceOver.
- Focus moves to the title when the sheet opens.
- Actions have the `button` role with a `disabled` state.
- Separators between actions are hidden from screen readers.

## Notes

- Padding uses the bottom and side safe-area insets, with a minimum of 8 points.
- On iOS the content is wrapped in a full-window overlay.
- Animations respect the system Reduce Motion setting.
- Uses `bg-surface-raised`, `bg-item-pressed`, `text-link` and `text-danger` tokens; light and dark follow the system appearance.
