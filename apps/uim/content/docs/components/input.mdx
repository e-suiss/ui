`Input` wraps a `TextInput` through the field control primitive. It tracks its own focused, filled, invalid and disabled state and styles itself from that state: a focus border while editing, a danger border and tint when invalid, and muted colors when disabled.

It comes in three sizes: `default` (44 pt), `md` and `sm`. Use the default size for forms on a full screen, and the smaller sizes inside dense layouts such as toolbars or sheets.

## Usage

<Code lang="tsx" code={"import { Input } from \"@/components/ui/input\""} />

<Code lang="tsx" code={"<Input placeholder=\"Email\" />"} />

Pass any `TextInput` prop, such as `placeholder`, `secureTextEntry`, `keyboardType` or `inputMode`, to get the matching field type.

The value works controlled with `value` and `onValueChange(value, details)`, or uncontrolled with `defaultValue`. Inside a `Field`, the input picks up the field's label, description, invalid and disabled state, so you usually set `invalid` on the `Field` instead of on the input.

`className` can be a function that receives the state (`focused`, `invalid`, `disabled`, `filled`, …) and returns classes.

## Accessibility

- Inside a `Field`, the input is linked to the field label through `accessibilityLabelledBy` and gets the label as `accessibilityLabel` and the description as `accessibilityHint`.
- `disabled` is set in `accessibilityState` and makes the input non-editable.
- Outside a `Field`, give the input an `accessibilityLabel`; a placeholder alone is not a label.

## Notes

- Uses the `bg-control`, `border-focus`, `border-danger` and `bg-control-disabled` tokens.
- Placeholder, cursor and selection colors come from the `label-secondary` and `accent` tokens.
- Light and dark colors follow the system appearance.
