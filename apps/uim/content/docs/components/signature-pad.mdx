`SignaturePad` is a `View` with a single-finger pan gesture from `react-native-gesture-handler`. Each touch records a stroke of points, and the strokes are drawn as smoothed paths with `react-native-svg`. A signature line with an `×` mark and a placeholder sits near the bottom, and a ghost Clear button appears in the top corner once something is drawn.

## Usage

<Code lang="tsx" code={"import { SignaturePad } from \"@/components/ui/signature-pad\""} />

<Code lang="tsx" code={"<SignaturePad />"} />

Use it uncontrolled with `defaultValue`, or controlled with `value` and `onChange`. The value is an array of strokes, where each stroke is an array of `{ x, y }` points.

Pass a `ref` to get a `SignaturePadHandle` with `toSVG()`, `clear()` and `isEmpty()`. `toSVG` returns an SVG string sized to the pad and accepts an optional `color` (defaults to `currentColor`).

The `SignaturePadHandle`, `SignaturePadPoint` and `SignaturePadStroke` types are also exported.

## Accessibility

- The pad is a single accessible element labeled by `accessibilityLabel`.
- Its value is announced as "Empty" or "Signed", and `disabled` is reported in its state.
- When it has a signature and is not disabled, it offers a `clear` accessibility action, so VoiceOver and TalkBack users can clear it without finding the button.

## Notes

- Uses `bg-surface-raised` in light mode and `bg-surface-secondary` in dark mode, with `border-separator` and `text-label` for the strokes.
- Points closer than one point to the previous point are skipped while drawing.
