`Spinner` wraps the native `ActivityIndicator` in a square `View`. The indicator is scaled from its native small size to the `size` you pass, so it can match text and icon sizes. Its color is set through a class.

## Usage

<Code lang="tsx" code={"import { Spinner } from \"@/components/ui/spinner\""} />

<Code lang="tsx" code={"<Spinner />"} />

Set `size` in points (default `16`) and `colorClassName` with an `accent-*` class, such as `accent-accent` or `accent-danger`. Inside a button, use `accent-on-accent` on the `default` variant so the spinner matches the label.

## Accessibility

- The wrapper has `role="progressbar"`, is `accessible`, and sets `busy: true` in `accessibilityState`.
- It is announced as `"Loading"` unless you pass another `accessibilityLabel`.

## Notes

- The default color uses the `label-secondary` token.
- The look of the indicator comes from the platform's native activity indicator, so it differs between iOS and Android.
