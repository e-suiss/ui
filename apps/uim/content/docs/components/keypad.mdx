`Keypad` lays out digits 1 to 9 in three rows and a bottom row with an accessory key, `0` and a delete key. Each key is a `KeypadKey`, a round `Pressable` with the `button` role. Digit keys have a filled background; the accessory and delete keys use the `plain` variant with no fill.

Use it for PIN entry, amounts and other numeric input where the system keyboard is not wanted.

## Usage

<Code lang="tsx" code={"import { KeypadKey, Keypad } from \"@/components/ui/keypad\""} />

<Code lang="tsx" code={"<KeyLog />"} />

Handle input in `onKeyPress`, which receives a digit string (`"0"` to `"9"`), `"decimal"`, `"delete"` or `"biometric"`. The keypad holds no value of its own.

Set `accessoryKey` to `decimal` or `biometric` to fill the bottom-left slot; otherwise it stays empty. Change the decimal character with `decimalSeparator` and the biometric icon with `biometricIcon`.

Use `deleteDisabled` to turn off only the delete key, for example when the value is empty. `KeypadKey` is exported for custom layouts, along with the `KeypadDigit`, `KeypadKeyValue` and `KeypadAccessoryKey` types.

## Accessibility

- Every key has the `button` role and an `accessibilityLabel`: the digit itself, or `decimalLabel`, `biometricLabel` and `deleteLabel` for the other keys.
- Disabled keys set `disabled` in their accessibility state and block presses.
- Translate the default labels (`Decimal separator`, `Use biometrics`, `Delete`) for localized apps.

## Notes

- Filled keys use `bg-control`, `bg-control-pressed` when pressed and `bg-control-disabled` when disabled.
- Digits use `text-2xl` with tabular numbers.
- Light and dark colors follow the system appearance.
