Charts are composed declaratively: a chart root such as `LineChart`, `AreaChart`, `BarChart`, `ComposedChart`, `PieChart`, `RadialBarChart` or `RadarChart` goes inside a `ChartContainer`, and series and axes such as `Line`, `Area`, `Bar`, `XAxis`, `YAxis` and `CartesianGrid` are added as children. These child components render nothing themselves; the root reads them and draws everything with `react-native-svg`.

Colors are theme tokens, not hex values. A series `color` such as `blue`, `teal` or `accent` resolves to the current token color, so charts follow light and dark mode automatically.

## Usage

<Code lang="tsx" code={"import { ChartPalette, ChartContainer, LineChart, AreaChart, BarChart, ComposedChart, PieChart, RadialBarChart, RadarChart, ChartTooltipContent, ChartLegendContent } from \"@/components/ui/chart\""} />

<Code lang="tsx" code={"<StackedTooltipChart\n  title=\"Dot indicator\"\n  description='indicator=\"dot\"'\n  defaultIndex={2}\n  content={<ChartTooltipContent indicator=\"dot\" />}\n/>"} />

Describe each series in a `ChartConfig` object with a `label`, a token `color` and an optional `icon`, and pass it to `ChartContainer` as `config`. The container is full width with a 16:9 aspect ratio unless you give it an `h-`, `size-` or `aspect-` class.

Add `ChartTooltip` with `content={<ChartTooltipContent />}` to make the chart respond to touch: touching or dragging selects the nearest data point, draws a cursor and shows the tooltip, with a selection haptic. `ChartTooltipContent` supports `indicator` (`dot`, `line` or `dashed`), `hideLabel`, `hideIndicator`, `labelFormatter`, `formatter` and `nameKey`. Use `defaultIndex` on `ChartTooltip` to start with a point selected, or `onActiveIndexChange` on the chart to react to selection.

Add `ChartLegend` with `content={<ChartLegendContent />}` for a legend in config order. `useChart()` returns the config inside a container, and `ChartPalette` resolves token colors for custom drawing.

## Accessibility

- The chart is one accessible element labelled with its series names and data range; pass `accessibilityLabel` to `ChartContainer` to override the names.
- With a tooltip it has the `adjustable` role: VoiceOver and TalkBack swipe actions step through data points, and the selected values are announced as the value text.
- Without a tooltip it has the `image` role.

## Notes

- Series colors accept named tokens such as `blue`, `green`, `teal`, `accent`, `success`, `danger` and `label`; grid and cursor lines use `separator`.
- Light and dark follow the system appearance.
