`BottomBar` is an animated `View` that adds bottom padding equal to the safe-area inset, or to the keyboard height while the keyboard is open, and animates between them with the keyboard's own timing. `BottomBarContent` adds the standard padding and spacing for the buttons inside.

Use it for the main call to action of a screen, such as checkout or a form submit button.

## Usage

<Code lang="tsx" code={"import { BottomBar, BottomBarContent } from \"@/components/ui/bottom-bar\""} />

<Code lang="tsx" code={"<Page>\n  <BottomBar>\n    <BottomBarContent>\n      <Button size=\"lg\" block>\n        <Text>Continue</Text>\n      </Button>\n    </BottomBarContent>\n  </BottomBar>\n</Page>"} />

Place `BottomBar` as the last child of the screen so it sits below the scrolling content. Stack buttons in `BottomBarContent`, or add `flex-row` to place them side by side.

Set `separator` to draw a hairline above the bar. Inside a `Screen` that already handles the bottom safe-area edge, the inset is not added twice.
