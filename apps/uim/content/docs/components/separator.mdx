`Separator` is a `View` drawn as a one-pixel line. Horizontal separators fill the width of their container; vertical separators stretch to the height of a row.

Use the default `horizontal` orientation between stacked blocks, and `orientation="vertical"` between items in a row. Add spacing with `className`, such as `my-4`.
