`Empty` is a centered column that fills the available space and holds an `EmptyHeader` with optional `EmptyMedia`, an `EmptyTitle` and an `EmptyDescription`, followed by `EmptyContent` for actions. Text is centered and the header and content are limited to a readable width.

Use it for empty lists, search results with no matches and first-run screens.

## Usage

<Code lang="tsx" code={"import { Empty, EmptyHeader, EmptyMedia, EmptyTitle, EmptyDescription, EmptyContent } from \"@/components/ui/empty\""} />

<Code lang="tsx" code={"<Empty>\n  <EmptyHeader>\n    <EmptyMedia variant=\"icon\">\n      <Icon as={FolderOpenIcon} />\n    </EmptyMedia>\n    <EmptyTitle>No projects yet</EmptyTitle>\n    <EmptyDescription>\n      You haven't created any projects yet. Get started by creating your\n      first project.\n    </EmptyDescription>\n  </EmptyHeader>\n  <EmptyContent>\n    <Button>\n      <Text>Create project</Text>\n    </Button>\n    <Button variant=\"link\">\n      <Text>Import project</Text>\n    </Button>\n  </EmptyContent>\n</Empty>"} />

`EmptyMedia` has two variants: `default` shows its child as is, such as an illustration, and `icon` puts an `Icon` in a small rounded tile. Put buttons or links in `EmptyContent`.

Add a background class such as `bg-surface-secondary` to `Empty` for a filled panel.

## Accessibility

- `EmptyTitle` has the `heading` role.
- `EmptyMedia` is hidden from screen readers, so the title and description must carry the message.

## Notes

- Uses `bg-surface-secondary`, `text-label` and `text-label-secondary` tokens; light and dark follow the system appearance.
