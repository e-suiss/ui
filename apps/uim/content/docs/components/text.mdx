`Text` renders a React Native `Text` with one of twelve typography variants: `default`, `h1`–`h4`, `p`, `blockquote`, `code`, `lead`, `large`, `small` and `muted`. Heading variants also set the `heading` role.

It reads `TextClassContext`, so components such as `Button` can pass a text color and size down to any `Text` inside them.

## Usage

<Code lang="tsx" code={"import { Text } from \"@/components/ui/text\""} />

<Code lang="tsx" code={"<Text>The quick brown fox jumps over the lazy dog.</Text>"} />

Pick a `variant` for the role of the text, and add classes through `className` for one-off changes.

Use the `render` prop to render a different component with the same classes. `TextClassContext` is exported so your own components can style nested `Text` the same way.

## Accessibility

- `h1` to `h4` set `role="heading"`, so VoiceOver and TalkBack can navigate by heading.
- Text scales with the system font size.

## Notes

- Colors use the `text-label` and `text-label-secondary` tokens; `code` uses `bg-surface-secondary` and `blockquote` a `border-separator` start border.
- Light and dark colors follow the system appearance.
