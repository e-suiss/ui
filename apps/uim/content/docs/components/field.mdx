`Field` wraps one control, such as an `Input`, `Textarea` or `Switch`, with a `FieldLabel`, an optional `FieldDescription` and a `FieldError`. It shares the field's disabled and invalid state with the control and handles validation: required values, length limits and custom `validate` functions, checked on submit, blur or change.

`FieldSet` and `FieldLegend` group related fields under a heading, and `FieldGroup` stacks fields. The `inset` variant of `FieldGroup` turns the fields into rows on a rounded secondary surface with hairlines between them, like a settings list.

## Usage

<Code lang="tsx" code={"import { FieldSet, FieldLegend, FieldGroup, Field, FieldContent, FieldLabel, FieldTitle, FieldDescription, FieldSeparator, FieldError } from \"@/components/ui/field\""} />

<Code lang="tsx" code={"<Field>\n  <FieldLabel>Username</FieldLabel>\n  <Input placeholder=\"evilrabbit\" autoCapitalize=\"none\" />\n  <FieldDescription>\n    Choose a unique username for your account.\n  </FieldDescription>\n</Field>"} />

Put a `FieldLabel`, the control and a `FieldError` inside `Field`. The control is labelled by the label and uses the description and error text as its accessibility hint. Set `invalid` to force the error state, or let validation decide it.

`FieldError` shows its children, or the messages from `errors` (for example from a form library), and can be limited to one failure with `match`, such as `tooShort`. Use `orientation="horizontal"` for a label beside a switch or checkbox, with `FieldContent` holding a `FieldTitle` and `FieldDescription`.

`FieldSeparator` divides fields and can show short text such as "or" in the middle.

## Accessibility

- The control is labelled by `FieldLabel` and gets the description and error text as its accessibility hint.
- `FieldError` has the `alert` role, so screen readers announce it when it appears.
- `FieldSet` has the `group` role labelled by its legend; the legend has the `header` role.
- Disabled state is passed to the label and control.

## Notes

- Uses `text-label`, `text-label-secondary`, `text-danger` and `bg-surface-secondary` tokens; light and dark follow the system appearance.
- Inset separators use start and end offsets, so they flip in right-to-left layouts.
