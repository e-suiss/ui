`Marker` is a row of secondary text with an optional icon. It has three variants: `default` for a plain row, `separator` for centered text with a line on each side, and `border` for a row with a bottom border.

Use `separator` for date dividers in a chat or feed, `border` for section headings, and `default` for short notices.

## Usage

<Code lang="tsx" code={"import { Marker, MarkerIcon, MarkerContent } from \"@/components/ui/marker\""} />

<Code lang="tsx" code={"<View className=\"gap-8\">\n  <Marker>\n    <MarkerIcon>\n      <Icon as={InfoIcon} />\n    </MarkerIcon>\n    <MarkerContent>Messages are end-to-end encrypted.</MarkerContent>\n  </Marker>\n  <Marker variant=\"separator\">\n    <MarkerContent>Today</MarkerContent>\n  </Marker>\n  <Marker variant=\"border\">\n    <MarkerIcon>\n      <Icon as={CalendarBlankIcon} />\n    </MarkerIcon>\n    <MarkerContent>Upcoming</MarkerContent>\n  </Marker>\n</View>"} />

Put the text in `MarkerContent` and an `Icon` in `MarkerIcon`. Text and icons inside the marker pick up the secondary label color and size through context.

Pass a `render` element to `Marker` to render it as another component instead of a `View`.

## Accessibility

- `MarkerIcon` and the separator lines are hidden from screen readers, so only the text is read.
- If the icon carries meaning, include it in the text.

## Notes

- Text uses `text-sm text-label-secondary` and icons `size-4`.
- Lines and the bottom border use `bg-separator` and `border-separator`.
- Light and dark colors follow the system appearance.
