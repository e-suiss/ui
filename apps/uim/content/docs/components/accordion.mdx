`Accordion` groups `AccordionItem`s, each with an `AccordionTrigger` and an `AccordionContent` panel. The root and items are Reanimated views with a layout transition, so items below move smoothly as a panel opens or closes, and the trigger's caret rotates as it opens.

The `default` variant draws items on the page background separated by hairlines. The `filled` variant puts the whole list on a rounded secondary surface, which suits grouped settings or FAQ cards.

## Usage

<Code lang="tsx" code={"import { Accordion, AccordionItem, AccordionTrigger, AccordionContent } from \"@/components/ui/accordion\""} />

<Code lang="tsx" code={"<Accordion defaultValue={[\"item-2\"]}>\n  <AccordionItems />\n</Accordion>"} />

Give each `AccordionItem` a `value`. By default only one item is open at a time; set `multiple` to let several stay open.

Use `defaultValue` (an array of item values) for uncontrolled state, or `value` with `onValueChange` to control it. Set `disabled` on the root or on a single item to block toggling, and `keepMounted` to keep closed panels mounted.

`accordionVariants` is also exported if you need the classes elsewhere.

## Accessibility

- The header row has the `header` role, and the trigger has the `button` role with `expanded` and `disabled` accessibility state.
- Closed panels are hidden from VoiceOver and TalkBack.
- A disabled trigger uses a dimmed label color.

## Notes

- The trigger label underlines while pressed.
- Animations respect the system Reduce Motion setting.
- Uses `bg-surface-secondary`, `border-separator` and `text-label` tokens; light and dark follow the system appearance.
