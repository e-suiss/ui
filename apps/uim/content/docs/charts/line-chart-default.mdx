The baseline line chart inside a `Card`: one series drawn as a natural curve with a month axis, a dashed horizontal grid and a tooltip. There is no value axis.

## Usage

<Code lang="tsx" code={"import { LineChartDefault } from \"@/components/charts/line-chart-default\""} />

<Code lang="tsx" code={"<LineChartDefault />"} />

Replace `chartData` with your records and change each `dataKey` to match your fields. Set the label and color in `chartConfig`, and change the curve with the `type` prop on `Line`. The component takes no props.
