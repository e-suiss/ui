## Overview

`@esuiss/ui` runs with `npx` and is never installed in your project. It has two commands: `init` and `add`. It is the same command as the web library [suiss/ui](https://ui.suiss.app) uses: it detects whether the folder holds an Expo or React Native app, an Xcode project, an Android Gradle module or a web app, and adds the matching sources.

## init

Sets up the styling, the theme and the `button` component. See [Installation](/docs/installation) for every step.

```bash title="Terminal"
npx @esuiss/ui@latest init [options]
```

| Option | Description |
| --- | --- |
| `-s, --styling <uniwind\|nativewind\|stylesheet>` | Styling to use, detected from the project when omitted |
| `-y, --yes` | Skip confirmation prompts |
| `-c, --cwd <dir>` | Run in another project directory |
| `-h, --help` | Show help |
| `-v, --version` | Show the version |

## add

Copies components into your project, together with the components and packages they depend on.

```bash title="Terminal"
npx @esuiss/ui@latest add [options]
npx @esuiss/ui@latest add <component...> [options]
```

| Option | Description |
| --- | --- |
| `-a, --all` | Add every component |
| `--diff` | Show how local files differ from the registry |
| `-o, --overwrite` | Replace local files that differ from the registry |
| `-y, --yes` | Skip confirmation prompts |
| `-c, --cwd <dir>` | Run in another project directory |

### Pick from a list

Run `add` without names to pick from a list. Choose components, patterns, interactions, charts or blocks, type to filter, select with space and press enter. In SwiftUI and Jetpack Compose projects the list only shows what exists for that platform.

```bash title="Terminal"
npx @esuiss/ui@latest add
npx @esuiss/ui@latest add --platform swift
```

Outside an interactive terminal, such as in CI, `add` without names prints the available names instead.

## Update a component

Check what changed, then overwrite:

```bash title="Terminal"
npx @esuiss/ui@latest add button --diff
npx @esuiss/ui@latest add button --overwrite
```
