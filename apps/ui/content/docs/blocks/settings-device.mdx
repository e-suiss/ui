A phone-style Settings screen with a search field, an account row and grouped rows that either open a detail page or hold a switch. Search filters rows by label, and turning on Airplane Mode also turns off Wi-Fi and Bluetooth. From small tablets up the screen sits in a phone frame; on the smallest screens it fills the width. Use it for mobile app settings or any grouped preferences list.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/settings-device
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks settings-device
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Avatar](/docs/components/avatar), [Input Group](/docs/components/input-group), [Item](/docs/components/item), [Switch](/docs/components/switch).

3. Copy the source into `components/blocks/settings-device.tsx`:

<ComponentSource path="components/blocks/settings-device.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { SettingsDevice } from "@/components/blocks/settings-device"
```

```tsx
<SettingsDevice />
```

Edit `groups`; each row has a label, icon, tint and either a `toggle` key or a `detail` function that derives its status text from the toggles. Persist the toggles to your settings store, and remove the Airplane Mode coupling if it doesn't apply. Row links point to hash anchors, so swap in your routes.

A large-title `Header` sits over an `InputGroup` search field, an account `Item` with an `Avatar`, and inset `ItemGroup` lists of rows with tinted icons. Airplane Mode and Focus use a `Switch`; Wi-Fi, Bluetooth and the other rows show a detail value and a chevron. Typing filters the rows and shows a message when nothing matches.

## Usage

```tsx
import { SettingsDevice } from "@/components/blocks/settings-device"
```

```tsx
<SettingsDevice />
```

Replace `GROUPS` with your rows and the account details with your user. Use `onAccountPress` and `onRowPress`, which receives the row label, to navigate.
