A `Carousel` of pages, each with an icon illustration, a title and a description. A `BottomBar` holds a `PageIndicator` you can tap to jump to a page, a Continue `Button` that moves to the next page and becomes Get started on the last, and a Skip button.

## Installation

<Only platform="rn">

```bash title="Terminal"
npx shadcn@latest add @esuiss/onboarding
```

See [Installation](/docs/installation) for the `components.json` setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add onboarding
```

</Only>

<Only platform="swift">

```bash title="Terminal"
npx @esuiss/ui@latest add onboarding --platform swift
```

</Only>

<Only platform="kotlin">

```bash title="Terminal"
npx @esuiss/ui@latest add onboarding --platform kotlin
```

</Only>

The CLI also adds what it builds on: [Bottom Bar](/docs/components/bottom-bar), [Button](/docs/components/button), [Carousel](/docs/components/carousel), [Icon](/docs/components/icon), [Page Indicator](/docs/components/page-indicator), [Screen](/docs/components/screen), [Text](/docs/components/text).

## Usage

```tsx
import { Onboarding } from "@/components/blocks/onboarding"
```

```tsx
<Onboarding />
```

Pass your own `pages` (each with a `title`, `description` and optional `illustration`), or edit `DEFAULT_PAGES`. `onDone` is called from Get started and Skip.
