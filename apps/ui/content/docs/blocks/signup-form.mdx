A full account creation form with name, country, birthday, email and a password with confirmation, grouped into labeled sections. A checklist of password rules appears as the user types, and mismatched passwords turn the fields red. Submitting a valid form shows a success view. Use it when you need more than an email and password at signup.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/signup-form
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add blocks signup-form
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Button](/docs/components/button), [Input](/docs/components/input), [Native Select](/docs/components/native-select).

3. Copy the source into `components/blocks/signup-form.tsx`:

<ComponentSource path="components/blocks/signup-form.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { SignupForm } from "@/components/blocks/signup-form"
```

```tsx
<SignupForm />
```

Replace the success branch with your registration API call. Edit `rules` for the password checklist and the country list inline. The birthday is free text and is never parsed, so swap in a date picker or validate it before sending.

## Notes

Every text field has an autocomplete value so browsers and password managers can fill it, and the form runs its own validation instead of the browser's.

Fields are grouped under short legends inside an `InputAccessoryBar` with a `KeyboardScrollView`, and the country uses a `Picker`. The password fields show a live checklist of password rules, and pressing Continue in the `BottomBar` validates every field, shows an error line if any fail, and swaps the form for a confirmation screen.
