A buy page where shoppers pick a model, a finish and a storage size while the product photo and price update to match. On desktop the photo sits beside the options; on mobile it shrinks to a panel above them, and a sticky footer keeps the price and Add to Bag button in reach. Good for any configurable product, such as hardware, tiered subscriptions or made-to-order goods.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/bag-configure
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add blocks bag-configure
```

## Usage

```tsx
import { BagConfigure } from "@/components/blocks/bag-configure"
```

```tsx
<BagConfigure />
```

Edit the `models`, `finishes` and `storage` lists: models carry a base price, finishes a swatch color and photo, and storage options a surcharge. The price is the model price plus the storage surcharge, with a 12-month estimate below it. Replace the Add to Bag handler, which only flips a local flag, with your cart call, and update the heading copy.

## Notes

Price changes are announced to screen readers, and each swatch is labeled with its finish name. Photos are Unsplash placeholders.
