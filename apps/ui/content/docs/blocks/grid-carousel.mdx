A horizontally scrolling row of product cards under a two-tone heading, each with an optional kicker, name, tagline, starting price and image. Previous and next buttons sit below the track, and cards shrink to fit narrow screens. With no state of its own, it is a simple base for latest products, featured items or related content rows.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/grid-carousel
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks grid-carousel
```

### Manual

1. Add the pieces it builds on: [Carousel](/docs/components/carousel).

2. Copy the source into `components/blocks/grid-carousel.tsx`:

<ComponentSource path="components/blocks/grid-carousel.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { GridCarousel } from "@/components/blocks/grid-carousel"
```

```tsx
<GridCarousel />
```

Replace `products`; each has an optional kicker, a name, tagline, formatted price, image and alt text. Card links are hash anchors built from the name, so point them at your product pages.
