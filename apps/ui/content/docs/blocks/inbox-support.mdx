<ComponentPreview type="block" name="inbox-support" />

A help desk inbox with Open, Pending, Solved and All views and live counts, a ticket list with priority badges and a detail pane for replying or marking a ticket solved. Sending a reply moves the ticket to Pending. On mobile the panes show one at a time with a back button. A good base for support queues, moderation queues or any triage workflow.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/inbox-support
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks inbox-support
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Avatar](/docs/components/avatar), [Button](/docs/components/button), [Split View](/docs/patterns/split-view), [Textarea](/docs/components/textarea), [Toggle Group](/docs/components/toggle-group).

3. Copy the source into `components/blocks/inbox-support.tsx`:

<ComponentSource path="components/blocks/inbox-support.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { InboxSupport } from "@/components/blocks/inbox-support"
```

```tsx
<InboxSupport />
```

Replace `initialTickets` with your tickets, each with an id, title, device, status, priority, requester and avatar hue; `priorityClass` maps priorities to badge colors. Connect the reply and Mark as solved actions to your help desk API. Every ticket shows the same hard-coded customer message and timestamp, so load the real conversation.

A help desk screen built on `SplitView`, with a sidebar of queues, a list of tickets showing the requester `Avatar`, priority and device, and a detail view. In the detail view a `ToggleGroup` changes the ticket status, a `Textarea` takes a reply, Send and set pending sends it and moves the ticket to Pending, and Mark as solved closes it.
