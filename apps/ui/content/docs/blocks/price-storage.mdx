A cloud storage plan picker with a monthly or yearly switch, four plan cards with feature lists and a button that names the selected plan. One card carries a Most popular badge. Cards show one column on mobile, two on tablets and four on large screens. Use it for storage, seat or usage-based pricing.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/price-storage
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks price-storage
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Button](/docs/components/button), [Label](/docs/components/label), [Radio Group](/docs/components/radio-group), [Toggle Group](/docs/components/toggle-group).

3. Copy the source into `components/blocks/price-storage.tsx`:

<ComponentSource path="components/blocks/price-storage.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { PriceStorage } from "@/components/blocks/price-storage"
```

```tsx
<PriceStorage />
```

Edit `plans`; each has a size, monthly price, a list of features and an optional popular flag. Yearly prices are ten times the monthly price to match the 2 months free label, so change both together. Replace the button handler, which only shows a confirmation, with your billing call.

The selected card lifts slightly, and the most popular plan carries a label. Yearly prices show ten months of the monthly price. A `BottomBar` `Button` confirms the switch.
