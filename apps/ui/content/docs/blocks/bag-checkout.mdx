A checkout that walks the shopper through delivery, payment and review one step at a time, with the order summary and running total alongside. Finished steps collapse to a short summary with an Edit button, and placing the order swaps the form for a confirmation. The summary sits beside the steps on desktop and stacks into a single column on mobile. Use it as the base for any multi-step purchase or booking flow.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/bag-checkout
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks bag-checkout
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Button](/docs/components/button), [Label](/docs/components/label), [Radio Group](/docs/components/radio-group).

3. Copy the source into `components/blocks/bag-checkout.tsx`:

<ComponentSource path="components/blocks/bag-checkout.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { BagCheckout } from "@/components/blocks/bag-checkout"
```

```tsx
<BagCheckout />
```

Swap the `items` array for your cart lines, each with a name, variant, price and image. The delivery and payment options and the express surcharge are hard-coded in the component, so drive them from your shipping and payment providers. Wire Place Order to your order API; today it only shows a confirmation with the fixed order number W1049.

## Notes

Collapsed steps are `inert`, so keyboard users only reach the open step, and the total is announced when it changes. Product photos are Unsplash placeholders.

A checkout built from `Screen`, `Header` with a collapsing large title, `RadioGroup`, `Button`, `Icon` and `BottomBar`. Delivery and payment are chosen with radio options, finished steps collapse to a one-line summary with an Edit link, and the bottom bar button advances through the steps. The total updates when express delivery is picked, and placing the order shows a confirmation screen with a Start over link.
