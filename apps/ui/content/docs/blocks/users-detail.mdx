A user directory with members on the left and the selected user's profile, sessions and security settings on the right, switched with tabs. Admins can change a role, sign out sessions, toggle security options and send a password reset link. It combines `Sidebar` navigation with a `SplitView`, so on mobile the list and detail show one at a time. Use it for team members, customers or any record with tabbed details.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/users-detail
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks users-detail
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Avatar](/docs/components/avatar), [Button](/docs/components/button), [Item](/docs/components/item), [Select](/docs/components/select), [Sidebar](/docs/components/sidebar), [Split View](/docs/patterns/split-view), [Switch](/docs/components/switch), [Toggle Group](/docs/components/toggle-group).

3. Copy the source into `components/blocks/users-detail.tsx`:

<ComponentSource path="components/blocks/users-detail.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { UsersDetail } from "@/components/blocks/users-detail"
```

```tsx
<UsersDetail />
```

Replace `users`, `roles` and `initialSessions` with your data. In the sample every user shares one session list, and Department and Joined are hard-coded, so load these per user. Connect the role change, session sign-outs, security switches and reset button to your user management API.

A `SplitView` lists users with an `Avatar` and status, and the detail pane shows the selected user's header and a `ToggleGroup` for Profile, Sessions and Security. Profile lists details with a role `Picker`, Sessions lets you sign out one device or all others, and Security has `Switch` rows and a password reset `Button`. The admin `TabBar` switches sections.
