An invite form that turns typed email addresses into removable chips, assigns a role and optionally sends a welcome email, with pending invitations listed below. Sending shows a toast and moves the addresses to the pending list, where each can be resent or cancelled. It sits in a `Sidebar` with admin navigation that opens as a sheet from the trigger on mobile. Use it for team invites or sharing access with several people at once.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/users-invite
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks users-invite
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Button](/docs/components/button), [Item](/docs/components/item), [Select](/docs/components/select), [Sidebar](/docs/components/sidebar), [Switch](/docs/components/switch), [Toast](/docs/components/toast).

3. Copy the source into `components/blocks/users-invite.tsx`:

<ComponentSource path="components/blocks/users-invite.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { UsersInvite } from "@/components/blocks/users-invite"
```

```tsx
<UsersInvite />
```

Replace the initial `pending` list with invitations from your API, and edit `roles`. Addresses are committed on Enter, comma, space or blur, and only valid, unique ones are added. Call your invitation API in place of the local send, resend and cancel handlers.

## Notes

Each chip's remove button names its address, and the summary line is announced as chips change.

Emails become `Chip`s as you type, and Backspace in an empty `Input` removes the last one. A `Picker` sets the role, a `Switch` toggles the welcome email, and the send `Button` adds the invites to the pending list. Pending invitations can be resent or cancelled, and sending or resending shows a toast through `Toaster`. The admin `TabBar` switches sections.
