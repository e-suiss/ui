A full site footer with numbered footnotes, a breadcrumb, a five-column link directory and a legal row with copyright and region links. On mobile the directory collapses into an accordion so the footer stays short. It is a server component with no state, suited to large marketing or store sites.

Edit `sections` for the directory, `columns` for which sections share each desktop column, and `legal` for the bottom links. Links are hash anchors from the `slug` helper, so swap it for your routing. Footnotes, the breadcrumb, phone number and copyright are inline.
