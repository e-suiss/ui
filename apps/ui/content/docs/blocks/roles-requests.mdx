An access request queue where admins approve or deny permission requests, each showing the requester, the permission, a reason and when it was asked. An Approval length menu in the header sets how long approvals last. A decided row shows its outcome briefly and then collapses out of the list, and an empty state appears once the queue is clear. Use it for access reviews, join requests or any approval inbox.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/roles-requests
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks roles-requests
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Avatar](/docs/components/avatar), [Button](/docs/components/button), [Empty](/docs/components/empty), [Select](/docs/components/select), [Sidebar](/docs/components/sidebar).

3. Copy the source into `components/blocks/roles-requests.tsx`:

<ComponentSource path="components/blocks/roles-requests.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { RolesRequests } from "@/components/blocks/roles-requests"
```

```tsx
<RolesRequests />
```

Replace `initialRequests` with your pending requests, each with a name, permission, reason, time and avatar hue. Call your API in `decide` and pass the selected `duration`. Requests are matched by name, so switch to a unique id, and remove the Reset the sample link from the empty state.

## Notes

Each decision is announced as it happens.

<Only platform="rn">

Each request shows an `Avatar`, the requester, the permission and an optional reason, with Deny and Approve `Button`s. Rows use `SwipeActions`, so swiping from the leading edge approves and from the trailing edge denies, and decided rows collapse out of the list. A `Picker` sets the grant duration, and an `Empty` state with a reset link appears once the queue is clear. It uses a collapsing `Header` and the admin `TabBar`.
