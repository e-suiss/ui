<ComponentPreview type="block" name="empty-offline" />

An offline state for a content app, with a Wi-Fi icon, an explanation and Try Again and Downloads buttons. Try Again shows a spinner while reconnecting, then reveals an album grid. Use it as the no-connection screen for media, feeds or any app that can fall back to cached content.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/empty-offline
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks empty-offline
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Button](/docs/components/button), [Empty](/docs/components/empty), [Spinner](/docs/components/spinner).

3. Copy the source into `components/blocks/empty-offline.tsx`:

<ComponentSource path="components/blocks/empty-offline.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { EmptyOffline } from "@/components/blocks/empty-offline"
```

```tsx
<EmptyOffline />
```

Replace `albums` with your content. The demo fakes reconnecting with a timer; drive the offline, loading and online states from your network status or a refetch instead, and remove the Disconnect link from the online view. Give the Downloads button a handler.
