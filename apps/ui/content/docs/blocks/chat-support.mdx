A support page with a floating chat panel holding a greeting, quick-reply suggestions, the conversation and a composer. Closing the panel shrinks it into a round launcher button that reopens it. The panel spans the bottom of the screen on mobile and docks to a corner on larger screens. Use it as the in-app help widget for a store, a SaaS product or a docs site.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/chat-support
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add blocks chat-support
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Bubble](/docs/components/bubble), [Button](/docs/components/button), [Input](/docs/components/input), [Message](/docs/components/message), [Message Scroller](/docs/components/message-scroller).

3. Copy the source into `components/blocks/chat-support.tsx`:

<ComponentSource path="components/blocks/chat-support.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { ChatSupport } from "@/components/blocks/chat-support"
```

```tsx
<ChatSupport />
```

Edit the `answers` record: each key becomes a quick-reply button and its value is the canned answer, while any other question gets a fallback about connecting to a Specialist. The `ask` function fakes a reply after a delay, so replace it with your support bot or live-agent API. Change the greeting and the hero photo in the `image` constant.

## Notes

Focus returns to the launcher when the panel closes. The hero photo is an Unsplash placeholder.

```tsx
import { ChatSupport } from "@/components/blocks/chat-support"
```

```tsx
<ChatSupport />
```

Replace `ANSWERS` and `FALLBACK` with your own replies or a call to your support service. Pass `onSend`, `onAttach` and `onOpenChange` to handle messages, attachments and the open state.
