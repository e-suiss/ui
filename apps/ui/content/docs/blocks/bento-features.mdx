A bento grid of feature tiles under a Why Phone Pro heading: a large camera photo tile, two stat tiles with gradient figures and a wide tile pairing copy with an image. Tiles stack in one column on mobile and form a four-column grid on desktop. It is static markup with no state, suited to marketing pages that summarize a product's highlights.

All copy, figures and gradient colors are inline in the JSX, so edit them in place. Images come from the `photo` helper, which takes an Unsplash photo ID and a width; swap it for your own image source. Both images are Unsplash placeholders with descriptive alt text.
