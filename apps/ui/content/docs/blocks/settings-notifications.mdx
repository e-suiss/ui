<ComponentPreview type="block" name="settings-notifications" />

Per-app notification settings with a live lock screen preview: toggle notifications and choose alert styles, banner style, sounds, badges, preview text and grouping, and the preview updates to match. The preview sits beside the settings on desktop and below them on mobile. Use it for any settings screen where a live preview helps users understand their choices.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/settings-notifications
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks settings-notifications
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Item](/docs/components/item), [Select](/docs/components/select), [Switch](/docs/components/switch), [Toggle](/docs/components/toggle), [Toggle Group](/docs/components/toggle-group).

3. Copy the source into `components/blocks/settings-notifications.tsx`:

<ComponentSource path="components/blocks/settings-notifications.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { SettingsNotifications } from "@/components/blocks/settings-notifications"
```

```tsx
<SettingsNotifications />
```

Every setting is local state, so persist each one to your settings store. `alerts`, `previewOptions` and `groupingOptions` define the choices. Replace the `wallpaper` image and the sample sender and message in the preview.

## Notes

When notifications are off, the dependent settings are dimmed and skipped by keyboard, and the preview has a text summary for screen readers. The wallpaper is an Unsplash placeholder.

A wallpaper preview shows a sample notification that reflects the current settings: hidden previews, stacking when grouping is on, and banners that fade out when set to temporary. Below it, `Switch` rows control notifications, sounds and badges, `Toggle` tiles choose Lock Screen, Notification Center and Banners, a `ToggleGroup` picks the banner style, and `Picker` rows set previews and grouping.
