A passwordless sign-in screen with an account chip, a Continue with passkey button and a fallback link to sign in with a password. Starting the flow opens a small dialog with a scanning animation that turns into a check mark, then the screen welcomes the user. Use it as the front door for passkey or biometric login.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/login-passkey
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks login-passkey
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Avatar](/docs/components/avatar), [Button](/docs/components/button), [Dialog](/docs/components/dialog).

3. Copy the source into `components/blocks/login-passkey.tsx`:

<ComponentSource path="components/blocks/login-passkey.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { LoginPasskey } from "@/components/blocks/login-passkey"
```

```tsx
<LoginPasskey />
```

The scan is faked with timers in `start`; replace it with a WebAuthn call such as `navigator.credentials.get` and move to the welcome state when it resolves. Replace the account email, initials and welcome name, and point the `#change` and `#password` links at your routes.

## Notes

Closing the dialog cancels the pending timers; abort your WebAuthn request the same way when the user cancels.
