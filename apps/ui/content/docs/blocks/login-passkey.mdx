A passwordless sign-in screen with an account chip, a Continue with passkey button and a fallback link to sign in with a password. Starting the flow opens a small dialog with a scanning animation that turns into a check mark, then the screen welcomes the user. Use it as the front door for passkey or biometric login.

<Code lang="tsx" code={"import { LoginPasskey } from \"@/components/blocks/login-passkey\""} />

<Code lang="tsx" code={"<LoginPasskey />"} />

The scan is faked with timers in `start`; replace it with a WebAuthn call such as `navigator.credentials.get` and move to the welcome state when it resolves. Replace the account email, initials and welcome name, and point the `#change` and `#password` links at your routes.

## Notes

Closing the dialog cancels the pending timers; abort your WebAuthn request the same way when the user cancels.

Continuing opens a `Dialog` with an animated scan glyph that turns into a verified state, then shows a welcome view with a Sign out link. The dialog can be cancelled during the scan.
