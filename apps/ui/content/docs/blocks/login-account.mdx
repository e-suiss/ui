A sign-in form that asks for an email first, then reveals a password field below it. Errors appear inline and shake the fields, followed by a Remember me checkbox and links for a forgotten password and account creation. A successful sign-in shows a greeting with a Sign out link. Use it for any email-and-password login.

## Usage

<Code lang="tsx" code={"import { LoginAccount } from \"@/components/blocks/login-account\""} />

<Code lang="tsx" code={"<LoginAccount />"} />

Replace the second step of `submit`, which accepts any password of four or more characters after a delay, with your authentication call, and pass its error message to `fail`. Point the `#forgot` and `#create` links at your routes, and wire the Remember me checkbox, which is uncontrolled. Drop the greeting view if you redirect after login.

## Notes

Inputs use the `username` and `current-password` autocomplete values so password managers work, and errors are tied to the fields and announced.

A sign-in screen inside a `KeyboardScrollView`. The email `Input` comes first; when the address looks valid, the password field appears below it and takes focus. Invalid input shakes the form and shows an error. It also has a Remember me `Checkbox` with a `Label`, a Forgot password link, a create account link, and a `Spinner` while signing in, followed by a welcome view with an `Avatar` and a Sign out link.
