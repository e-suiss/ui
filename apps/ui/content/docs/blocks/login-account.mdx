A sign-in form that asks for an email first, then reveals a password field below it. Errors appear inline and shake the fields, followed by a Remember me checkbox and links for a forgotten password and account creation. A successful sign-in shows a greeting with a Sign out link. Use it for any email-and-password login.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/login-account
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks login-account
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Avatar](/docs/components/avatar), [Button](/docs/components/button), [Checkbox](/docs/components/checkbox), [Input](/docs/components/input), [Label](/docs/components/label), [Spinner](/docs/components/spinner).

3. Copy the source into `components/blocks/login-account.tsx`:

<ComponentSource path="components/blocks/login-account.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { LoginAccount } from "@/components/blocks/login-account"
```

```tsx
<LoginAccount />
```

Replace the second step of `submit`, which accepts any password of four or more characters after a delay, with your authentication call, and pass its error message to `fail`. Point the `#forgot` and `#create` links at your routes, and wire the Remember me checkbox, which is uncontrolled. Drop the greeting view if you redirect after login.

## Notes

Inputs use the `username` and `current-password` autocomplete values so password managers work, and errors are tied to the fields and announced.

A sign-in screen inside a `KeyboardScrollView`. The email `Input` comes first; once a valid address is submitted, the password field appears below it and takes focus. Invalid input shakes the form and shows an error. It also has a Remember me `Checkbox` with a `Label`, a Forgot password link, a create account link, and a `Spinner` while signing in, followed by a welcome view with an `Avatar` and a Sign out link.

## Usage

```tsx
import { LoginAccount } from "@/components/blocks/login-account"
```

```tsx
<LoginAccount />
```

Wire `onSubmit` (receives the email and password) to your auth service, and `onForgotPassword` and `onCreateAccount` to your navigation. The sign-in delay and the success view are simulated in the component.
