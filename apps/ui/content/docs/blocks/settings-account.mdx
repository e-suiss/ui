An account settings page with a profile header and a sidebar of sections. Only Sign-In and Security is filled in: email and phone cards that expand into an inline edit form, a Passkeys switch, a two-factor row and a confirmation after each save, while the other sections show a placeholder. It uses a `Sidebar` that slides off canvas. Use it as the frame for any account or profile settings.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/settings-account
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks settings-account
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Avatar](/docs/components/avatar), [Button](/docs/components/button), [Input](/docs/components/input), [Sidebar](/docs/components/sidebar), [Switch](/docs/components/switch).

3. Copy the source into `components/blocks/settings-account.tsx`:

<ComponentSource path="components/blocks/settings-account.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { SettingsAccount } from "@/components/blocks/settings-account"
```

```tsx
<SettingsAccount />
```

Load the email, phone and profile details from the signed-in user, and replace the `onSave` handler with your account API. Add content for the remaining sections listed in `items`. The profile name, email and initials in the header are hard-coded.

## Notes

Collapsed edit forms are `inert`, focus moves to the input when a card opens, and save confirmations are announced.

The Sign-In & Security page has cards for email and phone that open an inline `Input` with Save and Cancel, a passkeys `Switch`, and a confirmation that appears after saving. Other sections show a placeholder.
