An account settings page with a profile header and a sidebar of sections. Only Sign-In and Security is filled in: email and phone cards that expand into an inline edit form, a Passkeys switch, a two-factor row and a confirmation after each save, while the other sections show a placeholder. It uses `AppShell` with an off-canvas sidebar. Use it as the frame for any account or profile settings.

## Notes
