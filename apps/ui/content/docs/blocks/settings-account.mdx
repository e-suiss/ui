An account settings page with a profile header and a sidebar of sections. Only Sign-In and Security is filled in: email and phone cards that expand into an inline edit form, a Passkeys switch, a two-factor row and a confirmation after each save, while the other sections show a placeholder. It uses a `Sidebar` that slides off canvas. Use it as the frame for any account or profile settings.

## Usage

<Code lang="tsx" code={"import { SettingsAccount } from \"@/components/blocks/settings-account\""} />

<Code lang="tsx" code={"<SettingsAccount />"} />

Load the email, phone and profile details from the signed-in user, and replace the `onSave` handler with your account API. Add content for the remaining sections listed in `items`. The profile name, email and initials in the header are hard-coded.

## Notes

Collapsed edit forms are `inert`, focus moves to the input when a card opens, and save confirmations are announced.
