A store landing header with a Store heading and tagline beside quick help links, then a draggable row of image tiles for each category. Selecting a tile lifts it and updates the line below to name the category. Use it as the top of a shop home page or any visual category picker.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/nav-categories
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add blocks nav-categories
```

### Manual

1. Add the pieces it builds on: [Carousel](/docs/components/carousel), [Toggle](/docs/components/toggle).

2. Copy the source into `components/blocks/nav-categories.tsx`:

<ComponentSource path="components/blocks/nav-categories.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { NavCategories } from "@/components/blocks/nav-categories"
```

```tsx
<NavCategories />
```

Replace `categories` with your categories, each with a label and image. Tiles only select themselves, so navigate or load products from the `Toggle`'s `onPressedChange`. Point the `#specialist` and `#stores` links at your routes.

## Notes

Tile images are decorative, so each tile is named by its label. Images are Unsplash placeholders.
