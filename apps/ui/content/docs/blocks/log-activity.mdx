An audit log that groups events by day, each with an icon for its type, the person, the action, the target and a time. Events that changed a value expand to show a before-and-after comparison, and a type filter and Export button sit in the header. It sits in a `Sidebar` with admin navigation that opens as a sheet from the trigger on mobile. Use it for audit trails, change history or admin activity pages.

Replace `events` with entries from your audit log API; each has a day, time, actor, action, target, kind and an optional before-and-after diff. `kinds` sets each event type's icon and tint, and `nav` the shell navigation. Give the Export button a handler.

An admin screen with a collapsing `Header` and large title, a scrollable `ChipGroup` to filter by event type (Price, Content, Security, Order, User), and events grouped under day headings. Events that carry a change expand with `Collapsible` to show the before and after values. A `TabBar` at the bottom switches between Users, Roles, Activity and Settings; only Activity has content in the sample.

<Only platform="rn">

Replace `EVENTS` with your audit log and `KINDS` with your event types. Wire `onFilterChange`, `onExport` (receives the current filter) and `onNavigate` (receives the selected tab) to your app.

</Only>
