An audit log that groups events by day, each with an icon for its type, the person, the action, the target and a time. Events that changed a value expand to show a before-and-after comparison, and a type filter and Export button sit in the header. It lives in an `AppShell`, so navigation becomes a tab bar on mobile. Use it for audit trails, change history or admin activity pages.
