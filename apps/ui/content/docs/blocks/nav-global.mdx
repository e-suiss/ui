A sticky top navigation bar with mega-menu panels, a brand link and search and bag buttons, shown above a sample hero. The bar is translucent and blurred, turns solid while a panel is open, and collapses into a full-screen menu on mobile or whenever the links don't fit. Built on the `Navbar` pattern, it suits sites with a deep catalog or many sections.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/nav-global
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks nav-global
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Button](/docs/components/button), [Navbar](/docs/patterns/navbar).

3. Copy the source into `components/blocks/nav-global.tsx`:

<ComponentSource path="components/blocks/nav-global.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { NavGlobal } from "@/components/blocks/nav-global"
```

```tsx
<NavGlobal />
```

Edit `items`: plain entries take a label and `href`, and mega-menu entries take `columns`, each with a label, an optional featured flag and a list of links. Replace the brand link and hash URLs, and give the search and bag buttons handlers. Remove the sample hero below the bar.
