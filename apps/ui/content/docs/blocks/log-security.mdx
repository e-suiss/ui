A security overview with a score ring that drops for each open alert and shifts from green to orange to red, next to open alert counts by severity. Below, alerts can be filtered by Open, Resolved or All and resolved or reopened one by one. It sits in a `Sidebar` with admin navigation that opens as a sheet from the trigger on mobile. Use it for security centers, compliance checklists or system health checks.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/log-security
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks log-security
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Button](/docs/components/button), [Sidebar](/docs/components/sidebar), [Toggle Group](/docs/components/toggle-group).

3. Copy the source into `components/blocks/log-security.tsx`:

<ComponentSource path="components/blocks/log-security.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { LogSecurity } from "@/components/blocks/log-security"
```

```tsx
<LogSecurity />
```

Replace `initialAlerts` with alerts from your security backend; each has a severity, title, detail and icon. `severity` sets each level's colors and how much it lowers the score. Alerts are matched by title when resolving, so switch to an id for real data, and connect Resolve and Reopen to your API.

An admin screen with a collapsing `Header`, a ring that shows a security score, and counts of open High, Medium and Low alerts. A `ChipGroup` filters the list by Open, Resolved or All, and each alert has a Resolve or Reopen `Button`; the score and counts update as alerts change. A `TabBar` at the bottom switches between admin sections; only Activity has content in the sample.
