A shopping bag page that leads with the order total, then lists each item with a photo, a quantity stepper, its price and a Remove link, followed by subtotal, shipping and total. Line items use a compact two-column layout on mobile and a four-column row on desktop. Removing everything turns the headline into an empty-bag message. Reach for it for any cart or order review screen.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/bag-review
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add blocks bag-review
```

### Manual

1. Add the pieces it builds on: [Button](/docs/components/button), [Stepper](/docs/interactions/stepper).

2. Copy the source into `components/blocks/bag-review.tsx`:

<ComponentSource path="components/blocks/bag-review.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { BagReview } from "@/components/blocks/bag-review"
```

```tsx
<BagReview />
```

Replace `initialItems` with your cart lines, each with a name, variant, price, image and quantity. Persist quantity changes and removals to your cart service, and connect both Check Out buttons to your checkout. The product links point to `#details`, and the free delivery and shipping copy is placeholder text. In the empty state, Continue Shopping restores the sample items, so point it at your catalog instead.

## Notes

Quantities are limited to 1–10, and each stepper and Remove button is labeled with the product name. Product photos are Unsplash placeholders.

Composes `Screen`, `Stepper` from the interactions, `Button`, `Text` and `BottomBar`. Each compact row shows a thumbnail, the product name with its line price, the variant, a quantity stepper and a Remove link; tapping the thumbnail or the name opens the product details. The heading and totals update as the bag changes, and removing every item shows an empty state with a Continue Shopping button.
