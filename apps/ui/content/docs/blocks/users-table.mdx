<ComponentPreview type="block" name="users-table" />

A users table with search, role filters and row selection; selecting rows reveals bulk actions to make editors, activate or suspend. Role and last sign-in columns appear as the screen widens, and the search and Invite button take the full width on mobile. It sits in a `Sidebar` with admin navigation that opens as a sheet from the trigger on mobile. Use it for any admin list that needs bulk actions.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/users-table
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks users-table
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Avatar](/docs/components/avatar), [Button](/docs/components/button), [Checkbox](/docs/components/checkbox), [Input Group](/docs/components/input-group), [Sidebar](/docs/components/sidebar), [Table](/docs/components/table), [Toggle Group](/docs/components/toggle-group).

3. Copy the source into `components/blocks/users-table.tsx`:

<ComponentSource path="components/blocks/users-table.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { UsersTable } from "@/components/blocks/users-table"
```

```tsx
<UsersTable />
```

Replace `initialUsers` with your users, each with a name, email, role, status, last-seen text and avatar hue. Call your API in `bulk`, which applies a change to every selected user. Search and filtering run in the browser, so move them server-side for large lists, and give Invite a handler.

## Notes

Each row has a hidden checkbox labeled with the user's name, so selection works from the keyboard as well as by clicking the row.

A collapsing `Header` holds a search `InputGroup` and a `ChipGroup` that filters by role. Rows show an `Avatar`, role and a `Badge` for status. The `SelectionList` trigger enters select mode, and the `SelectionListBar` applies bulk actions: make Editor, activate or suspend. An invite `Button` sits in the header, and the admin `TabBar` switches sections.
