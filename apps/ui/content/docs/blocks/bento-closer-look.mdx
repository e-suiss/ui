A feature spotlight with a list of features on one side and a photo on the other that cross-fades to match the open item. The list advances on its own every four seconds until someone opens an item, then stays put. On mobile the photo moves above the list. Use it to walk through a handful of product features without a carousel.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/bento-closer-look
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add blocks bento-closer-look
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Accordion](/docs/components/accordion).

3. Copy the source into `components/blocks/bento-closer-look.tsx`:

<ComponentSource path="components/blocks/bento-closer-look.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { BentoCloserLook } from "@/components/blocks/bento-closer-look"
```

```tsx
<BentoCloserLook />
```

Edit the `features` array; each entry has a title, description, image and alt text. Change the 4000 ms interval or the heading in the component. Nothing needs wiring to a backend.

## Notes

The automatic rotation keeps running under reduced motion until the user opens an item, so drop the interval if that matters for your audience. Photos are Unsplash placeholders.
