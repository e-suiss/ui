A primer shown before a system permission prompt: a large icon, a title, a description and a list of benefits, each with its own icon. Allow and Not now buttons sit in a `BottomBar`. By default it asks for notifications.

<Only platform="rn">

Every piece is a prop: `icon`, `title`, `description`, `benefits`, `allowLabel` and `dismissLabel`. Request the real permission in `onAllow` and close the screen in `onDismiss`.

</Only>
