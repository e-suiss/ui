<ComponentPreview type="block" name="price-care" />

A protection plan picker: choose a device, pick a payment option for it and, for some devices, add theft and loss cover, with a live total and an Add to Bag button. A photo of the selected device sits beside the options on desktop and above them on mobile. Use it for warranties, insurance add-ons or any per-product plan.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/price-care
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add blocks price-care
```

### Manual

1. Add the pieces it builds on: [Button](/docs/components/button), [Label](/docs/components/label), [Radio Group](/docs/components/radio-group), [Switch](/docs/components/switch), [Toggle Group](/docs/components/toggle-group).

2. Copy the source into `components/blocks/price-care.tsx`:

<ComponentSource path="components/blocks/price-care.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { PriceCare } from "@/components/blocks/price-care"
```

```tsx
<PriceCare />
```

Edit `devices`; each has a name, photo, alt text and payment options with a label, price and optional theft surcharge. The theft switch only appears for Phone Pro, so change that check if other devices offer it. Give Add to Bag a handler.

## Notes

The total is announced when it changes. Photos are Unsplash placeholders.
