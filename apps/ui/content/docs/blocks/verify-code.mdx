A two-factor screen with a six-digit code field that turns red on a wrong code and green on success, plus a resend countdown and a help link. A wrong code shakes the field and clears it. Use it for 2FA, phone verification or any one-time code step.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/verify-code
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add blocks verify-code
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Input Otp](/docs/components/input-otp).

3. Copy the source into `components/blocks/verify-code.tsx`:

<ComponentSource path="components/blocks/verify-code.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { VerifyCode } from "@/components/blocks/verify-code"
```

```tsx
<VerifyCode />
```

Replace the comparison with `DEMO_CODE` in `complete` with your verification API, and remove the demo code hint. Resend only restarts the 30-second timer, so connect it to your code delivery service. Point `#help` at your support page.

## Notes

The code field receives focus on load, and errors are announced.


```tsx
<VerifyCode />
```

`onVerify` receives the code and returns a boolean or a promise; by default it accepts the demo code `482913`. `onHelp` handles the help link.
