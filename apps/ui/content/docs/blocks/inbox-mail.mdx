A three-pane mail client: mailboxes on the left, a searchable message list in the middle and the open message with a reply box on the right. On small screens the panes collapse into a single view with a back button. Start from it for any inbox-style screen, such as support tickets or notifications.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/inbox-mail
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add blocks inbox-mail
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Avatar](/docs/components/avatar), [Button](/docs/components/button), [Input Group](/docs/components/input-group), [Split View](/docs/patterns/split-view), [Textarea](/docs/components/textarea).

3. Copy the source into `components/blocks/inbox-mail.tsx`:

<ComponentSource path="components/blocks/inbox-mail.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { InboxMail } from "@/components/blocks/inbox-mail"
```

```tsx
<InboxMail />
```

Replace `initialMail` with your messages, each with a sender, subject, body, time, avatar hue and unread and starred flags, and `mailboxes` with your folders. Only Starred actually filters the list, so load each folder from your mail backend. Archive and Delete both remove the message, the reply form only clears on submit, and New message has no handler.

## Notes

Search runs in the browser over sender, subject and body, so move it server-side for real mailboxes. The reply box receives focus when it opens.

A three-column mail screen built on `SplitView`: a sidebar of mailboxes (Inbox, Starred, Sent, Archive, Trash), a message list with a search field made from `InputGroup`, and a reader. On phones each column opens in turn. Rows use `Avatar` and support `SwipeActions` to archive or delete, and searching filters by sender, subject and body. The reader has Reply, Star, Archive and Delete buttons, and Reply opens a `Textarea`.
