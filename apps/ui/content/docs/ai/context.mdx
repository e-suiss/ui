Context shows how much of the model's context window the conversation has used. The trigger shows the share used, and a [Hover Card](/docs/components/hover-card) opens a [Progress](/docs/components/progress) bar with the input, output and reasoning tokens.

## Installation

Context is built with the [Hover Card](/docs/components/hover-card), [Progress](/docs/components/progress) and [Button](/docs/components/button) components.

```bash title="Terminal"
npx shadcn@latest add @esuiss/hover-card @esuiss/progress @esuiss/button
```

Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add hover-card progress button
```

## Usage

```tsx
import { Button } from "@/components/ui/button"
import { HoverCard, HoverCardContent, HoverCardTrigger } from "@/components/ui/hover-card"
import { Progress } from "@/components/ui/progress"
```

<OnlyBase base="base">

```tsx
<HoverCard>
  <HoverCardTrigger
    delay={10}
    closeDelay={100}
    render={<Button variant="outline" size="sm" />}
  >
    {percent}% context
  </HoverCardTrigger>
  <HoverCardContent className="flex w-64 flex-col gap-3">
    <div className="flex items-center justify-between gap-3 text-sm">

      <span className="text-muted-foreground">

      </span>
    </div>
    <Progress value={percent} aria-label="Context used" />
  </HoverCardContent>
</HoverCard>
```

## AI SDK

Read usage from the metadata on the agent's message. `messageMetadata` runs when the stream finishes.

```ts title="app/api/chat/route.ts"
return result.toUIMessageStreamResponse({
  messageMetadata: ({ part }) => {
    if (part.type === "finish") {
      return { usage: part.totalUsage }
    }
  },
})
```

```tsx
const usage = message.metadata?.usage
const used = (usage?.inputTokens ?? 0) + (usage?.outputTokens ?? 0)
const percent = Math.round((used / limit) * 100)
```

`limit` is the model's context window. The AI SDK does not send it, so set it from the model you use.

## Accessibility

- The trigger is a button, so the breakdown opens on focus as well as on hover.
- Give the progress bar an accessible name with `aria-label`, such as "Context used".
- Put the share in the trigger text, so it is announced without opening the card.
