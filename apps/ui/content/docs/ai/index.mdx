Each one is a composition of suiss/ui components that you copy into your project. There is no extra package to install, and they work with any model or SDK.

A [Chat](/docs/ai/chat) is a list of [Message](/docs/ai/message) turns inside a [Message Scroller](/docs/components/message-scroller). The steps an agent takes inside a turn, such as [Reasoning](/docs/ai/reasoning), [Tool](/docs/ai/tool) and [Plan](/docs/ai/plan), are built on [Trace](/docs/components/trace), so every step has the same shape.
