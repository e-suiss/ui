Inline Citation is a source that sits in the sentence it supports. The trigger is a link to the source, styled as a small [Button](/docs/components/button), and a [Hover Card](/docs/components/hover-card) previews its title and description.

To show a list of sources after the reply, use [Sources](/docs/ai/sources).

## Installation

Inline Citation is built with the [Hover Card](/docs/components/hover-card) and [Button](/docs/components/button) components.

```bash title="Terminal"
npx shadcn@latest add @esuiss/hover-card @esuiss/button
```

Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add hover-card button
```

## Usage

```tsx
import { buttonVariants } from "@/components/ui/button"
import { HoverCard, HoverCardContent, HoverCardTrigger } from "@/components/ui/hover-card"
```

```tsx
<HoverCard>
  <HoverCardTrigger
    href={url}
    target="_blank"
    rel="noreferrer"
    className={buttonVariants({ variant: "secondary", size: "xs" })}
  >
    {hostname}
    <span className="sr-only"> (opens in a new tab)</span>
  </HoverCardTrigger>
  <HoverCardContent className="flex w-64 flex-col gap-1 text-sm">
    <div className="font-medium">{title}</div>
    <p className="text-muted-foreground">{description}</p>
  </HoverCardContent>
</HoverCard>
```

## AI SDK

A `source-url` part is the citation. Set `sendSources: true` on `toUIMessageStreamResponse()`, or write the part yourself.

```ts title="app/api/chat/route.ts"
writer.write({
  type: "source-url",
  sourceId: "suiss",
  url: "https://suiss.app/ui",
  title: "suiss/ui",
})
```

```tsx
const sources = message.parts.filter((part) => part.type === "source-url")
```

`title` is optional. Fall back to the URL's hostname.

## Accessibility

- The trigger is a real link, so the source opens with a click or Enter, and the preview opens on focus as well as on hover.
- Add "(opens in a new tab)" to the link text with `sr-only`.
- The hover card repeats what the link names, so readers who cannot hover lose nothing.
