A borderless radar shape over shaded circular bands, separated by lines in the card's background color (`muted`). Choose it for a quieter, more graphic look where the grid reads as tinted rings rather than lines.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/radar-chart-grid-filled
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add charts radar-chart-grid-filled
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/radar-chart-grid-filled.tsx`:

<ComponentSource path="components/charts/radar-chart-grid-filled.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { RadarChartGridFilled } from "@/components/charts/radar-chart-grid-filled"
```

```tsx
<RadarChartGridFilled />
```

Replace `chartData`, set the axis and value keys, and rename the series in `chartConfig`. Adjust the band shading through the `fill` and opacity on `PolarGrid`, and the shape's strength through the opacity on `Radar`.

## Notes

The gaps between bands use the card's background color, so place this chart on that same surface or update the grid stroke to match.

## Usage

```tsx
import { RadarChartGridFilled } from "@/components/charts/radar-chart-grid-filled"
```

```tsx
<RadarChartGridFilled />
```

Replace `chartData` with your records, set `PolarAngleAxis` `dataKey` to your axis field, and rename the series in `chartConfig`. The component takes no props.
