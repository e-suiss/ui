Two overlapping radar shapes with a legend underneath naming each series. Pick it over the plain multiple-series chart when readers need to know which shape is which without hovering.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/radar-chart-legend
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add charts radar-chart-legend
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/radar-chart-legend.tsx`:

<ComponentSource path="components/charts/radar-chart-legend.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { RadarChartLegend } from "@/components/charts/radar-chart-legend"
```

```tsx
<RadarChartLegend />
```

Replace `chartData` and rename the series keys in the data, both `Radar` elements and `chartConfig`; the legend reads labels and colors from the config. The series declared last is drawn on top.

</Only>

## Usage

```tsx
import { RadarChartLegend } from "@/components/charts/radar-chart-legend"
```

```tsx
<RadarChartLegend />
```

Replace `chartData` with your records, set `PolarAngleAxis` `dataKey` to your axis field, and rename the series in `chartConfig`. The component takes no props.
