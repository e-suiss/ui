A stacked bar chart that shows the default tooltip indicator, a small colored square beside each series. It is the most compact indicator and the one you get without setting anything.

Leave `indicator` on `ChartTooltipContent` unset or set it to `dot`. Replace `chartData` and the series in `chartConfig` with your own. The tooltip opens on a preset month when the chart loads; remove `defaultIndex` if it should start hidden.
