Two series stacked into one bar per month, with a legend under the plot. Use it when the total per month matters as well as how each series contributes to it.

Replace `chartData` and rename the series keys in the data, both `Bar` elements and `chartConfig`; the legend reads labels and colors from the config. Every bar in the stack needs the same `stackId`, and the first one sits at the bottom. If you add a series, move the rounded top corners via `radius` to the top bar. Focus the chart and use the arrow keys to move the tooltip between months.
