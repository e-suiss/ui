Replace `chartData` and rename the series keys in the data, the `Radar` elements and `chartConfig`. Add more `Radar` elements for extra series; give each a distinct color in the config.

## Notes

Without fill or legend, color is the only cue for which line is which, so add a legend or pick strongly contrasting colors.
