A weather-app forecast where each horizontal pill spans a day's low to high temperature against a shared scale, with a colored gradient fill and the high on the right. Use floating range bars like these whenever each item has a minimum and a maximum.

## Usage

<Code lang="tsx" code={"import { BarChartRange } from \"@/components/charts/bar-chart-range\""} />

<Code lang="tsx" code={"<BarChartRange />"} />

Give each record a label, a `low` and a `high`; the chart derives the two-value `range` from them. Set the hidden value axis `domain` to cover your full range so pills line up across rows. Edit the gradient stops in the `defs` block to change the colors.

## Notes

The gradient runs across each pill rather than across the whole scale, so every pill shows the full color ramp regardless of its temperatures. Only the high is printed beside the bars; the low is available in the tooltip.
