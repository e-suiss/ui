A step-count bar chart whose tooltip is built from scratch as a small card with a big number, unit and day name. Reach for it when the stock tooltip layout can't express what you need, such as a single headline value.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add charts tooltip-chart-custom
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/tooltip-chart-custom.tsx`:

<ComponentSource path="components/charts/tooltip-chart-custom.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { TooltipChartCustom } from "@/components/charts/tooltip-chart-custom"
```

```tsx
<TooltipChartCustom />
```

Pass your own render function to the `content` prop of `ChartTooltip`; it receives the active state, the hovered rows and the label, and should return null when inactive. Change the unit text and number format inside it, and replace `chartData` and `chartConfig` as usual.

## Notes

A custom tooltip skips the built-in one entirely, so labels and colors from the config only appear if you read them yourself. The tooltip opens on a preset bar when the chart loads; remove `defaultIndex` to start hidden.
