A single bar series with each value printed above its bar and no grid lines. Use it when exact numbers matter and there are few enough bars for the labels to fit.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/bar-chart-labeled
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts bar-chart-labeled
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/bar-chart-labeled.tsx`:

<ComponentSource path="components/charts/bar-chart-labeled.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { BarChartLabeled } from "@/components/charts/bar-chart-labeled"
```

```tsx
<BarChartLabeled />
```

Replace `chartData`, set each `dataKey` and rename the `chartConfig` entry for the label and color. Move the labels with the `position` prop on `LabelList`, for example inside the bar. Increase the chart's top margin if larger labels get clipped.

## Notes

Labels follow the theme's text color in light and dark mode. Focus the chart and use the arrow keys to move between bars.
