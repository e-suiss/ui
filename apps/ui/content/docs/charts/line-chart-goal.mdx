Daily steps as a line with dots, plotted against a labeled dashed goal line. Use it when a single target gives the values their meaning, such as quotas, budgets or fitness goals.

Replace `chartData` and set `GOAL` to your target. Change the label on the `ReferenceLine`, the unit in the tooltip formatter and the axis `tickFormatter` to fit your metric. The value axis scales to the data only, so set a `domain` if the goal can fall outside it. Focus the chart and use the arrow keys to step through the days.
