Daily steps as a line with dots, plotted against a labeled dashed goal line. Use it when a single target gives the values their meaning, such as quotas, budgets or fitness goals.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add charts line-chart-goal
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/line-chart-goal.tsx`:

<ComponentSource path="components/charts/line-chart-goal.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { LineChartGoal } from "@/components/charts/line-chart-goal"
```

```tsx
<LineChartGoal />
```

Replace `chartData` and set `GOAL` to your target. Change the label text on the `ReferenceLine` and the unit in the tooltip formatter and axis `tickFormatter` to match your metric.

## Notes

The value axis scales to the data only, so a goal far above or below every value may fall outside the plot; set a `domain` on the axis if that can happen. Focus the chart and use the arrow keys to step through the days.
