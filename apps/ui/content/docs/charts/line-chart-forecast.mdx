Actual values drawn as a solid line that continues as a dashed forecast over a shaded future period. Use it whenever you show projections next to history and need readers to tell them apart.

## Usage

<Code lang="tsx" code={"import { LineChartForecast } from \"@/components/charts/line-chart-forecast\""} />

<Code lang="tsx" code={"<LineChartForecast />"} />

Fill the `actual` and `forecast` arrays; the forecast should start with the last actual value so the two lines meet. Move the shaded period by changing `x1` and `x2` on the reference area to match your first and last forecast labels. Both series share one color in `chartConfig`.

## Notes

Since actual and forecast use the same color, the dash pattern and shading carry the distinction; the tooltip also names each series. At the handover point the tooltip lists both values.
