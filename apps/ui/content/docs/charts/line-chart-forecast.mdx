Actual values drawn as a solid line that continues as a dashed forecast over a shaded future period. Use it whenever you show projections next to history and need readers to tell them apart.

Fill the `actual` and `forecast` arrays and start the forecast with the last actual value so the lines meet; at that point the tooltip lists both values. Move the shaded period with `x1` and `x2` on the reference area. Both series share one color in `chartConfig`, so the dash pattern, the shading and the series names in the tooltip tell them apart.

Two series share one axis: `actual` fills the first nine months and `forecast` continues from September, drawn with `strokeDasharray`. A `ReferenceArea` shades September to December to mark the forecast period. Missing values are `null`, so each line stops where its data ends.

</Only>

<Only platform="rn">

Replace the `actual` and `forecast` arrays; the forecast starts at the index set in `chartData`. Move the `ReferenceArea` `x1` and `x2` to match your forecast range. The component takes no props.

</Only>
