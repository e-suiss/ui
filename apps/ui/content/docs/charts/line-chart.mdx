Line charts follow a trend across time. Start with the default for one series, add dots or printed values when each reading matters, draw a goal line to show a target, and continue the line as a dashed forecast for values that have not happened yet. Linear and step lines avoid suggesting values between readings, and the multiple and interactive variants compare several series on the same axes.

Every variant below is its own registry item, so you can add only the ones you need. Each one renders the same design on React, React Native, SwiftUI and Jetpack Compose.
