A full screen-time report: stacked category bars per day, a Week and Day toggle, selectable days, per-category totals and a most-used apps list that all update together. Use it as a reference for building a drill-down dashboard on top of a bar chart.

## Usage

<Code lang="tsx" code={"import { BarChartInteractive } from \"@/components/charts/bar-chart-interactive\""} />

<Code lang="tsx" code={"<BarChartInteractive />"} />

Replace `USAGE` with your per-day category totals and `APPS` with your item breakdown, and rename the categories in `CATEGORIES` and `chartConfig`. The hourly Day view is generated from the daily totals for the demo, so feed it real hourly data in production. The comparison line under the headline is a fixed string until a day is selected.

## Notes

Click, tap or press Return on a bar to select a day, and select it again to clear the selection; taps that move like a scroll are ignored. Day view shows Sunday if no day was selected. The header is a live region so selection changes are announced.

Bars stack social, productivity and entertainment time. A `ToggleGroup` switches between a weekly view and an hourly view of one day. In the week view, touching a bar selects that day through `onActiveIndexChange`, dims the other days and updates the headline, comparison text, category totals and the most used apps list below. A dashed line marks the weekly average. The bars set `isAnimationActive={false}`, so they draw without the enter animation and switch views instantly.
