Concentric radial bars where the unfilled part of each track is a soft tint of the bar's own color instead of neutral gray. Choose it over the default radial chart for a more colorful look that still shows how far each bar has to go.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/radial-chart-tinted
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts radial-chart-tinted
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/radial-chart-tinted.tsx`:

<ComponentSource path="components/charts/radial-chart-tinted.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { RadialChartTinted } from "@/components/charts/radial-chart-tinted"
```

```tsx
<RadialChartTinted />
```

Replace `chartData` and add each category to `chartConfig`; the tinted tracks are built from the same data. Set `MAX` to the value that should close a full ring, and keep it at or above your largest value.

## Notes

The tracks are a second chart layered behind the real one and hidden from assistive technology, so keep the sizing shared between both when you change it.

A `RadialBarChart` with one bar per record in `chartData`, measured against a shared `MAX` of 320. Each bar is colored through `Cell`, and its background track uses the same color at low opacity. Pressing a bar shows a tooltip. The bars set `isAnimationActive={false}` and draw without the enter animation.
