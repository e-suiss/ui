Nightly sleep plotted against a dashed goal line, with each dot colored green if the goal was met and orange if not. Pick it over the plain goal chart when readers should spot hits and misses at a glance.

Replace `chartData` and set `GOAL` to your target; the dot colors follow the comparison. Adjust the value axis `domain` and `ticks`, and change the two dot colors in the custom `dot` renderer. The headline figure is static text, so wire it up to real values. Color alone marks a hit or miss on the chart, so keep a text explanation like the one in the header.

<Only platform="rn">

Seven nights of sleep drawn as a monotone line. The `dot` prop is a function that colors each point by comparing it with `GOAL`, and a dashed green `ReferenceLine` marks the goal itself. The tooltip formats values as hours and minutes.

Replace `chartData` with your nightly hours and set `GOAL`. The header average is static text, so update it with your own value. The component takes no props.

</Only>
