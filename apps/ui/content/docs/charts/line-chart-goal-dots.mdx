Nightly sleep plotted against a dashed goal line, with each dot colored green if the goal was met and orange if not. Pick it over the plain goal chart when readers should spot hits and misses at a glance.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add charts line-chart-goal-dots
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/line-chart-goal-dots.tsx`:

<ComponentSource path="components/charts/line-chart-goal-dots.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { LineChartGoalDots } from "@/components/charts/line-chart-goal-dots"
```

```tsx
<LineChartGoalDots />
```

Replace `chartData` and set `GOAL` to your target; dot colors update from the comparison automatically. Adjust the value axis `domain` and `ticks` to your range, and change the two dot colors in the custom `dot` renderer.

## Notes

The headline figure is hard-coded text, not computed from the data, so wire it up when you plug in real values. Color alone marks hit or miss on the chart, so keep a text explanation like the one in the header.

Seven nights of sleep drawn as a monotone line. The `dot` prop is a function that colors each point by comparing it with `GOAL`, and a dashed green `ReferenceLine` marks the goal itself. The tooltip formats values as hours and minutes.
