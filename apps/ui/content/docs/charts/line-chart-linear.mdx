One series joined by straight segments instead of a smoothed curve. Prefer it to the default when smoothing would imply values between readings that were never measured.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/line-chart-linear
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts line-chart-linear
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/line-chart-linear.tsx`:

<ComponentSource path="components/charts/line-chart-linear.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { LineChartLinear } from "@/components/charts/line-chart-linear"
```

```tsx
<LineChartLinear />
```

Replace `chartData`, update each `dataKey` and set the label and color in `chartConfig`. Everything else matches the default line chart.

## Notes

Keyboard users can focus the chart and move between points with the arrow keys.
