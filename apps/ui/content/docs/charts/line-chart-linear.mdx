<ComponentPreview type="chart" name="line-chart-linear" />

One series joined by straight segments instead of a smoothed curve. Prefer it to the default when smoothing would imply values between readings that were never measured.

Replace `chartData`, point each `dataKey` at your fields and set the label and color in `chartConfig`. Focus the chart and use the arrow keys to move the tooltip between months.

## Installation

<Only platform="rn">

One series with `type="linear"`, so each month connects to the next with a straight segment. It has a month axis, a dashed grid and a tooltip.

Replace `chartData` with your records and change each `dataKey` to match your fields. Set the label and color in `chartConfig`. The component takes no props.
