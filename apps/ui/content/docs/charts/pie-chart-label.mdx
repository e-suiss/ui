A pie with each category name printed outside its slice and connected by a leader line. Use it when readers shouldn't have to match colors against a separate legend.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/pie-chart-label
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts pie-chart-label
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/pie-chart-label.tsx`:

<ComponentSource path="components/charts/pie-chart-label.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { PieChartLabel } from "@/components/charts/pie-chart-label"
```

```tsx
<PieChartLabel />
```

Replace `chartData` and the category entries in `chartConfig`; labels read their text from the config. To print values or percentages instead, change what the custom `label` renderer returns. Shrink `outerRadius` if long names get clipped at the edges.

## Notes

Outside labels collide when slices are thin, so keep the category count low.

## Usage

```tsx
import { PieChartLabel } from "@/components/charts/pie-chart-label"
```

```tsx
<PieChartLabel />
```

Replace `chartData` with your records and keep `dataKey` and `nameKey` in step with your field names. Add one entry per slice to `chartConfig` with its label and color; the component takes no props.
