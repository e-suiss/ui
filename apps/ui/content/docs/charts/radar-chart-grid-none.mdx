A solid radar shape with no grid and no outline, leaving only the shape and the axis labels. Use it as a compact, decorative profile where exact values come from the tooltip.

Replace `chartData`, set the axis and value keys, and rename the series in `chartConfig`. `fillOpacity` on `Radar` sets the shape's intensity. With no grid, readers can't estimate values from the chart, so keep the tooltip or show the numbers elsewhere.

A `RadarChart` without a `PolarGrid`, so only the angle axis labels and one filled `Radar` shape remain. `chartData` has one record per axis (`skill`) with `thisMonth` and `lastMonth` scores. Pressing the chart shows a tooltip.

<Only platform="rn">

Replace `chartData` with your records, set `PolarAngleAxis` `dataKey` to your axis field, and rename the series in `chartConfig`. The component takes no props.

</Only>
