A solid radar shape with no grid and no outline, leaving only the shape and the axis labels. Use it as a compact, decorative profile where exact values come from the tooltip.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/radar-chart-grid-none
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts radar-chart-grid-none
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/radar-chart-grid-none.tsx`:

<ComponentSource path="components/charts/radar-chart-grid-none.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { RadarChartGridNone } from "@/components/charts/radar-chart-grid-none"
```

```tsx
<RadarChartGridNone />
```

Replace `chartData`, set the axis and value keys, and rename the series in `chartConfig`. Change the shape's intensity with `fillOpacity` on `Radar`.

## Notes

With no grid, readers can't estimate values from the chart itself, so keep the tooltip or show the numbers elsewhere.

## Usage

```tsx
import { RadarChartGridNone } from "@/components/charts/radar-chart-grid-none"
```

```tsx
<RadarChartGridNone />
```

Replace `chartData` with your records, set `PolarAngleAxis` `dataKey` to your axis field, and rename the series in `chartConfig`. The component takes no props.
