A donut whose slices are pushed apart with wide gaps and rounded corners, giving each segment a tile-like look. Choose it for a softer, more decorative style than the standard donut.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/pie-chart-separated
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts pie-chart-separated
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/pie-chart-separated.tsx`:

<ComponentSource path="components/charts/pie-chart-separated.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { PieChartSeparated } from "@/components/charts/pie-chart-separated"
```

```tsx
<PieChartSeparated />
```

Replace `chartData` and add each category to `chartConfig`. Tune the spacing with `paddingAngle` and the rounding with `cornerRadius`; large values for either make small slices hard to see.

## Notes

The wide gaps and rounded corners squeeze very thin slices, so this style suits data without tiny values.

## Usage

```tsx
import { PieChartSeparated } from "@/components/charts/pie-chart-separated"
```

```tsx
<PieChartSeparated />
```

Replace `chartData` with your records and keep `dataKey` and `nameKey` in step with your field names. Add one entry per slice to `chartConfig` with its label and color; the component takes no props.
