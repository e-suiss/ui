A donut whose slices are pushed apart with wide gaps and rounded corners, giving each segment a tile-like look. Choose it for a softer, more decorative style than the standard donut.

Replace `chartData` and add each category to `chartConfig`. `paddingAngle` sets the spacing and `cornerRadius` the rounding; large values squeeze thin slices, so this style suits data without tiny values.

A `PieChart` donut with `paddingAngle` and `cornerRadius` set so each slice stands apart. `chartData` holds one record per device with a `users` count. Pressing a slice shows a tooltip.

</Only>

<Only platform="rn">

Replace `chartData` with your records and keep `dataKey` and `nameKey` in step with your field names. Add one entry per slice to `chartConfig` with its label and color; the component takes no props.

</Only>
