A single full-circle progress ring with a percentage and caption centered inside. Use it for one headline ratio, such as storage used or a completion rate.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/radial-chart-text
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts radial-chart-text
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/radial-chart-text.tsx`:

<ComponentSource path="components/charts/radial-chart-text.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { RadialChartText } from "@/components/charts/radial-chart-text"
```

```tsx
<RadialChartText />
```

Set the value in `chartData` and keep the `domain` on `PolarAngleAxis` at your maximum. Update the percentage and caption in the center overlay, and change the color in `chartConfig`.

## Notes

The center text is hard-coded, not computed from the data, and there is no tooltip.

## Usage

```tsx
import { RadialChartText } from "@/components/charts/radial-chart-text"
```

```tsx
<RadialChartText />
```

Change the `value` in `chartData` (0 to 100) and the centered text to match it; the label and color live in `chartConfig`. The component takes no props.
