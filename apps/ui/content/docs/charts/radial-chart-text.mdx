A single full-circle progress ring with a percentage and caption centered inside. Use it for one headline ratio, such as storage used or a completion rate.

Set the value in `chartData` and keep the `domain` on `PolarAngleAxis` at your maximum. The percentage and caption in the center are static text, so update them with the value, and change the color in `chartConfig`. There is no tooltip.
