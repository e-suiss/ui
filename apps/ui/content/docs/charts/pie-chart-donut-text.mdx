A donut with the total shown in its center, so readers get the overall number and the breakdown in one glance. Prefer it over the plain donut when the total is the headline.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/pie-chart-donut-text
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add charts pie-chart-donut-text
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/pie-chart-donut-text.tsx`:

<ComponentSource path="components/charts/pie-chart-donut-text.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { PieChartDonutText } from "@/components/charts/pie-chart-donut-text"
```

```tsx
<PieChartDonutText />
```

Replace `chartData` and the category entries in `chartConfig`; the center total is summed from the data automatically. Change the caption under the number to your unit, and adjust `innerRadius` if a longer number needs more room.

## Notes

The center text sits on top of the chart but lets pointer events through, so slice tooltips still work.

## Usage

```tsx
import { PieChartDonutText } from "@/components/charts/pie-chart-donut-text"
```

```tsx

```

Replace `chartData` with your records; the center total recalculates from it. Update the `users` caption and `chartConfig` labels and colors to match. The component takes no props.
