A three-quarter arc tracking progress toward a goal, with the count shown in the center. Use it for goals with a clear finish line, like a reading challenge or a savings target.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/radial-chart-progress
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts radial-chart-progress
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/radial-chart-progress.tsx`:

<ComponentSource path="components/charts/radial-chart-progress.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { RadialChartProgress } from "@/components/charts/radial-chart-progress"
```

```tsx
<RadialChartProgress />
```

Set the progress as a percentage in `chartData`, or change the `domain` on `PolarAngleAxis` to your goal and pass the raw count. Update the center text and caption, and set the color in `chartConfig`.

## Notes

The center text is hard-coded and not derived from the value, so update both together. There is no tooltip.
