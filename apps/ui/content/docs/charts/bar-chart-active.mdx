A week of step counts where one bar is selected at a time: the chosen day stays solid, the rest dim, and the header shows its value. Use it when a bar chart doubles as a picker for the detail shown above it.

## Installation

### CLI

<Code lang="bash" title="Terminal" code={"npx @esuiss/ui@latest add charts bar-chart-active"} />

### Manual

1. Install the dependencies:

<Code lang="bash" title="Terminal" code={"npm install recharts"} />

3. Copy the source into `components/charts/bar-chart-active.tsx`:

<SourceFile path="components/charts/bar-chart-active.tsx" />

## Usage

<Code lang="tsx" code={"import { BarChartActive } from \"@/components/charts/bar-chart-active\""} />

<Code lang="tsx" code={"<BarChartActive />"} />

Replace `chartData` with your own days and values, and rename `steps` in the data, the `Bar` and `chartConfig`. Set the initially selected bar through the `selected` state, and change the unit text and number format in the header. Lower or raise the opacity of the dimmed bars to tune the contrast.

## Notes

Keyboard users move between bars with the arrow keys and select with Return or Space, and the header value is announced through a live region. There is no tooltip; the header is the only readout.

Seven bars, one per day, with the selected bar at full opacity and the others dimmed. The `BarChart` reports the touched bar through `onActiveIndexChange`, which updates local state and the header. The header is a live region, so screen readers announce the new step count. The bars set `isAnimationActive={false}` and draw without the enter animation.
