A single series drawn as a smooth area with a soft gradient fill, a dot at every value and a value axis on the right. Use it when readers need to read exact values off the chart, not just see the trend.

Replace `chartData`, point each `dataKey` at your fields and set the label and color in `chartConfig`. Set `orientation` on the value axis to move it to the left and `tickCount` to change how many values it shows. Each copy gets its own gradient, so several can share a page. Focus the chart and use the arrow keys to move the tooltip between months.

One series drawn as a monotone curve with a fill that fades from top to bottom, a dot on every month, a month axis below and a four-tick value axis on the right. The tooltip follows your finger across the plot.

<Only platform="rn">

Replace `chartData` with your records and change each `dataKey` to match your fields. Set the label and color in `chartConfig`, and adjust `tickCount` on the `YAxis` to change how many values it shows. The component takes no props.
