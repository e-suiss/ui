A stacked bar chart whose tooltip lists series names and values without any color marker. Use it for single-series charts, or when the series names are clear enough on their own.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/tooltip-chart-no-indicator
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts tooltip-chart-no-indicator
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/tooltip-chart-no-indicator.tsx`:

<ComponentSource path="components/charts/tooltip-chart-no-indicator.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { TooltipChartNoIndicator } from "@/components/charts/tooltip-chart-no-indicator"
```

```tsx
<TooltipChartNoIndicator />
```

Set `hideIndicator` on `ChartTooltipContent`. Replace `chartData` and the series in `chartConfig`, and keep the labels descriptive since they are the only cue.

## Notes

With several series and no color marker, readers can't match a row to a bar by color, so this suits one or two clearly named series best.
