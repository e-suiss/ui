A stacked bar chart whose tooltip lists series names and values without any color marker. Use it for single-series charts, or when the series names are clear enough on their own.

Set `hideIndicator` on `ChartTooltipContent`, and keep the series labels descriptive since they are the only cue. Without a color marker readers can't match a row to a bar, so this suits one or two clearly named series.
