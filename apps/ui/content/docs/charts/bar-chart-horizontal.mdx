Horizontal bars with category names down the left and a different color per category. Choose it over vertical bars when labels are long or when you are ranking items.

Give each record a category key, a value and a `fill` that points at its color variable, and add a label and color for each key to `chartConfig`. The left axis reads its text from those labels and sizes itself to the longest one, and `barSize` sets the bar thickness. Focus the chart and use the arrow keys to move the tooltip between bars.

<Only platform="rn">

A `BarChart` with `layout="vertical"`, so categories run down a `YAxis` and bars extend to the right, which leaves room for longer names. Each bar gets its color from `chartConfig` through a `Cell`, and the axis labels come from the same config.

Replace `chartData` with your categories and values, and add a matching entry with a label and color to `chartConfig` for each category. The component takes no props.

</Only>
