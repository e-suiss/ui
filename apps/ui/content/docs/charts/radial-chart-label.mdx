Concentric radial bars with each category name printed at the start of its bar. Pick it over the default radial chart when you want readers to identify bars without a legend or tooltip.

## Installation

### CLI

<Code lang="bash" title="Terminal" code={"npx @esuiss/ui@latest add charts radial-chart-label"} />

### Manual

1. Install the dependencies:

<Code lang="bash" title="Terminal" code={"npm install recharts"} />

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/radial-chart-label.tsx`:

<SourceFile path="components/charts/radial-chart-label.tsx" />

4. Update the import paths to match your project.

## Usage

<Code lang="tsx" code={"import { RadialChartLabel } from \"@/components/charts/radial-chart-label\""} />

<Code lang="tsx" code={"<RadialChartLabel />"} />

Replace `chartData` and add each category key with its label and color to `chartConfig`; the bar labels read from there. Change `startAngle` and `endAngle` to set how far the longest bar sweeps, and `barSize` to fit longer names.

## Notes

Labels sit inside the bars in a light color, so very short bars may not have room for their name.
