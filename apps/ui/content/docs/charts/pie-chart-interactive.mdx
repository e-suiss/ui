A storage breakdown with a Phone and Cloud switch, a stacked usage bar, a donut whose hovered slice lifts out and a list linked to it. The center shows the used total or the hovered category, and the slices morph when you switch devices. Use it as a reference for a rich part-to-whole view with linked controls.

Replace `STORAGE` with your own sources, each with a total and the size of every category, and list all categories in `KINDS`. Add a label and color for each category to `chartConfig`; the free space is computed from the total. Add another source to `STORAGE` to get another toggle.

## Notes

Highlighting works with a mouse over the slices, the bar or the list, but list rows aren't focusable, so keyboard users only get the totals. Changes in the center readout are announced through a live region, and the morph animation is skipped when reduced motion is preferred.
