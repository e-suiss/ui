A single filled area drawn as steps that hold each value flat until the next reading. It suits values that change in discrete jumps, like prices, plan tiers or inventory counts.

Replace `chartData`, point each `dataKey` at your fields and set the label and color in `chartConfig`. Set the curve type to `stepAfter` or `stepBefore` to move the jump to the other side of each point. Focus the chart and use the arrow keys to move the tooltip between months.

<Only platform="rn">

One series with `type="step"`, which draws flat runs between readings instead of a slope. Use it for values that change at discrete moments, such as prices or plan limits. It has a month axis, a dashed grid and a tooltip.

Replace `chartData` with your records and change each `dataKey` to match your fields. Set the label and color in `chartConfig`. The component takes no props.

</Only>
