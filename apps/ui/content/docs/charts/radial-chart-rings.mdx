Three nested activity rings for move, exercise and stand, each filling toward its own goal. They are drawn as plain SVG circles, so this is the lightest option when you just need static progress rings.

## Usage

<Code lang="tsx" code={"import { RadialChartRings } from \"@/components/charts/radial-chart-rings\""} />

<Code lang="tsx" code={"<RadialChartRings />"} />

Edit the `rings` array with your labels, values, goals and colors; each ring fills by value divided by goal. Change `SIZE` and `BAR` for the overall size and ring thickness.

## Notes

The graphic is exposed as an image with a label listing each ring's value and goal. A value above its goal just shows a closed ring, with no second lap.
