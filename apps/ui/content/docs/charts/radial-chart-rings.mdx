Three nested activity rings for move, exercise and stand, each filling toward its own goal. They are drawn as plain SVG circles, so this is the lightest option when you just need static progress rings.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add charts radial-chart-rings
```

### Manual

1. Add the pieces it builds on: [Card](/docs/components/card).

2. Copy the source into `components/charts/radial-chart-rings.tsx`:

<ComponentSource path="components/charts/radial-chart-rings.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { RadialChartRings } from "@/components/charts/radial-chart-rings"
```

```tsx
<RadialChartRings />
```

Edit the `rings` array with your labels, values, goals and colors; each ring fills by value divided by goal. Change `SIZE` and `BAR` for the overall size and ring thickness.

## Notes

The graphic is exposed as an image with a label listing each ring's value and goal. A value above its goal just shows a closed ring, with no second lap.

Three rings drawn with `Svg` circles colored through `ChartPalette`. Each entry in `rings` has a value and a goal, and the filled arc is capped at a full circle. The whole graphic is one accessible image whose label lists each ring's value and goal. Nothing is interactive.
