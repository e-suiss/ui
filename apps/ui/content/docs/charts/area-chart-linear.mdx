One series filled under straight line segments instead of a smoothed curve. Prefer it to the default when smoothing would suggest values between points that were never measured.

## Installation

### CLI

<Code lang="bash" title="Terminal" code={"npx @esuiss/ui@latest add charts area-chart-linear"} />

### Manual

1. Install the dependencies:

<Code lang="bash" title="Terminal" code={"npm install recharts"} />

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/area-chart-linear.tsx`:

<SourceFile path="components/charts/area-chart-linear.tsx" />

4. Update the import paths to match your project.

## Usage

<Code lang="tsx" code={"import { AreaChartLinear } from \"@/components/charts/area-chart-linear\""} />

<Code lang="tsx" code={"<AreaChartLinear />"} />

Replace `chartData`, update each `dataKey` to your field names and rename the `chartConfig` entry to set the label and color. Everything else matches the default area chart.

## Notes

Keyboard users can focus the plot and step through the months with the arrow keys.
