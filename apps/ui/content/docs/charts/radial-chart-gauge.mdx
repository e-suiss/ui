A gauge-style arc that opens at the bottom, showing a single reading with its value and rating in the center. Use it for scores with a known range, such as air quality, health scores or credit utilization.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/radial-chart-gauge
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts radial-chart-gauge
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/radial-chart-gauge.tsx`:

<ComponentSource path="components/charts/radial-chart-gauge.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { RadialChartGauge } from "@/components/charts/radial-chart-gauge"
```

```tsx
<RadialChartGauge />
```

Set the reading in `chartData` and the scale on `PolarAngleAxis` through its `domain`. Update the number and rating text in the center overlay, which are not read from the data. Change the color in `chartConfig`, or pick it from the value if the color should signal good and bad ranges.

## Notes

There is no tooltip and the center text is hard-coded, so keep it in sync with the value you pass.

## Usage

```tsx
import { RadialChartGauge } from "@/components/charts/radial-chart-gauge"
```

```tsx
<RadialChartGauge />
```

Change the `value` in `chartData` (0 to 100) and the centered text to match it; the label and color live in `chartConfig`. The component takes no props.
