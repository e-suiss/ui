A stacked quarterly revenue chart with live controls for every tooltip option: indicator style, hover or click trigger, a total in the title, and hiding the title or indicator. Use it to try combinations before copying the settings into your own chart.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add charts tooltip-chart-interactive
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart), [Switch](/docs/components/switch), [Toggle Group](/docs/components/toggle-group).

3. Copy the source into `components/charts/tooltip-chart-interactive.tsx`:

<ComponentSource path="components/charts/tooltip-chart-interactive.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { TooltipChartInteractive } from "@/components/charts/tooltip-chart-interactive"
```

```tsx
<TooltipChartInteractive />
```

Pick the combination you like, then copy the matching props into your chart: `indicator`, `hideLabel` and `hideIndicator` go on the tooltip content, and `trigger` on `ChartTooltip`. The total in the title comes from a label formatter that sums the rows.

## Notes

With the click trigger, the tooltip appears only after a bar is clicked and stays in place as the pointer moves. Every control is a labeled, keyboard-operable switch or toggle group.
