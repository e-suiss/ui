Two series as smooth lines on shared axes, with a legend below. Use it to compare how two metrics move over the same period.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/line-chart-multiple
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts line-chart-multiple
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/line-chart-multiple.tsx`:

<ComponentSource path="components/charts/line-chart-multiple.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { LineChartMultiple } from "@/components/charts/line-chart-multiple"
```

```tsx
<LineChartMultiple />
```

Replace `chartData` and rename the series keys in the data, both `Line` elements and `chartConfig`. Add another `Line` with its own config entry for more series; the legend and tooltip pick them up automatically.

## Notes

Beyond four or five lines the chart gets hard to read; consider the interactive variant that lets readers toggle series.
