Concentric radial bars, one per category, each running along a gray background track. Use it as a compact, circular alternative to a bar chart for a few categories.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/radial-chart-default
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts radial-chart-default
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/radial-chart-default.tsx`:

<ComponentSource path="components/charts/radial-chart-default.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { RadialChartDefault } from "@/components/charts/radial-chart-default"
```

```tsx
<RadialChartDefault />
```

Give each record a category key, a value and a `fill` that points at its color, and add each key to `chartConfig`. Adjust `barSize` for ring thickness and `innerRadius` to open up the center.

## Notes

Arc lengths are relative to the largest value, which always closes a full circle; add a `PolarAngleAxis` with a fixed `domain` if bars should be measured against a known maximum. The first record sits on the innermost ring, where the same value looks shorter than on outer rings.
