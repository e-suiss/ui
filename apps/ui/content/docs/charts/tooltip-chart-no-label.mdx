A stacked bar chart whose tooltip drops the category heading and shows only the series rows. Use it when the hovered category is obvious from the axis and you want a smaller tooltip.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/tooltip-chart-no-label
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts tooltip-chart-no-label
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/tooltip-chart-no-label.tsx`:

<ComponentSource path="components/charts/tooltip-chart-no-label.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { TooltipChartNoLabel } from "@/components/charts/tooltip-chart-no-label"
```

```tsx
<TooltipChartNoLabel />
```

Set `hideLabel` on `ChartTooltipContent`. Replace `chartData` and the series in `chartConfig` with your own.

## Notes

The tooltip opens on a preset month when the chart loads; remove `defaultIndex` if it should start hidden.
