The starting line chart: one smooth series without point markers, a month axis and a tooltip. Use it to show a trend over time when the overall shape matters more than individual readings.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/line-chart-default
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts line-chart-default
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/line-chart-default.tsx`:

<ComponentSource path="components/charts/line-chart-default.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { LineChartDefault } from "@/components/charts/line-chart-default"
```

```tsx
<LineChartDefault />
```

Replace `chartData`, point each `dataKey` at your fields and rename the `chartConfig` entry to set the label and color. Switch the `type` on the line to change the curve, or set `dot` to show markers.

## Notes

Focus the chart and use the arrow keys to step the tooltip through the points.
