One series drawn as a filled shape across six axes on a polygon grid. Use it to show the profile of a single item across several comparable scores, such as skills or product ratings.

## Usage

<Code lang="tsx" code={"import { RadarChartDefault } from \"@/components/charts/radar-chart-default\""} />

<Code lang="tsx" code={"<RadarChartDefault />"} />

Replace `chartData` with one record per axis, set `dataKey` on `PolarAngleAxis` to the axis name field and on `Radar` to your value field. Rename the series in `chartConfig` to set its label and color.

## Notes

Without a fixed scale the radius adapts to the largest value, so two charts with different data aren't directly comparable; see the radius-axis variant for a fixed range. Radar charts read best with five to eight axes.

The basic `RadarChart`: a polygon `PolarGrid`, an angle axis for each skill and one filled `Radar` series. `chartData` has one record per axis (`skill`) with `thisMonth` and `lastMonth` scores. Only `thisMonth` is drawn. Pressing the chart shows a tooltip.
