Radial charts bend bars around a center to show progress toward a goal or how categories compare. Use concentric bars for a few categories, a single ring with a centered value for one percentage, and a gauge or three-quarter arc when the value has a limit. The rings, batteries and stacked variants cover activity rings, device charge and two series sharing one arc.

Each chart is built on the [Chart](/docs/components/chart) and [Card](/docs/components/card) components.

Every variant below is its own registry item, so you can add only the ones you need. Each one renders the same design on React, React Native, SwiftUI and Jetpack Compose.
