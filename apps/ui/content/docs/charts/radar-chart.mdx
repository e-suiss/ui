Radar charts compare one or two subjects across several measures on axes that share a center. Use the default for a single profile, add a second series to compare two periods or products, and choose between polygonal, circular, filled or no grid lines to set how much structure the chart shows. The radius axis variant adds a visible value scale.

Each chart is built on the [Chart](/docs/components/chart) and [Card](/docs/components/card) components.

Every variant below is its own registry item, so you can add only the ones you need. Each one renders the same design on React, React Native, SwiftUI and Jetpack Compose.
