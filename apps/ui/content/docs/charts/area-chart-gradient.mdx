Two overlapping series whose fills fade to transparent toward the baseline, so the lower series stays visible through the upper one. Reach for it over the flat-filled default when you compare two series that cross each other.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/area-chart-gradient
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts area-chart-gradient
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/area-chart-gradient.tsx`:

<ComponentSource path="components/charts/area-chart-gradient.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { AreaChartGradient } from "@/components/charts/area-chart-gradient"
```

```tsx
<AreaChartGradient />
```

Replace `chartData` and rename the two series keys consistently across the data, the areas and `chartConfig`. Each series needs its own gradient in the `defs` block, so add or rename one when you add a series. Raise or lower the top stop's `stopOpacity` to make the fill stronger or subtler.

## Notes

The series are drawn in source order, so the last `Area` sits on top. Focus the plot and use the arrow keys to move the tooltip between months.

## Usage

```tsx
import { AreaChartGradient } from "@/components/charts/area-chart-gradient"
```

```tsx
<AreaChartGradient />
```

Replace `chartData` with your records and change each `dataKey` to match your fields. Add or rename series in `chartConfig`, and change the `fade` stops to make the gradient stronger or lighter. The component takes no props.
