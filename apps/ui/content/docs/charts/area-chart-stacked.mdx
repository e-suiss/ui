Two series stacked so the top edge shows the combined total, with a legend underneath. Use it when both the total and each part's contribution matter, as in desktop plus mobile traffic.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add charts area-chart-stacked
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/area-chart-stacked.tsx`:

<ComponentSource path="components/charts/area-chart-stacked.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { AreaChartStacked } from "@/components/charts/area-chart-stacked"
```

```tsx
<AreaChartStacked />
```

Replace `chartData` and rename the series keys in the data, both areas and `chartConfig`. Give every series the same `stackId` to stack them; the first one declared sits at the bottom. The legend picks up labels and colors from the config automatically.

## Notes

The tooltip follows the cursor or the arrow keys once the plot has focus.

## Usage

```tsx
import { AreaChartStacked } from "@/components/charts/area-chart-stacked"
```

```tsx
<AreaChartStacked />
```

Replace `chartData` with your records and change each `dataKey` to match your fields. Add, rename or recolor series in `chartConfig`; the legend picks the changes up. The component takes no props.
