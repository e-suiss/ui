Two series stacked so the top edge shows the combined total, with a legend underneath. Use it when both the total and each part's contribution matter, as in desktop plus mobile traffic.

## Usage

<Code lang="tsx" code={"import { AreaChartStacked } from \"@/components/charts/area-chart-stacked\""} />

<Code lang="tsx" code={"<AreaChartStacked />"} />

Replace `chartData` and rename the series keys in the data, both areas and `chartConfig`. Give every series the same `stackId` to stack them; the first one declared sits at the bottom. The legend picks up labels and colors from the config automatically.

## Notes
