A screen-time card with 24 thin hourly bars, a total in the header and a dashed line at the hourly average. Use it for any day-at-a-glance metric with many small periods.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/bar-chart-hourly
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add charts bar-chart-hourly
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/bar-chart-hourly.tsx`:

<ComponentSource path="components/charts/bar-chart-hourly.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { BarChartHourly } from "@/components/charts/bar-chart-hourly"
```

```tsx
<BarChartHourly />
```

Replace the 24 values in `chartData` with your own per-hour numbers; the total and the average line are computed from them. Change the axis `ticks` to label different hours, and update the minute unit in the axis, tooltip and header if you measure something else.

## Notes

With 24 narrow bars, the tooltip is the most reliable way to read a single hour. Focus the chart and use the arrow keys to step through the hours.
