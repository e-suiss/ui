A week of active-energy bars whose tooltip row is rewritten by a formatter to show a name, value and kcal unit. Use a formatter like this when values need units, thousands separators or extra context.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/tooltip-chart-formatter
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts tooltip-chart-formatter
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/tooltip-chart-formatter.tsx`:

<ComponentSource path="components/charts/tooltip-chart-formatter.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { TooltipChartFormatter } from "@/components/charts/tooltip-chart-formatter"
```

```tsx
<TooltipChartFormatter />
```

Pass a `formatter` to `ChartTooltipContent`; it receives each row's value and name and returns the markup for that row. Change the label text, number format and unit inside it, and replace `chartData` and `chartConfig` with your series.

## Notes

Dates are parsed at noon so the weekday labels don't shift a day in time zones behind UTC; keep that if you use date strings as categories.
