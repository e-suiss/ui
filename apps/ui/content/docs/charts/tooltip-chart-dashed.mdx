A stacked bar chart that shows the dashed tooltip indicator, which marks each series with a dashed outline in its color. Compare it with the dot and line variants to pick the indicator that fits your design.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/tooltip-chart-dashed
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add charts tooltip-chart-dashed
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/tooltip-chart-dashed.tsx`:

<ComponentSource path="components/charts/tooltip-chart-dashed.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { TooltipChartDashed } from "@/components/charts/tooltip-chart-dashed"
```

```tsx
<TooltipChartDashed />
```

Set `indicator` on `ChartTooltipContent` to `dashed`; the same setting works on any chart. Replace `chartData` and the series in `chartConfig` to use your own data.

## Notes

The tooltip opens on a preset month when the chart loads; remove `defaultIndex` if it should start hidden.
