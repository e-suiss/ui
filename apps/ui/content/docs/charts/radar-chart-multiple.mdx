Two semi-transparent radar shapes layered on the same grid, comparing this month with last month. Use it for a before-and-after or two-item comparison across the same axes.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/radar-chart-multiple
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add charts radar-chart-multiple
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/radar-chart-multiple.tsx`:

<ComponentSource path="components/charts/radar-chart-multiple.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { RadarChartMultiple } from "@/components/charts/radar-chart-multiple"
```

```tsx
<RadarChartMultiple />
```

Replace `chartData` and rename the series keys in the data, both `Radar` elements and `chartConfig`. Put the reference series first so the current one is drawn on top.

## Notes

There is no legend, so the tooltip is the only place series names appear; use the legend variant if that's not enough.

## Usage

```tsx
import { RadarChartMultiple } from "@/components/charts/radar-chart-multiple"
```

```tsx
<RadarChartMultiple />
```

Replace `chartData` with your records, set `PolarAngleAxis` `dataKey` to your axis field, and rename the series in `chartConfig`. The component takes no props.
