A single line drawn as flat steps that hold each value until the next reading. It fits values that change in discrete jumps, like prices, plan tiers or headcount.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add charts line-chart-step
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/line-chart-step.tsx`:

<ComponentSource path="components/charts/line-chart-step.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { LineChartStep } from "@/components/charts/line-chart-step"
```

```tsx
<LineChartStep />
```

Replace `chartData`, point each `dataKey` at your fields and set the label and color in `chartConfig`. Use `stepAfter` or `stepBefore` as the curve type to move where each jump happens.

## Notes

The tooltip follows the cursor, or the arrow keys once the chart has focus.
