A single line drawn as flat steps that hold each value until the next reading. It fits values that change in discrete jumps, like prices, plan tiers or headcount.

Replace `chartData`, point each `dataKey` at your fields and set the label and color in `chartConfig`. Set the curve type to `stepAfter` or `stepBefore` to move where each jump happens. Focus the chart and use the arrow keys to move the tooltip between months.

<Only platform="rn">

One series with `type="step"`, which draws flat runs and vertical jumps instead of slopes. Use it for values that change at discrete moments. It has a month axis, a dashed grid and a tooltip.

Replace `chartData` with your records and change each `dataKey` to match your fields. Set the label and color in `chartConfig`. The component takes no props.

</Only>
