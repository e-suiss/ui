Bar charts compare a value across categories or periods. Start with the default for one series, group or stack bars when there are two, turn them horizontal for long category names, and use the negative or range variants when a value can drop below zero or spans a low and a high.

Every variant below is its own registry item, so you can add only the ones you need. Each one renders the same design on React, React Native, SwiftUI and Jetpack Compose.
