A single radar shape with a 0 to 100 scale printed along the vertical axis. Choose it when readers need to estimate values, or when several radar charts must share the same scale.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/radar-chart-radius-axis
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts radar-chart-radius-axis
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/radar-chart-radius-axis.tsx`:

<ComponentSource path="components/charts/radar-chart-radius-axis.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { RadarChartRadiusAxis } from "@/components/charts/radar-chart-radius-axis"
```

```tsx
<RadarChartRadiusAxis />
```

Replace `chartData`, set the axis and value keys, and rename the series in `chartConfig`. Set `domain` on `PolarRadiusAxis` to your score range and `tickCount` for the number of labels. Change its angle to move the scale to another direction.

## Notes

A fixed domain keeps shapes comparable across charts, as long as your scores stay inside it.
