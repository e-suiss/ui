A single radar shape with a 0 to 100 scale printed along the vertical axis. Choose it when readers need to estimate values, or when several radar charts must share the same scale.

## Usage

<Code lang="tsx" code={"import { RadarChartRadiusAxis } from \"@/components/charts/radar-chart-radius-axis\""} />

<Code lang="tsx" code={"<RadarChartRadiusAxis />"} />

Replace `chartData`, set the axis and value keys, and rename the series in `chartConfig`. Set `domain` on `PolarRadiusAxis` to your score range and `tickCount` for the number of labels. Change its angle to move the scale to another direction.

## Notes

A fixed domain keeps shapes comparable across charts, as long as your scores stay inside it.
