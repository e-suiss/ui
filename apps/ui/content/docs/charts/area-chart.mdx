Area charts show how a value moves over time and how big it is at each point. Use the default for one series, stack areas to show a total and its parts, expand them to 100% to compare shares, and switch to linear or step lines when the readings should not look smoothed. The range variant shades a low-to-high band, and the sparkline fits a tiny trend beside a value.

Each chart is built on the [Chart](/docs/components/chart) and [Card](/docs/components/card) components.

Every variant below is its own registry item, so you can add only the ones you need. Each one renders the same design on React, React Native, SwiftUI and Jetpack Compose.
