A stacked bar chart that shows the line tooltip indicator, a thin vertical bar in each series' color. It reads cleanly in dense tooltips and pairs well with line and area charts.

Set `indicator` on `ChartTooltipContent` to `line`. Replace `chartData` and the series in `chartConfig` with your own. The tooltip opens on a preset month when the chart loads; remove `defaultIndex` if it should start hidden.
