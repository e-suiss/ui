Every chart shares one tooltip, and these variants show how to change it. Pick an indicator style, hide the indicator or the label, format values and headings with your own functions, show an icon per series, or replace the content with your own markup. The interactive variant lets you try the options on one chart.

These tooltips are the `ChartTooltipContent` of the [Chart](/docs/components/chart) component, used inside charts built on [Card](/docs/components/card).

Every variant below is its own registry item, so you can add only the ones you need.
