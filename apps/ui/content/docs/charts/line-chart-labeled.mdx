A single smooth line with a dot and a printed value at every point and no grid. Choose it for short series where readers want the exact numbers without hovering.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add charts line-chart-labeled
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/line-chart-labeled.tsx`:

<ComponentSource path="components/charts/line-chart-labeled.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { LineChartLabeled } from "@/components/charts/line-chart-labeled"
```

```tsx
<LineChartLabeled />
```

Replace `chartData`, point each `dataKey` at your fields and set the label and color in `chartConfig`. Move the value labels with the `position` prop on `LabelList`, and raise the chart's top margin if labels get clipped.

## Notes

Labels overlap quickly on long or dense series; keep this variant to a dozen points or fewer.
