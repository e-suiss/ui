A donut with a hollow center and small gaps between slices. It reads lighter than a full pie and leaves the center free for a label if you need one later.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/pie-chart-donut
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts pie-chart-donut
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/pie-chart-donut.tsx`:

<ComponentSource path="components/charts/pie-chart-donut.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { PieChartDonut } from "@/components/charts/pie-chart-donut"
```

```tsx
<PieChartDonut />
```

Replace `chartData` and add a label and color to `chartConfig` for each category key. Change the ring thickness with `innerRadius` and `outerRadius`, and the gap between slices with `paddingAngle`.

</Only>

## Usage

```tsx
import { PieChartDonut } from "@/components/charts/pie-chart-donut"
```

```tsx
<PieChartDonut />
```

Replace `chartData` with your records and keep `dataKey` and `nameKey` in step with your field names. Add one entry per slice to `chartConfig` with its label and color; the component takes no props.
