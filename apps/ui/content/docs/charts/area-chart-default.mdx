The baseline area chart: one series as a smooth, lightly filled curve with a month axis and a tooltip, and no value axis. Start here when you only need the shape of a trend and want to build up from the simplest version.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/area-chart-default
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts area-chart-default
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/area-chart-default.tsx`:

<ComponentSource path="components/charts/area-chart-default.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { AreaChartDefault } from "@/components/charts/area-chart-default"
```

```tsx
<AreaChartDefault />
```

Replace `chartData` with your records and change each `dataKey` to match your field names. Rename the series entry in `chartConfig` and pick its label and color there. Change the curve shape with the `type` prop on the area, for example to straight lines or steps.

## Notes

Focus the plot and use the arrow keys to move the tooltip between months. Colors come from `chartConfig`, so they follow light and dark mode without extra work.
