A single radar shape with a solid dot at the value on every axis. The dots make individual scores easier to locate than on the plain filled shape.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/radar-chart-dots
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add charts radar-chart-dots
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install recharts
```

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/radar-chart-dots.tsx`:

<ComponentSource path="components/charts/radar-chart-dots.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { RadarChartDots } from "@/components/charts/radar-chart-dots"
```

```tsx
<RadarChartDots />
```

Replace `chartData`, set the axis and value keys, and rename the series in `chartConfig`. Change the marker size through the `dot` prop on `Radar`, or set it to false to go back to the plain shape.

</Only>
