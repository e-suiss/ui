A single radar shape with a solid dot at the value on every axis. The dots make individual scores easier to locate than on the plain filled shape.

## Installation

### CLI

<Code lang="bash" title="Terminal" code={"npx @esuiss/ui@latest add charts radar-chart-dots"} />

### Manual

<Code lang="bash" title="Terminal" code={"npm install recharts"} />

2. Add the pieces it builds on: [Card](/docs/components/card), [Chart](/docs/components/chart).

3. Copy the source into `components/charts/radar-chart-dots.tsx`:

<SourceFile path="components/charts/radar-chart-dots.tsx" />

## Usage

<Code lang="tsx" code={"import { RadarChartDots } from \"@/components/charts/radar-chart-dots\""} />

<Code lang="tsx" code={"<RadarChartDots />"} />

Replace `chartData`, set the axis and value keys, and rename the series in `chartConfig`. Change the marker size through the `dot` prop on `Radar`, or set it to false to go back to the plain shape.
