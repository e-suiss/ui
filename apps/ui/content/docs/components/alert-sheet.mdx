Alert Sheet is an iOS-style action sheet built on Base UI's dialog primitives. An `AlertSheet` root contains an `AlertSheetTrigger` and an `AlertSheetContent`, which renders its own portal and scrim overlay. Inside, an `AlertSheetGroup` holds an optional `AlertSheetHeader` (with `AlertSheetTitle` and `AlertSheetDescription`) and one or more `AlertSheetAction` rows. A separate `AlertSheetCancel` sits below the group.

Use it to offer a short list of actions tied to the current context, especially on touch devices. For a centered confirmation, use Alert Dialog.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add alert-sheet
```

## Usage

```tsx
import { AlertSheet, AlertSheetTrigger, AlertSheetPortal, AlertSheetOverlay, AlertSheetContent, AlertSheetGroup, AlertSheetHeader, AlertSheetTitle, AlertSheetDescription, AlertSheetAction, AlertSheetCancel } from "@/components/ui/alert-sheet"
```

```tsx
<div className="flex min-h-svh items-center justify-center">
  <AlertSheet>
    <AlertSheetTrigger render={<Button variant="outline" />}>
      Delete order
    </AlertSheetTrigger>
    <AlertSheetContent>
      <AlertSheetGroup>
        <AlertSheetHeader>
          <AlertSheetTitle className="sr-only">Delete order</AlertSheetTitle>
          <AlertSheetDescription>
            Order #1042 will be permanently deleted. This action cannot be
            undone.
          </AlertSheetDescription>
        </AlertSheetHeader>
        <AlertSheetAction variant="destructive">
          Delete Order
        </AlertSheetAction>
      </AlertSheetGroup>
      <AlertSheetCancel>Cancel</AlertSheetCancel>
    </AlertSheetContent>
  </AlertSheet>
</div>
```

Every sheet needs an `AlertSheetTitle` for its accessible name. If the title should not be visible, hide it with `className="sr-only"`.

By default the sheet is `dismissible` and behaves like a regular dialog. Set `dismissible={false}` to render it as an alert dialog instead.

When the sheet opens, focus moves to `AlertSheetCancel` unless you pass your own `initialFocus` to `AlertSheetContent`. Every action and the cancel button close the sheet. Control the open state with `open` and `onOpenChange`, or use `defaultOpen`.

## Accessibility

- With `dismissible` (the default) the popup has the `dialog` role; with `dismissible={false}` it has the `alertdialog` role.
- The popup is named by `AlertSheetTitle` and described by `AlertSheetDescription`.
- Focus moves to the cancel button on open and returns to the trigger on close.
- `Escape` closes the sheet.

## Notes

- Styling hooks: `data-slot` values from `alert-sheet` through `alert-sheet-cancel`.
- The sheet slides with `translate-y-full` on `data-starting-style` and `data-ending-style`, and its bottom padding respects `env(safe-area-inset-bottom)`.
- When an action contains an icon, the group switches to a grid so icons and labels align across rows.

`AlertSheet` presents a set of choices related to the current context. `AlertSheetContent` renders through a portal (inside a full-window overlay on iOS), slides up from the bottom over a dimmed scrim, and respects the safe-area insets.

Actions sit in an `AlertSheetGroup`, a rounded card that draws a hairline between each child, and `AlertSheetCancel` sits below it as its own card with bold text. Use it for two to a few actions; for a single decision that needs confirmation, use Alert Dialog.

## Usage

```tsx
import { AlertSheet, AlertSheetOverlay, AlertSheetContent, AlertSheetGroup, AlertSheetHeader, AlertSheetTitle, AlertSheetDescription, AlertSheetAction, AlertSheetCancel } from "@/components/ui/alert-sheet"
```

```tsx
<View className="items-start">
  <AlertSheet defaultOpen>
    <AlertSheetTrigger render={<Button variant="outline" />}>
      <Text>Show sheet</Text>
    </AlertSheetTrigger>
    <SheetBody />
  </AlertSheet>
</View>
```

Compose `AlertSheetTrigger` and `AlertSheetContent`. Inside the content, put an `AlertSheetGroup` with an optional `AlertSheetHeader` (`AlertSheetTitle`, `AlertSheetDescription`) followed by `AlertSheetAction`s, then an `AlertSheetCancel`.

Every action closes the sheet when pressed. String children are wrapped in `Text` automatically. Use `variant="destructive"` on an action that deletes or removes, and `disabled` to dim and block it.

By default the sheet is dismissible and a tap on the scrim closes it. Set `dismissible={false}` to require an explicit choice.

## Accessibility

- When dismissible the popup has the `dialog` role, otherwise `alertdialog`; it is labelled by the title and marked as modal for VoiceOver.
- Focus moves to the title when the sheet opens.
- Actions have the `button` role with a `disabled` state.
- Separators between actions are hidden from screen readers.

## Notes

- Padding uses the bottom and side safe-area insets, with a minimum of 8 points.
- On iOS the content is wrapped in a full-window overlay.
- Animations respect the system Reduce Motion setting.
- Uses `bg-popover`, `text-primary` and `text-destructive` tokens, with `opacity-80` while pressed; light and dark follow the system appearance.
