<Only platform="rn">

`Icon` takes a Phosphor icon component in `as` and maps `size-*` classes to its size and `text-*` classes to its color. It defaults to `size-5 text-foreground`.

Icons inherit text and icon classes from their parent, so an `Icon` inside a `Button`, `Badge` or menu item picks up the right size and color without extra classes. Components provide these through `IconClassContext`.

</Only>

<Only platform="swift">

SwiftUI has no `Icon` view to install. Use the images from the Phosphor Swift package directly, and set their size and color with SwiftUI modifiers, as the examples on this page do.

</Only>

## Usage

<Only platform="rn">

```tsx
import { StarIcon } from "phosphor-react-native"
import { Icon } from "@/components/ui/icon"
```

```tsx
<Icon as={StarIcon} />
```

</Only>

<Only platform="swift">

```swift
import PhosphorSwift
import SwiftUI

struct IconExample: View {
  var body: some View {
    IconGlyph(image: Ph.star.regular)
  }
}

struct IconGlyph: View {
  let image: Image
  var size: CGFloat = 20
  var color: Color = EsuissColor.foreground

  var body: some View {
    image
      .resizable()
      .scaledToFit()
      .frame(width: size, height: size)
      .foregroundStyle(color)
  }
}
```

</Only>

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.Arrangement
import androidx.compose.foundation.layout.Row
import androidx.compose.runtime.Composable
import androidx.compose.ui.Alignment
import androidx.compose.ui.unit.dp
import com.adamglin.PhosphorIcons
import com.adamglin.phosphoricons.Regular
import com.adamglin.phosphoricons.regular.Star
import com.esuiss.ui.components.Icon

@Composable
fun IconRow(content: @Composable () -> Unit) {
    Row(horizontalArrangement = Arrangement.spacedBy(16.dp), verticalAlignment = Alignment.CenterVertically) {
        content()
    }
}

@Composable
fun IconDefault() {
    IconRow {
        Icon(PhosphorIcons.Regular.Star, contentDescription = null)
    }
}
```

## API Reference

</Only>

<Only platform="rn">

### Icon

Styled Phosphor icon.

| Prop | Type | Default |
| --- | --- | --- |
| `as` | `PhosphorIcon` | Required |

Also accepts the props of `IconProps` from `phosphor-react-native`.

Pass the Phosphor icon component to render in `as`, not an element: `<Icon as={HeartIcon} />`. Override the size and color with `className`, such as `size-6 text-destructive`. Other Phosphor props, such as `weight` and `mirrored`, are passed through. The default color is the `text-foreground` token, so icons follow light and dark mode. Wrap a subtree in `IconClassContext.Provider` to set default classes for the icons inside your own components.

</Only>

<Only platform="kotlin">

### Icon

Styled Phosphor icon.

| Parameter | Type | Default |
| --- | --- | --- |
| `imageVector` | `ImageVector` | - |
| `contentDescription` | `String?` | - |
| `modifier` | `Modifier` | `Modifier` |
| `size` | `Dp` | `LocalIconSize.current` |
| `tint` | `Color` | `LocalContentColor.current.takeOrElse { EsuissTheme.colors.foreground }` |

</Only>
