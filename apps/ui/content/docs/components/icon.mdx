`Icon` takes a Phosphor icon component in `as` and maps `size-*` classes to its size and `text-*` classes to its color. It defaults to `size-5 text-foreground`.

Icons inherit text and icon classes from their parent, so an `Icon` inside a `Button`, `Badge` or menu item picks up the right size and color without extra classes. Components provide these through `IconClassContext`.

</Only>

<Only platform="swift">

SwiftUI has no `Icon` view to install. Use the images from the Phosphor Swift package directly, and set their size and color with SwiftUI modifiers, as the examples on this page do.

</Only>

## Usage

```tsx
import { Icon } from "@/components/ui/icon"
```

```tsx
<Icon as={StarIcon} />
```

Pass the icon component, not an element: `<Icon as={HeartIcon} />`. Override the size and color with `className`, such as `size-6 text-destructive`. Other Phosphor props, such as `weight` and `mirrored`, are passed through.

Wrap a subtree in `IconClassContext.Provider` to set default classes for the icons inside your own components.

</Only>

## Accessibility

- Icons have no label of their own. When an icon is the only content of a pressable, give the pressable an `accessibilityLabel`.

## Notes

- The default color is the `text-foreground` token, so icons follow light and dark mode with the system appearance.
