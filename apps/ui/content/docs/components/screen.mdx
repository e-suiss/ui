`Screen` is a `View` that fills the screen, paints the `bg-background` color (or `bg-muted` for the `secondary` variant) and adds padding for the safe area insets on the edges you choose. It also renders a `StatusBar` with light or dark content to match the color scheme.

`ScreenContent` lays out the body with padding and gaps. With `scrollable`, it renders a `KeyboardScrollView` so content scrolls and stays above the keyboard.

## Usage

```tsx
import { Screen, ScreenContent } from "@/components/ui/screen"
```

```tsx
<Screen className="-m-4">
  <ScreenContent>
    <Text variant="h2">Account</Text>
    <Text variant="muted">
      The screen pads every safe-area edge and sets the status bar style
      from the color scheme.
    </Text>
    <Rows />
  </ScreenContent>
</Screen>
```

Wrap each screen in `Screen` and put the body in `ScreenContent`. Use `variant="secondary"` for grouped screens such as settings.

Pass `edges` to pad only some sides, for example `["top"]` when a tab bar or bottom bar handles the bottom inset. Set `scrollable` on `ScreenContent` for content taller than the screen or for forms.

The app must be wrapped in a `SafeAreaProvider` from `react-native-safe-area-context`. `ScreenContext` exposes the active `edges` to children.

## API Reference

<ApiPart index={1}>

### Screen

The root view that pads for safe area insets.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `edges` | `readonly ScreenEdge[]` | `ALL_EDGES` | Which sides get safe area padding: any of `top`, `right`, `bottom`, `left`. Defaults to all four. |
| `variant` | `"default" \| "secondary"` | `"default"` | Background: `default` or `secondary`. |

Also accepts the props of `ViewProps`.

</ApiPart>

<ApiPart index={2}>

### ScreenContent

The padded body, optionally scrollable.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `scrollable` | `boolean` | `false` | Renders a `KeyboardScrollView` instead of a `View`. Defaults to `false`. |

Also accepts the props of `ViewProps`.

</ApiPart>

## Notes

- Uses the `bg-background` and `bg-muted` tokens.
- The status bar uses `light-content` in dark mode and `dark-content` in light mode, following the system appearance.
- Requires `react-native-safe-area-context` and the Keyboard Scroll View component.
