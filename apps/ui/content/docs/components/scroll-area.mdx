Scroll Area wraps the scroll area primitive of the chosen base. `ScrollArea` renders the root, a focusable viewport for your content, a vertical `ScrollBar` and a corner. Add a horizontal `ScrollBar` as a child when content scrolls sideways.

Use Scroll Area to give overflowing content a consistent scrollbar across platforms. For chat transcripts that should open at the latest message, use Message Scroller.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/scroll-area
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add scroll-area
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install @base-ui/react
```

2. Copy the source into `components/ui/scroll-area.tsx`:

<ComponentSource path="components/ui/scroll-area.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { ScrollArea, ScrollBar } from "@/components/ui/scroll-area"
import { Separator } from "@/components/ui/separator"
```

```tsx
<ScrollArea className="h-72 w-48 rounded-2xl border">
  <div className="p-4">
    <h4 className="mb-4 text-sm font-medium">Releases</h4>
    {releases.map((release) => (
      <div key={release}>
        <div className="text-sm">{release}</div>
        <Separator className="my-2" />
      </div>
    ))}
  </div>
</ScrollArea>
```

Give `ScrollArea` a fixed height or width with `className` so its content can overflow. Children render inside the viewport.

<OnlyBase base="base radix">

For horizontal scrolling, make the content wider than the area (for example with `w-max`) and include `ScrollBar` with `orientation="horizontal"`.

</OnlyBase>

<OnlyBase base="aria">

The viewport scrolls natively and shows the browser's thin scrollbars, tinted with the `border` color. For horizontal scrolling, make the content wider than the area (for example with `w-max`). `ScrollBar` renders nothing in this base; it is kept so code written for the other bases still compiles.

</OnlyBase>

<ApiPart index={1}>

### ScrollArea

<OnlyBase base="base radix">

The root that renders the viewport, the vertical scrollbar and the corner.

Also accepts the props of the primitive part it wraps.

</OnlyBase>

<OnlyBase base="aria">

The root that renders a natively scrolling viewport.

Also accepts the props of `React.ComponentProps<"div">`.

</OnlyBase>

</ApiPart>

<ApiPart index={2}>

### ScrollBar

<OnlyBase base="base radix">

A scrollbar track and thumb for one orientation, vertical by default.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` | The direction the scrollbar controls. |

Also accepts the props of the primitive part it wraps.

</OnlyBase>

<OnlyBase base="aria">

Renders nothing. The viewport uses the browser's native scrollbars.

</OnlyBase>

</ApiPart>

## Accessibility

<OnlyBase base="base radix">

- The viewport is focusable while its content overflows, so keyboard users can Tab to it and scroll with the arrow keys.

</OnlyBase>

<OnlyBase base="aria">

- The viewport is always focusable, so keyboard users can Tab to it and scroll with the arrow keys.

</OnlyBase>

- Focus is shown with the standard focus ring around the viewport.

<OnlyBase base="base radix">

- The custom scrollbars are presentational; native scrolling by wheel, touch and keyboard still works.

</OnlyBase>

## Notes

<OnlyBase base="base radix">

- Styling hooks: `data-slot` values `scroll-area`, `scroll-area-viewport`, `scroll-area-scrollbar` and `scroll-area-thumb`. Scrollbars expose `data-orientation`.
- The thumb uses the `border` color.

</OnlyBase>

<OnlyBase base="aria">

- Styling hooks: `data-slot` values `scroll-area` and `scroll-area-viewport`.
- The native scrollbar thumb uses the `border` color.

</OnlyBase>

- The viewport inherits the root's border radius, so rounded containers clip their content.

</Only>
