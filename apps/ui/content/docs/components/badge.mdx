`Badge` is a single element that renders a `span` by default and can render as another element, such as a link. Badges can hold text and an icon on either side.

<OnlyBase base="base">

Use the `render` prop to render the badge as another element: `render={<a href="/" />}`.

</OnlyBase>

<OnlyBase base="radix">

Set `asChild` and pass the element as the only child to render the badge as it.

</OnlyBase>

<OnlyBase base="aria">

Pass a `render` function that returns the element; spread the props it receives onto it.

</OnlyBase>

Use a badge to tag content with a short status or category. For actions, use Button instead.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/badge
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"

```

## Usage

```tsx
import { Badge } from "@/components/ui/badge"
```

```tsx
<Badge>Badge</Badge>
```

Mark icons with `data-icon="inline-start"` or `data-icon="inline-end"` so the `outline` and `ghost` variants tighten their padding on that side. Icons are sized to `size-3`.

<OnlyBase base="base">

Pass `render` with an anchor element, for example an `a` with an `href`, to make the badge a link. Linked badges get hover styles that depend on the variant.

</OnlyBase>

<OnlyBase base="radix">

Set `asChild` and pass an anchor element, for example an `a` with an `href`, as the child to make the badge a link. Linked badges get hover styles that depend on the variant.

</OnlyBase>

<OnlyBase base="aria">

Pass a `render` function that returns an anchor element, for example an `a` with an `href`, to make the badge a link. Linked badges get hover styles that depend on the variant.

</OnlyBase>

To use a custom color, override the text color with a `className` such as `text-green-600 dark:text-green-400`.

## API Reference

<ApiPart index={1}>

### Badge

The inline label element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "secondary" \| "destructive" \| "outline" \| "ghost" \| "link"` | `"default"` | Visual style. `default`, `secondary`, `destructive` and `link` are text-only; `outline` adds a border and `ghost` adds horizontal padding. |

<OnlyBase base="base">

Also accepts the props of `useRender.ComponentProps<"span">`.

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Renders the child element, such as a link, instead of a `span`. |

Also accepts the props of `React.ComponentProps<"span">`.

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `render` | `(props: React.HTMLAttributes<HTMLElement>) => React.ReactNode` | — | Renders your own element, such as a link, with the badge's props. |

Also accepts the props of `React.ComponentProps<"span">`.

</OnlyBase>

</ApiPart>

## Accessibility

- A badge is static text by default and is not focusable.
- When rendered as a link, it shows a focus ring on keyboard focus.
- `aria-invalid` adds a `border-destructive` border.

## Notes

- Styling hook: `data-slot="badge"`, plus `data-variant`.
- The `destructive` variant also tints the focus ring with `ring-destructive/20` (`ring-destructive/40` in dark mode).
- Badges are a fixed `h-5` with fully rounded corners and do not wrap text.

</Only>

<Only platform="rn">

`Badge` is a compact pill `View` that passes a small, bold text style and a 12-point icon size to its children. Six variants are available. `default`, `secondary`, `destructive` and `link` show colored text with no background, while `outline` adds a hairline border and `ghost` adds horizontal padding.

</Only>

Use `default` for highlighted labels, `secondary` for neutral metadata, `destructive` for errors and `outline` when the badge needs a visible edge.

## Accessibility

- The badge adds no role; it is read as plain text.
- If you render it as a pressable element, give that element a role and label.

## Notes

- Text colors come from `text-primary`, `text-muted-foreground`, `text-destructive` and `text-foreground`; light and dark follow the system appearance.
