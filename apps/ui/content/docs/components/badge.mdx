`Badge` is a single element that renders a `span` by default and can render as another element, such as a link. Badges can hold text and an icon on either side.

Use a badge to tag content with a short status or category. For actions, use Button instead.

## Usage

```tsx
import { Badge } from "@/components/ui/badge"
```

```tsx
<Badge variant="default | secondary | destructive | outline | ghost | link">
  Badge
</Badge>
```

## Examples

### Variants

Use the `variant` prop to change the look of the badge. `default`, `secondary`, `destructive` and `link` are text only, `outline` adds a border and `ghost` adds horizontal padding.

<ComponentPreview name="badge-variants" />

### With icon

Mark an icon with `data-icon="inline-start"` or `data-icon="inline-end"` so the `outline` and `ghost` variants tighten their padding on that side. Icons are sized to `size-3`.

<ComponentPreview name="badge-with-icon" />

### As link

<OnlyBase base="base">

Use the `render` prop to render the badge as a link: `render={<a href="/" />}`. Linked badges get hover styles that depend on the variant.

</OnlyBase>

<OnlyBase base="radix">

Set `asChild` and pass a link as the only child to render the badge as a link. Linked badges get hover styles that depend on the variant.

</OnlyBase>

<OnlyBase base="aria">

Pass a `render` function that returns a link and spread the props it receives onto it. Linked badges get hover styles that depend on the variant.

</OnlyBase>

<ComponentPreview name="badge-as-link" />

### Custom color

Override the text color with a `className` such as `text-green-600 dark:text-green-400`.

<ComponentPreview name="badge-custom-color" />

## Accessibility

- A badge is static text by default and is not focusable.
- When rendered as a link, it shows a focus ring on keyboard focus.
- `aria-invalid` adds a `border-destructive` border.

## API Reference

### Badge

The `Badge` component displays a short inline label.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "secondary" \| "destructive" \| "outline" \| "ghost" \| "link"` | `"default"` |
| `className` | `string` | - |

<OnlyBase base="base">

Also accepts the props of `useRender.ComponentProps<"span">`.

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |

Also accepts the props of `React.ComponentProps<"span">`.

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `(props: React.HTMLAttributes<HTMLElement>) => React.ReactNode` | - |

Also accepts the props of `React.ComponentProps<"span">`.

</OnlyBase>

Badges are a fixed `h-5` with fully rounded corners and do not wrap text. The `destructive` variant also tints the focus ring. Style a badge through `data-slot="badge"` and `data-variant`.

</Only>

<Only platform="rn">

`Badge` is a compact pill `View` that passes a small, bold text style and a 12-point icon size to its children. Six variants are available. `default`, `secondary`, `destructive` and `link` show colored text with no background, while `outline` adds a hairline border and `ghost` adds horizontal padding.

</Only>

Use `default` for highlighted labels, `secondary` for neutral metadata, `destructive` for errors and `outline` when the badge needs a visible edge.

## API Reference

<Only platform="rn">

### Badge

The `Badge` component displays a short inline label.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "secondary" \| "destructive" \| "outline" \| "ghost" \| "link"` | `"default"` |
| `render` | `RenderProp` | - |

Also accepts the props of `ViewProps`.

Put the label in a `Text` and icons in an `Icon`. Use `render` to render the badge as another component, such as a `Pressable`, while keeping its styles. `badgeVariants` and `badgeTextVariants` are also exported if you need the classes on another element. Text colors come from `text-primary`, `text-muted-foreground`, `text-destructive` and `text-foreground`.

</Only>
