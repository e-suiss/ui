Progress wraps the progress primitive of the chosen base. `Progress` is the root and always renders a `ProgressTrack` containing a `ProgressIndicator` after its children. Add a `ProgressLabel` to name the bar and a `ProgressValue` to show the formatted value; they sit on one row above the track.

Use Progress for determinate or indeterminate task progress.

  ProgressLabel,

```tsx

```

## Composition

Use the following composition to build a `Progress`:

```text
Progress
├── ProgressLabel
└── ProgressValue
```

## Accessibility

- The root has the `progressbar` role with `aria-valuenow` reflecting the value.
- `ProgressLabel` provides the accessible name. Without it, pass `aria-label`.

<OnlyBase base="base radix">

- When `value` is `null`, `aria-valuenow` is omitted to signal an indeterminate state.

</OnlyBase>

<OnlyBase base="aria">

- With `isIndeterminate`, `aria-valuenow` is omitted to signal an indeterminate state.

</OnlyBase>

## API Reference

### Progress

The root that holds the value and renders the track and indicator.

<OnlyBase base="base">

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `number \| null` | — |
| `min` | `number` | `0` |
| `max` | `number` | `100` |

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `number \| null` | `null` |
| `max` | `number` | `100` |

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `number` | `0` |
| `minValue` | `number` | `0` |
| `maxValue` | `number` | `100` |
| `isIndeterminate` | `boolean` | `false` |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base">

Pass `value` as a number between `min` and `max`; `min` is the value of an empty bar and `max` of a full one. Set `value={null}` for an indeterminate bar when the amount of work is unknown.

</OnlyBase>

<OnlyBase base="radix">

Pass `value` as a number between `0` and `max`, the value of a full bar. Leave `value` out, or set `value={null}`, for an indeterminate bar when the amount of work is unknown.

</OnlyBase>

<OnlyBase base="aria">

Pass `value` as a number between `minValue` and `maxValue`, the values of an empty and a full bar. Set `isIndeterminate` for an indeterminate bar when the amount of work is unknown.

</OnlyBase>

The track and indicator are rendered for you after the children, so `ProgressTrack` and `ProgressIndicator` are not needed inside `Progress`. The indicator animates width changes.

### ProgressTrack

The full-width rail behind the indicator.

Also accepts the props of the primitive part it wraps.

### ProgressIndicator

The filled portion of the track that reflects the value.

Also accepts the props of the primitive part it wraps.

### ProgressLabel

Text that names the progress bar.

Also accepts the props of the primitive part it wraps.

### ProgressValue

The formatted current value, aligned to the end of the row.

Also accepts the props of the primitive part it wraps.

The value is shown as a percentage by default.

Each part sets a `data-slot`, such as `progress-track` or `progress-indicator`, for styling.

</Only>

## Usage

<Only platform="rn">

```tsx
import * as React from "react"
import { Progress } from "@/components/ui/progress"

function ProgressDemo() {
  const [value, setValue] = React.useState(13)
  React.useEffect(() => {
    const timer = setTimeout(() => setValue(66), 500)
    return () => clearTimeout(timer)
  }, [])
  return <Progress value={value} />
}

export function ProgressExample() {
  return (
    <ProgressDemo />
  )
}
```

</Only>

<Only platform="swift">

```swift
import SwiftUI

struct ProgressDelayed: View {
  @State private var value = 13.0

  var body: some View {
    ProgressView(value: value, total: 100)
      .progressViewStyle(.bar)
      .task {
        try? await Task.sleep(for: .milliseconds(500))
        value = 66
      }
  }
}
```

</Only>

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.runtime.Composable
import androidx.compose.runtime.LaunchedEffect
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableFloatStateOf
import androidx.compose.runtime.saveable.rememberSaveable
import androidx.compose.runtime.setValue
import androidx.compose.ui.Modifier
import com.esuiss.ui.components.Progress
import kotlinx.coroutines.delay

@Composable
fun ProgressDefault() {
    var value by rememberSaveable { mutableFloatStateOf(13f) }
    LaunchedEffect(Unit) {
        delay(500)
        value = 66f
    }
    Progress(value, Modifier.fillMaxWidth())
}
```

## API Reference

<Only platform="rn">

### Progress

Root that holds the value and renders the track and indicator.

| Prop | Type | Default |
| --- | --- | --- |
| `trackClassName` | `string` | - |
| `indicatorClassName` | `string` | - |

Also accepts the props of `React.ComponentProps<typeof ProgressPrimitive.Root>`.

Set `value` between `min` and `max` (0 and 100 by default). Pass `null` when the progress is unknown. `trackClassName` and `indicatorClassName` add classes to the track and the indicator. `ProgressTrack` and `ProgressIndicator` are also exported for custom layouts.

### ProgressTrack

Background bar.

Also accepts the props of `React.ComponentProps<typeof ProgressPrimitive.Track>`.

### ProgressIndicator

Animated fill that shows the current value.

Also accepts the props of `React.ComponentProps<typeof ProgressPrimitive.Indicator>`.

### ProgressLabel

Caption text above the bar.

Also accepts the props of `React.ComponentProps<typeof ProgressPrimitive.Label>`.

### ProgressValue

Formatted value text, aligned to the end.

Also accepts the props of `React.ComponentProps<typeof ProgressPrimitive.Value>`.

Format the value with `format` and `locale`. The value uses tabular numbers.

</Only>

<Only platform="swift">

### .progressViewStyle(.bar)

Style that creates `BarProgressViewStyle`.

Takes no parameters.

</Only>
