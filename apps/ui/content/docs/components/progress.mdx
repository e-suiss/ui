Progress wraps Base UI's Progress. `Progress` is the root and always renders a `ProgressTrack` containing a `ProgressIndicator` after its children. Add a `ProgressLabel` to name the bar and a `ProgressValue` to show the formatted value; they sit on one row above the track.

Use Progress for determinate or indeterminate task progress.

## Usage

<Code lang="tsx" code={"import { Progress, ProgressTrack, ProgressIndicator, ProgressLabel, ProgressValue } from \"@/components/ui/progress\""} />

<Code lang="tsx" code={"<div className=\"w-80\">\n  <Progress value={60} aria-label=\"Upload progress\" />\n</div>"} />

Pass `value` as a number between `min` and `max` (by default `0` and `100`). Set `value={null}` for an indeterminate state when the amount of work is unknown.

The track and indicator are rendered for you, so `ProgressTrack` and `ProgressIndicator` are not needed inside `Progress` children. `ProgressValue` uses Base UI's formatting and shows a percentage by default.

## Accessibility

- The root has the `progressbar` role with `aria-valuenow` reflecting the value.
- `ProgressLabel` provides the accessible name. Without it, pass `aria-label`.
- When `value` is `null`, `aria-valuenow` is omitted to signal an indeterminate state.

## Notes

- Styling hooks: `data-slot` values `progress`, `progress-track`, `progress-indicator`, `progress-label` and `progress-value`. Base UI also sets status attributes such as `data-progressing`, `data-complete` and `data-indeterminate`.
- The track uses `surface-secondary` and the indicator uses `accent`; the indicator animates width changes.

`Progress` renders a thin track with an indicator whose width follows `value`. The width animates with a Reanimated spring, clamped between 0 and 100 percent. Any children, such as `ProgressLabel` and `ProgressValue`, are placed in a row above the bar.

Use it for uploads, downloads and other tasks with a known amount of work.

## Usage

<Code lang="tsx" code={"import { Progress, ProgressTrack, ProgressIndicator, ProgressLabel, ProgressValue } from \"@/components/ui/progress\""} />

<Code lang="tsx" code={"<ProgressDemo />"} />

Set `value` between `min` and `max` (0 and 100 by default). Pass `null` when the progress is unknown.

Add a `ProgressLabel` and a `ProgressValue` as children to show a caption and the formatted value; the value is pushed to the end of the row. Format the value with `format` and `locale`.

Style the bar with `trackClassName` and `indicatorClassName`. `ProgressTrack` and `ProgressIndicator` are also exported for custom layouts.

## Accessibility

- The root has the `progressbar` role and reports `min`, `max`, the current value and a value text, so VoiceOver and TalkBack announce the progress.
- Use `getAccessibilityValueText` to customize the announced text.

## Notes

- The track uses `bg-surface-secondary` and the indicator `bg-accent`.
- Label and value text use `text-label` and `text-label-secondary`, with tabular numbers for the value.
- Light and dark colors follow the system appearance.
