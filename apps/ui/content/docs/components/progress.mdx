Progress wraps the progress primitive of the chosen base. `Progress` is the root and always renders a `ProgressTrack` containing a `ProgressIndicator` after its children. Add a `ProgressLabel` to name the bar and a `ProgressValue` to show the formatted value; they sit on one row above the track.

Use Progress for determinate or indeterminate task progress.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/progress
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add progress
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install @base-ui/react
```

2. Copy the source into `components/ui/progress.tsx`:

<ComponentSource path="components/ui/progress.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Progress, ProgressTrack, ProgressIndicator, ProgressLabel, ProgressValue } from "@/components/ui/progress"
```

```tsx
<div className="w-80">
  <Progress value={60} aria-label="Upload progress" />
</div>
```

<OnlyBase base="base">

Pass `value` as a number between `min` and `max` (by default `0` and `100`). Set `value={null}` for an indeterminate state when the amount of work is unknown.

</OnlyBase>

<OnlyBase base="radix">

Pass `value` as a number between `0` and `max` (by default `100`). Leave `value` out, or set `value={null}`, for an indeterminate state when the amount of work is unknown.

</OnlyBase>

<OnlyBase base="aria">

Pass `value` as a number between `minValue` and `maxValue` (by default `0` and `100`). Set `isIndeterminate` for an indeterminate state when the amount of work is unknown.

</OnlyBase>

The track and indicator are rendered for you, so `ProgressTrack` and `ProgressIndicator` are not needed inside `Progress` children. `ProgressValue` shows the formatted value, a percentage by default.

## Accessibility

- The root has the `progressbar` role with `aria-valuenow` reflecting the value.
- `ProgressLabel` provides the accessible name. Without it, pass `aria-label`.

<OnlyBase base="base radix">

- When `value` is `null`, `aria-valuenow` is omitted to signal an indeterminate state.

</OnlyBase>

<OnlyBase base="aria">

- With `isIndeterminate`, `aria-valuenow` is omitted to signal an indeterminate state.

</OnlyBase>

## Notes

- Styling hooks: `data-slot` values `progress`, `progress-track`, `progress-indicator`, `progress-label` and `progress-value`.
- The track uses `muted` and the indicator uses `primary`; the indicator animates width changes.

</Only>

## Usage

<Only platform="rn">

```tsx
import * as React from "react"
import { Progress } from "@/components/ui/progress"

function ProgressDemo() {
  const [value, setValue] = React.useState(13)
  React.useEffect(() => {
    const timer = setTimeout(() => setValue(66), 500)
    return () => clearTimeout(timer)
  }, [])
  return <Progress value={value} />
}

export function ProgressExample() {
  return (
    <ProgressDemo />
  )
}
```

</Only>

<Only platform="swift">

```swift
import EsuissUI
import SwiftUI

struct ProgressDelayed: View {
  @State private var value = 13.0

  var body: some View {
    ProgressView(value: value, total: 100)
      .progressViewStyle(.bar)
      .task {
        try? await Task.sleep(for: .milliseconds(500))
        value = 66
      }
  }
}
```

</Only>

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.runtime.Composable
import androidx.compose.runtime.LaunchedEffect
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableFloatStateOf
import androidx.compose.runtime.saveable.rememberSaveable
import androidx.compose.runtime.setValue
import androidx.compose.ui.Modifier
import com.esuiss.ui.components.Progress
import kotlinx.coroutines.delay

@Composable
fun ProgressDefault() {
    var value by rememberSaveable { mutableFloatStateOf(13f) }
    LaunchedEffect(Unit) {
        delay(500)
        value = 66f
    }
    Progress(value, Modifier.fillMaxWidth())
}
```

</Only>

<Only platform="rn">

Set `value` between `min` and `max` (0 and 100 by default). Pass `null` when the progress is unknown.

Add a `ProgressLabel` and a `ProgressValue` as children to show a caption and the formatted value; the value is pushed to the end of the row. Format the value with `format` and `locale`.

Style the bar with `trackClassName` and `indicatorClassName`. `ProgressTrack` and `ProgressIndicator` are also exported for custom layouts.

</Only>

## Accessibility

- The root has the `progressbar` role and reports `min`, `max`, the current value and a value text, so VoiceOver and TalkBack announce the progress.
- Use `getAccessibilityValueText` to customize the announced text.

## Notes

- The track uses `bg-muted` and the indicator `bg-primary`.
- Label and value text use `text-foreground` and `text-muted-foreground`, with tabular numbers for the value.
- Light and dark colors follow the system appearance.

</Only>
