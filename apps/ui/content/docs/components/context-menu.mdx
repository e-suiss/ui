Context menu wraps the context menu primitive of the chosen base. The `ContextMenu` root manages the open state and `ContextMenuTrigger` defines the area that opens the menu. `ContextMenuContent` renders the menu in a portal at the pointer position. Inside it, use `ContextMenuItem` for actions, `ContextMenuCheckboxItem` for toggles, and `ContextMenuRadioGroup` with `ContextMenuRadioItem` for a single choice. Organize items with `ContextMenuGroup`, `ContextMenuLabel` and `ContextMenuSeparator`, and nest a submenu with `ContextMenuSub`, `ContextMenuSubTrigger` and `ContextMenuSubContent`. `ContextMenuShortcut` displays a keyboard shortcut at the end of an item.

Use a context menu for secondary actions on an object. Because it is hidden until a right-click or long press, make the same actions available elsewhere. For a menu opened from a visible button, use a dropdown menu.

## Composition

Use the following composition to build a `ContextMenu`:

```text
ContextMenu
├── ContextMenuTrigger
└── ContextMenuContent
    ├── ContextMenuGroup
    │   ├── ContextMenuItem
    │   │   └── ContextMenuShortcut
    │   ├── ContextMenuCheckboxItem
    │   └── ContextMenuLabel
    ├── ContextMenuSeparator
    ├── ContextMenuSub
    │   ├── ContextMenuSubTrigger
    │   └── ContextMenuSubContent
    │       └── ContextMenuItem
    ├── ContextMenuRadioGroup
    │   ├── ContextMenuLabel
    │   └── ContextMenuRadioItem
    └── ContextMenuItem
        └── ContextMenuShortcut
```

### Inset

Set `inset` on items and labels that have no icon so their text aligns with items that do, or with the indicators of checkbox and radio items. The last item uses `variant="destructive"`.

## Accessibility

- The menu has the `menu` role. Items have the `menuitem`, `menuitemcheckbox` or `menuitemradio` role, and checkbox and radio items set `aria-checked`.
- Disabled items set `aria-disabled` and cannot be chosen.
- Arrow keys move between items. On a submenu trigger, the Right Arrow opens the submenu and moves focus into it, and the Left Arrow returns to the trigger. The arrow directions follow the reading direction.
- Escape closes the menu, and choosing a regular item closes it.
- `ContextMenuShortcut` only displays a shortcut; it does not register one. It is hidden on small screens.

## API Reference

### ContextMenu

The root that manages the menu's open state.

Also accepts the props of the primitive part it wraps.

### ContextMenuPortal

Renders its children into a portal outside the current DOM hierarchy.

Also accepts the props of the primitive part it wraps.

### ContextMenuTrigger

The area that opens the menu on right-click.

Also accepts the props of the primitive part it wraps.

The trigger sets `select-none` so long-pressing does not select its text.

### ContextMenuContent

The menu panel, rendered in a portal at the pointer position.

<OnlyBase base="base">

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"inline-end"` |
| `sideOffset` | `number` | `0` |
| `align` | `"start" \| "center" \| "end"` | `"start"` |
| `alignOffset` | `number` | `4` |

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `alignOffset` | `number` | `4` |

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `placement` | `Placement` | `"bottom start"` |
| `offset` | `number` | `0` |
| `crossOffset` | `number` | `4` |

</OnlyBase>

Also accepts the props of the primitive parts it wraps.

<OnlyBase base="base">

`side` and `align` place the menu against the pointer; by default it opens on the `inline-end` side, aligned to `start`. `sideOffset` and `alignOffset` are in pixels.

</OnlyBase>

<OnlyBase base="radix">

`alignOffset` is the offset along the alignment axis, in pixels.

</OnlyBase>

<OnlyBase base="aria">

`placement` sets where the menu opens relative to the pointer. `offset` and `crossOffset` are in pixels.

</OnlyBase>

### ContextMenuGroup

Groups related items.

Also accepts the props of the primitive part it wraps.

### ContextMenuLabel

A heading for a group of items.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |

Also accepts the props of the primitive part it wraps.

### ContextMenuItem

An action in the menu.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |
| `variant` | `"default" \| "destructive"` | `"default"` |

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base radix">

Respond to an action with the item's `onClick`.

</OnlyBase>

<OnlyBase base="aria">

Respond to an action with the item's `onAction`.

</OnlyBase>

Selecting a regular item closes the menu. `inset` adds leading padding so the item aligns with items that have an icon or indicator. `variant="destructive"` colors the item and its icon with the `destructive` color; use it on items that delete or remove something. Items set `data-inset` and `data-variant`, and disabled items get `data-disabled`.

### ContextMenuSub

The root of a nested submenu.

Also accepts the props of the primitive part it wraps.

### ContextMenuSubTrigger

The item that opens a submenu, shown with a trailing caret.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base">

An open submenu trigger gets `data-popup-open`.

</OnlyBase>

<OnlyBase base="radix">

An open submenu trigger gets `data-state="open"`.

</OnlyBase>

### ContextMenuSubContent

The panel of a submenu, opened beside its trigger.

Also accepts the props of `React.ComponentProps<typeof ContextMenuContent>`.

### ContextMenuCheckboxItem

An item that toggles a setting on or off and shows a check mark when on.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `defaultChecked` | `boolean` | `false` |
| `closeOnClick` | `boolean` | `false` |

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `isSelected` | `boolean` | - |
| `defaultSelected` | `boolean` | `false` |
| `onChange` | `(isSelected: boolean) => void` | - |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base radix">

Checkbox items are uncontrolled with `defaultChecked`, or controlled with `checked` and `onCheckedChange`.

</OnlyBase>

<OnlyBase base="radix">

Set `closeOnClick` to close the menu when the item is selected.

</OnlyBase>

<OnlyBase base="aria">

Checkbox items are uncontrolled with `defaultSelected`, or controlled with `isSelected` and `onChange`.

</OnlyBase>

Checkbox and radio items keep the menu open when selected.

### ContextMenuRadioGroup

Groups radio items so that only one can be selected.

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | - |
| `defaultValue` | `string` | - |
| `onChange` | `(value: string) => void` | - |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base radix">

Radio groups take `defaultValue`, or `value` and `onValueChange`.

</OnlyBase>

<OnlyBase base="aria">

Radio groups take `defaultValue`, or `value` and `onChange`, which is called with the `value` of the newly selected item.

</OnlyBase>

### ContextMenuRadioItem

An item in a radio group that shows a check mark when selected.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `closeOnClick` | `boolean` | `false` |

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | - |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

Each radio item needs a `value`, which the group reports when it is selected.

<OnlyBase base="radix">

Set `closeOnClick` to close the menu when the item is selected.

</OnlyBase>

### ContextMenuSeparator

A divider between groups of items.

Also accepts the props of the primitive part it wraps.

### ContextMenuShortcut

Displays a keyboard shortcut at the end of an item.

| Prop | Type | Default |
| --- | --- | --- |
| `mod` | `boolean` | - |

Also accepts the props of `React.ComponentProps<"span">`.

Set `mod` to prefix the shortcut with the platform modifier key, `⌘` on Apple platforms and `Ctrl+` elsewhere.

Each part sets a `data-slot`, such as `context-menu-item` or `context-menu-sub-trigger`, for styling.

`ContextMenu` attaches a menu to a `ContextMenuTrigger` area. A long press opens `ContextMenuContent` at the position of the finger with a medium impact haptic. The content renders through a portal (inside a full-window overlay on iOS) as a raised, rounded card.

Items can be plain actions, checkbox items, radio items in a group, or a submenu. `ContextMenuSubContent` expands in place under its trigger, and the caret turns to point down while it is open.

## Usage

<Only platform="rn">

<OnlyStyling styling="uniwind nativewind">

```tsx
import * as React from "react"
import { ContextMenu, ContextMenuCheckboxItem, ContextMenuContent, ContextMenuItem, ContextMenuLabel, ContextMenuRadioGroup, ContextMenuRadioItem, ContextMenuSeparator, ContextMenuSub, ContextMenuSubContent, ContextMenuSubTrigger, ContextMenuTrigger } from "@/components/ui/context-menu"
import { Text } from "@/components/ui/text"

function TriggerArea() {
  return (
    <ContextMenuTrigger className="border-border h-36 w-full items-center justify-center rounded-md border border-dashed">
      <Text className="text-sm text-muted-foreground">Long press here</Text>
    </ContextMenuTrigger>
  )
}

function ContextMenuDemo({ defaultOpen }: { defaultOpen?: boolean }) {
  const [showBookmarks, setShowBookmarks] = React.useState(true)
  const [showUrls, setShowUrls] = React.useState(false)
  const [person, setPerson] = React.useState("pedro")
  return (
    <ContextMenu defaultOpen={defaultOpen}>
      <TriggerArea />
      <ContextMenuContent className="w-64">
        <ContextMenuItem inset>
          <Text>Back</Text>
        </ContextMenuItem>
        <ContextMenuItem inset disabled>
          <Text>Forward</Text>
        </ContextMenuItem>
        <ContextMenuItem inset>
          <Text>Reload</Text>
        </ContextMenuItem>
        <ContextMenuSub>
          <ContextMenuSubTrigger inset>
            <Text>More tools</Text>
          </ContextMenuSubTrigger>
          <ContextMenuSubContent className="w-48">
            <ContextMenuItem>
              <Text>Save page</Text>
            </ContextMenuItem>
            <ContextMenuItem>
              <Text>Create shortcut</Text>
            </ContextMenuItem>
            <ContextMenuSeparator />
            <ContextMenuItem variant="destructive">
              <Text>Delete</Text>
            </ContextMenuItem>
          </ContextMenuSubContent>
        </ContextMenuSub>
        <ContextMenuSeparator />
        <ContextMenuCheckboxItem
          checked={showBookmarks}
          onCheckedChange={setShowBookmarks}
        >
          <Text>Show bookmarks</Text>
        </ContextMenuCheckboxItem>
        <ContextMenuCheckboxItem
          checked={showUrls}
          onCheckedChange={setShowUrls}
        >
          <Text>Show full URLs</Text>
        </ContextMenuCheckboxItem>
        <ContextMenuSeparator />
        <ContextMenuRadioGroup value={person} onValueChange={setPerson}>
          <ContextMenuLabel inset>People</ContextMenuLabel>
          <ContextMenuRadioItem value="pedro">
            <Text>Pedro Duarte</Text>
          </ContextMenuRadioItem>
          <ContextMenuRadioItem value="colm">
            <Text>Colm Tuite</Text>
          </ContextMenuRadioItem>
        </ContextMenuRadioGroup>
      </ContextMenuContent>
    </ContextMenu>
  )
}

export function ContextMenuExample() {
  return (
    <ContextMenuDemo />
  )
}
```

```kotlin
@Composable
fun ContextMenuTriggerArea() {
    val color = EsuissTheme.colors.border
    Box(
        modifier = Modifier
            .fillMaxWidth()
            .height(144.dp)
            .drawBehind {
                val stroke = 1.dp.toPx()
                drawRoundRect(
                    color = color,
                    topLeft = Offset(stroke / 2, stroke / 2),
                    size = Size(size.width - stroke, size.height - stroke),
                    cornerRadius = CornerRadius(Radius.md.toPx()),
                    style = Stroke(stroke, pathEffect = PathEffect.dashPathEffect(floatArrayOf(4.dp.toPx(), 3.dp.toPx()))),
                )
            },
        contentAlignment = Alignment.Center,
    ) {
        Text("Long press here", style = Typography.sm.copy(color = EsuissTheme.colors.mutedForeground))
    }
}

@Composable
fun ContextMenuDemo(defaultOpen: Boolean) {
    var open by rememberSaveable { mutableStateOf(defaultOpen) }
    var showBookmarks by rememberSaveable { mutableStateOf(true) }
    var showUrls by rememberSaveable { mutableStateOf(false) }
    var person by rememberSaveable { mutableStateOf("pedro") }
    ContextMenu(
        expanded = open,
        onExpandedChange = { open = it },
        trigger = { ContextMenuTriggerArea() },
        modifier = Modifier.width(256.dp),

        DropdownMenuItem("Back", onClick = {}, inset = true)
        DropdownMenuItem("Forward", onClick = {}, inset = true, enabled = false)

        DropdownMenuSub("More tools", inset = true) {
            Column(Modifier.width(192.dp)) {
                DropdownMenuItem("Save page", onClick = {})

                DropdownMenuSeparator()
                DropdownMenuItem("Delete", onClick = {}, variant = MenuItemVariant.Destructive)

        }

        DropdownMenuCheckboxItem("Show full URLs", checked = showUrls, onCheckedChange = { showUrls = it })
        DropdownMenuSeparator()
        DropdownMenuRadioGroup(value = person, onValueChange = { person = it }) {
            DropdownMenuLabel("People", inset = true)
            DropdownMenuRadioItem("pedro", "Pedro Duarte")
            DropdownMenuRadioItem("colm", "Colm Tuite")
        }
    }
```

## Accessibility

- The trigger exposes a `longpress` accessibility action, so VoiceOver and TalkBack users can open the menu, and reports its `expanded` state.
- The popup has the `menu` role; items use `menuitem`, `checkbox` and `radio` roles, and radio groups use `radiogroup`.
- Separators have the `separator` role.

</Only>

## API Reference

<Only platform="rn">

### ContextMenu

The root that manages the open state.

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `(open: boolean, details) => void` | - |
| `disabled` | `boolean` | `false` |

Use `open` with `onOpenChange` for controlled state, or `defaultOpen` for uncontrolled. `disabled` prevents the menu from opening. Wrap the long-pressable area in `ContextMenuTrigger`.

### ContextMenuContent

Floating menu card.

| Prop | Type | Default |
| --- | --- | --- |
| `portalHost` | `string` | - |

Also accepts the props of `React.ComponentProps<typeof ContextMenuPrimitive.Popup>`, `PositionerProps`.

`portalHost` names the portal host to render into. The fade-in respects the system Reduce Motion setting.

### ContextMenuSubTrigger

Row that expands the submenu.

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `React.ReactNode` | - |
| `iconClassName` | `string` | - |
| `inset` | `boolean` | - |

Also accepts the props of `React.ComponentProps<typeof ContextMenuPrimitive.SubmenuTrigger>`.

`iconClassName` adds classes to the caret icon.

### ContextMenuSubContent

Items of the submenu.

Also accepts the props of `React.ComponentProps<typeof ContextMenuPrimitive.Popup>`.

### ContextMenuItem

Action row.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |
| `variant` | `"default" \| "destructive"` | `"default"` |

Also accepts the props of `React.ComponentProps<typeof ContextMenuPrimitive.Item>`.

Items close the menu when pressed unless `closeOnPress={false}`. Set `variant="destructive"` on an item that deletes or removes. `inset` adds start padding to align an item without an icon with items that have one; the sub trigger, checkbox, radio and label parts take it too. A highlighted item fades to `opacity-80` and a disabled one to `opacity-50`.

### ContextMenuCheckboxItem

Row with a check mark that toggles.

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `React.ReactNode` | - |
| `inset` | `boolean` | - |

Also accepts the props of `React.ComponentProps<typeof ContextMenuPrimitive.CheckboxItem>`.

Control it with `checked` and `onCheckedChange`.

### ContextMenuRadioItem

Row that selects one value in its group.

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `React.ReactNode` | - |
| `inset` | `boolean` | - |

Also accepts the props of `React.ComponentProps<typeof ContextMenuPrimitive.RadioItem>`.

Place radio items inside a `ContextMenuRadioGroup` with `value` and `onValueChange`.

### ContextMenuLabel

Heading for a group.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |

Also accepts the props of `React.ComponentProps<typeof ContextMenuPrimitive.GroupLabel>`.

Group items with `ContextMenuGroup` and a `ContextMenuLabel`.

### ContextMenuSeparator

Line between sections.

Also accepts the props of `React.ComponentProps<typeof ContextMenuPrimitive.Separator>`.
