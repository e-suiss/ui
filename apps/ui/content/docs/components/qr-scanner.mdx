`QRScanner` is a `View` that draws an overlay on top of whatever you pass as `children`, usually a camera preview. It does not open the camera itself. The overlay dims everything outside a square frame with rounded corners (drawn with `react-native-svg`) and marks the frame with four rounded corner brackets. When `scanLine` is set, a line moves up and down inside the frame with Reanimated while the state is `idle`.

The frame size defaults to 66% of the shorter side, capped at 260 points. It is centered horizontally and sits slightly above the vertical center. A `title` sits above the frame and a `description` below it; the flashlight button sits near the bottom edge.

## Usage

```tsx
import { QRScanner } from "@/components/ui/qr-scanner"
```

```tsx
<Scanner description="Point your camera at a code to pay or connect." />
```

Render your camera view as `children` and size the scanner with `className`. When there are no children, the background falls back to `bg-black`.

Set `state` to `success` or `error` after you read a code. The brackets fade to a matching color, `success` springs the frame slightly smaller and `error` shakes it. Pass `onTorchToggle` together with a controlled `torch` value to show the flashlight button; leave it out to hide the button. `title` and `description` accept strings or your own elements.

The `QRScannerState` type is also exported.

## API Reference

<ApiPart index={1}>

### QRScanner

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `state` | `QRScannerState` | `"idle"` | `idle`, `success` or `error`. Sets the bracket color and triggers haptics, the success scale and the error shake. Defaults to `idle`. |
| `title` | `React.ReactNode` | - | Content shown above the frame. Strings are wrapped in a `Text`. |
| `description` | `React.ReactNode` | - | Content shown below the frame. Strings are wrapped in a `Text`. |
| `scanLine` | `boolean` | `false` | Shows the animated scan line while the state is `idle`. Defaults to `false`. |
| `torch` | `boolean` | `false` | Whether the flashlight is on. The button fills and the icon uses the fill weight when on. Defaults to `false`. |
| `onTorchToggle` | `(torch: boolean) => void` | - | Called with the next torch value when the flashlight button is pressed. The button is shown only when this is set. |
| `torchLabel` | `string` | `"Flashlight"` | Accessibility label for the flashlight button. Defaults to `"Flashlight"`. |
| `frameSize` | `number` | - | Side length of the scan frame in points. Overrides the automatic size. |

Also accepts the props of `React.ComponentProps<typeof View>`.

</ApiPart>

## Accessibility

- The dimmed surround and brackets are hidden from VoiceOver and TalkBack.
- The overlay is a polite live region, so changes to the title and description are announced on Android.
- The flashlight button has the `button` role, uses `torchLabel` as its label and reports `torch` as its selected state.
- State changes to `success` and `error` play a matching haptic notification when a haptics adapter is provided through `HapticsContext`.
- The shake and scan-line animations respect the system reduce motion setting, and the success scale is skipped when reduce motion is on.

## Notes

- Uses the `bg-black`, `text-black/50`, `text-white`, `text-green-600 dark:text-green-400`, `text-destructive` and `bg-primary` tokens; the flashlight button uses `bg-black/50` when off and `bg-white` with a `text-black` icon when on.
- The scan line restarts whenever the state returns to `idle`.
