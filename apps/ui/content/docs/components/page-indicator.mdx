<Only platform="rn">

`PageIndicator` draws one dot per page and widens the active one into a pill. Width and position changes animate with Reanimated. When `count` exceeds `maxVisible`, only a window of dots is shown; the window slides to keep the active dot near the center and the dots at its edges shrink to hint that more pages exist.

</Only>

It comes in two sizes, `default` and `sm`, and two variants: `default` uses the foreground color for the active dot and `accent` uses the primary color.

## Accessibility

- The indicator is a single element with the `adjustable` role, and the dots are not focusable on their own.
- Its value is announced as "2 of 5".
- When `onIndexChange` is set, VoiceOver and TalkBack users swipe up or down to move to the next or previous page.
- Animations respect the system reduce motion setting.

</Only>

## API Reference

<Only platform="rn">

### PageIndicator

The `PageIndicator` component shows the current page as a row of dots.

| Prop | Type | Default |
| --- | --- | --- |
| `count` | `number` | Required |
| `index` | `number` | Required |
| `onIndexChange` | `(index: number) => void` | - |
| `size` | `PageIndicatorSize` | `"default"` |
| `variant` | `PageIndicatorVariant` | `"default"` |
| `maxVisible` | `number` | `7` |

Also accepts the props of `ViewProps`.

The component is controlled: pass `count` and the zero-based `index` of the current page. Nothing renders when `count` is `0`. `onIndexChange` is called with the new index when a dot is pressed or an accessibility action is used; without it the indicator is display-only. `maxVisible` is the most dots shown at once, with a minimum of `3`. The `PageIndicatorSize` and `PageIndicatorVariant` types are also exported.

</Only>
