`PageIndicator` draws one dot per page and widens the active one into a pill. Width and position changes animate with Reanimated. When `count` exceeds `maxVisible`, only a window of dots is shown; the window slides to keep the active dot near the center and the dots at its edges shrink to hint that more pages exist.

It comes in two sizes, `default` and `sm`, and two variants: `default` uses the foreground color for the active dot and `accent` uses the primary color.

## Usage

```tsx
import { PageIndicator } from "@/components/ui/page-indicator"
```

```tsx
<PageIndicator count={5} index={1} />
```

The component is controlled: pass `count` and the current `index`. Pass `onIndexChange` to make the dots pressable; without it the indicator is display-only. Pressing a dot plays a selection haptic.

The `PageIndicatorSize` and `PageIndicatorVariant` types are also exported.

## API Reference

<ApiPart index={1}>

### PageIndicator

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `count` | `number` | Required | Total number of pages. Nothing renders when it is `0`. |
| `index` | `number` | Required | Zero-based index of the current page. |
| `onIndexChange` | `(index: number) => void` | - | Called with the new index when a dot is pressed or an accessibility action is used. |
| `size` | `PageIndicatorSize` | `"default"` | Dot size: `default` or `sm`. |
| `variant` | `PageIndicatorVariant` | `"default"` | Active dot color: `default` or `accent`. |
| `maxVisible` | `number` | `7` | Most dots shown at once. Defaults to `7`, minimum `3`. |

Also accepts the props of `ViewProps`.

</ApiPart>

## Accessibility

- The indicator is a single element with the `adjustable` role, and the dots are not focusable on their own.
- Its value is announced as "2 of 5".
- When `onIndexChange` is set, VoiceOver and TalkBack users swipe up or down to move to the next or previous page.
- Animations respect the system reduce motion setting.

## Notes

- Uses `bg-foreground` or `bg-primary` for the active dot and `bg-border` for the others; colors follow the system appearance.
