`SidebarProvider` holds the open state and wraps the whole layout. Inside it, `Sidebar` renders the panel and `SidebarInset` renders the main content beside it. The sidebar stacks `SidebarHeader`, a scrolling `SidebarContent` and `SidebarFooter`. Content is organized into `SidebarGroup` sections, each with a `SidebarGroupLabel`, an optional `SidebarGroupAction` and a `SidebarGroupContent`. Navigation lives in a `SidebarMenu` of `SidebarMenuItem` rows, each holding a `SidebarMenuButton` and optionally a `SidebarMenuAction`, `SidebarMenuBadge` or nested `SidebarMenuSub`.

`SidebarTrigger` and `SidebarRail` toggle the sidebar. On screens narrower than `48rem`, the sidebar renders inside a `Sheet` instead. Use `Sidebar` for the main navigation of an app; for bottom navigation on small screens, consider `TabBar`.

## Usage

```tsx
import {
  Sidebar,
  SidebarContent,
  SidebarGroup,
  SidebarGroupContent,
  SidebarGroupLabel,
  SidebarHeader,
  SidebarInset,
  SidebarMenu,
  SidebarMenuButton,
  SidebarMenuItem,
  SidebarProvider,
  SidebarRail,
  SidebarTrigger,
} from "@/components/ui/sidebar"
```

```tsx
<SidebarProvider>
  <Sidebar side="left" variant="sidebar" collapsible="icon">
    <SidebarHeader>Acme Inc.</SidebarHeader>
    <SidebarContent>
      <SidebarGroup>
        <SidebarGroupLabel>Platform</SidebarGroupLabel>
        <SidebarGroupContent>
          <SidebarMenu>
            {items.map((item) => (
              <SidebarMenuItem key={item.title}>
                <SidebarMenuButton isActive={item.active} tooltip={item.title}>
                  {item.icon}
                  <span>{item.title}</span>
                </SidebarMenuButton>
              </SidebarMenuItem>
            ))}
          </SidebarMenu>
        </SidebarGroupContent>
      </SidebarGroup>
    </SidebarContent>
    <SidebarRail />
  </Sidebar>
  <SidebarInset>
    <header className="flex h-14 items-center gap-2 border-b px-4">
      <SidebarTrigger />
    </header>
    <main className="p-4">{children}</main>
  </SidebarInset>
</SidebarProvider>
```

## Accessibility

- `SidebarTrigger` and `SidebarRail` are labelled `Toggle Sidebar`. The rail is removed from the tab order, so keep a `SidebarTrigger` in reach of keyboard users.
- Press `Command-B` on Apple platforms, or `Ctrl+B` elsewhere, to toggle the sidebar.
- On mobile, the sidebar is a dialog with a visually hidden title, `Sidebar`; `Escape` closes it.
- Menu-button tooltips appear only while the sidebar is collapsed, so labels stay available when only icons show.

## API Reference

### SidebarProvider

Holds the open state, provides it through context and wraps the layout.

| Prop | Type | Default |
| --- | --- | --- |
| `defaultOpen` | `boolean` | `true` |
| `open` | `boolean` | - |
| `onOpenChange` | `(open: boolean) => void` | - |

Also accepts the props of `React.ComponentProps<"div">`.

Use `defaultOpen` for an uncontrolled sidebar, or `open` with `onOpenChange` to control it. Every toggle writes the state to a `sidebar_state` cookie for 7 days; read it on the server to set `defaultOpen` and avoid a flash on load. Widths come from `--sidebar-width` (`16rem`) and `--sidebar-width-icon` (`3rem`), set on `SidebarProvider`; override them through its `style`.

Read and change the state from any child with the `useSidebar` hook, which returns `state`, `open`, `setOpen`, `openMobile`, `setOpenMobile`, `isMobile` and `toggleSidebar`. It throws when used outside a `SidebarProvider`.

### Sidebar

The sidebar panel; a sheet on mobile.

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"left" \| "right"` | `"left"` |
| `variant` | `"sidebar" \| "floating" \| "inset"` | `"sidebar"` |
| `collapsible` | `"offcanvas" \| "icon" \| "none"` | `"offcanvas"` |

Also accepts the props of `React.ComponentProps<"div">`.

`variant` chooses a full-height `sidebar`, a rounded `floating` panel or an `inset` layout. Set `collapsible="icon"` to shrink the sidebar to a rail of icons when collapsed, `offcanvas` to slide it out of view, or `none` to keep it fixed. On screens narrower than `48rem` the sidebar renders inside a `Sheet`. The sidebar element sets `data-state` (`expanded` or `collapsed`), `data-collapsible`, `data-variant` and `data-side` for styling. The panel uses the `sidebar-*` color variables; change them to style it apart from the page.

### SidebarMenuButton

The clickable row for a destination or command.

| Prop | Type | Default |
| --- | --- | --- |
| `isActive` | `boolean` | `false` |
| `tooltip` | `string \| React.ComponentProps<typeof TooltipContent>` | - |
| `variant` | `"default" \| "outline"` | `"default"` |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` |
