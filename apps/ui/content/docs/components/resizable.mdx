Resizable wraps react-resizable-panels. `ResizablePanelGroup` lays out its children in a row or column, alternating `ResizablePanel` and `ResizableHandle`. Drag a handle, or focus it and use the keyboard, to change the size of the panels on either side. Groups can be nested to build multi-pane layouts such as an editor with a sidebar and a terminal.

The `cards` variant renders each panel as a rounded card with a pill-shaped grip between them. Use Resizable for user-adjustable layouts; use Sidebar for a standard collapsible app navigation.

## Usage

```tsx
import { ResizableHandle, ResizablePanel, ResizablePanelGroup } from "@/components/ui/resizable"
```

```tsx
<ResizablePanelGroup orientation="horizontal">
  <ResizablePanel defaultSize="50%">
    <div className="flex h-full items-center justify-center p-6">Inbox</div>
  </ResizablePanel>
  <ResizableHandle />
  <ResizablePanel defaultSize="50%">
    <div className="flex h-full items-center justify-center p-6">Message</div>
  </ResizablePanel>
</ResizablePanelGroup>
```

## Composition

Use the following composition to build a `ResizablePanelGroup`:

```text
ResizablePanelGroup
├── ResizablePanel
└── ResizableHandle
```

## Accessibility

- Each handle has the `separator` role with `aria-valuenow` and `aria-orientation`, and is focusable with Tab.
- Arrow keys resize the adjacent panels; Home and End move the handle to its minimum and maximum.
- A panel that collapses to zero width or height becomes `inert`, so its content leaves the tab order.

## API Reference

### ResizablePanelGroup

The container that arranges panels and handles and tracks the layout.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "cards"` | `"default"` |

Also accepts the props of `GroupProps` from `react-resizable-panels`.

Set `orientation` to `horizontal` (default) or `vertical`. `variant` is `default` for flat panels with thin dividers, or `cards` for rounded panels with pill grips. Use `onLayoutChange` to read the current sizes, keyed by each panel's `id`. Large layout jumps, such as collapsing or expanding a panel, animate unless the user prefers reduced motion.

### ResizablePanel

One resizable section of the layout.

Also accepts the props of `PanelProps` from `react-resizable-panels`.

Size panels with `defaultSize`, `minSize` and `maxSize`, for example `"30%"`. Make a panel `collapsible` with a `collapsedSize` to let it collapse when dragged past its minimum. Collapsed panels expose `data-empty`.

### ResizableHandle

The draggable divider between two panels.

| Prop | Type | Default |
| --- | --- | --- |
| `withHandle` | `boolean` | - |

Also accepts the props of `SeparatorProps` from `react-resizable-panels`.

`withHandle` shows a visible grip on the divider. A handle next to a collapsed panel gets `data-collapsed` set to `start` or `end`, and its grip appears on hover.

Each part sets a `data-slot`, such as `resizable-panel-group`, for styling. The group also exposes `data-variant`.
