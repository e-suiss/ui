Resizable wraps react-resizable-panels. `ResizablePanelGroup` lays out its children in a row or column, alternating `ResizablePanel` and `ResizableHandle`. Drag a handle, or focus it and use the keyboard, to change the size of the panels on either side. Groups can be nested to build multi-pane layouts such as an editor with a sidebar and a terminal.

The `cards` variant renders each panel as a rounded card with a pill-shaped grip between them. Use Resizable for user-adjustable layouts; use Sidebar for a standard collapsible app navigation.

## Usage

<Code lang="tsx" code={"import { ResizablePanelGroup, ResizablePanel, ResizableHandle } from \"@/components/ui/resizable\""} />

<Code lang="tsx" code={"<ResizablePanelGroup orientation=\"horizontal\">\n  <ResizablePanel defaultSize=\"50%\">\n    <Pane label=\"Inbox\" />\n  </ResizablePanel>\n  <ResizableHandle />\n  <ResizablePanel defaultSize=\"50%\">\n    <Pane label=\"Message\" />\n  </ResizablePanel>\n</ResizablePanelGroup>"} />

Set `orientation` on the group to `horizontal` (default) or `vertical`. Size panels with `defaultSize`, `minSize` and `maxSize`, for example `"30%"`. Make a panel `collapsible` with a `collapsedSize` to let it collapse when dragged past its minimum.

Use `onLayoutChange` on the group to read the current sizes, keyed by each panel's `id`.

## Accessibility

- Each handle has the `separator` role with `aria-valuenow` and `aria-orientation`, and is focusable with Tab.
- Arrow keys resize the adjacent panels; Home and End move the handle to its minimum and maximum.
- A panel that collapses to zero width or height becomes `inert`, so its content leaves the tab order.

## Notes

- Styling hooks: `data-slot` values `resizable-panel-group`, `resizable-panel` and `resizable-handle`. The group exposes `data-variant`, and collapsed panels expose `data-empty`.
- A handle next to a collapsed panel gets `data-collapsed` set to `start` or `end`, and its grip appears on hover.
- Large layout jumps, such as collapsing or expanding a panel, animate unless the user prefers reduced motion.
- Uses the `separator`, `surface-secondary`, `label-quaternary` and `label-secondary` tokens.
