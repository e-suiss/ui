Resizable wraps react-resizable-panels. `ResizablePanelGroup` lays out its children in a row or column, alternating `ResizablePanel` and `ResizableHandle`. Drag a handle, or focus it and use the keyboard, to change the size of the panels on either side. Groups can be nested to build multi-pane layouts such as an editor with a sidebar and a terminal.

The `cards` variant renders each panel as a rounded card with a pill-shaped grip between them. Use Resizable for user-adjustable layouts; use Sidebar for a standard collapsible app navigation.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/resizable
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add resizable
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install react-resizable-panels
```

2. Copy the source into `components/ui/resizable.tsx`:

<ComponentSource path="components/ui/resizable.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { ResizablePanelGroup, ResizablePanel, ResizableHandle } from "@/components/ui/resizable"
```

```tsx
<ResizablePanelGroup orientation="horizontal">
  <ResizablePanel defaultSize="50%">
    <Pane label="Inbox" />
  </ResizablePanel>
  <ResizableHandle />
  <ResizablePanel defaultSize="50%">
    <Pane label="Message" />
  </ResizablePanel>
</ResizablePanelGroup>
```

Set `orientation` on the group to `horizontal` (default) or `vertical`. Size panels with `defaultSize`, `minSize` and `maxSize`, for example `"30%"`. Make a panel `collapsible` with a `collapsedSize` to let it collapse when dragged past its minimum.

Use `onLayoutChange` on the group to read the current sizes, keyed by each panel's `id`.

### ResizablePanelGroup

The container that arranges panels and handles and tracks the layout.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "cards"` | `"default"` | Sets the visual style: `default` for flat panels with thin dividers, or `cards` for rounded panels with pill grips. |

Also accepts the props of `ResizablePrimitive.GroupProps`.

</ApiPart>

<ApiPart index={2}>

### ResizablePanel

One resizable section of the layout.

Also accepts the props of `ResizablePrimitive.PanelProps`.

</ApiPart>

<ApiPart index={3}>

### ResizableHandle

The draggable divider between two panels.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `withHandle` | `boolean` | - | Shows a visible grip on the divider. |

Also accepts the props of `ResizablePrimitive.SeparatorProps`.

</ApiPart>

## Accessibility

- Each handle has the `separator` role with `aria-valuenow` and `aria-orientation`, and is focusable with Tab.
- Arrow keys resize the adjacent panels; Home and End move the handle to its minimum and maximum.
- A panel that collapses to zero width or height becomes `inert`, so its content leaves the tab order.

## Notes

- Styling hooks: `data-slot` values `resizable-panel-group`, `resizable-panel` and `resizable-handle`. The group exposes `data-variant`, and collapsed panels expose `data-empty`.
- A handle next to a collapsed panel gets `data-collapsed` set to `start` or `end`, and its grip appears on hover.
- Large layout jumps, such as collapsing or expanding a panel, animate unless the user prefers reduced motion.
- Uses the `border`, `muted` and `muted-foreground` colors.
