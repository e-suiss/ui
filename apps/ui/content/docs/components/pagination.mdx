Pagination is a set of link primitives you compose around your own page state. `Pagination` is the `nav` landmark. Inside it, `PaginationContent` is a list of `PaginationItem` entries, each holding a `PaginationLink`, `PaginationPrevious`, `PaginationNext`, `PaginationFirst`, `PaginationLast` or `PaginationEllipsis`.

For compact toolbars, `PaginationGroup` joins arrow links into one segmented control, `PaginationInput` lets the user type a page number, and `PaginationSummary` shows a range such as `6–10 / 62`. The component does not calculate page ranges; you decide which links to render.

## Usage

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationEllipsis,
  PaginationFirst,
  PaginationGroup,
  PaginationInput,
  PaginationItem,
  PaginationLast,
  PaginationLink,
  PaginationNext,
  PaginationPrevious,
  PaginationSummary,
} from "@/components/ui/pagination"
```

```tsx
<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href="/orders?page=1" />
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="/orders?page=1">1</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="/orders?page=2" isActive>
        2
      </PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="/orders?page=3">3</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationEllipsis />
    </PaginationItem>
    <PaginationItem>
      <PaginationNext href="/orders?page=3" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

## Composition

Use the following composition to build a `Pagination`:

```text
Pagination
├── PaginationContent
│   └── PaginationItem
│       ├── PaginationPrevious
│       ├── PaginationLink
│       ├── PaginationEllipsis
│       └── PaginationNext
├── PaginationSummary
├── PaginationInput
└── PaginationGroup
    ├── PaginationFirst
    ├── PaginationPrevious
    ├── PaginationNext
    └── PaginationLast
```

## Accessibility

- `Pagination` renders a `nav` with `aria-label="pagination"`.
- The active `PaginationLink` gets `aria-current="page"`.
- Arrow links have built-in accessible names: `Go to previous page`, `Go to next page`, `Go to first page` and `Go to last page`. Custom `text` on previous or next replaces the name.
- The `PaginationEllipsis` icon is hidden from assistive technology, and its visually hidden text, `More pages`, is read instead.
- `PaginationGroup` has `role="group"`.
- `PaginationInput` has no built-in label; associate one with `htmlFor` or `aria-label`.

## API Reference

### Pagination

The `nav` landmark that contains the pagination controls.

Also accepts the props of `React.ComponentProps<"nav">`.

### PaginationContent

The list that holds the pagination items.

Also accepts the props of `React.ComponentProps<"ul">`.

### PaginationItem

A list item wrapper for one link or ellipsis.

Also accepts the props of `React.ComponentProps<"li">`.

### PaginationLink

A page link styled as a button, highlighted when active.

| Prop | Type | Default |
| --- | --- | --- |
| `isActive` | `boolean` | - |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "xl" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg" \| "icon-xl"` | `"icon-sm"` |

Also accepts the props of `React.ComponentProps<"a">`.

Links render as `a` elements, so pass `href` for real routes, or `href="#"` with an `onClick` that calls `preventDefault()` for client-side state. `isActive` marks the current page with `aria-current="page"` and the `secondary` button variant; other links use `ghost`. `size` takes a Button size. To disable a link, set `aria-disabled` on it; it becomes non-interactive and dimmed.

### PaginationPrevious

A link to the previous page with a leading caret.

| Prop | Type | Default |
| --- | --- | --- |
| `text` | `string` | `"Previous"` |
| `isActive` | `boolean` | - |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "xl" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg" \| "icon-xl"` | `"sm"` |

Also accepts the props of `React.ComponentProps<typeof PaginationLink>`.

A custom `text` also becomes the accessible name. An empty string renders an icon-only link, and `size` then defaults to `"icon-sm"`. The text is hidden below the `sm` breakpoint, and the caret flips in right-to-left layouts.

### PaginationNext

A link to the next page with a trailing caret.

| Prop | Type | Default |
| --- | --- | --- |
| `text` | `string` | `"Next"` |
| `isActive` | `boolean` | - |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "xl" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg" \| "icon-xl"` | `"sm"` |

Also accepts the props of `React.ComponentProps<typeof PaginationLink>`.

Works like `PaginationPrevious`, with a trailing caret.

### PaginationFirst

An icon link to the first page.

| Prop | Type | Default |
| --- | --- | --- |
| `isActive` | `boolean` | - |

Also accepts the props of `React.ComponentProps<typeof PaginationLink>`.

### PaginationLast

An icon link to the last page.

| Prop | Type | Default |
| --- | --- | --- |
| `isActive` | `boolean` | - |

Also accepts the props of `React.ComponentProps<typeof PaginationLink>`.

### PaginationEllipsis

A placeholder that indicates skipped pages.

Also accepts the props of `React.ComponentProps<"span">`.

### PaginationSummary

Secondary text that summarizes the current range.

Also accepts the props of `React.ComponentProps<"p">`.

### PaginationGroup

Joins several links into one segmented control.

Also accepts the props of `React.ComponentProps<"div">`.

### PaginationInput

A numeric text field for jumping to a page.

Also accepts the props of `React.ComponentProps<"input">`.

`PaginationInput` uses `inputMode="numeric"` to show a number keypad on touch devices.

Each part sets a `data-slot`, such as `pagination-link` or `pagination-input`, for styling. Active links set `data-active`.
