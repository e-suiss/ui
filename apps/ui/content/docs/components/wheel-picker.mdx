`WheelPicker` is the frame: it draws the highlighted selection band across the middle and lays out one or more `WheelPickerColumn` wheels side by side. Each column is a scrolling list of `WheelPickerItem` options that snap to the center, and rows curve away and fade as they move from the middle.

A column selects the item that comes to rest in the center after scrolling, or the item that's clicked. Use a wheel picker for touch-friendly choices from ordered lists, especially several related columns such as day, hour and minute. For a compact dropdown, use `Select`.

## Usage

```tsx
import { WheelPicker, WheelPickerColumn, WheelPickerItem } from "@/components/ui/wheel-picker"
```

```tsx
<div className="w-80 rounded-2xl bg-card p-4 shadow-md ring-1 ring-foreground/5 dark:ring-foreground/10">
  <WheelPicker>
    <WheelPickerColumn aria-label="Fruit" defaultValue="Lemon">
      {fruits.map((fruit) => (
        <WheelPickerItem key={fruit} value={fruit}>
          {fruit}
        </WheelPickerItem>
      ))}
    </WheelPickerColumn>
  </WheelPicker>
</div>
```

Each column manages its own value. Use `defaultValue` on `WheelPickerColumn` for an uncontrolled column, or `value` with `onValueChange` to control it. Give every `WheelPickerItem` a unique string `value`; its children are the visible label.

Set `disabled` on items that can't be chosen. Scrolling skips past them to the nearest enabled item, and the keyboard steps over them.

### WheelPickerColumn

A scrolling, snapping wheel that holds one selected value.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | The selected value, for controlled use. |
| `defaultValue` | `string` | - | The initial value when uncontrolled. |

<ApiPart index={3}>

### WheelPickerItem

A single option in a column.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | The string value this item selects; it must be unique in its column. |
| `disabled` | `boolean` | `false` | Prevents the item from being selected. |

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

## Accessibility

- Each column has the `listbox` role and is focusable; name it with `aria-label`. Items are `option` elements with `aria-selected`, and the column points to the selected item with `aria-activedescendant`.
- With a column focused, the up and down arrow keys move to the previous or next enabled item, `Page Up` and `Page Down` move by five, and `Home` and `End` jump to the first and last enabled items.
- Disabled items set `aria-disabled` and ignore clicks.
- When reduced motion is preferred, the column scrolls to new values without smooth scrolling.

## Notes

- Row height comes from `--wheel-picker-item-height` (`--spacing(8)` by default), set on `WheelPicker`; the column shows about seven rows.
- The curve is driven by scroll-driven animations where `ViewTimeline` is supported, and by a scroll handler elsewhere.
- Parts carry `data-slot` attributes: `wheel-picker`, `wheel-picker-column` and `wheel-picker-item`. Items set `data-value`, `data-selected` and `data-disabled`.
- The selection band uses `bg-secondary`.

Use it for times, dates and other values picked from a short, ordered list, often in a sheet or popover.

## Usage

```tsx
import { WheelPicker, WheelPickerColumn, WheelPickerItem } from "@/components/ui/wheel-picker"
```

```tsx
<View className="w-80 rounded-2xl border border-foreground/5 bg-card p-4 shadow-md dark:border-foreground/10">
  <WheelPicker>
    <WheelPickerColumn accessibilityLabel="Fruit" defaultValue="Lemon">
      {fruits.map((fruit) => (
        <WheelPickerItem key={fruit} value={fruit}>
          {fruit}
        </WheelPickerItem>
      ))}
    </WheelPickerColumn>
  </WheelPicker>
</View>
```

Give each column a `defaultValue`, or `value` with `onValueChange`, and fill it with `WheelPickerItem` components that each have a unique `value`. Plain string or number children are wrapped in single-line `Text`.

The value is set when scrolling settles or when an item is pressed. Disabled items are skipped: if the wheel stops on one, it moves to the nearest enabled item.

Combine several columns for compound values such as day, hour and minute, and use `className` on columns and items to control width and alignment. Set `itemHeight` on `WheelPicker` to change the row height.

## Accessibility

- Each column has the `adjustable` role and announces the selected item's label as its value.
- VoiceOver and TalkBack users swipe up or down to move to the next or previous enabled item.
- Give each column an `accessibilityLabel`, such as `Hour` or `Minute`.
- The highlight band is hidden from screen readers.

## Notes

- A selection haptic plays when the value changes, if a haptics adapter is provided through the haptics context.
- The highlight uses `bg-secondary`; items use `text-xl text-foreground` with tabular numbers and `text-muted-foreground` when disabled.
- Light and dark colors follow the system appearance.
