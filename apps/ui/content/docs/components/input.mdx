`Input` renders a native `input` element with a filled control style. It supports every native input `type`, including `email`, `password`, `number`, `search` and `file`, and adds a `size` prop for three heights.

Use it for short, free-form values. For multi-line text use a textarea, for icons, buttons or text attached to the field use `InputGroup`, and for one-time codes use `InputOTP`.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/input
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add input
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install @base-ui/react
```

2. Copy the source into `components/ui/input.tsx`:

<ComponentSource path="components/ui/input.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Input } from "@/components/ui/input"
```

```tsx
<div className="w-80">
  <Input type="text" placeholder="Enter your name" />
</div>
```

Use `defaultValue` for an uncontrolled field, or `value` with `onChange` to control it. Give every input a visible label, for example with `FieldLabel` inside a `Field`, or set `aria-label` when a visible label is not possible. Choose a `size` that matches neighboring controls such as a `Button`.

## API Reference

<ApiPart index={1}>

### Input

The text field.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "md" \| "default"` | `"default"` | Sets the height and text size: `default` is the tallest, `md` is medium and `sm` is the most compact with a smaller radius. |

Also accepts the props of `React.ComponentProps<"input">`.

</ApiPart>

## Accessibility

- Renders a native `input`, so the role follows its `type`: `textbox` by default, `spinbutton` for `number` and `searchbox` for `search`.
- Needs an accessible name from an associated label or `aria-label`.
- Set `aria-invalid` to communicate a validation error.
- A disabled input cannot be focused or edited.

## Notes

- Styling hooks: `data-slot="input"` and `data-size`.
- Uses the `secondary`, `primary` (caret), `muted-foreground` (placeholder) and `destructive` colors, and `opacity-50` when disabled.
- The native `size` attribute is replaced by the `size` prop.

</Only>

<Only platform="rn">

`Input` wraps a `TextInput` through the field control primitive. It tracks its own focused, filled, invalid and disabled state and styles itself from that state: a focus border while editing, a destructive border and tint when invalid, and 50% opacity when disabled.

</Only>

It comes in three sizes: `default` (44 pt), `md` and `sm`. Use the default size for forms on a full screen, and the smaller sizes inside dense layouts such as toolbars or sheets.

## Usage

<Only platform="rn">

```tsx
import { Input } from "@/components/ui/input"
```

```tsx
<Input placeholder="Email" />
```

</Only>

<Only platform="swift">

```swift
import SwiftUI

struct InputExample: View {
  var body: some View {
    InputDemo(placeholder: "Email")
  }
}

struct InputDemo: View {
  let placeholder: LocalizedStringKey
  var size: InputStyle.Size = .default

  @State private var text: String

  init(placeholder: LocalizedStringKey, size: InputStyle.Size = .default, initial: String = "") {
    self.placeholder = placeholder
    self.size = size
    _text = State(initialValue: initial)
  }

  var body: some View {
    TextField(placeholder, text: $text)
      .textFieldStyle(.input(size: size))
  }
}
```

</Only>

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.saveable.rememberSaveable
import androidx.compose.runtime.setValue
import androidx.compose.ui.Modifier
import com.esuiss.ui.components.Input

@Composable
fun InputExample() {
    InputSingle(initial = "", placeholder = "Email")
}

@Composable
fun InputSingle(initial: String, placeholder: String, enabled: Boolean = true) {
    var value by rememberSaveable { mutableStateOf(initial) }
    Input(value, { value = it }, Modifier.fillMaxWidth(), enabled = enabled, placeholder = placeholder)
}
```

</Only>

<Only platform="rn">

Pass any `TextInput` prop, such as `placeholder`, `secureTextEntry`, `keyboardType` or `inputMode`, to get the matching field type.

The value works controlled with `value` and `onValueChange(value, details)`, or uncontrolled with `defaultValue`. Inside a `Field`, the input picks up the field's label, description, invalid and disabled state, so you usually set `invalid` on the `Field` instead of on the input.

`className` can be a function that receives the state (`focused`, `invalid`, `disabled`, `filled`, …) and returns classes.

</Only>

## Accessibility

- Inside a `Field`, the input is linked to the field label through `accessibilityLabelledBy` and gets the label as `accessibilityLabel` and the description as `accessibilityHint`.
- `disabled` is set in `accessibilityState` and makes the input non-editable.
- Outside a `Field`, give the input an `accessibilityLabel`; a placeholder alone is not a label.

## Notes

- Uses the `bg-secondary`, `border-ring` and `border-destructive` tokens, with `opacity-50` when disabled.
- In Uniwind and NativeWind, a focused field also draws the `ring-3 ring-ring/50` focus ring.
- Placeholder, cursor and selection colors come from the `muted-foreground` and `primary` tokens.
- Light and dark colors follow the system appearance.
