A `ButtonGroup` lays out its children in a row or column and joins them visually: only the outer corners stay rounded, and borders between neighbors collapse. Use `ButtonGroupSeparator` to draw a divider between filled buttons, and `ButtonGroupText` to add a static label or prefix such as `https://`.

Groups can contain buttons, `Input`, `InputGroup`, `Select` triggers, and the triggers of dropdown menus and popovers. Nest `ButtonGroup` parts to create clusters with a gap between them. Use a button group for closely related actions, split buttons, or input-and-button combinations; for a set of toggleable options, use Toggle Group instead.

```text
ButtonGroup
├── ButtonGroupSeparator
└── ButtonGroupText
```

## Accessibility

- `ButtonGroup` renders with `role="group"`; add an `aria-label` to name it.
- Each button, input and trigger remains a separate tab stop in document order.
- Icon-only buttons inside a group need an `aria-label`.

<OnlyBase base="base">

- `ButtonGroupText` renders a `div` and is not focusable; use `render` to render a `label` element if it labels an input.

</OnlyBase>

<OnlyBase base="radix">

- `ButtonGroupText` renders a `div` and is not focusable; set `asChild` with a `label` element as the child if it labels an input.

</OnlyBase>

<OnlyBase base="aria">

- `ButtonGroupText` renders a `div` and is not focusable; pass a `render` function that returns a `label` element if it labels an input.

</OnlyBase>

## API Reference

### ButtonGroup

The container that joins its children and sets the orientation.

| Prop | Type | Default |
| --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |

Also accepts the props of `React.ComponentProps<"div">`.

`horizontal` joins items in a row with pill ends; `vertical` stacks them with rounded top and bottom. Elements are joined only when they expose a `data-slot` attribute, as the library's components do. Focused items are raised with `z-10` so their focus ring is not clipped by neighbors. In groups that contain `outline` buttons, inputs, input groups and select triggers also get the `border-border` color.

### ButtonGroupText

A static, button-shaped label for text or icons.

<OnlyBase base="base">

Also accepts the props of `useRender.ComponentProps<"div">`.

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |

Also accepts the props of `React.ComponentProps<"div">`.

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `(props: React.HTMLAttributes<HTMLElement> & { ref?: React.Ref<HTMLElement> }) => React.ReactNode` | — |

Also accepts the props of `React.ComponentProps<"div">`.

</OnlyBase>

### ButtonGroupSeparator

A thin divider between adjacent items.

Also accepts the props of `React.ComponentProps<typeof Separator>`.

The separator is vertical by default; in a vertical group, pass `orientation="horizontal"`.

Each part sets a `data-slot`, such as `button-group-text`, for styling, and the group sets `data-orientation` when `orientation` is set.

</Only>

import PhosphorSwift
import SwiftUI

struct ButtonGroupExample: View {
  var body: some View {
    ButtonGroup {
      ButtonGroup {
        ButtonGroupIconButton(icon: Ph.arrowLeft.regular, label: "Go back", variant: .secondary)
      }
      ButtonGroup {
        Button("Archive") {}.buttonStyle(.variant(.secondary))
        ButtonGroupSeparator()
        Button("Report") {}.buttonStyle(.variant(.secondary))
      }
      ButtonGroup {
        Button("Snooze") {}.buttonStyle(.variant(.secondary))
        ButtonGroupSeparator()
        ButtonGroupMailMenu(variant: .secondary)
      }
    }
  }
}

struct ButtonGroupIcon: View {
  let icon: Image
  let size: VariantButtonStyle.Size

  var body: some View {
    icon.frame(width: size.iconSize, height: size.iconSize)
  }
}

struct ButtonGroupIconButton: View {
  let icon: Image
  let label: LocalizedStringKey
  let variant: VariantButtonStyle.Variant
  var size: VariantButtonStyle.Size = .icon

  var body: some View {
    Button {} label: {
      ButtonGroupIcon(icon: icon, size: size)
    }
    .buttonStyle(.variant(variant, size: size))
    .accessibilityLabel(Text(label))
  }
}

struct ButtonGroupMailMenu: View {
  let variant: VariantButtonStyle.Variant

  var body: some View {
    DropdownMenu(align: .end) {
      DropdownMenuGroup {
        DropdownMenuItem("Mark as read", icon: Ph.listPlus.regular) {}
        DropdownMenuItem("Archive", icon: Ph.archive.regular) {}
      }
      DropdownMenuSeparator()
      DropdownMenuGroup {
        DropdownMenuItem("Snooze", icon: Ph.clock.regular) {}
        DropdownMenuItem("Add to calendar", icon: Ph.calendarPlus.regular) {}
        DropdownMenuItem("Label as", icon: Ph.tag.regular) {}
      }
      DropdownMenuSeparator()
      DropdownMenuGroup {
        DropdownMenuItem("Trash", icon: Ph.trash.regular, variant: .destructive) {}
      }
    } label: {
      ButtonGroupIcon(icon: Ph.dotsThree.bold, size: .icon)
    }
    .buttonStyle(.variant(variant, size: .icon))
    .accessibilityLabel(Text("More options"))
  }
}

@Composable
fun ButtonGroupIconButton(
    label: String,
    icon: androidx.compose.ui.graphics.vector.ImageVector,
    variant: ButtonVariant = ButtonVariant.Default,
    size: ButtonSize = ButtonSize.Icon,
    onClick: () -> Unit = {},
) {
    Button(onClick = onClick, variant = variant, size = size) {
        Icon(icon, contentDescription = label)
    }
}

@Composable
fun ButtonGroupMailMenu(variant: ButtonVariant) {
    var open by rememberSaveable { mutableStateOf(false) }
    DropdownMenu(
        expanded = open,
        onExpandedChange = { open = it },
        trigger = { ButtonGroupIconButton("More options", PhosphorIcons.Regular.DotsThree, variant) { open = true } },
        align = PopupAlign.End,
    ) {
        DropdownMenuGroup {
            DropdownMenuItem("Mark as read", onClick = {}, icon = PhosphorIcons.Regular.ListPlus)
            DropdownMenuItem("Archive", onClick = {}, icon = PhosphorIcons.Regular.Archive)
        }
        DropdownMenuSeparator()
        DropdownMenuGroup {
            DropdownMenuItem("Snooze", onClick = {}, icon = PhosphorIcons.Regular.Clock)
            DropdownMenuItem("Add to calendar", onClick = {}, icon = PhosphorIcons.Regular.CalendarPlus)
            DropdownMenuItem("Label as", onClick = {}, icon = PhosphorIcons.Regular.Tag)
        }
        DropdownMenuSeparator()
        DropdownMenuGroup {
            DropdownMenuItem("Trash", onClick = {}, icon = PhosphorIcons.Regular.Trash, variant = MenuItemVariant.Destructive)
        }
    }
}

@Composable
fun ButtonGroupMail(variant: ButtonVariant, separators: Boolean) {
    ButtonGroup {
        ButtonGroup {
            ButtonGroupIconButton("Go back", PhosphorIcons.Regular.ArrowLeft, variant)
        }
        ButtonGroup {
            Button("Archive", onClick = {}, variant = variant)
            if (separators) ButtonGroupSeparator()
            Button("Report", onClick = {}, variant = variant)
        }
        ButtonGroup {
            Button("Snooze", onClick = {}, variant = variant)
            if (separators) ButtonGroupSeparator()
            ButtonGroupMailMenu(variant)
        }
    }
}

## Accessibility

- The container has the `group` role.
- Each button keeps its own role and state.
- Icon-only buttons need an `accessibilityLabel`.
- Give the group an `accessibilityLabel` when its purpose is not clear from its contents.

## API Reference

<Only platform="rn">

### ButtonGroup

Container that joins its children.

| Prop | Type | Default |
| --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |

Also accepts the props of `ViewProps`.

`ghost` and `plain` buttons are left unjoined. Colors follow the system appearance.

### ButtonGroupText

Pill-shaped label or icon slot.

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `RenderProp<Record<string, unknown>, Record<string, never>>` | - |

Also accepts the props of `ViewProps`.

`render` sets the element to render instead of the default `View`.

### ButtonGroupSeparator

Divider between joined buttons.

Also accepts the props of `React.ComponentProps<typeof Separator>`.

</Only>
