A `ButtonGroup` lays out its children in a row or column and joins them visually: only the outer corners stay rounded, and borders between neighbors collapse. Use `ButtonGroupSeparator` to draw a divider between filled buttons, and `ButtonGroupText` to add a static label or prefix such as `https://`.

Groups can contain buttons, `Input`, `InputGroup`, `Select` triggers, and the triggers of dropdown menus and popovers. Nest `ButtonGroup` parts to create clusters with a gap between them. Use a button group for closely related actions, split buttons, or input-and-button combinations; for a set of toggleable options, use Toggle Group instead.

## Usage

```tsx
import { ButtonGroup, ButtonGroupText, ButtonGroupSeparator } from "@/components/ui/button-group"
```

```tsx
<ButtonGroup orientation="horizontal">
  <ButtonGroup>
    <Button variant="secondary" size="icon" aria-label="Go back">
      <ArrowLeftIcon />
    </Button>
  </ButtonGroup>
  <ButtonGroup>
    <Button variant="secondary">Archive</Button>
    <ButtonGroupSeparator />
    <Button variant="secondary">Report</Button>
  </ButtonGroup>
  <ButtonGroup>
    <Button variant="secondary">Snooze</Button>
    <ButtonGroupSeparator />
    <DropdownMenu>
      <DropdownMenuTrigger
        render={
          <Button
            variant="secondary"
            size="icon"
            aria-label="More options"
          />
        }
      >
        <DotsThreeIcon />
      </DropdownMenuTrigger>
      <DropdownMenuContent align="end" className="w-52">
        <DropdownMenuGroup>
          <DropdownMenuItem>
            <ListPlusIcon />
            Mark as read
          </DropdownMenuItem>
          <DropdownMenuItem>
            <ArchiveIcon />
            Archive
          </DropdownMenuItem>
        </DropdownMenuGroup>
        <DropdownMenuSeparator />
        <DropdownMenuGroup>
          <DropdownMenuItem>
            <ClockIcon />
            Snooze
          </DropdownMenuItem>
          <DropdownMenuItem>
            <CalendarPlusIcon />
            Add to calendar
          </DropdownMenuItem>
          <DropdownMenuItem>
            <TagIcon />
            Label as
          </DropdownMenuItem>
        </DropdownMenuGroup>
        <DropdownMenuSeparator />
        <DropdownMenuGroup>
          <DropdownMenuItem variant="destructive">
            <TrashIcon />
            Trash
          </DropdownMenuItem>
        </DropdownMenuGroup>
      </DropdownMenuContent>
    </DropdownMenu>
  </ButtonGroup>
</ButtonGroup>
```

Elements are joined only when they expose a `data-slot` attribute, as the library's components do.

When a group contains other `ButtonGroup` parts, the outer group adds a gap between them instead of joining them.

`ButtonGroupSeparator` is vertical by default. In a vertical group, pass `orientation="horizontal"`. Separators are most useful between `secondary` or `default` buttons; `outline` buttons already show their borders.

Give the group an `aria-label` when its purpose is not clear from its contents, as in the pagination and media control examples.

<ApiPart index={1}>

### ButtonGroup

The container that joins its children and sets the orientation.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Direction of the group. `horizontal` joins items in a row with pill ends; `vertical` stacks them with rounded top and bottom. |

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

<ApiPart index={2}>

### ButtonGroupText

A static, button-shaped label for text or icons.

Also accepts the props of `useRender.ComponentProps<"div">`.

</ApiPart>

<ApiPart index={3}>

### ButtonGroupSeparator

A thin divider between adjacent items.

Also accepts the props of `React.ComponentProps<typeof Separator>`.

</ApiPart>

## Accessibility

- `ButtonGroup` renders with `role="group"`; add an `aria-label` to name it.
- Each button, input and trigger remains a separate tab stop in document order.
- Icon-only buttons inside a group need an `aria-label`.
- `ButtonGroupText` renders a `div` and is not focusable; use `render` to render a `label` element if it labels an input.

## Notes

- Styling hooks: `data-slot="button-group"`, `"button-group-text"` and `"button-group-separator"`, plus `data-orientation` on the group.
- Focused items are raised with `z-10` so their focus ring is not clipped by neighbors.
- In groups containing `outline` buttons, inputs, input groups and select triggers also get the `border-border` color.

`ButtonGroup` is a `View` with the `group` role that joins its children: only the outer ends keep their rounded corners and the shared borders collapse. It works with `Button` and with other controls such as inputs, selects and menu triggers. `ghost` and `plain` buttons are left unjoined.

Nest groups to keep separate clusters in one row with a gap between them. `ButtonGroupSeparator` draws a divider between joined buttons, and `ButtonGroupText` shows a label or icon in the same pill shape.

## Usage

```tsx
import { ButtonGroup, ButtonGroupText, ButtonGroupSeparator } from "@/components/ui/button-group"
```

```tsx
<ButtonGroup>
  <ButtonGroup>
    <Button variant="secondary" size="icon" accessibilityLabel="Go back">
      <Icon as={ArrowLeftIcon} />
    </Button>
  </ButtonGroup>
  <ButtonGroup>
    <Button variant="secondary">
      <Text>Archive</Text>
    </Button>
    <ButtonGroupSeparator />
    <Button variant="secondary">
      <Text>Report</Text>
    </Button>
  </ButtonGroup>
  <ButtonGroup>
    <Button variant="secondary">
      <Text>Snooze</Text>
    </Button>
    <ButtonGroupSeparator />
    <DropdownMenu>
      <DropdownMenuTrigger
        accessibilityLabel="More options"
        render={<Button variant="secondary" size="icon" />}
      >
        <Icon as={DotsThreeIcon} />
      </DropdownMenuTrigger>
      <MailMenuContent />
    </DropdownMenu>
  </ButtonGroup>
</ButtonGroup>
```

Set `orientation="vertical"` to stack the buttons. Use a separator between buttons of the same filled variant, such as in a split button, where there is no border to divide them.

Give icon-only buttons an `accessibilityLabel`, and give the group one when its purpose is not clear from its contents.

### ButtonGroup

Container that joins its children.

| Prop | Type | Default | Description |

</ApiPart>

### ButtonGroupSeparator

Divider between joined buttons.

Also accepts the props of `React.ComponentProps<typeof Separator>`.

</ApiPart>

## Accessibility

- The container has the `group` role.
- Each button keeps its own role and state.
- Icon-only buttons need an `accessibilityLabel`.

## Notes

- Uses `bg-secondary` for `ButtonGroupText` and `bg-foreground/20` for separators; light and dark follow the system appearance.
