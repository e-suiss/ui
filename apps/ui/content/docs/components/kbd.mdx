`Kbd` renders a single key as a native `kbd` element in a small rounded capsule. Set `mod` to prepend the platform's primary modifier: `⌘` on Apple platforms, `Ctrl` elsewhere (`Ctrl+` when the key has children).

Wrap several keys in `KbdGroup` to present a key combination. Use `Kbd` inline in text, in tooltips, or inside an input group addon to hint at a shortcut.

## Usage

<Code lang="tsx" code={"import { Kbd, KbdGroup } from \"@/components/ui/kbd\""} />

<Code lang="tsx" code={"<Kbd mod>K</Kbd>"} />

Pass the key label as children. Use `mod` instead of hard-coding `⌘` or `Ctrl` so the hint matches the user's platform. Icons placed inside `Kbd` are sized to `size-3` unless they set their own `size-*` class.

## Accessibility

- Keys render as native `kbd` elements, so the text is announced as keyboard input.
- `Kbd` and `KbdGroup` are hidden below the `md` breakpoint, so do not rely on them as the only place a shortcut is documented.
- `Kbd` sets `pointer-events-none`; clicks pass through to the surrounding control, as in an input group addon.

## Notes

- Styling hooks: `data-slot="kbd"` and `data-slot="kbd-group"`.
- Platform detection reads `navigator` through `useSyncExternalStore`; during server rendering the non-Apple modifier is used.
- Inside an input group or tooltip content, `Kbd` adapts its background and text colors automatically.
- Uses the `surface-secondary`, `surface` and `label-secondary` tokens.
