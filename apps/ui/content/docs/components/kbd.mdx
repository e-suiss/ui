`Kbd` renders a single key as a native `kbd` element in a small rounded box. Set `mod` to prepend the platform's primary modifier.

Wrap several keys in `KbdGroup` to present a key combination. Use `Kbd` inline in text, in tooltips, or inside an input group addon to hint at a shortcut.

## Accessibility

- Keys render as native `kbd` elements, so the text is announced as keyboard input.
- `Kbd` and `KbdGroup` are hidden below the `md` breakpoint, so do not rely on them as the only place a shortcut is documented.
- `Kbd` sets `pointer-events-none`; clicks pass through to the surrounding control, as in an input group addon.

## API Reference

### Kbd

Renders one key as a `kbd` element, optionally prefixed with the platform modifier.

| Prop | Type | Default |
| --- | --- | --- |
| `mod` | `boolean` | - |

Also accepts the props of `React.ComponentProps<"kbd">`.

Pass the key label as children. `mod` prepends the platform's primary modifier: `⌘` on macOS and iOS, `Ctrl` on other platforms (`Ctrl+` when the key has children). Use it instead of hard-coding `⌘` or `Ctrl` so the hint matches the user's platform. Platform detection reads `navigator`, so server rendering uses the non-Apple modifier.

### KbdGroup

Groups several keys into a single inline key combination.

Also accepts the props of `React.ComponentProps<"div">`.

Both parts set a `data-slot`, `kbd` and `kbd-group`, for styling.
