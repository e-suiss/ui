Dropdown menu wraps the menu primitive of the chosen base. The `DropdownMenu` root manages the open state and `DropdownMenuTrigger` opens it. `DropdownMenuContent` renders the menu in a portal, positioned below the trigger. Inside it, use `DropdownMenuItem` for actions, `DropdownMenuCheckboxItem` for toggles, and `DropdownMenuRadioGroup` with `DropdownMenuRadioItem` for a single choice. Organize items with `DropdownMenuGroup`, `DropdownMenuLabel` and `DropdownMenuSeparator`, and nest a submenu with `DropdownMenuSub`, `DropdownMenuSubTrigger` and `DropdownMenuSubContent`. `DropdownMenuShortcut` displays a keyboard shortcut at the end of an item.

Use a dropdown menu for actions and settings behind a visible button. For actions on an object opened with a right-click, use a context menu; to choose a value for a form field, use a select.

## Composition

Use the following composition to build a `DropdownMenu`:

```text
DropdownMenu
├── DropdownMenuTrigger
└── DropdownMenuContent
    ├── DropdownMenuGroup
    │   ├── DropdownMenuLabel
    │   ├── DropdownMenuItem
    │   │   └── DropdownMenuShortcut
    │   └── DropdownMenuCheckboxItem
    ├── DropdownMenuSeparator
    ├── DropdownMenuSub
    │   ├── DropdownMenuSubTrigger
    │   └── DropdownMenuSubContent
    │       └── DropdownMenuItem
    ├── DropdownMenuRadioGroup
    │   ├── DropdownMenuLabel
    │   └── DropdownMenuRadioItem
    └── DropdownMenuItem
        └── DropdownMenuShortcut
```

## Accessibility

- The trigger sets `aria-expanded`. The menu has the `menu` role; items have the `menuitem`, `menuitemcheckbox` or `menuitemradio` role, and checkbox and radio items set `aria-checked`.
- Groups have the `group` role and take their name from `DropdownMenuLabel`.
- Opening the menu from the keyboard focuses the first item. Arrow keys move between items, and disabled items set `aria-disabled`.
- On a submenu trigger, the Right Arrow opens the submenu and moves focus into it, and the Left Arrow returns to the trigger. The arrow directions follow the reading direction.
- Escape closes the menu and returns focus to the trigger.
- `DropdownMenuShortcut` only displays a shortcut; it does not register one. It is hidden on small screens.

## API Reference

### DropdownMenu

The root that manages the menu's open state.

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base radix">

The menu is uncontrolled by default; set `defaultOpen` to start open, or control it with `open` and `onOpenChange`.

</OnlyBase>

<OnlyBase base="aria">

The menu is uncontrolled by default; set `defaultOpen` to start open, or control it with `isOpen` and `onOpenChange`. The `Button` placed first inside `DropdownMenu` opens it.

</OnlyBase>

### DropdownMenuPortal

Renders its children into a portal outside the current DOM hierarchy.

Also accepts the props of the primitive part it wraps.

### DropdownMenuTrigger

The button that opens the menu.

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base">

Render the trigger as another component, such as a `Button`, with the `render` prop.

</OnlyBase>

<OnlyBase base="radix">

Set `asChild` to render your own `Button` as the trigger.

</OnlyBase>

### DropdownMenuContent

The menu panel, rendered in a portal and positioned relative to the trigger.

<OnlyBase base="base">

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `sideOffset` | `number` | `4` |
| `align` | `"start" \| "center" \| "end"` | `"start"` |
| `alignOffset` | `number` | `0` |

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` |
| `sideOffset` | `number` | `4` |
| `align` | `"start" \| "center" \| "end"` | `"start"` |
| `alignOffset` | `number` | `0` |

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `placement` | `Placement` | `"bottom start"` |
| `offset` | `number` | `4` |
| `crossOffset` | `number` | `0` |

</OnlyBase>

Also accepts the props of the primitive parts it wraps.

<OnlyBase base="base radix">

`side` is the side of the trigger the menu opens on, and `align` how it lines up with the trigger along that side. `sideOffset` and `alignOffset` are in pixels.

</OnlyBase>

<OnlyBase base="aria">

`placement` sets where the menu opens relative to the trigger. `offset` and `crossOffset` are in pixels.

</OnlyBase>

By default the menu opens below the trigger, aligned to `start`, and matches the trigger's width with a minimum of `12rem`. Override the width with `className`.

### DropdownMenuGroup

Groups related items.

Also accepts the props of the primitive part it wraps.

### DropdownMenuLabel

A heading for a group of items.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |

Also accepts the props of the primitive part it wraps.

### DropdownMenuItem

An action in the menu.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |
| `variant` | `"default" \| "destructive"` | `"default"` |

Also accepts the props of the primitive part it wraps.

Selecting a regular item closes the menu. `inset` adds leading padding so the item aligns with items that have an icon or indicator; labels, sub triggers, checkbox and radio items take it too. `variant="destructive"` colors the item and its icon with the `destructive` color; use it on items that delete or remove something. Items set `data-inset` and `data-variant`, and disabled items get `data-disabled`.

### DropdownMenuSub

The root of a nested submenu.

Also accepts the props of the primitive part it wraps.

### DropdownMenuSubTrigger

The item that opens a submenu, shown with a trailing caret.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |

Also accepts the props of the primitive part it wraps.

An open submenu trigger gets `data-popup-open`.

### DropdownMenuSubContent

The panel of a submenu, opened beside its trigger.

<OnlyBase base="base">

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left" \| "inline-start" \| "inline-end"` | `"inline-end"` |
| `sideOffset` | `number` | `0` |
| `align` | `"start" \| "center" \| "end"` | `"start"` |
| `alignOffset` | `number` | `-3` |

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `sideOffset` | `number` | `0` |
| `alignOffset` | `number` | `-3` |

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `placement` | `Placement` | `"end top"` |
| `offset` | `number` | `0` |
| `crossOffset` | `number` | `-3` |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

The placement props work as on `DropdownMenuContent`, measured against the submenu trigger.

### DropdownMenuCheckboxItem

An item that toggles a setting on or off and shows a check mark when on.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `defaultChecked` | `boolean` | `false` |
| `closeOnClick` | `boolean` | `false` |

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `isSelected` | `boolean` | - |
| `defaultSelected` | `boolean` | `false` |
| `onChange` | `(isSelected: boolean) => void` | - |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base radix">

Checkbox items are uncontrolled with `defaultChecked`, or controlled with `checked` and `onCheckedChange`.

</OnlyBase>

<OnlyBase base="radix">

Set `closeOnClick` to close the menu when the item is selected.

</OnlyBase>

<OnlyBase base="aria">

Checkbox items are uncontrolled with `defaultSelected`, or controlled with `isSelected` and `onChange`.

</OnlyBase>

Checkbox and radio items keep the menu open so several choices can be made in a row.

### DropdownMenuRadioGroup

Groups radio items so that only one can be selected.

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | - |
| `defaultValue` | `string` | - |
| `onChange` | `(value: string) => void` | - |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base radix">

Radio groups take `defaultValue`, or `value` and `onValueChange`.

</OnlyBase>

<OnlyBase base="aria">

Radio groups take `defaultValue`, or `value` and `onChange`, which is called with the `value` of the newly selected item.

</OnlyBase>

### DropdownMenuRadioItem

An item in a radio group that shows a check mark when selected.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `closeOnClick` | `boolean` | `false` |

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | - |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

Each radio item needs a `value`, which the group reports when it is selected.

<OnlyBase base="radix">

Set `closeOnClick` to close the menu when the item is selected.

</OnlyBase>

### DropdownMenuSeparator

A divider between groups of items.

Also accepts the props of the primitive part it wraps.

### DropdownMenuShortcut

Displays a keyboard shortcut at the end of an item.

| Prop | Type | Default |
| --- | --- | --- |
| `mod` | `boolean` | - |

Also accepts the props of `React.ComponentProps<"span">`.

Set `mod` to prefix the shortcut with the platform modifier key, `⌘` on Apple platforms and `Ctrl+` elsewhere.

Each part sets a `data-slot`, such as `dropdown-menu-item` or `dropdown-menu-checkbox-item-indicator`, for styling.

</Only>

<Only platform="rn">

`DropdownMenu` opens `DropdownMenuContent` next to a `DropdownMenuTrigger` when it is pressed. The content renders through a portal (inside a full-window overlay on iOS) as a raised, rounded card positioned below the trigger by default.

Items can be plain actions, checkbox items, radio items in a group, or a submenu. `DropdownMenuSubContent` expands in place under its trigger, and the caret turns to point down while it is open. For a menu that opens on long press at the touch point, use Context Menu.

fun DropdownMenuDemo(
    label: String,
    defaultOpen: Boolean = false,
    content: @Composable () -> Unit,
) {
    var open by rememberSaveable { mutableStateOf(defaultOpen) }
    Column {
        DropdownMenu(
            expanded = open,
            onExpandedChange = { open = it },
            trigger = { Button(label, onClick = { open = !open }, variant = ButtonVariant.Outline) },
            modifier = Modifier.width(224.dp),
            align = PopupAlign.Start,
        ) {
            content()
        }
    }
}

## Accessibility

- The trigger has the `button` role.
- The popup has the `menu` role; items use `menuitem`, `checkbox` and `radio` roles, and radio groups use `radiogroup`.
- Groups are labelled by their `DropdownMenuLabel`, and separators have the `separator` role.

</Only>

## API Reference

<Only platform="rn">

### DropdownMenu

The root that manages the open state.

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `(open: boolean, details) => void` | - |
| `modal` | `boolean` | `true` |
| `disabled` | `boolean` | `false` |

Use `open` with `onOpenChange` for controlled state, or `defaultOpen` for uncontrolled. `modal` blocks interaction with the rest of the screen while open, and `disabled` prevents the menu from opening. Use `render` on `DropdownMenuTrigger` to render it as a `Button`.

### DropdownMenuContent

Floating menu card.

| Prop | Type | Default |
| --- | --- | --- |
| `portalHost` | `string` | - |

Also accepts the props of `React.ComponentProps<typeof MenuPrimitive.Popup>`, `PositionerProps`.

Position the content with `side`, `align`, `sideOffset` and `alignOffset`. `portalHost` names the portal host to render into. The fade-in respects the system Reduce Motion setting.

### DropdownMenuSubTrigger

Row that expands the submenu.

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `React.ReactNode` | - |
| `iconClassName` | `string` | - |
| `inset` | `boolean` | - |

Also accepts the props of `React.ComponentProps<typeof MenuPrimitive.SubmenuTrigger>`.

`iconClassName` adds classes to the caret icon. An open submenu trigger uses `bg-accent`.

### DropdownMenuSubContent

Items of the submenu.

Also accepts the props of `React.ComponentProps<typeof MenuPrimitive.Popup>`.

### DropdownMenuItem

Action row.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |
| `variant` | `"default" \| "destructive"` | `"default"` |

Also accepts the props of `React.ComponentProps<typeof MenuPrimitive.Item>`.

Items close the menu when pressed unless `closeOnPress={false}`. Set `variant="destructive"` on an item that deletes or removes. `inset` adds start padding; the sub trigger, checkbox, radio and label parts take it too. A highlighted item fades to `opacity-80` and a disabled one to `opacity-50`.

### DropdownMenuCheckboxItem

Row with a check mark that toggles.

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `React.ReactNode` | - |
| `inset` | `boolean` | - |

Also accepts the props of `React.ComponentProps<typeof MenuPrimitive.CheckboxItem>`.

### DropdownMenuRadioItem

Row that selects one value in its group.

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `React.ReactNode` | - |
| `inset` | `boolean` | - |

Also accepts the props of `React.ComponentProps<typeof MenuPrimitive.RadioItem>`.

### DropdownMenuLabel

Heading for a group.

| Prop | Type | Default |
| --- | --- | --- |
| `inset` | `boolean` | - |

Also accepts the props of `React.ComponentProps<typeof MenuPrimitive.GroupLabel>`.

Group items with `DropdownMenuGroup` and a `DropdownMenuLabel`, and divide sections with `DropdownMenuSeparator`.

### DropdownMenuSeparator

Line between sections.

Also accepts the props of `React.ComponentProps<typeof MenuPrimitive.Separator>`.
