`Slider` wraps the slider primitive of the chosen base in a single component. It renders the track, the filled range and one thumb per value. The thumb is a wide capsule that stretches while it's dragged or pressed.

Use a slider when an approximate value within a range matters more than a precise number, such as volume or brightness. For exact numbers, use a number field or `Input`.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/slider
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add slider
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install @base-ui/react
```

2. Copy the source into `components/ui/slider.tsx`:

## Usage

```tsx
import { Slider } from "@/components/ui/slider"
```

<OnlyBase base="base radix">

```tsx
<div className="w-72">
  <Slider defaultValue={[50]} min={0} max={100} step={1} aria-label="Volume" />
</div>
```

Pass `defaultValue` or `value` as an array: one number for a single thumb, two for a range. `min` defaults to `0` and `max` to `100`; use `step` to snap to increments. Use `onValueChange` with `value` to control it, and set `orientation="vertical"` for a vertical slider. Set `disabled` to turn it off.

</OnlyBase>

## Accessibility

- Each thumb has the `slider` role with `aria-valuenow` and `aria-orientation`.

<OnlyBase base="base radix">

- `aria-label` and `aria-labelledby` on `Slider` are passed to every thumb, so each thumb is named.

</OnlyBase>

<OnlyBase base="aria">

- `aria-label` and `aria-labelledby` on `Slider` name the slider group, and every thumb is labelled by the group.

</OnlyBase>

- Arrow keys move the focused thumb by one step; `Home` and `End` jump to the minimum and maximum. Vertical sliders use the up and down arrow keys.
- In a range, `Tab` moves between thumbs, and each thumb moves independently.
- A disabled slider can't be focused.

## Notes

<OnlyBase base="base radix">

- The number of thumbs follows the length of the `value` or `defaultValue` array. Without an array, the slider renders one thumb. Always pass an array.

</OnlyBase>

<OnlyBase base="aria">

- The number of thumbs follows the length of the `value` or `defaultValue` array.

</OnlyBase>

- Parts carry `data-slot` attributes: `slider`, `slider-track`, `slider-range` and `slider-thumb`.
- The range uses `bg-primary`, the track uses `bg-border`, and disabled sliders are dimmed with `opacity-50`.

<OnlyBase base="base">

- Thumbs use `thumbAlignment="edge"`, so they stay inside the track at both ends.

</OnlyBase>

<Only platform="swift">

```swift
import SwiftUI

struct SliderExample: View {
  var body: some View {
    SliderDemo(initial: 50)
  }
}

struct SliderDemo: View {
  var bounds: ClosedRange<Double> = 0...100
  var step: Double = 1

  @State private var value: Double

  init(initial: Double, bounds: ClosedRange<Double> = 0...100, step: Double = 1) {
    self.bounds = bounds
    self.step = step
    _value = State(initialValue: initial)
  }

  var body: some View {
    ValueSlider(value: $value, in: bounds, step: step)
      .accessibilityLabel(Text("Volume"))
      .frame(maxWidth: .infinity)
  }
}
```

</Only>

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableFloatStateOf
import androidx.compose.runtime.saveable.rememberSaveable
import androidx.compose.runtime.setValue
import androidx.compose.ui.Modifier
import com.esuiss.ui.components.Slider

@Composable
fun SliderExample() {
    SliderUncontrolled(50f)
}

@Composable
fun SliderUncontrolled(
    initial: Float,
    valueRange: ClosedFloatingPointRange<Float> = 0f..100f,
    step: Float = 1f,
    enabled: Boolean = true,
) {
    var value by rememberSaveable { mutableFloatStateOf(initial) }
    Slider(
        value,
        { value = it },
        Modifier.fillMaxWidth(),
        enabled = enabled,
        valueRange = valueRange,
        step = step,
        contentDescription = "Volume",
    )
}
```

</Only>

<Only platform="rn">

Use `defaultValue` for an uncontrolled slider, or `value` with `onValueChange` to control it. `onValueCommitted` runs when a drag or track press ends, which suits saving or fetching.

Set `min`, `max` and `step` to define the range; `min` defaults to `0` and `max` to `100`. For ranges, `minStepsBetweenValues` keeps thumbs apart and `thumbCollisionBehavior` decides whether thumbs `push` each other, `swap`, or stop (`none`).

The number of thumbs comes from the array length of `value` or `defaultValue`.

</Only>

## Accessibility

- Each thumb has the `adjustable` role with its min, max and current value, so VoiceOver and TalkBack users can swipe up or down to change it.
- `accessibilityLabel` on `Slider` is passed to every thumb; set it, since the slider has no visible label.
- Disabled thumbs report `disabled` in their accessibility state.

## Notes

- The track uses `bg-border` and the indicator `bg-primary`, and the slider is shown at `opacity-50` when disabled.
- Thumbs use `bg-background` with a shadow, or `bg-foreground` in dark mode.
- Light and dark colors follow the system appearance.
