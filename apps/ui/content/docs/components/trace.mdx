A `Trace` is a list of `TraceLine` rows. Each row has a `TraceIcon`, a `TraceTitle`, and an optional `TraceDescription` and status. A row can expand to show more detail, link to a page, or open a dialog or sheet.

Every row has the same shape, so reasoning, tool calls, sources and plans built from Trace look and behave the same. Use Trace for the steps an agent takes, such as calling a tool, running a subagent or editing a file. Use [Message](/docs/components/message) for its reply and [Marker](/docs/components/marker) for notes and dividers between turns.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/trace
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add trace
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install @phosphor-icons/react
```

2. Add the pieces it builds on: [Collapsible](/docs/components/collapsible).

3. Copy the source into `components/ui/trace.tsx`:

<ComponentSource path="components/ui/trace.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { Trace, TraceCollapsible, TraceCollapsibleContent, TraceCollapsibleTrigger, TraceIcon, TraceLine, TraceTitle } from "@/components/ui/trace"
```

```tsx
<Trace>
  <TraceLine>
    <TraceIcon>
      <SearchIcon />
    </TraceIcon>
    <TraceTitle>Searched for minimumReleaseAge</TraceTitle>
  </TraceLine>
</Trace>
```

Wrap the row in a `TraceCollapsible` to show more detail when it expands. Put the `TraceLine` inside `TraceCollapsibleTrigger` and the detail in `TraceCollapsibleContent`:

```tsx
<Trace>
  <TraceCollapsible>
    <TraceCollapsibleTrigger>
      <TraceLine>
        <TraceIcon>
          <TerminalIcon />
        </TraceIcon>
        <TraceTitle>Ran node --version</TraceTitle>
      </TraceLine>
    </TraceCollapsibleTrigger>
    <TraceCollapsibleContent>v24.18.0</TraceCollapsibleContent>
  </TraceCollapsible>
</Trace>
```

`TraceLine` is always the row. To make a row do something, wrap it in that thing's trigger: a link, a `DialogTrigger`, a `SheetTrigger`, a drawer or a popover.

<OnlyBase base="base">

Rows start closed. Set `defaultOpen` on `TraceCollapsible` to start open, or pass `open` with `onOpenChange` to control it. Set `keepMounted` on `TraceCollapsibleContent` so nested rows keep their open state while the parent is closed.

</OnlyBase>

<OnlyBase base="radix">

Rows start closed. Set `defaultOpen` on `TraceCollapsible` to start open, or pass `open` with `onOpenChange` to control it.

</OnlyBase>

<OnlyBase base="aria">

Rows start closed. Set `defaultExpanded` on `TraceCollapsible` to start open, or pass `isExpanded` with `onExpandedChange` to control it.

</OnlyBase>

## Accessibility

- Trace adds no roles of its own. Each row gets its semantics from the element that wraps it.
- A `TraceLine` on its own is read as text and is not a tab stop.
- Inside `TraceCollapsibleTrigger` the row is a button with `aria-expanded`. Inside a link or a dialog or sheet trigger, it takes that element's keyboard and focus behavior.
- `TraceIcon` is hidden from assistive tech, so `TraceTitle` is the accessible name. Write it as a sentence that says what happened, such as "Edited trace.tsx", not just "trace.tsx".
- Status is shown with color and motion, so put it in the title too.
- The running shimmer stops when the reader prefers reduced motion.

## Notes

- Styling hooks: `data-slot="trace"`, `"trace-line"`, `"trace-icon"`, `"trace-title"`, `"trace-description"`, `"trace-collapsible"`, `"trace-collapsible-trigger"`, `"trace-collapsible-content"` and `"trace-collapsible-content-inner"`, plus `data-status` on the row.
- `TraceCollapsibleContent` mutes its text. Give a block with a muted background inside it `text-foreground` to keep its contrast; [Code Block](/docs/components/code-block) sets its own text color.

</Only>

```swift
import EsuissUI
import PhosphorSwift
import SwiftUI

struct TraceExample: View {
  var body: some View {
    VStack(alignment: .leading, spacing: 16) {
      Message(align: .end) {
        MessageContent {
          Bubble(variant: .muted, align: .end) { BubbleContent("Why does pnpm install fail in CI?") }
        }
      }
      Trace {
        TraceCollapsible {
          TraceCollapsibleTrigger {
            TraceLine {
              TraceIcon { Ph.checkCircle.regular }
              TraceTitle("Thought for 5s")
            }
          }
          TraceCollapsibleContent {
            Text("CI installs with a frozen lockfile, so the install stops when package.json and pnpm-lock.yaml disagree.")
          }
        }
        TraceLine {
          TraceIcon { Ph.checkCircle.regular }
          TraceTitle("Ran pnpm --version")
        }
        TraceCollapsible(initiallyExpanded: true) {
          TraceCollapsibleTrigger {
            TraceLine(status: .error) {
              TraceIcon { Ph.warningCircle.regular }
              TraceTitle("Failed to run pnpm install")
            }
          }
          TraceCollapsibleContent {
            TraceOutput(text: "ERR_PNPM_OUTDATED_LOCKFILE Cannot install with \"frozen-lockfile\" because pnpm-lock.yaml is not up to date with package.json", error: true)
          }
        }
      }
      Text("The last commit bumped a version in package.json without updating pnpm-lock.yaml. Run pnpm install locally and commit the lockfile.")
        .textStyle(.base)
    }
  }
}

struct TraceOutput: View {
  let text: String
  var error = false

  var body: some View {
    CodeBlock(error ? .destructive : .default, size: .sm) {
      CodeBlockContent(text, wrap: true)
    }
  }
}
```

```kotlin
        size = CodeBlockSize.Sm,

@Composable
fun TraceRow(icon: ImageVector, title: String, status: TraceStatus? = null, description: String? = null) {
    TraceLine(status = status) {
        TraceIcon { Icon(icon, contentDescription = null) }
        TraceTitle(title)
        if (description != null) TraceDescription(description)
    }
}

                    )
                }
            }
        }
        Text("The last commit bumped a version in package.json without updating pnpm-lock.yaml. Run pnpm install locally and commit the lockfile.")
    }
}
```

## Accessibility

- The trigger is a button whose state reads as expanded or collapsed.
- `TraceIcon` is hidden from assistive technology, so write the title as a sentence that says what happened.
- Status is shown with color and motion, so put it in the title too.
