`Toggle` wraps the Base UI Toggle primitive. When pressed, it shows a tinted background and `primary`-colored content, and it scales down slightly while being pressed.

Use a toggle for a single on-off option such as bold text or a bookmark. To choose among related options, use `ToggleGroup`; for a setting that takes effect immediately, use `Switch`.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add toggle
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install @base-ui/react class-variance-authority
```

2. Copy the source into `components/ui/toggle.tsx`:

<ComponentSource path="components/ui/toggle.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Toggle } from "@/components/ui/toggle"
```

```tsx
<Toggle aria-label="Toggle bold"><TextBIcon /></Toggle>
```

Use `defaultPressed` for an uncontrolled toggle, or `pressed` with `onPressedChange` to control it. Mark an icon beside a label with `data-icon="inline-start"` or `data-icon="inline-end"` to tighten the padding on that side.

## API Reference

<ApiPart index={1}>

### Toggle

The pressable two-state button.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "outline"` | `"default"` | Uses a borderless `default` style or an `outline` style with a border. |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` | Sets the height and padding: `sm`, `default` or `lg`. |

Also accepts the props of `TogglePrimitive.Props`.

</ApiPart>

## Accessibility

- Renders a `button` with `aria-pressed` reflecting its state.
- `Enter` and `Space` toggle the focused button.
- An icon-only toggle needs an `aria-label`.

## Notes

- Uses `data-slot="toggle"`. Pressed styles key off `aria-pressed`.
- `toggleVariants` is exported so other components, such as `ToggleGroupItem`, can share the styles.
- The press animation is removed when reduced motion is preferred.

`Toggle` is a `Pressable` with an on and off state. When on, it shows a selected background and its text turns to the primary color; it scales down slightly while pressed. It has two variants, `default` and `outline`, and three sizes.

`ToggleIcon` is an `Icon` sized for use inside a toggle.

## Usage

```tsx
import { Toggle, ToggleIcon } from "@/components/ui/toggle"
```

```tsx
<View className="flex-row">
  <ToggleDemo accessibilityLabel="Toggle bold">
    <ToggleIcon as={TextBIcon} />
  </ToggleDemo>
</View>
```

Control the state with `pressed` and `onPressedChange(pressed, details)`, or leave it uncontrolled with `defaultPressed`. Put text in a `Text` and icons in `ToggleIcon`.

Icon-only toggles need an `accessibilityLabel`. To group toggles with single or multiple selection, use Toggle Group. `toggleVariants`, `toggleStateClassName` and `toggleTextClassName` are exported for reuse in custom components.

## Accessibility

- Uses the `togglebutton` role and reports `checked` and `disabled` in `accessibilityState`.
- Inside a single-select Toggle Group, it uses the `radio` role instead.
- Icon-only toggles need an `accessibilityLabel`.

## Notes

- Changing the state triggers a selection haptic when a haptics adapter is provided through `HapticsContext`.
- Uses the `bg-accent`, `text-primary` and `border-border` tokens, with `opacity-80` while pressed and `opacity-50` when disabled.
- Light and dark colors follow the system appearance.
