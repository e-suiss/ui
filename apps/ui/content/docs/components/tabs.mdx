<ComponentPreview name="tabs-demo" />

`Tabs` wraps the tabs primitive of the chosen base. `TabsList` holds the `TabsTrigger` buttons, and each `TabsContent` panel is shown when its `value` matches the selected tab. An indicator slides to the active tab: a raised pill in the `default` variant, or an underline in the `line` variant.

When there are more tabs than fit, the list scrolls horizontally and keeps the active tab in view. On small screens, a horizontal list bleeds to the edges of its scroll container. Use `Tabs` to switch views within a page. For app-level navigation, use `TabBar` or `Sidebar`; for a compact single-choice control, consider a segmented `ToggleGroup`.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/tabs
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):


## Usage

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from "@/components/ui/tabs"
```

<OnlyBase base="base radix">

```tsx
<Tabs defaultValue="account" orientation="horizontal">
  <TabsList variant="default">
    {tabs.map((tab) => (
      <TabsTrigger key={tab.value} value={tab.value}>
        {tab.label}
      </TabsTrigger>
    ))}
  </TabsList>
  {tabs.map((tab) => (
    <TabsContent
      key={tab.value}
      value={tab.value}
      className="text-muted-foreground"
    >
      {tab.content}
    </TabsContent>
  ))}
</Tabs>
```

Use `defaultValue` on `Tabs` for an uncontrolled set, or `value` with `onValueChange` to control it. Give each `TabsTrigger` and its `TabsContent` the same `value`. Set `orientation="vertical"` on `Tabs` to stack the triggers beside the panel.

</OnlyBase>

<OnlyBase base="aria">

```tsx
<Tabs defaultSelectedKey="account" orientation="horizontal">
  <TabsList variant="default">
    {tabs.map((tab) => (
      <TabsTrigger key={tab.value} id={tab.value}>
        {tab.label}
      </TabsTrigger>
    ))}
  </TabsList>
  {tabs.map((tab) => (
    <TabsContent
      key={tab.value}
      id={tab.value}
      className="text-muted-foreground"
    >
      {tab.content}
    </TabsContent>
```

Use `defaultSelectedKey` on `Tabs` for an uncontrolled set, or `selectedKey` with `onSelectionChange` to control it. Give each `TabsTrigger` and its `TabsContent` the same `id`. Set `orientation="vertical"` on `Tabs` to stack the triggers beside the panel.

</OnlyBase>

## Accessibility

- The list has the `tablist` role with `aria-orientation`; triggers are `tab` elements with `aria-selected`, and panels are `tabpanel` elements.
- Arrow keys move focus between tabs, wrapping at the ends; `Enter` or `Space` selects the focused tab. Vertical tabs use the up and down arrow keys.
- `Home` and `End` move focus to the first and last tabs.
- Disabled tabs can't be selected by click or keyboard.

## Notes

- Parts carry `data-slot` attributes: `tabs`, `tabs-list`, `tabs-list-content`, `tabs-indicator`, `tabs-trigger` and `tabs-content`. The list and indicator set `data-variant`.

<OnlyBase base="base">

- The active trigger sets `data-active`.

</OnlyBase>

<OnlyBase base="radix">

- The active trigger sets `data-state="active"`.

</OnlyBase>

<OnlyBase base="aria">

- The active trigger sets `data-selected`.

</OnlyBase>

- The edge bleed on small screens is set through the `--tabs-list-bleed-start` and `--tabs-list-bleed-end` properties, which the list measures itself.
- `className` on `TabsList` styles the inner `tabs-list-content` element, not the scrolling list.
- Indicator and scroll animations are removed when reduced motion is preferred.

</Only>

## Usage

<Only platform="rn">

```tsx
import * as React from "react"
import { View } from "react-native"
import { Button } from "@/components/ui/button"
import { Card, CardContent, CardDescription, CardFooter, CardHeader, CardTitle } from "@/components/ui/card"
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs"
import { Text } from "@/components/ui/text"

function TabsDemo() {
  const [value, setValue] = React.useState("account")
  return (
    <Tabs value={value} onValueChange={setValue} className="w-full">
      <TabsList>
        <TabsTrigger value="account">
          <Text>Account</Text>
        </TabsTrigger>
        <TabsTrigger value="password">
          <Text>Password</Text>
        </TabsTrigger>
      </TabsList>
      <TabsContent value="account">
        <Card>
          <CardHeader>
            <CardTitle>Account</CardTitle>
            <CardDescription>
              Make changes to your account here.
            </CardDescription>
          </CardHeader>
          <CardContent className="gap-4">
            <View className="gap-2">
              <Label nativeID="tabs-name">Name</Label>
              <Input
                accessibilityLabelledBy="tabs-name"
                defaultValue="Pedro Duarte"
              />
            </View>
            <View className="gap-2">
              <Label nativeID="tabs-username">Username</Label>
              <Input
                accessibilityLabelledBy="tabs-username"
                defaultValue="@peduarte"
                autoCapitalize="none"
              />
            </View>
          </CardContent>
          <CardFooter>
            <Button>
              <Text>Save changes</Text>
            </Button>
          </CardFooter>
        </Card>
      </TabsContent>
      <TabsContent value="password">
        <Card>
          <CardHeader>
            <CardTitle>Password</CardTitle>
            <CardDescription>
              Change your password here. You will be logged out after saving.
            </CardDescription>
          </CardHeader>
          <CardContent className="gap-4">
            <View className="gap-2">
              <Label nativeID="tabs-current">Current password</Label>
              <Input accessibilityLabelledBy="tabs-current" secureTextEntry />
            </View>
            <View className="gap-2">
              <Label nativeID="tabs-new">New password</Label>
              <Input accessibilityLabelledBy="tabs-new" secureTextEntry />
            </View>
          </CardContent>
          <CardFooter>
            <Button>
              <Text>Save password</Text>
            </Button>
          </CardFooter>
        </Card>
      </TabsContent>
    </Tabs>
  )
}

export function TabsExample() {
  return (
    <TabsDemo />
  )
}
```

```swift
                  .textInputAutocapitalization(.never)

            }

            Button("Save changes") {}.buttonStyle(.variant())
          }
        }
      }
```

## Accessibility

- `TabsList` has the `tablist` role and each trigger has the `tab` role.
- Triggers report `selected` and `disabled` in their accessibility state, so VoiceOver and TalkBack announce the current tab.
- Hidden panels kept with `keepMounted` are removed from the accessibility tree.
- The indicator animation follows the system reduce motion setting.

## Notes

- The `default` track uses `bg-secondary` with a `bg-card` indicator (`bg-border` in dark mode); the `line` indicator uses `bg-foreground`.
- Labels use `text-foreground` when active, `text-muted-foreground` when inactive and `opacity-50` when disabled.
- Light and dark colors follow the system appearance.
