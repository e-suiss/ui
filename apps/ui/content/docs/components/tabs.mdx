`Tabs` wraps the tabs primitive of the chosen base. `TabsList` holds the `TabsTrigger` buttons, and each `TabsContent` panel is shown when its `value` matches the selected tab. An indicator slides to the active tab: a raised pill in the `default` variant, or an underline in the `line` variant.

Use `Tabs` to switch views within a page. For app-level navigation, use `TabBar` or `Sidebar`; for a compact single-choice control, consider a segmented `ToggleGroup`.

## Usage

```tsx
import {
  Tabs,
  TabsContent,
  TabsList,
  TabsTrigger,
} from "@/components/ui/tabs"
```

<OnlyBase base="base radix">

```tsx
<Tabs defaultValue="account" orientation="horizontal">
  <TabsList variant="default">
    {tabs.map((tab) => (
      <TabsTrigger key={tab.value} value={tab.value}>
        {tab.label}
      </TabsTrigger>
    ))}
  </TabsList>
  {tabs.map((tab) => (
    <TabsContent
      key={tab.value}
      value={tab.value}
      className="text-muted-foreground"
    >
      {tab.content}
    </TabsContent>
  ))}
</Tabs>
```

</OnlyBase>

      key={tab.value}

## Accessibility

- The list has the `tablist` role with `aria-orientation`; triggers are `tab` elements with `aria-selected`, and panels are `tabpanel` elements.
- Arrow keys move focus between tabs, wrapping at the ends; `Enter` or `Space` selects the focused tab. Vertical tabs use the up and down arrow keys.
- `Home` and `End` move focus to the first and last tabs.
- Disabled tabs can't be selected by click or keyboard.

Each part sets a `data-slot`, such as `tabs-list` or `tabs-trigger`, for styling. Indicator and scroll animations are removed when reduced motion is preferred.

### TabsList

The row or column of tabs, with the sliding indicator.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "line"` | `"default"` |

Also accepts the props of the primitive part it wraps.

`variant` chooses a filled `default` list with a raised pill, or a `line` list with an underline; the list and indicator set `data-variant`. `className` styles the inner `tabs-list-content` element, not the scrolling list. The edge bleed on small screens is set through the `--tabs-list-bleed-start` and `--tabs-list-bleed-end` properties, which the list measures itself.

fun TabsField(label: String, initial: String, password: Boolean = false, capitalize: Boolean = true) {

    Column(verticalArrangement = Arrangement.spacedBy(8.dp)) {

        Input(

        )
    }
}

## Accessibility

- `TabsList` has the `tablist` role and each trigger has the `tab` role.
- Triggers report `selected` and `disabled` in their accessibility state, so VoiceOver and TalkBack announce the current tab.
- Hidden panels kept with `keepMounted` are removed from the accessibility tree.
- The indicator animation follows the system reduce motion setting.

</Only>

## API Reference

<Only platform="rn">

### Tabs

Root that holds the active value and orientation.

Also accepts the props of `React.ComponentProps<typeof TabsPrimitive.Root>`.

Use `defaultValue` for an uncontrolled tab set, or `value` with `onValueChange` to control it. Set `orientation="vertical"` to stack the list beside the panels.

### TabsList

Row or column of triggers with the animated indicator.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "line"` | `"default"` |

Also accepts the props of `React.ComponentProps<typeof TabsPrimitive.List>`.

`variant` is `default` for a filled segmented track, or `line` for an underline. `tabsListVariants` is exported for reuse.

### TabsTrigger

Pressable tab that activates its panel.

Also accepts the props of `React.ComponentProps<typeof TabsPrimitive.Tab>`.

Give each `TabsTrigger` and its `TabsContent` the same `value`. Labels are dimmed to `opacity-50` when disabled.

### TabsContent

Panel shown when its value is active.

Also accepts the props of `React.ComponentProps<typeof TabsPrimitive.Panel>`.

Inactive panels are unmounted unless you set `keepMounted`.

</Only>
