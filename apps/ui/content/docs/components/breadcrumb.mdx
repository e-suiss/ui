A `Breadcrumb` is a labelled `nav` that contains a `BreadcrumbList`. The list holds `BreadcrumbItem` parts separated by `BreadcrumbSeparator` parts. Each item contains either a `BreadcrumbLink` to an ancestor page or, for the last item, a `BreadcrumbPage` for the current page. Use `BreadcrumbEllipsis` inside an item to stand in for collapsed levels.

Use breadcrumbs in deep hierarchies so people can see their location and move up quickly. For top-level navigation between sections, use a navigation menu or tabs.

## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbEllipsis,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@/components/ui/breadcrumb"
```

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="#">Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink href="#">Projects</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Website redesign</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## Composition

Use the following composition to build a `Breadcrumb`:

```text
Breadcrumb
└── BreadcrumbList
    ├── BreadcrumbItem
    │   ├── BreadcrumbLink
    │   ├── BreadcrumbPage
    │   └── BreadcrumbEllipsis
    └── BreadcrumbSeparator
```

## Accessibility

- `Breadcrumb` renders a `nav` with `aria-label="breadcrumb"`.
- `BreadcrumbPage` sets `aria-current="page"`.
- Separators have `role="presentation"` and `aria-hidden="true"`, so only items are announced as list items.
- `BreadcrumbEllipsis` hides its icon and includes visually hidden text, `More` by default; pass children to change it.
- Only links are in the tab order; the ellipsis and current page are skipped.

## API Reference

### Breadcrumb

The `nav` landmark that wraps the trail.

Also accepts the props of `React.ComponentProps<"nav">`.

### BreadcrumbList

The ordered list of items.

Also accepts the props of `React.ComponentProps<"ol">`.

### BreadcrumbItem

A single step in the trail.

Also accepts the props of `React.ComponentProps<"li">`.

### BreadcrumbLink

A link to an ancestor page.

<OnlyBase base="base">

Also accepts the props of `useRender.ComponentProps<"a">`.

`BreadcrumbLink` renders an `a` by default. Use the `render` prop to render your router's link component: `render={<Link href="/" />}`.

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |

Also accepts the props of `React.ComponentProps<"a">`.

`BreadcrumbLink` renders an `a` by default. Set `asChild` and pass your router's link component as the child to render it instead.

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `(props: React.HTMLAttributes<HTMLElement>) => React.ReactNode` | — |

Also accepts the props of `React.ComponentProps<"a">`.

`BreadcrumbLink` renders an `a` by default. Pass a `render` function that returns your router's link component with the props it receives.

</OnlyBase>

Ancestor links use `text-muted-foreground` and the current page uses `text-foreground`.

### BreadcrumbPage

The current page, rendered as plain text.

Also accepts the props of `React.ComponentProps<"span">`.

### BreadcrumbSeparator

A decorative divider between items.

Also accepts the props of `React.ComponentProps<"li">`.

Place a `BreadcrumbSeparator` between items as its own sibling, not inside a `BreadcrumbItem`. It renders a caret by default, which flips in right-to-left layouts; pass children to use a different separator.

### BreadcrumbEllipsis

A placeholder for collapsed levels, with a screen-reader label.

Also accepts the props of `React.ComponentProps<"span">`.

Each part sets a `data-slot`, such as `breadcrumb-list` or `breadcrumb-ellipsis`, for styling.
