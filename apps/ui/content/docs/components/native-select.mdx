`NativeSelect` wraps the browser's `select` element with the library's control styling and a trailing up-down caret. Add choices with `NativeSelectOption`, and group them under headings with `NativeSelectOptGroup`.

Because it uses the platform picker, it works well on touch devices and in plain HTML forms. Use Select when you need a custom-styled popup, rich option content or a searchable list.

## Usage

```tsx
import {
  NativeSelect,
  NativeSelectOptGroup,
  NativeSelectOption,
} from "@/components/ui/native-select"
```

```tsx
<NativeSelect defaultValue="" aria-label="Fruit">
  <NativeSelectOption value="" disabled>
    Select a fruit
  </NativeSelectOption>
  <NativeSelectOption value="apple">Apple</NativeSelectOption>
  <NativeSelectOption value="banana">Banana</NativeSelectOption>
  <NativeSelectOption value="cherry">Cherry</NativeSelectOption>
  <NativeSelectOption value="grape">Grape</NativeSelectOption>
</NativeSelect>
```

## Composition

Use the following composition to build a `NativeSelect`:

```text
NativeSelect
├── NativeSelectOption
└── NativeSelectOptGroup
    └── NativeSelectOption
```

## Accessibility

- Renders a native `select`, exposed as a `combobox` with native keyboard and picker behavior.
- Provide an accessible name with a `Label` linked through `htmlFor`, or with `aria-label`.
- `NativeSelectOptGroup` exposes its `label` as a named `group`.
- Set `aria-invalid` to communicate a validation error; it also applies the invalid styling.
- The caret icon is `aria-hidden`.

## API Reference

### NativeSelect

The wrapper and native `select` element, with a decorative caret icon.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"sm" \| "default"` | `"default"` |

Also accepts the props of `Omit<React.ComponentProps<"select">, "size">`. They go to the `select` element, except `className`, which goes to the wrapper.

Standard attributes such as `value`, `defaultValue`, `onChange`, `name` and `required` work as on a plain `select`. The `size` prop replaces the native `size` attribute. To show a placeholder, add a first option with `value=""` and `disabled`; while it is selected, the text uses `text-muted-foreground`.

### NativeSelectOption

A single choice, rendered as an `option` element.

Also accepts the props of `React.ComponentProps<"option">`.

### NativeSelectOptGroup

A labelled group of options, rendered as an `optgroup` element.

Also accepts the props of `React.ComponentProps<"optgroup">`.

Options and groups use the `Canvas` and `CanvasText` system colors so the native popup stays legible in light and dark modes. Each part sets a `data-slot`, such as `native-select-wrapper` or `native-select-option`, for styling. The wrapper and `select` both set `data-size`.
