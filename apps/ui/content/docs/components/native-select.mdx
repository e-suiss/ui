`NativeSelect` wraps the browser's `select` element with the library's control styling and a trailing up-down caret. Add choices with `NativeSelectOption`, and group them under headings with `NativeSelectOptGroup`.

Because it uses the platform picker, it works well on touch devices and in plain HTML forms. Use Select when you need a custom-styled popup, rich option content or a searchable list.

All standard `select` attributes, such as `value`, `defaultValue`, `onChange`, `name`, `disabled` and `required`, pass through to the `select` element. `className` is applied to the wrapper, not the `select`.

To show a placeholder, add a first option with `value=""` and `disabled`; while it is selected, the text uses the secondary label color.

## Accessibility

- Renders a native `select`, exposed as a `combobox` with native keyboard and picker behavior.
- Provide an accessible name with a `Label` linked through `htmlFor`, or with `aria-label`.
- `NativeSelectOptGroup` exposes its `label` as a named `group`.
- Set `aria-invalid` to communicate a validation error; it also applies the invalid styling.
- The caret icon is `aria-hidden`.

## Notes

- Styling hooks: `data-slot` values `native-select-wrapper`, `native-select`, `native-select-icon`, `native-select-option` and `native-select-optgroup`. The wrapper and `select` both expose `data-size`.
- The `size` prop accepts `default` (44px tall) or `sm` (36px tall) and replaces the native `size` attribute.
- Options and groups use the `Canvas` and `CanvasText` system colors so the native popup stays legible in light and dark modes.
- Uses the `control`, `control-disabled`, `danger` and `label-secondary` tokens.
