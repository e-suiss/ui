A `Bubble` wraps a `BubbleContent`, which renders the rounded message body. Add `BubbleReactions` inside the bubble to pin a reaction pill to its top or bottom edge. Stack bubbles in a `BubbleGroup` to form a conversation.

Align bubbles to the `start` or `end` of the conversation. The tail appears only on the last bubble in a run of consecutive bubbles with the same alignment, and never on the `outline` or `ghost` variants. Use Bubble for chat transcripts and assistant replies; for a full message row with avatar and metadata, see Message.

## Accessibility

- Bubbles are static content by default and contribute no focusable elements.
- When `BubbleContent` renders a `button` or `a`, it is in the tab order and shows a focus ring.
- Reactions are plain content; if they are emoji, consider adding text that screen readers can announce.

## API Reference

### BubbleGroup

A vertical stack of bubbles.

Also accepts the props of `React.ComponentProps<"div">`.

### Bubble

The positioned wrapper that sets variant and alignment.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "secondary" \| "muted" \| "tinted" \| "outline" \| "ghost" \| "destructive"` | `"default"` |
| `align` | `"start" \| "end"` | `"start"` |

Also accepts the props of `React.ComponentProps<"div">`.

The `ghost` variant has no background or padding. The tail appears only on the last bubble in a run with the same alignment, and never on `outline` or `ghost`. Bubbles are capped at 80% of the container width, except `ghost`. Bubbles also align to `end` when inside a `message` slot with `data-align="end"`. The background is set through the `--bubble-bg` custom property; set `--bubble-surface` when bubbles sit on a surface other than `--background`, so the tail and reaction ring blend in.

### BubbleContent

The rounded message body, with the tail.

<OnlyBase base="base">

Also accepts the props of `useRender.ComponentProps<"div">`.

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |

Also accepts the props of `React.ComponentProps<"div">`.

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `(props: React.HTMLAttributes<HTMLElement>) => React.ReactNode` | — |

Also accepts the props of `React.ComponentProps<"div">`.

</OnlyBase>

</OnlyBase>

<OnlyBase base="aria">

Renders a `div` by default. Pass a `render` function that returns a `button` or `a` with the props it receives.

</OnlyBase>

### BubbleReactions

A small pill for reactions, overlapping the bubble's edge.

| Prop | Type | Default |
| --- | --- | --- |
| `align` | `"start" \| "end"` | `"end"` |
| `side` | `"top" \| "bottom"` | `"bottom"` |

Also accepts the props of `React.ComponentProps<"div">`.

`side` picks the edge the pill overlaps and `align` its position along that edge. The bubble adds margin on that side so reactions do not overlap neighboring bubbles.

Each part sets a `data-slot`, such as `bubble-content`, for styling. The bubble also sets `data-variant` and `data-align`, and reactions set `data-side` and `data-align`.

</Only>

## API Reference

<Only platform="rn">

### BubbleGroup

Column that decides which bubbles show a tail.

Also accepts the props of `ViewProps`.

### Bubble

One message, aligned to the start or end.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `BubbleVariant` | `"default"` |
| `align` | `BubbleAlign` | - |

Also accepts the props of `ViewProps`.

`align` is `start` or `end` and defaults to `start`; you can also provide a default through `BubbleAlignContext`. The tail mirrors itself for `end` alignment and in right-to-left layouts. Colors follow the system appearance.

### BubbleContent

The bubble itself, optionally pressable.

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `RenderProp<Record<string, unknown>, Record<string, never>>` | - |

Also accepts the props of `React.ComponentProps<typeof Pressable>`, `React.RefAttributes<View>`.

Plain strings are wrapped in `Text`. `BubbleContent` becomes a `Pressable` when you pass `onPress`, `onLongPress` or `render`, and it fades to 80% opacity while pressed. `render` sets the element to render instead of the default view or pressable.

### BubbleReactions

Reaction pill on the edge of a bubble.

| Prop | Type | Default |
| --- | --- | --- |
| `align` | `BubbleAlign` | `"end"` |
| `side` | `"top" \| "bottom"` | `"bottom"` |

Also accepts the props of `ViewProps`.

The bubble adds margin on the reaction side so the pill does not overlap its neighbors.

</Only>
