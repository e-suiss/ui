A `Bubble` wraps a `BubbleContent`, which renders the rounded message body. Add `BubbleReactions` inside the bubble to pin a reaction pill to its top or bottom edge. Stack bubbles in a `BubbleGroup` to form a conversation.

Align bubbles to the `start` or `end` of the conversation. The tail appears only on the last bubble in a run of consecutive bubbles with the same alignment, and never on the `outline` or `ghost` variants. Use Bubble for chat transcripts and assistant replies; for a full message row with avatar and metadata, see Message.

## Usage

<Code lang="tsx" code={"import { BubbleGroup, Bubble, BubbleContent, BubbleReactions } from \"@/components/ui/bubble\""} />

<Code lang="tsx" code={"<div className=\"flex w-96 flex-col\">\n  <Bubble align=\"start\">\n    <BubbleContent>Are we still on for lunch tomorrow?</BubbleContent>\n  </Bubble>\n</div>"} />

Set `align="end"` for messages sent by the current user and leave the default `start` for incoming messages.

`BubbleContent` renders a `div` by default. Use its `render` prop to render a `button` or `a` for tappable bubbles, such as suggested replies; these get hover and focus styles.

`BubbleReactions` defaults to the bottom-end corner. The bubble adds margin on that side so reactions do not overlap neighboring bubbles.

## Accessibility

- Bubbles are static content by default and contribute no focusable elements.
- When `BubbleContent` renders a `button` or `a`, it is in the tab order and shows a focus ring.
- Reactions are plain content; if they are emoji, consider adding text that screen readers can announce.

## Notes

- Styling hooks: `data-slot="bubble"`, `"bubble-content"`, `"bubble-group"` and `"bubble-reactions"`, plus `data-variant` and `data-align` on the bubble and `data-side` and `data-align` on reactions.
- The background is set through the `--bubble-bg` custom property. Set `--bubble-surface` when bubbles sit on a surface other than `--surface`, so the tail and reaction ring blend in.
- Bubbles are capped at 80% of the container width, except the `ghost` variant.
- Bubbles also align to `end` when inside a `message` slot with `data-align="end"`.

`Bubble` lays out one message aligned to the `start` or `end` of the conversation, and `BubbleContent` draws the rounded bubble with an SVG tail on the aligned side. Seven variants are available: `default` (accent), `secondary`, `muted`, `tinted`, `outline`, `ghost` and `destructive`; `outline` and `ghost` have no tail.

`BubbleGroup` stacks messages and shows the tail only on the last bubble of each run from the same side, so consecutive messages read as one block. `BubbleReactions` pins a small reaction pill to the top or bottom edge of a bubble.

## Usage

<Code lang="tsx" code={"import { BubbleGroup, Bubble, BubbleContent, BubbleReactions } from \"@/components/ui/bubble\""} />

<Code lang="tsx" code={"<Bubble align=\"start\">\n  <BubbleContent>Are we still on for lunch tomorrow?</BubbleContent>\n</Bubble>"} />

Wrap each message in `Bubble` and put its text in `BubbleContent`; plain strings are wrapped in `Text`. Set `align="end"` for messages from the current user, or provide a default through `BubbleAlignContext`.

`BubbleContent` becomes a `Pressable` when you pass `onPress`, `onLongPress` or `render`, and its background darkens while pressed. Use `render` to attach it to a trigger such as a context menu.

`BubbleReactions` takes `side` (`top` or `bottom`) and `align` (`start` or `end`), and the bubble adds margin so the pill does not overlap its neighbors.

## Accessibility

- `BubbleContent` gets the `button` role when it has `onPress` or `onLongPress`.
- The tail is hidden from VoiceOver and TalkBack.
- Give long-press bubbles an `accessibilityLabel` that says who sent the message.

## Notes

- The tail mirrors itself for `end` alignment and in right-to-left layouts.
- Uses `bg-accent`, `bg-control`, `bg-surface-secondary` and `bg-danger-surface` tokens with pressed states; light and dark follow the system appearance.
