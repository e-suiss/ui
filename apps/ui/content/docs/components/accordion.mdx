Accordion wraps the accordion primitive of the chosen base. An `Accordion` holds one or more `AccordionItem` parts; each item pairs an `AccordionTrigger` with an `AccordionContent` panel. The trigger renders inside a heading element and shows a caret that flips between down and up as the panel opens and closes.

Use an accordion to shorten long pages of related content, such as FAQs or settings groups, where people only need one or a few sections at a time. For a single show-and-hide region, a collapsible is a lighter fit.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/accordion
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add accordion
```

## Usage

```tsx
import { Accordion, AccordionItem, AccordionTrigger, AccordionContent } from "@/components/ui/accordion"
```

<OnlyBase base="base">

```tsx
<div className="w-96">
  <Accordion>
    {items.map((item) => (
      <AccordionItem key={item.value} value={item.value}>
        <AccordionTrigger>{item.title}</AccordionTrigger>
        <AccordionContent>{item.content}</AccordionContent>
      </AccordionItem>
    ))}
  </Accordion>
</div>
```

Give each `AccordionItem` a unique `value`. By default only one panel is open at a time; opening another closes the previous one. Set `multiple` on `Accordion` to let several panels stay open.

The open state is an array of item values. Use `defaultValue` (for example `["shipping"]`) for uncontrolled use, or `value` with `onValueChange` to control it.

</OnlyBase>

<OnlyBase base="radix">

```tsx
<div className="w-96">
  <Accordion type="single" collapsible>
    {items.map((item) => (
      <AccordionItem key={item.value} value={item.value}>
        <AccordionTrigger>{item.title}</AccordionTrigger>
        <AccordionContent>{item.content}</AccordionContent>
      </AccordionItem>
    ))}
  </Accordion>
</div>
```

Give each `AccordionItem` a unique `value`. Set `type` on `Accordion`: `"single"` keeps one panel open at a time, and `"multiple"` lets several stay open. With `"single"`, add `collapsible` so the open panel can be closed again.

With `type="single"` the open state is one item value; with `type="multiple"` it is an array. Use `defaultValue` (for example `"shipping"` or `["shipping"]`) for uncontrolled use, or `value` with `onValueChange` to control it.

</OnlyBase>

<OnlyBase base="aria">

```tsx
<div className="w-96">
  <Accordion>
    {items.map((item) => (
      <AccordionItem key={item.value} id={item.value}>
        <AccordionTrigger>{item.title}</AccordionTrigger>
        <AccordionContent>{item.content}</AccordionContent>
      </AccordionItem>
    ))}
  </Accordion>
</div>
```

Give each `AccordionItem` a unique `id`. By default only one panel is open at a time; opening another closes the previous one. Set `allowsMultipleExpanded` on `Accordion` to let several panels stay open.

The open state is a set of item ids. Use `defaultExpandedKeys` (for example `["shipping"]`) for uncontrolled use, or `expandedKeys` with `onExpandedChange` to control it.

</OnlyBase>

## Accessibility

- Each trigger is a `button` with `aria-expanded` reflecting its panel's state.
- Triggers are wrapped in a heading element.
- Triggers are reachable with Tab; `Enter` and `Space` toggle the focused panel.
- Disabled triggers receive `aria-disabled` and are dimmed with `opacity-50`.

## Notes

- Styling hooks: `data-slot="accordion"`, `"accordion-item"`, `"accordion-trigger"`, `"accordion-trigger-icon"` and `"accordion-content"`.

<OnlyBase base="base">

- The panel animates with `animate-accordion-down` and `animate-accordion-up` on `data-open` and `data-closed`.

</OnlyBase>

<OnlyBase base="radix">

- The panel animates with `animate-accordion-down` and `animate-accordion-up` on `data-state="open"` and `data-state="closed"`.

</OnlyBase>

<OnlyBase base="aria">

- The panel animates open with `animate-accordion-down` inside an expanded item, and renders its content only while the item is expanded.

</OnlyBase>

- `className` on `AccordionContent` applies to the inner padded wrapper, not the animated panel.

</Only>

`Accordion` groups `AccordionItem`s, each with an `AccordionTrigger` and an `AccordionContent` panel. The root and items are Reanimated views with a layout transition, so items below move smoothly as a panel opens or closes, and the trigger's caret rotates as it opens.

The `default` variant draws items on the page background separated by hairlines. The `filled` variant puts the whole list on a rounded `bg-muted` surface, which suits grouped settings or FAQ cards.

## Usage

<Only platform="rn">

```tsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from "@/components/ui/accordion"
import { Text } from "@/components/ui/text"

const items = [
  {
    value: "item-1",
    title: "Is it accessible?",
    content: "Yes. It works with VoiceOver and TalkBack.",
  },
  {
    value: "item-2",
    title: "Is it styled?",
    content:
      "Yes. It comes with default styles that match the other components.",
  },
  {
    value: "item-3",
    title: "Is it animated?",
    content: "Yes. It animates open and closed by default.",
  },
]

function AccordionItems() {
  return items.map((item) => (
    <AccordionItem key={item.value} value={item.value}>
      <AccordionTrigger>
        <Text>{item.title}</Text>
      </AccordionTrigger>
      <AccordionContent>
        <Text>{item.content}</Text>
      </AccordionContent>
    </AccordionItem>
  ))
}

export function AccordionExample() {
  return (
    <Accordion>
      <AccordionItems />
    </Accordion>
  )
}
```

  let title: LocalizedStringKey

@MainActor let accordionEntries = [

  AccordionEntry(

    title: "Is it styled?",
    content: "Yes. It comes with default styles that match the other components."
  ),
  AccordionEntry(value: "item-3", title: "Is it animated?", content: "Yes. It animates open and closed by default."),

  var body: some View {
    ForEach(accordionEntries) { entry in

        Text(entry.content)

    }
  }

<Only platform="kotlin">

```kotlin
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.saveable.rememberSaveable
import androidx.compose.runtime.setValue
import com.esuiss.ui.components.Accordion
import com.esuiss.ui.components.AccordionItem
import com.esuiss.ui.components.AccordionVariant
import com.esuiss.ui.components.Text

@Composable
fun AccordionExample() {
    AccordionSingle(AccordionVariant.Default, "")
}

class AccordionEntry(val value: String, val title: String, val content: String)

val accordionEntries = listOf(
    AccordionEntry("item-1", "Is it accessible?", "Yes. It works with VoiceOver and TalkBack."),
    AccordionEntry("item-2", "Is it styled?", "Yes. It comes with default styles that match the other components."),
    AccordionEntry("item-3", "Is it animated?", "Yes. It animates open and closed by default."),
)

@Composable
fun AccordionItems(open: List<String>, onToggle: (String, Boolean) -> Unit) {
    accordionEntries.forEach { entry ->
        AccordionItem(
            expanded = entry.value in open,
            onExpandedChange = { onToggle(entry.value, it) },
            title = entry.title,
        ) {
            Text(entry.content)
        }
    }
}

@Composable
fun AccordionSingle(variant: AccordionVariant, defaultValue: String) {
    var open by rememberSaveable { mutableStateOf(defaultValue) }
    Accordion(variant = variant) {
        AccordionItems(listOf(open)) { value, expanded -> open = if (expanded) value else "" }
    }
}
```

## Accessibility

- The header row has the `header` role, and the trigger has the `button` role with `expanded` and `disabled` accessibility state.
- Closed panels are hidden from VoiceOver and TalkBack.
- A disabled trigger is shown at 50% opacity.

## Notes

- The trigger label underlines while pressed.
- Animations respect the system Reduce Motion setting.
- Uses `bg-muted`, `border-border` and `text-foreground` tokens; light and dark follow the system appearance.
