Accordion wraps the Base UI Accordion primitive. An `Accordion` holds one or more `AccordionItem` parts; each item pairs an `AccordionTrigger` with an `AccordionContent` panel. The trigger renders inside a heading element and shows a caret that flips between down and up as the panel opens and closes.

Use an accordion to shorten long pages of related content, such as FAQs or settings groups, where people only need one or a few sections at a time. For a single show-and-hide region, a collapsible is a lighter fit.

Give each `AccordionItem` a unique `value`. By default only one panel is open at a time; opening another closes the previous one. Set `multiple` on `Accordion` to let several panels stay open.

The open state is an array of item values. Use `defaultValue` (for example `["shipping"]`) for uncontrolled use, or `value` with `onValueChange` to control it.

## Accessibility

- Each trigger is a `button` with `aria-expanded` reflecting its panel's state.
- Triggers are wrapped in a heading element provided by Base UI.
- Triggers are reachable with Tab; `Enter` and `Space` toggle the focused panel.
- Disabled triggers receive `aria-disabled` and are styled with `text-label-quaternary`.

## Notes

- Styling hooks: `data-slot="accordion"`, `"accordion-item"`, `"accordion-trigger"`, `"accordion-trigger-icon"` and `"accordion-content"`.
- The panel animates with `animate-accordion-down` and `animate-accordion-up` on `data-open` and `data-closed`.
- `className` on `AccordionContent` applies to the inner padded wrapper, not the animated panel.

`Accordion` groups `AccordionItem`s, each with an `AccordionTrigger` and an `AccordionContent` panel. The root and items are Reanimated views with a layout transition, so items below move smoothly as a panel opens or closes, and the trigger's caret rotates as it opens.

The `default` variant draws items on the page background separated by hairlines. The `filled` variant puts the whole list on a rounded secondary surface, which suits grouped settings or FAQ cards.

## Usage

<Code lang="tsx" code={"import { Accordion, AccordionItem, AccordionTrigger, AccordionContent } from \"@/components/ui/accordion\""} />

Use `defaultValue` (an array of item values) for uncontrolled state, or `value` with `onValueChange` to control it. Set `disabled` on the root or on a single item to block toggling, and `keepMounted` to keep closed panels mounted.

`accordionVariants` is also exported if you need the classes elsewhere.

## Accessibility

- The header row has the `header` role, and the trigger has the `button` role with `expanded` and `disabled` accessibility state.
- Closed panels are hidden from VoiceOver and TalkBack.
- A disabled trigger uses a dimmed label color.

## Notes

- The trigger label underlines while pressed.
- Animations respect the system Reduce Motion setting.
- Uses `bg-surface-secondary`, `border-separator` and `text-label` tokens; light and dark follow the system appearance.
