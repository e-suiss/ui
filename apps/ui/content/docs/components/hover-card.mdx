`HoverCard` wraps the Base UI Preview Card. The `HoverCard` root manages the open state, `HoverCardTrigger` renders the link that opens it, and `HoverCardContent` renders the floating card in a portal, positioned next to the trigger.

Use a hover card for supplementary, non-essential previews, such as a profile summary behind a username. Because it only opens on hover or focus, do not put content there that people need to complete a task. For interactive content opened with a click, use a popover.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add hover-card
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @base-ui/react cn
```

2. Copy the source into `components/ui/hover-card.tsx`:

<ComponentSource path="components/ui/hover-card.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { HoverCard, HoverCardTrigger, HoverCardContent } from "@/components/ui/hover-card"
```

```tsx
<HoverCard>
  <HoverCardTrigger
    href="#"
    className={buttonVariants({ variant: "link" })}
  >
    @nextjs
  </HoverCardTrigger>
  <HoverCardContent className="w-80">
    <div className="flex gap-4">
      <Avatar size="lg">
        <AvatarImage src="https://github.com/vercel.png" alt="@nextjs" />
        <AvatarFallback>NJ</AvatarFallback>
      </Avatar>
      <div className="flex flex-col gap-1">
        <h4 className="text-sm font-semibold">@nextjs</h4>
        <p className="text-sm">
          The React framework, created and maintained by @vercel.
        </p>
        <div className="text-label-secondary mt-1 flex items-center gap-1.5 text-xs">
          <CalendarBlankIcon />
          Joined December 2021
        </div>
      </div>
    </div>
  </HoverCardContent>
</HoverCard>
```

The trigger renders an anchor, so give it an `href`. Position the card with the `side`, `sideOffset`, `align` and `alignOffset` props on `HoverCardContent`; by default it opens on the `bottom`, centered, with a `4` pixel offset. Set `defaultOpen` on the root to start open, or control it with `open` and `onOpenChange`.

## Accessibility

- The trigger renders as a link and is reachable with Tab.
- The card opens when the pointer rests on the trigger or when the trigger receives keyboard focus, and closes when the pointer leaves.
- The card is a visual preview; make sure the same information is available elsewhere, for example on the linked page.

## Notes

- Styling hooks: `data-slot` values `hover-card`, `hover-card-trigger` and `hover-card-content`.
- `HoverCardContent` receives `data-side` from Base UI, which drives the slide-in direction, along with `data-open` and `data-closed` for the fade and zoom animation.
- The card is `w-72` by default; override it with `className`.
- Uses the `surface-raised` and `label` tokens.
