`HoverCard` wraps the hover card primitive of the chosen base. The `HoverCard` root manages the open state, `HoverCardTrigger` renders the link that opens it, and `HoverCardContent` renders the floating card in a portal, positioned next to the trigger.

Use a hover card for supplementary, non-essential previews, such as a profile summary behind a username. Because it only opens on hover or focus, do not put content there that people need to complete a task. For interactive content opened with a click, use a popover.

## Usage

```tsx
import { HoverCard, HoverCardTrigger, HoverCardContent } from "@/components/ui/hover-card"
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
import { buttonVariants } from "@/components/ui/button"
```

```tsx
<HoverCard>
  <HoverCardTrigger
    href="#"
    className={buttonVariants({ variant: "link" })}
  >
    @nextjs
  </HoverCardTrigger>
  <HoverCardContent className="w-80">
    <div className="flex gap-4">
      <Avatar size="lg">
        <AvatarImage src="https://github.com/vercel.png" alt="@nextjs" />
        <AvatarFallback>NJ</AvatarFallback>
      </Avatar>
      <div className="flex flex-col gap-1">
        <h4 className="text-sm font-semibold">@nextjs</h4>
        <p className="text-sm">
          The React framework, created and maintained by @vercel.
        </p>
        <div className="text-muted-foreground mt-1 flex items-center gap-1.5 text-xs">
          <CalendarBlankIcon />
          Joined December 2021
        </div>
      </div>
    </div>
  </HoverCardContent>
</HoverCard>
```

## Composition

Use the following composition to build a `HoverCard`:

```text
HoverCard
├── HoverCardTrigger
└── HoverCardContent
```

### Sides

Use the `side` prop on `HoverCardContent` to open the card on the `top`, `right`, `bottom` or `left` of its trigger.

## Accessibility

- The trigger renders as a link and is reachable with Tab.
- The card opens when the pointer rests on the trigger or when the trigger receives keyboard focus, and closes when the pointer leaves.
- The card is a visual preview; make sure the same information is available elsewhere, for example on the linked page.

## API Reference

### HoverCard

The root that manages the card's open state. It renders no element of its own.

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base radix">

Set `defaultOpen` to start open, or control it with `open` and `onOpenChange`.

</OnlyBase>

<OnlyBase base="aria">

Set `defaultOpen` to start open, or control it with `isOpen` and `onOpenChange`.

</OnlyBase>

### HoverCardTrigger

The link that opens the card on hover or focus.

Also accepts the props of the primitive part it wraps.

The trigger renders an anchor, so give it an `href`.

### HoverCardContent

The floating card, rendered in a portal and positioned relative to the trigger.

<OnlyBase base="base aria">

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `sideOffset` | `number` | `4` |
| `align` | `"start" \| "center" \| "end"` | `"center"` |
| `alignOffset` | `number` | `4` |

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` |
| `sideOffset` | `number` | `4` |
| `align` | `"start" \| "center" \| "end"` | `"center"` |
| `alignOffset` | `number` | `4` |

</OnlyBase>

Also accepts the props of the primitive parts it wraps.

`side` picks the side of the trigger the card opens on, and `align` how it lines up along that side. `sideOffset` is the gap in pixels between the trigger and the card, and `alignOffset` the offset in pixels along the alignment axis. The card is `w-72` by default; override it with `className`. It slides in from the side it opens on, and fades and zooms as it opens and closes.

Each part sets a `data-slot`, such as `hover-card-trigger` or `hover-card-content`, for styling.

</Only>
