`InputGroup` is the container that draws the field's background, border and focus ring. Inside it, place one control, either `InputGroupInput` or `InputGroupTextarea`, and one or more `InputGroupAddon` elements. An addon can hold icons, `InputGroupText`, `InputGroupButton` or a `Kbd`, and is placed before, after, above or below the control with its `align` prop.

Use an input group when supporting content belongs inside the field, such as a search icon, a currency symbol, a clear button or a send button. For a plain field, use `Input`; for a field with a filterable list of options, use `Combobox`, which is built on this component.

## Usage

```tsx
import { InputGroup, InputGroupAddon, InputGroupButton, InputGroupText, InputGroupInput, InputGroupTextarea } from "@/components/ui/input-group"
```

```tsx
<div className="w-96">
  <InputGroup>
    <InputGroupInput placeholder="Search..." />
    <InputGroupAddon>
      <MagnifyingGlassIcon />
    </InputGroupAddon>
    <InputGroupAddon align="inline-end">12 results</InputGroupAddon>
  </InputGroup>
</div>
```

Addons are positioned with CSS order, so you can place them before or after the control in your markup. `inline-start` and `inline-end` sit beside the control; `block-start` and `block-end` sit above or below it and make the group grow to fit. Clicking an addon outside its buttons focuses the group's `input`.

`InputGroupButton` defaults to `type="button"`, so it does not submit a surrounding form unless you set `type="submit"`. Set `aria-invalid` on the control to show the error style on the whole group. To dim a disabled group's addons, disable the control and set `data-disabled="true"` on `InputGroup`.

The container that draws the field and holds the control and addons.

<ApiPart index={2}>

### InputGroupAddon

Holds icons, text or buttons beside, above or below the control.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `align` | `"inline-start" \| "inline-end" \| "block-start" \| "block-end"` | `"inline-start"` | Places the addon before (`inline-start`) or after (`inline-end`) the control, or above (`block-start`) or below (`block-end`) it. |

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

<ApiPart index={3}>

### InputGroupButton

A compact button sized to fit inside the field.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"xs" \| "sm" \| "icon-xs" \| "icon-sm"` | `"xs"` | `xs` for a small text button, or `icon-xs` and `icon-sm` for square icon buttons. `sm` keeps the base button size. |
| `type` | `"button" \| "submit" \| "reset"` | `"button"` | The native button type. Defaults to `button` so the button does not submit forms. |

Also accepts the props of `React.ComponentProps<typeof Button>`.

</ApiPart>

<ApiPart index={4}>

### InputGroupText

Static text or an icon with text, such as a unit or prefix.

Also accepts the props of `React.ComponentProps<"span">`.

</ApiPart>

<ApiPart index={5}>

### InputGroupInput

The single-line text control of the group.

Also accepts the props of `React.ComponentProps<"input">`.

</ApiPart>

<ApiPart index={6}>

### InputGroupTextarea

The multi-line text control of the group.

Also accepts the props of `React.ComponentProps<"textarea">`.

</ApiPart>

## Accessibility

- `InputGroup` and `InputGroupAddon` have the `group` role.
- Give the control an accessible name with a label or `aria-label`; placeholder text and addon text do not name it.
- Give icon-only buttons an accessible name with `aria-label`.
- Buttons in addons are reachable with Tab after the control.
- Set `aria-invalid` on the control to communicate a validation error.

## Notes

- Styling hooks: `data-slot` values `input-group`, `input-group-addon` and `input-group-control` (on the input or textarea). Addons set `data-align`, and buttons set `data-size`.
- The group's rounded corners grow when it contains a textarea or a block addon.
- Uses the `secondary`, `muted-foreground` and `destructive` colors, and `opacity-50` when disabled.

import { CopyIcon, MagnifyingGlassIcon, XIcon } from "phosphor-react-native"
import * as React from "react"

function SearchDemo() {
  const [value, setValue] = React.useState("")
  return (

        value={value}

            accessibilityLabel="Clear"
            onPress={() => setValue("")}

            <Icon as={XIcon} />
          </InputGroupButton>
        </InputGroupAddon>
      ) : null}
    </InputGroup>
  )
}

## Accessibility

- The container has the `group` role.
- Addons are not separate accessibility elements; their text is not announced with the input, so give the input an `accessibilityLabel` that includes needed context.
- Icon-only buttons need an `accessibilityLabel`.

## Notes

- Uses `bg-secondary`, `border-ring`, `border-destructive` tokens, with `opacity-50` when disabled; the invalid tint is stronger in dark mode.
- In Uniwind and NativeWind, a focused field also draws the `ring-3 ring-ring/50` focus ring.
- Light and dark follow the system appearance.
