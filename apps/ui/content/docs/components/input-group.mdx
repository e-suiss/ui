`InputGroup` is the container that draws the field's background, border and focus ring. Inside it, place one control, either `InputGroupInput` or `InputGroupTextarea`, and one or more `InputGroupAddon` elements. An addon can hold icons, `InputGroupText`, `InputGroupButton` or a `Kbd`, and is placed before, after, above or below the control with its `align` prop.

Use an input group when supporting content belongs inside the field, such as a search icon, a currency symbol, a clear button or a send button. For a plain field, use `Input`; for a field with a filterable list of options, use `Combobox`, which is built on this component.

## Composition

Use the following composition to build a `InputGroup`:

```text
InputGroup
├── InputGroupInput
├── InputGroupAddon
│   ├── InputGroupText
│   └── InputGroupButton
└── InputGroupTextarea
```

## Accessibility

- `InputGroup` and `InputGroupAddon` have the `group` role.
- Give the control an accessible name with a label or `aria-label`; placeholder text and addon text do not name it.
- Give icon-only buttons an accessible name with `aria-label`.
- Buttons in addons are reachable with Tab after the control.
- Set `aria-invalid` on the control to communicate a validation error.

## API Reference

### InputGroup

The container that draws the field and holds the control and addons.

Also accepts the props of `React.ComponentProps<"div">`.

Its rounded corners grow when it contains a textarea or a block addon. Each part sets a `data-slot`, such as `input-group-addon`, for styling; the input and textarea use `input-group-control`.

### InputGroupAddon

Holds icons, text or buttons beside, above or below the control.

| Prop | Type | Default |
| --- | --- | --- |
| `align` | `"inline-start" \| "inline-end" \| "block-start" \| "block-end"` | `"inline-start"` |

Also accepts the props of `React.ComponentProps<"div">`.

`align` places the addon before (`inline-start`) or after (`inline-end`) the control, or above (`block-start`) or below (`block-end`) it. Addons are positioned with CSS order, so you can place them before or after the control in your markup. Clicking an addon outside its buttons focuses the group's `input`. The addon sets `data-align`.

### InputGroupButton

A compact button sized to fit inside the field.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"xs" \| "sm" \| "icon-xs" \| "icon-sm"` | `"xs"` |
| `type` | `"button" \| "submit" \| "reset"` | `"button"` |

Also accepts the props of `React.ComponentProps<typeof Button>`.

`xs` is a small text button, and `icon-xs` and `icon-sm` are square icon buttons; `sm` keeps the base button size. `type` defaults to `button`, so the button does not submit a surrounding form unless you set `type="submit"`. The button sets `data-size`.

### InputGroupText

Static text or an icon with text, such as a unit or prefix.

Also accepts the props of `React.ComponentProps<"span">`.

### InputGroupInput

The single-line text control of the group.

Also accepts the props of `React.ComponentProps<"input">`.

### InputGroupTextarea

The multi-line text control of the group.

Also accepts the props of `React.ComponentProps<"textarea">`.

`InputGroup` draws one `bg-secondary` field and places an `InputGroupInput` or `InputGroupTextarea` inside it with addons around. Addons can sit on the start or end of the same line (`inline-start`, `inline-end`), or above or below the input (`block-start`, `block-end`), which turns the group into a column.

The group shows the focus border while its input is focused, and reads the disabled and invalid state from a surrounding Field. Pressing an addon focuses the input. Add children in any order; the group sorts start addons before the input and end addons after it. Put short labels such as a URL prefix or a unit in `InputGroupText`, and actions in `InputGroupButton`, a small rounded `Button` that defaults to the `ghost` variant and `xs` size.

import { CopyIcon, MagnifyingGlassIcon, XIcon } from "phosphor-react-native"
import * as React from "react"

  )
}

## Accessibility

- The container has the `group` role.
- Addons are not separate accessibility elements; their text is not announced with the input, so give the input an `accessibilityLabel` that includes needed context.
- Icon-only buttons need an `accessibilityLabel`.

</Only>

## API Reference

<Only platform="rn">

### InputGroup

Field container that lays out the input and addons.

| Prop | Type | Default |
| --- | --- | --- |
| `disabled` | `boolean` | `false` |
| `invalid` | `boolean` | - |

Also accepts the props of `ViewProps`.

Set `invalid` to show the destructive border and tint, or `disabled` to disable the group and its input, or let a Field provide them. In Uniwind and NativeWind, a focused field also draws a `ring-3 ring-ring/50` focus ring.

### InputGroupAddon

Slot for text, icons or buttons beside or around the input.

| Prop | Type | Default |
| --- | --- | --- |
| `align` | `"inline-start" \| "inline-end" \| "block-start" \| "block-end"` | `"inline-start"` |

Also accepts the props of `React.ComponentProps<typeof Pressable>`.

`inline-start` and `inline-end` place the addon on the same line as the input; `block-start` and `block-end` place it above or below and turn the group into a column.

### InputGroupButton

Compact button inside an addon.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"xs" \| "sm" \| "icon-xs" \| "icon-sm"` | `"xs"` |

Also accepts the props of `React.ComponentProps<typeof Button>`.

### InputGroupText

Text inside an addon.

Also accepts the props of `React.ComponentProps<typeof Text>`.

### InputGroupInput

Single-line input without its own border.

Also accepts the props of `React.ComponentProps<typeof Input>`.

### InputGroupTextarea

Multi-line input without its own border.

Also accepts the props of `React.ComponentProps<typeof Textarea>`.

</Only>
