An `Alert` is a rounded container with an optional leading icon, an `AlertTitle`, an optional `AlertDescription` and an optional `AlertAction`. Place the icon as a direct child; the layout switches to a two-column grid so the title and description align beside it.

Use an alert for inline, persistent messages such as updates, warnings or errors. To interrupt the user and require a decision, use Alert Dialog instead; for short-lived notifications, use Toast.

<Code lang="tsx" code={"import { Alert, AlertTitle, AlertDescription, AlertAction } from \"@/components/ui/alert\""} />

<Code lang="tsx" code={"<div className=\"w-96\">\n  <Alert>\n    <InfoIcon weight=\"fill\" />\n    <AlertTitle>Update available</AlertTitle>\n    <AlertDescription>\n      A new version is ready to install. Restart the app to apply it.\n    </AlertDescription>\n  </Alert>\n</div>"} />

Put a Phosphor icon (or any `svg`) first inside `Alert`; it is sized to `size-5` unless it already has a size class. When `AlertDescription` is present the icon spans both rows.

`AlertAction` is positioned in the top-end corner, and the alert reserves end padding for it automatically.

## Accessibility

- `Alert` renders with `role="alert"`, so assistive technology announces its content when it appears.
- Interactive content in `AlertAction` stays in the normal tab order.
- Decorative icons should not need a label; put the meaning in the title text.

## Notes

- Styling hooks: `data-slot="alert"`, `"alert-title"`, `"alert-description"` and `"alert-action"`.
- Both variants use `bg-surface-secondary`; they differ only in icon color (`text-accent` or `text-danger`).
- Links inside the title or description are underlined automatically.

`Alert` is a `View` on a rounded secondary surface with an optional leading icon, a title and description column, and an optional action pinned to the top-end corner. It is static and stays in the layout; it is not a toast or a modal.

Use the `default` variant for neutral information, where the icon uses the accent color, and `destructive` for errors, where the icon uses the danger color.

## Usage

<Code lang="tsx" code={"import { Alert, AlertTitle, AlertDescription, AlertAction } from \"@/components/ui/alert\""} />

<Code lang="tsx" code={"<Alert icon={CheckCircleIcon}>\n  <AlertTitle>Payment successful</AlertTitle>\n  <AlertDescription>\n    Your payment of $29.99 has been processed. A receipt has been sent to\n    your email.\n  </AlertDescription>\n</Alert>"} />

Pass a Phosphor icon component to `icon`, and compose `AlertTitle` and `AlertDescription` as children. Any `AlertAction` child is detected and placed in the corner, and extra end padding is added so the text does not run under it.

Use `iconClassName` to adjust the icon's size or color.
