An `Alert` is a rounded container with an optional leading icon, an `AlertTitle`, an optional `AlertDescription` and an optional `AlertAction`. Place the icon as a direct child; the layout switches to a two-column grid so the title and description align beside it.

Use an alert for inline, persistent messages such as updates, warnings or errors. To interrupt the user and require a decision, use Alert Dialog instead; for short-lived notifications, use Toast.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add alert
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install class-variance-authority cn
```

2. Copy the source into `components/ui/alert.tsx`:

<ComponentSource path="components/ui/alert.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Alert, AlertTitle, AlertDescription, AlertAction } from "@/components/ui/alert"
```

```tsx
<div className="w-96">
  <Alert>
    <InfoIcon weight="fill" />
    <AlertTitle>Update available</AlertTitle>
    <AlertDescription>
      A new version is ready to install. Restart the app to apply it.
    </AlertDescription>
  </Alert>
</div>
```

Put a Phosphor icon (or any `svg`) first inside `Alert`; it is sized to `size-5` unless it already has a size class. When `AlertDescription` is present the icon spans both rows.

`AlertAction` is positioned in the top-end corner, and the alert reserves end padding for it automatically.

## Accessibility

- `Alert` renders with `role="alert"`, so assistive technology announces its content when it appears.
- Interactive content in `AlertAction` stays in the normal tab order.
- Decorative icons should not need a label; put the meaning in the title text.

## Notes

- Styling hooks: `data-slot="alert"`, `"alert-title"`, `"alert-description"` and `"alert-action"`.
- Both variants use `bg-muted`; they differ only in icon color (`text-primary` or `text-destructive`).
- Links inside the title or description are underlined automatically.

`Alert` is a `View` on a rounded secondary surface with an optional leading icon, a title and description column, and an optional action pinned to the top-end corner. It is static and stays in the layout; it is not a toast or a modal.

Use the `default` variant for neutral information, where the icon uses the accent color, and `destructive` for errors, where the icon uses the danger color.

## Usage

```tsx
import { Alert, AlertTitle, AlertDescription, AlertAction } from "@/components/ui/alert"
```

```tsx
<Alert icon={CheckCircleIcon}>
  <AlertTitle>Payment successful</AlertTitle>
  <AlertDescription>
    Your payment of $29.99 has been processed. A receipt has been sent to
    your email.
  </AlertDescription>
</Alert>
```

Pass a Phosphor icon component to `icon`, and compose `AlertTitle` and `AlertDescription` as children. Any `AlertAction` child is detected and placed in the corner, and extra end padding is added so the text does not run under it.

Use `iconClassName` to adjust the icon's size or color.

## API Reference

<ApiPart index={1}>

### Alert

Container with the icon, text column and action.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `icon` | `PhosphorIcon` | - | Phosphor icon component shown before the text. |
| `variant` | `"default" \| "destructive"` | `"default"` | `default` or `destructive`; changes the icon color. |
| `iconClassName` | `string` | - | Extra classes for the icon. |

Also accepts the props of `React.ComponentProps<typeof View>`, `React.RefAttributes<View>`.

</ApiPart>

<ApiPart index={2}>

### AlertTitle

Bold first line.

Also accepts the props of `React.ComponentProps<typeof Text>`.

</ApiPart>

<ApiPart index={3}>

### AlertDescription

Secondary-colored supporting text.

Also accepts the props of `React.ComponentProps<typeof Text>`.

</ApiPart>

<ApiPart index={4}>

### AlertAction

Slot positioned in the top-end corner.

Also accepts the props of `React.ComponentProps<typeof View>`, `React.RefAttributes<View>`.

</ApiPart>

## Accessibility

- The container has the `alert` role.
- The icon is decorative; put the meaning in the title or description.

## Notes

- Uses `bg-surface-secondary`, `text-label`, `text-accent` and `text-danger` tokens; light and dark follow the system appearance.
- The action is positioned with `end-4`, so it flips in right-to-left layouts.
