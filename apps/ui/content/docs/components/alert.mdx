An `Alert` is a rounded container with an optional leading icon, an `AlertTitle`, an optional `AlertDescription` and an optional `AlertAction`. Place the icon as a direct child; the layout switches to a two-column grid so the title and description align beside it.

Use an alert for inline, persistent messages such as updates, warnings or errors. To interrupt the user and require a decision, use Alert Dialog instead; for short-lived notifications, use Toast.

## Accessibility

- `Alert` renders with `role="alert"`, so assistive technology announces its content when it appears.
- Interactive content in `AlertAction` stays in the normal tab order.
- Decorative icons should not need a label; put the meaning in the title text.

## API Reference

### Alert

The container that lays out the icon, text and action.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "destructive"` | `"default"` |

Also accepts the props of `React.ComponentProps<"div">`.

Put an icon from your icon library, or any `svg`, first inside `Alert`; it is sized to `size-5` unless it already has a size class. When `AlertDescription` is present the icon spans both rows. Both variants use `bg-muted` and differ only in icon color: `default` uses `text-primary` and `destructive` uses `text-destructive`. Links inside the title or description are underlined automatically.

### AlertTitle

The bold headline of the message.

Also accepts the props of `React.ComponentProps<"div">`.

### AlertDescription

Secondary text that explains the message.

Also accepts the props of `React.ComponentProps<"div">`.

### AlertAction

An absolutely positioned slot for a button or link in the top-end corner.

Also accepts the props of `React.ComponentProps<"div">`.

The alert reserves end padding for the action automatically. Each part sets a `data-slot`, such as `alert-title` or `alert-action`, for styling.

</Only>

## API Reference

<Only platform="rn">

### Alert

Container with the icon, text column and action.

| Prop | Type | Default |
| --- | --- | --- |
| `icon` | `PhosphorIcon` | - |
| `variant` | `"default" \| "destructive"` | `"default"` |
| `iconClassName` | `string` | - |

Also accepts the props of `React.ComponentProps<typeof View>`, `React.RefAttributes<View>`.

Pass a Phosphor icon component to `icon` to show it before the text, and use `iconClassName` to adjust its size or color. `variant` changes the icon color. Compose `AlertTitle` and `AlertDescription` as children.

### AlertTitle

Bold first line.

Also accepts the props of `React.ComponentProps<typeof Text>`.

### AlertDescription

Secondary-colored supporting text.

Also accepts the props of `React.ComponentProps<typeof Text>`.

### AlertAction

Slot positioned in the top-end corner.

Also accepts the props of `React.ComponentProps<typeof View>`, `React.RefAttributes<View>`.

Any `AlertAction` child is detected and placed in the corner, and extra end padding is added so the text does not run under it. The action is positioned with `end-4`, so it flips in right-to-left layouts.

</Only>
