`Questionnaire` renders a `form` that presents a sequence of questions, one at a time. Each `QuestionnaireItem` is a `fieldset` with a `QuestionnaireTitle`, an optional `QuestionnaireDescription`, an answer area and a `QuestionnaireError`. Answers are either `QuestionnaireChoices` holding `QuestionnaireChoice` cards (with optional `QuestionnaireChoiceDescription`), or a `QuestionnaireInput`.

`QuestionnaireProgress` shows the current position, and `QuestionnaireActions` lays out `QuestionnairePrevious`, `QuestionnaireSkip`, `QuestionnaireNext` and `QuestionnaireSubmit`, which show and hide themselves based on the current question. Use Questionnaire for onboarding flows and surveys; use Field and regular form controls when all fields should be visible at once.

## Accessibility

- Each item is a `fieldset` named by its `legend` title; inactive items are `hidden` and `inert`.
- Choices are native radio buttons or checkboxes inside a `label`. A choice description is linked with `aria-describedby`.
- `QuestionnaireInput` is labelled by the question title unless you pass `aria-label`.
- The item's description and, when invalid, its error are linked with `aria-describedby`. The error uses `role="alert"` and focus moves to the invalid answer.
- `QuestionnaireProgress` has `role="progressbar"`, an `aria-label` of `Questionnaire progress`, `aria-valuetext` and `aria-live="polite"`.
- Keyboard: Enter on an answered control advances or submits; Command or Control plus Enter advances from anywhere; ArrowUp and ArrowDown move between answers; outside text fields and radio buttons, ArrowLeft goes back and ArrowRight goes forward once the question has an answer. The active item lists these in `aria-keyshortcuts`.
- Hidden navigation buttons are `aria-hidden`, `inert` and removed from the tab order.

## API Reference

### Questionnaire

The `form` root that tracks the active question and handles navigation and submission.

| Prop | Type | Default |
| --- | --- | --- |
| `defaultItem` | `string` | - |
| `item` | `string` | - |
| `items` | `readonly QuestionnaireItemDefinition[]` | - |
| `onItemChange` | `(item: string) => void` | - |
| `shortcuts` | `QuestionnaireShortcutMode` | - |

Also accepts the props of `React.ComponentProps<"form">`.

The first item is shown by default. Use `defaultItem` to start elsewhere, or `item` with `onItemChange` to control the active question; `onItemChange` is called with the next item's `name`. Pass `items` (each with `name`, `required`, `disabled` and `choices`) to define the sequence and the order used for shortcut keys, instead of deriving them from the rendered items. `shortcuts` enables single-key answers with `letters` (A to Z) or `numbers` (1 to 9). Native browser validation is off by default (`noValidate`); the component runs its own validation on Next and Submit.

### QuestionnaireItem

A `fieldset` for one question, visible only while it is active.

| Prop | Type | Default |
| --- | --- | --- |
| `disabled` | `boolean` | `false` |
| `invalid` | `boolean` | `false` |
| `multiple` | `boolean` | `false` |
| `name` | `string` | Required |
| `onStatusChange` | `(status: QuestionnaireItemStatus) => void` | - |
| `required` | `boolean` | `false` |

Also accepts the props of `React.ComponentProps<"fieldset">`.

Give every item a unique `name`; it is used for navigation and answers are submitted as form data under it. A `required` item blocks Next and Submit until it is answered and hides the Skip button. A `disabled` item is left out of the sequence. `multiple` renders the choices as checkboxes instead of radio buttons, and `invalid` forces the invalid state. `onStatusChange` is called when the status changes between `unanswered`, `answered` and `skipped`.

`Questionnaire` is a `View` that tracks which question is active, collects answers and validates them. Each `QuestionnaireItem` is one question; only the active item is shown, and moving between items slides the content horizontally with a Reanimated keyframe that follows the layout direction.

Items hold `QuestionnaireChoice` rows, which are `Pressable` radios or, with `multiple`, checkboxes, or a `QuestionnaireInput` for a typed answer. `QuestionnaireActions` holds the Previous, Skip, Next and Submit buttons, each of which only appears when it applies.

<Only platform="swift">

```swift
import SwiftUI

struct QuestionnaireStoryActions: View {
  var body: some View {
    QuestionnaireActions {
      QuestionnairePrevious()
      QuestionnaireSkip()
      QuestionnaireNext()
      QuestionnaireSubmit()
    }
  }
}

struct QuestionnaireOnboarding: View {
  var attempted = false

  @State private var controller: QuestionnaireController
  @State private var submitted: String?

  init(defaultItem: String? = nil, attempted: Bool = false) {
    self.attempted = attempted
    _controller = State(initialValue: QuestionnaireController(
      defaultItem: defaultItem,
      defaultValues: ["team-size": ["small"]]
    ))
  }

  var body: some View {
    VStack(alignment: .leading, spacing: 16) {
      Questionnaire(controller: controller) {
        QuestionnaireProgress()
        QuestionnaireItem(name: "role", required: true, invalid: attempted) {
          QuestionnaireTitle("What best describes your role?")
          QuestionnaireDescription("This helps us tailor the setup to your team.")
          QuestionnaireChoices {
            QuestionnaireChoice("Engineering", value: "engineering")
            QuestionnaireChoice("Design", value: "design")
            QuestionnaireChoice("Product", value: "product")
            QuestionnaireChoice("Something else", value: "other")
          }
          QuestionnaireError()
        }
        QuestionnaireItem(name: "team-size") {
          QuestionnaireTitle("How large is your team?")
          QuestionnaireChoices {
            QuestionnaireChoice("Just me", value: "solo")
            QuestionnaireChoice("2 to 10 people", value: "small")
            QuestionnaireChoice("11 to 50 people", value: "medium")
            QuestionnaireChoice("More than 50 people", value: "large")
          }
          QuestionnaireError()
        }
        QuestionnaireItem(name: "company", required: true) {
          QuestionnaireTitle("What is your company called?")
          QuestionnaireInput("Acme Inc.")
          QuestionnaireError("Enter a company name to continue.")
        }
        QuestionnaireStoryActions()
      }
      if let submitted {
        Text(verbatim: submitted)
          .textStyle(.sm)
          .foregroundStyle(EsuissColor.mutedForeground)
          .accessibilityAddTraits(.updatesFrequently)
      }
    }
    .frame(maxWidth: .infinity, alignment: .leading)
    .onAppear {
      let controller = controller
      controller.onSubmit = { answers in
        let fields = controller.sequence.compactMap { name -> String? in
          guard let value = answers[name]?.first else { return nil }
          return "\"\(name)\":\"\(value)\""
        }
        submitted = "Submitted: {\(fields.joined(separator: ","))}"
      }
    }
  }
}
```

fun questionnaireJson(values: Map<String, List<String>>): String =
    values.entries.joinToString(",", "{", "}") { (key, list) ->
        "\"$key\":" + list.joinToString(",", "[", "]") { "\"$it\"" }
    }

@Composable
fun QuestionnaireActionsRow() {
    QuestionnaireActions {
        QuestionnairePrevious()
        QuestionnaireSkip()
        QuestionnaireNext()
        QuestionnaireSubmit()
    }
}

@Composable
fun QuestionnaireResult(values: String?) {
    if (values == null) return
    Text(
        "Submitted: $values",
        modifier = Modifier.semantics { liveRegion = LiveRegionMode.Polite },
        style = Typography.sm,
        color = EsuissTheme.colors.mutedForeground,
    )
}

@Composable
fun QuestionnaireOnboarding(defaultItem: String? = null, attempted: Boolean = false) {
    var values by rememberSaveable { mutableStateOf<String?>(null) }
    val state = rememberQuestionnaireState(defaultItem = defaultItem)
    Column(Modifier.fillMaxWidth(), verticalArrangement = Arrangement.spacedBy(16.dp)) {
        Questionnaire(state = state, onSubmit = { values = questionnaireJson(it) }) {
            QuestionnaireProgress()
            QuestionnaireItem(name = "role", required = true, invalid = attempted) {
                QuestionnaireTitle("What best describes your role?")
                QuestionnaireDescription("This helps us tailor the setup to your team.")
                QuestionnaireChoices {
                    QuestionnaireChoice("Engineering", value = "engineering")
                    QuestionnaireChoice("Design", value = "design")
                    QuestionnaireChoice("Product", value = "product")
                    QuestionnaireChoice("Something else", value = "other")
                }
                QuestionnaireError()
            }
            QuestionnaireItem(name = "team-size") {
                QuestionnaireTitle("How large is your team?")
                QuestionnaireChoices {
                    QuestionnaireChoice("Just me", value = "solo")
                    QuestionnaireChoice("2 to 10 people", value = "small", defaultChecked = true)
                    QuestionnaireChoice("11 to 50 people", value = "medium")
                    QuestionnaireChoice("More than 50 people", value = "large")
                }
                QuestionnaireError()
            }
            QuestionnaireItem(name = "company", required = true) {
                QuestionnaireTitle("What is your company called?")
                QuestionnaireInput(placeholder = "Acme Inc.")
                QuestionnaireError("Enter a company name to continue.")
            }
            QuestionnaireActionsRow()
        }
        QuestionnaireResult(values)
    }
}

## Accessibility

- Each item has the `radiogroup` role, or `group` when `multiple`, and is labelled by its `QuestionnaireTitle`, which has the `heading` role.
- Choices have the `radio` or `checkbox` role with checked and disabled states.
- `QuestionnaireInput` is labelled by the title unless you pass an `accessibilityLabel`.
- `QuestionnaireProgress` has the `progressbar` role, a value such as "Question 2 of 3" and a polite live region.
- `QuestionnaireError` has the `alert` role with a polite live region.
- Slide transitions respect the system reduce motion setting.

## API Reference

<Only platform="rn">

### Questionnaire

Root that holds the state and the active question.

| Prop | Type | Default |
| --- | --- | --- |
| `items` | `QuestionnaireItemDefinition[]` | - |
| `item` | `string` | - |
| `defaultItem` | `string` | - |
| `onItemChange` | `(item: string) => void` | - |
| `onSubmit` | `(values: QuestionnaireValues) => void` | - |

Also accepts the props of `React.ComponentProps<typeof View>`, `React.RefAttributes<View>`, `UseQuestionnaireParameters`.

`items` lists the questions in order, each with a `name` and optional `required` and `disabled`. The active item is uncontrolled through `defaultItem` or controlled with `item` and `onItemChange`. `onSubmit` is called when the last question is submitted and receives the collected values: a string for single-answer items and a string array for `multiple` items. Moving between items slides the content horizontally, and the direction flips for right-to-left layouts. Use `useQuestionnaireContext` to build custom controls, or `useQuestionnaire` for the underlying state.

### QuestionnaireProgress

Shows the current question number and total.

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `\| React.ReactNode \| ((state: QuestionnaireState) => React.ReactNode)` | - |

Also accepts the props of `React.ComponentProps<typeof View>`, `React.RefAttributes<View>`.

It shows "Question 1 of 3" by default. Pass a function as `children` to render your own content from the questionnaire state.

### QuestionnaireItem

One question; shown only while active.

| Prop | Type | Default |
| --- | --- | --- |
| `name` | `string` | Required |
| `required` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `invalid` | `boolean` | `false` |
| `multiple` | `boolean` | `false` |
| `onStatusChange` | `(status: QuestionnaireItemStatus) => void` | - |

Also accepts the props of `React.ComponentProps<typeof View>`, `React.RefAttributes<View>`.

Give every item a unique `name`; its answer is collected under that name. A `required` item blocks moving on without an answer and hides Skip. A `disabled` item is removed from the sequence. `onStatusChange` is called when the status changes to `unanswered`, `answered` or `skipped`.

### QuestionnaireTitle

The question heading.

Also accepts the props of `Text`.

### QuestionnaireDescription

Secondary text under the title.

Also accepts the props of `Text`.

### QuestionnaireChoices

Stack of choice rows.

Also accepts the props of `React.ComponentProps<typeof View>`, `React.RefAttributes<View>`.

### QuestionnaireChoice

A selectable answer row.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | Required |
| `checked` | `boolean` | - |
| `defaultChecked` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `onCheckedChange` | `(checked: boolean) => void` | - |
| `children` | `React.ReactNode` | - |

Also accepts the props of `React.ComponentProps<typeof Pressable>`, `React.RefAttributes<View>`.

Use `defaultChecked`, or controlled `checked` with `onCheckedChange`. Selecting a choice plays a selection haptic when a haptics adapter is provided through `HapticsContext`.

### QuestionnaireChoiceDescription

Secondary text inside a choice.

Also accepts the props of `Text`.

### QuestionnaireInput

Text field for a typed answer.

| Prop | Type | Default |
| --- | --- | --- |
| `type` | `QuestionnaireInputType` | `"text"` |

Also accepts the props of `React.ComponentProps<typeof Input>`.

`type` is `text`, `email`, `number`, `tel`, `url`, `password` or `search`, and sets the keyboard, autofill and secure entry.

### QuestionnaireError

Validation message shown when the item is invalid.

Also accepts the props of `Text`.

It has a default message that you can replace with children.

### QuestionnaireActions

Row for the navigation buttons.

Also accepts the props of `React.ComponentProps<typeof View>`, `React.RefAttributes<View>`.

### QuestionnairePrevious

Goes to the previous question.

Also accepts the props of `Button`.

### QuestionnaireSkip

Skips the active question when it is optional.

Also accepts the props of `Button`.

### QuestionnaireNext

Validates and moves to the next question.

Also accepts the props of `Button`.

### QuestionnaireSubmit

Validates all questions and calls `onSubmit` on the last step.

Also accepts the props of `Button`.
