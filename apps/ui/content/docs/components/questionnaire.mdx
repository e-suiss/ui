`Questionnaire` renders a `form` that presents a sequence of questions, one at a time. Each `QuestionnaireItem` is a `fieldset` with a `QuestionnaireTitle`, an optional `QuestionnaireDescription`, an answer area and a `QuestionnaireError`. Answers are either `QuestionnaireChoices` holding `QuestionnaireChoice` cards (with optional `QuestionnaireChoiceDescription`), or a `QuestionnaireInput`.

`QuestionnaireProgress` shows the current position, and `QuestionnaireActions` lays out `QuestionnairePrevious`, `QuestionnaireSkip`, `QuestionnaireNext` and `QuestionnaireSubmit`, which show and hide themselves based on the current question. Use Questionnaire for onboarding flows and surveys; use Field and regular form controls when all fields should be visible at once.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/questionnaire
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add questionnaire
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install @base-ui/react @phosphor-icons/react
```

2. Add the pieces it builds on: [Button](/docs/components/button), `use-questionnaire`.

3. Copy the source into `components/ui/questionnaire.tsx`:

4. Update the import paths to match your project.

## Usage

```tsx
import { Questionnaire, QuestionnaireProgress, QuestionnaireItem, QuestionnaireTitle, QuestionnaireDescription, QuestionnaireChoices, QuestionnaireChoice, QuestionnaireChoiceDescription, QuestionnaireInput, QuestionnaireError, QuestionnaireActions, QuestionnairePrevious, QuestionnaireSkip, QuestionnaireNext, QuestionnaireSubmit } from "@/components/ui/questionnaire"
```

```tsx
<div className="w-[28rem]">
  <Questionnaire onSubmit={(event) => event.preventDefault()}>
    <QuestionnaireProgress />
    <QuestionnaireItem name="role" required>
      <QuestionnaireTitle>What best describes your role?</QuestionnaireTitle>
      <QuestionnaireDescription>
        This helps us tailor the setup to your team.
      </QuestionnaireDescription>
      <QuestionnaireChoices>
        <QuestionnaireChoice value="engineering">
          Engineering
        </QuestionnaireChoice>
        <QuestionnaireChoice value="design">Design</QuestionnaireChoice>
        <QuestionnaireChoice value="product">Product</QuestionnaireChoice>
        <QuestionnaireChoice value="other">
          Something else
        </QuestionnaireChoice>
      </QuestionnaireChoices>
      <QuestionnaireError />
    </QuestionnaireItem>
    <QuestionnaireItem name="team-size">
      <QuestionnaireTitle>How large is your team?</QuestionnaireTitle>
      <QuestionnaireChoices>
        <QuestionnaireChoice value="solo">Just me</QuestionnaireChoice>
        <QuestionnaireChoice value="small">
          2 to 10 people
        </QuestionnaireChoice>
        <QuestionnaireChoice value="medium">
          11 to 50 people
        </QuestionnaireChoice>
        <QuestionnaireChoice value="large">
          More than 50 people
        </QuestionnaireChoice>
      </QuestionnaireChoices>
      <QuestionnaireError />
    </QuestionnaireItem>
    <QuestionnaireItem name="company" required>
      <QuestionnaireTitle>What is your company called?</QuestionnaireTitle>
      <QuestionnaireInput placeholder="Acme Inc." />
      <QuestionnaireError>
        Enter a company name to continue.
      </QuestionnaireError>
    </QuestionnaireItem>
    <QuestionnaireActions>
      <QuestionnairePrevious />
      <QuestionnaireSkip />
      <QuestionnaireNext />
      <QuestionnaireSubmit />
    </QuestionnaireActions>
  </Questionnaire>
</div>
```

Give every item a unique `name`; answers are submitted as form data under that name. The first item is shown by default. Use `defaultItem` to start elsewhere, or `item` with `onItemChange` to control the active question.

A `required` item blocks Next and Submit until it is answered. An optional item shows the Skip button. Set `multiple` on an item to render its choices as checkboxes instead of radio buttons.

Pass `items` to define the sequence, which items are required or disabled, and the order used for shortcut keys, instead of deriving them from the rendered items. Native browser validation is off by default (`noValidate`); the component runs its own validation on Next and Submit.

### Questionnaire

The `form` root that tracks the active question and handles navigation and submission.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultItem` | `string` | - | The `name` of the item shown first when uncontrolled. |
| `item` | `string` | - | The `name` of the active item, for controlled use. |
| `items` | `readonly QuestionnaireItemDefinition[]` | - | Optional item definitions with `name`, `required`, `disabled` and `choices`, used to define the sequence and shortcut order. |
| `onItemChange` | `(item: string) => void` | - | Called with the next item's `name` when the active question changes. |
| `shortcuts` | `QuestionnaireShortcutMode` | - | Enables single-key answer shortcuts using `letters` (A to Z) or `numbers` (1 to 9). |

Also accepts the props of `React.ComponentProps<"form">`.

## Accessibility

- Each item is a `fieldset` named by its `legend` title; inactive items are `hidden` and `inert`.
- Choices are native radio buttons or checkboxes inside a `label`. A choice description is linked with `aria-describedby`.
- `QuestionnaireInput` is labelled by the question title unless you pass `aria-label`.
- The item's description and, when invalid, its error are linked with `aria-describedby`. The error uses `role="alert"` and focus moves to the invalid answer.
- `QuestionnaireProgress` has `role="progressbar"`, an `aria-label` of `Questionnaire progress`, `aria-valuetext` and `aria-live="polite"`.
- Keyboard: Enter on an answered control advances or submits; Command or Control plus Enter advances from anywhere; ArrowUp and ArrowDown move between answers; outside text fields and radio buttons, ArrowLeft goes back and ArrowRight goes forward once the question has an answer. The active item lists these in `aria-keyshortcuts`.
- Hidden navigation buttons are `aria-hidden`, `inert` and removed from the tab order.

## Notes

- Styling hooks: every part sets a `data-slot`, such as `questionnaire`, `questionnaire-item`, `questionnaire-choice`, `questionnaire-choice-indicator`, `questionnaire-choice-shortcut`, `questionnaire-input` and `questionnaire-error`.
- Choices expose `data-checked` or `data-unchecked`, plus `data-type`, `data-disabled`, `data-invalid` and `data-shortcut`. Inputs expose `data-filled` or `data-empty`. Navigation buttons expose `data-visible` or `data-hidden`.
- Shortcut badges are hidden below the `md` breakpoint.
- The default error text is `Choose an answer to continue.` for required items; pass children to customize it.
- Uses the `primary`, `border`, `secondary`, `destructive` and `accent` colors.

`Questionnaire` is a `View` that tracks which question is active, collects answers and validates them. Each `QuestionnaireItem` is one question; only the active item is shown, and moving between items slides the content horizontally with a Reanimated keyframe that follows the layout direction.

Items hold `QuestionnaireChoice` rows, which are `Pressable` radios or, with `multiple`, checkboxes, or a `QuestionnaireInput` for a typed answer. `QuestionnaireActions` holds the Previous, Skip, Next and Submit buttons, each of which only appears when it applies.

<Only platform="swift">

```swift
import EsuissUI
import SwiftUI

struct QuestionnaireStoryActions: View {
  var body: some View {
    QuestionnaireActions {
      QuestionnairePrevious()
      QuestionnaireSkip()
      QuestionnaireNext()
      QuestionnaireSubmit()
    }
  }
}

struct QuestionnaireOnboarding: View {
  var attempted = false

  @State private var controller: QuestionnaireController
  @State private var submitted: String?

  init(defaultItem: String? = nil, attempted: Bool = false) {
    self.attempted = attempted
    _controller = State(initialValue: QuestionnaireController(
      defaultItem: defaultItem,
      defaultValues: ["team-size": ["small"]]
    ))
  }

  var body: some View {
    VStack(alignment: .leading, spacing: 16) {
      Questionnaire(controller: controller) {
        QuestionnaireProgress()
        QuestionnaireItem(name: "role", required: true, invalid: attempted) {
          QuestionnaireTitle("What best describes your role?")
          QuestionnaireDescription("This helps us tailor the setup to your team.")
          QuestionnaireChoices {
            QuestionnaireChoice("Engineering", value: "engineering")
            QuestionnaireChoice("Design", value: "design")
            QuestionnaireChoice("Product", value: "product")
            QuestionnaireChoice("Something else", value: "other")
          }
          QuestionnaireError()
        }
        QuestionnaireItem(name: "team-size") {
          QuestionnaireTitle("How large is your team?")
          QuestionnaireChoices {
            QuestionnaireChoice("Just me", value: "solo")
            QuestionnaireChoice("2 to 10 people", value: "small")
            QuestionnaireChoice("11 to 50 people", value: "medium")
            QuestionnaireChoice("More than 50 people", value: "large")
          }
          QuestionnaireError()
        }
        QuestionnaireItem(name: "company", required: true) {
          QuestionnaireTitle("What is your company called?")
          QuestionnaireInput("Acme Inc.")
          QuestionnaireError("Enter a company name to continue.")
        }
        QuestionnaireStoryActions()
      }
      if let submitted {
        Text(verbatim: submitted)
          .textStyle(.sm)
          .foregroundStyle(EsuissColor.mutedForeground)
          .accessibilityAddTraits(.updatesFrequently)
      }
    }
    .frame(maxWidth: .infinity, alignment: .leading)
    .onAppear {
      let controller = controller
      controller.onSubmit = { answers in
        let fields = controller.sequence.compactMap { name -> String? in
          guard let value = answers[name]?.first else { return nil }
          return "\"\(name)\":\"\(value)\""
        }
        submitted = "Submitted: {\(fields.joined(separator: ","))}"
      }
    }
  }
}
```

```kotlin
fun questionnaireJson(values: Map<String, List<String>>): String =
    values.entries.joinToString(",", "{", "}") { (key, list) ->
        "\"$key\":" + list.joinToString(",", "[", "]") { "\"$it\"" }
    }

@Composable
fun QuestionnaireActionsRow() {
    QuestionnaireActions {
        QuestionnairePrevious()
        QuestionnaireSkip()
        QuestionnaireNext()
        QuestionnaireSubmit()
    }
}

@Composable
fun QuestionnaireResult(values: String?) {
    if (values == null) return
    Text(
        "Submitted: $values",
        modifier = Modifier.semantics { liveRegion = LiveRegionMode.Polite },
        style = Typography.sm,
        color = EsuissTheme.colors.mutedForeground,
    )
}

@Composable
fun QuestionnaireOnboarding(defaultItem: String? = null, attempted: Boolean = false) {
    var values by rememberSaveable { mutableStateOf<String?>(null) }
    val state = rememberQuestionnaireState(defaultItem = defaultItem)
    Column(Modifier.fillMaxWidth(), verticalArrangement = Arrangement.spacedBy(16.dp)) {
        Questionnaire(state = state, onSubmit = { values = questionnaireJson(it) }) {
            QuestionnaireProgress()
            QuestionnaireItem(name = "role", required = true, invalid = attempted) {
                QuestionnaireTitle("What best describes your role?")
                QuestionnaireDescription("This helps us tailor the setup to your team.")
                QuestionnaireChoices {
                    QuestionnaireChoice("Engineering", value = "engineering")
                    QuestionnaireChoice("Design", value = "design")
                    QuestionnaireChoice("Product", value = "product")
                    QuestionnaireChoice("Something else", value = "other")
                }
                QuestionnaireError()
            }
            QuestionnaireItem(name = "team-size") {
                QuestionnaireTitle("How large is your team?")
                QuestionnaireChoices {
                    QuestionnaireChoice("Just me", value = "solo")
                    QuestionnaireChoice("2 to 10 people", value = "small", defaultChecked = true)
                    QuestionnaireChoice("11 to 50 people", value = "medium")
                    QuestionnaireChoice("More than 50 people", value = "large")
                }
                QuestionnaireError()
            }
            QuestionnaireItem(name = "company", required = true) {
                QuestionnaireTitle("What is your company called?")
                QuestionnaireInput(placeholder = "Acme Inc.")
                QuestionnaireError("Enter a company name to continue.")
            }
            QuestionnaireActionsRow()
        }
        QuestionnaireResult(values)
    }
}
```

</Only>

Give every `QuestionnaireItem` a unique `name`; answers are collected under that name. Mark items `required` to block moving on without an answer; optional items show the Skip button. `QuestionnaireError` appears only when the item is invalid and has a default message you can replace.

The active item is uncontrolled through `defaultItem` or controlled with `item` and `onItemChange`. `onSubmit` receives the collected values: a string for single-answer items and a string array for `multiple` items.

<Only platform="rn">

`QuestionnaireChoice` supports `defaultChecked`, or controlled `checked` with `onCheckedChange`. `QuestionnaireInput` takes a `type` that sets the keyboard, autocomplete and secure entry. `QuestionnaireProgress` shows "Question 1 of 3" by default and accepts a render function. Use `useQuestionnaireContext` to build custom controls, or `useQuestionnaire` for the underlying state.

</Only>

## Accessibility

- Each item has the `radiogroup` role, or `group` when `multiple`, and is labelled by its `QuestionnaireTitle`, which has the `heading` role.
- Choices have the `radio` or `checkbox` role with checked and disabled states.
- `QuestionnaireInput` is labelled by the title unless you pass an `accessibilityLabel`.
- `QuestionnaireProgress` has the `progressbar` role, a value such as "Question 2 of 3" and a polite live region.
- `QuestionnaireError` has the `alert` role with a polite live region.
- Slide transitions respect the system reduce motion setting.

## Notes

- Selecting a choice plays a selection haptic when a haptics adapter is provided through `HapticsContext`.
- Selected choices use `border-primary` and `bg-primary`; invalid items use `border-destructive`.
- The slide direction flips for right-to-left layouts.
- Light and dark colors follow the system appearance.
