Popover wraps Base UI's Popover. `Popover` is the root that holds the open state, `PopoverTrigger` toggles it, and `PopoverContent` renders the positioned panel in a portal. Inside the content, `PopoverHeader` groups a `PopoverTitle` and `PopoverDescription` above any other content, such as form fields.

Use a popover for interactive content that relates to its trigger. Use Tooltip for short, non-interactive hints, and Dialog when the task needs the user's full attention.

The popover is uncontrolled by default; use `defaultOpen`, or `open` with `onOpenChange` to control it. `PopoverContent` accepts the positioning props `side`, `sideOffset`, `align` and `alignOffset`, defaulting to `bottom`, `4`, `center` and `0`.

Use the trigger's `render` prop to render it as another component, such as a `Button`.

## Accessibility

- The panel has the `dialog` role. `PopoverTitle` provides its accessible name and `PopoverDescription` its accessible description.
- The trigger exposes `aria-expanded`.
- Escape closes the popover and returns focus to the trigger.
- Clicking outside the panel, or clicking the trigger again, closes it.

## Notes

- Styling hooks: `data-slot` values `popover`, `popover-trigger`, `popover-content`, `popover-header`, `popover-title` and `popover-description`.
- The panel is `w-72` by default; override it with `className`.
- The panel animates in from the side it opens on, using Base UI's `data-side`, `data-open` and `data-closed` attributes.
- Uses the `surface-raised`, `label` and `label-secondary` tokens.

`Popover` positions a panel next to its `PopoverTrigger`. `PopoverContent` renders in a portal, is placed on any `side` with an `align` and offsets, and animates in with a short fade, scale and slide using Reanimated. On iOS the content is wrapped in a `FullWindowOverlay` from `react-native-screens`, so it draws above native modals.

Use `PopoverHeader`, `PopoverTitle` and `PopoverDescription` to label the panel. For short hints, use Tooltip instead.

## Usage

<Code lang="tsx" code={"import { PopoverContent, PopoverHeader, PopoverTitle, PopoverDescription } from \"@/components/ui/popover\""} />

<Code lang="tsx" code={"<View className=\"items-start\">\n  <Popover defaultOpen>\n    <PopoverTrigger render={<Button variant=\"outline\" />}>\n      <Text>Open popover</Text>\n    </PopoverTrigger>\n    <PopoverContent align=\"start\" className=\"w-80\">\n      <View className=\"gap-4\">\n        <PopoverHeader>\n          <PopoverTitle>Dimensions</PopoverTitle>\n          <PopoverDescription>\n            Set the dimensions for the layer.\n          </PopoverDescription>\n        </PopoverHeader>\n        <View className=\"gap-2\">\n          {dimensions.map((dimension) => (\n            <View\n              key={dimension.id}\n              className=\"flex-row items-center gap-4\"\n            >\n              <Label nativeID={`popover-${dimension.id}`} className=\"w-24\">\n                {dimension.label}\n              </Label>\n              <Input\n                accessibilityLabelledBy={`popover-${dimension.id}`}\n                defaultValue={dimension.value}\n                className=\"h-8 flex-1\"\n              />\n            </View>\n          ))}\n        </View>\n      </View>\n    </PopoverContent>\n  </Popover>\n</View>"} />

The popover is uncontrolled by default. Use `defaultOpen` to start open, or `open` with `onOpenChange` to control it. `onOpenChangeComplete` runs after the open or close animation.

Pass a `render` element to `PopoverTrigger`, such as a `Button`, to use your own pressable.

To share one popover between several triggers, create a handle with `createHandle` from the popover primitive, pass it as `handle` to the `Popover` and each `PopoverTrigger`, and give each trigger a `payload`. The `Popover` children can be a function that receives the active `payload`.

Use `portalHost` on `PopoverContent` to render into a named portal host.

## Accessibility

- The panel has the `dialog` role and is labeled by `PopoverTitle` when one is present.
- `PopoverTitle` has the `heading` role.
- When the popover opens, focus moves to the title by default.
- The popover can close from an outside press, the Android back button, or the screen reader escape gesture.
- Animations follow the system reduce motion setting.

## Notes

- The panel uses `bg-surface-raised`, a subtle `border-label/5` border (`border-label/10` in dark mode) and `shadow-lg`.
- `FullWindowOverlay` is used only on iOS; on Android the content renders in the portal directly.
- Light and dark colors follow the system appearance.
