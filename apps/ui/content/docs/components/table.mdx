`Table` renders a native `table` inside a container that scrolls horizontally when the table is too wide. Build it from `TableHeader`, `TableBody` and `TableFooter`, each holding `TableRow` elements with `TableHead` or `TableCell` cells. `TableCaption` adds a caption below the table.

The parts add spacing, hairline row dividers, hover and selection backgrounds, and tabular numbers in cells. They don't add sorting, pagination or selection logic; handle those in your own code.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add table
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install cn
```

2. Copy the source into `components/ui/table.tsx`:

<ComponentSource path="components/ui/table.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Table, TableHeader, TableBody, TableFooter, TableRow, TableHead, TableCell, TableCaption } from "@/components/ui/table"
```

```tsx
<div className="w-[36rem]">
  <Table>
    <TableCaption>A list of your recent invoices.</TableCaption>
    <TableHeader>
      <TableRow>
        <TableHead>Invoice</TableHead>
        <TableHead>Status</TableHead>
        <TableHead>Method</TableHead>
        <TableHead className="text-end">Amount</TableHead>
      </TableRow>
    </TableHeader>
    <TableBody>
      {invoices.map((invoice) => (
        <TableRow key={invoice.id}>
          <TableCell className="font-medium">{invoice.id}</TableCell>
          <TableCell>{invoice.status}</TableCell>
          <TableCell>{invoice.method}</TableCell>
          <TableCell className="text-end">
            {currency.format(invoice.amount)}
          </TableCell>
        </TableRow>
      ))}
    </TableBody>
    <TableFooter>
      <TableRow>
        <TableCell colSpan={3}>Total</TableCell>
        <TableCell className="text-end">{currency.format(total)}</TableCell>
      </TableRow>
    </TableFooter>
  </Table>
</div>
```

Every part passes its props to the native element, so use standard attributes such as `colSpan`. Align numeric columns with `text-end` on both the `TableHead` and its cells. To highlight a row, set `data-selected` on `TableRow`.

## Accessibility

- The parts render native table elements, so rows, column headers and cells keep their built-in roles.
- `TableCaption` gives the table its accessible name.

## Notes

- `data-selected` is matched by presence, so leave the attribute off unselected rows rather than setting it to `false`.
- A `TableRow` that contains an element with `aria-expanded` also gets the selected background.
- Header and data cells that contain a `role="checkbox"` drop their end padding.
- Parts carry `data-slot` attributes such as `table-container`, `table`, `table-row` and `table-cell`.
- Hover and selection use the `item-hover` and `item-selected` tokens; the footer uses a tinted `surface-secondary`.
