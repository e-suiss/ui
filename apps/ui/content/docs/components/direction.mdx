The direction module provides `DirectionProvider` and `useDirection` from the chosen base. `DirectionProvider` takes a `direction` of `ltr` or `rtl` and makes it available to the primitives below it, so behaviors that depend on direction, such as arrow-key navigation and popup placement, follow the reading direction. `useDirection` returns the current direction for your own components.

The provider does not set the `dir` attribute on the page. Set `dir` on the `html` element or on a container yourself so that the browser and logical CSS properties flip the layout.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/direction
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add direction
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @base-ui/react
```

2. Copy the source into `components/ui/direction.tsx`:

<ComponentSource path="components/ui/direction.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
<DirectionProvider direction="ltr">
  <DirectionPreview />
</DirectionProvider>
```

Wrap your app, or a subtree, in `DirectionProvider` with the same direction you set in the `dir` attribute. Read the value with `useDirection` when a component needs to adapt, for example to pass it to a `dir` attribute or to rotate a directional icon.

## Notes

- Pair directional icons with the `rtl:` Tailwind variant, for example `rtl:rotate-180`, so arrows point the right way.
- Many components in the library use logical properties such as `ps-`, `pe-`, `ms-` and `me-`, which flip automatically under `dir="rtl"`.
