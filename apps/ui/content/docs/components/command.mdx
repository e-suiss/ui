Command is built on cmdk. The `Command` root filters and orders its items as people type into `CommandInput`. `CommandList` holds the results: `CommandGroup` sections with a `heading`, `CommandItem` rows, `CommandSeparator` dividers, and a `CommandEmpty` message shown when nothing matches. `CommandShortcut` displays a keyboard shortcut at the end of an item.

`CommandDialog` places a `Command` in a modal dialog for a command palette. Use a command menu for actions and navigation that people search by name. To pick a value for a form field, use a combobox instead.

## Usage

<Code lang="tsx" code={"import { Command, CommandDialog, CommandInput, CommandList, CommandEmpty, CommandGroup, CommandSeparator, CommandItem, CommandShortcut } from \"@/components/ui/command\""} />

<Code lang="tsx" code={"<div className=\"w-140\">\n  <Command className=\"ring-label/5 shadow-md ring-1\">\n    <CommandInput placeholder=\"Type a command or search...\" />\n    <CommandList>\n      <CommandItems />\n    </CommandList>\n  </Command>\n</div>"} />

Compose `CommandInput` and `CommandList` inside `Command`, and put groups and items in the list. For a palette, wrap the `Command` in `CommandDialog` and control it with `open` and `onOpenChange`. Respond to a chosen item with its `onSelect` callback, and set `disabled` on items that are unavailable.

Set `mod` on `CommandShortcut` to prefix the shortcut with the platform modifier key: `⌘` on Apple platforms and `Ctrl+` elsewhere.

## Accessibility

- The input has the `combobox` role and items have the `option` role. The highlighted item sets `aria-selected` and disabled items set `aria-disabled`.
- The first item is highlighted by default. Arrow keys move the highlight and skip disabled items; Enter selects the highlighted item.
- `CommandDialog` renders a `dialog` named by its `title`, moves focus inside when it opens, closes with Escape, and returns focus to the element that opened it.
- `CommandShortcut` is hidden on small screens.

## Notes

- Styling hooks: `data-slot` values `command`, `command-input-wrapper`, `command-input`, `command-list`, `command-empty`, `command-group`, `command-separator`, `command-item` and `command-shortcut`.
- The highlighted item gets `data-selected` and is filled with the `accent` color. Disabled items get `data-disabled="true"`.
- An item with `data-checked="true"` shows a check mark, unless it contains a `CommandShortcut`.
- Inside a dialog, `Command` drops its own background and rounded corners. The palette uses a translucent, blurred `surface-raised` background.
