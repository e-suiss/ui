`Collapsible` wraps the Base UI Collapsible primitive. The `Collapsible` root holds the open state, a `CollapsibleTrigger` toggles it, and `CollapsibleContent` holds the content that is shown or hidden. The parts are unstyled, so you control layout and appearance with `className`, or render the trigger as another component such as `Button` with the `render` prop.

Use a collapsible for a single disclosure region. For a set of related, stacked sections, use an accordion instead.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add collapsible
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @base-ui/react
```

2. Copy the source into `components/ui/collapsible.tsx`:

<ComponentSource path="components/ui/collapsible.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Collapsible, CollapsibleTrigger, CollapsibleContent } from "@/components/ui/collapsible"
```

```tsx
<div className="w-80">
  <Collapsible className="flex flex-col gap-2">
    <div className="flex items-center justify-between gap-4 px-3">
      <span className="text-sm font-medium">
        @ademceper starred 3 repositories
      </span>
      <CollapsibleTrigger
        render={
          <Button variant="ghost" size="icon-sm" aria-label="Toggle list" />
        }
      >
        <CaretUpDownIcon />
      </CollapsibleTrigger>
    </div>
    <div className="bg-muted rounded-2xl px-4 py-2 text-sm">
      {repositories[0]}
    </div>
    <CollapsibleContent className="flex flex-col gap-2">
      {repositories.slice(1).map((repository) => (
        <div
          key={repository}
          className="bg-muted rounded-2xl px-4 py-2 text-sm"
        >
          {repository}
        </div>
      ))}
    </CollapsibleContent>
  </Collapsible>
</div>
```

The root is uncontrolled by default; set `defaultOpen` to start expanded. To control it, pass `open` and `onOpenChange`. Set `disabled` on the root to prevent toggling. While collapsed, the content is removed from the page.

## Accessibility

- The trigger renders as a button and sets `aria-expanded` to reflect the open state.
- The trigger toggles on click, and with Enter or Space when focused.
- Give an icon-only trigger an accessible name with `aria-label`.

## Notes

- Styling hooks: `data-slot="collapsible"`, `data-slot="collapsible-trigger"` and `data-slot="collapsible-content"`.
- Base UI sets state attributes such as `data-open` and `data-closed` on the parts, which you can use for styling and animation.
- No styles are applied by default.

## Usage

```tsx
<CollapsibleDemo initialOpen />
```

Put any content in `CollapsibleTrigger`, for example a `Text` and a caret `Icon`, and use `render` to render it as a `Button`. Use `open` with `onOpenChange` for controlled state, or `defaultOpen` for uncontrolled.

Set `keepMounted` on `CollapsibleContent` to keep the content mounted while closed.
