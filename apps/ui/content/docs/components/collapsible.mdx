`Collapsible` wraps the collapsible primitive of the chosen base. The `Collapsible` root holds the open state, a `CollapsibleTrigger` toggles it, and `CollapsibleContent` holds the content that is shown or hidden. The parts are unstyled, so you control layout and appearance with `className`, or render the trigger as another component such as `Button`.

Use a collapsible for a single disclosure region. For a set of related, stacked sections, use an accordion instead.

## Usage

```tsx
import { Button } from "@/components/ui/button"
import { Collapsible, CollapsibleTrigger, CollapsibleContent } from "@/components/ui/collapsible"
```

<OnlyBase base="base">

```tsx
<div className="w-80">
  <Collapsible className="flex flex-col gap-2">
    <div className="flex items-center justify-between gap-4 px-3">
      <span className="text-sm font-medium">
        @ademceper starred 3 repositories
      </span>
      <CollapsibleTrigger
        render={
          <Button variant="ghost" size="icon-sm" aria-label="Toggle list" />
        }
      >
        <CaretUpDownIcon />
      </CollapsibleTrigger>
    </div>
    <div className="bg-muted rounded-2xl px-4 py-2 text-sm">

        <div
          key={repository}

        >
          {repository}
        </div>
      ))}
    </CollapsibleContent>
  </Collapsible>
```

## Accessibility

- The trigger renders as a button and sets `aria-expanded` to reflect the open state.
- The trigger toggles on click, and with Enter or Space when focused.
- Give an icon-only trigger an accessible name with `aria-label`.

## API Reference

### Collapsible

The root that holds the open state and groups the trigger and content.

<OnlyBase base="base radix">

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | — |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `(open: boolean) => void` | — |
| `disabled` | `boolean` | `false` |

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `isExpanded` | `boolean` | — |
| `defaultExpanded` | `boolean` | `false` |
| `onExpandedChange` | `(isExpanded: boolean) => void` | — |
| `isDisabled` | `boolean` | `false` |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base radix">

The root is uncontrolled by default; set `defaultOpen` to start expanded, or control it with `open` and `onOpenChange`.

</OnlyBase>

<OnlyBase base="aria">

The root is uncontrolled by default; set `defaultExpanded` to start expanded, or control it with `isExpanded` and `onExpandedChange`.

</OnlyBase>

### CollapsibleTrigger

The button that toggles the content open and closed.

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base">

Render the trigger as another component, such as `Button`, with the `render` prop.

</OnlyBase>

<OnlyBase base="radix">

Set `asChild` to render another component, such as `Button`, as the trigger.

</OnlyBase>

<OnlyBase base="aria">

Any `Button` with `slot="trigger"` inside `Collapsible` toggles it.

</OnlyBase>

### CollapsibleContent

The panel that is shown when the collapsible is open.

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base radix">

While collapsed, the content is removed from the page.

</OnlyBase>

<OnlyBase base="aria">

While collapsed, the content's children are not rendered.

</OnlyBase>

No styles are applied by default. Each part sets a `data-slot`, such as `collapsible-trigger`, and the primitive sets state attributes you can use for styling and animation.

</Only>

```swift
import PhosphorSwift
import SwiftUI

let collapsibleRepositories = ["esuiss/ui", "esuiss/docs", "esuiss/cli"]

struct CollapsibleDemo: View {
  var disabled = false

  @State private var open: Bool

  init(initialOpen: Bool = false, disabled: Bool = false) {
    self.disabled = disabled
    _open = State(initialValue: initialOpen)
  }

  var body: some View {
    Collapsible(isExpanded: $open, spacing: 8) {
      HStack(spacing: 16) {
        Text("@ademceper starred 3 repositories")
          .textStyle(.sm, weight: .medium)
          .foregroundStyle(EsuissColor.foreground)
          .frame(maxWidth: .infinity, alignment: .leading)
        CollapsibleTrigger {
          Ph.caretUpDown.regular
            .frame(width: 16, height: 16)
        }
        .buttonStyle(.variant(.ghost, size: .iconSm))
        .disabled(disabled)
      }
      .padding(.horizontal, 12)
      CollapsibleRepository(name: collapsibleRepositories[0])
      CollapsibleContent {
        VStack(spacing: 8) {
          ForEach(collapsibleRepositories.dropFirst(), id: \.self) { repository in
            CollapsibleRepository(name: repository)
          }
        }
      }
    }
    .frame(maxWidth: .infinity)
  }
}

struct CollapsibleRepository: View {
  let name: String

  var body: some View {
    Text(verbatim: name)
      .textStyle(.sm)
      .foregroundStyle(EsuissColor.foreground)
      .padding(.horizontal, 16)
      .padding(.vertical, 8)
      .frame(maxWidth: .infinity, alignment: .leading)
      .background(EsuissColor.muted, in: RoundedRectangle(cornerRadius: Radius.xl2, style: .continuous))
  }
}
```

## API Reference

<Only platform="rn">

### Collapsible

Root that holds the open state.

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `(open: boolean, details) => void` | - |
| `disabled` | `boolean` | `false` |
| `render` | `React.ReactElement \| ((props, state) => React.ReactElement)` | - |

Also accepts the props of `View`.

Use `open` with `onOpenChange` for controlled state, or `defaultOpen` for uncontrolled. `render` replaces the default `View`.

### CollapsibleTrigger

Pressable that opens and closes the content.

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `React.ReactElement \| ((props, state) => React.ReactElement)` | - |

Also accepts the props of `Pressable`.

Put any content in the trigger, for example a `Text` and a caret `Icon`. Use `render` to render it as another element, such as a `Button`, in place of the default `Pressable`.

### CollapsibleContent

The content shown while open.

| Prop | Type | Default |
| --- | --- | --- |
| `keepMounted` | `boolean` | `false` |
| `render` | `React.ReactElement \| ((props, state) => React.ReactElement)` | - |

Also accepts the props of `View`.

Set `keepMounted` to keep the content mounted while closed. `render` replaces the default `View`.
