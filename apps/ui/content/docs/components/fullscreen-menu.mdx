Fullscreen menu is built on the dialog primitive of the chosen base. The `FullscreenMenu` root manages the open state, and `FullscreenMenuTrigger` renders a menu button whose two-line icon animates into a close icon. `FullscreenMenuContent` covers the viewport and reveals from the top, with a sticky header that holds the close button. Inside it, `FullscreenMenuTitle` names the menu, `FullscreenMenuGroup` holds a list of `FullscreenMenuLink` items, and `FullscreenMenuLabel` adds a caption to a group. Links and labels fade in with a staggered delay as the menu opens.

Use it for the primary navigation of a website on phones, like the global navigation on apple.com. For a short list of actions, use a dropdown menu; for a panel that keeps part of the page visible, use a drawer or sheet.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/fullscreen-menu
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add fullscreen-menu
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install @base-ui/react
```

2. Add the pieces it builds on: [Button](/docs/components/button).

3. Copy the source into `components/ui/fullscreen-menu.tsx`:

<ComponentSource path="components/ui/fullscreen-menu.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { FullscreenMenu, FullscreenMenuTrigger, FullscreenMenuContent, FullscreenMenuTitle, FullscreenMenuGroup, FullscreenMenuLabel, FullscreenMenuLink, FullscreenMenuClose } from "@/components/ui/fullscreen-menu"
```

```tsx
<MenuExample />
```

The menu is uncontrolled by default; set `defaultOpen` to start open, or control it with `open` and `onOpenChange`. Choosing a `FullscreenMenuLink` closes the menu. Set `isActive` on the link for the current page.

Groups that contain a `FullscreenMenuLabel` render their links smaller than groups without one, so the first group reads as primary navigation. `FullscreenMenuLink` can render a router link instead of an anchor.

Use `FullscreenMenuLink` with the `render` prop to render a router link instead of an anchor.

</OnlyBase>

<OnlyBase base="radix">

</OnlyBase>

<OnlyBase base="aria">

Pass a `render` function to `FullscreenMenuLink` that returns a router link with the props it receives.

</OnlyBase>

## API Reference

<ApiPart index={1}>

### FullscreenMenu

The root that manages the menu's open state.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | - | Whether the menu is open, for controlled use. |
| `defaultOpen` | `boolean` | `false` | Whether the menu starts open when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | - | Called when the menu opens or closes. |

Also accepts the props of the primitive part it wraps, plus `FullscreenMenuProps`.

<OnlyBase base="aria">

On the `aria` base, use `isOpen` instead of `open`.

</OnlyBase>

</ApiPart>

<ApiPart index={2}>

### FullscreenMenuTrigger

The menu button, with an icon that animates between menu and close states.

Also accepts the props of the primitive part it wraps.

</ApiPart>

<ApiPart index={3}>

### FullscreenMenuContent

The full-screen panel, with a sticky header that holds the close button.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `showCloseButton` | `boolean` | `true` | Shows the header with a close button at the top of the menu. |
| `closeLabel` | `string` | - | Replaces the close button's icon with this text. |

Also accepts the props of the primitive part it wraps.

</ApiPart>

<ApiPart index={4}>

### FullscreenMenuTitle

The menu's title, visually hidden and used as its accessible name.

Also accepts the props of the primitive part it wraps.

</ApiPart>

<ApiPart index={5}>

### FullscreenMenuGroup

A list of links, animated in sequence.

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

<ApiPart index={6}>

### FullscreenMenuLabel

A caption for a group of links.

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

<ApiPart index={7}>

### FullscreenMenuLink

A navigation link that closes the menu when chosen.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `isActive` | `boolean` | `false` | Marks the link as the current page with `aria-current="page"` and `text-primary`. |

Also accepts the props of `useRender.ComponentProps<"a">`, `React.ComponentProps<"a">`.

</ApiPart>

<ApiPart index={8}>

### FullscreenMenuClose

A button that closes the menu from any element.

Also accepts the props of the primitive part it wraps.

</ApiPart>

## Accessibility

- The panel has the `dialog` role and takes its name from `FullscreenMenuTitle`, which is visually hidden. Always include one.
- The trigger has no text of its own, so give it an accessible name with `aria-label`. It sets `aria-expanded` while the menu is open.
- Opening the menu moves focus inside it. Escape closes it and returns focus to the trigger.
- The icon-only close button has a visually hidden `Close` label.
- The active link sets `aria-current="page"`.

## Notes

- Styling hooks: `data-slot` values `fullscreen-menu-trigger`, `fullscreen-menu-content`, `fullscreen-menu-header`, `fullscreen-menu-body`, `fullscreen-menu-close`, `fullscreen-menu-title`, `fullscreen-menu-group`, `fullscreen-menu-label` and `fullscreen-menu-link`.
- The active link gets `data-active`.
- The stagger delay is computed from a link's position in its group, for up to 10 links, and the group's position in the menu, for up to 6 sections.
- The content respects safe-area insets, and animations are disabled when reduced motion is preferred.
- Uses the `background`, `foreground`, `muted-foreground` and `primary` tokens.
