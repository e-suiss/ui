A `Card` stacks a `CardHeader`, `CardContent` and `CardFooter` with consistent spacing. The header holds a `CardTitle`, an optional `CardDescription`, and an optional `CardAction` that sits in the top-end corner. An `img` placed as the first child runs edge to edge, with rounded top corners and no top padding.

Use a card to present a self-contained summary, such as a plan, a metric or a place. For dense lists of rows, use Item or a table instead.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/card
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add card
```

### Manual

1. Add the [`cn` helper](/docs/installation#the-cn-helper).

2. Copy the source into `components/ui/card.tsx`:

<ComponentSource path="components/ui/card.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Button } from "@/components/ui/button"
import { Card, CardHeader, CardTitle, CardDescription, CardAction, CardContent, CardFooter } from "@/components/ui/card"
```

```tsx
<div className="w-96">
  <Card>
    <CardHeader>
      <CardTitle>Team plan</CardTitle>
      <CardDescription>
        Everything your team needs to ship faster.
      </CardDescription>
    </CardHeader>
    <CardContent>
      <p>
        Unlimited projects, shared workspaces, and priority support for up to
        ten members.
      </p>
    </CardContent>
    <CardFooter className="gap-2">
      <Button>Upgrade</Button>
      <Button variant="ghost">Learn more</Button>
    </CardFooter>
  </Card>
</div>
```

All parts are plain `div` elements, so you can omit any of them. Add `border-b` to `CardHeader` or `border-t` to `CardFooter` to draw a divider; the card adds matching padding on that side.

Spacing is controlled by the `--card-spacing` custom property, which the `sm` size reduces.

## Accessibility

- Card parts are non-semantic `div` elements, and `CardTitle` is not a heading. If the title belongs in the document outline, place a heading element such as `h2` inside it.
- Icon-only buttons in `CardAction` need an `aria-label`.

## Notes

- Styling hooks: `data-slot` values `card`, `card-header`, `card-title`, `card-description`, `card-action`, `card-content` and `card-footer`, plus `data-size` and `data-variant` on the root.
- The header switches to a two-column grid when it contains a `CardAction`.
- Calendar detects `data-slot="card-content"` and drops its own background inside a card.

## Usage

<Only platform="rn">

```tsx
import { View } from "react-native"
import { Button } from "@/components/ui/button"
import { Card, CardHeader, CardTitle, CardDescription, CardAction, CardContent, CardFooter } from "@/components/ui/card"
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"
import { Text } from "@/components/ui/text"
```

```tsx
<Card className="w-full">
  <CardHeader>
    <CardTitle>Login to your account</CardTitle>
    <CardDescription>
      Enter your email below to login to your account
    </CardDescription>
  </CardHeader>
  <CardContent className="gap-4">
    <View className="gap-2">
      <Label nativeID="card-email">Email</Label>
      <Input
        accessibilityLabelledBy="card-email"
        placeholder="m@example.com"
        keyboardType="email-address"
        autoCapitalize="none"
      />
    </View>
    <View className="gap-2">
      <Label nativeID="card-password">Password</Label>
      <Input accessibilityLabelledBy="card-password" secureTextEntry />
    </View>
  </CardContent>
  <CardFooter className="flex-col gap-2">
    <Button block>
      <Text>Login</Text>
    </Button>
    <Button block variant="secondary">
      <Text>Login with Google</Text>
    </Button>
  </CardFooter>
</Card>
```

<Only platform="swift">

```swift
import SwiftUI

struct CardLoginDemo: View {
  @State private var email = ""
  @State private var password = ""

  var body: some View {
    Card {
      CardHeader("Login to your account", description: "Enter your email below to login to your account")
      CardContent {
        VStack(alignment: .leading, spacing: 16) {
          VStack(alignment: .leading, spacing: 8) {
            FieldLabel("Email")
              .accessibilityHidden(true)
            TextField("Email", text: $email, prompt: Text(verbatim: "m@example.com"))
              .textFieldStyle(.input)
              .keyboardType(.emailAddress)
              .textInputAutocapitalization(.never)
          }
          VStack(alignment: .leading, spacing: 8) {
            FieldLabel("Password")
              .accessibilityHidden(true)
            SecureField("Password", text: $password, prompt: Text(verbatim: ""))
              .textFieldStyle(.input)
          }
        }
      }
      CardFooter {
        VStack(spacing: 8) {
          Button("Login") {}
            .buttonStyle(.variant(block: true))
          Button("Login with Google") {}
            .buttonStyle(.variant(.secondary, block: true))
        }
      }
    }
  }
}
```

import androidx.compose.ui.text.input.KeyboardType
import androidx.compose.ui.text.input.PasswordVisualTransformation
import androidx.compose.ui.unit.dp
import com.esuiss.ui.components.Button
import com.esuiss.ui.components.ButtonVariant
import com.esuiss.ui.components.Card
import com.esuiss.ui.components.CardContent
import com.esuiss.ui.components.CardFooter
import com.esuiss.ui.components.CardHeader
import com.esuiss.ui.components.Input
import com.esuiss.ui.components.Label

@Composable
fun CardDefault() {
    var email by rememberSaveable { mutableStateOf("") }
    var password by rememberSaveable { mutableStateOf("") }
    Card {
        CardHeader("Login to your account", description = "Enter your email below to login to your account")
        CardContent {
            Column(verticalArrangement = Arrangement.spacedBy(16.dp)) {
                Column(verticalArrangement = Arrangement.spacedBy(8.dp)) {
                    Label("Email")
                    Input(
                        email,
                        { email = it },
                        Modifier.semantics { contentDescription = "Email" },
                        placeholder = "m@example.com",
                        keyboardOptions = KeyboardOptions(
                            capitalization = KeyboardCapitalization.None,
                            autoCorrectEnabled = false,
                            keyboardType = KeyboardType.Email,
                        ),
                    )
                }
                Column(verticalArrangement = Arrangement.spacedBy(8.dp)) {
                    Label("Password")
                    Input(
                        password,
                        { password = it },
                        Modifier.semantics { contentDescription = "Password" },
                        keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Password),
                        visualTransformation = PasswordVisualTransformation(),
                    )
                }
            }
        }
        CardFooter {
            Column(Modifier.fillMaxWidth(), verticalArrangement = Arrangement.spacedBy(8.dp)) {
                Button("Login", onClick = {}, block = true)
                Button("Login with Google", onClick = {}, variant = ButtonVariant.Secondary, block = true)
            }
        }
    }
}

## Accessibility

- `CardTitle` has the `heading` role.
- The card itself adds no role; actions inside provide their own.

## Notes

- Uses `bg-card` with a shadow, or `bg-muted` for `filled`; the border is stronger in dark mode.
- Light and dark follow the system appearance.
