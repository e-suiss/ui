A `Card` stacks a `CardHeader`, `CardContent` and `CardFooter` with consistent spacing. The header holds a `CardTitle`, an optional `CardDescription`, and an optional `CardAction` that sits in the top-end corner. An `img` placed as the first child runs edge to edge, with rounded top corners and no top padding.

Use a card to present a self-contained summary, such as a plan, a metric or a place. For dense lists of rows, use Item or a table instead.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add card
```

### Manual

1. Add the [`cn` helper](/docs/installation#the-cn-helper).

2. Copy the source into `components/ui/card.tsx`:

<ComponentSource path="components/ui/card.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Card, CardHeader, CardTitle, CardDescription, CardAction, CardContent, CardFooter } from "@/components/ui/card"
```

```tsx
<div className="w-96">
  <Card>
    <CardHeader>
      <CardTitle>Team plan</CardTitle>
      <CardDescription>
        Everything your team needs to ship faster.
      </CardDescription>
    </CardHeader>
    <CardContent>
      <p>
        Unlimited projects, shared workspaces, and priority support for up to
        ten members.
      </p>
    </CardContent>
    <CardFooter className="gap-2">
      <Button>Upgrade</Button>
      <Button variant="ghost">Learn more</Button>
    </CardFooter>
  </Card>
</div>
```

All parts are plain `div` elements, so you can omit any of them. Add `border-b` to `CardHeader` or `border-t` to `CardFooter` to draw a divider; the card adds matching padding on that side.

Spacing is controlled by the `--card-spacing` custom property, which the `sm` size reduces.

The rounded container that sets size and surface.

| Prop | Type | Default | Description |

## Accessibility

- Card parts are non-semantic `div` elements, and `CardTitle` is not a heading. If the title belongs in the document outline, place a heading element such as `h2` inside it.
- Icon-only buttons in `CardAction` need an `aria-label`.

## Notes

- Styling hooks: `data-slot` values `card`, `card-header`, `card-title`, `card-description`, `card-action`, `card-content` and `card-footer`, plus `data-size` and `data-variant` on the root.
- The header switches to a two-column grid when it contains a `CardAction`.
- Calendar detects `data-slot="card-content"` and drops its own background inside a card.

`Card` is a rounded `View` that stacks a `CardHeader`, `CardContent` and `CardFooter` with consistent spacing. The `default` variant is a raised surface with a hairline border and a shadow; the `filled` variant is a flat secondary surface.

The `sm` size reduces the padding and gaps for dense layouts. All parts read the size from context, so their horizontal padding stays aligned.

## Usage

```tsx
import { Card, CardHeader, CardTitle, CardDescription, CardAction, CardContent, CardFooter } from "@/components/ui/card"
```

```tsx
<Card className="w-full">
  <CardHeader>
    <CardTitle>Login to your account</CardTitle>
    <CardDescription>
      Enter your email below to login to your account
    </CardDescription>
  </CardHeader>
  <CardContent className="gap-4">
    <View className="gap-2">
      <Label nativeID="card-email">Email</Label>
      <Input
        accessibilityLabelledBy="card-email"
        placeholder="m@example.com"
        keyboardType="email-address"
        autoCapitalize="none"
      />
    </View>
    <View className="gap-2">
      <Label nativeID="card-password">Password</Label>
      <Input accessibilityLabelledBy="card-password" secureTextEntry />
    </View>
  </CardContent>
  <CardFooter className="flex-col gap-2">
    <Button block>
      <Text>Login</Text>
    </Button>
    <Button block variant="secondary">
      <Text>Login with Google</Text>
    </Button>
  </CardFooter>
</Card>
```

Put a `CardTitle` and `CardDescription` in `CardHeader`. Add a `CardAction` anywhere in the header and it is placed in the top-end corner beside the title.

To show an image edge to edge, place it directly in the card before the header and add `pt-0` to the card; only the header, content and footer are padded horizontally.

## Accessibility

- `CardTitle` has the `heading` role.
- The card itself adds no role; actions inside provide their own.

## Notes

- Uses `bg-card` with a shadow, or `bg-muted` for `filled`; the border is stronger in dark mode.
- Light and dark follow the system appearance.
