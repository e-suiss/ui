`Marker` displays a short line of secondary text, typically between messages or list entries. Put the text in `MarkerContent` and, optionally, a leading `MarkerIcon`.

The `variant` prop changes the treatment: plain text, text centered between two separator rules, or text above a bottom border. Use `Marker` for annotations within content; use `Separator` for a purely visual rule with no text.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add marker
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @base-ui/react class-variance-authority cn
```

2. Copy the source into `components/ui/marker.tsx`:

<ComponentSource path="components/ui/marker.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Marker, MarkerIcon, MarkerContent } from "@/components/ui/marker"
```

```tsx
<div className="w-96">
  <Marker>
    <MarkerContent>Conversation started</MarkerContent>
  </Marker>
</div>
```

`Marker` is built on Base UI's `useRender`, so it accepts a `render` prop to change the underlying element. Links inside the marker or its content are underlined automatically.

### Marker

The container row that applies the variant styling.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "separator" \| "border"` | `"default"` | Sets the visual treatment: `default` for plain text, `separator` for text between two rules, or `border` for text above a bottom border. |

Also accepts the props of `useRender.ComponentProps<"div">`.

</ApiPart>

<ApiPart index={2}>

### MarkerIcon

A decorative icon slot shown before the content and hidden from assistive technology.

Also accepts the props of `React.ComponentProps<"span">`.

</ApiPart>

<ApiPart index={3}>

### MarkerContent

Holds the marker text and any inline links.

Also accepts the props of `React.ComponentProps<"span">`.

</ApiPart>

## Accessibility

- `MarkerIcon` sets `aria-hidden="true"`, so icons must be decorative; put meaningful text in `MarkerContent`.
- Links inside the content remain in the normal tab order.

## Notes

- Styling hooks: `data-slot="marker"`, `data-slot="marker-icon"` and `data-slot="marker-content"`. The root also exposes `data-variant`.
- Rules and borders use the `separator` token; text uses `label-secondary` and links hover to `label`.

`Marker` is a row of secondary text with an optional icon. It has three variants: `default` for a plain row, `separator` for centered text with a line on each side, and `border` for a row with a bottom border.

Use `separator` for date dividers in a chat or feed, `border` for section headings, and `default` for short notices.

## Usage

```tsx
import { Marker, MarkerIcon, MarkerContent } from "@/components/ui/marker"
```

```tsx
<View className="gap-8">
  <Marker>
    <MarkerIcon>
      <Icon as={InfoIcon} />
    </MarkerIcon>
    <MarkerContent>Messages are end-to-end encrypted.</MarkerContent>
  </Marker>
  <Marker variant="separator">
    <MarkerContent>Today</MarkerContent>
  </Marker>
  <Marker variant="border">
    <MarkerIcon>
      <Icon as={CalendarBlankIcon} />
    </MarkerIcon>
    <MarkerContent>Upcoming</MarkerContent>
  </Marker>
</View>
```

Put the text in `MarkerContent` and an `Icon` in `MarkerIcon`. Text and icons inside the marker pick up the secondary label color and size through context.

Pass a `render` element to `Marker` to render it as another component instead of a `View`.

## API Reference

<ApiPart index={1}>

### Marker

Row that sets the variant and the text and icon styles.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "separator" \| "border"` | `"default"` | `default`, `separator` or `border`. |
| `render` | `RenderProp<Record<string, unknown>, Record<string, never>>` | - | Element to render in place of the default `View`. |

Also accepts the props of `ViewProps`.

</ApiPart>

<ApiPart index={2}>

### MarkerIcon

Fixed-size slot for an icon.

Also accepts the props of `ViewProps`.

</ApiPart>

<ApiPart index={3}>

### MarkerContent

Marker text, centered in the `separator` variant.

Also accepts the props of `React.ComponentProps<typeof Text>`.

</ApiPart>

## Accessibility

- `MarkerIcon` and the separator lines are hidden from screen readers, so only the text is read.
- If the icon carries meaning, include it in the text.

## Notes

- Text uses `text-sm text-label-secondary` and icons `size-4`.
- Lines and the bottom border use `bg-separator` and `border-separator`.
- Light and dark colors follow the system appearance.
