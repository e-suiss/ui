`Marker` displays a short line of secondary text, typically between messages or list entries. Put the text in `MarkerContent` and, optionally, a leading `MarkerIcon`.

Use `Marker` for annotations within content; use `Separator` for a purely visual rule with no text.

```text

├── MarkerContent
└── MarkerIcon
```

## Examples

### Variants

Use the `variant` prop to pick the treatment: `default` for plain text, `separator` for text between two rules, or `border` for text above a bottom border.

## Accessibility

- `MarkerIcon` sets `aria-hidden="true"`, so icons must be decorative; put meaningful text in `MarkerContent`.
- Links inside the content remain in the normal tab order.

## API Reference

### Marker

The container row that applies the variant styling.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "separator" \| "border"` | `"default"` |

<OnlyBase base="base">

Also accepts the props of `useRender.ComponentProps<"div">`.

Use the `render` prop to change the underlying element.

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |

Also accepts the props of `React.ComponentProps<"div">`.

Set `asChild` and pass the element as the child to change the underlying element.

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `(props) => React.ReactNode` | - |

Also accepts the props of `React.ComponentProps<"div">`.

Pass a `render` function that returns the element with the props it receives to change the underlying element.

</OnlyBase>

Rules and borders use the `border` color and text uses `muted-foreground`.

### MarkerIcon

A decorative icon slot shown before the content and hidden from assistive technology.

Also accepts the props of `React.ComponentProps<"span">`.

### MarkerContent

Holds the marker text and any inline links.

Also accepts the props of `React.ComponentProps<"span">`.

Each part sets a `data-slot`, such as `marker` or `marker-content`, for styling. The root also exposes `data-variant`.

</Only>

`Marker` is a row of secondary text with an optional icon. It has three variants: `default` for a plain row, `separator` for centered text with a line on each side, and `border` for a row with a bottom border.

Use `separator` for date dividers in a chat or feed, `border` for section headings, and `default` for short notices.

- If the icon carries meaning, include it in the text.

## API Reference

<Only platform="rn">

### Marker

Row that sets the variant and the text and icon styles.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "separator" \| "border"` | `"default"` |
| `render` | `RenderProp<Record<string, unknown>, Record<string, never>>` | - |

Also accepts the props of `ViewProps`.

Pass a `render` element to render the marker as another component instead of a `View`. Text and icons inside the marker pick up the `text-sm text-muted-foreground` style and the `size-4` icon size through context. Lines and the bottom border use `bg-border` and `border-border`.

### MarkerIcon

Fixed-size slot for an icon.

Also accepts the props of `ViewProps`.

Put an `Icon` inside it.

### MarkerContent

Marker text, centered in the `separator` variant.

Also accepts the props of `React.ComponentProps<typeof Text>`.

</Only>
