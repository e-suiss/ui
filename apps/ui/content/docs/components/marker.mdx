`Marker` displays a short line of secondary text, typically between messages or list entries. Put the text in `MarkerContent` and, optionally, a leading `MarkerIcon`.

The `variant` prop changes the treatment: plain text, text centered between two separator rules, or text above a bottom border. Use `Marker` for annotations within content; use `Separator` for a purely visual rule with no text.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/marker
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add marker
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install @base-ui/react class-variance-authority
```

2. Copy the source into `components/ui/marker.tsx`:

<ComponentSource path="components/ui/marker.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Marker, MarkerIcon, MarkerContent } from "@/components/ui/marker"
```

```tsx
<div className="w-96">
  <Marker>
    <MarkerContent>Conversation started</MarkerContent>
  </Marker>
</div>
```

Links inside the marker or its content are underlined automatically. The underlying element can be changed:

</OnlyBase>

<OnlyBase base="aria">

Pass a `render` function to `Marker` that returns the element with the props it receives.

</OnlyBase>

## Accessibility

- `MarkerIcon` sets `aria-hidden="true"`, so icons must be decorative; put meaningful text in `MarkerContent`.
- Links inside the content remain in the normal tab order.

## Notes

- Styling hooks: `data-slot="marker"`, `data-slot="marker-icon"` and `data-slot="marker-content"`. The root also exposes `data-variant`.
- Rules and borders use the `border` color; text uses `muted-foreground` and links hover to `foreground`.

`Marker` is a row of secondary text with an optional icon. It has three variants: `default` for a plain row, `separator` for centered text with a line on each side, and `border` for a row with a bottom border.

Use `separator` for date dividers in a chat or feed, `border` for section headings, and `default` for short notices.

## Usage

<Only platform="rn">

```tsx
import { View } from "react-native"
import { Icon } from "@/components/ui/icon"
import { Marker, MarkerIcon, MarkerContent } from "@/components/ui/marker"
```

```tsx
<View className="gap-8">
  <Marker>
    <MarkerIcon>
      <Icon as={InfoIcon} />
    </MarkerIcon>
    <MarkerContent>Messages are end-to-end encrypted.</MarkerContent>
  </Marker>
  <Marker variant="separator">
    <MarkerContent>Today</MarkerContent>
  </Marker>
  <Marker variant="border">
    <MarkerIcon>
      <Icon as={CalendarBlankIcon} />
    </MarkerIcon>
    <MarkerContent>Upcoming</MarkerContent>
  </Marker>
</View>
```

import com.esuiss.ui.components.MarkerContent
import com.esuiss.ui.components.MarkerIcon

@Composable
fun MarkerVariants() {
    Column(Modifier.fillMaxWidth(), verticalArrangement = Arrangement.spacedBy(32.dp)) {
        Marker {
            MarkerIcon { Icon(PhosphorIcons.Regular.Info, contentDescription = null) }
            MarkerContent("Messages are end-to-end encrypted.")
        }
        Marker(variant = MarkerVariant.Separator) {
            MarkerContent("Today")
        }

            MarkerContent("Upcoming")
        }
    }

Put the text in `MarkerContent` and an `Icon` in `MarkerIcon`. Text and icons inside the marker pick up the `text-muted-foreground` color and size through context.

Pass a `render` element to `Marker` to render it as another component instead of a `View`.

## Accessibility

- `MarkerIcon` and the separator lines are hidden from screen readers, so only the text is read.
- If the icon carries meaning, include it in the text.

## Notes

- Text uses `text-sm text-muted-foreground` and icons `size-4`.
- Lines and the bottom border use `bg-border` and `border-border`.
- Light and dark colors follow the system appearance.
