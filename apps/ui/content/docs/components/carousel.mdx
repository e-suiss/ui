Carousel is built on `embla-carousel-react`. A `Carousel` root holds a `CarouselContent` track whose children are `CarouselItem` slides. Add `CarouselPrevious` and `CarouselNext` to page through slides; on their own they float outside the track's edges. To lay controls out in a row below the track instead, place them in a `CarouselControls` container, along with `CarouselDots` for per-slide indicators and `CarouselPlayButton` for autoplay.

Use a carousel for featured content, product shelves, testimonials and galleries where people browse a set of peers one at a time. For content everyone must see, prefer a static layout.

## Usage

<Code lang="tsx" code={"import { Carousel, CarouselContent, CarouselItem, CarouselPrevious, CarouselNext, CarouselControls, CarouselDots, CarouselPlayButton } from \"@/components/ui/carousel\""} />

<Code lang="tsx" code={"<Carousel orientation=\"horizontal\">\n  <CarouselContent>\n    {slides.map((slide) => (\n      <CarouselItem key={slide}>\n        <Card>\n          <CardContent className=\"flex aspect-square items-center justify-center\">\n            <span className=\"text-4xl font-semibold\">{slide}</span>\n          </CardContent>\n        </Card>\n      </CarouselItem>\n    ))}\n  </CarouselContent>\n  <CarouselPrevious />\n  <CarouselNext />\n</Carousel>"} />

`Carousel` accepts `opts` (Embla options such as `align`, `loop` and `dragFree`), `plugins`, `orientation` (`horizontal` or `vertical`) and `setApi`, which receives the Embla API so you can read or drive the carousel from outside. The scroll direction follows the surrounding `DirectionProvider`.

Set the width of each slide with a `basis-*` class on `CarouselItem`, for example `basis-1/2` to show two at a time. The track uses negative margin and slides use start padding for gutters; adjust both together, as in `-ms-3` with `ps-3`.

Set `autoplay` to `true` for a 5-second interval, or to a number of milliseconds. Autoplay pauses while the pointer hovers the carousel, while it has keyboard focus, and while the page is hidden, and starts paused when the user prefers reduced motion. `CarouselPlayButton` renders only when autoplay is enabled, and the active dot fills as a progress bar.

Use the `useCarousel` hook inside a `Carousel` to build custom controls.

## Accessibility

- The root renders with `role="region"` and `aria-roledescription="carousel"`; each `CarouselItem` has `role="group"` and `aria-roledescription="slide"`. Add an `aria-label` to the root to name it.
- Arrow keys move between slides while focus is inside the carousel: left and right for horizontal (reversed in right-to-left layouts), up and down for vertical.
- `CarouselPrevious` and `CarouselNext` include visually hidden labels, `Previous slide` and `Next slide`. When one becomes disabled while focused, focus moves to the other.
- Each dot is labelled `Go to slide N`, and the current dot has `aria-current="true"`.
- `CarouselPlayButton` is labelled `Pause slideshow` or `Play slideshow` to match its state.

## Notes

- Styling hooks: `data-slot` values `carousel`, `carousel-content`, `carousel-item`, `carousel-previous`, `carousel-next`, `carousel-controls`, `carousel-dots` and `carousel-play-button`.
- The root sets `data-playing` while autoplay is running. Dots expose `data-active` on the current dot, and the dots container sets `data-variant` and `data-autoplay`.
- `CarouselPrevious` and `CarouselNext` default to the `secondary` variant and `icon` size; `CarouselPlayButton` defaults to `secondary` and `icon-sm`.
- In vertical carousels, standalone previous and next buttons are rotated 90 degrees; inside `CarouselControls` they are not.

`Carousel` wraps a scroll view that snaps to each `CarouselItem`. It scrolls horizontally by default or vertically with `orientation="vertical"`. `CarouselPrevious` and `CarouselNext` are round `Button`s that sit outside the slides, or inline when placed in `CarouselControls`.

`CarouselDots` shows one dot per snap point, with the active dot stretched into a pill; with autoplay on, the active dot fills up as a timer. `CarouselPlayButton` pauses and resumes autoplay.

## Usage

<Code lang="tsx" code={"import { Carousel, CarouselContent, CarouselItem, CarouselPrevious, CarouselNext, CarouselControls, CarouselDots, CarouselPlayButton } from \"@/components/ui/carousel\""} />

<Code lang="tsx" code={"<View className=\"mx-12\">\n  <Carousel>\n    <NumberSlides />\n    <CarouselPrevious />\n    <CarouselNext />\n  </Carousel>\n</View>"} />

Set each slide's width with `basis` on `CarouselItem`, as a fraction of the viewport (for example `0.5` for two per view). Use `opts` for `loop`, `align` (`start` or `center`) and `dragFree` scrolling without snapping.

Pass `autoplay` as `true` for the default 5-second delay, or as a number of milliseconds. Put `CarouselDots`, `CarouselPlayButton` and nav buttons inside `CarouselControls` to show them in a row below the slides; `CarouselDots` takes `variant="plain"` to drop its background.

Use `setApi` to get a `CarouselApi` for scrolling from outside, or call `useCarousel()` inside the carousel to read the selected index and scroll state.

## Accessibility

- Previous and next buttons have the `button` role and are labelled "Previous slide" and "Next slide", with a disabled state at the ends.
- Each dot is labelled "Go to slide N" and marks the current slide as selected.
- The play button is labelled "Pause slideshow" or "Play slideshow".

## Notes

- Arrow icons are mirrored in right-to-left layouts.
- Dot and progress animations respect the system Reduce Motion setting.
- Uses `bg-control`, `bg-label` and `bg-label-tertiary` tokens; light and dark follow the system appearance.
