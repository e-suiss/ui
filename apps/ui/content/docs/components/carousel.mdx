Carousel is built on `embla-carousel-react`. A `Carousel` root holds a `CarouselContent` track whose children are `CarouselItem` slides. Add `CarouselPrevious` and `CarouselNext` to page through slides; on their own they float outside the track's edges. To lay controls out in a row below the track instead, place them in a `CarouselControls` container, along with `CarouselDots` for per-slide indicators and `CarouselPlayButton` for autoplay.

Use a carousel for featured content, product shelves, testimonials and galleries where people browse a set of peers one at a time. For content everyone must see, prefer a static layout.

## Usage

```tsx
import { Card, CardContent } from "@/components/ui/card"
import {
  Carousel,
  CarouselContent,
  CarouselControls,
  CarouselDots,
  CarouselItem,
  CarouselNext,
  CarouselPlayButton,
  CarouselPrevious,
} from "@/components/ui/carousel"
```

```tsx
<Carousel orientation="horizontal">
  <CarouselContent>
    {slides.map((slide) => (
      <CarouselItem key={slide}>
        <Card>
          <CardContent className="flex aspect-square items-center justify-center">
            <span className="text-4xl font-semibold">{slide}</span>
          </CardContent>
        </Card>
      </CarouselItem>
    ))}
  </CarouselContent>
  <CarouselPrevious />
  <CarouselNext />
</Carousel>
```

## Composition

Use the following composition to build a `Carousel`:

```text
Carousel
├── CarouselContent
│   └── CarouselItem
├── CarouselPrevious
├── CarouselNext
├── CarouselControls
│   ├── CarouselDots
│   ├── CarouselPlayButton
│   ├── CarouselNext
│   └── CarouselPrevious
└── CarouselPlayButton
```

## Accessibility

- The root renders with `role="region"` and `aria-roledescription="carousel"`; each `CarouselItem` has `role="group"` and `aria-roledescription="slide"`. Add an `aria-label` to the root to name it.
- Arrow keys move between slides while focus is inside the carousel: left and right for horizontal (reversed in right-to-left layouts), up and down for vertical.
- `CarouselPrevious` and `CarouselNext` include visually hidden labels, `Previous slide` and `Next slide`. When one becomes disabled while focused, focus moves to the other.
- Each dot is labelled `Go to slide N`, and the current dot has `aria-current="true"`.
- `CarouselPlayButton` is labelled `Pause slideshow` or `Play slideshow` to match its state.

## API Reference

### Carousel

The root region that owns the Embla instance, keyboard handling and autoplay state.

| Prop | Type | Default |
| --- | --- | --- |
| `opts` | `EmblaOptionsType` | - |
| `plugins` | `EmblaPluginType[]` | - |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `setApi` | `(api: CarouselApi) => void` | - |
| `autoplay` | `boolean \| number` | `false` |

Also accepts the props of `React.ComponentProps<"div">`.

`opts` are passed to Embla Carousel, for example `align`, `loop` and `dragFree`, and `plugins` are Embla plugins. `setApi` receives the Embla API once it is ready, so you can read or drive the carousel from outside. The scroll direction follows the surrounding `DirectionProvider`.

Set `autoplay` to `true` for a 5-second interval, or to a number of milliseconds. Autoplay pauses while the pointer hovers the carousel, while it has keyboard focus, and while the page is hidden, and starts paused when the user prefers reduced motion. The root sets `data-playing` while autoplay is running. Use the `useCarousel` hook inside a `Carousel` to build custom controls.

### CarouselContent

The clipping viewport and the flex track that holds the slides.

Also accepts the props of `React.ComponentProps<"div">`.

### CarouselItem

A single slide.

Also accepts the props of `React.ComponentProps<"div">`.

The track uses negative margin and slides use start padding for gutters; adjust both together, as in `-ms-3` with `ps-3`.

### CarouselPrevious

A button that scrolls to the previous slide, disabled at the start.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "tinted" \| "ghost" \| "plain" \| "destructive" \| "link"` | `"secondary"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "xl" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg" \| "icon-xl"` | `"icon"` |

Also accepts the props of [Button](/docs/components/button).

### CarouselNext

A button that scrolls to the next slide, disabled at the end.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "tinted" \| "ghost" \| "plain" \| "destructive" \| "link"` | `"secondary"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "xl" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg" \| "icon-xl"` | `"icon"` |

Also accepts the props of [Button](/docs/components/button).

`variant` and `size` are passed to the `Button`, as on `CarouselPrevious`. On their own, the previous and next buttons float outside the track's edges; inside `CarouselControls` they sit in the row and are not rotated in vertical carousels.

### CarouselControls

A row that lays out buttons, dots and the play button below the track.

Also accepts the props of `React.ComponentProps<"div">`.

### CarouselDots

One button per snap point that jumps to that slide and marks the current one.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "plain"` | `"default"` |

Also accepts the props of `React.ComponentProps<"div">`.

`default` places the dots on a blurred pill background; `plain` removes the background and padding. The current dot sets `data-active`, and the container sets `data-variant` and `data-autoplay`.

### CarouselPlayButton

Toggles autoplay between playing and paused.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "tinted" \| "ghost" \| "plain" \| "destructive" \| "link"` | `"secondary"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "xl" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg" \| "icon-xl"` | `"icon-sm"` |

Also accepts the props of [Button](/docs/components/button).

It renders only when autoplay is enabled. `variant` and `size` are passed to the `Button`.

Each part sets a `data-slot`, such as `carousel-item` or `carousel-play-button`, for styling.

import com.esuiss.ui.components.CarouselContent

import com.esuiss.ui.components.Text
import com.esuiss.ui.components.rememberCarouselState

@Composable
fun CarouselExample() {
    CarouselNumbers(basis = null, loop = false)
}

val carouselSlides = listOf(1, 2, 3, 4, 5)

val carouselSpacing = 16.dp

fun carouselPeek(width: Dp, basis: Float?, spacing: Dp = carouselSpacing): PaddingValues {
    if (basis == null) return PaddingValues(0.dp)
    val page = (width + spacing) * basis - spacing
    return PaddingValues(end = width - page)
}

@Composable
fun CarouselNumbers(basis: Float?, loop: Boolean) {
    val state = rememberCarouselState(pageCount = carouselSlides.size, loop = loop)
    BoxWithConstraints(Modifier.fillMaxWidth()) {
        val width = maxWidth
        Carousel(state = state, modifier = Modifier.fillMaxWidth()) {
            CarouselContent(contentPadding = carouselPeek(width, basis)) { page ->
                CarouselItem {
                    Card(size = if (basis != null) CardSize.Sm else CardSize.Default) {
                        CardContent {
                            Box(Modifier.fillMaxWidth().aspectRatio(1f), contentAlignment = Alignment.Center) {
                                Text(
                                    carouselSlides[page].toString(),
                                    style = Typography.xl3.copy(fontWeight = FontWeight.SemiBold),
                                )
                            }
                        }
                    }
                }
            }
            Row(
                Modifier.fillMaxWidth().padding(top = 12.dp),
                horizontalArrangement = Arrangement.SpaceBetween,
                verticalAlignment = Alignment.CenterVertically,
            ) {
                CarouselPrevious()
                CarouselNext()
            }
        }
    }
}

## API Reference

<Only platform="rn">

### Carousel

Root that holds the scroll state and options.

Also accepts the props of `React.ComponentProps<typeof CarouselPrimitive.Root>`.

Use `opts` for `loop`, `align` (`start` or `center`) and `dragFree`. Pass `autoplay` as `true` for the default 5-second delay, or as a number of milliseconds. Use `setApi` to get a `CarouselApi` for scrolling from outside, or call `useCarousel()` inside the carousel to read the selected index and scroll state.

### CarouselContent

Scrolling track for the slides.

Also accepts the props of `React.ComponentProps<typeof CarouselPrimitive.Content>`.

### CarouselItem

One slide.

Also accepts the props of `React.ComponentProps<typeof CarouselPrimitive.Item>`.

### CarouselPrevious

Button that scrolls to the previous slide.

Also accepts the props of `React.ComponentProps<typeof Button>`.

### CarouselNext

Button that scrolls to the next slide.

Also accepts the props of `React.ComponentProps<typeof Button>`.

Arrow icons are mirrored in right-to-left layouts.

### CarouselControls

Row that lays out dots and buttons below the slides.

Also accepts the props of `ViewProps`.

Put `CarouselDots`, `CarouselPlayButton` and the previous and next buttons inside it to show them in a row below the slides.

### CarouselDots

One pressable dot per snap point.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "plain"` | `"default"` |
