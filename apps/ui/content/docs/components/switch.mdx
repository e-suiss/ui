`Switch` wraps the switch primitive of the chosen base and renders the track and thumb together. The thumb stretches while pressed, and the track fills with the primary color when on.

Use a switch for settings that take effect immediately. To select an option in a form that's submitted later, use `Checkbox`.

## Accessibility

- Renders with the `switch` role and `aria-checked`.
- Give it a name with `aria-label` or by wrapping it in a `Label`.
- `Space` toggles the focused switch.
- A disabled switch ignores clicks and keyboard presses.

## API Reference

### Switch

The switch track and its sliding thumb.

<OnlyBase base="base radix">

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"sm" \| "default"` | `"default"` |
| `checked` | `boolean` | — |
| `defaultChecked` | `boolean` | `false` |
| `onCheckedChange` | `(checked: boolean) => void` | — |
| `disabled` | `boolean` | `false` |

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"sm" \| "default"` | `"default"` |
| `isSelected` | `boolean` | — |
| `defaultSelected` | `boolean` | `false` |
| `onChange` | `(isSelected: boolean) => void` | — |
| `isDisabled` | `boolean` | `false` |
| `isInvalid` | `boolean` | `false` |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base radix">

Use `defaultChecked` for an uncontrolled switch, or `checked` with `onCheckedChange` to control it. `onCheckedChange` is called when the switch is toggled.

</OnlyBase>

<OnlyBase base="aria">

Use `defaultSelected` for an uncontrolled switch, or `isSelected` with `onChange` to control it. `onChange` is called when the switch is toggled.

</OnlyBase>

A transparent hit area extends around the track to make it easier to tap, and the thumb's travel flips in right-to-left layouts. The parts set `data-slot="switch"` and `data-slot="switch-thumb"`, plus `data-size` and the primitive's state attributes, for styling.

</Only>

Use a switch for settings that take effect immediately. For choices that are submitted later, use Checkbox. The switch has a hit slop around it, so it is easier to press than its visual size.

## Usage

<Only platform="rn">

```tsx
import * as React from "react"
import { Switch } from "@/components/ui/switch"

function SwitchDemo({ initial = false }: { initial?: boolean }) {
  const [checked, setChecked] = React.useState(initial)
  return <Switch checked={checked} onCheckedChange={setChecked} />
}

export function SwitchExample() {
  return (
    <SwitchDemo />
  )
}
```

</Only>

<Only platform="swift">

```swift
import SwiftUI

struct SwitchExample: View {
  var body: some View {
    SwitchDemo(initial: false)
  }
}

struct SwitchDemo: View {
  var size: SwitchStyle.Size = .default
  var label: LocalizedStringKey?

  @State private var checked: Bool

  init(initial: Bool, size: SwitchStyle.Size = .default, label: LocalizedStringKey? = nil) {
    self.size = size
    self.label = label
    _checked = State(initialValue: initial)
  }

  var body: some View {
    if let label {
      Toggle(isOn: $checked) { EmptyView() }
        .toggleStyle(.switch(size: size))
        .accessibilityLabel(Text(label))
    } else {
      Toggle(isOn: $checked) { EmptyView() }
        .toggleStyle(.switch(size: size))
    }
  }
}
```

</Only>

## Accessibility

- The root has the `switch` role and reports `checked` and `disabled` in its accessibility state, so VoiceOver and TalkBack announce whether it is on.
- The thumb is hidden from the accessibility tree.
- Label every switch with `accessibilityLabel` or `accessibilityLabelledBy`.
- The thumb animation follows the system reduce motion setting.

</Only>

## API Reference

<Only platform="rn">

### Switch

The switch track and its sliding thumb.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `SwitchSize` | `"default"` |
| `invalid` | `boolean` | - |

Also accepts the props of `React.ComponentProps<typeof SwitchPrimitives.Root>`.

Use `defaultChecked` for an uncontrolled switch, or `checked` with `onCheckedChange` to control it. `invalid` adds a destructive border when the switch is not disabled. A disabled switch is shown at `opacity-50`.

A switch has no visible text of its own. Pair it with a `Label` and link them with `accessibilityLabelledBy` and the label's `nativeID`, or set an `accessibilityLabel`. Give the `Label` an `onPress` that toggles the value if the label should be pressable too.

</Only>
