`Switch` wraps the Base UI Switch primitive and renders the track and thumb together. The thumb stretches while pressed, and the track fills with the accent color when on.

Use a switch for settings that take effect immediately. To select an option in a form that's submitted later, use `Checkbox`.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add switch
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @base-ui/react cn
```

2. Copy the source into `components/ui/switch.tsx`:

<ComponentSource path="components/ui/switch.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Switch } from "@/components/ui/switch"
```

```tsx
<Switch aria-label="Wi-Fi" />
```

Use `defaultChecked` for an uncontrolled switch, or `checked` with `onCheckedChange` to control it. Wrap the switch and its text in a `Label` so the text toggles it too.

## API Reference

<ApiPart index={1}>

### Switch

The switch track and its sliding thumb.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "default"` | `"default"` | Sets the switch size: `default` or the smaller `sm`. |

Also accepts the props of `SwitchPrimitive.Root.Props`.

</ApiPart>

## Accessibility

- Renders with the `switch` role and `aria-checked`.
- Give it a name with `aria-label` or by wrapping it in a `Label`.
- `Space` toggles the focused switch.
- A disabled switch sets `aria-disabled` and ignores clicks.

## Notes

- Uses `data-slot="switch"` and `data-slot="switch-thumb"`, plus `data-size` and Base UI's `data-checked`, `data-unchecked` and `data-disabled` attributes.
- An invalid switch draws a `destructive` border.
- A transparent hit area extends around the track to make it easier to tap.
- The thumb's travel flips in right-to-left layouts.

`Switch` is a pressable track with a round thumb that slides between the off and on positions. The thumb animates with Reanimated and stretches slightly while pressed. It comes in two sizes, `default` and `sm`, and has an `invalid` state that adds a danger-colored border.

Use a switch for settings that take effect immediately. For choices that are submitted later, use Checkbox.

## Usage

```tsx
import { Switch } from "@/components/ui/switch"
```

```tsx
<SwitchDemo />
```

Use `defaultChecked` for an uncontrolled switch, or `checked` with `onCheckedChange` to control it.

A switch has no visible text of its own. Pair it with a `Label` and link them with `accessibilityLabelledBy` and the label's `nativeID`, or set an `accessibilityLabel`. Give the `Label` an `onPress` that toggles the value if the label should be pressable too.

The switch has a hit slop around it, so it is easier to press than its visual size.

### Switch

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `SwitchSize` | `"default"` | `default` or `sm`. |

Also accepts the props of `React.ComponentProps<typeof SwitchPrimitives.Root>`.

</ApiPart>

## Accessibility

- The root has the `switch` role and reports `checked` and `disabled` in its accessibility state, so VoiceOver and TalkBack announce whether it is on.
- The thumb is hidden from the accessibility tree.
- Label every switch with `accessibilityLabel` or `accessibilityLabelledBy`.
- The thumb animation follows the system reduce motion setting.

## Notes

- The track uses `bg-primary` when on and `bg-input` when off, with `opacity-50` when disabled.
- The thumb uses `bg-background`, or `bg-foreground` in dark mode.
- Light and dark colors follow the system appearance.
