<Only platform="rn">

`SignaturePad` is a `View` with a single-finger pan gesture from `react-native-gesture-handler`. Each touch records a stroke of points, and the strokes are drawn as smoothed paths with `react-native-svg`. A signature line with an `×` mark and a placeholder sits near the bottom, and a ghost Clear button appears in the top corner once something is drawn.

</Only>

## Usage

<Only platform="rn">

```tsx
import { SignaturePad } from "@/components/ui/signature-pad"
```

```tsx
<SignaturePad />
```

</Only>

<Only platform="swift">

```swift
import SwiftUI

struct SignaturePadExample: View {
  var body: some View {
    SignaturePadDemo(initial: [])
  }
}

struct SignaturePadDemo: View {
  var strokeWidth: CGFloat = 2.5

  @State private var strokes: [SignatureStroke]

  init(initial: [SignatureStroke], strokeWidth: CGFloat = 2.5) {
    self.strokeWidth = strokeWidth
    _strokes = State(initialValue: initial)
  }

  var body: some View {
    SignaturePad(value: $strokes, strokeWidth: strokeWidth)
      .frame(height: 192)
      .frame(maxWidth: .infinity)
  }
}
```

## Accessibility

- The pad is a single accessible element labeled by `accessibilityLabel`.
- Its value is announced as "Empty" or "Signed", and `disabled` is reported in its state.
- When it has a signature and is not disabled, it offers a `clear` accessibility action, so VoiceOver and TalkBack users can clear it without finding the button.

</Only>

## API Reference

<Only platform="rn">

### SignaturePad

The `SignaturePad` component captures a handwritten signature as strokes.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `SignaturePadStroke[]` | - |
| `defaultValue` | `SignaturePadStroke[]` | - |
| `onChange` | `(value: SignaturePadStroke[]) => void` | - |
| `strokeWidth` | `number` | `2.5` |
| `disabled` | `boolean` | `false` |
| `placeholder` | `React.ReactNode` | `"Sign here"` |
| `clearLabel` | `React.ReactNode` | `"Clear"` |
| `ref` | `React.Ref<SignaturePadHandle>` | - |

Also accepts the props of `React.ComponentProps<typeof View>`.

Use it uncontrolled with `defaultValue`, or controlled with `value` and `onChange`. The value is an array of strokes, where each stroke is an array of `{ x, y }` points. `onChange` is called with the full list of strokes after each stroke ends or the pad is cleared. Points closer than one point to the previous point are skipped while drawing. `disabled` turns off drawing, hides the Clear button and dims the pad. `placeholder` is shown on the signature line while the pad is empty.

Pass a `ref` to get a `SignaturePadHandle` with `toSVG()`, `clear()` and `isEmpty()`. `toSVG` returns an SVG string sized to the pad and accepts an optional `color` (defaults to `currentColor`). The `SignaturePadHandle`, `SignaturePadPoint` and `SignaturePadStroke` types are also exported.

</Only>
