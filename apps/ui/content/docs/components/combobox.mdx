Combobox is built on the Base UI Combobox. The `Combobox` root takes the `items` to choose from and holds the value. `ComboboxInput` renders the text field inside an `InputGroup`, with an optional button that opens the list and an optional clear button. `ComboboxContent` renders the popup in a portal; inside it, `ComboboxList` renders each item through a render function, `ComboboxEmpty` appears when nothing matches, and `ComboboxItem` shows a check mark when selected. Group related items with `ComboboxGroup`, `ComboboxLabel`, `ComboboxCollection` and `ComboboxSeparator`.

For multiple selection, replace `ComboboxInput` with `ComboboxChips`, which shows each selected value as a `ComboboxChip` next to a `ComboboxChipsInput`. Use a combobox when the list is long enough that typing to filter helps. For a short, fixed list without filtering, use a select; for a list of actions rather than values, use a command menu.

## Usage

```tsx
import { ComboboxValue, ComboboxTrigger, ComboboxInput, ComboboxContent, ComboboxList, ComboboxItem, ComboboxGroup, ComboboxLabel, ComboboxCollection, ComboboxEmpty, ComboboxSeparator, ComboboxChips, ComboboxChip, ComboboxChipsInput } from "@/components/ui/combobox"
```

```tsx
<div className="w-72">
  <Combobox items={frameworks}>
    <ComboboxInput
      placeholder="Select a framework"
      disabled={false}
    />
    <ComboboxContent>
      <ComboboxEmpty>No framework found.</ComboboxEmpty>
      <ComboboxList>
        {(item: string) => (
          <ComboboxItem key={item} value={item}>
            {item}
          </ComboboxItem>
        )}
      </ComboboxList>
    </ComboboxContent>
  </Combobox>
</div>
```

Pass `items` to the root and a function as the child of `ComboboxList`, which receives each item and returns a `ComboboxItem` with a matching `value`. The value is uncontrolled with `defaultValue`, or controlled with `value` and `onValueChange`. To read or control the typed text, use `inputValue` and `onInputValueChange`.

For grouped data, pass groups as `items`, render a `ComboboxGroup` with its own `items` for each one, and render its items with `ComboboxCollection`. For multiple selection, set `multiple` on the root, create a ref with `useComboboxAnchor`, attach it to `ComboboxChips`, and pass it as `anchor` to `ComboboxContent` so the popup aligns to the chips field. Use `ComboboxValue` with a render function to map the selected values to chips.

## Accessibility

- The input has the `combobox` role and sets `aria-expanded` to reflect whether the list is open.
- The popup has the `listbox` role, options have the `option` role and selected options set `aria-selected`; groups have the `group` role and take their name from `ComboboxLabel`.
- Typing filters the options. Arrow keys move the highlight, Enter selects the highlighted option, and Escape closes the list.
- In multiple selection, Backspace in the empty input removes the last chip.
- The open button is labelled `Show options` and the clear button is labelled `Clear`.
- When disabled, the input and the open button are disabled and removed from the Tab order.
- Give the input an accessible name with a visible label or `aria-label`.

## Notes

- Styling hooks: `data-slot` values such as `combobox-content`, `combobox-list`, `combobox-item`, `combobox-label`, `combobox-empty`, `combobox-chips`, `combobox-chip`, `combobox-chip-remove` and `combobox-chip-input`.
- Highlighted items get `data-highlighted` and disabled items get `data-disabled`.
- The popup matches the width of its anchor through `--anchor-width` and limits its height to the available space.
- Uses the `popover`, `accent`, `primary`, `secondary` and `border` colors.

`Combobox` pairs a text input with a floating list that filters its `items` as the user types. `ComboboxInput` draws the field with a caret trigger and an optional clear button, and `ComboboxContent` renders the list through a portal (inside a full-window overlay on iOS), positioned below the input and as wide as it.

For multiple selection, set `multiple` and use `ComboboxChips` with a `ComboboxChip` per selected value and a `ComboboxChipsInput` for typing. Each chip has a remove button.

## Usage

```tsx
import { ComboboxTrigger, ComboboxInput, ComboboxContent, ComboboxList, ComboboxItem, ComboboxGroup, ComboboxLabel, ComboboxEmpty, ComboboxSeparator, ComboboxChips, ComboboxChip, ComboboxChipsInput } from "@/components/ui/combobox"
```

```tsx
<ComboboxDemo defaultValue="Expo" defaultOpen />
```

Pass `items` to the root and render the filtered list with a function child of `ComboboxList`. For grouped items, render a `ComboboxGroup` per group with a `ComboboxLabel` and a `ComboboxCollection`. Add `ComboboxEmpty` for the no-results message.

Use `value`, `defaultValue` and `onValueChange` for the selection, and `inputValue` with `onInputValueChange` for the typed text. For object items, provide `itemToStringLabel`. `filter`, `limit` and `locale` tune matching.

With chips, create a ref with `useComboboxAnchor()`, attach it to `ComboboxChips`, and pass it to `ComboboxContent` as `anchor` so the list lines up with the chips field. On `ComboboxInput`, set `showClear` to add a clear button and `showTrigger={false}` to hide the caret.

## Accessibility

- The input has the `combobox` role with `expanded` and `disabled` state.
- Items have the `option` role with `selected` and `disabled` state; the list has the `list` role.
- The empty message is a polite live region.
- The trigger, clear and chip remove buttons are labelled "Show options", "Clear" and "Remove".

## Notes

- Uses `bg-secondary`, `bg-popover`, `border-ring` and `border-destructive` tokens; light and dark follow the system appearance.
- In Uniwind and NativeWind, a focused field also draws the `ring-3 ring-ring/50` focus ring.
- Fade animations respect the system Reduce Motion setting.
