Avatar wraps the avatar primitive of the chosen base. An `Avatar` contains an `AvatarImage` and an `AvatarFallback`; the fallback shows while the image is loading or if it fails to load. Add an `AvatarBadge` to show a status dot or icon in the bottom-end corner.

To show several people together, place avatars in an `AvatarGroup`, which overlaps them and rings each one with the background color. End the group with an `AvatarGroupCount` to indicate how many more people there are.

## Usage

```tsx
import {
  Avatar,
  AvatarBadge,
  AvatarFallback,
  AvatarGroup,
  AvatarGroupCount,
  AvatarImage,
} from "@/components/ui/avatar"
```

```tsx
<Avatar>
  <AvatarImage src={people[0].src} alt={people[0].name} />
  <AvatarFallback>{people[0].initials}</AvatarFallback>
</Avatar>
```

## Composition

Use the following composition to build a `Avatar`:

```text
Avatar
├── AvatarImage
├── AvatarFallback
└── AvatarBadge
AvatarGroup
├── Avatar
│   ├── AvatarImage
│   └── AvatarFallback
└── AvatarGroupCount
```

## Accessibility

- Give `AvatarImage` an `alt` that names the person.
- `AvatarBadge` and `AvatarGroupCount` are plain elements; if they carry meaning, label them or describe the status in nearby text.

## API Reference

### Avatar

The circular root that sets the size.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"default" \| "sm" \| "lg" \| "xl"` | `"default"` |

Also accepts the props of the primitive part it wraps.

`size` sets the diameter and also scales the fallback text and badge. It is exposed as `data-size`.

### AvatarImage

The person's image, cropped to a circle.

Also accepts the props of the primitive part it wraps.

### AvatarFallback

Content shown when the image is missing or still loading.

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `delay` | `number` | - |

`delay` is the number of milliseconds to wait before showing the fallback.

</OnlyBase>

Also accepts the props of the primitive part it wraps.

Always provide an `AvatarFallback` alongside `AvatarImage`, usually the person's initials. The fallback can also hold an icon, which scales to 60% of the avatar. It uses a vertical gradient of `muted-foreground` with `text-primary-foreground`.

### AvatarBadge

A small status indicator pinned to the bottom-end corner.

Also accepts the props of `React.ComponentProps<"span">`.

The badge uses `bg-primary` by default; override it, for example with `bg-green-500`. At the `sm` size, icons inside the badge are hidden.

### AvatarGroup

A row that overlaps avatars with a ring between them.

Also accepts the props of `React.ComponentProps<"div">`.

### AvatarGroupCount

A trailing circle that shows how many avatars are not displayed.

Also accepts the props of `React.ComponentProps<"div">`.

Inside an `AvatarGroup`, `AvatarGroupCount` matches the size of the avatars in the group automatically.

Each part sets a `data-slot`, such as `avatar`, `avatar-fallback` or `avatar-group-count`, for styling.

</Only>

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.Row
import androidx.compose.runtime.Composable
import androidx.compose.runtime.remember
import androidx.compose.ui.graphics.Brush
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.graphics.painter.BrushPainter
import androidx.compose.ui.semantics.contentDescription
import com.esuiss.ui.components.Avatar
import com.esuiss.ui.components.AvatarFallback
import com.esuiss.ui.components.AvatarSize
import com.esuiss.ui.theme.Palette

class AvatarPerson(val name: String, val initials: String, val tones: @Composable () -> List<Color>)

val avatarPeople = listOf(
    AvatarPerson("Ada Lovelace", "AL") { listOf(Palette.pink500, Palette.purple500) },
    AvatarPerson("Alan Turing", "AT") { listOf(Palette.teal500, Palette.blue500) },
    AvatarPerson("Grace Hopper", "GH") { listOf(Palette.orange500, Palette.red500) },
)

@Composable
fun AvatarPhoto(person: AvatarPerson, size: AvatarSize = AvatarSize.Default, badge: (@Composable () -> Unit)? = null) {
    val tones = person.tones()
    val photo = remember(tones) { BrushPainter(Brush.linearGradient(tones)) }
    Avatar(
        size = size,
        image = photo,
        contentDescription = person.name,
        badge = badge,
        fallback = { AvatarFallback(person.initials) },
    )
}

@Composable
fun AvatarDefault() {
    Row {
        AvatarPhoto(avatarPeople[0])
    }
}
```

## API Reference

<Only platform="rn">

### Avatar

Round container that sets the size.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `AvatarSize` | `"default"` |

Also accepts the props of `React.ComponentProps<typeof AvatarPrimitive.Root>`.

### AvatarImage

Image that appears once it has loaded.

Also accepts the props of `React.ComponentProps<typeof AvatarPrimitive.Image>`.

Give `AvatarImage` a `source` and an `alt`. Use `onLoadingStatusChange` to react to loading.

### AvatarFallback

Initials or icon shown while the image is missing.

Also accepts the props of `React.ComponentProps<typeof AvatarPrimitive.Fallback>`.

Put initials or an `Icon` in the fallback; plain strings are wrapped in `Text`. Use `delay` to avoid a flash on fast connections. The fallback is softer in dark mode.

### AvatarBadge

Status dot in the bottom-end corner.

Also accepts the props of `React.ComponentProps<typeof View>`, `React.RefAttributes<View>`.

### AvatarGroup

Row that overlaps its avatars.

Also accepts the props of `React.ComponentProps<typeof View>`, `React.RefAttributes<View>`.

### AvatarGroupCount

Round counter for the remaining items in a group.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `AvatarSize` | `"default"` |

Also accepts the props of `React.ComponentProps<typeof View>`, `React.RefAttributes<View>`.

Set `size` to match the avatars in the group.

</Only>
