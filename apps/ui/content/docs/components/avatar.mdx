Avatar wraps the avatar primitive of the chosen base. An `Avatar` contains an `AvatarImage` and an `AvatarFallback`; the fallback shows while the image is loading or if it fails to load. Add an `AvatarBadge` to show a status dot or icon in the bottom-end corner.

To show several people together, place avatars in an `AvatarGroup`, which overlaps them and rings each one with the background color. End the group with an `AvatarGroupCount` to indicate how many more people there are.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/avatar
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add avatar
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install @base-ui/react
```

2. Copy the source into `components/ui/avatar.tsx`:

<ComponentSource path="components/ui/avatar.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Avatar, AvatarImage, AvatarFallback, AvatarBadge, AvatarGroup, AvatarGroupCount } from "@/components/ui/avatar"
```

```tsx
<Avatar>
  <AvatarImage src={people[0].src} alt={people[0].name} />
  <AvatarFallback>{people[0].initials}</AvatarFallback>
</Avatar>
```

Always provide an `AvatarFallback` alongside `AvatarImage`, usually the person's initials. The fallback can also hold an icon, which scales to 60% of the avatar.

Set `size` on each `Avatar`. Inside an `AvatarGroup`, `AvatarGroupCount` matches the size of the avatars in the group automatically.

## Accessibility

- Give `AvatarImage` an `alt` that names the person.
- `AvatarBadge` and `AvatarGroupCount` are plain elements; if they carry meaning, label them or describe the status in nearby text.

## Notes

- Styling hooks: `data-slot="avatar"`, `"avatar-image"`, `"avatar-fallback"`, `"avatar-badge"`, `"avatar-group"` and `"avatar-group-count"`, plus `data-size` on the root.
- `AvatarBadge` uses `bg-primary` by default; override it, for example with `bg-green-500`. At the `sm` size, icons inside the badge are hidden.
- The fallback uses a vertical gradient of `muted-foreground` with `text-primary-foreground`.

</Only>

`Avatar` is a round `View` that holds an `AvatarImage` and an `AvatarFallback`. The image stays hidden until it loads, and the fallback is shown while it loads or if it fails. Four sizes are available: `sm`, `default`, `lg` and `xl`; the fallback text, icons and badge scale with the size.

`AvatarBadge` adds a small status dot in the bottom-end corner, and `AvatarGroup` overlaps several avatars with an outline between them, with `AvatarGroupCount` for the remaining number.

## Usage

<Only platform="rn">

```tsx
import { Avatar, AvatarImage, AvatarFallback, AvatarBadge, AvatarGroup, AvatarGroupCount } from "@/components/ui/avatar"

```

```tsx

  <AvatarImage
    alt="Ada Lovelace"
    source={{ uri: "https://i.pravatar.cc/150?img=5" }}

    <Text>AL</Text>
  </AvatarFallback>
</Avatar>
```

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.Row
import androidx.compose.runtime.Composable
import androidx.compose.runtime.remember
import androidx.compose.ui.graphics.Brush
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.graphics.painter.BrushPainter
import androidx.compose.ui.semantics.contentDescription
import com.esuiss.ui.components.Avatar
import com.esuiss.ui.components.AvatarFallback
import com.esuiss.ui.components.AvatarSize
import com.esuiss.ui.theme.Palette

class AvatarPerson(val name: String, val initials: String, val tones: @Composable () -> List<Color>)

val avatarPeople = listOf(
    AvatarPerson("Ada Lovelace", "AL") { listOf(Palette.pink500, Palette.purple500) },
    AvatarPerson("Alan Turing", "AT") { listOf(Palette.teal500, Palette.blue500) },
    AvatarPerson("Grace Hopper", "GH") { listOf(Palette.orange500, Palette.red500) },
)

@Composable
fun AvatarPhoto(person: AvatarPerson, size: AvatarSize = AvatarSize.Default, badge: (@Composable () -> Unit)? = null) {
    val tones = person.tones()
    val photo = remember(tones) { BrushPainter(Brush.linearGradient(tones)) }
    Avatar(
        size = size,
        image = photo,
        contentDescription = person.name,
        badge = badge,
        fallback = { AvatarFallback(person.initials) },
    )
}

@Composable
fun AvatarDefault() {
    Row {
        AvatarPhoto(avatarPeople[0])
    }
}
```

</Only>

<Only platform="rn">

Give `AvatarImage` a `source` and an `alt`. Put initials or an `Icon` in `AvatarFallback`; plain strings are wrapped in `Text`. Use `delay` on the fallback to avoid a flash on fast connections, and `onLoadingStatusChange` on the image to react to loading.

</Only>

Set `size` on each `Avatar`, and pass the same `size` to `AvatarGroupCount`. On the `sm` size, the badge hides its children and shows a plain dot.

## Accessibility

- `AvatarImage` uses `alt` as its `accessibilityLabel`.
- The image is hidden from screen readers until it has loaded.
- The badge has no label; describe the status in nearby text if it matters.

## Notes

- Uses `bg-muted-foreground`, `bg-primary`, `bg-muted` and `border-background` tokens; the fallback is softer in dark mode.
- Light and dark follow the system appearance.
