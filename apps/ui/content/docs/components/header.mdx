<NativeExample name="header-demo" />

`Header` is a 44-point bar that sorts its children into three slots: `HeaderBack` and leading `HeaderActions` on the start side, `HeaderTitle` in the center, and everything else on the end side. The side slots share the remaining width equally, so the title stays centered.

<Only platform="swift">

```swift
import SwiftUI

struct HeaderExample: View {
  var body: some View {
    Header {
      HeaderTitle("Profile")
    } leading: {
      HeaderBack("Settings")
    } trailing: {
      HeaderActions {
        Button {} label: {
          Text("Edit").fontWeight(.semibold)
        }
        .buttonStyle(.variant(.plain, size: .sm))
      }
    }
    .headerStoryBleed()
  }
}

extension View {
  func headerStoryBleed() -> some View {
    padding(.horizontal, -16).padding(.top, -16)
  }
}
```

</Only>

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.Column
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.layout.layout
import androidx.compose.ui.text.TextStyle
import androidx.compose.ui.text.font.FontWeight
import androidx.compose.ui.unit.dp
import com.esuiss.ui.components.Button
import com.esuiss.ui.components.ButtonSize
import com.esuiss.ui.components.ButtonVariant
import com.esuiss.ui.components.Header
import com.esuiss.ui.components.HeaderActions
import com.esuiss.ui.components.HeaderBack
import com.esuiss.ui.components.HeaderTitle
import com.esuiss.ui.components.Text

fun Modifier.headerBleed(): Modifier = layout { measurable, constraints ->
    val inset = 16.dp.roundToPx()
    val width = constraints.maxWidth + inset * 2
    val placeable = measurable.measure(constraints.copy(minWidth = width, maxWidth = width))
    layout(constraints.maxWidth, (placeable.height - inset).coerceAtLeast(0)) {
        placeable.place(-inset, -inset)
    }
}

@Composable
fun HeaderPlainAction(text: String) {
    Button(onClick = {}, variant = ButtonVariant.Plain, size = ButtonSize.Sm) {
        Text(text, style = TextStyle(fontWeight = FontWeight.SemiBold))
    }
}

@Composable
fun HeaderDefault() {
    Column(Modifier.headerBleed()) {
        Header {
            HeaderBack(onClick = {}, text = "Settings")
            HeaderTitle("Profile")
            HeaderActions { HeaderPlainAction("Edit") }
        }
    }
}
```

### Large title

A large title that collapses into the bar on scroll.

<Only platform="rn">

Create a scroll state with `useHeaderScroll()`, pass it to both `Header` and `HeaderScrollView`, and put a `HeaderLargeTitle` at the top of the scroll view. As the large title scrolls away, the small title fades in and a hairline appears under the bar. Pulling down stretches the large title slightly.

## Accessibility

- `HeaderTitle` and a string `HeaderLargeTitle` have the `heading` role.
- `HeaderBack` has the `button` role and is labelled with its text, or "Back" when it has none.
- Give icon-only actions an `accessibilityLabel`.

</Only>

## API Reference

<Only platform="rn">

### Header

Bar that lays out the back button, title and actions.

| Prop | Type | Default |
| --- | --- | --- |
| `scroll` | `HeaderScroll` | - |

Also accepts the props of `ViewProps`.

`scroll` takes the scroll state from `useHeaderScroll()`. Colors follow light and dark mode with the system appearance.

### HeaderTitle

Centered title with optional subtitle.

| Prop | Type | Default |
| --- | --- | --- |
| `subtitle` | `React.ReactNode` | - |

Also accepts the props of `ViewProps`.

### HeaderLargeTitle

Large title at the top of the scroll content.

| Prop | Type | Default |
| --- | --- | --- |
| `subtitle` | `React.ReactNode` | - |

Also accepts the props of `ViewProps`.

In right-to-left layouts the large title scales from the correct edge.

### HeaderBack

Back button with a caret and optional label.

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `React.ReactNode` | - |

Also accepts the props of `React.ComponentProps<typeof Pressable>`.

Pass a text label such as the previous screen's name as `children`, and wire `onPress` to your navigation. The button dims to `opacity-80` while pressed, and the caret rotates in right-to-left layouts.

### HeaderActions

Row of actions for either side.

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"leading" \| "trailing"` | `"trailing"` |

Also accepts the props of `ViewProps`.

Group icon buttons in `HeaderActions`.

### HeaderScrollView

Scroll view that drives the header animations.

| Prop | Type | Default |
| --- | --- | --- |
| `scroll` | `HeaderScroll` | Required |

Also accepts the props of `ScrollViewProps`.

Pass the same scroll state from `useHeaderScroll()` that the `Header` gets.

</Only>
