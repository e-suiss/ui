`Checkbox` wraps the checkbox primitive and renders a check icon inside its indicator when checked. It is a single self-contained part: there are no child components to compose.

Use a checkbox for independent options that people can select in any combination, such as accepting terms or opting in to email. For a mutually exclusive choice, use a radio group; for a setting that takes effect immediately, consider a switch.

## Accessibility

- Renders with the `checkbox` role and exposes its checked state to assistive technology.
- Toggles on click and with Space when focused.
- Needs an accessible name: wrap it in a `Label`, associate a `Label` through `htmlFor` and `id`, or set `aria-label`.
- When `disabled`, it sets `aria-disabled`, ignores clicks, and is removed from the Tab order.

<OnlyBase base="base radix">

- Set `aria-invalid` to communicate a validation error; the border turns to the `destructive` color.

</OnlyBase>

<OnlyBase base="aria">

- Set `isInvalid` to communicate a validation error.

</OnlyBase>

## API Reference

### Checkbox

The checkbox control, rendering the box and its check indicator.

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `checked` | `boolean` | — |
| `defaultChecked` | `boolean` | — |
| `onCheckedChange` | `(checked: boolean) => void` | — |
| `disabled` | `boolean` | — |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

Leave the checkbox uncontrolled with `defaultChecked`, or control it with `checked` and `onCheckedChange`.

<OnlyBase base="aria">

The props map to React Aria: `checked` to `isSelected`, `defaultChecked` to `defaultSelected` and `disabled` to `isDisabled`. `onCheckedChange` is called with the new checked state, alongside `onChange`.

</OnlyBase>

The hit area extends beyond the visible box through an `after` pseudo-element, so the small control is easier to tap. The root sets `data-slot="checkbox"` and the indicator `data-slot="checkbox-indicator"` for styling.

</Only>

## Usage

<Only platform="rn">

```tsx
import * as React from "react"
import { Checkbox } from "@/components/ui/checkbox"

function CheckboxDemo({ initial = false }: { initial?: boolean }) {
  const [checked, setChecked] = React.useState(initial)
  return <Checkbox checked={checked} onCheckedChange={setChecked} />
}

export function CheckboxExample() {
  return (
    <CheckboxDemo />
  )
}
```

</Only>

<Only platform="swift">

```swift
import SwiftUI

struct CheckboxExample: View {
  var body: some View {
    CheckboxDemo(initial: false)
  }
}

struct CheckboxDemo: View {
  @State private var checked: Bool

  init(initial: Bool) {
    _checked = State(initialValue: initial)
  }

  var body: some View {
    Toggle(isOn: $checked) { EmptyView() }
      .toggleStyle(.checkbox)
  }
}
```

</Only>

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.Row
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.saveable.rememberSaveable
import androidx.compose.runtime.setValue
import com.esuiss.ui.components.Checkbox

@Composable
fun CheckboxExample() {
    CheckboxDemo(initial = false)
}

@Composable
fun CheckboxDemo(initial: Boolean) {
    var checked by rememberSaveable { mutableStateOf(initial) }
    Row {
        Checkbox(checked, { checked = it })
    }
}
```

## API Reference

<Only platform="rn">

### Checkbox

The checkbox control, rendering the box and its check indicator.

| Prop | Type | Default |
| --- | --- | --- |
| `iconClassName` | `string` | - |
| `invalid` | `boolean` | - |

Also accepts the props of `React.ComponentProps<typeof CheckboxPrimitive.Root>`.

Use `checked` with `onCheckedChange` for controlled state, or `defaultChecked` for uncontrolled. Set `indeterminate` for a parent checkbox whose children are partly selected. `iconClassName` adds classes to the check icon, and `invalid` shows a destructive border. In dark mode the unchecked box is filled instead of outlined.

</Only>
