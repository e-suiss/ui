`Checkbox` wraps the Base UI `Checkbox.Root` and renders a check icon inside a `Checkbox.Indicator` when checked. It is a single self-contained part: there are no child components to compose.

Use a checkbox for independent options that people can select in any combination, such as accepting terms or opting in to email. For a mutually exclusive choice, use a radio group; for a setting that takes effect immediately, consider a switch.

Leave the checkbox uncontrolled with `defaultChecked`, or control it with `checked` and `onCheckedChange`. Pair it with a visible `Label`: wrapping the checkbox in `Label` makes the whole label text clickable. To add supporting text, give the checkbox an `id` and an `aria-describedby` that points to the description element.

## Accessibility

- Renders with the `checkbox` role and exposes its checked state to assistive technology.
- Toggles on click and with Space when focused.
- Needs an accessible name: wrap it in a `Label`, associate a `Label` through `htmlFor` and `id`, or set `aria-label`.
- When `disabled`, it sets `aria-disabled`, ignores clicks, and is removed from the Tab order.
- Set `aria-invalid` to communicate a validation error; the border turns to the `danger` color.

## Notes

- Styling hooks: `data-slot="checkbox"` on the root and `data-slot="checkbox-indicator"` on the indicator.
- State attributes from Base UI such as `data-checked` and `data-disabled` drive the checked and disabled styles.
- Uses the `accent`, `accent-pressed`, `on-accent`, `surface`, `control` and `control-disabled` tokens.
- The hit area extends beyond the visible box through an `after` pseudo-element, making the small control easier to tap.

`Checkbox` is a `Pressable` with the `checkbox` role that shows a check icon when checked and a minus icon when `indeterminate`. It has an enlarged hit area around the box so it is easy to tap.

Use it for options that can be combined, such as terms acceptance or multi-select lists. For a single on/off setting that applies right away, use Switch.

<Code lang="tsx" code={"<CheckboxDemo />"} />

Use `checked` with `onCheckedChange` for controlled state, or `defaultChecked` for uncontrolled. Set `indeterminate` for a parent checkbox whose children are partly selected.

Pair the checkbox with a `Label`: give the label a `nativeID` and the checkbox a matching `accessibilityLabelledBy`, and toggle the value from the label's `onPress`. Set `invalid` to show a danger border.

## Accessibility

- Has the `checkbox` role with `checked` (or `mixed` when indeterminate) and `disabled` state.
- Link it to a visible label with `accessibilityLabelledBy`, or give it an `accessibilityLabel`.

## Notes

- Uses `bg-accent` when checked and `bg-surface` with a translucent border when unchecked; in dark mode the unchecked box is filled instead of outlined.
- Light and dark follow the system appearance.
