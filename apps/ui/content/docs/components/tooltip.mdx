`Tooltip` wraps the Base UI Tooltip primitive. `TooltipTrigger` is the element that shows the tooltip, and `TooltipContent` renders the dark label with an arrow in a portal, positioned beside the trigger. `TooltipProvider` shares open delays across a group of tooltips.

Use tooltips to name icon-only buttons or show a keyboard shortcut. Keep the text short and don't put essential information or interactive content in a tooltip; use `Popover` for that.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/tooltip
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add tooltip
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install @base-ui/react
```

2. Copy the source into `components/ui/tooltip.tsx`:

<ComponentSource path="components/ui/tooltip.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { TooltipProvider, Tooltip, TooltipTrigger, TooltipContent } from "@/components/ui/tooltip"
```

```tsx
<TooltipProvider>
  <div className="p-12">
    <Tooltip>
      <TooltipTrigger render={<Button variant="outline" />}>
        Hover me
      </TooltipTrigger>
      <TooltipContent side="top">Add to library</TooltipContent>
    </Tooltip>
  </div>
</TooltipProvider>
```

Use the `render` prop on `TooltipTrigger` to render it as a `Button`. Set `side` on `TooltipContent` to place the tooltip on another side; it opens above the trigger by default, `4px` away. Place a `Kbd` inside `TooltipContent` to show a shortcut.

Wrap your app, or a toolbar of tooltips, in `TooltipProvider`. This wrapper sets the provider's `delay` to `0`, so tooltips open without waiting.

## Accessibility

- Tooltips open when the trigger is hovered or receives keyboard focus, and close when the pointer leaves.
- `Escape` closes an open tooltip while focus stays on the trigger.
- A tooltip doesn't name its trigger. Give icon-only triggers their own `aria-label`.

## Notes

- Parts carry `data-slot` attributes such as `tooltip-trigger` and `tooltip-content`; the popup and arrow set `data-side`.
- The label uses `bg-foreground` with `text-background`, so it inverts against the page in both light and dark appearances.
- `TooltipContent` accepts the positioner props `side`, `sideOffset`, `align` and `alignOffset`.
