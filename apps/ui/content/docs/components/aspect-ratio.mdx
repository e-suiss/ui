`AspectRatio` is a single `div` that sets the CSS `aspect-ratio` property from the `ratio` prop. Its width follows the parent, and its height is derived from the ratio. It is positioned `relative`, so children can be absolutely positioned inside it.

Use it to reserve space for images, video or embeds so the layout does not shift while media loads.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/aspect-ratio
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add aspect-ratio
```

## Usage

```tsx
import { AspectRatio } from "@/components/ui/aspect-ratio"
```

```tsx
<div className="w-96">
  <AspectRatio ratio={16 / 9} className="overflow-hidden rounded-2xl bg-muted">
    <img
      src="https://images.unsplash.com/photo-1506744038136-46273834b3fb?w=800&q=80"
      alt="Mountain lake at sunrise"
      className="size-full object-cover"
    />
  </AspectRatio>
</div>
```

Pass `ratio` as a number, typically written as a division such as `16 / 9`, `4 / 3` or `1`. Give media inside it `className="size-full object-cover"` to fill the frame. Add `overflow-hidden` and a radius class to clip the content to rounded corners.

<ApiPart index={1}>

### AspectRatio

The ratio-locked container.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `ratio` | `number` | Required | Width divided by height, for example `16 / 9`. Required. |

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

## Notes

- Styling hook: `data-slot="aspect-ratio"`.
- The ratio is passed through the `--ratio` CSS custom property and applied with the Tailwind class `aspect-(--ratio)`.

<Only platform="swift">

```swift
import SwiftUI

struct AspectRatioExample: View {
  var body: some View {
    AspectRatio(ratio: 16 / 9) {
      AspectRatioPhoto()
    }
    .clipShape(RoundedRectangle(cornerRadius: Radius.lg, style: .continuous))
    .frame(maxWidth: .infinity)
  }
}

struct AspectRatioPhoto: View {
  var body: some View {
    AsyncImage(
      url: URL(string: "https://images.unsplash.com/photo-1588345921523-c2dcdb7f1dcd?w=800&dpr=2&q=80")
    ) { phase in
      if let image = phase.image {
        image.resizable().scaledToFill()
      } else {
        EsuissColor.muted
      }
    }
    .frame(maxWidth: .infinity, maxHeight: .infinity)
  }
}
```

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.Image
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.foundation.layout.width
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.runtime.Composable
import androidx.compose.runtime.remember
import androidx.compose.ui.Modifier
import androidx.compose.ui.draw.clip
import androidx.compose.ui.graphics.Brush
import androidx.compose.ui.graphics.painter.BrushPainter
import androidx.compose.ui.layout.ContentScale
import androidx.compose.ui.unit.Dp
import com.adamglin.phosphoricons.regular.Image
import com.esuiss.ui.components.AspectRatio
import com.esuiss.ui.theme.EsuissTheme
import com.esuiss.ui.theme.Palette
import com.esuiss.ui.theme.Radius

@Composable
fun AspectRatioExample() {
    AspectRatioPhoto(null, 16f / 9f)
}

@Composable
fun AspectRatioPhoto(width: Dp?, ratio: Float) {
    val colors = EsuissTheme.colors
    val photo = remember(colors) { BrushPainter(Brush.linearGradient(listOf(Palette.teal500, Palette.blue500, Palette.indigo500))) }
    Box(
        (if (width != null) Modifier.width(width) else Modifier.fillMaxWidth())
            .clip(RoundedCornerShape(Radius.lg)),
    ) {
        AspectRatio(ratio) {
            Image(photo, contentDescription = null, modifier = Modifier.fillMaxSize(), contentScale = ContentScale.Crop)
        }
    }
}
```

</Only>
