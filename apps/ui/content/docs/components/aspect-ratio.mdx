`AspectRatio` is a single `div` that sets the CSS `aspect-ratio` property from the `ratio` prop. Its width follows the parent, and its height is derived from the ratio. It is positioned `relative`, so children can be absolutely positioned inside it.

Use it to reserve space for images, video or embeds so the layout does not shift while media loads.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add aspect-ratio
```

### Manual

1. Add the [`cn` helper](/docs/installation#the-cn-helper).

2. Copy the source into `components/ui/aspect-ratio.tsx`:

<ComponentSource path="components/ui/aspect-ratio.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { AspectRatio } from "@/components/ui/aspect-ratio"
```

```tsx
<div className="w-96">
  <AspectRatio ratio={16 / 9} className="overflow-hidden rounded-2xl bg-muted">
    <img
      src="https://images.unsplash.com/photo-1506744038136-46273834b3fb?w=800&q=80"
      alt="Mountain lake at sunrise"
      className="size-full object-cover"
    />
  </AspectRatio>
</div>
```

Pass `ratio` as a number, typically written as a division such as `16 / 9`, `4 / 3` or `1`. Give media inside it `className="size-full object-cover"` to fill the frame. Add `overflow-hidden` and a radius class to clip the content to rounded corners.

## API Reference

<ApiPart index={1}>

### AspectRatio

The ratio-locked container.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `ratio` | `number` | Required | Width divided by height, for example `16 / 9`. Required. |

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

## Notes

- Styling hook: `data-slot="aspect-ratio"`.
- The ratio is passed through the `--ratio` CSS custom property and applied with the Tailwind class `aspect-(--ratio)`.

`AspectRatio` is a `View` that sets the `aspectRatio` style from its `ratio` prop. Its height follows from the width it is given, so the content keeps its shape at any screen size.

Use it for images, video thumbnails and placeholders that must not stretch.

## Usage

```tsx
<View className="w-full overflow-hidden rounded-lg">
  <AspectRatio ratio={16 / 9}>
    <Image source={{ uri: imageUri }} className="h-full w-full" />
  </AspectRatio>
</View>
```

Pass `ratio` as width divided by height, such as `16 / 9`. It defaults to `1`. Size the content inside with `h-full w-full`, and put rounding or clipping on a parent view.
