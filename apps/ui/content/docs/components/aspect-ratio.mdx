`AspectRatio` is a single `div` that sets the CSS `aspect-ratio` property from the `ratio` prop. Its width follows the parent, and its height is derived from the ratio. It is positioned `relative`, so children can be absolutely positioned inside it.

Use it to reserve space for images, video or embeds so the layout does not shift while media loads.

<Code lang="tsx" code={"<div className=\"w-96\">\n  <AspectRatio ratio={16 / 9} className=\"overflow-hidden rounded-2xl bg-surface-secondary\">\n    <img\n      src=\"https://images.unsplash.com/photo-1506744038136-46273834b3fb?w=800&q=80\"\n      alt=\"Mountain lake at sunrise\"\n      className=\"size-full object-cover\"\n    />\n  </AspectRatio>\n</div>"} />

Pass `ratio` as a number, typically written as a division such as `16 / 9`, `4 / 3` or `1`. Give media inside it `className="size-full object-cover"` to fill the frame. Add `overflow-hidden` and a radius class to clip the content to rounded corners.
