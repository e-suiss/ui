Chart does not draw charts itself; it styles charts you compose with `recharts`. A `ChartContainer` takes a `config` that maps each data key to a label, an optional icon and a color, and wraps your Recharts chart in a `ResponsiveContainer`. Inside the chart, use `ChartTooltip` with `content={<ChartTooltipContent />}` and `ChartLegend` with `content={<ChartLegendContent />}` to render a tooltip and legend that read labels and colors from the config.

Use it for bar, line, area and pie charts in dashboards and reports. Because you work with Recharts directly, every Recharts chart type and prop remains available.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/chart
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

## Usage

```tsx
import { Bar, BarChart, CartesianGrid, XAxis } from "recharts"
import { type ChartConfig, ChartContainer, ChartTooltip, ChartTooltipContent } from "@/components/ui/chart"
```

```tsx
const visitors = [
  { month: "January", desktop: 186 },
  { month: "February", desktop: 305 },
  { month: "March", desktop: 237 },
]

const visitorsConfig = {
  desktop: { label: "Desktop", color: "var(--chart-1)" },
} satisfies ChartConfig
```

```tsx
<ChartContainer config={visitorsConfig} className="w-full max-w-lg">
  <BarChart accessibilityLayer data={visitors}>
    <CartesianGrid vertical={false} />
    <XAxis dataKey="month" tickLine={false} tickMargin={10} axisLine={false} />
    <ChartTooltip content={<ChartTooltipContent />} />
    <Bar dataKey="desktop" fill="var(--color-desktop)" radius={8} />
  </BarChart>
</ChartContainer>
```

Each key in `config` becomes a CSS custom property scoped to the chart, such as `--color-desktop`. Reference it from your series, as in `fill="var(--color-desktop)"`. Set `color` for a single value, or `theme` with `light` and `dark` values to switch colors with the `.dark` class.

For data where each row is its own category, such as a pie chart, put the color in the row (for example `fill: "var(--color-safari)"`) and pass `nameKey` to `ChartLegendContent` so labels are looked up by that field.

The container is `aspect-video` by default; override its size with `className`, for example `aspect-square max-w-72`. Enable `accessibilityLayer` on the Recharts chart to support keyboard navigation.

`ChartTooltip`, `ChartLegend` and `ChartStyle` are also exported; the first two are the Recharts `Tooltip` and `Legend` components.

## API Reference

<ApiPart index={1}>

### ChartContainer

Provides the config, injects the color variables and makes the chart responsive.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `config` | `ChartConfig` | Required | Maps data keys to a `label`, optional `icon`, and a `color` or per-theme `theme` colors. |
| `children` | `React.ReactNode` | Required | The Recharts chart element to render responsively. |
| `initialDimension` | `{ width: number; height: number }` | `{ width: 320, height: 200 }` | Width and height used before the container is measured. |
| `aria-label` | `string` | `"Chart of <series labels>"` | The chart's accessible name. Without it, the chart gets "Chart of" followed by the config labels, or "Chart" when there are none. |

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

<ApiPart index={2}>

### ChartTooltipContent

A styled tooltip body that lists each series with its indicator, label and value.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `hideLabel` | `boolean` | `false` | Hides the tooltip's heading label. |
| `hideIndicator` | `boolean` | `false` | Hides the color indicator next to each series. |
| `indicator` | `"line" \| "dot" \| "dashed"` | `"dot"` | Shape of the series indicator: `dot`, `line` or `dashed`. |
| `nameKey` | `string` | - | Field used to look up each item's config entry instead of its name or data key. |
| `labelKey` | `string` | - | Field used to look up the heading label in the config. |

Also accepts the props of the Recharts `Tooltip` and `React.ComponentProps<"div">`.

</ApiPart>

<ApiPart index={3}>

### ChartLegendContent

A styled legend that lists series in config order with a swatch or icon.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `hideIcon` | `boolean` | `false` | Shows a color swatch even when the config entry has an `icon`. |
| `nameKey` | `string` | - | Field used to look up each legend item's config entry instead of its data key. |

Also accepts the props of `React.ComponentProps<"div">` and the Recharts `DefaultLegendContentProps`.

</ApiPart>

## Accessibility

- With `accessibilityLayer` on the Recharts chart, the chart is focusable and arrow keys move between data points, showing the tooltip for each.
- `ChartContainer` gives the chart an `aria-label`: yours, or "Chart of" followed by the config labels. A chart element that already has an `aria-label` keeps it.
- Charts are visual; provide a nearby summary or table when the exact values matter.
- Do not rely on color alone to tell series apart; the legend and tooltip pair each color with its label.

## Notes

- Styling hooks: `data-slot="chart"` and a unique `data-chart` id on the container, which scopes the generated `--color-*` variables.
- Config keys and color values containing unsafe characters are skipped when generating CSS.
- The container restyles Recharts defaults, such as grid lines, axis ticks and the tooltip cursor, with the `border`, `muted-foreground` and `muted` colors.
- Tooltip values that are numbers are formatted with `toLocaleString()`.

<Only platform="rn">

Charts are composed declaratively: a chart root such as `LineChart`, `AreaChart`, `BarChart`, `ComposedChart`, `PieChart`, `RadialBarChart` or `RadarChart` goes inside a `ChartContainer`, and series and axes such as `Line`, `Area`, `Bar`, `XAxis`, `YAxis` and `CartesianGrid` are added as children. These child components render nothing themselves; the root reads them and draws everything with `react-native-svg`.

</Only>

Charts animate in when they first render: bars grow from the baseline, lines draw along their path, areas reveal from left to right, pie and radial sectors sweep open and radar shapes grow from the center. When the data changes, shapes animate from their previous values to the new ones.

Colors are theme tokens, not hex values. A series `color` such as `chart-1`, `chart-2` or `primary` resolves to the current token color, so charts follow light and dark mode automatically.

```tsx
import * as React from "react"
import { Card, CardContent, CardDescription, CardHeader, CardTitle } from "@/components/ui/card"
import { Bar, BarChart, type ChartConfig, ChartContainer, ChartTooltip, ChartTooltipContent, XAxis } from "@/components/ui/chart"

const monthData = [
  { month: "January", desktop: 186, mobile: 80 },
  { month: "February", desktop: 305, mobile: 200 },
  { month: "March", desktop: 237, mobile: 120 },
  { month: "April", desktop: 173, mobile: 190 },
  { month: "May", desktop: 209, mobile: 130 },
  { month: "June", desktop: 264, mobile: 140 },
]

const deviceConfig = {
  desktop: { label: "Desktop", color: "chart-1" },
  mobile: { label: "Mobile", color: "chart-2" },
} satisfies ChartConfig

function StackedTooltipChart({
  title,
  description,
  defaultIndex,
  content,
}: {
  title: string
  description: string
  defaultIndex: number
  content: React.ReactElement
}) {
  return (
    <Card variant="filled" size="sm">
      <CardHeader>
        <CardTitle>{title}</CardTitle>
        <CardDescription>{description}</CardDescription>
      </CardHeader>
      <CardContent>
        <ChartContainer
          config={deviceConfig}
          accessibilityLabel={title}
          className="h-52 w-full"
        >
          <BarChart
            data={monthData}
            margin={{ top: 70, right: 4, left: 4, bottom: 0 }}
          >
            <XAxis
              dataKey="month"
              tickMargin={8}
              interval={0}
              tickFormatter={(value: string) => value.slice(0, 3)}
            />
            <ChartTooltip
              defaultIndex={defaultIndex}
              cursor={false}
              content={content}
            />
            <Bar
              dataKey="desktop"
              stackId="a"
              radius={[0, 0, 4, 4]}
              maxBarSize={30}
            />
            <Bar
              dataKey="mobile"
              stackId="a"
              radius={[4, 4, 0, 0]}
              maxBarSize={30}
            />
          </BarChart>
        </ChartContainer>
      </CardContent>
    </Card>
  )
}
```

```swift
import Charts
import SwiftUI

struct ChartTooltipDotExample: View {
  var body: some View {
    ChartStackedTooltip(title: "Dot indicator", description: "indicator=\"dot\"", defaultIndex: 2) { payload in
      ChartTooltipContent(payload, indicator: .dot)
    }
  }
}

let chartMonthData: [(month: String, desktop: Double, mobile: Double)] = [
  ("January", 186, 80),
  ("February", 305, 200),
  ("March", 237, 120),
  ("April", 173, 190),
  ("May", 209, 130),
  ("June", 264, 140),
]

let chartDevices: ChartConfig = [
  "desktop": .init("Desktop", color: Palette.blue500),
  "mobile": .init("Mobile", color: Palette.teal500),
]

struct ChartStackedTooltip<Tooltip: View>: View {
  let title: String
  let description: String
  var config = chartDevices
  let defaultIndex: Int
  @ViewBuilder let tooltip: (ChartTooltipPayload) -> Tooltip

  var body: some View {
    Card(.filled, size: .sm) {
      CardHeader(LocalizedStringKey(title), description: LocalizedStringKey(description))
      CardContent {
        ChartContainer(config: config) {
          ChartAnimator(animationDuration: 400) { progress in
            Chart {
              ForEach(chartMonthData.indices, id: \.self) { index in
                let item = chartMonthData[index]
                BarMark(
                  x: .value("Month", item.month),
                  yStart: .value("Start", 0),
                  yEnd: .value("Desktop", item.desktop * progress),
                  width: .fixed(30)
                )
                .clipShape(UnevenRoundedRectangle(bottomLeadingRadius: 4, bottomTrailingRadius: 4, style: .continuous))
                .foregroundStyle(config.color("desktop"))
                BarMark(
                  x: .value("Month", item.month),
                  yStart: .value("Start", item.desktop * progress),
                  yEnd: .value("Mobile", (item.desktop + item.mobile) * progress),
                  width: .fixed(30)
                )
                .clipShape(UnevenRoundedRectangle(topLeadingRadius: 4, topTrailingRadius: 4, style: .continuous))
                .foregroundStyle(config.color("mobile"))
                ChartAnchorMark(x: .value("Month", item.month), y: .value("Mobile", item.desktop + item.mobile))
              }
            }
            .chartYScale(range: .plotDimension(endPadding: 70))
            .chartXAxis { ChartAxis.x(values: chartMonthData.map(\.month)) { String($0.prefix(3)) } }
            .chartYAxis(.hidden)
            .chartTooltip(
              x: chartMonthData.map(\.month),
              defaultIndex: defaultIndex,
              cursor: false,
              accessibilityLabel: title,
              items: { index in
                [
                  ChartTooltipItem("desktop", value: chartMonthData[index].desktop),
                  ChartTooltipItem("mobile", value: chartMonthData[index].mobile),
                ]
              },
              content: tooltip
            )
          }
        }
        .frame(height: 208)
      }
    }
  }
}
```

<Only platform="rn">

Describe each series in a `ChartConfig` object with a `label`, a token `color` and an optional `icon`, and pass it to `ChartContainer` as `config`. The container is full width with a 16:9 aspect ratio unless you give it an `h-`, `size-` or `aspect-` class.

Add `ChartTooltip` with `content={<ChartTooltipContent />}` to make the chart respond to touch: touching or dragging selects the nearest data point, draws a cursor and shows the tooltip, with a selection haptic. `ChartTooltipContent` supports `indicator` (`dot`, `line` or `dashed`), `hideLabel`, `hideIndicator`, `labelFormatter`, `formatter` and `nameKey`. Use `defaultIndex` on `ChartTooltip` to start with a point selected, or `onActiveIndexChange` on the chart to react to selection.

`Line`, `Area`, `Bar`, `Pie`, `RadialBar` and `Radar` take `isAnimationActive`, `animationDuration` and `animationEasing`. Bars default to 400 ms and curves, sectors and radar shapes to 1500 ms, with `ease` easing. Set `isAnimationActive={false}` to draw a series in its final state, for example when its data changes on every interaction.

Add `ChartLegend` with `content={<ChartLegendContent />}` for a legend in config order. `useChart()` returns the config inside a container, and `ChartPalette` resolves token colors for custom drawing.

</Only>

## Accessibility

- The chart is one accessible element labelled with its series names and data range; pass `accessibilityLabel` to `ChartContainer` to override the names.
- With a tooltip it has the `adjustable` role: VoiceOver and TalkBack swipe actions step through data points, and the selected values are announced as the value text.
- Without a tooltip it has the `image` role.
- With Reduce Motion on, charts skip the enter and update animations and draw in their final state.

## Notes

- Series colors accept `chart-1` to `chart-5`, theme colors such as `primary`, `destructive` and `foreground`, and palette colors such as `green-500` and `red-500`; grid and cursor lines use `border`.
- Value labels from `LabelList` and pie `label` appear once a series finishes animating.
- Light and dark follow the system appearance.
