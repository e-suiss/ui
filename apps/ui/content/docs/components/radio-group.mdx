Radio Group wraps the radio group primitive of the chosen base. `RadioGroup` holds the selected value and contains one `RadioGroupItem` per option. Each item renders a round control with an indicator dot when checked; pair it with a `Label` to give it visible text.

Use a radio group for a small set of mutually exclusive options that should all stay visible. Use Select or Native Select for longer lists, and Checkbox when several options can be selected.

## Usage

```tsx
import { Label } from "@/components/ui/label"
import { RadioGroup, RadioGroupItem } from "@/components/ui/radio-group"
```

```tsx
<div className="w-64">
  <RadioGroup aria-label="Notification method" defaultValue="email">
    {options.map((option) => (
      <Label key={option.value}>
        <RadioGroupItem value={option.value} />
        {option.label}
      </Label>
    ))}
  </RadioGroup>
</div>
```

## Composition

Use the following composition to build a `RadioGroup`:

```text
RadioGroup
└── RadioGroupItem
```

## Accessibility

- The group has the `radiogroup` role and each item the `radio` role with `aria-checked`.
- Name the group with `aria-label` or `aria-labelledby`, and name each item with a wrapping `Label` or `aria-labelledby`.
- Arrow keys move focus and selection between items, skipping disabled ones.

<OnlyBase base="base radix">

- Set `aria-invalid` on items to communicate a validation error.

</OnlyBase>

<OnlyBase base="aria">

- Set `isInvalid` on the group to communicate a validation error.

</OnlyBase>

- Each item has an enlarged invisible hit area for easier pointer targeting.

### RadioGroupItem

A single radio button with a checked indicator.

<OnlyBase base="base radix">

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | — |
| `disabled` | `boolean` | `false` |

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | — |
| `isDisabled` | `boolean` | `false` |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

Give each item a unique `value`; it identifies the item in the group's value. Wrap each item and its text in a `Label` so clicking the text selects the option. Items carry the `peer` class, so a following `Label` can react to their state, and the label switches to regular weight next to a radio item.

Each part sets a `data-slot`, such as `radio-group` or `radio-group-item`, for styling.

</Only>

## Usage

<Only platform="rn">

<OnlyStyling styling="uniwind nativewind">

```tsx
import * as React from "react"
import { View } from "react-native"
import { Label } from "@/components/ui/label"
import { RadioGroup, RadioGroupItem } from "@/components/ui/radio-group"

const options = [
  { value: "default", label: "Default" },
  { value: "comfortable", label: "Comfortable" },
  { value: "compact", label: "Compact" },
]

function RadioGroupDemo({
  disabled = false,
  disabledItem,
}: {
  disabled?: boolean
  disabledItem?: string
}) {
  const [value, setValue] = React.useState("comfortable")
  return (
    <RadioGroup value={value} onValueChange={setValue} disabled={disabled}>
      {options.map((option) => {
        const isDisabled = disabled || option.value === disabledItem
        return (
          <View key={option.value} className="flex-row items-center gap-3">
            <RadioGroupItem
              value={option.value}
              accessibilityLabelledBy={`radio-${option.value}`}
              disabled={isDisabled}
            />
            <Label
              nativeID={`radio-${option.value}`}
              disabled={isDisabled}
              onPress={() => setValue(option.value)}
            >
              {option.label}
            </Label>
          </View>
        )
      })}
    </RadioGroup>
  )
}

export function RadioGroupExample() {
  return (
    <RadioGroupDemo />
  )
}
```

class RadioGroupOption(val value: String, val label: String, val description: String = "")

val radioGroupOptions = listOf(
    RadioGroupOption("default", "Default"),
    RadioGroupOption("comfortable", "Comfortable"),
    RadioGroupOption("compact", "Compact"),
)

@Composable
fun Modifier.radioGroupTap(enabled: Boolean, onTap: () -> Unit): Modifier = clickable(
    interactionSource = remember { MutableInteractionSource() },
    indication = null,
    enabled = enabled,
    onClick = onTap,
)

@Composable
fun RadioGroupDemo(disabled: Boolean = false, disabledItem: String? = null) {
    var value by rememberSaveable { mutableStateOf("comfortable") }
    RadioGroup(value = value, onValueChange = { value = it }, enabled = !disabled) {
        radioGroupOptions.forEach { option ->
            val isDisabled = disabled || option.value == disabledItem
            Row(horizontalArrangement = Arrangement.spacedBy(12.dp), verticalAlignment = Alignment.CenterVertically) {
                RadioGroupItem(
                    option.value,
                    Modifier.semantics { contentDescription = option.label },
                    enabled = !isDisabled,
                )
                Label(option.label, Modifier.radioGroupTap(!isDisabled) { value = option.value }, enabled = !isDisabled)
            }
        }
    }

## Accessibility

- The group has the `radiogroup` role and reports `disabled` in `accessibilityState`.
- Each item has the `radio` role and reports `checked` and `disabled` in `accessibilityState`.
- The indicator is hidden from screen readers; label each item with a linked `Label` or an `accessibilityLabel`.

## API Reference

<Only platform="rn">

### RadioGroup

The container that holds the selected value.

Also accepts the props of `RadioGroupProps<Value>`.

Control the group with `value` and `onValueChange(value, details)`, or leave it uncontrolled with `defaultValue`. Values are generic, so they can be strings or other types. Set `disabled` to disable all items. Selecting an item triggers a selection haptic when a haptics adapter is provided through `HapticsContext`.

### RadioGroupItem

A single radio button with its checked indicator.

| Prop | Type | Default |
| --- | --- | --- |
| `invalid` | `boolean` | - |

Also accepts the props of `RadioPrimitive.RootProps<Value>`.

Give every item a unique `value`, and set `disabled` on a single item to disable it. `invalid` shows a destructive border while the item is unchecked. Put a `Label` next to each item and link it through `nativeID` and `accessibilityLabelledBy`. In dark mode unchecked items drop the border and shadow.

</Only>
