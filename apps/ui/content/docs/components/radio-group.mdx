Radio Group wraps Base UI's Radio Group and Radio. `RadioGroup` holds the selected value and contains one `RadioGroupItem` per option. Each item renders a round control with an indicator dot when checked; pair it with a `Label` to give it visible text.

Use a radio group for a small set of mutually exclusive options that should all stay visible. Use Select or Native Select for longer lists, and Checkbox when several options can be selected.

Give each `RadioGroupItem` a unique `value`. The group is uncontrolled with `defaultValue`, or controlled with `value` and `onValueChange`. Set `disabled` on the group to disable every item, or on a single item.

Wrap each item and its text in a `Label` so clicking the text selects the option. The label switches to regular weight automatically next to a radio item.

## Accessibility

- The group has the `radiogroup` role and each item the `radio` role with `aria-checked`.
- Name the group with `aria-label` or `aria-labelledby`, and name each item with a wrapping `Label` or `aria-labelledby`.
- Arrow keys move focus and selection between items, skipping disabled ones.
- Set `aria-invalid` on items to communicate a validation error.
- Each item has an enlarged invisible hit area for easier pointer targeting.

## Notes

- Styling hooks: `data-slot` values `radio-group`, `radio-group-item` and `radio-group-indicator`. Base UI sets `data-checked`, `data-unchecked` and `data-disabled` on items.
- Items carry the `peer` class, so a following `Label` can react to their state.
- Uses the `accent`, `accent-pressed`, `accent-disabled`, `on-accent`, `control-disabled` and `danger` tokens.

## Usage

<Code lang="tsx" code={"import { RadioGroup, RadioGroupItem } from \"@/components/ui/radio-group\""} />

<Code lang="tsx" code={"<RadioGroupDemo />"} />

Give every `RadioGroupItem` a unique `value`. Control the group with `value` and `onValueChange(value, details)`, or leave it uncontrolled with `defaultValue`. Values are generic, so they can be strings or other types.

Put a `Label` next to each item and link it through `nativeID` and `accessibilityLabelledBy`. Set `disabled` on the group to disable all items, or on a single item. Set `invalid` on items to show the danger border.

## Accessibility

- The group has the `radiogroup` role and reports `disabled` in `accessibilityState`.
- Each item has the `radio` role and reports `checked` and `disabled` in `accessibilityState`.
- The indicator is hidden from screen readers; label each item with a linked `Label` or an `accessibilityLabel`.

## Notes

- Selecting an item triggers a selection haptic when a haptics adapter is provided through `HapticsContext`.
- Uses the `bg-accent`, `bg-accent-disabled`, `bg-control-disabled`, `bg-on-accent` and `border-danger` tokens.
- Light and dark colors follow the system appearance; in dark mode unchecked items drop the border and shadow.
