<Only platform="rn">

`Chip` is a toggle rendered as a rounded `Pressable`. It switches between an unselected `bg-secondary` background and a selected `bg-foreground` fill, and shrinks slightly while pressed. It has `default` and `sm` sizes, an optional leading `icon`, and an optional trailing remove button when `onRemove` is set.

</Only>

`ChipGroup` manages selection for a set of chips: single selection by default, or several with `multiple`. It wraps chips onto new lines, or lays them out in a horizontal scroll view with `scrollable`.

## Usage

<Only platform="rn">

```tsx
import { Chip, ChipGroup } from "@/components/ui/chip"
```

```tsx
<Chip>Open now</Chip>
```

</Only>

<Only platform="swift">

```swift
import SwiftUI

struct ChipExample: View {
  var body: some View {
    ChipToggleDemo(title: "Open now", initial: false)
  }
}

struct ChipToggleDemo: View {
  let title: LocalizedStringKey
  var size: ChipSize?
  var icon: Image?
  var onRemove: (() -> Void)?

  @State private var selected: Bool

  init(
    title: LocalizedStringKey,
    initial: Bool,
    size: ChipSize? = nil,
    icon: Image? = nil,
    onRemove: (() -> Void)? = nil
  ) {
    self.title = title
    self.size = size
    self.icon = icon
    self.onRemove = onRemove
    _selected = State(initialValue: initial)
  }

  var body: some View {
    Chip(title, isSelected: $selected, size: size, icon: icon, onRemove: onRemove)
  }
}
```

</Only>

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.Column
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.saveable.rememberSaveable
import androidx.compose.runtime.setValue
import androidx.compose.ui.graphics.vector.ImageVector
import com.esuiss.ui.components.Chip
import com.esuiss.ui.components.ChipSize

@Composable
fun ChipItem(
    text: String,
    defaultSelected: Boolean = false,
    size: ChipSize = ChipSize.Default,
    enabled: Boolean = true,
    icon: ImageVector? = null,
    onRemove: (() -> Unit)? = null,
) {
    var selected by rememberSaveable { mutableStateOf(defaultSelected) }
    Chip(
        text,
        selected = selected,
        onSelectedChange = { selected = it },
        size = size,
        enabled = enabled,
        icon = icon,
        onRemove = onRemove,
    )
}

@Composable
fun ChipDefault() {
    Column {
        ChipItem("Open now")
    }
}
```

</Only>

<Only platform="rn">

Use `selected` with `onSelectedChange`, or `defaultSelected`, on a standalone chip. Inside a `ChipGroup`, give each chip a `value` and control the group with `value`, `defaultValue` and `onValueChange` (arrays of values).

</Only>

<Only platform="rn kotlin">

The group's `size` is passed to every chip unless a chip sets its own. Use `removeLabel` to localize the remove button's label.

</Only>

<Only platform="rn">

`chipVariants` is also exported if you need the classes elsewhere.

</Only>

## API Reference

<Only platform="rn">

<ApiPart index={1}>

### Chip

Selectable pill.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `selected` | `boolean` | - | Whether the chip is selected, for controlled use. |
| `defaultSelected` | `boolean` | - | Whether the chip starts selected when uncontrolled. |
| `onSelectedChange` | `(selected: boolean, details) => void` | - | Called when the chip is toggled. |
| `size` | `"default" \| "sm"` | `"default"` | The chip height; inherited from a surrounding group. |
| `icon` | `PhosphorIcon` | - | An icon shown before the label. |
| `onRemove` | `() => void` | - | Shows a remove button and is called when it is pressed. |
| `removeLabel` | `string` | `"Remove"` | Accessibility label of the remove button. |

Also accepts the props of `ChipProps`.

</ApiPart>

Also accepts the props of `React.ComponentProps<typeof ToggleGroupPrimitive>`.

</ApiPart>

## Accessibility

- A chip has the `togglebutton` role with `checked` state, or the `radio` role in a single-selection group.
- A group has the `radiogroup` role for single selection and `group` for multiple.
- With `onRemove`, the chip exposes a `remove` accessibility action, and the remove button has its own `button` role and label.

## Notes

- Uses `bg-secondary`, `bg-foreground` and `text-background` tokens, with `opacity-80` while pressed and `opacity-50` when disabled; light and dark follow the system appearance.
