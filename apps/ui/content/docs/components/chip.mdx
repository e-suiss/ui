`Chip` is a toggle rendered as a rounded `Pressable`. It switches between an unselected `bg-secondary` background and a selected `bg-foreground` fill, and shrinks slightly while pressed. It has `default` and `sm` sizes, an optional leading `icon`, and an optional trailing remove button when `onRemove` is set.

`ChipGroup` manages selection for a set of chips: single selection by default, or several with `multiple`. It wraps chips onto new lines, or lays them out in a horizontal scroll view with `scrollable`.

## Usage

```tsx
import { Chip, ChipGroup } from "@/components/ui/chip"
```

```tsx
<Chip>Open now</Chip>
```

Use `selected` with `onSelectedChange`, or `defaultSelected`, on a standalone chip. Inside a `ChipGroup`, give each chip a `value` and control the group with `value`, `defaultValue` and `onValueChange` (arrays of values).

The group's `size` is passed to every chip unless a chip sets its own. Use `removeLabel` to localize the remove button's label.

`chipVariants` is also exported if you need the classes elsewhere.

## API Reference

<ApiPart index={1}>

### Chip

Selectable pill.

Also accepts the props of `ChipProps`.

</ApiPart>

<ApiPart index={2}>

### ChipGroup

Manages selection and layout for several chips.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `ChipSize` | `"default"` | Size passed to every chip. |
| `scrollable` | `boolean` | `false` | Shows chips in a horizontal scroll view instead of wrapping. |

Also accepts the props of `React.ComponentProps<typeof ToggleGroupPrimitive>`.

</ApiPart>

## Accessibility

- A chip has the `togglebutton` role with `checked` state, or the `radio` role in a single-selection group.
- A group has the `radiogroup` role for single selection and `group` for multiple.
- With `onRemove`, the chip exposes a `remove` accessibility action, and the remove button has its own `button` role and label.

## Notes

- Uses `bg-secondary`, `bg-foreground` and `text-background` tokens, with `opacity-80` while pressed and `opacity-50` when disabled; light and dark follow the system appearance.
