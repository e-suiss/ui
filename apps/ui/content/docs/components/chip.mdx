<Only platform="rn">

`Chip` is a toggle rendered as a rounded `Pressable`. It switches between an unselected `bg-secondary` background and a selected `bg-foreground` fill, and shrinks slightly while pressed. It has `default` and `sm` sizes, an optional leading `icon`, and an optional trailing remove button when `onRemove` is set.

</Only>

`ChipGroup` manages selection for a set of chips: single selection by default, or several with `multiple`. It wraps chips onto new lines, or lays them out in a horizontal scroll view with `scrollable`.

## Usage

<Only platform="rn">

```tsx
import { Chip, ChipGroup } from "@/components/ui/chip"
```

```tsx
<Chip>Open now</Chip>
```

</Only>

<Only platform="swift">

```swift
import SwiftUI

struct ChipExample: View {
  var body: some View {
    ChipToggleDemo(title: "Open now", initial: false)
  }
}

struct ChipToggleDemo: View {
  let title: LocalizedStringKey
  var size: ChipSize?
  var icon: Image?
  var onRemove: (() -> Void)?

  @State private var selected: Bool

  init(
    title: LocalizedStringKey,
    initial: Bool,
    size: ChipSize? = nil,
    icon: Image? = nil,
    onRemove: (() -> Void)? = nil
  ) {
    self.title = title
    self.size = size
    self.icon = icon
    self.onRemove = onRemove
    _selected = State(initialValue: initial)
  }

  var body: some View {
    Chip(title, isSelected: $selected, size: size, icon: icon, onRemove: onRemove)
  }
}
```

</Only>

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.Column
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.saveable.rememberSaveable
import androidx.compose.runtime.setValue
import androidx.compose.ui.graphics.vector.ImageVector
import com.esuiss.ui.components.Chip
import com.esuiss.ui.components.ChipSize

@Composable
fun ChipItem(
    text: String,
    defaultSelected: Boolean = false,
    size: ChipSize = ChipSize.Default,
    enabled: Boolean = true,
    icon: ImageVector? = null,
    onRemove: (() -> Unit)? = null,
) {
    var selected by rememberSaveable { mutableStateOf(defaultSelected) }
    Chip(
        text,
        selected = selected,
        onSelectedChange = { selected = it },
        size = size,
        enabled = enabled,
        icon = icon,
        onRemove = onRemove,
    )
}

@Composable
fun ChipDefault() {
    Column {
        ChipItem("Open now")
    }
}
```

</Only>

## Accessibility

- A chip has the `togglebutton` role with `checked` state, or the `radio` role in a single-selection group.
- A group has the `radiogroup` role for single selection and `group` for multiple.
- With `onRemove`, the chip exposes a `remove` accessibility action, and the remove button has its own `button` role and label.

</Only>

## API Reference

<Only platform="rn">

### Chip

Selectable pill.

| Prop | Type | Default |
| --- | --- | --- |
| `selected` | `boolean` | - |
| `defaultSelected` | `boolean` | - |
| `onSelectedChange` | `(selected: boolean, details) => void` | - |
| `size` | `"default" \| "sm"` | `"default"` |
| `icon` | `PhosphorIcon` | - |
| `onRemove` | `() => void` | - |
| `removeLabel` | `string` | `"Remove"` |

Also accepts the props of `React.ComponentProps<typeof TogglePrimitive>`, except `pressed`, `defaultPressed` and `onPressedChange`.

Use `selected` with `onSelectedChange`, or `defaultSelected`, on a standalone chip. Inside a group, give each chip a `value`; its `size` is then inherited from the group. `icon` is shown before the label, and `removeLabel` is the accessibility label of the remove button. While pressed the chip drops to `opacity-80`. `chipVariants` is also exported if you need the classes elsewhere.

### ChipGroup

Manages selection and layout for several chips.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `ChipSize` | `"default"` |
| `scrollable` | `boolean` | `false` |

Also accepts the props of `React.ComponentProps<typeof ToggleGroupPrimitive>`.

Control the group with `value`, `defaultValue` and `onValueChange`, which take arrays of values. `scrollable` shows the chips in a horizontal scroll view instead of wrapping them.

</Only>
