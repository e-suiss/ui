`AmountInput` combines a big formatted amount with a `Keypad`. The amount is formatted with `Intl.NumberFormat` for the given `locale` and `currency`, the currency symbol is drawn smaller, and the font size steps down as the number gets longer.

The decimal key appears only when the currency allows fractions, using the locale's decimal separator. A key that would exceed the limits is rejected with a shake and an error haptic; accepted keys play a selection haptic.

## Usage

```tsx
import { AmountInput } from "@/components/ui/amount-input"
```

```tsx
<AmountInput currency="USD" locale="en-US" />
```

The value is a plain numeric string such as `"1250.5"`. Use `defaultValue` for uncontrolled state, or `value` with `onValueChange`, which receives the string and the parsed number.

Fraction digits default to the currency's own precision (for example 0 for JPY); override with `maxFractionDigits`. Use `max` to cap the amount. Input is limited to 15 digits.

Pass `deleteLabel` and `decimalLabel` to localize the keypad's spoken labels.

## API Reference

<ApiPart index={1}>

### AmountInput

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | Controlled numeric string. |
| `defaultValue` | `string` | `""` | Initial numeric string when uncontrolled. |
| `onValueChange` | `(value: string, amount: number) => void` | - | Called with the new string and its numeric amount. |
| `currency` | `string` | - | ISO currency code used for formatting. |
| `locale` | `string` | - | Locale used for formatting and the decimal separator. |
| `maxFractionDigits` | `number` | - | Maximum digits after the decimal separator. |
| `max` | `number` | - | Largest allowed amount. |
| `placeholder` | `string` | `"0"` | Shown in place of the integer when empty. Defaults to `"0"`. |
| `disabled` | `boolean` | `false` | Dims the amount and disables the keypad. |
| `deleteLabel` | `string` | - | Accessibility label for the delete key. |
| `decimalLabel` | `string` | - | Accessibility label for the decimal key. |
| `amountClassName` | `string` | - | Extra classes for the amount text. |
| `keypadClassName` | `string` | - | Extra classes for the keypad. |

Also accepts the props of `React.ComponentProps<typeof View>`.

</ApiPart>

## Accessibility

- The amount text is a polite live region, so changes are announced.
- Its label is the formatted amount, prefixed with `accessibilityLabel` when given.
- Keypad keys announce their digit; the delete key is disabled while the value is empty.

## Notes

- The shake animation respects the system Reduce Motion setting.
- Uses tabular numerals so digits do not shift as they change.
- Uses `text-foreground` and `text-muted-foreground` tokens; light and dark follow the system appearance.
