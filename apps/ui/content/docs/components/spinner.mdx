`Spinner` is an SVG of eight fading spokes that rotates in steps, like the system activity indicator. It draws in `currentColor` and is `size-4` by default, so it inherits the surrounding text color.

Use it for short waits whose length is unknown, such as saving or loading more. For a placeholder that previews the shape of content, use `Skeleton`.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/spinner
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add spinner
```

### Manual

1. Add the [`cn` helper](/docs/installation#the-cn-helper).

2. Copy the source into `components/ui/spinner.tsx`:

<ComponentSource path="components/ui/spinner.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Spinner } from "@/components/ui/spinner"
```

```tsx
<Spinner />
```

Change the size with a `size-*` class and the color with a `text-*` class. Inside a `Button`, pair it with `disabled` and give it `data-icon="inline-start"` to place it before the label.

## Usage

```tsx
import { Spinner } from "@/components/ui/spinner"
```

```tsx
<Spinner />
```

Set `size` in points (default `16`) and `colorClassName` with an `accent-*` class, such as `accent-primary` or `accent-destructive`. Inside a button, use `accent-primary-foreground` on the `default` variant so the spinner matches the label.

## API Reference

<ApiPart index={1}>

### Spinner

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `number` | `16` | Width and height in points. Defaults to `16`. |
| `colorClassName` | `string` | `"accent-muted-foreground"` | Class that sets the indicator color. Defaults to `accent-muted-foreground`. |

Also accepts the props of `React.ComponentProps<typeof ActivityIndicator>`.

</ApiPart>

## Accessibility

- The wrapper has `role="progressbar"`, is `accessible`, and sets `busy: true` in `accessibilityState`.
- It is announced as `"Loading"` unless you pass another `accessibilityLabel`.

## Notes

- The default color uses the `muted-foreground` token.
- The look of the indicator comes from the platform's native activity indicator, so it differs between iOS and Android.
