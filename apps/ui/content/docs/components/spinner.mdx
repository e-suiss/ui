`Spinner` is an SVG of eight fading spokes that rotates in steps, like the system activity indicator. It draws in `currentColor` and is `size-4` by default, so it inherits the surrounding text color.

Use it for short waits whose length is unknown, such as saving or loading more. For a placeholder that previews the shape of content, use `Skeleton`.

## API Reference

### Spinner

The animated activity indicator.

Also accepts the props of `React.ComponentProps<"svg">`.

The rotation lasts `0.8s` and moves in eight steps, so one spoke advances at a time. Style it through `data-slot="spinner"`.

## API Reference

<Only platform="rn">

### Spinner

The animated activity indicator.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `number` | `16` |
| `colorClassName` | `string` | `"accent-muted-foreground"` |

Also accepts the props of `React.ComponentProps<typeof ActivityIndicator>`.

`size` sets the width and height in points. `colorClassName` sets the indicator color with an `accent-*` class, such as `accent-primary` or `accent-destructive`. Inside a button, use `accent-primary-foreground` on the `default` variant so the spinner matches the label. The look of the indicator comes from the platform's native activity indicator, so it differs between iOS and Android.

</Only>

<Only platform="swift">

### Spinner

The animated activity indicator.

| Parameter | Type | Default |
| --- | --- | --- |
| `_ size` | `Size`: `.sm` \| `.default` \| `.lg` \| `.xl` | `.default` |
| `label` | `LocalizedStringKey` | `"Loading"` |
| `dimension` | `CGFloat` | - |

Overloads: `init(_:label:)`, `init(dimension:label:)`.

</Only>
