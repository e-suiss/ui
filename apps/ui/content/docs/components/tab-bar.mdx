`TabBar` renders a fixed `nav` centered at the bottom of the screen. `TabBarList` holds the primary `TabBarItem` buttons. `TabBarTrigger` is the More button: pressing it expands `TabBarContent` above the list, with a spring animation, to show `TabBarSection` columns. Each section has a `TabBarSectionTitle` and a set of `TabBarLink` entries.

The list measures itself and moves items that don't fit into the expanded content, where they appear as links. When every item fits and there are no sections, the More button is hidden. Use `TabBar` for top-level navigation on any screen size; for in-page panels, use `Tabs`, and for an app's side navigation, use `Sidebar`.

## Usage

```tsx
import { TabBar, TabBarList, TabBarItem, TabBarTrigger, TabBarContent, TabBarSection, TabBarSectionTitle, TabBarLink } from "@/components/ui/tab-bar"
```

```tsx
<TabBar aria-label="Main">
  <TabBarList>
    {items.map((item) => (
      <TabBarItem
        key={item}
        isActive={value === item}
        onClick={() => setValue(item)}
      >
        {item}
      </TabBarItem>
    ))}
  </TabBarList>
  <TabBarContent>
    {sections.map((section) => (
      <TabBarSection key={section.title}>
        <TabBarSectionTitle>{section.title}</TabBarSectionTitle>
        {section.links.map((link) => (
          <TabBarLink key={link.href} href={link.href}>
            {link.label}
          </TabBarLink>
        ))}
      </TabBarSection>
    ))}
  </TabBarContent>
  <TabBarTrigger>More</TabBarTrigger>
</TabBar>
```

Use `defaultOpen` on `TabBar` for an uncontrolled bar, or `open` with `onOpenChange` to control it. Give the `nav` a name with `aria-label`.

Mark the current destination with `isActive` on a `TabBarItem` or `TabBarLink`. A `TabBarItem` can render as a link or router link. Choosing a `TabBarLink` or an overflowed item closes the bar. Child components can read the bar's state with the `useTabBar` hook.

<OnlyBase base="base">

Use the `render` prop to render a `TabBarItem` as a link or router link.

</OnlyBase>

<OnlyBase base="radix">

Set `asChild` on a `TabBarItem` and pass a link or router link as the child.

</OnlyBase>

<OnlyBase base="aria">

Pass a `render` function to a `TabBarItem` that returns a link or router link with the props it receives.

</OnlyBase>

## Accessibility

- `TabBar` is a `navigation` landmark; name it with `aria-label`.
- Active items and links set `aria-current="page"`.
- The More button sets `aria-expanded` and `aria-controls` to point to the content.
- `Escape` closes the open bar and returns focus to the More button. A pointer press outside the bar also closes it.
- While open, the list is `inert`. Items moved into the overflow are hidden from assistive technologies and removed from the tab order in the list, and appear as links in the content instead.
- When the More button isn't needed, it's hidden and removed from the tab order.

## Notes

- `TabBar` sets `data-open`, `data-overflowing` and `data-sections` for styling. The trigger sets `data-idle` when it's hidden, and items and links set `data-active`.
- Parts carry `data-slot` attributes such as `tab-bar`, `tab-bar-list`, `tab-bar-item`, `tab-bar-trigger` and `tab-bar-content`.
- The bar sits above the safe-area inset at the bottom of the screen and uses a `card` background with a thin border and a shadow. The active item gets a `secondary` fill and `primary` text.
- Animations are removed when reduced motion is preferred.
- `useTabBar` throws if it's used outside a `TabBar`.

`TabBar` is built on the tabs primitive and sits at the bottom of a screen. `TabBarList` is a rounded capsule with a shadow, inset from the screen edges, so the bar floats above the page. The root adds bottom padding for the safe area, minus any inset an enclosing `Screen` already handles, and never less than 12 points. `TabBarItem` stacks an icon over a short label; the active tab sits on a `bg-secondary` pill and uses `text-primary` and a filled icon weight.

## Usage

<Only platform="rn">

```tsx
import { ChatCircleIcon, HouseIcon, MagnifyingGlassIcon, UserIcon } from "phosphor-react-native"
import * as React from "react"
import { View } from "react-native"
import { TabBar, TabBarItem, TabBarList } from "@/components/ui/tab-bar"
import { Text } from "@/components/ui/text"

const items = [
  { value: "home", label: "Home", icon: HouseIcon },
  { value: "search", label: "Search", icon: MagnifyingGlassIcon },
  { value: "messages", label: "Messages", icon: ChatCircleIcon, badge: 3 },
  { value: "profile", label: "Profile", icon: UserIcon, badge: true },
]

function Page({
  title,
  children,
}: {
  title: string
  children: React.ReactNode
}) {
  return (
    <View className="-m-4 flex-1 bg-background">
      <View className="flex-1 gap-2 p-4">
        <Text variant="h3">{title}</Text>
        <Text variant="muted">Tap a tab to switch screens.</Text>
      </View>
      {children}
    </View>
  )
}

function TabBarExample({
  badges = true,
  disabled,
}: {
  badges?: boolean
  disabled?: string
}) {
  const [value, setValue] = React.useState("home")
  const current = items.find((item) => item.value === value)
  return (
    <Page title={current?.label ?? ""}>
      <TabBar value={value} onValueChange={setValue}>
        <TabBarList>
          {items.map((item) => (
            <TabBarItem
              key={item.value}
              value={item.value}
              icon={item.icon}
              badge={badges ? item.badge : undefined}
              disabled={item.value === disabled}
            >
              {item.label}
            </TabBarItem>
          ))}
        </TabBarList>
      </TabBar>
    </Page>
  )
}

export function TabBarExampleDemo() {
  return (
    <TabBarExample />
  )
}
```

  let title: String
  @ViewBuilder let bar: () -> Bar

## Accessibility

- The list has the `tablist` role and each item has the `tab` role, with selected and disabled states.
- A badge with a count or text is exposed as the tab's accessibility value, so VoiceOver and TalkBack read it after the label.
- A dot badge is visual only and is not announced.

## Notes

- The capsule uses `bg-card` with a `border-foreground/5` border (`border-foreground/10` in dark mode) and a large shadow. The active tab uses `bg-secondary` and `text-primary`, and badges use `bg-destructive`; colors follow the system appearance.
- The bottom padding is the remaining safe area inset minus 8 points, and never less than 12 points.
