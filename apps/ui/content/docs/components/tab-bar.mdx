`TabBar` renders a fixed, translucent `nav` centered at the bottom of the screen. `TabBarList` holds the primary `TabBarItem` buttons. `TabBarTrigger` is the More button: pressing it expands `TabBarContent` above the list, with a spring animation, to show `TabBarSection` columns. Each section has a `TabBarSectionTitle` and a set of `TabBarLink` entries.

The list measures itself and moves items that don't fit into the expanded content, where they appear as links. When every item fits and there are no sections, the More button is hidden. Use `TabBar` for top-level navigation on any screen size; for in-page panels, use `Tabs`, and for an app's side navigation, use `Sidebar`.

## Usage

<Code lang="tsx" code={"import { TabBar, TabBarList, TabBarItem, TabBarTrigger, TabBarContent, TabBarSection, TabBarSectionTitle, TabBarLink } from \"@/components/ui/tab-bar\""} />

<Code lang="tsx" code={"<TabBarExample />"} />

Use `defaultOpen` on `TabBar` for an uncontrolled bar, or `open` with `onOpenChange` to control it. Give the `nav` a name with `aria-label`.

Mark the current destination with `isActive` on a `TabBarItem` or `TabBarLink`. Use the `render` prop to render a `TabBarItem` as a link or router link. Choosing a `TabBarLink` or an overflowed item closes the bar. Child components can read the bar's state with the `useTabBar` hook.

## Accessibility

- `TabBar` is a `navigation` landmark; name it with `aria-label`.
- Active items and links set `aria-current="page"`.
- The More button sets `aria-expanded` and `aria-controls` to point to the content.
- `Escape` closes the open bar and returns focus to the More button. A pointer press outside the bar also closes it.
- While open, the list is `inert`. Items moved into the overflow are hidden from assistive technologies and removed from the tab order in the list, and appear as links in the content instead.
- When the More button isn't needed, it's hidden and removed from the tab order.

## Notes

- `TabBar` sets `data-open`, `data-overflowing` and `data-sections` for styling. The trigger sets `data-idle` when it's hidden, and items and links set `data-active`.
- Parts carry `data-slot` attributes such as `tab-bar`, `tab-bar-list`, `tab-bar-item`, `tab-bar-trigger` and `tab-bar-content`.
- The bar sits above the safe-area inset at the bottom of the screen and uses a blurred `surface-secondary` background.
- Animations are removed when reduced motion is preferred.
- `useTabBar` throws if it's used outside a `TabBar`.
