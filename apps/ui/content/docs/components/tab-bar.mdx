`TabBar` renders a fixed `nav` centered at the bottom of the screen. `TabBarList` holds the primary `TabBarItem` buttons. `TabBarTrigger` is the More button: pressing it expands `TabBarContent` above the list, with a spring animation, to show `TabBarSection` columns. Each section has a `TabBarSectionTitle` and a set of `TabBarLink` entries.

The list measures itself and moves items that don't fit into the expanded content, where they appear as links. When every item fits and there are no sections, the More button is hidden. Use `TabBar` for top-level navigation on any screen size; for in-page panels, use `Tabs`, and for an app's side navigation, use `Sidebar`.

## Usage

```tsx
import {
  TabBar,
  TabBarContent,
  TabBarItem,
  TabBarLink,
  TabBarList,
  TabBarSection,
  TabBarSectionTitle,
  TabBarTrigger,
} from "@/components/ui/tab-bar"
```

```tsx
<TabBar aria-label="Main">
  <TabBarList>
    {items.map((item) => (
      <TabBarItem
        key={item}
        isActive={value === item}
        onClick={() => setValue(item)}
      >
        {item}
      </TabBarItem>
    ))}
  </TabBarList>
  <TabBarContent>
    {sections.map((section) => (
      <TabBarSection key={section.title}>
        <TabBarSectionTitle>{section.title}</TabBarSectionTitle>
        {section.links.map((link) => (
          <TabBarLink key={link.href} href={link.href}>
            {link.label}
          </TabBarLink>
        ))}
      </TabBarSection>
    ))}
  </TabBarContent>
  <TabBarTrigger>More</TabBarTrigger>
</TabBar>
```

## Composition

Use the following composition to build a `TabBar`:

```text
TabBar
├── TabBarList
│   └── TabBarItem
├── TabBarContent
│   └── TabBarSection
│       ├── TabBarSectionTitle
│       └── TabBarLink
└── TabBarTrigger
```

## Accessibility

- `TabBar` is a `navigation` landmark; name it with `aria-label`.
- Active items and links set `aria-current="page"`.
- The More button sets `aria-expanded` and `aria-controls` to point to the content.
- `Escape` closes the open bar and returns focus to the More button. A pointer press outside the bar also closes it.
- While open, the list is `inert`. Items moved into the overflow are hidden from assistive technologies and removed from the tab order in the list, and appear as links in the content instead.
- When the More button isn't needed, it's hidden and removed from the tab order.

## API Reference

### TabBar

The floating `nav` container that holds the open state.

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `(open: boolean) => void` | - |

Also accepts the props of `React.ComponentProps<"nav">`.

Use `defaultOpen` for an uncontrolled bar, or `open` with `onOpenChange` to control it; `onOpenChange` is called when the More panel opens or closes. Give the `nav` a name with `aria-label`. The bar sits above the safe-area inset at the bottom of the screen, and animations are removed when reduced motion is preferred. Child components can read the bar's state with the `useTabBar` hook, which throws if it's used outside a `TabBar`.

### TabBarList

The row of primary items; items that don't fit move into the content.

Also accepts the props of `React.ComponentProps<"div">`.

### TabBarItem

A primary destination in the list, rendered as a button by default.

| Prop | Type | Default |
| --- | --- | --- |
| `isActive` | `boolean` | `false` |

<OnlyBase base="base">

Also accepts the props of `useRender.ComponentProps<"button">`, `React.ComponentProps<"button">`.

</OnlyBase>

<OnlyBase base="radix">

Also accepts the props of `React.ComponentProps<"button">`, plus `asChild`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts the props of `React.ComponentProps<"button">`, plus a `render` function.

</OnlyBase>

`isActive` marks the item as the current page with `aria-current="page"`. An item can render as a link or router link, as in the Links example.

### TabBarTrigger

The More button that expands and collapses the content.

Also accepts the props of `React.ComponentProps<typeof Button>`.

### TabBarContent

The expandable area above the list that holds overflowed items and sections.

Also accepts the props of `React.ComponentProps<"div">`.

### TabBarSection

A column of related links in the content.

Also accepts the props of `React.ComponentProps<"div">`.

### TabBarSectionTitle

The heading of a section, marked with a small dot.

Also accepts the props of `React.ComponentProps<"div">`.

### TabBarLink

A link inside a section that closes the bar when chosen.

| Prop | Type | Default |
| --- | --- | --- |
| `isActive` | `boolean` | `false` |

<OnlyBase base="base">

Also accepts the props of `useRender.ComponentProps<"a">`, `React.ComponentProps<"a">`.

</OnlyBase>

<OnlyBase base="radix">

Also accepts the props of `React.ComponentProps<"a">`, plus `asChild`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts the props of `React.ComponentProps<"a">`, plus a `render` function.

</OnlyBase>

`isActive` marks the link as the current page with `aria-current="page"`.

Each part sets a `data-slot`, such as `tab-bar-item` or `tab-bar-content`, for styling. `TabBar` sets `data-open`, `data-overflowing` and `data-sections`, the trigger sets `data-idle` when it's hidden, and items and links set `data-active`.

</Only>

<Only platform="rn">

`TabBar` is built on the tabs primitive and sits at the bottom of a screen. `TabBarList` is a rounded capsule with a shadow, inset from the screen edges, so the bar floats above the page. The root adds bottom padding for the safe area, minus any inset an enclosing `Screen` already handles, and never less than 12 points. `TabBarItem` stacks an icon over a short label; the active tab sits on a `bg-secondary` pill and uses `text-primary` and a filled icon weight.

</Only>

Use it for switching between the top-level sections of an app. For switching views within a screen, use Tabs.

  title,
  children,

  title: string
  children: React.ReactNode
}) {
  return (
    <View className="-m-4 flex-1 bg-background">
      <View className="flex-1 gap-2 p-4">
        <Text variant="h3">{title}</Text>
        <Text variant="muted">Tap a tab to switch screens.</Text>
      </View>
      {children}
    </View>
  )
}

  badges = true,
  disabled,
}: {
  badges?: boolean
  disabled?: string
}) {

              key={item.value}
              value={item.value}
              icon={item.icon}
              badge={badges ? item.badge : undefined}
              disabled={item.value === disabled}

              {item.label}
            </TabBarItem>

}

## Accessibility

- The list has the `tablist` role and each item has the `tab` role, with selected and disabled states.
- A badge with a count or text is exposed as the tab's accessibility value, so VoiceOver and TalkBack read it after the label.

### TabBar

Root that holds the active tab, the side inset and the safe area padding.

Also accepts the props of `React.ComponentProps<typeof TabsPrimitive.Root>`.

Control the active tab with `value` and `onValueChange`, or set `defaultValue`. A selection haptic plays whenever the tab changes, when a haptics adapter is provided through `HapticsContext`. The bottom padding is the remaining safe area inset minus 8 points, and never less than 12 points.

### TabBarList

Capsule that holds the tabs.

Also accepts the props of `React.ComponentProps<typeof TabsPrimitive.List>`.

Put `TabBarItem` entries inside a `TabBarList`, inside `TabBar`.

### TabBarItem

One tab with an icon, a label and an optional badge.

| Prop | Type | Default |
| --- | --- | --- |
| `icon` | `PhosphorIcon` | - |
| `badge` | `TabBarBadgeValue` | - |

Also accepts the props of `React.ComponentProps<typeof TabsPrimitive.Tab>`.

Give each item a `value`, an `icon` and a label as children. The Phosphor `icon` sits above the label and uses the fill weight when active. `badge` sits on the icon's corner and takes a number, text or `true`: numbers above 99 show as `99+`, `0` and empty strings show nothing, and `true` shows a small dot. The `TabBarBadgeValue` type is also exported.
