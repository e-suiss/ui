<Only platform="rn">

`Fab` is a round primary `Pressable` rendered through a portal and pinned to the bottom-end corner of the screen, above the safe-area insets. It comes in `default` and `lg` sizes, and becomes an extended pill when you pass a `label`.

</Only>

When it has `FabAction` children, pressing it opens a speed dial: a scrim dims the screen and the actions rise above the button one after another. The plus icon rotates 45 degrees into a close mark; other icons swap to an X.

<Only platform="swift">

```swift
import PhosphorSwift
import SwiftUI

struct FabExample: View {
  var body: some View {
    FabStage {
      Fab(accessibilityLabel: "New note", action: {}) { Ph.plus.bold }
    }
  }
}

struct FabPage: View {
  var log: String?

  var body: some View {
    VStack(alignment: .leading, spacing: 8) {
      Text("Notes")
        .textVariant(.h3)
      Text("The button floats at the bottom end of the screen.")
        .textVariant(.muted)
      if let log, !log.isEmpty {
        Text(verbatim: log)
          .textStyle(.sm)
          .foregroundStyle(EsuissColor.mutedForeground)
          .accessibilityAddTraits(.updatesFrequently)
      }
    }
    .frame(maxWidth: .infinity, alignment: .leading)
  }
}

struct FabStage<Content: View>: View {
  var log: String?
  @ViewBuilder let content: () -> Content

  var body: some View {
    ZStack(alignment: .topLeading) {
      FabPage(log: log)
      content()
    }
    .containerRelativeFrame(.vertical) { height, _ in max(height - 32, 0) }
  }
}
```

import com.adamglin.PhosphorIcons
import com.adamglin.phosphoricons.Regular

@Composable
fun FabExample() {
    FabPage {
        Fab(PhosphorIcons.Regular.Plus, contentDescription = "New note", onClick = {})
    }

@Composable
fun FabPage(log: String? = null, fab: @Composable () -> Unit) {
    Box(Modifier.fillMaxSize()) {
        Column(
            modifier = Modifier
                .fillMaxWidth()
                .windowInsetsPadding(WindowInsets.safeDrawing)
                .padding(16.dp),
            verticalArrangement = Arrangement.spacedBy(8.dp),
        ) {
            Text("Notes", variant = TextVariant.H3)
            Text("The button floats at the bottom end of the screen.", variant = TextVariant.Muted)
            if (!log.isNullOrEmpty()) {
                Text(
                    log,
                    modifier = Modifier.semantics { liveRegion = LiveRegionMode.Polite },
                    style = Typography.sm.copy(color = EsuissTheme.colors.mutedForeground),
                )
            }
        }
        fab()
    }
}

## Accessibility

- The button and each action have the `button` role.
- With actions, the button reports its `expanded` state.
- The VoiceOver escape gesture and the Android back button close the speed dial.
- The scrim is hidden from screen readers.

</Only>

## API Reference

<Only platform="rn">

### Fab

Floating button that also hosts the speed dial.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `FabSize` | `"default"` |
| `icon` | `PhosphorIcon` | `PlusIcon` |
| `label` | `React.ReactNode` | - |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `(open: boolean) => void` | - |
| `portalHost` | `string` | - |
| `children` | `React.ReactNode` | - |

Also accepts the props of `React.ComponentProps<typeof Pressable>`.

`icon` defaults to a plus, and `label` can be text or a node. Add `FabAction` children to turn the button into a speed dial; tapping the scrim or pressing the Android back button closes it. Use `open`, `defaultOpen` and `onOpenChange` to control it, and pass `portalHost` to render into a named portal host. The position follows the safe-area insets and flips sides in right-to-left layouts. Animations respect the system Reduce Motion setting.

### FabAction

One action in the speed dial, with an icon and optional label.

| Prop | Type | Default |
| --- | --- | --- |
| `icon` | `PhosphorIcon` | Required |
| `children` | `React.ReactNode` | - |

Also accepts the props of `React.ComponentProps<typeof Pressable>`.

Pass the optional text label as children. Pressing an action calls its `onPress` and closes the dial. Actions use `bg-muted` in dark mode.

</Only>
