`Fab` is a round primary `Pressable` rendered through a portal and pinned to the bottom-end corner of the screen, above the safe-area insets. It comes in `default` and `lg` sizes, and becomes an extended pill when you pass a `label`.

When it has `FabAction` children, pressing it opens a speed dial: a scrim dims the screen and the actions rise above the button one after another. The plus icon rotates 45 degrees into a close mark; other icons swap to an X.

## Usage

```tsx
import { Fab, FabAction } from "@/components/ui/fab"
```

```tsx
<View className="flex-1">
  <Page />
  <Fab accessibilityLabel="New note" />
</View>
```

Use the default plus icon or pass any Phosphor icon to `icon`. Give an icon-only button an `accessibilityLabel`.

For a speed dial, add `FabAction` children with an `icon` and an optional text label. Pressing an action calls its `onPress` and closes the dial. Tapping the scrim or pressing the Android back button also closes it. Use `open`, `defaultOpen` and `onOpenChange` to control it.

Pass `portalHost` to render into a named portal host.

## API Reference

<ApiPart index={1}>

### Fab

Floating button that also hosts the speed dial.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `FabSize` | `"default"` | `default` or `lg`. |
| `icon` | `PhosphorIcon` | `PlusIcon` | Phosphor icon component. Defaults to a plus. |
| `label` | `React.ReactNode` | - | Text or node shown beside the icon. |
| `open` | `boolean` | - | Controlled speed dial state. |
| `defaultOpen` | `boolean` | `false` | Initial speed dial state. |
| `onOpenChange` | `(open: boolean) => void` | - | Called when the speed dial opens or closes. |
| `portalHost` | `string` | - | Name of the portal host to render into. |
| `children` | `React.ReactNode` | - |  |

Also accepts the props of `React.ComponentProps<typeof Pressable>`.

</ApiPart>

<ApiPart index={2}>

### FabAction

One action in the speed dial, with an icon and optional label.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `icon` | `PhosphorIcon` | Required | Phosphor icon component for the action. |
| `children` | `React.ReactNode` | - |  |

Also accepts the props of `React.ComponentProps<typeof Pressable>`.

</ApiPart>

## Accessibility

- The button and each action have the `button` role.
- With actions, the button reports its `expanded` state.
- The VoiceOver escape gesture and the Android back button close the speed dial.
- The scrim is hidden from screen readers.

## Notes

- Position follows the safe-area insets and flips sides in right-to-left layouts.
- Animations respect the system Reduce Motion setting.
- Uses `bg-primary`, `bg-card` and `bg-black/50` tokens; actions use `bg-muted` in dark mode.
