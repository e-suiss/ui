Navigation Menu wraps the navigation menu primitive of the chosen base. `NavigationMenu` is the root; inside it, `NavigationMenuList` holds `NavigationMenuItem` entries. An item contains either a `NavigationMenuTrigger` with `NavigationMenuContent`, or a single `NavigationMenuLink`. Inside content, use `NavigationMenuLabel` for column headings and `NavigationMenuLink` for destinations.

The root renders the popup for you. With `layout="popover"` it adds a `NavigationMenuPositioner`, a floating card that resizes and slides between items. With `layout="panel"` it adds a `NavigationMenuPanel`, a full-width sheet under the bar with a blurred backdrop, like a store's global navigation. Use Navigation Menu for site navigation links; use Menubar or Dropdown Menu for commands.

## Usage

```tsx
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuList,
  NavigationMenuTrigger,
  navigationMenuTriggerStyle,
} from "@/components/ui/navigation-menu"
```

```tsx
<div className="flex min-h-96 items-start justify-center">
  <NavigationMenu align="start">
    <NavigationMenuList>
      <NavigationMenuItem value="products">
        <NavigationMenuTrigger>Products</NavigationMenuTrigger>
        <NavigationMenuContent>
          <ul className="grid w-96 gap-1">
            {products.map((product) => (
              <li key={product.title}>
                <NavigationMenuLink href="#" className="items-start gap-3">
                  <product.icon className="mt-0.5" />
                  <div className="flex flex-col gap-1">
                    <span className="font-medium">{product.title}</span>
                    <span className="text-muted-foreground">
                      {product.description}
                    </span>
                  </div>
                </NavigationMenuLink>
              </li>
            ))}
          </ul>
        </NavigationMenuContent>
      </NavigationMenuItem>
      <NavigationMenuItem value="resources">
        <NavigationMenuTrigger>Resources</NavigationMenuTrigger>
        <NavigationMenuContent>
          <ul className="grid w-56 gap-1">
            {resources.map((resource) => (
              <li key={resource.title}>
                <NavigationMenuLink href="#">
                  <resource.icon />
                  {resource.title}
                </NavigationMenuLink>
              </li>
            ))}
          </ul>
        </NavigationMenuContent>
      </NavigationMenuItem>
      <NavigationMenuItem>
        <NavigationMenuLink href="#" className={navigationMenuTriggerStyle()}>
          Pricing
        </NavigationMenuLink>
      </NavigationMenuItem>
    </NavigationMenuList>
  </NavigationMenu>
</div>
```

## Composition

Use the following composition to build a `NavigationMenu`:

```text
NavigationMenu
├── NavigationMenuList
│   └── NavigationMenuItem
│       ├── NavigationMenuTrigger
│       ├── NavigationMenuContent
│       │   ├── NavigationMenuLabel
│       │   └── NavigationMenuLink
│       └── NavigationMenuLink
├── NavigationMenuPositioner
└── NavigationMenuPanel
```

## Accessibility

- Triggers are buttons with `aria-expanded` reflecting whether their content is open.
- Enter opens a focused trigger, and Tab moves focus into the open content.
- Escape closes the open content and returns focus to its trigger.
- Hovering another trigger switches the open content.
- A link with `active` set receives `aria-current="page"`.
- The trigger's caret icon is `aria-hidden`.

## API Reference

### NavigationMenu

The root that manages open state and renders the popover or panel popup.

| Prop | Type | Default |
| --- | --- | --- |
| `layout` | `"popover" \| "panel"` | `"popover"` |
| `align` | `"start" \| "center" \| "end"` | `"start"` |

<OnlyBase base="base aria">

| Prop | Type | Default |
| --- | --- | --- |
| `anchor` | `Element \| React.RefObject<Element \| null> \| VirtualElement \| (() => Element \| VirtualElement \| null) \| null` | - |

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `anchor` | `React.RefObject<HTMLElement \| null>` | - |

</OnlyBase>

Also accepts the props of the primitive parts it wraps.

`layout="popover"` shows a floating card, and `layout="panel"` a full-width sheet with a backdrop. `align` sets how the card lines up with the bar in the `popover` layout. `anchor` is the element the popup is positioned against; in the `panel` layout, pass a ref to the full-width bar. Give each item with content a `value` so the menu can be opened by default or controlled with `value`, `defaultValue` and `onValueChange`.

### NavigationMenuList

The horizontal list of top-level items.

Also accepts the props of the primitive part it wraps.

### NavigationMenuItem

One top-level entry, holding a trigger with content or a single link.

Also accepts the props of the primitive part it wraps.

### NavigationMenuTrigger

The button that opens its item's content, with a caret in the popover layout.

Also accepts the props of the primitive part it wraps.

### NavigationMenuContent

The content shown in the popup when its item is open.

Also accepts the props of the primitive part it wraps.

### NavigationMenuPositioner

The floating popover card used by the `popover` layout. `NavigationMenu` renders it for you.

<OnlyBase base="base aria">

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `sideOffset` | `number` | `8` |
| `align` | `"start" \| "center" \| "end"` | `"start"` |
| `alignOffset` | `number` | `0` |

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `align` | `"start" \| "center" \| "end"` | `"start"` |
| `anchor` | `React.RefObject<HTMLElement \| null>` | - |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

<OnlyBase base="base aria">

`side` is the side of the bar the card opens on, and `sideOffset` the gap in pixels between them. `alignOffset` shifts the card in pixels along the alignment axis.

</OnlyBase>

<OnlyBase base="radix">

`anchor` is the element the card is positioned against.

</OnlyBase>

### NavigationMenuPanel

The full-width sheet and backdrop used by the `panel` layout. `NavigationMenu` renders it for you.

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `anchor` | `React.RefObject<HTMLElement \| null>` | - |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

### NavigationMenuLink

A navigation link, either in the bar or inside content.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"default" \| "lg"` | `"default"` |

Also accepts the props of the primitive part it wraps.

`size="lg"` uses large, semibold text for primary destinations. Set `active` to mark the current page. To style a top-level link like a trigger, pass `navigationMenuTriggerStyle()` as its `className`. Triggers and links restyle themselves in the `panel` layout, and panel list items animate in with a stagger that respects reduced motion.

### NavigationMenuLabel

A small secondary heading above a group of links.

Also accepts the props of `React.ComponentProps<"p">`.

### NavigationMenuIndicator

A small arrow that fades in while its menu is open.

Also accepts the props of the primitive part it wraps.

Each part sets a `data-slot`, such as `navigation-menu-trigger` or `navigation-menu-panel`, for styling. The root sets `data-layout`, and links set `data-size` and `data-active`.
