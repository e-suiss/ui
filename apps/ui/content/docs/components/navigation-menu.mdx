Navigation Menu wraps Base UI's Navigation Menu. `NavigationMenu` is the root; inside it, `NavigationMenuList` holds `NavigationMenuItem` entries. An item contains either a `NavigationMenuTrigger` with `NavigationMenuContent`, or a single `NavigationMenuLink`. Inside content, use `NavigationMenuLabel` for column headings and `NavigationMenuLink` for destinations.

The root renders the popup for you. With `layout="popover"` it adds a `NavigationMenuPositioner`, a floating card that resizes and slides between items. With `layout="panel"` it adds a `NavigationMenuPanel`, a full-width sheet under the bar with a blurred backdrop, like a store's global navigation. Use Navigation Menu for site navigation links; use Menubar or Dropdown Menu for commands.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add navigation-menu
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @base-ui/react @phosphor-icons/react class-variance-authority cn
```

2. Copy the source into `components/ui/navigation-menu.tsx`:

<ComponentSource path="components/ui/navigation-menu.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { NavigationMenu, NavigationMenuList, NavigationMenuItem, NavigationMenuTrigger, NavigationMenuContent, NavigationMenuPositioner, NavigationMenuPanel, NavigationMenuLink, NavigationMenuLabel, NavigationMenuIndicator } from "@/components/ui/navigation-menu"
```

```tsx
<div className="flex min-h-96 items-start justify-center">
  <NavigationMenu align="start">
    <NavigationMenuList>
      <NavigationMenuItem value="products">
        <NavigationMenuTrigger>Products</NavigationMenuTrigger>
        <NavigationMenuContent>
          <ul className="grid w-96 gap-1">
            {products.map((product) => (
              <li key={product.title}>
                <NavigationMenuLink href="#" className="items-start gap-3">
                  <product.icon className="mt-0.5" />
                  <div className="flex flex-col gap-1">
                    <span className="font-medium">{product.title}</span>
                    <span className="text-label-secondary">
                      {product.description}
                    </span>
                  </div>
                </NavigationMenuLink>
              </li>
            ))}
          </ul>
        </NavigationMenuContent>
      </NavigationMenuItem>
      <NavigationMenuItem value="resources">
        <NavigationMenuTrigger>Resources</NavigationMenuTrigger>
        <NavigationMenuContent>
          <ul className="grid w-56 gap-1">
            {resources.map((resource) => (
              <li key={resource.title}>
                <NavigationMenuLink href="#">
                  <resource.icon />
                  {resource.title}
                </NavigationMenuLink>
              </li>
            ))}
          </ul>
        </NavigationMenuContent>
      </NavigationMenuItem>
      <NavigationMenuItem>
        <NavigationMenuLink href="#" className={navigationMenuTriggerStyle()}>
          Pricing
        </NavigationMenuLink>
      </NavigationMenuItem>
    </NavigationMenuList>
  </NavigationMenu>
</div>
```

Give each item with content a `value` so the menu can be opened by default or controlled with `value`, `defaultValue` and `onValueChange` on the root. The root also accepts `align` for the popover and `anchor` for either layout; in `panel` layout, pass a ref to the full-width bar as `anchor` so the panel spans its width.

To style a top-level link like a trigger, pass `navigationMenuTriggerStyle()` as its `className`. Set `active` on a link to mark the current page.

### NavigationMenu

The root that manages open state and renders the popover or panel popup.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `layout` | `"popover" \| "panel"` | `"popover"` | Chooses the popup style: `popover` for a floating card, or `panel` for a full-width sheet with a backdrop. |

Also accepts the props of `NavigationMenuPrimitive.Root.Props`, `NavigationMenuPrimitive.Positioner.Props`.

</ApiPart>

### NavigationMenuList

The horizontal list of top-level items.

Also accepts the props of `React.ComponentPropsWithRef<typeof NavigationMenuPrimitive.List>`.

</ApiPart>

One top-level entry, holding a trigger with content or a single link.

Also accepts the props of `React.ComponentPropsWithRef<typeof NavigationMenuPrimitive.Item>`.

</ApiPart>

The button that opens its item's content, with a caret in the popover layout.

The floating popover card used by the `popover` layout.

Also accepts the props of `NavigationMenuPrimitive.Positioner.Props`.

The full-width sheet and backdrop used by the `panel` layout.

### NavigationMenuLink

A navigation link, either in the bar or inside content.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"default" \| "lg"` | `"default"` | Sets the link size; `lg` uses large, semibold text for primary destinations. |

Also accepts the props of `NavigationMenuPrimitive.Link.Props`.

</ApiPart>

<ApiPart index={9}>

### NavigationMenuLabel

A small secondary heading above a group of links.

Also accepts the props of `React.ComponentProps<"p">`.

</ApiPart>

<ApiPart index={10}>

### NavigationMenuIndicator

A small arrow built on the Base UI `NavigationMenu.Icon` part that fades in while its menu is open.

Also accepts the props of `React.ComponentPropsWithRef<typeof NavigationMenuPrimitive.Icon>`.

</ApiPart>

## Accessibility

- Triggers are buttons with `aria-expanded` reflecting whether their content is open.
- Enter opens a focused trigger, and Tab moves focus into the open content.
- Escape closes the open content and returns focus to its trigger.
- Hovering another trigger switches the open content.
- A link with `active` set receives `aria-current="page"`.
- The trigger's caret icon is `aria-hidden`.

## Notes

- Styling hooks: `data-slot` values such as `navigation-menu`, `navigation-menu-trigger`, `navigation-menu-content`, `navigation-menu-popup`, `navigation-menu-panel`, `navigation-menu-backdrop` and `navigation-menu-link`. The root exposes `data-layout`; links expose `data-size` and `data-active`.
- Triggers and links restyle themselves automatically in the `panel` layout, and panel list items animate in with a stagger that respects reduced motion.
- `navigationMenuTriggerStyle` is exported for styling links as triggers.
- Uses the `surface-raised`, `surface`, `item-hover`, `item-selected`, `scrim` and `link` tokens.
