An `Attachment` typically contains an `AttachmentMedia` thumbnail, an `AttachmentContent` block with `AttachmentTitle` and `AttachmentDescription`, and an `AttachmentActions` slot holding one or more `AttachmentAction` buttons. `AttachmentMedia` can hold an icon, an `img`, or an `AttachmentLabel` file-type tag. During an upload, put an `AttachmentProgress` bar inside the content. Add an `AttachmentTrigger` to make the whole card clickable.

Wrap several attachments in an `AttachmentGroup` to render them as a single list with inset dividers. Use attachments for files in composers, chat messages and upload forms.

## Usage

```tsx
import {
  Attachment,
  AttachmentAction,
  AttachmentActions,
  AttachmentContent,
  AttachmentDescription,
  AttachmentGroup,
  AttachmentLabel,
  AttachmentMedia,
  AttachmentProgress,
  AttachmentTitle,
  AttachmentTrigger,
} from "@/components/ui/attachment"
```

```tsx
<Attachment orientation="horizontal" state="done">
  <AttachmentMedia variant="document">
    <AttachmentLabel className="bg-red-600">pdf</AttachmentLabel>
  </AttachmentMedia>
  <AttachmentContent>
    <AttachmentTitle>Quarterly report.pdf</AttachmentTitle>
    <AttachmentDescription>2.4 MB</AttachmentDescription>
  </AttachmentContent>
  <AttachmentActions>
    <AttachmentAction aria-label="Remove">
      <XIcon />
    </AttachmentAction>
  </AttachmentActions>
</Attachment>
```

## Composition

Use the following composition to build a `Attachment`:

```text
Attachment
├── AttachmentMedia
│   └── AttachmentLabel
├── AttachmentContent
│   ├── AttachmentTitle
│   ├── AttachmentDescription
│   └── AttachmentProgress
├── AttachmentActions
│   └── AttachmentAction
└── AttachmentTrigger
AttachmentGroup
└── Attachment
    ├── AttachmentMedia
    │   └── AttachmentLabel
    ├── AttachmentContent
    │   ├── AttachmentTitle
    │   ├── AttachmentProgress
    │   └── AttachmentDescription
    └── AttachmentActions
        └── AttachmentAction
```

## Accessibility

- `AttachmentProgress` wraps the progress primitive and exposes the `progressbar` role with `aria-valuenow`; give it an `aria-label`.
- `AttachmentTrigger` renders a `button` with `type="button"` by default; give it an `aria-label` that names the file.
- The trigger and each `AttachmentAction` are separate tab stops, in that order.
- The card shows a focus ring when its trigger has keyboard focus.

## API Reference

### Attachment

The card container that sets size, orientation and state.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"default" \| "sm" \| "xs"` | `"default"` |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `state` | `"idle" \| "uploading" \| "processing" \| "error" \| "done"` | `"done"` |

Also accepts the props of `React.ComponentProps<"div">`.

`orientation="horizontal"` places the media beside the content; `vertical` stacks it above and overlays the actions on the media. Set `state` to reflect the file's lifecycle: `idle` adds a dashed border (outside a group), and `error` colors the description red. The `state`, `size` and `orientation` values are exposed as `data-state`, `data-size` and `data-orientation` for your own styling.

### AttachmentLabel

A small uppercase tag, usually the file extension, shown inside the media.

Also accepts the props of `React.ComponentProps<"span">`.

The label uses `bg-primary` by default; override it with a color class per file type.

### AttachmentMedia

The thumbnail area for an icon, document tag or image.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"icon" \| "document" \| "image"` | `"icon"` |

Also accepts the props of `React.ComponentProps<"div">`.

Use `icon` for a bordered icon tile, `document` for a page shape with a bottom tag, and `image` for a cropped image. The variant is exposed as `data-variant`.

### AttachmentContent

Wraps the title, description and progress bar.

Also accepts the props of `React.ComponentProps<"div">`.

### AttachmentTitle

The file name, truncated to one line.

Also accepts the props of `React.ComponentProps<"span">`.

### AttachmentDescription

Secondary details such as file size or an error message.

Also accepts the props of `React.ComponentProps<"span">`.

### AttachmentProgress

A progress bar with a value readout for uploads.

Also accepts the props of the primitive part it wraps.

### AttachmentActions

The slot for action buttons or status indicators.

Also accepts the props of `React.ComponentProps<"div">`.

### AttachmentAction

A compact button for actions such as remove, cancel or download.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "tinted" \| "ghost" \| "plain" \| "destructive" \| "link"` | `"secondary"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "xl" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg" \| "icon-xl"` | `"icon-xs"` |

Also accepts the props of [Button](/docs/components/button).

`AttachmentAction` renders a `Button` with the `secondary` variant and an icon size by default. Pass `variant="link"` for a text action such as "Try Again"; its size then defaults to `"sm"`. Icon-only actions need an `aria-label`.

### AttachmentTrigger

An invisible button covering the card to make it clickable.

<OnlyBase base="base">

Also accepts the props of `useRender.ComponentProps<"button">`.

`AttachmentTrigger` is an invisible button stretched over the card. Give it an `aria-label`, or use `render` to turn it into a link. Actions sit above it, so they remain separately clickable.

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |

Also accepts the props of `React.ComponentProps<"button">`.

`AttachmentTrigger` is an invisible button stretched over the card. Give it an `aria-label`, or set `asChild` with a link as its child to turn it into a link. Actions sit above it, so they remain separately clickable.

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `(props: React.HTMLAttributes<HTMLElement>) => React.ReactNode` | — |

Also accepts the props of `React.ComponentProps<"button">`.

`AttachmentTrigger` is an invisible button stretched over the card. Give it an `aria-label`, or pass a `render` function that returns a link to turn it into a link. Actions sit above it, so they remain separately clickable.

</OnlyBase>

### AttachmentGroup

Stacks attachments into one rounded list with dividers.

Also accepts the props of `React.ComponentProps<"div">`.

Inside `AttachmentGroup`, attachments fill the width, lose their own rounding and get inset top dividers.

Each part sets a `data-slot`, such as `attachment`, `attachment-media` or `attachment-action`, for styling.

</Only>

`Attachment` is a rounded `View` that lays out an `AttachmentMedia` thumbnail, an `AttachmentContent` column and `AttachmentActions`. It comes in `default`, `sm` and `xs` sizes and in `horizontal` or `vertical` orientation; the vertical layout makes a tile with the actions floating over the media.

The `state` prop reflects the upload lifecycle: `idle` draws a dashed border for an empty drop slot, `error` turns the description red, and `uploading`, `processing` and `done` are passed to the parts through context. Put several attachments in an `AttachmentGroup` to show them as one list with hairlines between rows.
