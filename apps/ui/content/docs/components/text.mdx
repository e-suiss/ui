<Only platform="rn">

`Text` renders a React Native `Text` with one of twelve typography variants: `default`, `h1`–`h4`, `p`, `blockquote`, `code`, `lead`, `large`, `small` and `muted`. Heading variants also set the `heading` role.

It reads `TextClassContext`, so components such as `Button` can pass a text color and size down to any `Text` inside them.

</Only>

## Usage

<Only platform="rn">

```tsx
import { Text } from "@/components/ui/text"
```

```tsx
<Text>The quick brown fox jumps over the lazy dog.</Text>
```

</Only>

<Only platform="swift">

```swift
import SwiftUI

struct TextExample: View {
  var body: some View {
    Text("The quick brown fox jumps over the lazy dog.")
      .textVariant(.default)
  }
}
```

</Only>

## Accessibility

- `h1` to `h4` set `role="heading"`, so VoiceOver and TalkBack can navigate by heading.
- Text scales with the system font size.

## API Reference

<Only platform="rn">

### Text

The text element with typography variants.

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `RenderProp<Record<string, unknown>, Record<string, never>>` | - |
| `variant` | `"default" \| "h1" \| "h2" \| "h3" \| "h4" \| "p" \| "blockquote" \| "code" \| "lead" \| "large" \| "small" \| "muted"` | `"default"` |

Also accepts the props of `TextProps`.

Pick a `variant` for the role of the text, and add classes through `className` for one-off changes. Use `render` to render another component in place of the default `Text`, with the same props and classes. `TextClassContext` is exported so your own components can style nested `Text` the same way.

</Only>

<Only platform="swift">

### TextVariant

Values: `.default`, `.h1`, `.h2`, `.h3`, `.h4`, `.p`, `.blockquote`, `.code`, `.lead`, `.large`, `.small`, `.muted`.

### TextVariant

Values: `Default`, `H1`, `H2`, `H3`, `H4`, `P`, `Blockquote`, `Code`, `Lead`, `Large`, `Small`, `Muted`.

### Text

The text element with typography variants.

| Parameter | Type | Default |
| --- | --- | --- |
| `text` | `String` | - |
| `modifier` | `Modifier` | `Modifier` |
| `variant` | `TextVariant`: `Default` \| `H1` \| `H2` \| `H3` \| `H4` \| `P` \| `Blockquote` \| `Code` \| `Lead` \| `Large` \| `Small` \| `Muted` | `TextVariant.Default` |
| `color` | `Color` | `Color.Unspecified` |
| `textAlign` | `TextAlign` | `TextAlign.Unspecified` |
| `overflow` | `TextOverflow` | `TextOverflow.Clip` |
| `softWrap` | `Boolean` | `true` |
| `maxLines` | `Int` | `Int.MAX_VALUE` |
| `minLines` | `Int` | `1` |
| `style` | `TextStyle` | `TextStyle.Default` |
