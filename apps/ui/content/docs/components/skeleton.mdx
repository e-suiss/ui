`Skeleton` is a plain `div` with a pulsing animation, rounded corners and a `muted` fill. It has no size of its own; set width, height and shape with utility classes so each placeholder matches the content it replaces.

Combine several skeletons to sketch a layout, such as an avatar with two lines of text. For an indeterminate activity indicator, use `Spinner` instead.

## Accessibility

- `Skeleton` renders an empty `div` with no role or text, so it isn't announced. Let assistive technologies know content is loading another way, for example with `aria-busy` on the region that's loading.

## API Reference

### Skeleton

A pulsing placeholder block.

Also accepts the props of `React.ComponentProps<"div">`.

Size every skeleton with classes such as `h-4 w-48`. The skeleton sets `data-slot="skeleton"` and uses the `animate-pulse` animation.

## API Reference

<Only platform="rn">

### Skeleton

A pulsing placeholder block.

Also accepts the props of `React.ComponentProps<typeof View>`, `React.RefAttributes<View>`.

Set width, height and radius through `className`, for example `h-4 w-48` for a line of text or `size-12 rounded-full` for an avatar. Compose several skeletons to mirror the layout of the loaded content, then swap them for the real content once it arrives. The pulse runs on the UI thread through Reanimated, with a 1000 ms cycle.

</Only>

<Only platform="swift">

### Skeleton

A pulsing placeholder block.

| `cornerRadius` | `CGFloat` | `Radius.md` |
