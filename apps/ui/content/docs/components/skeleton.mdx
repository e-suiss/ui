`Skeleton` is a plain `div` with a pulsing animation, rounded corners and a `muted` fill. It has no size of its own; set width, height and shape with utility classes so each placeholder matches the content it replaces.

Combine several skeletons to sketch a layout, such as an avatar with two lines of text. For an indeterminate activity indicator, use `Spinner` instead.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/skeleton
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add skeleton
```

### Manual

1. Add the [`cn` helper](/docs/installation#the-cn-helper).

2. Copy the source into `components/ui/skeleton.tsx`:

<ComponentSource path="components/ui/skeleton.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton"
```

```tsx
<Skeleton className="h-4 w-48" />
```

Size every skeleton with classes such as `h-4 w-48`. Use `rounded-full` for avatars and other rounded shapes to override the default `rounded-md`.

## Accessibility

- `Skeleton` renders an empty `div` with no role or text, so it isn't announced. Let assistive technologies know content is loading another way, for example with `aria-busy` on the region that's loading.

## Notes

- Uses `data-slot="skeleton"`, the `animate-pulse` animation and the `bg-muted` token.

## Accessibility

- The skeleton is a plain view with no role or label. If loading state matters to the user, announce it elsewhere, for example with a `Spinner` that has an `accessibilityLabel`.

## Notes

- Uses the `bg-muted` token.
- The pulse runs on the UI thread through Reanimated, with a 1000 ms cycle.
- Light and dark colors follow the system appearance.
