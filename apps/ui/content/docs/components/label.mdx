`Label` renders a native `label` element with the library's form typography. Associate it with a control through `htmlFor`, or nest the control inside it, so clicking the label focuses or toggles the control.

Use `Label` for standalone controls. Inside a `Field` layout, prefer the field's own label part when one is provided.

## Accessibility

- The label text becomes the control's accessible name when linked with `htmlFor` or by nesting.
- Clicking the label focuses a text input or toggles a checkbox, matching native `label` behavior.

## Notes

- Styling hook: `data-slot="label"`.
- The label dims to `label-quaternary` when it follows a disabled peer control, or when an ancestor with the `group` class has `data-disabled="true"`.
- Font weight drops to normal when the label contains, or follows, a `checkbox`, `radio-group-item` or `switch` slot.

`Label` renders a `Text` inside a `Pressable` row. The pressable accepts `onPress`, `onLongPress`, `onPressIn` and `onPressOut`, so pressing the label can toggle or focus the control next to it. A disabled label uses a muted color.

## Usage

<Code lang="tsx" code={"import { Label } from \"@/components/ui/label\""} />

<Code lang="tsx" code={"<Label>Your email address</Label>"} />

Set a `nativeID` on the label and point the control's `accessibilityLabelledBy` at it, so screen readers read the label with the control.

For a checkbox or switch, pass an `onPress` that toggles the control, which gives a larger touch target. Inside a `Field`, use `FieldLabel` instead.

## Accessibility

- The label text reports its `disabled` state in `accessibilityState`.
- Link it to its control with `nativeID` on the label and `accessibilityLabelledBy` on the control.

## Notes

- Text uses the `text-label` token, and `text-label-quaternary` when disabled.
- Light and dark colors follow the system appearance.
