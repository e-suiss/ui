`Label` renders a native `label` element with the library's form typography. Associate it with a control through `htmlFor`, or nest the control inside it, so clicking the label focuses or toggles the control.

Use `Label` for standalone controls. Inside a `Field` layout, prefer the field's own label part when one is provided.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/label
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add label
```

### Manual

1. Add the [`cn` helper](/docs/installation#the-cn-helper).

2. Copy the source into `components/ui/label.tsx`:

<ComponentSource path="components/ui/label.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { Label } from "@/components/ui/label"
```

```tsx
<Label>Email address</Label>
```

Give the control an `id` and pass the same value to `htmlFor`. Next to a checkbox, radio item or switch, the label automatically switches to regular weight.

## API Reference

<ApiPart index={1}>

### Label

Renders a `label` element that names and activates its associated control.

Also accepts the props of `React.ComponentProps<"label">`.

</ApiPart>

## Accessibility

- The label text becomes the control's accessible name when linked with `htmlFor` or by nesting.
- Clicking the label focuses a text input or toggles a checkbox, matching native `label` behavior.

## Notes

- Styling hook: `data-slot="label"`.
- The label dims to `opacity-50` when it follows a disabled peer control, or when an ancestor with the `group` class has `data-disabled="true"`.
- Font weight drops to normal when the label contains, or follows, a `checkbox`, `radio-group-item` or `switch` slot.

`Label` renders a `Text` inside a `Pressable` row. The pressable accepts `onPress`, `onLongPress`, `onPressIn` and `onPressOut`, so pressing the label can toggle or focus the control next to it. A disabled label is dimmed to 50% opacity.

For a checkbox or switch, pass an `onPress` that toggles the control, which gives a larger touch target. Inside a `Field`, use `FieldLabel` instead.

<Only platform="rn">

## Accessibility

- The label text reports its `disabled` state in `accessibilityState`.
- Link it to its control with `nativeID` on the label and `accessibilityLabelledBy` on the control.

## Notes

- Text uses the `text-foreground` token, and `opacity-50` when disabled.
- Light and dark colors follow the system appearance.
