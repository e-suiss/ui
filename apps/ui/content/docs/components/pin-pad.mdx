<Only platform="rn">

`PinPad` combines a row of dots that fill as digits are entered with a `Keypad` for input. The length is between 4 and 8 digits. Each key press plays a selection haptic, and switching to the error state turns the dots red, plays an error haptic and shakes the row with Reanimated. Haptics play when a haptics adapter is provided through `HapticsContext`.

</Only>

An optional biometric key appears in the bottom-left corner of the keypad when `onBiometric` is set, and the delete key is disabled while nothing is entered.

## Usage

<Only platform="rn">

```tsx
import { PinPad } from "@/components/ui/pin-pad"
```

```tsx
<PinPad />
```

</Only>

<Only platform="swift">

```swift
import SwiftUI

struct PinPadDemo: View {
  let length: Int
  let error: Bool
  let biometric: Bool

  @State private var value: String

  init(value: String = "", length: Int = 6, error: Bool = false, biometric: Bool = false) {
    self.length = length
    self.error = error
    self.biometric = biometric
    _value = State(initialValue: value)
  }

  var body: some View {
    PinPad(value: $value, length: length, error: error, onBiometric: biometric ? {} : nil)
      .frame(maxWidth: .infinity)
  }
}
```

</Only>

## Accessibility

- The dots row is a single element labeled by `dotsLabel`, so screen readers hear progress without the digits.
- The row is a polite live region, so TalkBack announces progress as it changes.
- Keypad keys are buttons labeled with their digit; the delete and biometric keys use `deleteLabel` and `biometricLabel`.
- The shake animation respects the system reduce motion setting.

</Only>

## API Reference

<Only platform="rn">

### PinPad

The `PinPad` component shows passcode dots above a numeric keypad.

| Prop | Type | Default |
| --- | --- | --- |
| `length` | `number` | `6` |
| `value` | `string` | - |
| `defaultValue` | `string` | `""` |
| `onValueChange` | `(value: string) => void` | - |
| `onComplete` | `(value: string) => void` | - |
| `error` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `onBiometric` | `() => void` | - |
| `biometricIcon` | `PhosphorIcon` | - |
| `biometricLabel` | `string` | - |
| `deleteLabel` | `string` | - |
| `dotsLabel` | `(entered: number, length: number) => string` | `defaultDotsLabel` |
| `dotsClassName` | `string` | - |
| `keypadClassName` | `string` | - |

Also accepts the props of `React.ComponentProps<typeof View>`.

Use it uncontrolled with `defaultValue`, or controlled with `value` and `onValueChange`. Non-digits in `defaultValue` are removed. `length` is clamped between 4 and 8. `onValueChange` is called after each digit or deletion, and `onComplete` with the full code when the last digit is entered. Turning `error` on shakes the dots and plays an error haptic. `disabled` turns off the keypad and dims the dots.

The biometric key is shown only when `onBiometric` is set. `biometricLabel` and `deleteLabel` are the accessibility labels of those keys. `dotsLabel` builds the dots label from the entered count and the length, such as "3 of 6 entered". Style the dots and keypad separately with `dotsClassName` and `keypadClassName`.

</Only>
