`PinPad` combines a row of dots that fill as digits are entered with a `Keypad` for input. The length is between 4 and 8 digits. Each key press plays a selection haptic, and switching to the error state turns the dots red, plays an error haptic and shakes the row with Reanimated. Haptics play when a haptics adapter is provided through `HapticsContext`.

An optional biometric key appears in the bottom-left corner of the keypad when `onBiometric` is set, and the delete key is disabled while nothing is entered.

## Usage

```tsx
import { PinPad } from "@/components/ui/pin-pad"
```

```tsx
<PinPad />
```

Use it uncontrolled with `defaultValue`, or controlled with `value` and `onValueChange`. `onComplete` fires with the full code once the last digit is entered; check the code there, set `error` when it is wrong and clear the value to let the user try again.

Pass `onBiometric` to show the biometric key, with `biometricIcon` and `biometricLabel` to match the method in use. Style the dots and keypad separately with `dotsClassName` and `keypadClassName`.

## API Reference

<ApiPart index={1}>

### PinPad

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `length` | `number` | `6` | Number of digits, clamped between 4 and 8. Defaults to `6`. |
| `value` | `string` | - | Entered digits for controlled use. |
| `defaultValue` | `string` | `""` | Initial digits for uncontrolled use. Non-digits are removed. |
| `onValueChange` | `(value: string) => void` | - | Called with the new value after each digit or deletion. |
| `onComplete` | `(value: string) => void` | - | Called with the full code when the last digit is entered. |
| `error` | `boolean` | `false` | Shows the error state. Turning it on shakes the dots and plays an error haptic. |
| `disabled` | `boolean` | `false` | Turns off the keypad and dims the dots. |
| `onBiometric` | `() => void` | - | Called when the biometric key is pressed. The key is shown only when this is set. |
| `biometricIcon` | `PhosphorIcon` | - | Icon for the biometric key. |
| `biometricLabel` | `string` | - | Accessibility label for the biometric key. |
| `deleteLabel` | `string` | - | Accessibility label for the delete key. |
| `dotsLabel` | `(entered: number, length: number) => string` | `defaultDotsLabel` | Builds the dots label from the entered count and the length. Defaults to "3 of 6 entered". |
| `dotsClassName` | `string` | - | Classes for the dots row. |
| `keypadClassName` | `string` | - | Classes for the keypad. |

Also accepts the props of `React.ComponentProps<typeof View>`.

</ApiPart>

## Accessibility

- The dots row is a single element labeled by `dotsLabel`, so screen readers hear progress without the digits.
- The row is a polite live region, so TalkBack announces progress as it changes.
- Keypad keys are buttons labeled with their digit; the delete and biometric keys use `deleteLabel` and `biometricLabel`.
- The shake animation respects the system reduce motion setting.

## Notes

- Uses `bg-foreground` for filled dots, `border-input` for empty ones and `bg-destructive` in the error state; colors follow the system appearance.
