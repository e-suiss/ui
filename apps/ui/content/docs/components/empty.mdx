`Empty` is a centered container for empty states. Inside it, `EmptyHeader` groups an optional `EmptyMedia` with an `EmptyTitle` and `EmptyDescription`, and `EmptyContent` holds the actions, such as buttons, a search field or a help link. All parts are plain, styled elements with no interactive behavior of their own.

Use it when a list, folder, search or page has nothing to show. Keep the title short and use the description to suggest a next step.

## Usage

```tsx
import {
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle,
} from "@/components/ui/empty"
import { Button } from "@/components/ui/button"
```

```tsx
<div className="w-[32rem]">
  <Empty>
    <EmptyHeader>
      <EmptyMedia variant="icon">
        <FolderSimpleIcon />
      </EmptyMedia>
      <EmptyTitle>No projects yet</EmptyTitle>
      <EmptyDescription>
        You haven&apos;t created any projects yet. Get started by creating
        your first project.
      </EmptyDescription>
    </EmptyHeader>
    <EmptyContent>
      <div className="flex gap-2">
        <Button>Create project</Button>
        <Button variant="outline">Import project</Button>
      </div>
      <Button variant="link" size="sm" className="text-muted-foreground">
        Learn more
        <ArrowUpRightIcon data-icon="inline-end" />
      </Button>
    </EmptyContent>
  </Empty>
</div>
```

## Composition

Use the following composition to build a `Empty`:

```text
Empty
├── EmptyHeader
│   ├── EmptyMedia
│   ├── EmptyTitle
│   └── EmptyDescription
└── EmptyContent
    └── EmptyDescription
```

## Accessibility

- `EmptyTitle` renders a `div`, not a heading. If the empty state should appear in the document outline, render a heading element inside it or pass the appropriate role and level.
- Give interactive elements in `EmptyContent` clear accessible names.

## API Reference

### Empty

The centered container for the empty state.

Also accepts the props of `React.ComponentProps<"div">`.

### EmptyHeader

Groups the media, title and description.

Also accepts the props of `React.ComponentProps<"div">`.

### EmptyMedia

Holds an icon or image above the title.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "icon"` | `"default"` |

Also accepts the props of `React.ComponentProps<"div">`.

`icon` places the icon in a small rounded `bg-muted` tile; `default` renders the media without a background. `EmptyMedia` sets `data-variant`.

### EmptyTitle

The short heading of the empty state.

Also accepts the props of `React.ComponentProps<"div">`.

### EmptyDescription

Supporting text that explains the state or suggests a next step.

Also accepts the props of `React.ComponentProps<"p">`.

It renders a `div` element even though it accepts paragraph props. Links placed directly inside it are underlined.

### EmptyContent

Holds actions such as buttons, inputs or links.

Also accepts the props of `React.ComponentProps<"div">`.

Each part sets a `data-slot`, such as `empty-header` or `empty-content`, for styling. `EmptyMedia` uses `empty-icon`.

`Empty` is a centered column that fills the available space and holds an `EmptyHeader` with optional `EmptyMedia`, an `EmptyTitle` and an `EmptyDescription`, followed by `EmptyContent` for actions. Text is centered and the header and content are limited to a readable width.

Use it for empty lists, search results with no matches and first-run screens.

<Only platform="rn kotlin">

`EmptyMedia` has two variants: `default` shows its child as is, such as an illustration, and `icon` puts an `Icon` in a small rounded tile. Put buttons or links in `EmptyContent`.
