`Message` arranges one message row: an optional `MessageAvatar` and a `MessageContent` column. Inside the content, place an optional `MessageHeader` (such as a sender name), one or more bubbles, and an optional `MessageFooter` (such as a timestamp or read receipt). Wrap consecutive messages in `MessageGroup` to stack them.

`Message` handles layout only. Pair it with Bubble for the message surface and with Message Scroller for a scrolling transcript.

Set `align="end"` for messages sent by the current user. The row reverses, so the avatar moves to the end, and the content's children and the footer align to the end edge.

## Notes

- Styling hooks: `data-slot` values `message-group`, `message`, `message-avatar`, `message-content`, `message-header` and `message-footer`. `Message` also sets `data-align`.
- When a footer is present, the avatar shifts up to line up with the last bubble rather than the footer.
- Header and footer drop their horizontal padding when the message contains an element with `data-variant="ghost"`.
- Header and footer text uses the `label-secondary` token; the avatar background uses `surface-secondary`.
