`Message` arranges one message row: an optional `MessageAvatar` and a `MessageContent` column. Inside the content, place an optional `MessageHeader` (such as a sender name), one or more bubbles, and an optional `MessageFooter` (such as a timestamp or read receipt). Wrap consecutive messages in `MessageGroup` to stack them.

`Message` handles layout only. Pair it with Bubble for the message surface and with Message Scroller for a scrolling transcript.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/message
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add message
```

### Manual

1. Add the [`cn` helper](/docs/installation#the-cn-helper).

2. Copy the source into `components/ui/message.tsx`:

<ComponentSource path="components/ui/message.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { MessageGroup, Message, MessageAvatar, MessageContent, MessageHeader, MessageFooter } from "@/components/ui/message"
import { Avatar, AvatarFallback } from "@/components/ui/avatar"
import { Bubble, BubbleContent } from "@/components/ui/bubble"
```

```tsx
<div className="w-96">
  <Message align="start">
    <MessageAvatar>
      <Avatar>
        <AvatarFallback>MK</AvatarFallback>
      </Avatar>
    </MessageAvatar>
    <MessageContent>
      <Bubble variant="muted">
        <BubbleContent>Are we still on for lunch tomorrow?</BubbleContent>
      </Bubble>
    </MessageContent>
  </Message>
</div>
```

Set `align="end"` for messages sent by the current user. The row reverses, so the avatar moves to the end, and the content's children and the footer align to the end edge.

## Notes

- Styling hooks: `data-slot` values `message-group`, `message`, `message-avatar`, `message-content`, `message-header` and `message-footer`. `Message` also sets `data-align`.
- When a footer is present, the avatar shifts up to line up with the last bubble rather than the footer.
- Header and footer drop their horizontal padding when the message contains an element with `data-variant="ghost"`.
- Header and footer text uses the `muted-foreground` color; the avatar background uses `muted`.

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import com.esuiss.ui.components.Avatar
import com.esuiss.ui.components.AvatarFallback
import com.esuiss.ui.components.Bubble
import com.esuiss.ui.components.BubbleContent
import com.esuiss.ui.components.BubbleVariant
import com.esuiss.ui.components.Message
import com.esuiss.ui.components.MessageAvatar
import com.esuiss.ui.components.MessageContent

@Composable
fun MessageInitials(text: String) {
    MessageAvatar {
        Avatar(fallback = { AvatarFallback(text) })
    }
}

@Composable
fun MessageDefault() {
    Message(Modifier.fillMaxWidth()) {
        MessageInitials("MK")
        MessageContent {
            Bubble(variant = BubbleVariant.Muted) {
                BubbleContent("Are we still on for lunch tomorrow?")
            }
        }
    }
}
```

</Only>

Put a `MessageAvatar` and a `MessageContent` inside each `Message`, and place `Bubble` components, a `MessageHeader` and a `MessageFooter` in `MessageContent`.

<Only platform="rn">

Plain strings in `MessageHeader` and `MessageFooter` are wrapped in `Text` for you, so you can pass text directly or mix it with an `Icon`.

</Only>

When `MessageContent` contains a `MessageFooter`, the avatar shifts up so it lines up with the last bubble instead of the footer.

## Accessibility

- Messages are plain `View` and `Text` elements, so screen readers read the header, bubble text and footer in order.
- Give avatars without visible text, such as images, an `accessibilityLabel`.

## Notes

- Header and footer text use `text-xs text-muted-foreground`, with icons at `size-3.5`.
- The avatar slot uses `bg-muted`.
- Light and dark colors follow the system appearance.
