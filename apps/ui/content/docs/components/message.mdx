`Message` arranges one message row: an optional `MessageAvatar` and a `MessageContent` column. Inside the content, place an optional `MessageHeader` (such as a sender name), one or more bubbles, and an optional `MessageFooter` (such as a timestamp or read receipt). Wrap consecutive messages in `MessageGroup` to stack them.

`Message` handles layout only. Pair it with Bubble for the message surface and with Message Scroller for a scrolling transcript.

## Usage

```tsx
import {
  Message,
  MessageAvatar,
  MessageContent,
  MessageFooter,
  MessageGroup,
  MessageHeader,
} from "@/components/ui/message"
import { Avatar, AvatarFallback } from "@/components/ui/avatar"
import { Bubble, BubbleContent } from "@/components/ui/bubble"
```

```tsx
<div className="w-96">
  <Message align="start">
    <MessageAvatar>
      <Avatar>
        <AvatarFallback>MK</AvatarFallback>
      </Avatar>
    </MessageAvatar>
    <MessageContent>
      <Bubble variant="muted">
        <BubbleContent>Are we still on for lunch tomorrow?</BubbleContent>
      </Bubble>
    </MessageContent>
  </Message>
</div>
```

## Composition

Use the following composition to build a `Message`:

```text
Message
├── MessageAvatar
└── MessageContent
    ├── MessageHeader
    └── MessageFooter
MessageGroup
└── Message
    ├── MessageAvatar
    └── MessageContent
        └── MessageFooter
```

## API Reference

### MessageGroup

Stacks several messages vertically.

Also accepts the props of `React.ComponentProps<"div">`.

### Message

The row for one message that sets its alignment.

| Prop | Type | Default |
| --- | --- | --- |
| `align` | `"start" \| "end"` | `"start"` |

Also accepts the props of `React.ComponentProps<"div">`.

`align="end"` reverses the row for outgoing messages, so the avatar moves to the end and the content's children and the footer align to the end edge.

### MessageAvatar

A round container for the sender's avatar, aligned to the bottom of the row.

Also accepts the props of `React.ComponentProps<"div">`.

### MessageContent

The column that holds the header, bubbles and footer.

Also accepts the props of `React.ComponentProps<"div">`.

### MessageHeader

Small secondary text above the bubbles, such as the sender name.

Also accepts the props of `React.ComponentProps<"div">`.

### MessageFooter

Small secondary text below the bubbles, such as a timestamp.

Also accepts the props of `React.ComponentProps<"div">`.

The header and footer drop their horizontal padding when the message contains an element with `data-variant="ghost"`.

Each part sets a `data-slot`, such as `message` or `message-footer`, for styling. `Message` also sets `data-align`.

`Message` is a horizontal `View` that places an avatar next to a column of bubbles. Its `align` prop puts the row on the leading (`start`) or trailing (`end`) side and passes the alignment to any `Bubble` inside through context.

</Only>

`MessageGroup` stacks several messages into a conversation. `MessageHeader` and `MessageFooter` hold small secondary text, such as a sender name or a timestamp. Put a `MessageAvatar` and a `MessageContent` inside each `Message`, and place `Bubble` components, a `MessageHeader` and a `MessageFooter` in `MessageContent`.

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import com.esuiss.ui.components.Avatar
import com.esuiss.ui.components.AvatarFallback
import com.esuiss.ui.components.Bubble
import com.esuiss.ui.components.BubbleContent
import com.esuiss.ui.components.BubbleVariant
import com.esuiss.ui.components.Message
import com.esuiss.ui.components.MessageAvatar
import com.esuiss.ui.components.MessageContent

@Composable
fun MessageInitials(text: String) {
    MessageAvatar {
        Avatar(fallback = { AvatarFallback(text) })
    }
}

@Composable
fun MessageDefault() {
    Message(Modifier.fillMaxWidth()) {
        MessageInitials("MK")
        MessageContent {
            Bubble(variant = BubbleVariant.Muted) {
                BubbleContent("Are we still on for lunch tomorrow?")
            }
        }
    }
}
```

## Accessibility

- Messages are plain `View` and `Text` elements, so screen readers read the header, bubble text and footer in order.
- Give avatars without visible text, such as images, an `accessibilityLabel`.

## API Reference

<Only platform="rn">

### MessageGroup

Vertical stack of messages.

Also accepts the props of `ViewProps`.

### Message

Row that holds the avatar and content and sets the alignment.

| Prop | Type | Default |
| --- | --- | --- |
| `align` | `MessageAlign` | `"start"` |

Also accepts the props of `ViewProps`.

`align` also passes the side to nested bubbles and the footer through context.

### MessageAvatar

Round slot for an avatar, pinned to the bottom of the row.

Also accepts the props of `ViewProps`.

### MessageContent

Column of bubbles built on `BubbleGroup`.

Also accepts the props of `React.ComponentProps<typeof BubbleGroup>`.

### MessageHeader

Small secondary text above the bubbles.

Also accepts the props of `ViewProps`.

Plain strings in `MessageHeader` and `MessageFooter` are wrapped in `Text` for you, so you can pass text directly or mix it with an `Icon`.

### MessageFooter

Small secondary text below the bubbles, aligned with the message side.

Also accepts the props of `ViewProps`.

</Only>
