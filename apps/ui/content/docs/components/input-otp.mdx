Input OTP is built on the `input-otp` library. `InputOTP` renders a single hidden text input that holds the whole code, and displays it through `InputOTPSlot` elements, each showing the character at its `index`. Group slots with `InputOTPGroup`, and place an `InputOTPSeparator` between groups to split a code, for example into two sets of three.

Use it for verification and two-factor codes. For other short values, use `Input`.

## Usage

```tsx
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSeparator,
  InputOTPSlot,
} from "@/components/ui/input-otp"
```

```tsx
<InputOTP maxLength={6} aria-label="Verification code">
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} />
    <InputOTPSlot index={4} />
    <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>
```

## Composition

Use the following composition to build a `InputOTP`:

```text
InputOTP
├── InputOTPGroup
│   └── InputOTPSlot
└── InputOTPSeparator
```

## Accessibility

- The code is entered into one native text input, so it has the `textbox` role. Give it an accessible name with `aria-label` or an associated label.
- Slots are visual only; assistive technology reads the value of the input.
- `InputOTPSeparator` has the `separator` role.
- When `disabled`, the input cannot be edited and the slots are dimmed.

## API Reference

### InputOTP

The root that holds the code in a single hidden input.

| Prop | Type | Default |
| --- | --- | --- |
| `containerClassName` | `string` | - |

Also accepts the props of `React.ComponentProps<typeof OTPInput>`.

Set `maxLength` to the length of the code. The value is uncontrolled with `defaultValue`, or controlled with `value` and `onChange`, which receives the code as a string. Typing fills the slots in order and stops at `maxLength`; Backspace removes the last character. `containerClassName` styles the element that wraps the slots, which also passes the invalid and disabled states to them through `data-input-otp-container`.

### InputOTPGroup

Groups adjacent slots.

Also accepts the props of `React.ComponentProps<"div">`.

### InputOTPSlot

Displays one character of the code and a caret when active.

| Prop | Type | Default |
| --- | --- | --- |
| `index` | `number` | Required |

Also accepts the props of `React.ComponentProps<"div">`.

Render one slot for each position, with `index` values from `0`. The active slot gets `data-active="true"`, a `primary` border and a blinking caret.

### InputOTPSeparator

A dash shown between groups of slots.

Also accepts the props of `React.ComponentProps<"div">`.

Each part sets a `data-slot`, such as `input-otp-slot`, for styling.

`InputOTP` is backed by one hidden `TextInput` and shows each character in an `InputOTPSlot`. The active slot gets a `border-primary` border and a blinking caret. The hidden input uses the one-time-code autofill hints, so codes from messages can be filled in automatically, and pasting fills every slot.

Group slots with `InputOTPGroup` and place an `InputOTPSeparator` between groups for codes such as `123-456`.

## Accessibility

- Screen readers interact with the hidden input, labelled "N character code" by default; pass `inputProps` with an `accessibilityLabel` to localize it.
- The visual slots are hidden from VoiceOver and TalkBack.
- `disabled` is exposed on the input.

## API Reference

<Only platform="rn">

### InputOTP

Root that owns the hidden input and the value.

Also accepts the props of `React.ComponentProps<typeof OTPFieldPrimitive.Root>`.

Set `length` to the length of the code. Use `value` with `onValueChange` for controlled state, or `defaultValue`. `onValueComplete` fires when every slot is filled. `validationType` limits input to `numeric` (the default number pad), `alpha`, `alphanumeric` or `none`, and `onValueInvalid` reports rejected characters. Set `mask` to hide the characters. The hidden input sets `textContentType="oneTimeCode"` and `autoComplete="one-time-code"` for autofill.

### InputOTPGroup

Row of adjacent slots.

Also accepts the props of `React.ComponentProps<typeof View>`.

### InputOTPSlot

Box that shows one character.

Also accepts the props of `React.ComponentProps<typeof OTPFieldPrimitive.Input>`.

Render one slot per `index`. Use `InputOTPSlotClassContext` to style every slot at once, or `className` on a single slot. The caret blink respects the system Reduce Motion setting.

### InputOTPSeparator

Dash between groups.

Also accepts the props of `React.ComponentProps<typeof OTPFieldPrimitive.Separator>`.

</Only>
