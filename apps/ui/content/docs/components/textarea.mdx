`Textarea` renders a native `textarea` styled to match the other form controls. By default it uses `field-sizing: content`, so it grows as people type, starting at a minimum height of `4rem`.

Set `resizable` to give it a fixed height and a custom handle that people drag to resize it vertically. Use `Textarea` for free-form text such as messages or notes; for a single line, use `Input`.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/textarea
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"

```

## Usage

```tsx
import { Textarea } from "@/components/ui/textarea"
```

```tsx
<div className="w-80">
  <Textarea placeholder="Type your message here." />
</div>
```

`Textarea` passes its props to the native element, so use `value` with `onChange` to control it, or `defaultValue` for an uncontrolled field. Pair it with a `Label` through `htmlFor` and `id`, and link hint text with `aria-describedby`.

With `resizable`, the textarea and its handle are wrapped in a relative container. Double-click the handle to reset the height.

## API Reference

<ApiPart index={1}>

### Textarea

The multi-line text field, with an optional resize handle.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `resizable` | `"inside" \| "outside"` | - | Adds a vertical resize handle, placed `inside` or `outside` the field's bottom corner, and turns off automatic growth. |

Also accepts the props of `React.ComponentProps<"textarea">`.

</ApiPart>

## Accessibility

- Renders a native `textarea` with the `textbox` role. Name it with a `Label` or `aria-label`.
- The resize handle is hidden from assistive technologies and works with a pointer only.
- An invalid field is exposed through `aria-invalid`.

## Notes

- Uses `data-slot="textarea"` and sets `data-resizable` when resizable; the wrapper and handle use `textarea-container` and `textarea-handle`.
- A resizable textarea starts at a minimum height of `6rem`, and dragging never shrinks it below its minimum height.
- The handle is hidden while the textarea is disabled, and mirrors in right-to-left layouts.
- The caret uses the `primary` color; invalid fields use the `destructive` color.

<Only platform="rn">

`Textarea` is the multi-line version of `Input`. It wraps a `TextInput` through the same field control primitive, defaults to `multiline` with `numberOfLines={8}`, aligns text to the top and has a minimum height. It shows a focus border while editing, a destructive border and tint when invalid, and 50% opacity when disabled.

<Only platform="swift">

```swift
import SwiftUI

struct TextareaDemo: View {
  let placeholder: LocalizedStringKey

  @State private var text: String

  init(initial: String = "", placeholder: LocalizedStringKey = "Type your message here.") {
    self.placeholder = placeholder
    _text = State(initialValue: initial)
  }

  var body: some View {
    TextField(placeholder, text: $text, axis: .vertical)
      .textFieldStyle(.textarea)
      .frame(maxWidth: .infinity)
  }
}
```

</Only>

<Only platform="kotlin">

```kotlin
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.saveable.rememberSaveable
import androidx.compose.runtime.setValue
import androidx.compose.ui.Modifier
import com.esuiss.ui.components.Textarea

@Composable
fun TextareaDemo(
    initial: String = "",
    placeholder: String = "Type your message here.",
    enabled: Boolean = true,
) {
    var value by rememberSaveable { mutableStateOf(initial) }
    Textarea(value, { value = it }, Modifier.fillMaxWidth(), enabled = enabled, placeholder = placeholder)
}
```

</Only>

<Only platform="rn">

Use it for comments, messages and other free-form text. Use `Input` for single-line values.

The value works controlled with `value` and `onValueChange(value, details)`, or uncontrolled with `defaultValue`. Inside a `Field`, the textarea picks up the field's label, description, invalid and disabled state.

Override `numberOfLines` or set a height through `className` to change the visible size.

</Only>

## Accessibility

- Inside a `Field`, the textarea gets the field label as `accessibilityLabel` and the description as `accessibilityHint`.
- `disabled` is set in `accessibilityState` and makes the textarea non-editable.
- Outside a `Field`, give it an `accessibilityLabel`.

## Notes

- Uses the `bg-secondary`, `border-ring` and `border-destructive` tokens, with `opacity-50` when disabled.
- In Uniwind and NativeWind, a focused field also draws the `ring-3 ring-ring/50` focus ring.
- Placeholder, cursor and selection colors come from the `muted-foreground` and `primary` tokens.
- Light and dark colors follow the system appearance.
