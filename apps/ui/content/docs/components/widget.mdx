`Widget` is a rounded `muted` card that comes in four sizes: `small` (168 × 168), `medium` (352 × 168), `large` (352 × 352) and `extra-large` (720 × 352), or `auto` to fill its parent. Compose it from `WidgetHeader`, which holds a `WidgetIcon`, `WidgetTitle` and an optional `WidgetAction`, followed by `WidgetValue`, `WidgetDescription`, `WidgetContent` and a `WidgetFooter` pinned to the bottom.

With `resizable`, a corner handle lets people drag the widget to another size. While dragging, a dashed outline previews the size it will snap to on release. Use widgets for glanceable summaries on a dashboard; for general grouped content, use `Card`.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/widget
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add widget
```

## Usage

```tsx
import { Widget, WidgetHeader, WidgetIcon, WidgetTitle, WidgetAction, WidgetDescription, WidgetValue, WidgetContent, WidgetFooter } from "@/components/ui/widget"
```

```tsx
<Widget size="small" align="start">
  <WidgetHeader>
    <WidgetIcon>
      <SunIcon weight="fill" />
    </WidgetIcon>
    <WidgetTitle>Istanbul</WidgetTitle>
  </WidgetHeader>
  <WidgetContent>
    <WidgetValue>24°</WidgetValue>
    <WidgetDescription>Partly cloudy</WidgetDescription>
  </WidgetContent>
  <WidgetFooter>H 27° · L 18°</WidgetFooter>
</Widget>
```

Use `size` with `onSizeChange` to control the size, or `defaultSize` to set where an uncontrolled widget starts. Without either, a resizable widget starts `small` and a fixed widget is `auto`. Limit the sizes a drag can snap to with `sizes`.

Set `resizable="free"` to follow the pointer without snapping; the widget stays between the smallest size and the largest allowed size. Double-click the handle to return to the starting size.

Adapt the content to the current size with the `group/widget` group and `data-size`, for example `group-data-[size=small]/widget:hidden`.

### Widget

The rounded card that sets the size, alignment and resize behavior.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `WidgetSize \| "auto"` | - | Controls the current size, or `auto` to fill the parent. |
| `defaultSize` | `WidgetSize \| "auto"` | - | Sets the starting size when uncontrolled; double-clicking the handle also returns to it. |
| `onSizeChange` | `(size: WidgetSize \| "auto") => void` | - | Called with the new size when a drag snaps to a different size or the size is reset. |
| `sizes` | `WidgetSize[]` | `["small", "medium", "large", "extra-large"]` | Lists the sizes a drag can snap to; the largest also caps free resizing. |
| `resizable` | `boolean \| "free"` | `false` | Adds a resize handle; `true` snaps to `sizes`, and `free` follows the pointer. |
| `handle` | `"inside" \| "outside"` | `"outside"` | Places the resize handle `inside` or `outside` the bottom corner. |
| `align` | `"start" \| "center"` | `"start"` | Centers the content horizontally and vertically when set to `center`. |

Also accepts the props of `React.ComponentProps<"div">`.

`WidgetSize` is `"small" | "medium" | "large" | "extra-large"`, exported from `@/components/ui/widget`.

## Accessibility

- `WidgetIcon` is hidden from assistive technologies, so make sure the title conveys its meaning.
- The resize handle is hidden from assistive technologies and works with a pointer only. Offer another way to change the size, such as a control that sets `size`, if it matters.

## Notes

- `Widget` sets `data-size` and `data-align`, and `data-resizing` while dragging. It's also a `@container/widget` container for container queries.
- Parts carry `data-slot` attributes such as `widget`, `widget-container`, `widget-handle`, `widget-preview` and `widget-header`.
- The handle is visible on hover and always visible on touch screens. It mirrors in right-to-left layouts.
- Size changes animate over `500ms`, and the animation is removed when reduced motion is preferred.

<Only platform="rn">

`Widget` is a `View` with a rounded, filled surface. It comes in four fixed sizes, `small` (168×168), `medium` (352×168), `large` (352×352) and `extra-large` (720×352), or `auto`, which fills its parent. Fixed sizes animate with Reanimated when the size changes.

With `resizable`, a corner handle lets the user drag the widget between sizes: a dashed outline previews the size it will snap to, a selection haptic plays on each new snap (when a haptics adapter is provided through `HapticsContext`), and double-tapping the handle returns to the initial size. Only sizes that fit the available width are offered. Set `align="center"` to center the content, which also hides `WidgetAction`.

</Only>

## Usage

<Only platform="rn">

```tsx
import { SunIcon } from "phosphor-react-native"
import { Icon } from "@/components/ui/icon"
import { Widget, WidgetContent, WidgetDescription, WidgetFooter, WidgetHeader, WidgetIcon, WidgetTitle, WidgetValue } from "@/components/ui/widget"

function Weather() {
  return (
    <>
      <WidgetHeader>
        <WidgetIcon>
          <Icon as={SunIcon} weight="fill" />
        </WidgetIcon>
        <WidgetTitle>Istanbul</WidgetTitle>
      </WidgetHeader>
      <WidgetContent>
        <WidgetValue>24°</WidgetValue>
        <WidgetDescription>Partly cloudy</WidgetDescription>
      </WidgetContent>
      <WidgetFooter>H 27° · L 18°</WidgetFooter>
    </>
  )
}

export function WidgetExample() {
  return (
    <Widget size="small" align="start">
      <Weather />
    </Widget>
  )
}
```

## Accessibility

- The resize handle has the `adjustable` role, its `resizeLabel` and the current size as its value; increment and decrement actions step through the available sizes, so VoiceOver and TalkBack users can resize without dragging.
- `WidgetTitle` has the `heading` role.
- `WidgetIcon` and the resize preview outline are hidden from assistive technology.
- Size animations respect the system reduce motion setting.

## Notes

- Uses `bg-muted` for the surface, `bg-secondary` for icon frames, and `text-muted-foreground/50` for the handle, which turns `text-primary` while dragging.
- The handle and drag direction mirror in right-to-left layouts.
- Light and dark colors follow the system appearance.
