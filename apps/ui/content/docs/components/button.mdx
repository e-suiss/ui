`Button` renders a native `button` by default. It supports eight visual variants, five text sizes and five icon-only sizes, and an optional `block` mode that fills the container width.

Use the `default` variant for the primary action in a view, `secondary`, `tinted` or `outline` for supporting actions, `ghost` and `plain` for low-emphasis actions, and `destructive` for actions that delete or remove. To join several buttons into one control, use Button Group.

## Accessibility

- Renders a native `button`, so `Enter` and `Space` activate it.
- A disabled button is removed from the tab order.
- Icon-only buttons need an `aria-label`.
- Keyboard focus shows a 3px ring in `--ring`; the `destructive` variant tints it with `ring-destructive/20`.
- `aria-invalid` adds a destructive border and ring, and `aria-expanded` shows a selected background on `outline`, `ghost` and `plain` buttons that open menus or popovers.

## API Reference

### Button

The interactive button element.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "tinted" \| "ghost" \| "plain" \| "destructive" \| "link"` | `"default"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "xl" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg" \| "icon-xl"` | `"default"` |
| `block` | `true` | - |

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

The `xs` to `xl` sizes are for text buttons; `icon-xs` to `icon-xl` are square sizes for icon-only buttons. `block` fills the container width and swaps the pill shape for rounded corners.

<OnlyBase base="base">

To render a link or a router component with button styling, use the `render` prop. `buttonVariants` is also exported if you need the classes on another element.

</OnlyBase>

<OnlyBase base="radix">

To render a link or a router component with button styling, set `asChild` and pass it as the child. `buttonVariants` is also exported if you need the classes on another element.

</OnlyBase>

<OnlyBase base="aria">

`Button` always renders a `button`. To give a link or a router component button styling, apply the classes from `buttonVariants` to it.

</OnlyBase>

Hover uses the variant color with an opacity, such as `hover:bg-primary/80`, and disabled buttons use `opacity-50`. In a group, the focused button is raised above its neighbors so the whole ring stays visible. Style a button through `data-slot="button"`.

</Only>

## API Reference

<Only platform="rn">

### Button

The interactive button element.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "tinted" \| "ghost" \| "plain" \| "destructive" \| "link"` | `"default"` |
| `size` | `"xs" \| "sm" \| "default" \| "lg" \| "xl" \| "icon-xs" \| "icon-sm" \| "icon" \| "icon-lg" \| "icon-xl"` | `"default"` |
| `block` | `boolean` | - |

Also accepts the props of `PressableProps`.

`icon` sizes are square, for buttons that contain only an icon. `block` stretches the button to the full width of its container. Put the label in a `Text` and icons in an `Icon`; the button passes its text color and icon size down through context, so children pick them up without extra classes. `buttonVariants` and `buttonTextVariants` are also exported if you need the classes on another element. Pressed buttons use `opacity-80` and disabled buttons `opacity-50`, and colors follow the system appearance.

</Only>

| `size` | `VariantButtonStyle.Size`: `.default` \| `.xs` \| `.sm` \| `.lg` \| `.xl` \| `.icon` \| `.iconXs` \| `.iconSm` \| `.iconLg` \| `.iconXl` | `.default` |
| `block` | `Bool` | `false` |

</Only>

<Only platform="kotlin">

### ButtonVariant

Values: `Default`, `Outline`, `Secondary`, `Tinted`, `Ghost`, `Plain`, `Destructive`, `Link`.

### ButtonSize

Values: `Default`, `Xs`, `Sm`, `Lg`, `Xl`, `Icon`, `IconXs`, `IconSm`, `IconLg`, `IconXl`.

### Button

The interactive button element.

| Parameter | Type | Default |
| --- | --- | --- |
| `onClick` | `() -> Unit` | - |
| `modifier` | `Modifier` | `Modifier` |

| `content` | `@Composable RowScope.() -> Unit` | - |
