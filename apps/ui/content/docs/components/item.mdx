`Item` is a row container. Inside it, `ItemMedia` holds an icon, image or avatar, `ItemContent` stacks an `ItemTitle` and `ItemDescription`, and `ItemActions` holds buttons or indicators at the end. `ItemHeader` and `ItemFooter` span the full width of the item, above and below the main row. Use the `render` prop to turn the whole item into a link or button.

`ItemGroup` stacks items as a list, and its `inset` variant groups them into a rounded list on a secondary surface, like iOS Settings. Place an `ItemSeparator` between items to divide them. Use items to display content; for form controls with labels and validation, use `Field`.

`ItemGroup` has the `list` role, so set `role="listitem"` on each `Item` inside it. Choose a `variant` for the item's border and background, and a `size` for its padding. Items inside a group with `sm` or `xs` items are spaced more tightly.

When `ItemDescription` is present, the media aligns to the top of the item instead of its center. The title is limited to one line and the description to two.

## Accessibility

- `ItemGroup` has the `list` role; give each `Item` in it the `listitem` role.
- `ItemSeparator` has the `none` role, so it is ignored by assistive technology.
- An item rendered as a link or button is a single focusable element and shows a focus ring.
- Give icon-only action buttons an accessible name with `aria-label`.

## Notes

- Styling hooks: `data-slot` values `item-group`, `item-separator`, `item`, `item-media`, `item-content`, `item-title`, `item-description`, `item-actions`, `item-header` and `item-footer`.
- `Item` sets `data-variant` and `data-size`; `ItemGroup` and `ItemMedia` set `data-variant`.
- An item rendered as an anchor gets the `item-hover` background on hover.
- Uses the `separator`, `surface-secondary`, `item-hover`, `label-secondary` and `link` tokens.

`ItemGroup` stacks items as a list. Its `inset` variant joins them into one rounded card with square inner corners, which suits settings screens; add `ItemSeparator` between rows to draw an inset divider.

Compose a row from `ItemMedia`, `ItemContent` (holding `ItemTitle` and `ItemDescription`) and `ItemActions`. Use `ItemHeader` and `ItemFooter` for full-width rows above or below the main content.

`ItemMedia` with `variant="icon"` sizes icons to 16 points; `variant="image"` makes a square thumbnail that shrinks with the item size. `ItemTitle` truncates to one line and `ItemDescription` to two by default; override with `numberOfLines`. Text inside `ItemActions` picks up a secondary color.

Pass `render` to render the row as another component while keeping the item styles.

## Accessibility

- `ItemGroup` has the `list` role.
- A static `Item` has the `listitem` role; an item with `onPress` or `onLongPress` has the `button` role and shows a pressed background.
- `disabled` dims the item and blocks presses.
- `ItemSeparator` is hidden from VoiceOver and TalkBack.

## Notes

- Uses `bg-surface-secondary` for inset groups and the `muted` variant, `border-separator` for `outline`, and `bg-item-pressed` for the pressed state.
- Colors follow the system appearance.
