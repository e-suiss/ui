`Item` is a row container. Inside it, `ItemMedia` holds an icon, image or avatar, `ItemContent` stacks an `ItemTitle` and `ItemDescription`, and `ItemActions` holds buttons or indicators at the end. `ItemHeader` and `ItemFooter` span the full width of the item, above and below the main row. The whole item can also render as a link or button.

<OnlyBase base="base">

Use the `render` prop to turn the whole item into a link or button.

</OnlyBase>

<OnlyBase base="radix">

Set `asChild` and pass a link or button as the child to turn the whole item into it.

</OnlyBase>

<OnlyBase base="aria">

Pass a `render` function that returns a link or button with the props it receives to turn the whole item into it.

</OnlyBase>

`ItemGroup` stacks items as a list, and its `inset` variant groups them into a rounded list on `bg-muted`, like iOS Settings. Place an `ItemSeparator` between items to divide them. Use items to display content; for form controls with labels and validation, use `Field`.

## Usage

```tsx
import { ItemGroup, ItemSeparator, Item, ItemMedia, ItemContent, ItemTitle, ItemDescription, ItemActions, ItemHeader, ItemFooter } from "@/components/ui/item"
```

```tsx
<div className="w-96">
  <Item variant="outline">
    <ItemMedia variant="icon">
      <ShieldCheckIcon />
    </ItemMedia>
    <ItemContent>
      <ItemTitle>Two-factor authentication</ItemTitle>
      <ItemDescription>
        Add an extra layer of security to your account.
      </ItemDescription>
    </ItemContent>
    <ItemActions>
      <Button variant="outline" size="sm">
        Enable
      </Button>
    </ItemActions>
  </Item>
</div>
```

`ItemGroup` has the `list` role, so set `role="listitem"` on each `Item` inside it. Choose a `variant` for the item's border and background, and a `size` for its padding. Items inside a group with `sm` or `xs` items are spaced more tightly.

When `ItemDescription` is present, the media aligns to the top of the item instead of its center. The title is limited to one line and the description to two.

## Accessibility

- `ItemGroup` has the `list` role; give each `Item` in it the `listitem` role.
- `ItemSeparator` has the `none` role, so it is ignored by assistive technology.
- An item rendered as a link or button is a single focusable element and shows a focus ring.
- Give icon-only action buttons an accessible name with `aria-label`.

## Notes

- Styling hooks: `data-slot` values `item-group`, `item-separator`, `item`, `item-media`, `item-content`, `item-title`, `item-description`, `item-actions`, `item-header` and `item-footer`.
- `Item` sets `data-variant` and `data-size`; `ItemGroup` and `ItemMedia` set `data-variant`.
- An item rendered as an anchor gets the `accent` background on hover.
- Uses the `border`, `muted`, `accent`, `muted-foreground` and `primary` colors.

import com.esuiss.ui.components.ItemMediaVariant

import com.esuiss.ui.theme.Typography

@Composable
fun ItemCaret() {
    Icon(PhosphorIcons.Regular.CaretRight, contentDescription = null, size = 16.dp, tint = EsuissTheme.colors.mutedForeground)

@Composable
fun ItemDefault() {
    Column(Modifier.fillMaxWidth(), verticalArrangement = Arrangement.spacedBy(16.dp)) {
        Item(variant = ItemVariant.Outline, role = null) {
            ItemContent {
                ItemTitle("Basic item")
                ItemDescription("A simple item with a title and a description.")
            }
            ItemActions {
                Button("Action", onClick = {}, variant = ButtonVariant.Outline, size = ButtonSize.Sm)
            }
        }
        Item(variant = ItemVariant.Muted, size = ItemSize.Sm, onClick = {}) {
            ItemMedia(variant = ItemMediaVariant.Icon) {
                Icon(PhosphorIcons.Regular.ShieldCheck, contentDescription = null)
            }
            ItemContent {
                ItemTitle("Your profile has been verified.")
            }
            ItemActions { ItemCaret() }
        }
        Item(variant = ItemVariant.Outline, size = ItemSize.Xs, role = null) {
            ItemHeader {
                ItemTitle("Header")
                Badge("New")
            }
            ItemContent {
                ItemDescription("Items can carry a header and a footer.")
            }
            ItemFooter {
                Text("Footer", style = Typography.sm.copy(color = EsuissTheme.colors.mutedForeground))
            }
        }
    }
}

</Only>

Compose a row from `ItemMedia`, `ItemContent` (holding `ItemTitle` and `ItemDescription`) and `ItemActions`. Use `ItemHeader` and `ItemFooter` for full-width rows above or below the main content.

<Only platform="rn">

`ItemMedia` with `variant="icon"` sizes icons to 16 points; `variant="image"` makes a square thumbnail that shrinks with the item size. `ItemTitle` truncates to one line and `ItemDescription` to two by default; override with `numberOfLines`. Text inside `ItemActions` picks up `text-muted-foreground`.

Pass `render` to render the row as another component while keeping the item styles.

</Only>

## Accessibility

- `ItemGroup` has the `list` role.
- A static `Item` has the `listitem` role; an item with `onPress` or `onLongPress` has the `button` role and fades to 80% opacity while pressed.
- `disabled` dims the item and blocks presses.
- `ItemSeparator` is hidden from VoiceOver and TalkBack.

## Notes

- Uses `bg-muted` for inset groups and the `muted` variant, `border-border` for `outline`, and `opacity-80` for the pressed state.
- Colors follow the system appearance.
