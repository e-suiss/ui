`ToggleGroup` wraps the toggle group primitive of the chosen base and holds `ToggleGroupItem` buttons that share the group's `variant` and `size`. Items can be spaced apart, attached into one bar, or combined into a segmented control.

Use a segmented group to switch between views, such as day, week and month. For a single on-off option, use `Toggle`; for switching panels of content, use `Tabs`.

## Accessibility

<OnlyBase base="base">

- The group has the `group` role; name it with `aria-label`.
- Each item is a `button` with `aria-pressed`. Icon-only items need an `aria-label`.

</OnlyBase>

<OnlyBase base="radix">

- The group has the `group` role; name it with `aria-label`.
- With `type="multiple"` each item is a `button` with `aria-pressed`. With `type="single"` each item has the `radio` role with `aria-checked`. Icon-only items need an `aria-label`.

</OnlyBase>

<OnlyBase base="aria">

- With `selectionMode="multiple"` the group has the `toolbar` role and each item is a `button` with `aria-pressed`. With `"single"` the group is a `radiogroup` and each item has the `radio` role with `aria-checked`. Name the group with `aria-label`. Icon-only items need an `aria-label`.

</OnlyBase>

- Arrow keys move focus between items: left and right in a horizontal group, up and down in a vertical one. `Space` toggles the focused item.

<OnlyBase base="base radix">

- `disabled` on the group disables every item.

</OnlyBase>

<OnlyBase base="aria">

- `isDisabled` on the group disables every item.

</OnlyBase>

<OnlyBase base="base">

The group's value is an array of item values. Use `defaultValue` for an uncontrolled group, or `value` with `onValueChange` to control it. Set `multiple` to let several items be pressed at once; without it, pressing an item releases the others.

</OnlyBase>

<OnlyBase base="radix">

Set `type` to `"single"` or `"multiple"`; it is required. With `"single"` the value is one item value, and pressing an item releases the others. With `"multiple"` it is an array of item values. Use `defaultValue` for an uncontrolled group, or `value` with `onValueChange` to control it.

</OnlyBase>

<OnlyBase base="aria">

The selection is a set of item ids. Use `defaultSelectedKeys` for an uncontrolled group, or `selectedKeys` with `onSelectionChange` to control it. Set `selectionMode="multiple"` to let several items be pressed at once; the default, `"single"`, releases the others when an item is pressed.

</OnlyBase>

`variant` and `size` style every item; values set on a `ToggleGroupItem` are overridden by the group's. `spacing` sets the gap between items on the spacing scale. `orientation` also sets which arrow keys move focus.

The segmented indicator's position is set through `--active-toggle-left`, `--active-toggle-top`, `--active-toggle-width` and `--active-toggle-height`. Its animation is removed when reduced motion is preferred.

<OnlyBase base="base radix">

The group sets `data-variant`, `data-size`, `data-spacing` and `data-orientation`.

</OnlyBase>

<OnlyBase base="aria">

The group sets `data-variant`, `data-size` and `data-spacing`, plus `data-horizontal` or `data-vertical`.

</OnlyBase>

## Usage

<Only platform="rn">

```tsx
import { TextBIcon, TextItalicIcon, TextUnderlineIcon } from "phosphor-react-native"
import * as React from "react"
import { ToggleGroup, ToggleGroupIcon, ToggleGroupItem } from "@/components/ui/toggle-group"

type GroupProps = Omit<
  React.ComponentProps<typeof ToggleGroup>,
  "value" | "onValueChange" | "children"
>

function FormattingDemo({
  initial = ["bold"],
  ...props
}: GroupProps & { initial?: string[] }) {
  const [value, setValue] = React.useState<string[]>(initial)
  return (
    <ToggleGroup multiple value={value} onValueChange={setValue} {...props}>
      <ToggleGroupItem value="bold" accessibilityLabel="Toggle bold">
        <ToggleGroupIcon as={TextBIcon} />
      </ToggleGroupItem>
      <ToggleGroupItem value="italic" accessibilityLabel="Toggle italic">
        <ToggleGroupIcon as={TextItalicIcon} />
      </ToggleGroupItem>
      <ToggleGroupItem value="underline" accessibilityLabel="Toggle underline">
        <ToggleGroupIcon as={TextUnderlineIcon} />
      </ToggleGroupItem>
    </ToggleGroup>
  )
}

export function ToggleGroupExample() {
  return (
    <FormattingDemo />
  )
}
```

## Accessibility

- A single-selection group has the `radiogroup` role and its items have the `radio` role.
- A `multiple` group has the `group` role and its items have the `togglebutton` role.
- Items report checked and disabled states to VoiceOver and TalkBack.
- The sliding segmented indicator is hidden from VoiceOver and TalkBack.
- Icon-only items need an `accessibilityLabel`; label the group itself with `accessibilityLabel` when its purpose is not clear from context.

## API Reference

<Only platform="rn">

### ToggleGroup

Container that holds the shared value.

| Prop | Type | Default |
| --- | --- | --- |
| `spacing` | `number` | `2` |

Also accepts the props of `React.ComponentProps<typeof ToggleGroupPrimitive>`.

The value is always an array of strings. Use `value` and `onValueChange` for controlled use, or `defaultValue`. Set `multiple` to allow more than one pressed item; without it, pressing an item replaces the selection. `spacing` sets the gap between items in steps of 4 points, and `0` joins them. `orientation` switches between a row and a column, and `disabled` on the group turns off every item.

### ToggleGroupItem

One toggle in the group.

Also accepts the props of `React.ComponentProps<typeof TogglePrimitive>`.

Give each item a `value`. Items take the same `variant` and `size` styles as Toggle. Give icon-only items an `accessibilityLabel`.

### ToggleGroupIcon

Icon sized for a toggle group item.

Also accepts the props of `React.ComponentProps<typeof Icon>`.

Sizes the icon to 16 points.

</Only>
