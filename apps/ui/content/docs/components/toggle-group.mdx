`ToggleGroup` wraps the toggle group primitive of the chosen base and holds `ToggleGroupItem` buttons that share the group's `variant` and `size`. Items can be spaced apart, attached into one bar, or combined into a segmented control.

With `spacing={0}` and the `default` variant, the group becomes a segmented control: a filled track where a raised pill slides to the pressed item. Use a segmented group to switch between views, such as day, week and month. For a single on-off option, use `Toggle`; for switching panels of content, use `Tabs`.

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group"
```

<OnlyBase base="base">

```tsx
<ToggleGroup spacing={2} orientation="horizontal" multiple defaultValue={["bold"]}>
  <ToggleGroupItem value="bold" aria-label="Toggle bold">
    <TextBIcon />
  </ToggleGroupItem>
  <ToggleGroupItem value="italic" aria-label="Toggle italic">
    <TextItalicIcon />
  </ToggleGroupItem>
  <ToggleGroupItem value="underline" aria-label="Toggle underline">
    <TextUnderlineIcon />
  </ToggleGroupItem>
</ToggleGroup>
```

The group's value is an array of item values. Use `defaultValue` for an uncontrolled group, or `value` with `onValueChange` to control it. Set `multiple` to let several items be pressed at once; without it, pressing an item releases the others.

</OnlyBase>

<OnlyBase base="radix">

```tsx
<ToggleGroup spacing={2} orientation="horizontal" type="multiple" defaultValue={["bold"]}>
  <ToggleGroupItem value="bold" aria-label="Toggle bold">
    <TextBIcon />
  </ToggleGroupItem>
  <ToggleGroupItem value="italic" aria-label="Toggle italic">
    <TextItalicIcon />
  </ToggleGroupItem>
  <ToggleGroupItem value="underline" aria-label="Toggle underline">
    <TextUnderlineIcon />
  </ToggleGroupItem>
</ToggleGroup>
```

Set `type` to `"single"` or `"multiple"`; it is required. With `"single"` the value is one item value, and pressing an item releases the others. With `"multiple"` it is an array of item values. Use `defaultValue` for an uncontrolled group, or `value` with `onValueChange` to control it.

</OnlyBase>

<OnlyBase base="aria">

```tsx
<ToggleGroup spacing={2} orientation="horizontal" selectionMode="multiple" defaultSelectedKeys={["bold"]}>
  <ToggleGroupItem id="bold" aria-label="Toggle bold">
    <TextBIcon />
  </ToggleGroupItem>
  <ToggleGroupItem id="italic" aria-label="Toggle italic">
    <TextItalicIcon />
  </ToggleGroupItem>
  <ToggleGroupItem id="underline" aria-label="Toggle underline">
    <TextUnderlineIcon />
  </ToggleGroupItem>
</ToggleGroup>
```

Give each item an `id`. The selection is a set of item ids. Use `defaultSelectedKeys` for an uncontrolled group, or `selectedKeys` with `onSelectionChange` to control it. Set `selectionMode="multiple"` to let several items be pressed at once; the default, `"single"`, releases the others when an item is pressed.

</OnlyBase>

Set `variant` and `size` on `ToggleGroup`; items take these from the group. Use `spacing={0}` with the `outline` variant to join items into one bordered bar.

## Accessibility

<OnlyBase base="base">

- The group has the `group` role; name it with `aria-label`.
- Each item is a `button` with `aria-pressed`. Icon-only items need an `aria-label`.

</OnlyBase>

<OnlyBase base="radix">

- The group has the `group` role; name it with `aria-label`.
- With `type="multiple"` each item is a `button` with `aria-pressed`. With `type="single"` each item has the `radio` role with `aria-checked`. Icon-only items need an `aria-label`.

</OnlyBase>

<OnlyBase base="aria">

- With `selectionMode="multiple"` the group has the `toolbar` role and each item is a `button` with `aria-pressed`. With `"single"` the group is a `radiogroup` and each item has the `radio` role with `aria-checked`. Name the group with `aria-label`. Icon-only items need an `aria-label`.

</OnlyBase>

- Arrow keys move focus between items: left and right in a horizontal group, up and down in a vertical one. `Space` toggles the focused item.

<OnlyBase base="base radix">

- `disabled` on the group disables every item.

</OnlyBase>

<OnlyBase base="aria">

- `isDisabled` on the group disables every item.

</OnlyBase>

## Notes

- The segmented indicator appears only when exactly one item is pressed. Its position is set through `--active-toggle-left`, `--active-toggle-top`, `--active-toggle-width` and `--active-toggle-height`.
- `variant` and `size` set on a `ToggleGroupItem` are overridden by the group's values.

<OnlyBase base="base radix">

- The group sets `data-variant`, `data-size`, `data-spacing` and `data-orientation`.

</OnlyBase>

<OnlyBase base="aria">

- The group sets `data-variant`, `data-size` and `data-spacing`, plus `data-horizontal` or `data-vertical`.

</OnlyBase>

- Parts use the `toggle-group`, `toggle-group-item` and `toggle-group-indicator` slots.
- The segmented track uses `bg-secondary` and the pill uses `bg-card`. Its animation is removed when reduced motion is preferred.

</Only>

<Only platform="rn">

`ToggleGroup` is built on the toggle group primitive and lays out `ToggleGroupItem` toggles in a row or a column. Items take the same `variant` and `size` styles as Toggle. The `spacing` prop sets the gap between items in steps of 4 points.

With `spacing={0}`, the group changes shape: the `default` variant becomes a segmented control on a `bg-secondary` track, and the `outline` variant joins items into one bordered strip. In a single-selection segmented control, the selected item is marked by a raised indicator that slides to the new item when the selection changes, like Tabs. In a `multiple` segmented control, each pressed item is raised on its own. Use the segmented style for switching views and the spaced style for toolbars.

</Only>

## Usage

<Only platform="rn">

```tsx
import { TextBIcon, TextItalicIcon, TextUnderlineIcon } from "phosphor-react-native"
import * as React from "react"
import { ToggleGroup, ToggleGroupIcon, ToggleGroupItem } from "@/components/ui/toggle-group"

type GroupProps = Omit<
  React.ComponentProps<typeof ToggleGroup>,
  "value" | "onValueChange" | "children"
>

function FormattingDemo({
  initial = ["bold"],
  ...props
}: GroupProps & { initial?: string[] }) {
  const [value, setValue] = React.useState<string[]>(initial)
  return (
    <ToggleGroup multiple value={value} onValueChange={setValue} {...props}>
      <ToggleGroupItem value="bold" accessibilityLabel="Toggle bold">
        <ToggleGroupIcon as={TextBIcon} />
      </ToggleGroupItem>
      <ToggleGroupItem value="italic" accessibilityLabel="Toggle italic">
        <ToggleGroupIcon as={TextItalicIcon} />
      </ToggleGroupItem>
      <ToggleGroupItem value="underline" accessibilityLabel="Toggle underline">
        <ToggleGroupIcon as={TextUnderlineIcon} />
      </ToggleGroupItem>
    </ToggleGroup>
  )
}

export function ToggleGroupExample() {
  return (
    <FormattingDemo />
  )
}
```

```kotlin
@Composable
fun ToggleGroupFormatting(
    variant: ToggleVariant = ToggleVariant.Default,
    size: ToggleSize = ToggleSize.Default,
    spacing: Int = 2,
    orientation: Orientation = Orientation.Horizontal,
    enabled: Boolean = true,
    initial: Set<String> = setOf("bold"),
) {
    var values by rememberSaveable { mutableStateOf(initial.toList()) }
    ToggleGroup(
        values = values.toSet(),
        onValuesChange = { values = it.toList() },
        variant = variant,
        size = size,
        spacing = spacing,
        orientation = orientation,
        enabled = enabled,
    ) {
        ToggleGroupIconItem("bold", "Toggle bold", PhosphorIcons.Regular.TextB)
        ToggleGroupIconItem("italic", "Toggle italic", PhosphorIcons.Regular.TextItalic)
        ToggleGroupIconItem("underline", "Toggle underline", PhosphorIcons.Regular.TextUnderline)
    }
```

## Accessibility

- A single-selection group has the `radiogroup` role and its items have the `radio` role.
- A `multiple` group has the `group` role and its items have the `togglebutton` role.
- Items report checked and disabled states to VoiceOver and TalkBack.
- The sliding segmented indicator is hidden from VoiceOver and TalkBack.
- Icon-only items need an `accessibilityLabel`; label the group itself with `accessibilityLabel` when its purpose is not clear from context.

## Notes

- Pressed items use `bg-accent` and `text-primary`; the segmented indicator and pressed segmented items use `bg-card` with a small shadow in light mode and `bg-border` in dark mode.
- The indicator slides over 300 ms and respects the system reduce motion setting. It is hidden when the selected item is disabled.
- Colors follow the system appearance.
