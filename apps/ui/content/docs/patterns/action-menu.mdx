`ActionMenu` renders a `DropdownMenu` on desktop and an `AlertSheet` below the `48rem` breakpoint (`useIsMobile`). Each part switches to its matching component: items become `DropdownMenuItem`s or `AlertSheetAction`s, and the label becomes a menu label or the sheet title. On mobile, the content wraps the items in a grouped card and appends a Cancel button.

Use it for a short set of actions on a single object, such as editing, sharing or deleting a record, where an iOS-style action sheet suits touch screens.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/action-menu
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add patterns action-menu
```

### Manual

1. Add the pieces it builds on: [Alert Sheet](/docs/components/alert-sheet), [Dropdown Menu](/docs/components/dropdown-menu), `use-mobile`.

2. Copy the source into `components/patterns/action-menu.tsx`:

<ComponentSource path="components/patterns/action-menu.tsx" />

3. Update the import paths to match your project.

## Usage

```tsx
import { ActionMenu, ActionMenuTrigger, ActionMenuContent, ActionMenuLabel, ActionMenuItem, ActionMenuSeparator } from "@/components/patterns/action-menu"
```

<OnlyBase base="base radix">

```tsx
<div className="flex min-h-svh items-center justify-center">
  <ActionMenu>
    <ActionMenuTrigger render={<Button variant="outline" />}>
      Order actions
    </ActionMenuTrigger>
    <ActionMenuContent>
      <ActionMenuLabel>Order #1042</ActionMenuLabel>
      <ActionMenuItem>Edit</ActionMenuItem>
      <ActionMenuItem>Duplicate</ActionMenuItem>
      <ActionMenuItem>Share</ActionMenuItem>
      <ActionMenuSeparator />
      <ActionMenuItem variant="destructive">Delete</ActionMenuItem>
    </ActionMenuContent>
  </ActionMenu>
</div>
```

</OnlyBase>

<OnlyBase base="aria">

```tsx
<div className="flex min-h-svh items-center justify-center">
  <ActionMenu>
    <Button variant="outline">Order actions</Button>
    <ActionMenuContent>
      <ActionMenuLabel>Order #1042</ActionMenuLabel>
      <ActionMenuItem>Edit</ActionMenuItem>
      <ActionMenuItem>Duplicate</ActionMenuItem>
      <ActionMenuItem>Share</ActionMenuItem>
      <ActionMenuSeparator />
      <ActionMenuItem variant="destructive">Delete</ActionMenuItem>
    </ActionMenuContent>
  </ActionMenu>
</div>
```

</OnlyBase>

Pass `render` to `ActionMenuTrigger` to use your own button, for example a `Button` with `variant="outline"`. `open`, `defaultOpen` and `onOpenChange` work on both layouts, so the menu can be controlled or uncontrolled. `align`, `alignOffset`, `side` and `sideOffset` on `ActionMenuContent` position the desktop popup and are ignored on mobile.

<ApiPart index={1}>

### ActionMenu

The root that renders a `DropdownMenu` on desktop and an `AlertSheet` on mobile.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onOpenChange` | `(open: boolean) => void` | - | Called when the menu or sheet opens or closes. |
| `dismissible` | `boolean` | `true` | When `true`, the mobile sheet closes on an outside press; when `false`, it uses an alert dialog that closes only through an action or Cancel. |

Also accepts the props of `React.ComponentProps<typeof DropdownMenu>`.

</ApiPart>

<ApiPart index={2}>

### ActionMenuTrigger

The button that opens the menu or sheet.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `render` | `React.ReactElement` | - | Replaces the default button element with your own element, such as a `Button`. |

Also accepts the props of `React.ButtonHTMLAttributes<HTMLButtonElement>`.

</ApiPart>

<ApiPart index={3}>

### ActionMenuContent

The popup holding the actions; on mobile it adds a Cancel button below them.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `cancelLabel` | `string` | `"Cancel"` | Text of the Cancel button shown below the actions on mobile. |

Also accepts the props of `React.HTMLAttributes<HTMLElement>`, `React.ComponentProps<typeof DropdownMenuContent>`.

</ApiPart>

<ApiPart index={4}>

### ActionMenuLabel

A non-interactive heading; a menu label on desktop and the sheet title on mobile.

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</ApiPart>

<ApiPart index={5}>

### ActionMenuItem

An actionable entry that closes the menu when chosen.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "destructive"` | - | Use `destructive` to style the item as a destructive action. |
| `disabled` | `boolean` | - | Prevents the item from being chosen. |

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

<OnlyBase base="aria">

On the `aria` base, respond to the item with `onAction`.

</OnlyBase>

</ApiPart>

<ApiPart index={6}>

### ActionMenuSeparator

A divider between groups of items, rendered on desktop only.

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</ApiPart>

## Accessibility

- On desktop the popup has the `menu` role and each item has the `menuitem` role.
- `ArrowDown` from the trigger opens the menu and focuses the first item; arrow keys move between items and `Enter` runs the focused one.
- `Escape` closes the menu and returns focus to the trigger.

## Notes

Parts carry `data-slot` values `action-menu`, `action-menu-trigger`, `action-menu-content`, `action-menu-label`, `action-menu-item` and `action-menu-separator`. `ActionMenuSeparator` renders nothing on mobile; the sheet groups items in a single card instead.
