`ActionMenu` renders a `DropdownMenu` on desktop and an `AlertSheet` below the `48rem` breakpoint (`useIsMobile`). Each part switches to its matching component: items become `DropdownMenuItem`s or `AlertSheetAction`s, and the label becomes a menu label or the sheet title.

Use it for a short set of actions on a single object, such as editing, sharing or deleting a record, where an action sheet suits touch screens.

## Usage

```tsx
import {
  ActionMenu,
  ActionMenuContent,
  ActionMenuItem,
  ActionMenuLabel,
  ActionMenuSeparator,
  ActionMenuTrigger,
} from "@/components/patterns/action-menu"
import { Button } from "@/components/ui/button"
```

<OnlyBase base="base">

```tsx
<div className="flex min-h-svh items-center justify-center">
  <ActionMenu>
    <ActionMenuTrigger render={<Button variant="outline" />}>
      Order actions
    </ActionMenuTrigger>
    <ActionMenuContent>
      <ActionMenuLabel>Order #1042</ActionMenuLabel>
      <ActionMenuItem>Edit</ActionMenuItem>
      <ActionMenuItem>Duplicate</ActionMenuItem>
      <ActionMenuItem>Share</ActionMenuItem>
      <ActionMenuSeparator />
      <ActionMenuItem variant="destructive">Delete</ActionMenuItem>
    </ActionMenuContent>
  </ActionMenu>
</div>
```

## Composition

Use the following composition to build a `ActionMenu`:

```text
ActionMenu
├── ActionMenuTrigger
└── ActionMenuContent
    ├── ActionMenuLabel
    ├── ActionMenuItem
    └── ActionMenuSeparator
```

## Accessibility

- On desktop the popup has the `menu` role and each item has the `menuitem` role.
- `ArrowDown` from the trigger opens the menu and focuses the first item; arrow keys move between items and `Enter` runs the focused one.
- `Escape` closes the menu and returns focus to the trigger.

## API Reference

### ActionMenu

The root that renders a `DropdownMenu` on desktop and an `AlertSheet` on mobile.

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | - |
| `onOpenChange` | `(open: boolean) => void` | - |
| `dismissible` | `boolean` | `true` |
| `children` | `React.ReactNode` | - |

`open`, `defaultOpen` and `onOpenChange` work on both layouts, so the menu can be controlled or uncontrolled.

### ActionMenuTrigger

The button that opens the menu or sheet.

<OnlyBase base="base">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `React.ReactElement` | - |

Also accepts the props of `DropdownMenuTrigger`.

Use `render` to replace the default button with your own element, for example a `Button` with `variant="outline"`.

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |

Also accepts the props of `DropdownMenuTrigger`.

Set `asChild` to render your own button in place of the default one, for example a `Button` with `variant="outline"`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts the props of `DropdownMenuTrigger`.

You can also leave it out and place your own `Button` directly inside `ActionMenu` to open it.

</OnlyBase>

### ActionMenuContent

The popup holding the actions; on mobile it adds a Cancel button below them.

| Prop | Type | Default |
| --- | --- | --- |
| `cancelLabel` | `string` | `"Cancel"` |

<OnlyBase base="base radix">

Also accepts `align`, `alignOffset`, `side` and `sideOffset` from `DropdownMenuContent`, which position the desktop popup, and the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `placement`, `offset` and `crossOffset` from `DropdownMenuContent`, which position the desktop popup, and `className`, `children`, `id` and `aria-label`.

</OnlyBase>

The positioning props are ignored on mobile, where the content wraps the items in a grouped card and appends a Cancel button labelled by `cancelLabel`.

### ActionMenuLabel

A non-interactive heading; a menu label on desktop and the sheet title on mobile.

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children` and `id`.

</OnlyBase>

### ActionMenuItem

An actionable entry that closes the menu when chosen.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "destructive"` | - |
| `disabled` | `boolean` | - |

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Respond to the item with `onAction`. Also accepts `className`, `children`, `id` and `aria-label`.

</OnlyBase>

### ActionMenuSeparator

A divider between groups of items, rendered on desktop only.

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`.

</OnlyBase>

`ActionMenuSeparator` renders nothing on mobile; the sheet groups items in a single card instead. Each part sets a `data-slot`, such as `action-menu-content` or `action-menu-item`, for styling.

</Only>
