`Preview` reveals extra information about a link, such as a profile or page summary, without navigating. On desktop it renders a suiss/ui `HoverCard` that opens when the trigger is hovered or focused. On mobile (below `48rem`, via `useIsMobile`), where hover is not available, it renders a `Drawer` with a swipe handle that opens when the trigger is tapped. The drawer floats inset from the screen edges by default.

Use it for supplementary content that people can skip. Keep essential information and actions out of the preview, because the hover card opens only on hover or focus.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/preview
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add patterns preview
```

### Manual

1. Add the [`cn` helper](/docs/installation#the-cn-helper).

2. Add the pieces it builds on: [Drawer](/docs/components/drawer), [Hover Card](/docs/components/hover-card), `use-mobile`.

3. Copy the source into `components/patterns/preview.tsx`:

<ComponentSource path="components/patterns/preview.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { Preview, PreviewTrigger, PreviewContent } from "@/components/patterns/preview"
```

```tsx
<div className="flex min-h-svh items-center justify-center p-4">
  <Preview>
    <PreviewTrigger href="#">@nextjs</PreviewTrigger>
    <PreviewContent>
      <ProfileCard />
    </PreviewContent>
  </Preview>
</div>
```

- Place `PreviewTrigger` and `PreviewContent` inside `Preview`. The parts throw when used outside it.
- Open state is uncontrolled by default; use `defaultOpen`, or `open` with `onOpenChange` to control it.
- On desktop the trigger is a link that uses `href`; on mobile it is a button that opens the drawer, so the link target is not followed.
- `align`, `alignOffset`, `side` and `sideOffset` position the desktop card. `showCloseButton` and `closeLabel` apply only to the mobile drawer.

### Preview

The root that chooses HoverCard or Drawer and holds the open state.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onOpenChange` | `(open: boolean) => void` | - | Called with the new open state when the preview opens or closes. |
| `floating` | `boolean` | `true` | Insets the mobile drawer from the screen edges. Has no effect on desktop. |

Also accepts the props of `React.ComponentProps<typeof HoverCard>`.

</ApiPart>

<ApiPart index={2}>

### PreviewTrigger

The link-styled element that opens the preview.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `href` | `string` | - | The link destination on desktop. Ignored on mobile. |

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</ApiPart>

<ApiPart index={3}>

### PreviewContent

The card or drawer that holds the preview.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `showCloseButton` | `boolean` | - | Shows a close button in the mobile drawer. |
| `closeLabel` | `string` | - | Text for the mobile close button in place of the icon. |

Also accepts the props of `React.HTMLAttributes<HTMLElement>`, `React.ComponentProps<typeof HoverCardContent>`.

</ApiPart>

## Accessibility

- On desktop the trigger is a link; the card opens on hover and on keyboard focus, and closes when the pointer leaves.
- On mobile the trigger is a button that opens the drawer.
- The trigger shows a focus ring when focused with the keyboard.

## Notes

Styling hooks: `data-slot="preview"`, `preview-trigger` and `preview-content`. On mobile, `className` on `PreviewContent` applies to an inner padded wrapper, which adds end padding to clear the close button when it is shown.

## Usage

```tsx
import { Preview, PreviewTrigger, PreviewContent } from "@/components/patterns/preview"
```

```tsx
<PreviewDemo defaultOpen />
```

Put a `PreviewTrigger` and a `PreviewContent` inside `Preview`. A string or number child of the trigger is wrapped in `Text`.

The preview can be uncontrolled or controlled with `open`, `defaultOpen` and `onOpenChange`. `PreviewContent` pads its children and adds end padding when a close button is shown, so content does not sit under it.
