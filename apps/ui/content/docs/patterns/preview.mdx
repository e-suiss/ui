`Preview` reveals extra information about a link, such as a profile or page summary, without navigating. On desktop it renders a suiss/ui `HoverCard` that opens when the trigger is hovered or focused. On mobile (below `48rem`, via `useIsMobile`), where hover is not available, it renders a `Drawer` with a swipe handle that opens when the trigger is tapped. The drawer floats inset from the screen edges by default.

Use it for supplementary content that people can skip. Keep essential information and actions out of the preview, because the hover card opens only on hover or focus.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/preview
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add patterns preview
```

### Manual

1. Add the [`cn` helper](/docs/installation#the-cn-helper).

2. Add the pieces it builds on: [Drawer](/docs/components/drawer), [Hover Card](/docs/components/hover-card), `use-mobile`.

3. Copy the source into `components/patterns/preview.tsx`:

<ComponentSource path="components/patterns/preview.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { Preview, PreviewTrigger, PreviewContent } from "@/components/patterns/preview"
```

```tsx
<div className="flex min-h-svh items-center justify-center p-4">
  <Preview>
    <PreviewTrigger href="#">@nextjs</PreviewTrigger>
    <PreviewContent>
      <p className="text-sm">
        The React framework, created and maintained by @vercel.
      </p>
    </PreviewContent>
  </Preview>
</div>
```

- Place `PreviewTrigger` and `PreviewContent` inside `Preview`. The parts throw when used outside it.
- Open state is uncontrolled by default; use `defaultOpen`, or `open` with `onOpenChange` to control it.
- On desktop the trigger is a link that uses `href`; on mobile it is a button that opens the drawer, so the link target is not followed.
- `align`, `alignOffset`, `side` and `sideOffset` position the desktop card. `showCloseButton` and `closeLabel` apply only to the mobile drawer.

<ApiPart index={1}>

### Preview

The root that chooses HoverCard or Drawer and holds the open state.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | - | Whether the preview is open, for controlled use. |
| `defaultOpen` | `boolean` | - | Whether the preview starts open when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | - | Called with the new open state when the preview opens or closes. |
| `floating` | `boolean` | `true` | Insets the mobile drawer from the screen edges. Has no effect on desktop. |
| `children` | `React.ReactNode` | - | The trigger and content. |

</ApiPart>

<ApiPart index={2}>

### PreviewTrigger

The link-styled element that opens the preview.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `href` | `string` | - | The link destination on desktop. Ignored on mobile. |

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children`, `id` and `aria-label`.

</OnlyBase>

</ApiPart>

<ApiPart index={3}>

### PreviewContent

The card or drawer that holds the preview.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `showCloseButton` | `boolean` | - | Shows a close button in the mobile drawer. |
| `closeLabel` | `string` | - | Text for the mobile close button in place of the icon. |

<OnlyBase base="base radix">

Also accepts `align`, `alignOffset`, `side` and `sideOffset` from `HoverCardContent`, which position the desktop card, and the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `align`, `alignOffset`, `side` and `sideOffset` from `HoverCardContent`, which position the desktop card, and `className`, `style`, `children`, `id` and `aria-label`.

</OnlyBase>

</ApiPart>

## Accessibility

- On desktop the trigger is a link; the card opens on hover and on keyboard focus, and closes when the pointer leaves.
- On mobile the trigger is a button that opens the drawer.
- The trigger shows a focus ring when focused with the keyboard.

## Notes

Styling hooks: `data-slot="preview"`, `preview-trigger` and `preview-content`. On mobile, `className` on `PreviewContent` applies to an inner padded wrapper, which adds end padding to clear the close button when it is shown.

## Usage

<Only platform="rn">

```tsx
import { CalendarBlankIcon } from "phosphor-react-native"
import { View } from "react-native"
import { Preview, PreviewContent, PreviewTrigger } from "@/components/patterns/preview"
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
import { Icon } from "@/components/ui/icon"
import { Text } from "@/components/ui/text"

function ProfileCard() {
  return (
    <View className="flex-row gap-4">
      <Avatar size="lg">
        <AvatarImage
          alt="Ada Lovelace"
          source={{ uri: "https://i.pravatar.cc/150?img=5" }}
        />
        <AvatarFallback>AL</AvatarFallback>
      </Avatar>
      <View className="flex-1 gap-1">
        <Text className="text-sm font-semibold">@ada</Text>
        <Text className="text-sm">
          Mathematician and writer, known for her work on the Analytical Engine.
        </Text>
        <View className="mt-1 flex-row items-center gap-1.5">
          <Icon
            as={CalendarBlankIcon}
            className="size-4 text-muted-foreground"
          />
          <Text className="text-xs text-muted-foreground">
            Joined December 2021
          </Text>
        </View>
      </View>
    </View>
  )
}

function PreviewDemo({
  defaultOpen,
  floating,
  showCloseButton,
  closeLabel,
}: {
  defaultOpen?: boolean
  floating?: boolean
  showCloseButton?: boolean
  closeLabel?: string
}) {
  return (
    <View className="flex-1 items-center justify-center">
      <Preview defaultOpen={defaultOpen} floating={floating}>
        <PreviewTrigger>@ada</PreviewTrigger>
        <PreviewContent
          showCloseButton={showCloseButton}
          closeLabel={closeLabel}
          accessibilityLabel="@ada"
        >
          <ProfileCard />
        </PreviewContent>
      </Preview>
    </View>
  )
}

export function PreviewExample() {
  return (
    <PreviewDemo />
  )
}
```

```swift
import EsuissUI
import PhosphorSwift
import SwiftUI

struct PreviewDemo: View {
  var showCloseButton = false
  var closeLabel: LocalizedStringKey?

  @State private var open: Bool

  init(open: Bool = false, showCloseButton: Bool = false, closeLabel: LocalizedStringKey? = nil) {
    _open = State(initialValue: open)
    self.showCloseButton = showCloseButton
    self.closeLabel = closeLabel
  }

  var body: some View {
    Button {
      open = true
    } label: {
      Text(verbatim: "@ada")
        .textStyle(.base)
        .foregroundStyle(EsuissColor.primary)
    }
    .buttonStyle(PreviewTriggerStyle())
    .preview(isPresented: $open) {
      PreviewContent(showCloseButton: showCloseButton, closeLabel: closeLabel) {
        PreviewProfileCard()
      }
      .accessibilityLabel(Text(verbatim: "@ada"))
    }
    .frame(maxWidth: .infinity)
  }
}

struct PreviewTriggerStyle: ButtonStyle {
  func makeBody(configuration: Configuration) -> some View {
    configuration.label
      .opacity(configuration.isPressed ? 0.8 : 1)
  }
}

struct PreviewProfileCard: View {
  var body: some View {
    HStack(alignment: .top, spacing: 16) {
      Avatar(url: URL(string: "https://i.pravatar.cc/150?img=5"), initials: "AL", size: .lg)
        .accessibilityLabel(Text(verbatim: "Ada Lovelace"))
      VStack(alignment: .leading, spacing: 4) {
        Text(verbatim: "@ada")
          .textStyle(.sm, weight: .semibold)
          .foregroundStyle(EsuissColor.foreground)
        Text("Mathematician and writer, known for her work on the Analytical Engine.")
          .textStyle(.sm)
          .foregroundStyle(EsuissColor.foreground)
          .fixedSize(horizontal: false, vertical: true)
        HStack(spacing: 6) {
          Ph.calendarBlank.regular
            .frame(width: 16, height: 16)
          Text("Joined December 2021")
            .textStyle(.xs)
        }
        .foregroundStyle(EsuissColor.mutedForeground)
        .padding(.top, 4)
      }
      .frame(maxWidth: .infinity, alignment: .leading)
    }
  }
}
```

```kotlin
fun PreviewProfileCard() {
    val colors = EsuissTheme.colors
    Row(horizontalArrangement = Arrangement.spacedBy(16.dp)) {

            AvatarFallback("AL")

                style = Typography.sm,
            )
            Row(
                modifier = Modifier.padding(top = 4.dp),
                horizontalArrangement = Arrangement.spacedBy(6.dp),
                verticalAlignment = Alignment.CenterVertically,
            ) {
                Icon(PhosphorIcons.Regular.CalendarBlank, contentDescription = null, size = 16.dp, tint = colors.mutedForeground)
                Text("Joined December 2021", style = Typography.xs.copy(color = colors.mutedForeground))
            }
        }
    }
}

@Composable
fun PreviewDemo(
    defaultOpen: Boolean = false,
    floating: Boolean = true,
    showCloseButton: Boolean = false,
    closeLabel: String? = null,
) {
    var open by rememberSaveable { mutableStateOf(defaultOpen) }
    Box(Modifier.fillMaxWidth(), contentAlignment = Alignment.Center) {
        Preview(open = open, onOpenChange = { open = it }, floating = floating) {
            PreviewTrigger("@ada")
            PreviewContent(
                modifier = Modifier.semantics { contentDescription = "@ada" },
                showCloseButton = showCloseButton,
                closeLabel = closeLabel,
            ) {
                PreviewProfileCard()
            }
        }
    }
}
```

<Only platform="rn">

Put a `PreviewTrigger` and a `PreviewContent` inside `Preview`. A string or number child of the trigger is wrapped in `Text`.

The preview can be uncontrolled or controlled with `open`, `defaultOpen` and `onOpenChange`. `PreviewContent` pads its children and adds end padding when a close button is shown, so content does not sit under it.

</Only>
