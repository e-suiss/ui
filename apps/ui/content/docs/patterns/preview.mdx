`Preview` reveals extra information about a link, such as a profile or page summary, without navigating. On desktop it renders a suiss/ui `HoverCard` that opens when the trigger is hovered or focused. On mobile (below `48rem`, via `useIsMobile`), where hover is not available, it renders a `Drawer` with a swipe handle that opens when the trigger is tapped. The drawer floats inset from the screen edges by default.

Use it for supplementary content that people can skip. Keep essential information and actions out of the preview, because the hover card opens only on hover or focus.

## Usage

<Code lang="tsx" code={"import { Preview, PreviewTrigger, PreviewContent } from \"@/components/patterns/preview\""} />

<Code lang="tsx" code={"<div className=\"flex min-h-svh items-center justify-center p-4\">\n  <Preview>\n    <PreviewTrigger href=\"#\">@nextjs</PreviewTrigger>\n    <PreviewContent>\n      <ProfileCard />\n    </PreviewContent>\n  </Preview>\n</div>"} />

- Place `PreviewTrigger` and `PreviewContent` inside `Preview`. The parts throw when used outside it.
- Open state is uncontrolled by default; use `defaultOpen`, or `open` with `onOpenChange` to control it.
- On desktop the trigger is a link that uses `href`; on mobile it is a button that opens the drawer, so the link target is not followed.
- `align`, `alignOffset`, `side` and `sideOffset` position the desktop card. `showCloseButton` and `closeLabel` apply only to the mobile drawer.

## Accessibility

- On desktop the trigger is a link; the card opens on hover and on keyboard focus, and closes when the pointer leaves.
- On mobile the trigger is a button that opens the drawer.
- The trigger shows a focus ring when focused with the keyboard.

## Notes

Styling hooks: `data-slot="preview"`, `preview-trigger` and `preview-content`. On mobile, `className` on `PreviewContent` applies to an inner padded wrapper, which adds end padding to clear the close button when it is shown.

Put a `PreviewTrigger` and a `PreviewContent` inside `Preview`. A string or number child of the trigger is wrapped in `Text`.

The preview can be uncontrolled or controlled with `open`, `defaultOpen` and `onOpenChange`. `PreviewContent` pads its children and adds end padding when a close button is shown, so content does not sit under it.
