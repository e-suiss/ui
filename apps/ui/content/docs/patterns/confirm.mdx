`Confirm` asks the user to confirm or cancel an action. On desktop it renders an `AlertDialog` with a header and a footer of buttons. Below the `48rem` breakpoint it renders an `AlertSheet`: `ConfirmContent` lifts the buttons out of `ConfirmFooter`, places the title, description and actions in one grouped card, and moves `ConfirmCancel` into its own button below the card.

Use it before destructive or irreversible actions, such as deleting a record, where the user must make an explicit choice.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/confirm
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add patterns confirm
```

### Manual

1. Add the pieces it builds on: [Alert Dialog](/docs/components/alert-dialog), [Alert Sheet](/docs/components/alert-sheet), `use-mobile`.

2. Copy the source into `components/patterns/confirm.tsx`:

<ComponentSource path="components/patterns/confirm.tsx" />

3. Update the import paths to match your project.

Write the content once with the desktop structure: `ConfirmHeader` holding `ConfirmTitle` and `ConfirmDescription`, then `ConfirmFooter` holding `ConfirmCancel` and `ConfirmAction`. Keep `ConfirmCancel` and `ConfirmAction` as direct children of `ConfirmFooter` so the mobile layout can find them. The mobile sheet is not dismissible by default; pass `dismissible` to let an outside press close it.

<OnlyBase base="base radix">

## Accessibility

- The popup has the `alertdialog` role, named by `ConfirmTitle` and described by `ConfirmDescription`. On mobile with `dismissible` set, it has the `dialog` role instead.
- Opening moves focus into the dialog, and closing returns it to the trigger.
- On desktop, pressing outside does not close the dialog; `Escape`, Cancel or an action does.

## Notes

Parts carry `data-slot` values from `confirm` through `confirm-cancel`. Pass `variant="destructive"` to `ConfirmAction` for destructive actions. The `size` prop of `ConfirmContent` applies to the desktop `AlertDialogContent` only.

import com.esuiss.ui.patterns.ConfirmAction

    ConfirmDemo(defaultOpen = false)

@Composable
fun ConfirmDemo(defaultOpen: Boolean) {
    var open by rememberSaveable { mutableStateOf(defaultOpen) }
    Column {
        Button("Delete account", onClick = { open = true }, variant = ButtonVariant.Destructive)
        Confirm(open = open, onOpenChange = { open = it }) {
            ConfirmHeader {
                ConfirmTitle("Delete your account?")
                ConfirmDescription("This permanently deletes your account and all of its data.")
            }
            ConfirmFooter {
                ConfirmCancel("Cancel")
                ConfirmAction("Delete Account", onClick = {}, variant = AlertSheetActionVariant.Destructive)
            }
        }
    }
}
