`Confirm` asks the user to confirm or cancel an action. On desktop it renders an `AlertDialog` with a header and a footer of buttons. Below the `48rem` breakpoint it renders an `AlertSheet`, with the title, description and actions in one grouped card and Cancel in its own button below it.

Use it before destructive or irreversible actions, such as deleting a record, where the user must make an explicit choice.

Use the following composition to build a `Confirm`:

```text
Confirm
├── ConfirmTrigger
└── ConfirmContent
    ├── ConfirmHeader
    │   ├── ConfirmTitle
    │   └── ConfirmDescription
    └── ConfirmFooter
        ├── ConfirmCancel
        └── ConfirmAction
```

## Accessibility

- The popup has the `alertdialog` role, named by `ConfirmTitle` and described by `ConfirmDescription`. On mobile with `dismissible` set, it has the `dialog` role instead.
- Opening moves focus into the dialog, and closing returns it to the trigger.
- On desktop, pressing outside does not close the dialog; `Escape`, Cancel or an action does.

## API Reference

### Confirm

The root that renders an `AlertDialog` on desktop and an `AlertSheet` on mobile.

| Prop | Type | Default |
| --- | --- | --- |
| `dismissible` | `boolean` | `false` |

Also accepts the props of `React.ComponentProps<typeof AlertSheet>`.

The mobile sheet is not dismissible by default; set `dismissible` to let an outside press close it.

<OnlyBase base="base radix">

`Confirm` accepts `open`, `defaultOpen` and `onOpenChange` for controlled or uncontrolled use.

</OnlyBase>

<OnlyBase base="aria">

`Confirm` accepts `isOpen`, `defaultOpen` and `onOpenChange` for controlled or uncontrolled use. A `Button` placed inside `Confirm` opens it.

</OnlyBase>

### ConfirmTrigger

The button that opens the confirmation.

Also accepts the props of `React.ComponentProps<typeof AlertDialogTrigger>`.

### ConfirmContent

The popup; on mobile it regroups the footer buttons into the sheet layout.

Also accepts the props of `React.ComponentProps<typeof AlertDialogContent>`.

Write the content once with the desktop structure: `ConfirmHeader` holding `ConfirmTitle` and `ConfirmDescription`, then `ConfirmFooter` holding `ConfirmCancel` and `ConfirmAction`. On mobile, `ConfirmContent` lifts the buttons out of `ConfirmFooter`. The `size` prop applies to the desktop `AlertDialogContent` only.

### ConfirmHeader

Groups the title and description.

Also accepts the props of `React.ComponentProps<"div">`.

### ConfirmFooter

Holds the cancel and action buttons on desktop; on mobile its buttons are moved into the sheet.

Also accepts the props of `React.ComponentProps<"div">`.

Keep `ConfirmCancel` and `ConfirmAction` as direct children of `ConfirmFooter` so the mobile layout can find them.

### ConfirmTitle

The prompt's title, used as the dialog's accessible name.

Also accepts the props of `React.ComponentProps<typeof AlertDialogTitle>`.

### ConfirmDescription

Supporting text, used as the dialog's accessible description.

Also accepts the props of `React.ComponentProps<typeof AlertDialogDescription>`.

### ConfirmAction

A button that performs the action and closes the prompt.

Also accepts the props of `React.ComponentProps<typeof AlertSheetAction>`.

Pass `variant="destructive"` for destructive actions.

### ConfirmCancel

A button that closes the prompt without acting; shown separately below the actions on mobile.

Also accepts the props of `React.ComponentProps<typeof AlertSheetCancel>`.

Each part sets a `data-slot`, such as `confirm-content` or `confirm-cancel`, for styling.

fun ConfirmDemo(defaultOpen: Boolean) {
    var open by rememberSaveable { mutableStateOf(defaultOpen) }
    Column {
        Button("Delete account", onClick = { open = true }, variant = ButtonVariant.Destructive)

                ConfirmTitle("Delete your account?")
                ConfirmDescription("This permanently deletes your account and all of its data.")
            }
            ConfirmFooter {
                ConfirmCancel("Cancel")
                ConfirmAction("Delete Account", onClick = {}, variant = AlertSheetActionVariant.Destructive)
            }
        }
    }

<Only platform="rn">

### Confirm

The sheet that groups the header and actions and places Cancel below.

Also accepts the props of `React.ComponentProps<typeof AlertSheetContent>`.

Put `ConfirmTitle` and `ConfirmDescription` in a `ConfirmHeader`, and the buttons in a `ConfirmFooter` inside `ConfirmContent`. Any `ConfirmAction` goes into the group; `ConfirmCancel` is moved out of it. On iOS the sheet renders in a full-window overlay so it appears above native screens.

### ConfirmHeader

Holds the title and description.

Also accepts the props of `React.ComponentProps<typeof AlertSheetHeader>`.

### ConfirmFooter

Holds the action and cancel buttons.

Also accepts the props of `ViewProps`.

### ConfirmTitle

The question being asked.

Also accepts the props of `React.ComponentProps<typeof AlertSheetTitle>`.

### ConfirmDescription

Supporting text about the consequences.

Also accepts the props of `React.ComponentProps<typeof AlertSheetDescription>`.

### ConfirmAction

A confirming action, rendered as an `AlertSheetAction`.

Also accepts the props of `React.ComponentProps<typeof AlertSheetAction>`.

Set `variant="destructive"` for delete-style actions.

### ConfirmCancel

The cancel button, shown separately below the group.

Also accepts the props of `React.ComponentProps<typeof AlertSheetCancel>`.
