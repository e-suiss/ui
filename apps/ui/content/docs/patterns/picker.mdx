`Picker` lets the user choose one option from a short list. On desktop it renders a suiss/ui `Select`. On mobile (below `48rem`, via `useIsMobile`) it renders a `NativeSelect`, so the platform's own picker wheel or sheet appears. The same `PickerItem` markup drives both presentations.

Use it for form fields where the options are known and do not need search; for long lists, use `SearchPicker`.

```tsx

```

```tsx

```

## Composition

Use the following composition to build a `Picker`:

```text
Picker
├── PickerGroup
│   └── PickerItem
└── PickerSeparator
```

## Accessibility

- The desktop trigger has the `combobox` role and opens a `listbox`; the selected option has `aria-selected`, and disabled options have `aria-disabled`.
- Labelled groups are exposed as `group` elements named by their label.
- Escape closes the desktop list without changing the value.
- On mobile the control is a native `select`, with the platform's built-in keyboard and screen reader support.

## API Reference

### Picker

The root that renders the Select or native select and holds the value.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | - |
| `defaultValue` | `string` | - |
| `onValueChange` | `(value: string) => void` | - |
| `placeholder` | `string` | - |
| `items` | `PickerItemData[]` | - |
| `size` | `"sm" \| "default"` | `"default"` |
| `id` | `string` | - |
| `name` | `string` | - |
| `disabled` | `boolean` | - |
| `required` | `boolean` | - |
| `className` | `string` | - |
| `children` | `React.ReactNode` | - |
| `aria-invalid` | `boolean` | - |
| `aria-label` | `string` | - |
| `aria-describedby` | `string` | - |

The value is uncontrolled by default; use `defaultValue`, or `value` with `onValueChange` to control it. On mobile, `placeholder` is a disabled first option. `id` and `className` go to the trigger on desktop and to the native select on mobile. Give the picker an accessible name with `aria-label` or a `Label` that points at its `id`.

`Picker` collects the value and label of each `PickerItem` from its children so the desktop trigger can show the selected label. Pass `items` only when options are not rendered as direct or nested `PickerItem` elements. `PickerGroup`, `PickerItem` and `PickerSeparator` must be used inside `Picker`, or they throw. Each part sets a `data-slot`, such as `picker` or `picker-item`, for styling.

### PickerGroup

Groups related options under an optional label.

| Prop | Type | Default |
| --- | --- | --- |
| `label` | `string` | - |
| `children` | `React.ReactNode` | - |

### PickerItem

A selectable option.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | Required |
| `disabled` | `boolean` | - |
| `children` | `React.ReactNode` | - |

## Usage

<Only platform="rn">

<OnlyStyling styling="uniwind nativewind">

```tsx
import * as React from "react"
import { View } from "react-native"
import { Picker, PickerGroup, PickerItem, PickerSeparator } from "@/components/patterns/picker"
import { Text } from "@/components/ui/text"

function PickerDemo() {
  const [value, setValue] = React.useState<string>()
  return (
    <View className="gap-2">
      <Picker
        value={value}
        onValueChange={setValue}
        placeholder="Select a fruit"
        accessibilityLabel="Fruit"
        className="w-56"
      >
        <PickerGroup label="Fruits">
          <PickerItem value="cherry">Cherry</PickerItem>
          <PickerItem value="banana">Banana</PickerItem>
          <PickerItem value="mango">Mango</PickerItem>
        </PickerGroup>
        <PickerSeparator />
        <PickerGroup label="Vegetables">
          <PickerItem value="carrot">Carrot</PickerItem>
          <PickerItem value="spinach" disabled>
            Spinach
          </PickerItem>
        </PickerGroup>
      </Picker>
      <Text className="text-sm text-muted-foreground">
        Selected: {value ?? "none"}
      </Text>
    </View>
  )
}

export function PickerExample() {
  return (
    <PickerDemo />
  )
}
```

@Composable
fun PickerDefault() {
    var value by rememberSaveable { mutableStateOf<String?>(null) }
    Column(verticalArrangement = Arrangement.spacedBy(8.dp)) {
        Picker(
            value = value,
            onValueChange = { value = it },

            }
            PickerSeparator()
            PickerGroup(label = "Vegetables") {
                PickerItem("carrot", "Carrot")
                PickerItem("spinach", "Spinach", enabled = false)
            }
        }
        Text("Selected: ${value ?: "none"}", style = Typography.sm.copy(color = EsuissTheme.colors.mutedForeground))
    }
}

## API Reference

<Only platform="rn">

### Picker

The root that renders the trigger and the options popup.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | - |
| `defaultValue` | `string` | - |
| `onValueChange` | `(value: string) => void` | - |
| `placeholder` | `string` | - |
| `items` | `PickerItemData[]` | - |
| `size` | `"sm" \| "default"` | `"default"` |
| `disabled` | `boolean` | - |
| `invalid` | `boolean` | - |
| `className` | `string` | - |
| `accessibilityLabel` | `string` | - |
| `accessibilityLabelledBy` | `string` | - |
| `children` | `React.ReactNode` | - |

Use it uncontrolled with `defaultValue`, or controlled with `value` and `onValueChange`. `placeholder` shows while nothing is selected. List `PickerItem`s as children, optionally inside `PickerGroup`s separated by `PickerSeparator`. The picker collects the items from its children to show the selected label, or you can pass `items` directly as `{ value, label }` pairs.

The popup fades in and out and respects the system reduce motion setting. On iOS it renders in a full-window overlay so it appears above native screens.
