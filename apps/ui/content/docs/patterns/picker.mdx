`Picker` lets the user choose one option from a short list. On desktop it renders a suiss/ui `Select` with a trigger, a popup list, labelled groups and separators. On mobile (below `48rem`, via `useIsMobile`) it renders a `NativeSelect`, so the platform's own picker wheel or sheet appears; groups become `optgroup` elements and separators are omitted.

You describe options once with `PickerItem`, `PickerGroup` and `PickerSeparator`, and the same markup drives both presentations. Use it for form fields where the options are known and do not need search; for long lists, use `SearchPicker`.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/picker
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add patterns picker
```

### Manual

1. Add the pieces it builds on: [Native Select](/docs/components/native-select), [Select](/docs/components/select), `use-mobile`.

2. Copy the source into `components/patterns/picker.tsx`:

3. Update the import paths to match your project.

## Usage

```tsx
import { Picker, PickerGroup, PickerItem, PickerSeparator } from "@/components/patterns/picker"
```

```tsx
<Picker placeholder="Select a fruit" aria-label="Fruit" className="w-48">{fruitItems}</Picker>
```

- The value is uncontrolled by default; use `defaultValue`, or `value` with `onValueChange` to control it.
- `Picker` collects the value and label of each `PickerItem` from its children so the desktop trigger can show the selected label. Pass `items` only when options are not rendered as direct or nested `PickerItem` elements.
- `PickerGroup`, `PickerItem` and `PickerSeparator` must be used inside `Picker`, or they throw.
- Give the picker an accessible name with `aria-label` or a `Label` that points at its `id`.

### Picker

The root that renders the Select or native select and holds the value.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | The selected value when controlled. |
| `defaultValue` | `string` | - | The initially selected value when uncontrolled. |
| `onValueChange` | `(value: string) => void` | - | Called with the new value when the user picks an option. |
| `placeholder` | `string` | - | Text shown when no value is selected; on mobile it is a disabled first option. |
| `items` | `PickerItemData[]` | - | Value and label pairs used to display the selected label; collected from `PickerItem` children when omitted. |
| `size` | `"sm" \| "default"` | `"default"` | The control height. |
| `id` | `string` | - | The ID of the trigger on desktop or the native select on mobile. |
| `name` | `string` | - | The field name submitted with a form. |
| `disabled` | `boolean` | - | Disables the picker. |
| `required` | `boolean` | - | Marks the field as required for form validation. |
| `className` | `string` | - | Classes applied to the trigger on desktop or the native select on mobile. |
| `children` | `React.ReactNode` | - | The `PickerItem`, `PickerGroup` and `PickerSeparator` elements. |
| `aria-invalid` | `boolean` | - | Marks the field as invalid and applies the error style. |
| `aria-label` | `string` | - | The accessible name of the control. |
| `aria-describedby` | `string` | - | The ID of an element that describes the control. |

</ApiPart>

<ApiPart index={2}>

### PickerGroup

Groups related options under an optional label.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | - | The group's heading; becomes the `optgroup` label on mobile. |
| `children` | `React.ReactNode` | - | The options in the group. |

</ApiPart>

<ApiPart index={3}>

### PickerItem

A selectable option.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | The value selected by this option. |
| `disabled` | `boolean` | - | Prevents selecting this option. |
| `children` | `React.ReactNode` | - | The option's label. |

</ApiPart>

## Accessibility

- The desktop trigger has the `combobox` role and opens a `listbox`; the selected option has `aria-selected`, and disabled options have `aria-disabled`.
- Labelled groups are exposed as `group` elements named by their label.
- Escape closes the desktop list without changing the value.
- On mobile the control is a native `select`, with the platform's built-in keyboard and screen reader support.

## Notes

Styling hooks: `data-slot="picker"`, `picker-group`, `picker-item` and `picker-separator`.

## Usage

```tsx
import { Picker, PickerGroup, PickerItem, PickerSeparator } from "@/components/patterns/picker"
```

```tsx
<PickerDemo />
```

List `PickerItem`s as children, optionally inside `PickerGroup`s separated by `PickerSeparator`. The picker collects the items from its children to show the selected label, or you can pass `items` directly.

Use it uncontrolled with `defaultValue`, or controlled with `value` and `onValueChange`. `placeholder` shows while nothing is selected.

## Accessibility

- Give the picker an `accessibilityLabel` or `accessibilityLabelledBy`, since the trigger shows only the value.

## Notes

- The popup uses `bg-card` with a subtle border that is stronger in dark mode.
- The popup fades in and out, and respects the system reduce motion setting.
- On iOS the popup renders in a full-window overlay so it appears above native screens.
