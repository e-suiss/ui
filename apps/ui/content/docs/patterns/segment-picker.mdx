`SegmentPicker` presents a small set of mutually exclusive options, such as a time period or a view mode. On desktop it renders a suiss/ui `ToggleGroup` in which exactly one segment stays pressed. On mobile it renders a `NativeSelect` so the choice fits narrow screens and uses the platform picker.

Use it for two to five short options that change how content is displayed.

## Usage

```tsx
import { SegmentPicker, SegmentPickerItem } from "@/components/patterns/segment-picker"
```

```tsx
<SegmentPicker defaultValue="week" aria-label="Period">{periods}</SegmentPicker>
```

## Composition

Use the following composition to build a `SegmentPicker`:

```text
SegmentPicker
└── SegmentPickerItem
```

## Accessibility

- On desktop the root is a `group` named by `aria-label`, and each segment is a button with `aria-pressed`.
- Disabled segments are disabled buttons and cannot be selected.
- On mobile the control is a native `select`.

## API Reference

### SegmentPicker

The root that renders the toggle group or native select and holds the value.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | - |
| `defaultValue` | `string` | - |
| `onValueChange` | `(value: string) => void` | - |
| `variant` | `"default" \| "outline"` | `"default"` |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` |
| `spacing` | `number` | `0` |
| `id` | `string` | - |
| `name` | `string` | - |
| `disabled` | `boolean` | - |
| `className` | `string` | - |
| `children` | `React.ReactNode` | - |
| `aria-label` | `string` | - |
| `aria-describedby` | `string` | - |

The value is uncontrolled by default; use `defaultValue`, or `value` with `onValueChange` to control it. `variant` and `spacing` apply only on desktop. `id` and `className` go to the group on desktop and to the select on mobile. With `name`, desktop renders a hidden input so the value is submitted with a form.

The picker switches to the native select below `48rem`, via `useIsMobile`. It sets `data-slot="segment-picker"`, and each item sets `data-slot="segment-picker-item"`, for styling.

### SegmentPickerItem

One option, rendered as a toggle on desktop and an `option` on mobile.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | Required |
| `label` | `string` | - |
| `disabled` | `boolean` | - |
| `className` | `string` | - |
| `children` | `React.ReactNode` | - |
| `aria-label` | `string` | - |

On mobile each option shows `label`, then `aria-label`, then string children, then `value`. On desktop, `label` is the segment content when there are no children, and `className` goes to the toggle. `SegmentPickerItem` throws when used outside `SegmentPicker`.
