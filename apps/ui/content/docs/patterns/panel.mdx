`Panel` presents secondary content such as forms, filters or details without leaving the page. On desktop it renders a suiss/ui `Sheet` that slides in from the chosen side. On mobile (below `48rem`, via `useIsMobile`) it switches to a `Drawer` with a swipe handle, and every subcomponent swaps to its Drawer counterpart.

Use it where a desktop layout calls for a side sheet and a phone calls for a bottom sheet.

## Usage

```tsx
import {
  Panel,
  PanelBody,
  PanelClose,
  PanelContent,
  PanelDescription,
  PanelFooter,
  PanelHeader,
  PanelTitle,
  PanelTrigger,
} from "@/components/patterns/panel"
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"
```

<OnlyBase base="base aria">

```tsx
<div className="flex min-h-svh items-center justify-center">
  <Panel>
    <PanelTrigger render={<Button variant="outline" />}>
      Edit profile
    </PanelTrigger>
    <PanelContent>
      <PanelHeader>
        <PanelTitle>Edit profile</PanelTitle>
        <PanelDescription>
          Update your details and save when you are done.
        </PanelDescription>
      </PanelHeader>
      <PanelBody className="grid gap-2">
        <Label htmlFor="panel-name">Name</Label>
        <Input id="panel-name" defaultValue="Jordan Lee" />
      </PanelBody>
      <PanelFooter>
        <Button>Save changes</Button>
        <PanelClose render={<Button variant="secondary" />}>Cancel</PanelClose>
      </PanelFooter>
    </PanelContent>
  </Panel>
</div>
```

</OnlyBase>

## Composition

Use the following composition to build a `Panel`:

```text
Panel
├── PanelTrigger
└── PanelContent
    ├── PanelHeader
    │   ├── PanelTitle
    │   └── PanelDescription
    ├── PanelBody
    └── PanelFooter
        └── PanelClose
```

## Accessibility

- The content is a `dialog` named by `PanelTitle` and described by `PanelDescription`.
- Escape closes the panel and returns focus to the trigger.
- The built-in close button is named Close, or by `closeLabel` when set.

## API Reference

### Panel

The root that chooses Sheet or Drawer and holds the open state.

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | - |
| `onOpenChange` | `(open: boolean) => void` | - |
| `floating` | `boolean` | - |
| `children` | `React.ReactNode` | - |

Open state is uncontrolled by default; use `defaultOpen` for an initial state, or `open` with `onOpenChange` to control it. Compose `PanelTrigger` and `PanelContent` inside `Panel`; all parts must be used inside it, or they throw. The presentation follows the viewport at render time, so a panel open while the viewport crosses `48rem` re-renders in the other presentation.

### PanelTrigger

### PanelContent

The popup surface, with an optional close button.

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"right"` |
| `showCloseButton` | `boolean` | `true` |
| `closeLabel` | `string` | - |

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `style`, `children`, `id` and `aria-label`.

</OnlyBase>

### PanelHeader

Groups the title and description.

Also accepts the props of `React.ComponentProps<"div">`.

### PanelTitle

The panel's heading, which names the dialog.

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLHeadingElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children` and `id`.

</OnlyBase>

### PanelDescription

Supporting text that describes the dialog.

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLParagraphElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children` and `id`.

</OnlyBase>

### PanelBody

The padded main content area.

Also accepts the props of `React.ComponentProps<"div">`.

Put scrollable or form content here. Its padding matches each presentation.

### PanelFooter

Holds the panel's actions.

Also accepts the props of `React.ComponentProps<"div">`.
