`Modal` presents focused content that blocks the rest of the page, such as a form or a share sheet. On desktop it renders a `Dialog`. Below the `48rem` breakpoint it renders a bottom `Drawer` with a swipe handle, and each part switches to its drawer counterpart: the header, title, description and close map to the drawer's parts, `ModalBody` gains padding, and `ModalFooter` stacks its buttons in reverse order so the primary action sits on top.

Use it for tasks that need the user's full attention before returning to the page.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add patterns modal
```

### Manual

1. Add the [`cn` helper](/docs/installation#the-cn-helper).

2. Add the pieces it builds on: [Dialog](/docs/components/dialog), [Drawer](/docs/components/drawer), `use-mobile`.

3. Copy the source into `components/patterns/modal.tsx`:

<ComponentSource path="components/patterns/modal.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { Modal, ModalTrigger, ModalContent, ModalHeader, ModalBody, ModalFooter, ModalTitle, ModalDescription, ModalClose } from "@/components/patterns/modal"
```

```tsx
<div className="flex min-h-svh items-center justify-center">
  <Modal>
    <ModalTrigger render={<Button variant="outline" />}>
      Edit profile
    </ModalTrigger>
    <ModalContent>
      <ModalHeader>
        <ModalTitle>Edit profile</ModalTitle>
        <ModalDescription>
          Update your name and username. Click save when you are done.
        </ModalDescription>
      </ModalHeader>
      <ModalBody className="grid gap-4">
        <div className="grid gap-2">
          <Label htmlFor="modal-name">Name</Label>
          <Input id="modal-name" defaultValue="Ada Lovelace" />
        </div>
        <div className="grid gap-2">
          <Label htmlFor="modal-username">Username</Label>
          <Input id="modal-username" defaultValue="@ada" />
        </div>
      </ModalBody>
      <ModalFooter>
        <ModalClose render={<Button variant="secondary" />}>
          Cancel
        </ModalClose>
        <Button>Save changes</Button>
      </ModalFooter>
    </ModalContent>
  </Modal>
</div>
```

The modal can be controlled with `open` and `onOpenChange` or uncontrolled with `defaultOpen`. Pass `render` to `ModalTrigger` or `ModalClose` to use your own `Button`. `ModalContent` shows a close button by default; set `showCloseButton` to `false` to hide it, or pass `closeLabel` to show text instead of the icon.

### Modal

The root that renders a `Dialog` on desktop and a `Drawer` on mobile.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onOpenChange` | `(open: boolean) => void` | - | Called when the modal opens or closes. |
| `floating` | `boolean` | - | Insets the mobile drawer from the screen edges with fully rounded corners. |

Also accepts the props of `React.ComponentProps<typeof Dialog>`.

</ApiPart>

<ApiPart index={2}>

### ModalTrigger

The button that opens the modal.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - | Classes applied to the trigger. |

Also accepts the props of `React.ComponentProps<typeof DialogTrigger>`.

</ApiPart>

<ApiPart index={3}>

### ModalContent

The popup window, with a close button by default.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - | Classes applied to the dialog or drawer popup. |
| `style` | `React.CSSProperties` | - | Inline styles applied to the dialog or drawer popup. |

Also accepts the props of `React.ComponentProps<typeof DialogContent>`.

</ApiPart>

<ApiPart index={4}>

### ModalHeader

Groups the title and description.

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

<ApiPart index={5}>

### ModalBody

The main content area, padded on mobile.

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

<ApiPart index={6}>

### ModalFooter

Holds the modal's actions; stacked with the primary action on top on mobile.

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

<ApiPart index={7}>

### ModalTitle

The modal's title, used as its accessible name.

Also accepts the props of `React.ComponentProps<typeof DialogTitle>`.

</ApiPart>

<ApiPart index={8}>

### ModalDescription

Supporting text, used as the modal's accessible description.

Also accepts the props of `React.ComponentProps<typeof DialogDescription>`.

</ApiPart>

<ApiPart index={9}>

### ModalClose

A button that closes the modal.

Also accepts the props of `React.ComponentProps<typeof DialogClose>`.

</ApiPart>

## Accessibility

- The popup has the `dialog` role, named by `ModalTitle` and described by `ModalDescription`.
- `Escape` closes the modal and returns focus to the trigger.
- The default close button is labelled Close.

## Notes

Parts carry `data-slot` values from `modal` through `modal-close`. `ModalContent` accepts `className` and `style` as plain values only, because the same props are forwarded to either the dialog or the drawer popup.
