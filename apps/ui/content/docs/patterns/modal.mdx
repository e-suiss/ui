`Modal` presents focused content that blocks the rest of the page, such as a form or a share sheet. On desktop it renders a `Dialog`. Below the `48rem` breakpoint it renders a bottom `Drawer` with a swipe handle, and each part switches to its drawer counterpart.

Use it for tasks that need the user's full attention before returning to the page.

## Usage

```tsx
import {
  Modal,
  ModalBody,
  ModalClose,
  ModalContent,
  ModalDescription,
  ModalFooter,
  ModalHeader,
  ModalTitle,
  ModalTrigger,
} from "@/components/patterns/modal"
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"
```

<OnlyBase base="base aria">

```tsx
<div className="flex min-h-svh items-center justify-center">
  <Modal>
    <ModalTrigger render={<Button variant="outline" />}>
      Edit profile
    </ModalTrigger>
    <ModalContent>
      <ModalHeader>
        <ModalTitle>Edit profile</ModalTitle>
        <ModalDescription>
          Update your name and username. Click save when you are done.
        </ModalDescription>
      </ModalHeader>
      <ModalBody className="grid gap-4">
        <div className="grid gap-2">
          <Label htmlFor="modal-name">Name</Label>
          <Input id="modal-name" defaultValue="Ada Lovelace" />
        </div>
        <div className="grid gap-2">
          <Label htmlFor="modal-username">Username</Label>
          <Input id="modal-username" defaultValue="@ada" />
        </div>
      </ModalBody>
      <ModalFooter>
        <ModalClose render={<Button variant="secondary" />}>
          Cancel
        </ModalClose>
        <Button>Save changes</Button>
      </ModalFooter>
    </ModalContent>
  </Modal>
</div>
```

</OnlyBase>

## Composition

Use the following composition to build a `Modal`:

```text
Modal
├── ModalTrigger
└── ModalContent
    ├── ModalHeader
    │   ├── ModalTitle
    │   └── ModalDescription
    ├── ModalBody
    └── ModalFooter
        └── ModalClose
```

## Accessibility

- The popup has the `dialog` role, named by `ModalTitle` and described by `ModalDescription`.
- `Escape` closes the modal and returns focus to the trigger.
- The default close button is labelled Close.

## API Reference

### Modal

The root that renders a `Dialog` on desktop and a `Drawer` on mobile.

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | - |
| `onOpenChange` | `(open: boolean) => void` | - |
| `floating` | `boolean` | - |
| `children` | `React.ReactNode` | - |

The modal can be controlled with `open` and `onOpenChange` or uncontrolled with `defaultOpen`.

### ModalTrigger

The button that opens the modal.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

<OnlyBase base="base radix">

Also accepts the props of `React.ComponentProps<typeof DialogTrigger>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children`, `id` and `aria-label`.

</OnlyBase>

<OnlyBase base="base aria">

Pass `render` to replace the button with your own element, such as a `Button`.

</OnlyBase>

<OnlyBase base="radix">

Set `asChild` to use your own element, such as a `Button`.

</OnlyBase>

### ModalContent

The popup window, with a close button by default.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |
| `style` | `React.CSSProperties` | - |

<OnlyBase base="base radix">

Also accepts the props of `React.ComponentProps<typeof DialogContent>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `showCloseButton`, `closeLabel`, `children`, `id` and `aria-label`.

</OnlyBase>

`className` and `style` apply to the dialog or drawer popup. They are plain values only, because the same props are forwarded to either popup.

### ModalHeader

Groups the title and description.

Also accepts the props of `React.ComponentProps<"div">`.

### ModalBody

The main content area, padded on mobile.

Also accepts the props of `React.ComponentProps<"div">`.

### ModalFooter

Holds the modal's actions; stacked with the primary action on top on mobile.

Also accepts the props of `React.ComponentProps<"div">`.

On mobile it stacks its buttons in reverse order so the primary action sits on top.

### ModalTitle

The modal's title, used as its accessible name.

<OnlyBase base="base radix">

Also accepts the props of `React.ComponentProps<typeof DialogTitle>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children` and `id`.

</OnlyBase>

### ModalDescription

Supporting text, used as the modal's accessible description.

<OnlyBase base="base radix">

Also accepts the props of `React.ComponentProps<typeof DialogDescription>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children` and `id`.

</OnlyBase>

### ModalClose

A button that closes the modal.

<OnlyBase base="base radix">

Also accepts the props of `React.ComponentProps<typeof DialogClose>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children`, `id` and `aria-label`.

</OnlyBase>

<OnlyBase base="base aria">

Pass `render` to replace the button with your own element, such as a `Button`.

</OnlyBase>

<OnlyBase base="radix">

Set `asChild` to use your own element, such as a `Button`.

</OnlyBase>

Each part sets a `data-slot`, such as `modal-content` or `modal-close`, for styling.

</Only>
