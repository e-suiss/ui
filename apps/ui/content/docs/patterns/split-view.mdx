`SplitView` arranges content in up to three columns, like Mail: a sidebar, a list and a detail pane. On desktop it places the panes in a horizontal suiss/ui `ResizablePanelGroup` with resize handles between them. The panes default to 20%, 32% and 48% of the width, with minimum sizes of 15%, 22% and 30%.

On mobile (below `48rem`, via `useIsMobile`) only one column shows at a time. Tapping a `SplitViewItem` pushes the next column, and a back button labelled with the previous pane's title returns to it. After navigation, focus moves to the new pane's heading and the view scrolls into place. Use it for master-detail interfaces such as mail, settings or file browsers.

## Usage

<Code lang="tsx" code={"import { SplitView, SplitViewSidebar, SplitViewList, SplitViewDetail, SplitViewItem } from \"@/components/patterns/split-view\""} />

<Code lang="tsx" code={"<MailExample />"} />

- Place `SplitViewSidebar`, `SplitViewList` and `SplitViewDetail` as direct children of `SplitView`. Leave out the sidebar for a two-column layout.
- The mobile column is uncontrolled by default and starts at `defaultColumn`. Use `column` with `onColumnChange` to control it.
- `SplitViewItem` advances to the next column on click and runs your own `onClick` too. Set `isActive` on the current item.
- The list pane shows a back button to the sidebar only when the sidebar has a `title`.
- `useSplitView` returns `isMobile`, `column` and `setColumn` for custom navigation inside the view.

## Accessibility

- Each pane is a `section` labelled by its `title` heading, so titled panes are exposed as regions.
- The active item has `aria-current="true"`.
- On mobile, navigating moves focus to the new pane's heading. The back button's chevron is hidden from assistive technology.

## Notes

Styling hooks: `data-slot="split-view"`, `split-view-sidebar`, `split-view-list`, `split-view-detail`, `split-view-back` and `split-view-item`; desktop panels use `split-view-sidebar-panel`, `split-view-list-panel` and `split-view-detail-panel`. On mobile the root has `data-column` set to the visible column. Use the `render` prop on `SplitViewItem` to render it as a link.
