`SplitView` arranges content in up to three columns, like Mail: a sidebar, a list and a detail pane. On desktop it places the panes in a horizontal suiss/ui `ResizablePanelGroup` with resize handles between them. On mobile (below `48rem`, via `useIsMobile`) only one column shows at a time, and tapping a `SplitViewItem` pushes the next column.

Use it for master-detail interfaces such as mail, settings or file browsers.

## Usage

```tsx
import {
  SplitView,
  SplitViewDetail,
  SplitViewItem,
  SplitViewList,
  SplitViewSidebar,
} from "@/components/patterns/split-view"
```

```tsx
<SplitView>
  <SplitViewSidebar title="Mailboxes">
    <SplitViewItem isActive>Inbox</SplitViewItem>
    <SplitViewItem>Sent</SplitViewItem>
  </SplitViewSidebar>
  <SplitViewList title="Inbox">
    <SplitViewItem isActive>Your order has shipped</SplitViewItem>
    <SplitViewItem>Tomorrow's meeting</SplitViewItem>
  </SplitViewList>
  <SplitViewDetail title="Your order has shipped">
    <p>Order #1042 will be delivered tomorrow.</p>
  </SplitViewDetail>
</SplitView>
```

## Accessibility

- Each pane is a `section` labelled by its `title` heading, so titled panes are exposed as regions.
- The active item has `aria-current="true"`.
- On mobile, navigating moves focus to the new pane's heading. The back button's chevron is hidden from assistive technology.

## API Reference

### SplitView

The root that lays out the panes and tracks the visible mobile column.

| Prop | Type | Default |
| --- | --- | --- |
| `column` | `SplitViewColumn` | - |
| `defaultColumn` | `SplitViewColumn` | `"list"` |
| `onColumnChange` | `(column: SplitViewColumn) => void` | - |

Also accepts the props of `React.ComponentProps<"div">`.

Place `SplitViewSidebar`, `SplitViewList` and `SplitViewDetail` as direct children. On desktop the panes default to 20%, 32% and 48% of the width, with minimum sizes of 15%, 22% and 30%. The mobile column is uncontrolled by default and starts at `defaultColumn`; use `column` with `onColumnChange` to control it. On mobile the root sets `data-column` to the visible column. `useSplitView` returns `isMobile`, `column` and `setColumn` for custom navigation inside the view.

### SplitViewSidebar

The leading pane, usually for sources or categories.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `React.ReactNode` | - |

Also accepts the props of `React.ComponentProps<"section">`.

`title` is the pane heading and accessible name. It also labels the back button in the list pane, which shows a back button to the sidebar only when the sidebar has a `title`.

### SplitViewList

The middle pane, usually a list of items.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `React.ReactNode` | - |

Also accepts the props of `React.ComponentProps<"section">`.

`title` is visually hidden on desktop and labels the back button in the detail pane.

### SplitViewDetail

The trailing pane that shows the selected item.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `React.ReactNode` | - |

Also accepts the props of `React.ComponentProps<"section">`.

### SplitViewItem

A button row that marks the current selection and advances to the next column on mobile.

| Prop | Type | Default |
| --- | --- | --- |
| `isActive` | `boolean` | `false` |

<OnlyBase base="base">

Also accepts the props of `useRender.ComponentProps<"button">`.

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |

Also accepts the props of `React.ComponentProps<"button">`.

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `(props: React.HTMLAttributes<HTMLElement>) => React.ReactNode` | - |

Also accepts the props of `React.ComponentProps<"button">`.

</OnlyBase>

On mobile it advances to the next column on click and runs your own `onClick` too. Set `isActive` on the current item; it sets `aria-current` and `data-active`.

<OnlyBase base="base">

Use the `render` prop to render it as a link.

</OnlyBase>

<OnlyBase base="radix">

Set `asChild` and pass a link as the child to render it as a link.

</OnlyBase>

<OnlyBase base="aria">

Pass a `render` function that returns a link with the props it receives.

</OnlyBase>

Each part sets a `data-slot`, such as `split-view-list`, `split-view-back` or `split-view-list-panel`, for styling.

</Only>

`SplitView` lays out up to three panes: `SplitViewSidebar`, `SplitViewList` and `SplitViewDetail`. When the window is at least `breakpoint` wide (768 by default), they sit side by side in a bordered row, sized 20, 32 and 48 parts.

</Only>

Below the breakpoint only the current column is shown, full screen and scrollable, with a large title. Pressing a `SplitViewItem` moves to the next column, and a back button titled with the previous pane returns to it. Use it for mail, notes or settings screens that drill down.

<Only platform="rn kotlin">

On Android the hardware back button also returns to the previous column.

import * as React from "react"
import { View } from "react-native"
import { SplitView, type SplitViewColumn, SplitViewDetail, SplitViewItem, SplitViewList, SplitViewSidebar } from "@/components/patterns/split-view"
import { Text } from "@/components/ui/text"

const mailboxes = ["Inbox", "Sent", "Drafts", "Archive"]

const messages = [
  {
    id: "order",
    from: "Acme Store",
    time: "09:12",
    subject: "Your order has shipped",
    body: "Order #1042 will be delivered tomorrow. Tracking number: 4815 1623 42.",
  },
  {
    id: "meeting",
    from: "Jordan Lee",
    time: "Yesterday",
    subject: "Tomorrow's meeting",
    body: "Does 10:00 work for you? On the agenda: the Q4 budget and the campaign plan.",
  },
  {
    id: "storage",
    from: "Cloud Drive",
    time: "Mon",
    subject: "Your storage is almost full",
    body: "Your cloud storage is 90% full. Upgrade your plan to get more space.",
  },
] as const

function MailExample({
  withSidebar = true,
  defaultColumn,
}: {
  withSidebar?: boolean
  defaultColumn?: SplitViewColumn
}) {
  const [mailbox, setMailbox] = React.useState("Inbox")
  const [messageId, setMessageId] = React.useState<string>("order")
  const message = messages.find((item) => item.id === messageId) ?? messages[0]

  return (
    <SplitView defaultColumn={defaultColumn}>
      {withSidebar ? (
        <SplitViewSidebar title="Mailboxes">
          {mailboxes.map((name) => (
            <SplitViewItem
              key={name}
              isActive={mailbox === name}
              onPress={() => setMailbox(name)}
            >
              {name}
            </SplitViewItem>
          ))}
        </SplitViewSidebar>
      ) : null}
      <SplitViewList title={mailbox}>
        {messages.map((item) => (
          <SplitViewItem
            key={item.id}
            isActive={item.id === messageId}
            onPress={() => setMessageId(item.id)}
          >
            <View className="flex-row items-baseline justify-between gap-2">
              <Text className="shrink font-semibold" numberOfLines={1}>
                {item.from}
              </Text>
              <Text className="text-sm text-muted-foreground">{item.time}</Text>
            </View>
            <Text numberOfLines={1}>{item.subject}</Text>
            <Text className="text-sm text-muted-foreground" numberOfLines={1}>
              {item.body}
            </Text>
          </SplitViewItem>
        ))}
      </SplitViewList>
      <SplitViewDetail title={message.subject}>
        <Text className="text-sm text-muted-foreground">
          {message.from} · {message.time}
        </Text>
        <Text className="mt-6">{message.body}</Text>
      </SplitViewDetail>
    </SplitView>
  )
}

export function SplitViewExample() {
  return (
    <MailExample />
  )
}

  let id: String
  let from: String
  let time: String
  let subject: String
  let body: String

let splitViewMailboxes = ["Inbox", "Sent", "Drafts", "Archive"]

  SplitViewMessage(
    id: "order",
    from: "Acme Store",
    time: "09:12",
    subject: "Your order has shipped",
    body: "Order #1042 will be delivered tomorrow. Tracking number: 4815 1623 42."
  ),
  SplitViewMessage(
    id: "meeting",
    from: "Jordan Lee",
    time: "Yesterday",
    subject: "Tomorrow's meeting",
    body: "Does 10:00 work for you? On the agenda: the Q4 budget and the campaign plan."
  ),
  SplitViewMessage(
    id: "storage",
    from: "Cloud Drive",
    time: "Mon",
    subject: "Your storage is almost full",
    body: "Your cloud storage is 90% full. Upgrade your plan to get more space."
  ),
]

struct SplitViewMail: View {
  var withSidebar = true

  @State private var column: SplitViewColumn
  @State private var mailbox = "Inbox"
  @State private var messageID = "order"

  init(column: SplitViewColumn = .list, withSidebar: Bool = true) {
    _column = State(initialValue: column)
    self.withSidebar = withSidebar
  }

  var message: SplitViewMessage {
    splitViewMessages.first { $0.id == messageID } ?? splitViewMessages[0]
  }

  var body: some View {
    SplitView(column: $column) {
      if withSidebar {
        SplitViewSidebar("Mailboxes") {
          ForEach(splitViewMailboxes, id: \.self) { name in
            SplitViewItem(isActive: mailbox == name, action: { mailbox = name }) {
              Text(verbatim: name)
            }
          }
        }
      }
      SplitViewList(verbatim: mailbox) {
        ForEach(splitViewMessages) { item in
          SplitViewItem(isActive: item.id == messageID, action: { messageID = item.id }) {
            HStack(alignment: .firstTextBaseline, spacing: 8) {
              Text(verbatim: item.from)
                .fontWeight(.semibold)
                .lineLimit(1)
                .frame(maxWidth: .infinity, alignment: .leading)
              Text(verbatim: item.time)
                .textStyle(.sm)
                .foregroundStyle(EsuissColor.mutedForeground)
            }
            Text(verbatim: item.subject)
              .lineLimit(1)
            Text(verbatim: item.body)
              .textStyle(.sm)
              .foregroundStyle(EsuissColor.mutedForeground)
              .lineLimit(1)
          }
        }
      }
      SplitViewDetail(verbatim: message.subject) {
        Text(verbatim: "\(message.from) · \(message.time)")
          .textStyle(.sm)
          .foregroundStyle(EsuissColor.mutedForeground)
        Text(verbatim: message.body)
          .foregroundStyle(EsuissColor.foreground)
          .fixedSize(horizontal: false, vertical: true)
          .padding(.top, 24)
      }
    }
    .containerRelativeFrame(.vertical) { height, _ in height - 32 }
  }
}

    val id: String,
    val from: String,
    val time: String,
    val subject: String,
    val body: String,
)

val splitViewMailboxes = listOf("Inbox", "Sent", "Drafts", "Archive")

val splitViewMessages = listOf(
    SplitViewMessage(
        "order",
        "Acme Store",
        "09:12",
        "Your order has shipped",
        "Order #1042 will be delivered tomorrow. Tracking number: 4815 1623 42.",
    ),
    SplitViewMessage(
        "meeting",
        "Jordan Lee",
        "Yesterday",
        "Tomorrow's meeting",
        "Does 10:00 work for you? On the agenda: the Q4 budget and the campaign plan.",
    ),
    SplitViewMessage(
        "storage",
        "Cloud Drive",
        "Mon",
        "Your storage is almost full",
        "Your cloud storage is 90% full. Upgrade your plan to get more space.",
    ),

@Composable
fun SplitViewMail(withSidebar: Boolean = true, defaultColumn: SplitViewColumn = SplitViewColumn.List) {
    var mailbox by rememberSaveable { mutableStateOf("Inbox") }
    var messageId by rememberSaveable { mutableStateOf("order") }
    val message = splitViewMessages.firstOrNull { it.id == messageId } ?: splitViewMessages.first()
    val colors = EsuissTheme.colors
    SplitView(modifier = Modifier.fillMaxWidth().height(640.dp), defaultColumn = defaultColumn) {
        if (withSidebar) {
            SplitViewSidebar(title = "Mailboxes") {
                splitViewMailboxes.forEach { name ->
                    SplitViewItem(isActive = mailbox == name, onClick = { mailbox = name }) {
                        Text(name)
                    }
                }
            }
        }
        SplitViewList(title = mailbox) {
            splitViewMessages.forEach { item ->
                SplitViewItem(isActive = item.id == messageId, onClick = { messageId = item.id }) {
                    Row(
                        modifier = Modifier.fillMaxWidth(),
                        horizontalArrangement = Arrangement.spacedBy(8.dp),
                        verticalAlignment = Alignment.CenterVertically,
                    ) {
                        Text(
                            item.from,
                            modifier = Modifier.weight(1f),
                            style = Typography.base.copy(fontWeight = FontWeight.SemiBold),
                            maxLines = 1,
                            overflow = TextOverflow.Ellipsis,
                        )
                        Text(item.time, style = Typography.sm.copy(color = colors.mutedForeground), maxLines = 1)
                    }
                    Text(item.subject, maxLines = 1, overflow = TextOverflow.Ellipsis)
                    Text(
                        item.body,
                        style = Typography.sm.copy(color = colors.mutedForeground),
                        maxLines = 1,
                        overflow = TextOverflow.Ellipsis,
                    )
                }
            }
        }
        SplitViewDetail(title = message.subject) {
            Text("${message.from} · ${message.time}", style = Typography.sm.copy(color = colors.mutedForeground))
            Text(message.body, modifier = Modifier.padding(top = 24.dp))
        }
    }
}

## Accessibility

- Pane titles have the `heading` role, and panes are labelled by string titles.
- On phones, screen reader focus moves to the new pane's heading after navigating.
- `SplitViewItem` exposes its `selected` state.
- Back and row chevrons mirror in right-to-left layouts.

</Only>

## API Reference

<Only platform="rn">

### SplitView

The root that tracks the current column and the layout mode.

| Prop | Type | Default |
| --- | --- | --- |
| `column` | `SplitViewColumn` | - |
| `defaultColumn` | `SplitViewColumn` | `"list"` |
| `onColumnChange` | `(column: SplitViewColumn) => void` | - |
| `breakpoint` | `number` | `768` |

Also accepts the props of `ViewProps`.

The current column is uncontrolled with `defaultColumn` or controlled with `column` and `onColumnChange`. `breakpoint` is the window width at which the panes sit side by side. On phones the new pane fades in, respecting the system reduce motion setting. `useSplitView` returns `isCompact`, `column` and `setColumn` for custom navigation.

### SplitViewSidebar

The first pane, for top-level sections.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `React.ReactNode` | - |

Also accepts the props of `ViewProps`.

Give each pane a `title`; the back button only appears when the previous pane exists and has a title.

### SplitViewList

The middle pane, for the items in a section.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `React.ReactNode` | - |

Also accepts the props of `ViewProps`.

### SplitViewDetail

The last pane, for the selected item.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `React.ReactNode` | - |

Also accepts the props of `ViewProps`.

### SplitViewItem

A pressable row that moves to the next column.

| Prop | Type | Default |
| --- | --- | --- |
| `isActive` | `boolean` | `false` |
| `children` | `React.ReactNode` | - |

Also accepts the props of `React.ComponentProps<typeof Pressable>`.

Put items in the sidebar and list panes, and use their `onPress` to set the selection in your own state. `isActive` highlights the row and marks it as selected.

</Only>
