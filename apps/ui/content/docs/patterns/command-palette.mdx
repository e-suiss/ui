`CommandPalette` hosts a `Command` list inside a `Dialog` on desktop, positioned in the upper third of the viewport, and inside a bottom `Drawer` with a swipe handle below the `48rem` breakpoint. Fill `CommandPaletteContent` with `CommandInput`, `CommandList`, `CommandGroup`, `CommandItem` and the other `Command` parts.

A global keyboard shortcut toggles the palette: `Cmd+K` on macOS and `Ctrl+K` elsewhere by default. Use it for app-wide search and quick actions.

## Usage

<Code lang="tsx" code={"import { CommandPalette, CommandPaletteTrigger, CommandPaletteContent } from \"@/components/patterns/command-palette\""} />

<Code lang="tsx" code={"<div className=\"flex min-h-svh items-center justify-center\">\n  <CommandPalette>\n    <Trigger />\n    <CommandPaletteContent>\n      <PaletteItems />\n    </CommandPaletteContent>\n  </CommandPalette>\n</div>"} />

The palette can be controlled with `open` and `onOpenChange` or uncontrolled with `defaultOpen`; the hotkey and the trigger update the same state. Set `hotkey` to another letter to change the shortcut, or to `false` to disable it. `CommandPaletteTrigger` accepts `render` to use your own button, for example a `Button` with a `Kbd` hint. Remaining props on `CommandPaletteContent` pass through to `Command`.

## Accessibility

- The popup is a `dialog` named by `title` and described by `description`.
- Opening the palette focuses the search input, and the first enabled option is selected.
- Arrow keys move between options and skip disabled ones; typing filters the list.
- `Escape` closes the palette and returns focus to the trigger.

## Notes

Parts carry `data-slot` values `command-palette`, `command-palette-trigger` and `command-palette-content`. On mobile the list is capped at `60dvh` and the input gains end padding when a close button is shown. `className` on `CommandPaletteContent` applies to the inner `Command`, not the dialog or drawer.
