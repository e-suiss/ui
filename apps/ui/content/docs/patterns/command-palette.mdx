`CommandPalette` hosts a `Command` list inside a `Dialog` on desktop, positioned in the upper third of the viewport, and inside a bottom `Drawer` with a swipe handle below the `48rem` breakpoint. A global keyboard shortcut toggles it: `Cmd+K` on macOS and `Ctrl+K` elsewhere by default.

Use it for app-wide search and quick actions.

## Usage

```tsx
import { CommandPalette, CommandPaletteTrigger, CommandPaletteContent } from "@/components/patterns/command-palette"
import { Button } from "@/components/ui/button"
import {
  CommandEmpty,
  CommandGroup,
  CommandInput,
  CommandItem,
  CommandList,
  CommandShortcut,
} from "@/components/ui/command"
```

## Accessibility

- The popup is a `dialog` named by `title` and described by `description`.
- Opening the palette focuses the search input, and the first enabled option is selected.
- Arrow keys move between options and skip disabled ones; typing filters the list.
- `Escape` closes the palette and returns focus to the trigger.

## API Reference

### CommandPalette

The root that renders a `Dialog` on desktop and a `Drawer` on mobile and registers the hotkey.

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `(open: boolean) => void` | - |
| `hotkey` | `string \| false` | `"k"` |
| `floating` | `boolean` | - |
| `children` | `React.ReactNode` | - |

The palette can be controlled with `open` and `onOpenChange` or uncontrolled with `defaultOpen`; the hotkey and the trigger update the same state, and `onOpenChange` also fires for the hotkey. `hotkey` is the letter that toggles the palette together with `Cmd` on macOS or `Ctrl` elsewhere. Set it to another letter to change the shortcut, or to `false` to disable it.

### CommandPaletteContent

The popup that wraps a `Command` with a visually hidden title and description.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | `"Command Palette"` |
| `description` | `string` | `"Search for a command to run..."` |
| `showCloseButton` | `boolean` | `false` |
| `closeLabel` | `string` | - |

Also accepts the props of `React.ComponentProps<typeof Command>`.

Fill it with `CommandInput`, `CommandList`, `CommandGroup`, `CommandItem` and the other `Command` parts. `title` and `description` name and describe the dialog and are rendered visually hidden. Remaining props, including `className`, pass through to the inner `Command`, not the dialog or drawer. On mobile the list is capped at `60dvh`.

Each part sets a `data-slot`, such as `command-palette` or `command-palette-content`, for styling.
