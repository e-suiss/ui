`Trail` shows where the current page sits in a hierarchy. On desktop it renders a suiss/ui `Breadcrumb` that links every ancestor and marks the last item as the current page. On mobile it renders a single back link to the parent page, with a menu of all ancestors.

Use it on documentation, support and settings pages with nested structure.

## Usage

```tsx
import { Trail, type TrailItem } from "@/components/patterns/trail"
```

```tsx
const items: TrailItem[] = [
  { label: "Support", href: "/support" },
  { label: "Account", href: "/support/account" },
  { label: "Turn on two-factor authentication" },
]

<Trail items={items} />
```

## Accessibility

- On desktop the trail is a navigation landmark named breadcrumb, and the current page has `aria-current="page"`.
- On mobile it is a navigation landmark named Back. When a history menu is available, the back link has `aria-haspopup="menu"` and `aria-expanded`.
- The history menu opens from the keyboard with the Context Menu key or Shift+F10.

## API Reference

### Trail

The navigation element that renders the breadcrumbs or the mobile back link.

| Prop | Type | Default |
| --- | --- | --- |
| `items` | `TrailItem[]` | Required |
| `maxItems` | `number` | - |
| `backLabel` | `string` | - |
| `ellipsisLabel` | `string` | `"More"` |

<OnlyBase base="base radix">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `React.ReactElement` | A plain `a` |

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `(props: React.ComponentProps<"a">) => React.ReactNode` | A plain `a` |

</OnlyBase>

Also accepts the props of `React.ComponentProps<"nav">`.

Pass `items` in order from the root to the current page. Each `TrailItem` has a `label` and an optional `href`; the last item is the current page. `ellipsisLabel` is the accessible label of the collapsed ellipsis.

On mobile (below `48rem`, via `useIsMobile`) the trail renders a back link to the parent page, and nothing when there is only one item. When there is more than one ancestor, a long press, right-click, the Context Menu key or Shift+F10 opens a menu of all ancestors, nearest first. A long press opens it only for touch and pen input, cancels if the pointer moves more than 10 pixels, and does not also follow the back link.

<OnlyBase base="base radix">

Use `render` to output links through your router, for example a framework `Link` element. It applies to breadcrumb links, the mobile back link and the history menu items.

</OnlyBase>

<OnlyBase base="aria">

Pass a `render` function to output links through your router. It receives the link props, including `href`, and applies to breadcrumb links, the mobile back link and the history menu items.

</OnlyBase>

Each part sets a `data-slot`, such as `trail`, `trail-back` or `trail-history-item`, for styling.

</Only>
