`ActionBar` groups several `ActionBarMenu`s. On desktop it renders a `Menubar`, and hovering another trigger while a menu is open switches menus. Below the `48rem` breakpoint (`useIsMobile`), the bar collapses into a ghost icon `Button` that opens a `Drawer` with a row per menu; choosing a row opens that menu's items in an `AlertSheet`.

Use it for toolbar-style command groups, such as File, Edit and View, that need to fit on small screens.

## Usage

```tsx
import {
  ActionBar,
  ActionBarContent,
  ActionBarItem,
  ActionBarLabel,
  ActionBarMenu,
  ActionBarSeparator,
  ActionBarShortcut,
  ActionBarTrigger,
} from "@/components/patterns/action-bar"
```

```tsx
<ActionBar>
  <ActionBarMenu>
    <ActionBarTrigger>File</ActionBarTrigger>
    <ActionBarContent>
      <ActionBarItem>
        New tab
        <ActionBarShortcut mod>T</ActionBarShortcut>
      </ActionBarItem>
      <ActionBarSeparator />
      <ActionBarItem>
        Print
        <ActionBarShortcut mod>P</ActionBarShortcut>
      </ActionBarItem>
    </ActionBarContent>
  </ActionBarMenu>
  <ActionBarMenu>
    <ActionBarTrigger>View</ActionBarTrigger>
    <ActionBarContent>

      <ActionBarItem>Zoom in</ActionBarItem>
      <ActionBarItem>Zoom out</ActionBarItem>
    </ActionBarContent>
  </ActionBarMenu>
</ActionBar>
```

## Accessibility

- On desktop the bar has the `menubar` role and each trigger and item has the `menuitem` role.
- Disabled items expose `aria-disabled="true"`.
- `Escape` closes an open menu and returns focus to its trigger.
- On mobile the More actions button is labelled by `moreLabel`, and each drawer row has `aria-haspopup="dialog"`.

## API Reference

### ActionBar

The root that renders a `Menubar` on desktop and a More actions button with a `Drawer` on mobile.

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `(open: boolean) => void` | - |
| `dismissible` | `boolean` | `true` |
| `floating` | `boolean` | - |
| `moreLabel` | `string` | `"More actions"` |
| `cancelLabel` | `string` | `"Cancel"` |

Also accepts the props of `React.ComponentProps<"div">`.

Each child should be an `ActionBarMenu`; the bar uses the child index to pair the mobile row with its sheet. `open`, `defaultOpen` and `onOpenChange` control the mobile More actions drawer only and have no effect on desktop.

### ActionBarMenu

One menu in the bar; a `MenubarMenu` on desktop and an `AlertSheet` on mobile.

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | - |
| `onOpenChange` | `(open: boolean) => void` | - |
| `children` | `React.ReactNode` | - |

Put one `ActionBarTrigger` and one `ActionBarContent` in each menu. Its own `open`, `defaultOpen` and `onOpenChange` control that menu, on desktop and for the mobile sheet.

### ActionBarTrigger

The menu's button; a menubar trigger on desktop and a drawer row with a chevron on mobile.

Also accepts the props of `React.ButtonHTMLAttributes<HTMLButtonElement>`.

### ActionBarContent

The menu's items; a `MenubarContent` popup on desktop and an `AlertSheetContent` with a Cancel button on mobile.

<OnlyBase base="base radix">

Also accepts `align`, `alignOffset`, `side` and `sideOffset` from `MenubarContent`, which position the desktop popup, and the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `align`, `alignOffset`, `side` and `sideOffset` from `MenubarContent`, which position the desktop popup, and `className`, `children`, `id` and `aria-label`.

</OnlyBase>

### ActionBarLabel

A non-interactive heading; a menu label on desktop and the sheet title on mobile.

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children` and `id`.

</OnlyBase>

### ActionBarItem

An actionable entry; a `MenubarItem` on desktop and an `AlertSheetAction` on mobile.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "destructive"` | - |
| `disabled` | `boolean` | - |

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Respond to the item with `onAction`. Also accepts `className`, `children`, `id` and `aria-label`.

</OnlyBase>

### ActionBarSeparator

A divider between item groups, rendered on desktop only.

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`.

</OnlyBase>

### ActionBarShortcut

A keyboard shortcut hint aligned to the end of an item, rendered on desktop only.

Also accepts the props of `React.ComponentProps<typeof MenubarShortcut>`.

Set `mod` to prefix the platform modifier key. `ActionBarSeparator` and `ActionBarShortcut` render nothing on mobile. Each part sets a `data-slot`, such as `action-bar-trigger` or `action-bar-more`, for styling.

</Only>

## Usage

<Only platform="rn">

```tsx
import { ClipboardTextIcon, CopyIcon, ScissorsIcon, TrashIcon } from "phosphor-react-native"
import { ActionBar, ActionBarContent, ActionBarItem, ActionBarLabel, ActionBarMenu, ActionBarSeparator, ActionBarTrigger } from "@/components/patterns/action-bar"
import { Icon } from "@/components/ui/icon"
import { Text } from "@/components/ui/text"

function FileMenu({ defaultOpen }: { defaultOpen?: boolean }) {
  return (
    <ActionBarMenu defaultOpen={defaultOpen}>
      <ActionBarTrigger>File</ActionBarTrigger>
      <ActionBarContent>
        <ActionBarItem>New tab</ActionBarItem>
        <ActionBarItem>New window</ActionBarItem>
        <ActionBarItem disabled>New incognito window</ActionBarItem>
        <ActionBarSeparator />
        <ActionBarItem>Print</ActionBarItem>
      </ActionBarContent>
    </ActionBarMenu>
  )
}

function EditMenu({ withIcons = false }: { withIcons?: boolean }) {
  return (
    <ActionBarMenu>
      <ActionBarTrigger>Edit</ActionBarTrigger>
      <ActionBarContent>
        <ActionBarItem>
          {withIcons ? <Icon as={ScissorsIcon} /> : null}
          <Text>Cut</Text>
        </ActionBarItem>
        <ActionBarItem>
          {withIcons ? <Icon as={CopyIcon} /> : null}
          <Text>Copy</Text>
        </ActionBarItem>
        <ActionBarItem>
          {withIcons ? <Icon as={ClipboardTextIcon} /> : null}
          <Text>Paste</Text>
        </ActionBarItem>
        <ActionBarSeparator />
        <ActionBarItem variant="destructive">
          {withIcons ? <Icon as={TrashIcon} /> : null}
          <Text>Delete</Text>
        </ActionBarItem>
      </ActionBarContent>
    </ActionBarMenu>
  )
}

function ViewMenu() {
  return (
    <ActionBarMenu>
      <ActionBarTrigger>View</ActionBarTrigger>
      <ActionBarContent>
        <ActionBarLabel>Appearance</ActionBarLabel>
        <ActionBarItem>Zoom in</ActionBarItem>
        <ActionBarItem>Zoom out</ActionBarItem>
        <ActionBarItem>Actual size</ActionBarItem>
      </ActionBarContent>
    </ActionBarMenu>
  )
}

export function ActionBarExample() {
  return (
    <ActionBar>
      <FileMenu />
      <EditMenu />
      <ViewMenu />
    </ActionBar>
  )
}
```

```swift
  var body: some View {
    ActionBarDemo {
      ActionBarFileMenu()
      ActionBarEditMenu()
      ActionBarViewMenu()
    }
  }

struct ActionBarDemo<Content: View>: View {
  var dismissible = true
  var moreLabel: LocalizedStringKey = "More actions"
  var cancelLabel: LocalizedStringKey = "Cancel"
  let content: Content

  @State private var open: Bool

  init(
    open: Bool = false,
    dismissible: Bool = true,
    moreLabel: LocalizedStringKey = "More actions",
    cancelLabel: LocalizedStringKey = "Cancel",
    @ViewBuilder content: () -> Content
  ) {
    _open = State(initialValue: open)
    self.dismissible = dismissible
    self.moreLabel = moreLabel
    self.cancelLabel = cancelLabel
    self.content = content()
  }

  var body: some View {
    ActionBar(isPresented: $open, dismissible: dismissible, moreLabel: moreLabel, cancelLabel: cancelLabel) {
      content
    }
  }
}

struct ActionBarFileMenu: View {
  var isPresented: Binding<Bool>?

  var body: some View {
    ActionBarMenu("File", isPresented: isPresented) {
      ActionBarItem("New tab") {}
      ActionBarItem("New window") {}
      ActionBarItem("New incognito window") {}.disabled(true)
      ActionBarSeparator()
      ActionBarItem("Print") {}
    }
  }
}

struct ActionBarEditMenu: View {
  var withIcons = false

  var body: some View {
    ActionBarMenu("Edit") {

        ActionBarItem("Cut", icon: Ph.scissors.regular) {}
        ActionBarItem("Copy", icon: Ph.copy.regular) {}
```

```kotlin
@Composable
fun ActionBarDemo(
    defaultOpen: Boolean = false,
    fileOpen: Boolean = false,
    withIcons: Boolean = false,
    view: Boolean = true,
    dismissible: Boolean = true,
    floating: Boolean = false,
    moreLabel: String = "More actions",
    cancelLabel: String = "Cancel",
) {
    var open by rememberSaveable { mutableStateOf(defaultOpen) }
    ActionBar(
        open = open,
        onOpenChange = { open = it },
        modifier = Modifier.fillMaxWidth(),
        dismissible = dismissible,
        floating = floating,
        moreLabel = moreLabel,
        cancelLabel = cancelLabel,
    ) {
        actionBarFileMenu(fileOpen)
        actionBarEditMenu(withIcons)
        if (view) actionBarViewMenu()
    }
}

fun ActionBarScope.actionBarFileMenu(defaultOpen: Boolean) {
    ActionBarMenu(defaultOpen = defaultOpen) {
        ActionBarTrigger("File")
        ActionBarContent {
            ActionBarItem("New tab", onClick = {})
            ActionBarItem("New window", onClick = {})
            ActionBarItem("New incognito window", onClick = {}, enabled = false)
            ActionBarSeparator()
            ActionBarItem("Print", onClick = {})
        }
    }
}

fun ActionBarScope.actionBarEditMenu(withIcons: Boolean) {
    ActionBarMenu {
        ActionBarTrigger("Edit")
        ActionBarContent {
            ActionBarItem("Cut", onClick = {}, icon = if (withIcons) PhosphorIcons.Regular.Scissors else null)
            ActionBarItem("Copy", onClick = {}, icon = if (withIcons) PhosphorIcons.Regular.Copy else null)
            ActionBarItem("Paste", onClick = {}, icon = if (withIcons) PhosphorIcons.Regular.ClipboardText else null)
            ActionBarSeparator()
            ActionBarItem(
                "Delete",
                onClick = {},
                variant = MenuItemVariant.Destructive,
                icon = if (withIcons) PhosphorIcons.Regular.Trash else null,
            )
        }
    }
}

fun ActionBarScope.actionBarViewMenu() {
    ActionBarMenu {
        ActionBarTrigger("View")
        ActionBarContent {
            ActionBarLabel("Appearance")
            ActionBarItem("Zoom in", onClick = {})
            ActionBarItem("Zoom out", onClick = {})

    }
```
