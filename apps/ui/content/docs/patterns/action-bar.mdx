`ActionBar` groups several `ActionBarMenu`s, each with a `ActionBarTrigger` and `ActionBarContent`. On desktop it renders a `Menubar`: each menu is a `MenubarMenu`, and hovering another trigger while a menu is open switches menus.

Below the `48rem` breakpoint (`useIsMobile`), the bar collapses into a ghost icon `Button` that opens a `Drawer`. The drawer lists every menu's trigger as a row; choosing a row closes the drawer and opens that menu's items in an `AlertSheet`, with a Cancel button appended. Use it for toolbar-style command groups, such as File, Edit and View, that need to fit on small screens.

## Usage

<Code lang="tsx" code={"import { ActionBar, ActionBarMenu, ActionBarTrigger, ActionBarContent, ActionBarLabel, ActionBarItem, ActionBarSeparator, ActionBarShortcut } from \"@/components/patterns/action-bar\""} />

<Code lang="tsx" code={"<div className=\"min-h-96\">\n  <ActionBar>\n    <FileMenu />\n    <EditMenu />\n    <ViewMenu />\n  </ActionBar>\n</div>"} />

Each child of `ActionBar` should be an `ActionBarMenu` containing one `ActionBarTrigger` and one `ActionBarContent`; the bar uses the child index to pair the mobile row with its sheet. `open`, `defaultOpen` and `onOpenChange` on `ActionBar` control the mobile More actions drawer only; on desktop they have no effect. `ActionBarMenu` accepts its own `open`, `defaultOpen` and `onOpenChange` for an individual menu, which apply on desktop and to the mobile sheet. Use `ActionBarShortcut` with `mod` to prefix the platform modifier key.

## Accessibility

- On desktop the bar has the `menubar` role and each trigger and item has the `menuitem` role.
- Disabled items expose `aria-disabled="true"`.
- `Escape` closes an open menu and returns focus to its trigger.
- On mobile the More actions button is labelled by `moreLabel`, and each drawer row has `aria-haspopup="dialog"`.

## Notes

Parts carry `data-slot` values such as `action-bar`, `action-bar-menu`, `action-bar-trigger`, `action-bar-content`, `action-bar-item`, `action-bar-more`, `action-bar-label`, `action-bar-separator` and `action-bar-shortcut`. `ActionBarSeparator` and `ActionBarShortcut` render nothing on mobile.

`ActionBar` groups several `ActionBarMenu`s, such as File, Edit and View, behind one ghost icon `Button`. Pressing it opens a `Drawer` that lists each menu's trigger as a row with a chevron.

Choosing a row closes the drawer and opens that menu's items in an `AlertSheet`, with a Cancel button appended. Use it for toolbar-style command groups that need to fit on a phone screen.

## Usage

<Code lang="tsx" code={"import { ActionBar, ActionBarMenu, ActionBarTrigger, ActionBarContent, ActionBarLabel, ActionBarItem, ActionBarSeparator } from \"@/components/patterns/action-bar\""} />

<Code lang="tsx" code={"<ActionBar defaultOpen>\n  <FileMenu defaultOpen />\n  <EditMenu />\n  <ViewMenu />\n</ActionBar>"} />

Each child of `ActionBar` should be an `ActionBarMenu` containing one `ActionBarTrigger` and one `ActionBarContent`. The bar renders every child twice, once as a drawer row and once as a sheet, and pairs them by child index.

`open`, `defaultOpen` and `onOpenChange` on `ActionBar` control the drawer. `ActionBarMenu` takes its own `open`, `defaultOpen` and `onOpenChange` for its sheet. A string child of `ActionBarTrigger` is wrapped in `Text`.

## Accessibility

- The More actions button and the drawer are labelled by `moreLabel`.
- Each drawer row has the `button` role and exposes its disabled state.
- The chevron flips in right-to-left layouts.

## Notes

- Rows sit on `bg-surface-secondary` with `border-separator` dividers; disabled rows use `text-label-quaternary`.
- Without `floating`, the drawer's top corners are square.
