`ActionBar` groups several `ActionBarMenu`s, each with a `ActionBarTrigger` and `ActionBarContent`. On desktop it renders a `Menubar`: each menu is a `MenubarMenu`, and hovering another trigger while a menu is open switches menus.

Below the `48rem` breakpoint (`useIsMobile`), the bar collapses into a ghost icon `Button` that opens a `Drawer`. The drawer lists every menu's trigger as a row; choosing a row closes the drawer and opens that menu's items in an `AlertSheet`, with a Cancel button appended. Use it for toolbar-style command groups, such as File, Edit and View, that need to fit on small screens.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/action-bar
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add patterns action-bar
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

## Usage

```tsx
import { ActionBar, ActionBarMenu, ActionBarTrigger, ActionBarContent, ActionBarLabel, ActionBarItem, ActionBarSeparator, ActionBarShortcut } from "@/components/patterns/action-bar"
```

```tsx
<ActionBar>
  <ActionBarMenu>
    <ActionBarTrigger>File</ActionBarTrigger>
    <ActionBarContent>
      <ActionBarItem>
        New tab
        <ActionBarShortcut mod>T</ActionBarShortcut>
      </ActionBarItem>
      <ActionBarSeparator />
      <ActionBarItem>
        Print
        <ActionBarShortcut mod>P</ActionBarShortcut>
      </ActionBarItem>
    </ActionBarContent>
  </ActionBarMenu>
  <ActionBarMenu>
    <ActionBarTrigger>View</ActionBarTrigger>
    <ActionBarContent>
      <ActionBarLabel>Appearance</ActionBarLabel>
      <ActionBarItem>Zoom in</ActionBarItem>
      <ActionBarItem>Zoom out</ActionBarItem>
    </ActionBarContent>
  </ActionBarMenu>
</ActionBar>
```

Each child of `ActionBar` should be an `ActionBarMenu` containing one `ActionBarTrigger` and one `ActionBarContent`; the bar uses the child index to pair the mobile row with its sheet. `open`, `defaultOpen` and `onOpenChange` on `ActionBar` control the mobile More actions drawer only; on desktop they have no effect. `ActionBarMenu` accepts its own `open`, `defaultOpen` and `onOpenChange` for an individual menu, which apply on desktop and to the mobile sheet. Use `ActionBarShortcut` with `mod` to prefix the platform modifier key.

## API Reference

<ApiPart index={1}>

### ActionBar

The root that renders a `Menubar` on desktop and a More actions button with a `Drawer` on mobile.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | - | Controls whether the mobile More actions drawer is open. |
| `defaultOpen` | `boolean` | `false` | Whether the mobile More actions drawer starts open when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | - | Called when the mobile More actions drawer opens or closes. |
| `dismissible` | `boolean` | `true` | When `true`, mobile sheets close on an outside press; when `false`, they use an alert dialog that closes only through an action or Cancel. |
| `floating` | `boolean` | - | Insets the mobile drawer from the screen edges with fully rounded corners. |
| `moreLabel` | `string` | `"More actions"` | Accessible label of the mobile More actions button and title of its drawer. |
| `cancelLabel` | `string` | `"Cancel"` | Text of the Cancel button appended to each mobile sheet. |

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

<ApiPart index={2}>

### ActionBarMenu

One menu in the bar; a `MenubarMenu` on desktop and an `AlertSheet` on mobile.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | - | Whether this menu is open, for controlled use. |
| `defaultOpen` | `boolean` | - | Whether this menu starts open when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | - | Called when this menu opens or closes. |
| `children` | `React.ReactNode` | - | The menu's `ActionBarTrigger` and `ActionBarContent`. |

</ApiPart>

<ApiPart index={3}>

### ActionBarTrigger

The menu's button; a menubar trigger on desktop and a drawer row with a chevron on mobile.

Also accepts the props of `React.ButtonHTMLAttributes<HTMLButtonElement>`.

</ApiPart>

<ApiPart index={4}>

### ActionBarContent

The menu's items; a `MenubarContent` popup on desktop and an `AlertSheetContent` with a Cancel button on mobile.

<OnlyBase base="base radix">

Also accepts `align`, `alignOffset`, `side` and `sideOffset` from `MenubarContent`, which position the desktop popup, and the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `align`, `alignOffset`, `side` and `sideOffset` from `MenubarContent`, which position the desktop popup, and `className`, `children`, `id` and `aria-label`.

</OnlyBase>

</ApiPart>

<ApiPart index={5}>

### ActionBarLabel

A non-interactive heading; a menu label on desktop and the sheet title on mobile.

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children` and `id`.

</OnlyBase>

</ApiPart>

<ApiPart index={6}>

### ActionBarItem

An actionable entry; a `MenubarItem` on desktop and an `AlertSheetAction` on mobile.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "destructive"` | - | Use `destructive` to style the item as a destructive action. |
| `disabled` | `boolean` | - | Prevents the item from being chosen. |

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Respond to the item with `onAction`. Also accepts `className`, `children`, `id` and `aria-label`.

</OnlyBase>

</ApiPart>

<ApiPart index={7}>

### ActionBarSeparator

A divider between item groups, rendered on desktop only.

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`.

</OnlyBase>

</ApiPart>

<ApiPart index={8}>

### ActionBarShortcut

A keyboard shortcut hint aligned to the end of an item, rendered on desktop only.

Also accepts the props of `React.ComponentProps<typeof MenubarShortcut>`.

</ApiPart>

## Accessibility

- On desktop the bar has the `menubar` role and each trigger and item has the `menuitem` role.
- Disabled items expose `aria-disabled="true"`.
- `Escape` closes an open menu and returns focus to its trigger.
- On mobile the More actions button is labelled by `moreLabel`, and each drawer row has `aria-haspopup="dialog"`.

## Notes

Parts carry `data-slot` values such as `action-bar`, `action-bar-menu`, `action-bar-trigger`, `action-bar-content`, `action-bar-item`, `action-bar-more`, `action-bar-label`, `action-bar-separator` and `action-bar-shortcut`. `ActionBarSeparator` and `ActionBarShortcut` render nothing on mobile.

</Only>

## Usage

<Only platform="rn">

```tsx
import { ClipboardTextIcon, CopyIcon, ScissorsIcon, TrashIcon } from "phosphor-react-native"
import { ActionBar, ActionBarContent, ActionBarItem, ActionBarLabel, ActionBarMenu, ActionBarSeparator, ActionBarTrigger } from "@/components/patterns/action-bar"
import { Icon } from "@/components/ui/icon"
import { Text } from "@/components/ui/text"

function FileMenu({ defaultOpen }: { defaultOpen?: boolean }) {
  return (
    <ActionBarMenu defaultOpen={defaultOpen}>
      <ActionBarTrigger>File</ActionBarTrigger>
      <ActionBarContent>
        <ActionBarItem>New tab</ActionBarItem>
        <ActionBarItem>New window</ActionBarItem>
        <ActionBarItem disabled>New incognito window</ActionBarItem>
        <ActionBarSeparator />
        <ActionBarItem>Print</ActionBarItem>
      </ActionBarContent>
    </ActionBarMenu>
  )
}

function EditMenu({ withIcons = false }: { withIcons?: boolean }) {
  return (
    <ActionBarMenu>
      <ActionBarTrigger>Edit</ActionBarTrigger>
      <ActionBarContent>
        <ActionBarItem>
          {withIcons ? <Icon as={ScissorsIcon} /> : null}
          <Text>Cut</Text>
        </ActionBarItem>
        <ActionBarItem>
          {withIcons ? <Icon as={CopyIcon} /> : null}
          <Text>Copy</Text>
        </ActionBarItem>
        <ActionBarItem>
          {withIcons ? <Icon as={ClipboardTextIcon} /> : null}
          <Text>Paste</Text>
        </ActionBarItem>
        <ActionBarSeparator />
        <ActionBarItem variant="destructive">
          {withIcons ? <Icon as={TrashIcon} /> : null}
          <Text>Delete</Text>
        </ActionBarItem>
      </ActionBarContent>
    </ActionBarMenu>
  )
}

function ViewMenu() {
  return (
    <ActionBarMenu>
      <ActionBarTrigger>View</ActionBarTrigger>
      <ActionBarContent>
        <ActionBarLabel>Appearance</ActionBarLabel>
        <ActionBarItem>Zoom in</ActionBarItem>
        <ActionBarItem>Zoom out</ActionBarItem>
        <ActionBarItem>Actual size</ActionBarItem>
      </ActionBarContent>
    </ActionBarMenu>
  )
}

export function ActionBarExample() {
  return (
    <ActionBar>
      <FileMenu />
      <EditMenu />
      <ViewMenu />
    </ActionBar>
  )
}
```

```swift
    ActionBarDemo {
      ActionBarFileMenu()

struct ActionBarDemo<Content: View>: View {
  var dismissible = true
  var moreLabel: LocalizedStringKey = "More actions"
  var cancelLabel: LocalizedStringKey = "Cancel"
  let content: Content

  @State private var open: Bool

  init(
    open: Bool = false,
    dismissible: Bool = true,
    moreLabel: LocalizedStringKey = "More actions",
    cancelLabel: LocalizedStringKey = "Cancel",
    @ViewBuilder content: () -> Content
  ) {
    _open = State(initialValue: open)
    self.dismissible = dismissible
    self.moreLabel = moreLabel
    self.cancelLabel = cancelLabel
    self.content = content()
  }

  var body: some View {
    ActionBar(isPresented: $open, dismissible: dismissible, moreLabel: moreLabel, cancelLabel: cancelLabel) {
      content
    }
  }
}

struct ActionBarFileMenu: View {
  var isPresented: Binding<Bool>?

  var body: some View {

      ActionBarItem("New tab") {}
      ActionBarItem("New window") {}
      ActionBarItem("New incognito window") {}.disabled(true)
      ActionBarSeparator()
      ActionBarItem("Print") {}
    }
  }
}
```

```kotlin
fun ActionBarDemo(
    defaultOpen: Boolean = false,
    fileOpen: Boolean = false,
    withIcons: Boolean = false,
    view: Boolean = true,
    dismissible: Boolean = true,
    floating: Boolean = false,
    moreLabel: String = "More actions",

        onOpenChange = { open = it },

        floating = floating,
        moreLabel = moreLabel,

        actionBarEditMenu(withIcons)
```

## Accessibility

- The More actions button and the drawer are labelled by `moreLabel`.
- Each drawer row has the `button` role and exposes its disabled state.
- The chevron flips in right-to-left layouts.

## Notes

- Rows sit on `bg-muted` with `border-border` dividers; disabled rows use `opacity-50`.
- Without `floating`, the drawer's top corners are square.
