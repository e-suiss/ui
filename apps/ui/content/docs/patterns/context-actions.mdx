`ContextActions` attaches a set of actions to an area of the page. On desktop it renders a `ContextMenu` that opens at the pointer on right click. Below the `48rem` breakpoint it renders an `AlertSheet` instead, opened by a 500 ms long press on touch, by the context menu event, or by the `ContextMenu` key or `Shift+F10`; the sheet groups the items in a card and appends a Cancel button.

Use it for secondary actions on content such as photos, files or list rows, where actions should stay out of the way until requested.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/context-actions
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add patterns context-actions
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install @base-ui/react
```

2. Add the pieces it builds on: [Alert Sheet](/docs/components/alert-sheet), [Context Menu](/docs/components/context-menu), `use-mobile`.

3. Copy the source into `components/patterns/context-actions.tsx`:

4. Update the import paths to match your project.

## Usage

```tsx
import { ContextActions, ContextActionsTrigger, ContextActionsContent, ContextActionsLabel, ContextActionsItem, ContextActionsSeparator } from "@/components/patterns/context-actions"
```

```tsx
<div className="flex min-h-svh items-center justify-center p-4">
  <ContextActions>
    <ContextActionsTrigger className="flex h-40 w-72 items-center justify-center rounded-2xl border border-dashed text-sm text-muted-foreground">
      Right click or long press
    </ContextActionsTrigger>
    <ContextActionsContent>
      <ContextActionsLabel>Photo.jpg</ContextActionsLabel>
      <ContextActionsItem>Edit</ContextActionsItem>
      <ContextActionsItem>Duplicate</ContextActionsItem>
      <ContextActionsItem>Share</ContextActionsItem>
      <ContextActionsSeparator />
      <ContextActionsItem variant="destructive">Delete</ContextActionsItem>
    </ContextActionsContent>
  </ContextActions>
</div>
```

Wrap the target area in `ContextActionsTrigger` and list the actions in `ContextActionsContent`. The open state is internal; use `onOpenChange` to react to it. A long press is cancelled if the finger moves more than 10 pixels, so scrolling over the trigger does not open the sheet.

The root that renders a `ContextMenu` on desktop and an `AlertSheet` on mobile.

| Prop | Type | Default | Description |

## Accessibility

- On desktop the popup has the `menu` role and receives focus when opened; arrow keys move between `menuitem`s and `Enter` runs the focused one.
- `Escape` closes the menu.
- On mobile the trigger has `role="button"`, `tabIndex={0}` and `aria-haspopup="dialog"`, and opens with the `ContextMenu` key or `Shift+F10`.

## Notes

Parts carry `data-slot` values `context-actions`, `context-actions-trigger`, `context-actions-content`, `context-actions-label`, `context-actions-item` and `context-actions-separator`. On mobile the trigger disables text selection and the iOS touch callout so a long press does not select text.

## Usage

```tsx
import { ContextActions, ContextActionsTrigger, ContextActionsContent, ContextActionsLabel, ContextActionsItem, ContextActionsSeparator } from "@/components/patterns/context-actions"
```

```tsx
<ContextActions>
  <ContextActionsTrigger
    accessibilityLabel="Photo"
    className="h-40 items-center justify-center gap-2 rounded-2xl bg-muted active:opacity-80"
  >
    <Icon as={ImageIcon} className="size-8 text-muted-foreground" />
    <Text className="text-sm text-muted-foreground">Long press</Text>
  </ContextActionsTrigger>
  <ContextActionsContent>
    <ContextActionsLabel>Photo</ContextActionsLabel>
    <ContextActionsItem>Copy</ContextActionsItem>
    <ContextActionsItem>Share</ContextActionsItem>
    <ContextActionsItem variant="destructive">Delete</ContextActionsItem>
  </ContextActionsContent>
</ContextActions>
```

Wrap the target in `ContextActionsTrigger` and list `ContextActionsItem`s in `ContextActionsContent`. Add a `ContextActionsLabel` first to show a title.

The open state is managed internally; use `onOpenChange` to react to it. `ContextActionsTrigger` accepts every `Pressable` prop, so `onPress` still works for a normal tap, and your own `onLongPress` runs before the sheet opens. Change the hold time with `delayLongPress`.

## Accessibility

- The trigger has the hint "Long press for actions".
- It adds `longpress` and `showActions` ("Show actions") accessibility actions, so screen reader users can open the sheet without holding.
- Your own `accessibilityActions` and `onAccessibilityAction` are kept.

## Notes

- Item text uses `text-primary`, or `text-destructive` for the `destructive` variant.
- On iOS the sheet renders in a full-window overlay so it appears above native screens.
