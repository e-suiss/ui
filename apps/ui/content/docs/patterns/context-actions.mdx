`ContextActions` attaches a set of actions to an area of the page. On desktop it renders a `ContextMenu` that opens at the pointer on right click. Below the `48rem` breakpoint it renders an `AlertSheet` instead, opened by a long press.

Use it for secondary actions on content such as photos, files or list rows, where actions should stay out of the way until requested.

## Usage

```tsx
import {
  ContextActions,
  ContextActionsContent,
  ContextActionsItem,
  ContextActionsLabel,
  ContextActionsSeparator,
  ContextActionsTrigger,
} from "@/components/patterns/context-actions"
```

```tsx
<div className="flex min-h-svh items-center justify-center p-4">
  <ContextActions>
    <ContextActionsTrigger className="flex h-40 w-72 items-center justify-center rounded-2xl border border-dashed text-sm text-muted-foreground">
      Right click or long press
    </ContextActionsTrigger>
    <ContextActionsContent>
      <ContextActionsLabel>Photo.jpg</ContextActionsLabel>
      <ContextActionsItem>Edit</ContextActionsItem>
      <ContextActionsItem>Duplicate</ContextActionsItem>
      <ContextActionsItem>Share</ContextActionsItem>
      <ContextActionsSeparator />
      <ContextActionsItem variant="destructive">Delete</ContextActionsItem>
    </ContextActionsContent>
  </ContextActions>
</div>
```

## Composition

Use the following composition to build a `ContextActions`:

```text
ContextActions
├── ContextActionsTrigger
└── ContextActionsContent
    ├── ContextActionsLabel
    ├── ContextActionsItem
    └── ContextActionsSeparator
```

## Accessibility

- On desktop the popup has the `menu` role and receives focus when opened; arrow keys move between `menuitem`s and `Enter` runs the focused one.
- `Escape` closes the menu.
- On mobile the trigger has `role="button"`, `tabIndex={0}` and `aria-haspopup="dialog"`, and opens with the `ContextMenu` key or `Shift+F10`.

## API Reference

### ContextActions

The root that renders a `ContextMenu` on desktop and an `AlertSheet` on mobile.

| Prop | Type | Default |
| --- | --- | --- |
| `onOpenChange` | `(open: boolean) => void` | - |
| `dismissible` | `boolean` | `true` |
| `children` | `React.ReactNode` | - |

The open state is internal; use `onOpenChange` to react to it.

### ContextActionsTrigger

The area that opens the actions on right click, or on long press and keyboard on mobile.

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

Wrap the target area in it. On mobile it opens the sheet on a 500 ms long press on touch, on the context menu event, or on the `ContextMenu` key or `Shift+F10`. A long press is cancelled if the finger moves more than 10 pixels, so scrolling over the trigger does not open the sheet. The trigger also disables text selection and the iOS touch callout so a long press does not select text.

### ContextActionsContent

The popup holding the actions; on mobile it adds a Cancel button below them.

| Prop | Type | Default |
| --- | --- | --- |
| `cancelLabel` | `string` | `"Cancel"` |

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children`, `id` and `aria-label`.

</OnlyBase>

On mobile the sheet groups the items in a card and appends a Cancel button labelled by `cancelLabel`.

### ContextActionsLabel

A non-interactive heading; a menu label on desktop and the sheet title on mobile.

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children` and `id`.

</OnlyBase>

### ContextActionsItem

An actionable entry that closes the actions when chosen.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "destructive"` | - |
| `disabled` | `boolean` | - |

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Respond to the item with `onAction`. Also accepts `className`, `children`, `id` and `aria-label`.

</OnlyBase>

### ContextActionsSeparator

A divider between groups of items, rendered on desktop only.

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`.

</OnlyBase>

Each part sets a `data-slot`, such as `context-actions-trigger` or `context-actions-item`, for styling.

</Only>

@Composable
fun ContextActionsDefault() {
    val colors = EsuissTheme.colors
    val shape = RoundedCornerShape(Radius.xl2)
    ContextActions {

                .height(160.dp)
                .clip(shape)
                .background(colors.muted, shape),
            label = "Photo",

            Column(

                Text("Long press", style = Typography.sm.copy(color = colors.mutedForeground))
            }
        }
        ContextActionsContent {
            ContextActionsLabel("Photo")
            ContextActionsItem("Copy", onClick = {})
            ContextActionsItem("Share", onClick = {})
            ContextActionsItem("Delete", onClick = {}, variant = MenuItemVariant.Destructive)
        }
    }
}

## Accessibility

- The trigger has the hint "Long press for actions".
- It adds `longpress` and `showActions` ("Show actions") accessibility actions, so screen reader users can open the sheet without holding.
- Your own `accessibilityActions` and `onAccessibilityAction` are kept.

## API Reference

<Only platform="rn">

### ContextActions

The root that owns the open state.

| Prop | Type | Default |
| --- | --- | --- |
| `onOpenChange` | `(open: boolean) => void` | - |
| `dismissible` | `boolean` | `true` |
| `children` | `React.ReactNode` | - |

The open state is managed internally; use `onOpenChange` to react to it. Set `dismissible` to `false` so the sheet ignores outside presses.

### ContextActionsTrigger

A `Pressable` that opens the sheet on long press.

Also accepts the props of `React.ComponentProps<typeof Pressable>`.

Wrap the target in it. `onPress` still works for a normal tap, and your own `onLongPress` runs before the sheet opens. Change the hold time with `delayLongPress`.

### ContextActionsContent

The sheet with the grouped items and a Cancel button.

| Prop | Type | Default |
| --- | --- | --- |
| `cancelLabel` | `string` | `"Cancel"` |

Also accepts the props of `React.ComponentProps<typeof AlertSheetContent>`.

List `ContextActionsItem`s in it, with a `ContextActionsLabel` first to show a title. On iOS the sheet renders in a full-window overlay so it appears above native screens.

### ContextActionsLabel

A title shown at the top of the group.

Also accepts the props of `React.ComponentProps<typeof AlertSheetTitle>`.

### ContextActionsItem

An actionable entry, rendered as an `AlertSheetAction`.

Also accepts the props of `React.ComponentProps<typeof AlertSheetAction>`.

### ContextActionsSeparator

Kept for API parity; renders nothing.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |
