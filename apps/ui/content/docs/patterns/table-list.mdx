`TableList` displays rows of data from a column definition. On desktop it renders a suiss/ui `Table` inside a bordered section, with a header row and one cell per column. On mobile (below `48rem`, via `useIsMobile`), where wide tables do not fit, it renders an inset grouped list: each row shows a title line, a secondary line that joins description columns with a middle dot, and trailing values on the end.

Each column chooses its place in the mobile row through `slot`, and can provide a simpler `mobileCell`. Use it for orders, invoices, transactions and other records that people compare in columns on large screens.

## Usage

```tsx
import { TableList, type TableListColumn } from "@/components/patterns/table-list"
```

```tsx
type Order = { id: number; product: string; total: string }

const orders: Order[] = [
  { id: 1042, product: "Wireless earbuds", total: "$249.00" },
  { id: 1041, product: "Magnetic charger", total: "$49.00" },
]

const columns: TableListColumn<Order>[] = [
  { key: "product", header: "Product", cell: (order) => order.product, slot: "title" },
  { key: "id", header: "Order", cell: (order) => `#${order.id}`, slot: "description" },
  { key: "total", header: "Total", cell: (order) => order.total, slot: "trailing", align: "end" },
]

<TableList rows={orders} columns={columns} getKey={(order) => order.id} title="Orders" />
```

- Each `TableListColumn` has a `key`, a `header` and a `cell` renderer. Optional fields are `mobileCell`, `slot` (`title`, `description`, `trailing` or `hidden`) and `align` (`start` or `end`).
- On mobile, the first `title` column becomes the primary line, `description` columns form the secondary line, and `trailing` columns appear at the end. Columns without a slot, or with `hidden`, are left out on mobile.
- `mobileCell` replaces `cell` on mobile, for example to drop styling that does not fit the list.
- `align: "end"` right-aligns the desktop header and cells.

## API Reference

<ApiPart index={1}>

### TableList

The section that renders the rows as a table or a grouped list.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `rows` | `T[]` | Required | The data rows to display. |
| `columns` | `TableListColumn<T>[]` | Required | The column definitions that render each row. |
| `getKey` | `(row: T, index: number) => React.Key` | `(_, index) => index` | Returns the React key for a row. |
| `title` | `React.ReactNode` | - | A heading above the data that also names the section. |
| `emptyText` | `React.ReactNode` | `"No results."` | Content shown when `rows` is empty. |

Also accepts the props of `React.ComponentProps<"section">`.

</ApiPart>

## Accessibility

- With a `title`, the section is labelled by its heading and exposed as a region.
- On desktop the data is a real table with column headers; an empty state is a single cell that spans every column.
- On mobile the rows are list items in a `ul`.

## Notes

Styling hooks: `data-slot="table-list"` and `table-list-title`; on mobile also `table-list-items` and `table-list-item`. The `TableListColumn` type is exported.

```kotlin
import androidx.compose.foundation.layout.Arrangement
import androidx.compose.foundation.layout.Column
import androidx.compose.runtime.Composable
import androidx.compose.ui.unit.dp
import com.esuiss.ui.components.Text
import com.esuiss.ui.patterns.TableList
import com.esuiss.ui.patterns.TableListAlign
import com.esuiss.ui.patterns.TableListColumn
import com.esuiss.ui.patterns.TableListSlot

class TableListInvoice(
    val id: String,
    val customer: String,
    val status: String,
    val method: String,
    val amount: String,
)

val tableListInvoices = listOf(
    TableListInvoice("INV001", "Olivia Martin", "Paid", "Card", "$250.00"),
    TableListInvoice("INV002", "Jackson Lee", "Pending", "PayPal", "$150.00"),
    TableListInvoice("INV003", "Isabella Nguyen", "Unpaid", "Transfer", "$350.00"),
    TableListInvoice("INV004", "William Kim", "Paid", "Card", "$450.00"),
)

val tableListColumns = listOf(
    TableListColumn<TableListInvoice>("customer", "Customer", slot = TableListSlot.Title) { Text(it.customer, maxLines = 1) },
    TableListColumn<TableListInvoice>("status", "Status", slot = TableListSlot.Description) { Text(it.status, maxLines = 1) },
    TableListColumn<TableListInvoice>("method", "Method", slot = TableListSlot.Description) { Text(it.method, maxLines = 1) },
    TableListColumn<TableListInvoice>("amount", "Amount", slot = TableListSlot.Trailing, align = TableListAlign.End) {
        Text(it.amount, maxLines = 1)
    },
)

@Composable
fun TableListDefault() {
    Column(verticalArrangement = Arrangement.spacedBy(32.dp)) {
        TableList(
            rows = tableListInvoices,
            columns = tableListColumns,
            getKey = { row, _ -> row.id },
            title = "Invoices",
            onRowClick = {},
        )
        TableList(rows = emptyList(), columns = tableListColumns, emptyText = "No invoices yet.")
    }
}
```

</Only>

<Only platform="rn">

Define columns with `key`, `header`, `cell` and `slot`. Several `description` columns are joined with ` · `, and several `trailing` columns are shown side by side. Use `mobileCell` to render a different value than `cell` in the list, such as a shorter date.

Pass `onRowPress` to make rows pressable. When there are no rows, `emptyText` is shown in the group. The `TableListColumn` type is exported.

With a `FlatList`, use `TableListRow` as the item, pass `first` and `last` to round the ends, `TableListSeparator` as `ItemSeparatorComponent`, and `TableListHeader` and `TableListFooter` around the list.

</Only>

## Accessibility

- The group has the `list` role; rows have the `listitem` role, or `button` when `onRowPress` is set.
- `TableListTitle` and `TableListHeader` have the `heading` role.
- Separators are hidden from screen readers.

## Notes

- Rows use `bg-muted` and `opacity-80` when pressed.
- The `header` and `align` column fields are not rendered by the list layout.
