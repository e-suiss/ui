`SearchPicker` lets the user find and choose one item from a long list. On desktop it renders a suiss/ui `Combobox`: the field itself is the search input, and the list filters as the user types. On mobile (below `48rem`, via `useIsMobile`) it renders a field-style button that opens a `Drawer` with a swipe handle and a searchable `Command` menu. Choosing an item closes the drawer.

Use it for countries, cities, users and other lists too long to scan; for short lists, use `Picker`.

## Accessibility

- On desktop the field has the `combobox` role and controls a `listbox`. The selected option has `aria-selected`, disabled options have `aria-disabled`, and groups are exposed as `group` elements named by their heading.
- Escape closes the desktop list.
- On mobile, the drawer is titled by `title`, `placeholder` or `aria-label`, and focus moves to the search input when it opens.

## API Reference

### SearchPicker

The complete searchable picker, rendered from the `items` array.

| Prop | Type | Default |
| --- | --- | --- |
| `items` | `SearchPickerItem[]` | Required |
| `value` | `string \| null` | - |
| `defaultValue` | `string \| null` | - |
| `onValueChange` | `(value: string \| null) => void` | - |
| `placeholder` | `string` | - |
| `searchPlaceholder` | `string` | `"Search..."` |
| `emptyText` | `string` | `"No results found."` |
| `title` | `string` | - |
| `disabled` | `boolean` | - |
| `floating` | `boolean` | - |
| `showCloseButton` | `boolean` | `false` |
| `closeLabel` | `string` | - |
| `id` | `string` | - |
| `className` | `string` | - |
| `aria-invalid` | `boolean` | - |
| `aria-label` | `string` | - |
| `aria-describedby` | `string` | - |

Each item in `items` has a `value`, a `label`, and an optional `group` and `disabled` flag; the `SearchPickerItem` type is exported. The value is uncontrolled by default; use `defaultValue`, or `value` with `onValueChange` to control it. The value is `null` when nothing is selected.

`searchPlaceholder`, `title`, `floating`, `showCloseButton` and `closeLabel` affect only the mobile drawer. On desktop the field itself is the search input and shows `placeholder`. Mobile search matches against each item's label. `id` and `className` go to the input on desktop and to the trigger button on mobile.

The parts set `data-slot="search-picker"`, `search-picker-trigger` (mobile) and `search-picker-content` for styling. The mobile trigger has `data-placeholder` while nothing is selected, and the selected command item has `data-checked`.

`SearchPicker` renders a field-style `DrawerTrigger` with the selected label and an up-down caret. Pressing it opens a `Drawer` with a search input and a scrollable list of options.

Typing filters options by label, case-insensitively. Options with a `group` are shown under a group heading. Choosing an option selects it, closes the drawer and clears the search. Use it when the list is too long to scan, such as countries, cities or frameworks.

```swift
import SwiftUI

@MainActor let searchPickerFrameworks = [
  SearchPickerItem(value: "next", label: "Next.js"),
  SearchPickerItem(value: "remix", label: "Remix"),
  SearchPickerItem(value: "astro", label: "Astro"),
  SearchPickerItem(value: "sveltekit", label: "SvelteKit"),
  SearchPickerItem(value: "nuxt", label: "Nuxt"),
  SearchPickerItem(value: "gatsby", label: "Gatsby", disabled: true),
]

struct SearchPickerDemo: View {
  var items = searchPickerFrameworks
  var placeholder: LocalizedStringKey = "Select a framework"
  var searchPlaceholder: LocalizedStringKey = "Search frameworks..."
  var emptyText: LocalizedStringKey = "No framework found."
  var label: LocalizedStringKey = "Framework"
  var title: LocalizedStringKey?
  var showCloseButton = false
  var closeLabel: LocalizedStringKey?

  @State private var value: String?

  init(
    value: String? = nil,
    items: [SearchPickerItem] = searchPickerFrameworks,
    placeholder: LocalizedStringKey = "Select a framework",
    searchPlaceholder: LocalizedStringKey = "Search frameworks...",
    emptyText: LocalizedStringKey = "No framework found.",
    label: LocalizedStringKey = "Framework",
    title: LocalizedStringKey? = nil,
    showCloseButton: Bool = false,
    closeLabel: LocalizedStringKey? = nil
  ) {
    _value = State(initialValue: value)
    self.items = items
    self.placeholder = placeholder
    self.searchPlaceholder = searchPlaceholder
    self.emptyText = emptyText
    self.label = label
    self.title = title
    self.showCloseButton = showCloseButton
    self.closeLabel = closeLabel
  }

  var body: some View {
    SearchPicker(
      items: items,
      selection: $value,
      placeholder: placeholder,
      searchPlaceholder: searchPlaceholder,
      emptyText: emptyText,
      title: title,
      showCloseButton: showCloseButton,
      closeLabel: closeLabel
    )
    .frame(width: 224)
    .accessibilityLabel(Text(label))
  }
}
```

import androidx.compose.ui.unit.dp
import com.esuiss.ui.patterns.SearchPicker

val searchPickerFrameworks = listOf(
    SearchPickerItem("next", "Next.js"),
    SearchPickerItem("remix", "Remix"),
    SearchPickerItem("astro", "Astro"),
    SearchPickerItem("sveltekit", "SvelteKit"),
    SearchPickerItem("nuxt", "Nuxt"),
    SearchPickerItem("gatsby", "Gatsby", enabled = false),
)

@Composable
fun SearchPickerDemo(
    initial: String? = null,
    items: List<SearchPickerItem> = searchPickerFrameworks,
    placeholder: String = "Select a framework",
    searchPlaceholder: String = "Search frameworks...",
    emptyText: String = "No framework found.",

    enabled: Boolean = true,
    invalid: Boolean? = null,
    floating: Boolean = false,
    showCloseButton: Boolean = false,

        items = items,
        value = value,
        onValueChange = { value = it },
        modifier = Modifier.width(224.dp).semantics { contentDescription = label },
        placeholder = placeholder,
        searchPlaceholder = searchPlaceholder,
        emptyText = emptyText,
        title = title,
        enabled = enabled,
        invalid = invalid,
        floating = floating,
        showCloseButton = showCloseButton,
        closeLabel = closeLabel,
    )
}

Pass `items` as an array of `{ value, label, group?, disabled? }`; the `SearchPickerItem` type is exported. Use it uncontrolled with `defaultValue`, or controlled with `value` and `onValueChange`; the value is a string or `null`. `emptyText` shows when nothing matches.

`searchPlaceholder` is also the label of the search input, which disables autocorrect and autocapitalization. The list stays between 40% and 60% of the window height, and taps work while the keyboard is open.
