`SearchPicker` lets the user find and choose one item from a long list. On desktop it renders a suiss/ui `Combobox`: the field itself is the search input, and the list filters as the user types. On mobile (below `48rem`, via `useIsMobile`) it renders a field-style button that shows the selected label. Tapping it opens a `Drawer` with a swipe handle and a `Command` menu whose search input receives focus. Choosing an item closes the drawer.

Items are passed as data. When any item has a `group`, items are listed under group headings in both presentations. Use it for countries, cities, users and other lists too long to scan; for short lists, use `Picker`.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/search-picker
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the suiss/ui CLI:

```bash title="Terminal"
npx @esuiss/ui@latest add patterns search-picker
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"

```

2. Add the pieces it builds on: [Combobox](/docs/components/combobox), [Command](/docs/components/command), [Drawer](/docs/components/drawer), `use-mobile`.

## Usage

```tsx
import { SearchPicker } from "@/components/patterns/search-picker"
```

```tsx
<SearchPicker items={frameworks} placeholder="Select a framework" searchPlaceholder="Search frameworks..." emptyText="No framework found." aria-label="Framework" className="w-56" />
```

- Each item in `items` has a `value`, a `label`, and an optional `group` and `disabled` flag. The `SearchPickerItem` type is exported.
- The value is uncontrolled by default; use `defaultValue`, or `value` with `onValueChange` to control it. The value is `null` when nothing is selected.
- `searchPlaceholder`, `title`, `floating`, `showCloseButton` and `closeLabel` affect only the mobile drawer. On desktop the field shows `placeholder`.
- Mobile search matches against each item's label.

## API Reference

<ApiPart index={1}>

### SearchPicker

The complete searchable picker, rendered from the `items` array.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `SearchPickerItem[]` | Required | The items to choose from, each with a `value`, `label`, and optional `group` and `disabled`. |
| `value` | `string \| null` | - | The selected value when controlled, or `null` for no selection. |
| `defaultValue` | `string \| null` | - | The initially selected value when uncontrolled. |
| `onValueChange` | `(value: string \| null) => void` | - | Called with the new value, or `null`, when the selection changes. |
| `placeholder` | `string` | - | Text shown when nothing is selected. |
| `searchPlaceholder` | `string` | `"Search..."` | Placeholder of the search input in the mobile drawer. |
| `emptyText` | `string` | `"No results found."` | Text shown when no item matches the search. |
| `title` | `string` | - | A visible heading for the mobile drawer. When omitted, the drawer title is visually hidden and falls back to `placeholder` or `aria-label`. |
| `disabled` | `boolean` | - | Disables the field. |
| `floating` | `boolean` | - | Insets the mobile drawer from the screen edges. |
| `showCloseButton` | `boolean` | `false` | Shows a close button in the mobile drawer. |
| `closeLabel` | `string` | - | Text for the mobile close button in place of the icon. |
| `id` | `string` | - | The ID of the input on desktop or the trigger button on mobile. |
| `className` | `string` | - | Classes applied to the input on desktop or the trigger button on mobile. |
| `aria-invalid` | `boolean` | - | Marks the field as invalid and applies the error style. |
| `aria-label` | `string` | - | The accessible name of the field. |
| `aria-describedby` | `string` | - | The ID of an element that describes the field. |

</ApiPart>

## Accessibility

- On desktop the field has the `combobox` role and controls a `listbox`. The selected option has `aria-selected`, disabled options have `aria-disabled`, and groups are exposed as `group` elements named by their heading.
- Escape closes the desktop list.
- On mobile, the drawer is titled by `title`, `placeholder` or `aria-label`, and focus moves to the search input when it opens.

## Notes

Styling hooks: `data-slot="search-picker"`, `search-picker-trigger` (mobile) and `search-picker-content`. The mobile trigger has `data-placeholder` while nothing is selected, and the selected command item has `data-checked`.

`SearchPicker` renders a field-style `DrawerTrigger` with the selected label and an up-down caret. Pressing it opens a `Drawer` with a search input and a scrollable list of options.

Typing filters options by label, case-insensitively. Options with a `group` are shown under a group heading. Choosing an option selects it, closes the drawer and clears the search. Use it when the list is too long to scan, such as countries, cities or frameworks.

<SearchPicker items={frameworks} placeholder="Select a framework" searchPlaceholder="Search frameworks..." emptyText="No framework found." accessibilityLabel="Framework" className="w-56" />

Use it uncontrolled with `defaultValue`, or controlled with `value` and `onValueChange`; the value is a string or `null`. `emptyText` shows when nothing matches.

| `floating` | `boolean` | - | Insets the drawer from the screen edges. |

| `className` | `string` | - |  |
| `accessibilityLabel` | `string` | - | Label for the field. |

## Accessibility

- Each option is a button that exposes `selected` and `disabled` states.
- Each group has the `group` role and is labelled by its name.
- The search input is labelled by `searchPlaceholder`.
- Without a `title`, the drawer is labelled by the placeholder or `accessibilityLabel`.

## Notes

- The list stays between 40% and 60% of the window height, and taps work while the keyboard is open.
- The field uses `bg-secondary`, `border-destructive` with a `bg-destructive` tint when invalid, and `opacity-50` when disabled; the tint is stronger in dark mode.
- The search input disables autocorrect and autocapitalization.
