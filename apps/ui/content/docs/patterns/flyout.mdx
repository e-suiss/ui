`Flyout` shows supplementary content, such as a small form or a share link, next to the control that opened it. On desktop it renders a `Popover` positioned against the trigger. Below the `48rem` breakpoint it renders a bottom `Drawer` with a swipe handle, and each part switches to its drawer counterpart: `FlyoutHeader`, `FlyoutTitle` and `FlyoutDescription` map to the drawer's header, title and description, and `FlyoutBody` gains padding.

Use it for quick settings or filters that do not need a full modal.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/flyout
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add patterns flyout
```

### Manual

1. Install the dependencies and add the [`cn` helper](/docs/installation#the-cn-helper):

```bash title="Terminal"
npm install @base-ui/react
```

2. Add the pieces it builds on: [Drawer](/docs/components/drawer), [Popover](/docs/components/popover), `use-mobile`.

3. Copy the source into `components/patterns/flyout.tsx`:

<ComponentSource path="components/patterns/flyout.tsx" />

4. Update the import paths to match your project.

## Usage

```tsx
import { Flyout, FlyoutTrigger, FlyoutContent, FlyoutHeader, FlyoutTitle, FlyoutDescription, FlyoutBody, FlyoutClose } from "@/components/patterns/flyout"
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"
```

<OnlyBase base="base aria">

```tsx
<div className="flex min-h-svh items-center justify-center">
  <Flyout>
    <FlyoutTrigger render={<Button variant="outline" />}>
      Dimensions
    </FlyoutTrigger>
    <FlyoutContent>
      <FlyoutHeader>
        <FlyoutTitle>Dimensions</FlyoutTitle>
        <FlyoutDescription>
          Set the dimensions for the layer.
        </FlyoutDescription>
      </FlyoutHeader>
      <FlyoutBody className="grid gap-3">
        <div className="grid grid-cols-3 items-center gap-3">
          <Label htmlFor="flyout-width">Width</Label>
          <Input
            id="flyout-width"
            defaultValue="100%"
            className="col-span-2"
          />
        </div>
        <div className="grid grid-cols-3 items-center gap-3">
          <Label htmlFor="flyout-height">Height</Label>
          <Input
            id="flyout-height"
            defaultValue="25px"
            className="col-span-2"
          />
        </div>
      </FlyoutBody>
    </FlyoutContent>
  </Flyout>
</div>
```

The flyout is uncontrolled with `defaultOpen`, or controlled with `open` and `onOpenChange`. `align`, `alignOffset`, `side` and `sideOffset` on `FlyoutContent` position the desktop popover and are ignored on mobile. Put interactive content in `FlyoutBody`, and use `FlyoutClose` for a button that closes the flyout after an action.

### Flyout

The root that renders a `Popover` on desktop and a `Drawer` on mobile.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | - | Whether the flyout is open, for controlled use. |
| `defaultOpen` | `boolean` | - | Whether the flyout starts open when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | - | Called when the flyout opens or closes. |
| `floating` | `boolean` | - | Insets the mobile drawer from the screen edges with fully rounded corners. |
| `children` | `React.ReactNode` | - | The trigger and content. |

</ApiPart>

<ApiPart index={2}>

### FlyoutTrigger

The button that opens the flyout.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `render` | `React.ReactElement` | - | Replaces the default button element with your own element, such as a `Button`. |

<OnlyBase base="base radix">

Also accepts the props of `React.ButtonHTMLAttributes<HTMLButtonElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children`, `id` and `aria-label`.

</OnlyBase>

<OnlyBase base="radix">

On the `radix` base, set `asChild` and pass your element as the child instead of `render`.

</OnlyBase>

</ApiPart>

<ApiPart index={3}>

### FlyoutContent

The popup; a `PopoverContent` on desktop and a `DrawerContent` on mobile.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `showCloseButton` | `boolean` | - | Shows a close button in the mobile drawer. |
| `closeLabel` | `string` | - | Replaces the drawer's close icon with this text; requires `showCloseButton`. |

## Accessibility

- The popup has the `dialog` role, named by `FlyoutTitle` and described by `FlyoutDescription`.
- Opening moves focus into the flyout.
- `Escape` closes it and returns focus to the trigger; pressing outside also closes it.

## Notes

Parts carry `data-slot` values from `flyout` through `flyout-close`. `showCloseButton` and `closeLabel` only affect the mobile drawer; on desktop, add a `FlyoutClose` if the popover needs an explicit close control.
