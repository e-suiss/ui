`Flyout` shows supplementary content, such as a small form or a share link, next to the control that opened it. On desktop it renders a `Popover` positioned against the trigger. Below the `48rem` breakpoint it renders a bottom `Drawer` with a swipe handle, and each part switches to its drawer counterpart.

Use it for quick settings or filters that do not need a full modal.

## Usage

```tsx
import {
  Flyout,
  FlyoutBody,
  FlyoutClose,
  FlyoutContent,
  FlyoutDescription,
  FlyoutHeader,
  FlyoutTitle,
  FlyoutTrigger,
} from "@/components/patterns/flyout"
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"
```

<OnlyBase base="base aria">

```tsx
<div className="flex min-h-svh items-center justify-center">
  <Flyout>
    <FlyoutTrigger render={<Button variant="outline" />}>
      Dimensions
    </FlyoutTrigger>
    <FlyoutContent>
      <FlyoutHeader>
        <FlyoutTitle>Dimensions</FlyoutTitle>
```

## Composition

Use the following composition to build a `Flyout`:

```text
Flyout
├── FlyoutTrigger
└── FlyoutContent
    ├── FlyoutHeader
    │   ├── FlyoutTitle
    │   └── FlyoutDescription
    └── FlyoutBody
        └── FlyoutClose
```

## Accessibility

- The popup has the `dialog` role, named by `FlyoutTitle` and described by `FlyoutDescription`.
- Opening moves focus into the flyout.
- `Escape` closes it and returns focus to the trigger; pressing outside also closes it.

## API Reference

### Flyout

The root that renders a `Popover` on desktop and a `Drawer` on mobile.

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | - |
| `onOpenChange` | `(open: boolean) => void` | - |
| `floating` | `boolean` | - |
| `children` | `React.ReactNode` | - |

The flyout is uncontrolled with `defaultOpen`, or controlled with `open` and `onOpenChange`.

### FlyoutTrigger

The button that opens the flyout.

<OnlyBase base="base aria">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `React.ReactElement` | - |

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | - |

</OnlyBase>

<OnlyBase base="base radix">

Also accepts the props of `React.ButtonHTMLAttributes<HTMLButtonElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children`, `id` and `aria-label`.

</OnlyBase>

### FlyoutContent

The popup; a `PopoverContent` on desktop and a `DrawerContent` on mobile.

| Prop | Type | Default |
| --- | --- | --- |
| `showCloseButton` | `boolean` | - |
| `closeLabel` | `string` | - |

<OnlyBase base="base radix">

Also accepts `align`, `alignOffset`, `side` and `sideOffset` from `PopoverContent`, which position the desktop popover, and the props of `React.HTMLAttributes<HTMLElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `align`, `alignOffset`, `side` and `sideOffset` from `PopoverContent`, which position the desktop popover, and `className`, `style`, `children`, `id` and `aria-label`.

</OnlyBase>

The positioning props are ignored on mobile, and `showCloseButton` and `closeLabel` only affect the mobile drawer.

### FlyoutHeader

Groups the title and description.

Also accepts the props of `React.ComponentProps<"div">`.

### FlyoutTitle

The flyout's title, used as its accessible name.

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLHeadingElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children` and `id`.

</OnlyBase>

### FlyoutDescription

Supporting text, used as the flyout's accessible description.

<OnlyBase base="base radix">

Also accepts the props of `React.HTMLAttributes<HTMLParagraphElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children` and `id`.

</OnlyBase>

### FlyoutBody

The main content area, padded on mobile.

Also accepts the props of `React.ComponentProps<"div">`.

Put interactive content here.

### FlyoutClose

A button that closes the flyout.

<OnlyBase base="base aria">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `React.ReactElement` | - |

</OnlyBase>

<OnlyBase base="radix">

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | - |

</OnlyBase>

<OnlyBase base="base radix">

Also accepts the props of `React.ButtonHTMLAttributes<HTMLButtonElement>`.

</OnlyBase>

<OnlyBase base="aria">

Also accepts `className`, `children`, `id` and `aria-label`.

</OnlyBase>

<OnlyBase base="base aria">

Use `render` on `FlyoutTrigger` and `FlyoutClose` to replace the default button with your own element, such as a `Button`.

</OnlyBase>

<OnlyBase base="radix">

Set `asChild` on `FlyoutTrigger` and `FlyoutClose` to render your own element, such as a `Button`, in place of the default button.

</OnlyBase>

Each part sets a `data-slot`, such as `flyout-content` or `flyout-close`, for styling.
