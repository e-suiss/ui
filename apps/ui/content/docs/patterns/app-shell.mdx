`AppShell` builds navigation from an `items` array and wraps your page content. On desktop it renders a collapsible `Sidebar` and the page renders in a `SidebarInset`. On mobile a `TabBar` pinned to the bottom of the screen replaces the sidebar.

Use it as the outermost layout of an app with a handful of top-level destinations.

## Usage

```tsx
import { AppShell, type AppShellItem, AppShellTrigger } from "@/components/patterns/app-shell"
```

```tsx
const items: AppShellItem[] = [
  { value: "home", label: "Home", icon: <HouseIcon /> },
  { value: "inbox", label: "Inbox", icon: <TrayIcon />, badge: 12 },
  { value: "settings", label: "Settings", icon: <GearIcon /> },
]

<AppShell items={items}>
  <header className="flex h-14 items-center gap-2 border-b px-4">
    <AppShellTrigger />
    <h1 className="text-base font-semibold">Home</h1>
  </header>
</AppShell>
```

## Accessibility

- The selected item has `aria-current="page"`.
- Collapsed sidebar items show their label in a tooltip on hover.
- `AppShellTrigger` is labelled Toggle Sidebar, and `Cmd+B` on macOS or `Ctrl+B` elsewhere toggles the sidebar.
- With `collapsible="offcanvas"`, the hidden sidebar is removed from view and the tab order.
- Disabled items are disabled buttons.

## API Reference

### AppShell

The root layout that renders the sidebar or tab bar from `items` and wraps the page content.

| Prop | Type | Default |
| --- | --- | --- |
| `items` | `AppShellItem[]` | Required |
| `value` | `string` | - |
| `defaultValue` | `string` | First item |
| `onValueChange` | `(value: string) => void` | - |
| `header` | `React.ReactNode` | - |
| `footer` | `React.ReactNode` | - |
| `variant` | `"sidebar" \| "floating" \| "inset"` | `"sidebar"` |
| `collapsible` | `"offcanvas" \| "icon" \| "none"` | `"icon"` |
| `side` | `"left" \| "right"` | `"left"` |
| `rail` | `boolean` | `true` |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | `true` |
| `onOpenChange` | `(open: boolean) => void` | - |
| `moreLabel` | `string` | `"More"` |
| `label` | `string` | `"Main"` |
| `className` | `string` | - |
| `children` | `React.ReactNode` | - |

<OnlyBase base="base radix">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `React.ReactElement` | A plain `a` |

</OnlyBase>

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `(props: React.ComponentProps<"a">) => React.ReactNode` | A plain `a` |

</OnlyBase>

Each `AppShellItem` has a `value`, `label` and `icon`, plus optional `href`, `badge`, `group` and `disabled`. The selected item is controlled with `value` and `onValueChange`, or uncontrolled with `defaultValue`; it defaults to the first item. `open`, `defaultOpen` and `onOpenChange` hold the sidebar's expanded state. `rail` renders a rail along the sidebar edge that toggles it, only when `collapsible` is not `none`. `label` names the navigation landmark on mobile.

<OnlyBase base="base radix">

Items with an `href` render as the `render` element, a plain anchor by default, so you can pass your router's link component.

</OnlyBase>

<OnlyBase base="aria">

Items with an `href` render through the `render` function, a plain anchor by default, so you can return your router's link component. It receives the link props, including `href`.

</OnlyBase>

Below the `48rem` breakpoint the content renders in a `main` element padded to clear the tab bar. `className` applies to the content area on both layouts. The sidebar sets `data-state` (`expanded` or `collapsed`), `data-collapsible`, `data-variant` and `data-side`, and on mobile the wrapper and content set `data-slot="app-shell"` and `data-slot="app-shell-content"`, for styling.

### AppShellTrigger

A `SidebarTrigger` that toggles the sidebar on desktop and renders nothing on mobile.

Also accepts the props of `React.ComponentProps<typeof SidebarTrigger>`.

Place it in your page header to toggle the sidebar.
