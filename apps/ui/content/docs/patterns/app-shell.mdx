`AppShell` builds navigation from an `items` array of `AppShellItem` objects and wraps your page content. On desktop it renders a `Sidebar` inside a `SidebarProvider`, with optional `header` and `footer`, group labels, badges, tooltips on collapsed icons and a `SidebarRail`; the page renders in a `SidebarInset`.

Below the `48rem` breakpoint the sidebar is replaced by a `TabBar` pinned to the bottom of the screen, and the content renders in a `main` element padded to clear it. Items that do not fit in the tab bar move behind its More trigger. Use it as the outermost layout of an app with a handful of top-level destinations.

## Installation

### CLI

```bash title="Terminal"
npx shadcn@latest add @esuiss/app-shell
```

Works in any project with a `components.json`. See [Installation](/docs/installation#add-components) for the one-line registry setup. Or use the [suiss/ui CLI](/docs/cli):

```bash title="Terminal"
npx @esuiss/ui@latest add patterns app-shell
```

### Manual

1. Add the [`cn` helper](/docs/installation#the-cn-helper).

2. Add the pieces it builds on: [Sidebar](/docs/components/sidebar), [Tab Bar](/docs/components/tab-bar).

3. Copy the source into `components/patterns/app-shell.tsx`:

4. Update the import paths to match your project.

## Usage

```tsx
import { AppShell, AppShellTrigger } from "@/components/patterns/app-shell"
```

```tsx
<ShellExample items={items} />
```

Each `AppShellItem` has a `value`, `label` and `icon`, plus optional `href`, `badge`, `group` and `disabled`. Items with the same `group` render under a shared `SidebarGroupLabel`. The selected item is controlled with `value` and `onValueChange`, or uncontrolled with `defaultValue`; it defaults to the first item. Items with an `href` render through `render`, which defaults to a plain anchor, so you can pass your router's link component.

The sidebar accepts `variant` (`sidebar`, `floating` or `inset`), `collapsible` (`icon` by default, `offcanvas` or `none`), `side`, `rail`, and `open`, `defaultOpen` and `onOpenChange` for its expanded state. `moreLabel` sets the tab bar's More trigger text and `label` names the navigation landmark (`Main` by default). Place `AppShellTrigger` in your page header to toggle the sidebar.

## API Reference

<ApiPart index={1}>

### AppShell

The root layout that renders the sidebar or tab bar from `items` and wraps the page content.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `AppShellItem[]` | Required | The destinations, each with a `value`, `label` and `icon`. |
| `value` | `string` | - | The selected item, for controlled use. |
| `defaultValue` | `string` | First item | The initially selected item when uncontrolled. |
| `onValueChange` | `(value: string) => void` | - | Called when an item is chosen. |
| `header` | `React.ReactNode` | - | Content at the top of the sidebar. |
| `footer` | `React.ReactNode` | - | Content at the bottom of the sidebar. |
| `variant` | `"sidebar" \| "floating" \| "inset"` | `"sidebar"` | The sidebar style. |
| `collapsible` | `"offcanvas" \| "icon" \| "none"` | `"icon"` | How the sidebar collapses. |
| `side` | `"left" \| "right"` | `"left"` | The side the sidebar sits on. |
| `rail` | `boolean` | `true` | Shows a rail along the sidebar edge that toggles it. |
| `open` | `boolean` | - | Whether the sidebar is expanded, for controlled use. |
| `defaultOpen` | `boolean` | `true` | Whether the sidebar starts expanded when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | - | Called when the sidebar expands or collapses. |
| `moreLabel` | `string` | `"More"` | Text of the More tab on mobile. |
| `render` | `React.ReactElement` | `<AppShellLink />` | The element items with an `href` render as, such as your router's link. |

Also accepts the props of `React.ComponentProps<typeof AppShellLayout>`.

</ApiPart>

<ApiPart index={2}>

### AppShellTrigger

A `SidebarTrigger` that toggles the sidebar on desktop and renders nothing on mobile.

Also accepts the props of `React.ComponentProps<typeof SidebarTrigger>`.

</ApiPart>

## Accessibility

- The selected item has `aria-current="page"`.
- Collapsed sidebar items show their label in a tooltip on hover.
- `AppShellTrigger` is labelled Toggle Sidebar, and `Cmd+B` on macOS or `Ctrl+B` elsewhere toggles the sidebar.
- With `collapsible="offcanvas"`, the hidden sidebar is removed from view and the tab order.
- Disabled items are disabled buttons.

## Notes

The sidebar exposes `data-state` (`expanded` or `collapsed`), `data-collapsible`, `data-variant` and `data-side` for styling. On mobile the wrapper carries `data-slot="app-shell"` and the content `data-slot="app-shell-content"`; `className` applies to the content area on both layouts. `rail` only renders when `collapsible` is not `none`.
