`PullToRefresh` is a vertically scrolling container. When it is scrolled to the top, dragging down with touch, or scrolling up with a trackpad or wheel, pulls the content down with increasing resistance. An indicator above the content fills in spoke by spoke as the pull nears the threshold. Releasing past the threshold calls `onRefresh`, holds the content open, and swaps the indicator for the suiss/ui `Spinner` until the refresh finishes; a shorter pull springs back without refreshing.

The spinner stays visible for at least 600 ms so fast refreshes still read clearly. Use it for lists of fetched content, such as feeds and inboxes.

- Give `PullToRefresh` a bounded height so its content scrolls inside it.
- `onRefresh` can return a promise; the container stays in the refreshing state until it settles, whether it resolves or rejects.
- Pulls only start at the top of the scroll position and are ignored while a refresh is in progress.

## Accessibility

- The container sets `aria-busy` while refreshing.
- The spinner is labelled `Refreshing`; the pull indicator is `aria-hidden`.
- Pulling requires touch or a scroll gesture, so offer another way to refresh where it matters, such as a button.

## Notes

- The root exposes `data-slot="pull-to-refresh"` and `data-phase` (`idle`, `pulling`, `refreshing`, `settling`). The indicator and content use `pull-to-refresh-indicator` and `pull-to-refresh-content`.
- The `--pull` and `--pull-progress` custom properties track the pull distance and progress toward the threshold.
- Transitions are disabled under `prefers-reduced-motion`.
