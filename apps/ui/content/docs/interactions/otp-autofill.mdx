`OtpAutofill` builds on the suiss/ui `InputOTP` component to recreate the iOS security code autofill flow. When the field is focused and empty, `OtpAutofillSuggestion` offers the received code; choosing it types the digits in with a short pop animation and calls `onVerify` once all slots are filled. A valid code turns the slots green and locks the field; an invalid one shakes the slots, marks them red, then clears the field and refocuses it.

The suggestion adapts to the device through `useIsMobile`. Below `48rem` it docks above the on-screen keyboard like the QuickType bar, tracking the visual viewport; on wider screens it appears as an inline pill under the field. In supporting browsers, the WebOTP API also reads codes from SMS and fills them automatically.

## Accessibility

- Label the field with `aria-label` on `OtpAutofillInput`, which renders a single text input.
- The input is read-only while filling, verifying, or verified, and sets `aria-invalid` when the code is rejected.
- The suggestion is a native button that is `inert` while hidden, and it prevents focus from leaving the field on press.
- After a rejected code, focus returns to the field. Pair the root with a `role="status"` element to announce the result.

## API Reference

### OtpAutofill

The root that holds the code value and verification state.

| Prop | Type | Default |
| --- | --- | --- |
| `maxLength` | `number` | Required |
| `onVerify` | `(code: string) => Promise<boolean> \| boolean` | Required |
| `webOtp` | `boolean` | `true` |

Also accepts the props of `React.ComponentProps<"div">`.

Place `OtpAutofillInput` and `OtpAutofillSuggestion` inside `OtpAutofill`. The value is managed internally. `onVerify` is called with the complete code once it reaches `maxLength`, whether it was filled, typed or pasted; return or resolve `true` to accept it or `false` to reject it. A paste of several characters fills with the same animation. Use `useOtpAutofill` to read `state` (`idle`, `filling`, `verifying`, `verified`, `invalid`) for status text or other UI. `webOtp` listens for SMS codes through the WebOTP API, where supported.

The root sets `data-slot="otp-autofill"` and `data-state`. The pop and shake animations are skipped under `prefers-reduced-motion`.

### OtpAutofillInput

The `InputOTP` field wired to the autofill state.

| Prop | Type | Default |
| --- | --- | --- |
| `containerClassName` | `string` | - |
| `children` | `React.ReactNode` | Required |

Also accepts the props of `React.ComponentProps<"input">`.

Pass `InputOTPGroup`, `InputOTPSlot` and `InputOTPSeparator` from `input-otp` as children. `containerClassName` styles the slot container and is merged with the state styles.

### OtpAutofillSuggestion

The button that offers the received code and fills it when pressed.

| Prop | Type | Default |
| --- | --- | --- |
| `code` | `string \| null \| undefined` | Required |
| `source` | `React.ReactNode` | `"From Messages"` |

Also accepts the props of `React.ComponentProps<"button">`.

Set `code` to `null` until a code arrives; the suggestion stays hidden without one. `source` names where the code came from. The suggestion sets `data-slot="otp-autofill-suggestion"`, `data-placement` (`keyboard` or `inline`) and `data-closed` while hidden.

</Only>

`OtpAutofill` wraps an `InputOTP` and runs it through `idle`, `filling`, `verifying`, `verified` and `invalid` states. When the input is focused and empty, `OtpAutofillSuggestion` slides up above the keyboard with the incoming code; pressing it types the code one digit at a time.

When all digits are entered, `onVerify` runs and the slots dim while it is pending. A valid code turns the slots green and locks the input. An invalid code turns them red and shakes the row, then clears the input and refocuses it. Pasting or a system autofill of several digits plays the same digit-by-digit fill.

<Only platform="kotlin">

Pass `maxLength` and `onVerify`, a suspending function that returns whether the code is right. Put `InputOTPGroup` and `InputOTPSlot`s inside `OtpAutofillInput`, and render an `OtpAutofillSuggestion` with the `code` your app received; it hides when `code` is empty.

## Usage

<Only platform="rn">

<OnlyStyling styling="uniwind nativewind">

```tsx
import * as React from "react"
import { View } from "react-native"
import { OtpAutofill, OtpAutofillInput, OtpAutofillSuggestion, useOtpAutofill } from "@/components/interactions/otp-autofill"
import { Button } from "@/components/ui/button"
import { InputOTPGroup, InputOTPSeparator, InputOTPSlot } from "@/components/ui/input-otp"
import { Text } from "@/components/ui/text"

const CODE = "482913"

function wait(ms: number) {
  return new Promise<void>((resolve) => setTimeout(resolve, ms))
}

function statusClassName(state: string) {
  if (state === "invalid") return "min-h-5 text-sm text-destructive"
  if (state === "verified")
    return "min-h-5 text-sm text-green-600 dark:text-green-400"
  return "min-h-5 text-sm text-muted-foreground"
}

function statusText(state: string) {
  if (state === "verifying") return "Verifying…"
  if (state === "verified") return "Verified"
  if (state === "invalid") return "That code didn't work. Try again."
  return ""
}

function Status() {
  const { state } = useOtpAutofill()

  return (
    <Text
      role="status"
      accessibilityLiveRegion="polite"
      className={statusClassName(state)}
    >
      {statusText(state)}
    </Text>
  )
}

function VerificationExample({ incoming }: { incoming: string }) {
  const [suggestion, setSuggestion] = React.useState<string | null>(null)
  const [sending, setSending] = React.useState(false)

  const send = React.useCallback(async () => {
    setSending(true)
    setSuggestion(null)
    await wait(1200)
    setSuggestion(incoming)
    setSending(false)
  }, [incoming])

  React.useEffect(() => {
    send()
  }, [send])

  return (
    <View className="w-full items-center gap-2">
      <Text className="text-center text-2xl font-bold">Enter the code</Text>
      <Text className="text-center text-sm text-muted-foreground">
        We sent a 6-digit code to +1 555 0100.
      </Text>
      <OtpAutofill
        maxLength={6}
        onVerify={async (code) => {
          await wait(700)
          return code === CODE
        }}
        className="mt-4"
      >
        <OtpAutofillInput autoFocus accessibilityLabel="Verification code">
          <InputOTPGroup>
            <InputOTPSlot index={0} />
            <InputOTPSlot index={1} />
            <InputOTPSlot index={2} />
          </InputOTPGroup>
          <InputOTPSeparator />
          <InputOTPGroup>
            <InputOTPSlot index={3} />
            <InputOTPSlot index={4} />
            <InputOTPSlot index={5} />
          </InputOTPGroup>
        </OtpAutofillInput>
        <Status />
        <OtpAutofillSuggestion code={suggestion} />
      </OtpAutofill>
      <Button variant="plain" onPress={send} disabled={sending}>
        <Text>{sending ? "Sending…" : "Resend code"}</Text>
      </Button>
    </View>
  )
}

export function OtpAutofillExample() {
  return (
    <VerificationExample incoming={CODE} />
  )
}
```

```swift
  var body: some View {
    OtpAutofillVerification(incoming: otpAutofillCode)

struct OtpAutofillStatus: View {

  var body: some View {
    Text(text)
      .textStyle(.sm)
      .foregroundStyle(color)
      .frame(minHeight: 20)
      .accessibilityAddTraits(.updatesFrequently)
  }

  var text: LocalizedStringKey {
    switch state {
    case .verifying: "Verifying…"
    case .verified: "Verified"
    case .invalid: "That code didn't work. Try again."
    case .idle, .filling: ""
    }
  }

  var color: Color {
    switch state {
    case .verified: Color.adaptive(light: Palette.green600, dark: Palette.green400)
    case .invalid: EsuissColor.destructive
    default: EsuissColor.mutedForeground
    }
  }

  let incoming: String

  @State private var suggestion: String?
  @State private var sending = false

  var body: some View {
    VStack(spacing: 8) {
      Text("Enter the code")
        .textStyle(.xl2, weight: .bold)
        .foregroundStyle(EsuissColor.foreground)
        .multilineTextAlignment(.center)

        try? await Task.sleep(for: .milliseconds(700))
        return code == otpAutofillCode

        OtpAutofillInput(autoFocus: true) {
          InputOTPGroup {
            InputOTPSlot(index: 0)
            InputOTPSlot(index: 1)

            InputOTPSlot(index: 3)
            InputOTPSlot(index: 4)
```

A bar above the keyboard that fills the suggested code on press.
