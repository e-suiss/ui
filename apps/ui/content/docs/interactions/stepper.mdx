`Stepper` recreates the iOS stepper on top of a number field primitive. It pairs an editable `StepperInput` with a segmented `StepperGroup` of `StepperDecrement` and `StepperIncrement` buttons. Each press changes the value by `step`; holding a button repeats the change after a short delay and speeds up over time. Each button disables itself when the value reaches `min` or `max`.

Use it for small, bounded quantities such as copies, servings, or scale, where people usually adjust a value by a few steps.

## Usage

```tsx
import {
  Stepper,
  StepperDecrement,
  StepperGroup,
  StepperIncrement,
  StepperInput,
  StepperSeparator,
} from "@/components/interactions/stepper"
```

```tsx
<Stepper defaultValue={1} min={0} max={10}>
  <StepperInput aria-label="Quantity" />
  <StepperGroup>
    <StepperDecrement />
    <StepperSeparator />
    <StepperIncrement />
  </StepperGroup>
</Stepper>
```

Use the following composition to build a `Stepper`:

```text

├── StepperInput
└── StepperGroup
    ├── StepperDecrement
    ├── StepperSeparator
    └── StepperIncrement
```

## Accessibility

- Label `StepperInput` with `aria-label` or `aria-labelledby`.
- The arrow keys step the value from the input, as provided by the number field primitive.
- The buttons are labelled `Decrease` and `Increase`, and are disabled at the limits or when the stepper is disabled.
- `StepperGroup` has `role="group"`, and `StepperSeparator` is `aria-hidden`.

## API Reference

### Stepper

The Number Field root that holds the value and its limits.

| Prop | Type | Default |
| --- | --- | --- |
| `step` | `number` | `1` |
| `value` | `number` | - |
| `defaultValue` | `number` | `0` |
| `onValueChange` | `(value: number) => void` | - |
| `min` | `number` | - |
| `max` | `number` | - |
| `disabled` | `boolean` | `false` |

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `format` | `Intl.NumberFormatOptions` | - |

</OnlyBase>

Also accepts the props of the primitive part it wraps.

Compose `StepperInput` and a `StepperGroup` containing `StepperDecrement`, `StepperSeparator` and `StepperIncrement` inside `Stepper`. The value is uncontrolled by default; pass `value` and `onValueChange` to control it. `min` and `max` have no limit by default, and `disabled` disables the input and both buttons. Other number field props pass through to the root. Values are rounded to the precision of `step`, so decimal steps do not accumulate floating-point errors. Each part sets a `data-slot`, such as `stepper-input`, for styling.

<OnlyBase base="aria">

`format` sets how the number is formatted in the input.

</OnlyBase>

### StepperInput

The editable text field that shows the value.

Also accepts the props of the primitive part it wraps.

### StepperGroup

The segmented container for the decrement and increment buttons.

Also accepts the props of `React.ComponentProps<"div">`.

### StepperDecrement

The button that decreases the value by one step.

Also accepts the props of `React.ComponentProps<"button">`.

### StepperIncrement

The button that increases the value by one step.

Also accepts the props of `React.ComponentProps<"button">`.

Both buttons render minus and plus icons by default; pass children to replace them. They suppress the long-press context menu so holding them on touch devices keeps stepping.

### StepperSeparator

A thin divider between the two buttons.

Also accepts the props of `React.ComponentProps<"span">`.

struct StepperParts: View {

import androidx.compose.foundation.layout.Row
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableDoubleStateOf
import androidx.compose.runtime.saveable.rememberSaveable
import androidx.compose.runtime.setValue
import com.esuiss.ui.interactions.Stepper
import com.esuiss.ui.interactions.StepperDecrement
import com.esuiss.ui.interactions.StepperGroup
import com.esuiss.ui.interactions.StepperIncrement
import com.esuiss.ui.interactions.StepperInput
import com.esuiss.ui.interactions.StepperSeparator

@Composable
fun StepperControls() {
    StepperGroup {
        StepperDecrement()
        StepperSeparator()
        StepperIncrement()
    }
}

@Composable
fun StepperDefault() {
    var value by rememberSaveable { mutableDoubleStateOf(1.0) }
    Row {
        Stepper(value = value, onValueChange = { value = it }, min = 0.0, max = 10.0) {
            StepperInput(contentDescription = "Quantity")
            StepperControls()
        }
    }
}

## API Reference

<Only platform="rn">

### Stepper

The root that holds the value and limits.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `number` | - |
| `defaultValue` | `number` | `0` |
| `onValueChange` | `( value: number, eventDetails: NumberFieldPrimitive.ChangeEventDetails ) => void` | - |

Also accepts the props of `React.ComponentProps<typeof NumberFieldPrimitive.Root>`.

Compose `StepperInput` and a `StepperGroup` containing `StepperDecrement`, `StepperSeparator` and `StepperIncrement` inside `Stepper`. Use it uncontrolled with `defaultValue` or controlled with `value` and `onValueChange`, which is called with the new number and change details. Clearing the field never reports `null`; the change is cancelled instead. `min`, `max`, `step`, `format` (`Intl.NumberFormatOptions`), `locale` and `disabled` are passed to the number field. A selection haptic plays on each step, if the app provides an adapter through `HapticsProvider`.

### StepperInput

The editable, right-aligned value.

Also accepts the props of `React.ComponentProps<typeof NumberFieldPrimitive.Input>`.

### StepperGroup

The rounded field that holds the buttons.

Also accepts the props of `React.ComponentProps<typeof NumberFieldPrimitive.Group>`.

### StepperDecrement

The minus button.

Also accepts the props of `React.ComponentProps<typeof NumberFieldPrimitive.Decrement>`.

### StepperIncrement

The plus button.

Also accepts the props of `React.ComponentProps<typeof NumberFieldPrimitive.Increment>`.

### StepperSeparator

A thin divider between the buttons.

Also accepts the props of `ViewProps`.
