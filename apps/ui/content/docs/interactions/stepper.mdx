`Stepper` recreates the iOS stepper on top of the Base UI Number Field. It pairs an editable `StepperInput` with a segmented `StepperGroup` of `StepperDecrement` and `StepperIncrement` buttons. Each press changes the value by `step`; holding a button repeats the change after a short delay and speeds up over time. Each button disables itself when the value reaches `min` or `max`.

Use it for small, bounded quantities such as copies, servings, or scale, where people usually adjust a value by a few steps.

## Accessibility

- Label `StepperInput` with `aria-label` or `aria-labelledby`.
- The arrow keys step the value from the input, as provided by Base UI Number Field.
- The buttons are labelled `Decrease` and `Increase`, and are disabled at the limits or when the stepper is disabled.
- `StepperGroup` has `role="group"`, and `StepperSeparator` is `aria-hidden`.

## Notes

- Parts use `data-slot` values `stepper`, `stepper-input`, `stepper-group`, `stepper-decrement`, `stepper-increment`, and `stepper-separator`.
- Values are rounded to the precision of `step`, so decimal steps do not accumulate floating-point errors.
- The buttons suppress the long-press context menu so holding them on touch devices keeps stepping.

`Stepper` is a number field laid out as a right-aligned value followed by a field holding minus and plus buttons, inset from its edges. Each step snaps to `step` and stays within `min` and `max`, and a button that can go no further is shown as disabled.

Pressing and holding a button steps once, then repeats every 60 ms after 400 ms. The value can also be typed. Use it for quantities, copies or percentages in settings rows.
