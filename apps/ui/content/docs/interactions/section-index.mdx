`SectionIndex` recreates the iOS list index. Sections marked with `SectionIndexSection` carry sticky `SectionIndexHeader` titles, and `SectionIndexBar` sits along the trailing edge. Tapping or dragging over the bar scrolls the nearest scrollable ancestor so the matching section is at the top; while dragging, a bubble shows the current letter. If a letter has no section, it jumps to the next one that exists.

When the container is too short to fit every letter, the bar collapses to fewer letters separated by dots, while still mapping the full alphabet across its height. Use it for long alphabetized lists such as contacts.

- Wrap the scrolling list and `SectionIndexBar` in `SectionIndex`, which positions the bar. The list can scroll in its own container, such as `ScrollArea`, or in the page.
- Set `value` on each `SectionIndexSection` to a letter from `letters` so the bar can find it.
- Use `onValueChange` to react to jumps.

## Accessibility

- The bar is a vertical `slider` labelled `Section index`, with `aria-valuetext` set to the current letter.
- Arrow keys move one letter, `PageUp` and `PageDown` move five, and `Home` and `End` reach the first and last letters.
- Typing a letter jumps directly to it.
- The visible letters and drag bubble are `aria-hidden`.

## Notes

- Parts use `data-slot` values `section-index`, `section-index-section`, `section-index-header`, `section-index-bar`, and `section-index-bubble`. Sections expose `data-value`, and the bar sets `data-dragging` during a drag.
- The bar extends its hit area toward the list so it is easier to grab.

`SectionIndex` pairs a scroll view of lettered sections with `SectionIndexBar`, a column of letters on the end edge. Tapping a letter scrolls to that section; dragging along the bar scrubs through sections and shows the current letter in a large bubble beside the finger.

When the bar is too short for every letter, it shows a subset with `•` between them. Use it for long alphabetical lists such as contacts.

Put a `SectionIndexScrollView` and a `SectionIndexBar` inside `SectionIndex`. Wrap each group in a `SectionIndexSection` with its letter as `value`, and start it with a `SectionIndexHeader`.

The bar shows `A` to `Z` and `#` by default; pass `letters` to match your sections. `onValueChange` is called with the letter when the user jumps.

## Accessibility

- The bar is `adjustable`: swiping up or down with a screen reader moves to the previous or next section, and the current letter is announced as its value.
- `SectionIndexHeader` has the `heading` role.

## Notes

- A selection haptic plays on each letter change from touch, if the app provides an adapter through `HapticsProvider`.
- Letters use `text-link`; the bubble uses `bg-surface-raised`.
- The bubble animation respects the system reduce motion setting.
