`CardStack` shows the top card of `data` with up to `visibleCount` cards stacked behind it, each slightly smaller and lower. Dragging the top card sideways moves and tilts it, while the cards behind grow into place.

Releasing past `threshold`, or flicking faster than 800 points per second, flies the card off in that direction and shows the next one; otherwise it springs back. Use it for one-at-a-time decisions such as keep or skip.

## Usage

```tsx
import { CardStack, CardStackEmpty, CardStackActions, CardStackSwipeButton, CardStackUndo } from "@/components/interactions/card-stack"
```

```tsx
<Demo />
```

Pass `data` and `renderItem`, and handle `onSwipe(direction, item, index)`. Add children below the deck: `CardStackActions` with `CardStackSwipeButton`s and a `CardStackUndo`, and a `CardStackEmpty` shown once every card is swiped.

Undo brings back the last card from the side it left and calls `onUndo`. `useCardStack` exposes `index`, `count`, `remaining`, `canUndo`, `swipe` and `undo` for custom controls. The `CardStackDirection` type is exported.

## API Reference

<ApiPart index={1}>

### CardStack

The root that renders the deck and handles the drag gesture.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `readonly T[]` | Required | The items to show as cards. |
| `renderItem` | `(item: T, index: number) => React.ReactNode` | Required | Renders one card from the item and its index. |
| `keyExtractor` | `(item: T, index: number) => string` | - | Returns a key for a card. Defaults to its position. |
| `onSwipe` | `(direction: CardStackDirection, item: T, index: number) => void` | - | Called with the direction, item and index after a card leaves. |
| `onUndo` | `(item: T, index: number) => void` | - | Called with the item and index after undo. |
| `threshold` | `number` | `120` | Drag distance that commits a swipe. Defaults to `120`. |
| `visibleCount` | `number` | `3` | Cards stacked behind the top card. Defaults to `3`. |
| `disabled` | `boolean` | `false` | Turns off the gesture and the swipe buttons. |
| `itemAccessibilityLabel` | `(item: T, index: number) => string` | - | Returns the label for the top card. |
| `deckClassName` | `string` | - | Classes for the deck area, which is `h-96` by default. |

Also accepts the props of `ViewProps`.

</ApiPart>

<ApiPart index={2}>

### CardStackEmpty

A dashed placeholder shown when no cards remain.

Also accepts the props of `ViewProps`, `React.RefAttributes<View>`.

</ApiPart>

<ApiPart index={3}>

### CardStackActions

A centered row for the buttons.

Also accepts the props of `ViewProps`, `React.RefAttributes<View>`.

</ApiPart>

<ApiPart index={4}>

### CardStackSwipeButton

A round button that swipes the top card left or right.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `direction` | `CardStackDirection` | Required | `left` shows an X icon, `right` shows a heart icon. |

Also accepts the props of `React.ComponentProps<typeof Button>`.

</ApiPart>

<ApiPart index={5}>

### CardStackUndo

A button that restores the last swiped card.

Also accepts the props of `React.ComponentProps<typeof Button>`.

</ApiPart>

## Accessibility

- The top card has `Swipe left` and `Swipe right` accessibility actions.
- Cards behind the top card are hidden from screen readers.
- Swipe buttons are labelled `Swipe left` and `Swipe right`, and undo is labelled `Undo`, unless you pass `accessibilityLabel`.

## Notes

- A medium impact haptic plays when a card is swiped by gesture, button or accessibility action, if the app provides an adapter through `HapticsProvider`.
- Fly-out and spring animations respect the system reduce motion setting.
- The left button icon uses `text-destructive`; the right uses `text-primary`.
