<Only platform="rn kotlin">

`CardStack` shows the top card of `data` with up to `visibleCount` cards stacked behind it, each slightly smaller and lower. Dragging the top card sideways moves and tilts it, while the cards behind grow into place.

</Only>

Releasing past `threshold`, or flicking faster than 800 points per second, flies the card off in that direction and shows the next one; otherwise it springs back. Use it for one-at-a-time decisions such as keep or skip.

```tsx
import * as React from "react"
import { View } from "react-native"
import { CardStack, CardStackActions, CardStackEmpty, CardStackSwipeButton, CardStackUndo } from "@/components/interactions/card-stack"
import { Card, CardContent, CardDescription, CardHeader, CardTitle } from "@/components/ui/card"
import { Text } from "@/components/ui/text"

type Place = { id: string; name: string; city: string; detail: string }

const places: Place[] = [
  {
    id: "harbor",
    name: "Harbor Café",
    city: "Lisbon",
    detail: "Slow mornings, strong coffee and a view of the river.",
  },
  {
    id: "garden",
    name: "Garden Library",
    city: "Kyoto",
    detail: "Quiet reading rooms around a moss garden.",
  },
  {
    id: "market",
    name: "Night Market",
    city: "Taipei",
    detail: "Street food stalls open until two in the morning.",
  },
]

function PlaceCard({ place }: { place: Place }) {
  return (
    <Card className="h-full">
      <CardHeader>
        <CardTitle>{place.name}</CardTitle>
        <CardDescription>{place.city}</CardDescription>
      </CardHeader>
      <CardContent className="grow">
        <View className="grow rounded-xl bg-muted" />
      </CardContent>
      <CardContent>
        <Text className="text-sm text-muted-foreground">{place.detail}</Text>
      </CardContent>
    </Card>
  )
}

function Demo({ disabled = false }: { disabled?: boolean }) {
  const [log, setLog] = React.useState("")
  return (
    <View className="gap-3">
      <CardStack
        data={places}
        keyExtractor={(place) => place.id}
        renderItem={(place) => <PlaceCard place={place} />}
        itemAccessibilityLabel={(place) => `${place.name}, ${place.city}`}
        disabled={disabled}
        onSwipe={(direction, place) =>
          setLog(`${direction === "left" ? "Skipped" : "Liked"} ${place.name}`)
        }
        onUndo={(place) => setLog(`Restored ${place.name}`)}
      >
        <CardStackEmpty>You have seen every place.</CardStackEmpty>
        <CardStackActions>
          <CardStackSwipeButton direction="left" />
          <CardStackUndo />
          <CardStackSwipeButton direction="right" />
        </CardStackActions>
      </CardStack>
      <Text role="status" className="text-center text-sm text-muted-foreground">
        {log}
      </Text>
    </View>
  )
}

export function CardStackExample() {
  return (
    <Demo />
  )
}
```

```swift
      VStack(spacing: 24) {
        ZStack {
          if !controller.canSwipe {
            Text("You have seen every place.")
              .textStyle(.sm)
              .foregroundStyle(EsuissColor.mutedForeground)
              .multilineTextAlignment(.center)
              .padding(24)
              .frame(maxWidth: .infinity, maxHeight: .infinity)

                RoundedRectangle(cornerRadius: Radius.xl2, style: .continuous)

          }
          CardStack(
            places,
            controller: controller,
            onSwipe: { direction, place in
              log = "\(direction == .left ? "Skipped" : "Liked") \(place.name)"

              log = "Restored \(place.name)"

          CardStackButton(.swipeLeft, controller: controller)
          CardStackButton(.undo, controller: controller)
          CardStackButton(.swipeRight, controller: controller)
        }
      }
      if showsLog {
        Text(verbatim: log)
          .textStyle(.sm)
          .foregroundStyle(EsuissColor.mutedForeground)
          .multilineTextAlignment(.center)
          .frame(maxWidth: .infinity)
          .accessibilityAddTraits(.updatesFrequently)
      }
    }
  }
```

## Accessibility

- The top card has `Swipe left` and `Swipe right` accessibility actions.
- Cards behind the top card are hidden from screen readers.
- Swipe buttons are labelled `Swipe left` and `Swipe right`, and undo is labelled `Undo`, unless you pass `accessibilityLabel`.

## API Reference

<Only platform="rn">

### CardStack

The root that renders the deck and handles the drag gesture.

| Prop | Type | Default |
| --- | --- | --- |
| `data` | `readonly T[]` | Required |
| `renderItem` | `(item: T, index: number) => React.ReactNode` | Required |
| `keyExtractor` | `(item: T, index: number) => string` | - |
| `onSwipe` | `(direction: CardStackDirection, item: T, index: number) => void` | - |
| `onUndo` | `(item: T, index: number) => void` | - |
| `threshold` | `number` | `120` |
| `visibleCount` | `number` | `3` |
| `disabled` | `boolean` | `false` |
| `itemAccessibilityLabel` | `(item: T, index: number) => string` | - |
| `deckClassName` | `string` | - |

Also accepts the props of `ViewProps`.

Pass `data` and `renderItem`, and add children below the deck: `CardStackActions` with `CardStackSwipeButton`s and a `CardStackUndo`, and a `CardStackEmpty` shown once every card is swiped. `onSwipe` is called with the direction, item and index after a card leaves. `keyExtractor` defaults to the card's position. `threshold` is the drag distance that commits a swipe, and `visibleCount` is the number of cards stacked behind the top card. `disabled` turns off the gesture and the swipe buttons. `itemAccessibilityLabel` returns the label for the top card. The deck area is `h-96` by default; change it with `deckClassName`.

Undo brings back the last card from the side it left and calls `onUndo` with the item and index. `useCardStack` exposes `index`, `count`, `remaining`, `canUndo`, `swipe` and `undo` for custom controls. The `CardStackDirection` type is exported. A medium impact haptic plays when a card is swiped by gesture, button or accessibility action, if the app provides an adapter through `HapticsProvider`. Fly-out and spring animations respect the system reduce motion setting.

### CardStackEmpty

A dashed placeholder shown when no cards remain.

Also accepts the props of `ViewProps`, `React.RefAttributes<View>`.

### CardStackActions

A centered row for the buttons.

Also accepts the props of `ViewProps`, `React.RefAttributes<View>`.

### CardStackSwipeButton

A round button that swipes the top card left or right.

| Prop | Type | Default |
| --- | --- | --- |
| `direction` | `CardStackDirection` | Required |

Also accepts the props of `React.ComponentProps<typeof Button>`.

`left` shows an X icon and `right` shows a heart icon.

### CardStackUndo

A button that restores the last swiped card.

Also accepts the props of `React.ComponentProps<typeof Button>`.

</Only>

<Only platform="swift">

### CardStackDirection

Values: `.left`, `.right`.

### CardStackController

Takes no parameters.

| Property | Type |
| --- | --- |
