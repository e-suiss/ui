`PreviewMenu` builds on the Base UI Context Menu. Touching and holding the trigger, or right-clicking it, blurs the page and animates the trigger from its position into a centered preview up to `360px` wide, morphing its corner radius along the way. The menu of actions opens below the preview and the trigger stays hidden until the menu finishes closing, so the preview appears to return to its place.

By default, the preview shows the trigger's own content. Pass `preview` to `PreviewMenuContent` to show richer content instead; the trigger's snapshot crossfades into it. Use it for items that benefit from a quick look before acting, such as photos, documents, or messages.

## Usage

<Code lang="tsx" code={"import { PreviewMenu, PreviewMenuTrigger, PreviewMenuContent, PreviewMenuItem, PreviewMenuSeparator } from \"@/components/interactions/preview-menu\""} />

<Code lang="tsx" code={"<PhotoGrid />"} />

- Compose `PreviewMenuTrigger` and `PreviewMenuContent` inside `PreviewMenu`, with `PreviewMenuItem` and `PreviewMenuSeparator` inside the content.
- The menu is uncontrolled by default; pass `open` and `onOpenChange` to control it.
- Set `aspectRatio` when a custom `preview` has a different shape than the trigger; otherwise the preview keeps the trigger's proportions.
- Handle actions with `onClick` on each item. Items close the menu when chosen.

## Accessibility

- The popup has `role="menu"` and items have `role="menuitem"`, with keyboard navigation from Base UI Context Menu.
- `Escape` closes the menu without running an action.
- Disabled items set `aria-disabled` and cannot be chosen.
- The lifted preview is `aria-hidden`, so assistive technologies read the trigger and menu only.

## Notes

- Parts use `data-slot` values `preview-menu-trigger`, `preview-menu-backdrop`, `preview-menu-preview`, `preview-menu-content`, `preview-menu-item`, and `preview-menu-separator`. Items set `data-variant`.
- The trigger carries `data-previewing` while open and `data-lifted` until the closing animation ends, and is invisible during that time.
- The trigger disables text selection and the iOS touch callout so long presses open the menu.
