`PreviewMenu` builds on the menu primitives of the chosen base. Touching and holding the trigger, or right-clicking it, blurs the page and animates the trigger from its position into a centered preview up to `360px` wide, morphing its corner radius along the way. The menu of actions opens below the preview and the trigger stays hidden until the menu finishes closing, so the preview appears to return to its place.

By default, the preview shows the trigger's own content. Pass `preview` to `PreviewMenuContent` to show richer content instead; the trigger's snapshot crossfades into it. Use it for items that benefit from a quick look before acting, such as photos, documents, or messages.

## Usage

```tsx
import { PreviewMenu, PreviewMenuTrigger, PreviewMenuContent, PreviewMenuItem, PreviewMenuSeparator } from "@/components/interactions/preview-menu"
```

```tsx
<PhotoGrid />
```

- Compose `PreviewMenuTrigger` and `PreviewMenuContent` inside `PreviewMenu`, with `PreviewMenuItem` and `PreviewMenuSeparator` inside the content.
- The menu is uncontrolled by default; pass `open` and `onOpenChange` to control it.
- Set `aspectRatio` when a custom `preview` has a different shape than the trigger; otherwise the preview keeps the trigger's proportions.
- Handle actions with `onClick` on each item. Items close the menu when chosen.

## Accessibility

- The popup has `role="menu"` and items have `role="menuitem"`, with keyboard navigation from the menu primitive.
- `Escape` closes the menu without running an action.
- Disabled items set `aria-disabled` and cannot be chosen.
- The lifted preview is `aria-hidden`, so assistive technologies read the trigger and menu only.

## Notes

- Parts use `data-slot` values `preview-menu-trigger`, `preview-menu-backdrop`, `preview-menu-preview`, `preview-menu-content`, `preview-menu-item`, and `preview-menu-separator`. Items set `data-variant`.
- The trigger carries `data-previewing` while open and `data-lifted` until the closing animation ends, and is invisible during that time.
- The trigger disables text selection and the iOS touch callout so long presses open the menu.

Long pressing a `PreviewMenuTrigger` measures it and the menu, then animates its content from its place on screen into a larger preview, up to 360 points wide. The preview and the menu below it are centered together between the top and bottom safe areas. The rest of the screen fades behind a scrim, and the menu grows out of the trigger into place.

The original trigger is hidden while lifted, so the preview appears to rise out of it. With custom `preview` content, the trigger's content cross-fades into it as it grows. Pressing outside closes the menu and the preview and menu shrink back into the trigger. Use it for photos, messages or cards that benefit from a closer look before acting.

## Usage

```tsx
import { PreviewMenu, PreviewMenuTrigger, PreviewMenuContent, PreviewMenuItem, PreviewMenuSeparator } from "@/components/interactions/preview-menu"
```

```tsx
<PhotoGrid openIndex={1} />
```

Put a `PreviewMenuTrigger` with the element and a `PreviewMenuContent` with `PreviewMenuItem`s inside `PreviewMenu`. By default the preview repeats the trigger's children; pass `preview` to show different content, such as a larger image.

Set `aspectRatio` to size the preview, for example `4 / 3`. The menu can be uncontrolled or controlled with `open`, `defaultOpen` and `onOpenChange`. `usePreviewMenu` returns `open`, `lifted` and `frame`.

## Accessibility

- The trigger has a `longpress` accessibility action, so screen reader users can open the menu without holding.
- The trigger exposes `expanded` and `disabled` states.
- The preview is hidden from screen readers; focus goes to the menu.

## Notes

- A medium impact haptic plays when the menu opens, if the app provides an adapter through `HapticsProvider`.
- The menu uses `bg-popover` with a border that is stronger in dark mode, and the backdrop uses `bg-black/50`.
- The preview stays within the top and bottom safe areas and leaves room for the measured height of the menu.
- Animations respect the system reduce motion setting.
- On iOS the content renders in a full-window overlay so it appears above native screens.
