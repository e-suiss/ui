`SearchReveal` recreates the iOS pattern where a search field hides above a list. The container starts scrolled so the field is just out of view; scrolling up reveals it and fades it in. When scrolling stops partway, the container settles to fully shown or fully hidden, and it stays revealed while the field holds a query. Focusing the field scrolls it into view.

`SearchRevealField` is a controlled search input with a magnifying glass and a clear button. Use the pattern for lists such as notes, messages, or contacts where search should be available without taking up space.

## Usage

```tsx
import { SearchReveal, SearchRevealField, SearchRevealContent } from "@/components/interactions/search-reveal"
```

```tsx
<NotesExample count={12} />
```

- Place `SearchRevealField` first and `SearchRevealContent` after it inside `SearchReveal`, and give the container a bounded height.
- The field is controlled: pass `value` and update it in `onValueChange`. Filter the content from that value.
- `SearchRevealContent` fills at least the container's height, so the field can hide even when the list is short.
- `placeholder` defaults to `Search` and also labels the input.

## API Reference

<ApiPart index={1}>

### SearchReveal

The scroll container that hides, reveals, and snaps the search field.

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

<ApiPart index={2}>

### SearchRevealField

The search input with a clear button.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | The current query. |
| `onValueChange` | `(value: string) => void` | Required | Called with the new query when the user types or clears the field. |

Also accepts the props of `React.ComponentProps<"input">`.

</ApiPart>

<ApiPart index={3}>

### SearchRevealContent

The scrolling content below the field.

Also accepts the props of `React.ComponentProps<"div">`.

</ApiPart>

## Accessibility

- The input has `type="search"` and is labelled by its placeholder through `aria-label`.
- The clear button is labelled `Clear search` and returns focus to the input.
- Focusing the field, including with the keyboard, scrolls it into view.

## Notes

- Parts use `data-slot` values `search-reveal`, `search-reveal-field`, `search-reveal-input`, and `search-reveal-content`.
- The `--search-reveal` custom property runs from `0` to `1` as the field is revealed and drives its opacity.

`SearchReveal` is a scroll view that starts scrolled just past its `SearchRevealField`, so the list shows first and the field is out of view. Pulling down reveals the field, which fades in as it appears, and the scroll snaps either fully open or fully hidden.

Focusing the field scrolls it into view. While there is a query, snapping is turned off so the field stays visible. Use it for notes, mail or settings lists where search should be close but not take space.

## Usage

```tsx
import { SearchReveal, SearchRevealField, SearchRevealContent } from "@/components/interactions/search-reveal"
```

```tsx
<NotesExample count={12} />
```

Put a `SearchRevealField` first, then the list inside a `SearchRevealContent`, all inside `SearchReveal`. The field is controlled: pass `value` and update it in `onValueChange`, then filter your list with it.

`SearchRevealContent` is at least as tall as the scroll view, so the field can be hidden even when the list is short. Other `ScrollView` props, except `onScroll`, pass through to `SearchReveal`, and other `TextInput` props pass through to the field.

## Accessibility

- The input has the `searchbox` role and is labelled by `placeholder`.
- The clear button is labelled `Clear search` and returns focus to the input.

## Notes

- The field uses `bg-secondary` with `muted-foreground` placeholder and icons.
- Autocorrect and autocapitalization are off, and the return key reads `search`.
- Taps on the list work while the keyboard is open.
