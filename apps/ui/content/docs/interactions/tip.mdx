`Tip` recreates TipKit-style feature tips. Each tip has an `id`; once dismissed, the id is stored in `localStorage` and the tip no longer appears. Show a tip inline with `TipCard`, which expands into the layout, or attach it to a control with `TipAnchor` and `TipPopover`, which uses a non-modal popover with an arrow. Using the anchored control also dismisses its tip.

Wrap several tips in `TipGroup` to show them one at a time, in the order they mount; when one is dismissed, the next appears. Use tips sparingly to point out features people might otherwise miss.

```tsx
<TipGroup>
  <Tip id="notes-pin">
    <TipCard>
      <TipIcon>
        <PushPinIcon />
      </TipIcon>
      <TipContent>
        <TipTitle>Pin your favorites</TipTitle>
        <TipDescription>
          Swipe right on a note to keep it at the top of the list.
        </TipDescription>
      </TipContent>
      <TipClose />
    </TipCard>
  </Tip>
  <Tip id="notes-compose">
    <TipAnchor>
      <Button size="icon" aria-label="New note">
        <NotePencilIcon />
      </Button>
    </TipAnchor>
    <TipPopover>
      <TipContent>
        <TipTitle>Start a note fast</TipTitle>
        <TipDescription>Tap here any time to begin a new note.</TipDescription>
      </TipContent>
      <TipClose />
    </TipPopover>
  </Tip>
</TipGroup>
```

## Accessibility

- `TipCard` renders with `role="note"`.
- `TipPopover` is labelled by `TipTitle` and described by `TipDescription`. It does not move focus when it opens or closes, and pressing `Escape` or outside dismisses it.
- `TipClose` is labelled `Dismiss tip`. `TipIcon` is `aria-hidden`.

## API Reference

### TipGroup

Shows the tips inside it one at a time, in order.

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `React.ReactNode` | - |

### Tip

Holds a single tip's visibility and dismissed state.

| Prop | Type | Default |
| --- | --- | --- |
| `id` | `string` | Required |
| `delay` | `number` | `0` |
| `onDismiss` | `() => void` | - |
| `children` | `React.ReactNode` | - |

Give every `Tip` a stable, unique `id`; it is the key used to remember that the tip was dismissed. Place either a `TipCard`, or a `TipAnchor` with a `TipPopover`, inside it, and build the content with `TipIcon`, `TipContent`, `TipTitle`, `TipDescription` and `TipClose`. `delay` is the number of milliseconds to wait before showing the tip.

Dismissed tips are stored under `tip:` followed by the id in `localStorage`. When storage is unavailable, tips still dismiss for the current session. Call `resetTips` with a list of ids to clear their dismissed state, for example from a Show tips again control.

### TipCard

An inline card that expands into the layout while the tip is visible.

Also accepts the props of `React.ComponentProps<"div">`.

### TipAnchor

Wraps the control that a popover tip points to.

Also accepts the props of `React.ComponentProps<"span">`.

### TipPopover

A popover with an arrow, positioned against `TipAnchor`.

<OnlyBase base="aria">

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `align` | `"start" \| "center" \| "end"` | `"center"` |
| `sideOffset` | `number` | `10` |

</OnlyBase>

Also accepts the props of the primitive parts it wraps.

Position the popover with `side`, `align` and `sideOffset`, which default to `bottom`, `center` and `10` pixels.

### TipIcon

The leading icon of the tip.

Also accepts the props of `React.ComponentProps<"span">`.

### TipContent

The container for the title and description.

Also accepts the props of `React.ComponentProps<"div">`.

### TipTitle

The tip's title.

Also accepts the props of `React.ComponentProps<"p">`.

### TipDescription

The tip's supporting text.

Also accepts the props of `React.ComponentProps<"p">`.

### TipClose

The button that dismisses the tip.

Also accepts the props of `React.ComponentProps<"button">`.

Each part sets a `data-slot`, such as `tip-card` or `tip-popover`, for styling.

```tsx
import { NotePencilIcon, PushPinIcon, ShareNetworkIcon } from "phosphor-react-native"
import * as React from "react"
import { Pressable, View } from "react-native"
import { resetTips, Tip, TipAnchor, TipCard, TipClose, TipContent, TipDescription, TipGroup, TipIcon, TipPopover, TipTitle } from "@/components/interactions/tip"
import { Button } from "@/components/ui/button"
import { Icon } from "@/components/ui/icon"
import { Text } from "@/components/ui/text"

const notes = [
  { id: 1, title: "Groceries", preview: "Milk, eggs, bread, coffee" },
  { id: 2, title: "Trip ideas", preview: "Lisbon, Porto, the coast road" },
  { id: 3, title: "Book list", preview: "Three novels for the summer" },
  { id: 4, title: "Meeting notes", preview: "Ship the beta on Friday" },
]

const TIP_IDS = ["notes-pin", "notes-compose"]

function NotesPage() {
  const [log, setLog] = React.useState("")
  return (
    <TipGroup>
      <View className="w-full gap-4">
        <View className="flex-row items-center justify-between">
          <Text variant="h1">Notes</Text>
          <View className="flex-row items-center">
            <Button
              variant="plain"
              size="icon-lg"
              accessibilityLabel="Share folder"
              onPress={() => setLog("Shared the folder")}
            >
              <Icon as={ShareNetworkIcon} className="size-5.5" />
            </Button>
            <Tip id="notes-compose" delay={600}>
              <TipAnchor>
                <Button
                  variant="plain"
                  size="icon-lg"
                  accessibilityLabel="New note"
                  onPress={() => setLog("Started a new note")}
                >
                  <Icon as={NotePencilIcon} className="size-5.5" />
                </Button>
              </TipAnchor>
              <TipPopover side="bottom" align="end">
                <TipIcon>
                  <Icon as={NotePencilIcon} weight="duotone" />
                </TipIcon>
                <TipContent>
                  <TipTitle>Start a note fast</TipTitle>
                  <TipDescription>
                    Tap here any time to begin a new note.
                  </TipDescription>
                </TipContent>
                <TipClose />
              </TipPopover>
            </Tip>
          </View>
        </View>
        <Tip id="notes-pin">
          <TipCard>
            <TipIcon>
              <Icon as={PushPinIcon} weight="duotone" />
            </TipIcon>
            <TipContent>
              <TipTitle>Pin your favorites</TipTitle>
              <TipDescription>
                Swipe right on a note to keep it at the top of the list.
              </TipDescription>
            </TipContent>
            <TipClose />
          </TipCard>
        </Tip>
        <View className="overflow-hidden rounded-2xl border border-border">
          {notes.map((note, index) => (
            <Pressable
              key={note.id}
              onPress={() => setLog(`Opened ${note.title}`)}
              className={
                index > 0
                  ? "border-t border-border px-4 py-3 active:opacity-80"
                  : "px-4 py-3 active:opacity-80"
              }
            >
              <Text numberOfLines={1} className="font-semibold">
                {note.title}
              </Text>
              <Text numberOfLines={1} className="text-sm text-muted-foreground">
                {note.preview}
              </Text>
            </Pressable>
          ))}
        </View>
        <Text role="status" className="min-h-5 text-sm text-muted-foreground">
          {log}
        </Text>
      </View>
    </TipGroup>
  )
}

function TipsExample({ fresh = false }: { fresh?: boolean }) {
  const [key, setKey] = React.useState(0)
  const [ready, setReady] = React.useState(!fresh)

  React.useEffect(() => {
    if (!fresh) return
    resetTips(TIP_IDS).then(() => setReady(true))
  }, [fresh])

  return (
    <View className="gap-6">
      {ready ? <NotesPage key={key} /> : null}
      <Button
        variant="secondary"
        size="sm"
        className="self-center"
        onPress={() => {
          resetTips(TIP_IDS).then(() => setKey((value) => value + 1))
        }}
      >
        <Text>Show tips again</Text>
      </Button>
    </View>
  )
}

export function TipExample() {
  return (
    <TipsExample fresh />
  )
}
```

```swift
import PhosphorSwift
import SwiftUI

let tipIDs = ["notes-pin", "notes-compose"]

struct TipNote: Identifiable {
  let id: Int
  let title: String
  let preview: String
}

@MainActor let tipNotes = [
  TipNote(id: 1, title: "Groceries", preview: "Milk, eggs, bread, coffee"),
  TipNote(id: 2, title: "Trip ideas", preview: "Lisbon, Porto, the coast road"),
  TipNote(id: 3, title: "Book list", preview: "Three novels for the summer"),
  TipNote(id: 4, title: "Meeting notes", preview: "Ship the beta on Friday"),
]

struct TipPinCard: View {
  let id: String

  var body: some View {
    Tip(id: id) {
      TipCard {
        TipIcon { Ph.pushPin.duotone }
        TipContent {
          TipTitle("Pin your favorites")
          TipDescription("Swipe right on a note to keep it at the top of the list.")
        }
        TipClose()
      }
    }
  }
}

struct TipNotesPage: View {
  @State private var log = ""

  var body: some View {
    let shape = RoundedRectangle(cornerRadius: Radius.xl2, style: .continuous)
    TipGroup {
      VStack(alignment: .leading, spacing: 16) {
        HStack {
          Text("Notes")
            .textVariant(.h1)
          Spacer()
          Button {
            log = "Shared the folder"
          } label: {
            Ph.shareNetwork.regular.frame(width: 22, height: 22)
          }
          .buttonStyle(.variant(.plain, size: .iconLg))
          .accessibilityLabel(Text("Share folder"))
          Tip(id: "notes-compose", delay: .milliseconds(600)) {
            Button {
              log = "Started a new note"
            } label: {
              Ph.notePencil.regular.frame(width: 22, height: 22)
            }
            .buttonStyle(.variant(.plain, size: .iconLg))
            .accessibilityLabel(Text("New note"))
            .tipPopover(side: .bottom) {
              TipIcon { Ph.notePencil.duotone }
              TipContent {
                TipTitle("Start a note fast")
                TipDescription("Tap here any time to begin a new note.")
              }
              TipClose()
            }
          }
        }
        TipPinCard(id: "notes-pin")
        VStack(spacing: 0) {
          ForEach(Array(tipNotes.enumerated()), id: \.element.id) { index, note in
            Button {
              log = "Opened \(note.title)"
            } label: {
              VStack(alignment: .leading, spacing: 0) {
                Text(verbatim: note.title)
                  .textStyle(.base, weight: .semibold)
                  .foregroundStyle(EsuissColor.foreground)
                  .lineLimit(1)
                Text(verbatim: note.preview)
                  .textStyle(.sm)
                  .foregroundStyle(EsuissColor.mutedForeground)
                  .lineLimit(1)
              }
              .padding(.horizontal, 16)
              .padding(.vertical, 12)
              .frame(maxWidth: .infinity, alignment: .leading)
              .contentShape(Rectangle())
            }
            .buttonStyle(TipRowStyle())
            .overlay(alignment: .top) {
              if index > 0 {
                EsuissColor.border.frame(height: 1)
              }
            }
          }
        }
        .clipShape(shape)
        .overlay { shape.strokeBorder(EsuissColor.border) }
        Text(verbatim: log)
          .textStyle(.sm)
          .foregroundStyle(EsuissColor.mutedForeground)
          .frame(minHeight: 20)
          .accessibilityAddTraits(.updatesFrequently)
      }
    }
  }
}

struct TipRowStyle: ButtonStyle {
  func makeBody(configuration: Configuration) -> some View {
    configuration.label
      .opacity(configuration.isPressed ? 0.8 : 1)
  }
}

struct TipExample: View {
  @State private var key = 0
  @State private var ready = false

  var body: some View {
    VStack(spacing: 24) {
      if ready {
        TipNotesPage()
          .id(key)
      }
      Button("Show tips again") {
        Task {
          await resetTips(tipIDs)
          key += 1
        }
      }
      .buttonStyle(.variant(.secondary, size: .sm))
    }
    .task {
      await resetTips(tipIDs)
      ready = true
    }
  }
}
```

```kotlin
@Composable
fun TipNoteRow(note: TipNote, onClick: () -> Unit) {

    }

@Composable
fun TipExample() {
    val scope = rememberCoroutineScope()
    var ready by remember { mutableStateOf(false) }
    var page by remember { mutableIntStateOf(0) }
    LaunchedEffect(Unit) {
        resetTips(tipIds)
        ready = true
    }
    Column(verticalArrangement = Arrangement.spacedBy(24.dp), horizontalAlignment = Alignment.CenterHorizontally) {
        if (ready) {
            key(page) { TipNotesPage() }
        }
        Button(
            "Show tips again",
            onClick = {
                scope.launch {
                    resetTips(tipIds)
                    page += 1
                }
            },
            variant = ButtonVariant.Secondary,
            size = ButtonSize.Sm,
        )
    }
}
```

## API Reference

<Only platform="rn">

### TipGroup

Shows its tips one at a time and supplies the storage.

| Prop | Type | Default |
| --- | --- | --- |
| `storage` | `TipStorage` | `memoryStorage` |
| `children` | `React.ReactNode` | - |

By default dismissals are kept in memory and reset when the app restarts. To persist them, pass a `storage` adapter with `getItem` and `setItem`, sync or async, such as one backed by your app's key-value store. Keys are prefixed with `tip:`. `resetTips(ids, storage)` clears dismissals. The `TipStorage` type is exported.

### Tip

One hint, identified by `id`.

| Prop | Type | Default |
| --- | --- | --- |
| `id` | `string` | Required |
| `delay` | `number` | `0` |
| `onDismiss` | `() => void` | - |
| `children` | `React.ReactNode` | - |

Give each `Tip` a stable `id`, the key used to remember the dismissal. Compose `TipIcon`, `TipContent` with `TipTitle` and `TipDescription`, and `TipClose` inside a `TipCard` or `TipPopover`. For a popover, wrap the target in `TipAnchor` inside the same `Tip`. `delay` is the number of milliseconds to wait before showing. `useTip` returns `visible` and `dismiss`.

### TipCard

Renders the tip inline as a card.

Also accepts the props of `ViewProps`.

### TipAnchor

The element the popover points at.

Also accepts the props of `ViewProps`.

### TipPopover

Renders the tip as a popover next to the anchor.

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `Side` | `"bottom"` |
| `align` | `Align` | `"center"` |
| `sideOffset` | `number` | `10` |
| `portalHost` | `string` | - |

Also accepts the props of `React.ComponentProps<typeof PopoverPrimitive.Popup>`.

`sideOffset` is the gap from the anchor. `portalHost` names a portal host to render into. Popovers are up to 320 points wide, and animations respect the system reduce motion setting. On iOS the popover renders in a full-window overlay so it appears above native screens.

### TipIcon

A decorative icon slot.

Also accepts the props of `ViewProps`.

### TipContent

Holds the title and description.

Also accepts the props of `ViewProps`.

### TipTitle

The tip's heading.

Also accepts the props of `React.ComponentProps<typeof Text>`.

### TipDescription

The tip's supporting text.

Also accepts the props of `React.ComponentProps<typeof Text>`.

### TipClose

A button that dismisses the tip.

Also accepts the props of `React.ComponentProps<typeof Pressable>`.
