`UndoBarProvider` renders a floating bar at the bottom of the screen and provides `useUndoBar`. Calling `show` displays a title and an Undo button with a countdown ring. Pressing Undo, or `Ctrl+Z` or `Cmd+Z` outside text fields, runs `onUndo`; when the timer runs out, the bar closes and runs `onCommit`. Showing a new entry commits the previous one first.

The countdown pauses while the pointer hovers the bar, while it has focus, and while the page is hidden. The Undo button is a suiss/ui `Button`. Use it to make destructive actions, such as deleting from a list, immediate but reversible.

## Usage

```tsx
import { UndoBarProvider } from "@/components/interactions/undo-bar"
```

```tsx
<UndoBarProvider>
  <NotesList />
</UndoBarProvider>
```

- Wrap the app or screen in `UndoBarProvider` and call `show({ title, actionLabel, onUndo, onCommit })` from `useUndoBar` after performing the action.
- Apply the change optimistically, restore it in `onUndo`, and finalize it in `onCommit`.
- `actionLabel` defaults to `Undo`. `useUndoBar` also returns `undo` and `dismiss` to settle the current entry from code.
- It pairs well with `SwipeActions`, including full swipes.

## API Reference

<ApiPart index={1}>

### UndoBarProvider

Provides `useUndoBar` and renders the floating undo bar.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `timeout` | `number` | `5000` | Milliseconds the bar stays visible before committing. |
| `className` | `string` | - | Classes for the fixed region that positions the bar. |
| `children` | `React.ReactNode` | - | The content that can show undo entries. |

</ApiPart>

## Accessibility

- The bar sits in a polite live region, so its title is announced when it appears.
- The bar has `role="group"` and is labelled by its title.
- `Ctrl+Z` or `Cmd+Z` triggers undo while the bar is visible, except when focus is in an editable field.
- The countdown pauses while the bar has keyboard focus, giving people time to reach the button.

## Notes

- Parts use `data-slot` values `undo-bar-region`, `undo-bar`, `undo-bar-title`, and `undo-bar-action`. The bar sets `data-paused` while the countdown is paused and `data-closed` while closing.
- The bar is fixed to the bottom of the viewport above the safe-area inset.

`UndoBarProvider` shows a pill-shaped bar above the bottom safe area when `show` is called from `useUndoBar`. It holds a message, a countdown ring and an Undo button, and slides up into view.

If the user presses Undo, `onUndo` runs. If the countdown runs out, `onCommit` runs. Only one bar shows at a time: calling `show` again commits the previous action first. The countdown pauses while the app is in the background and resumes with the time left. Use it after deleting, archiving or moving items.

## Usage

```tsx
import { UndoBarProvider } from "@/components/interactions/undo-bar"
```

```tsx
<UndoBarProvider>
  <NotesList />
</UndoBarProvider>
```

Wrap the screen or app in `UndoBarProvider`. After removing an item from the UI, call `show({ title, onUndo, onCommit?, actionLabel? })`: restore the item in `onUndo`, and do the permanent work, such as a server delete, in `onCommit`.

`useUndoBar` also returns `undo`, which runs the current undo, and `dismiss`, which commits and hides the bar.

### UndoBarProvider

Holds the current undo entry and renders the bar in a portal.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `timeout` | `number` | `5000` | Countdown length in milliseconds. Defaults to `5000`. |
| `className` | `string` | - | Classes for the bar. |
| `portalHost` | `string` | - | Name of a portal host to render into. |
| `children` | `React.ReactNode` | - |  |

</ApiPart>

## Accessibility

- A string title is announced when the bar appears.
- The bar has the `group` role and is a polite live region.
- The countdown ring is hidden from screen readers.

## Notes

- The bar is up to 384 points wide and centered; it uses `bg-popover`, or `bg-muted` in dark mode, with a `border-border` outline.
- The ring drains linearly and runs counterclockwise in right-to-left layouts.
- Slide animations respect the system reduce motion setting; the countdown always runs.
