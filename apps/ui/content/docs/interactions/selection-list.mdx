`SelectionList` recreates the iOS Select mode for lists. Pressing `SelectionListTrigger` switches into editing: each `SelectionListItem` slides in a round checkmark indicator and becomes a checkbox, and `SelectionListBar` rises from the bottom of the screen as a floating toolbar. The row content is made `inert` while editing, so taps toggle selection instead of opening the row. Leaving editing clears the selection.

The trigger is a suiss/ui `Button` that reads `Select` or `Done` by default, and `SelectionListCount` shows how many rows are selected. Use it for lists where people manage several items at once, such as deleting notes or archiving mail.

## Usage

```tsx
import { SelectionList, SelectionListTrigger, SelectionListItem, SelectionListBar, SelectionListCount } from "@/components/interactions/selection-list"
```

```tsx
<NotesExample />
```

- Place `SelectionListTrigger`, the `SelectionListItem` rows, and `SelectionListBar` inside `SelectionList`. Put your own action buttons and `SelectionListCount` inside the bar.
- Editing and selection are each uncontrolled by default. Pass `editing` and `onEditingChange`, or `value` and `onValueChange`, to control them.
- `useSelectionList` returns `editing`, `setEditing`, `selected`, `setSelected`, `selectAll`, and `clear` for building actions such as Select All or Delete.
- Shift-clicking a row, or pressing `Shift` with `Enter` or `Space`, selects the range from the previously toggled row.
- `Escape` leaves editing.

## API Reference

<ApiPart index={1}>

### SelectionList

The root that holds the editing state and the selected values.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `editing` | `boolean` | - | Whether the list is in editing mode, for controlled use. |
| `defaultEditing` | `boolean` | `false` | Whether the list starts in editing mode when uncontrolled. |
| `onEditingChange` | `(editing: boolean) => void` | - | Called when editing mode turns on or off. |
| `value` | `string[]` | - | The selected row values, for controlled use. |
| `defaultValue` | `string[]` | `[]` | The rows selected initially when uncontrolled. |
| `onValueChange` | `(value: string[]) => void` | - | Called with the new array of selected values. |

Also accepts the props of `React.ComponentProps<"div">`.

## Accessibility

- `SelectionListTrigger` sets `aria-pressed` while editing.
- In editing mode, each row has `role="checkbox"` with `aria-checked`, is focusable, and toggles with `Enter` or `Space`. Its accessible name comes from the row's text unless you set `aria-label`.
- `SelectionListBar` has `role="toolbar"` and is `inert` while not editing; give it an `aria-label`.
- `SelectionListCount` is a polite live region, so selection changes are announced.

## Notes

- The root sets `data-editing` while editing, available to children as the `group/selection-list` Tailwind group. Rows expose `data-value` and `data-checked`.
- Parts use `data-slot` values `selection-list`, `selection-list-trigger`, `selection-list-item`, `selection-list-indicator`, `selection-list-item-content`, `selection-list-bar`, and `selection-list-count`.
- The bar is fixed to the bottom of the viewport, so leave room below the list for it.

`SelectionList` switches a list between normal and editing modes. In editing mode each `SelectionListItem` slides in a check circle at its start, the whole row toggles on press, and selected rows are highlighted.

`SelectionListBar` floats above the bottom safe area while editing, sliding up into view, for actions such as delete or move. Leaving editing mode clears the selection. On Android the hardware back button also leaves it. Use it for mail, notes or photo lists that need bulk actions.

## Usage

```tsx
import { SelectionList, SelectionListTrigger, SelectionListItem, SelectionListBar, SelectionListCount } from "@/components/interactions/selection-list"
```

```tsx
<NotesExample />
```

Wrap the list in `SelectionList`, add a `SelectionListTrigger` that toggles editing (it reads `Select` and `Done` by default), and give each `SelectionListItem` a unique `value`. Put your buttons and a `SelectionListCount` in `SelectionListBar`.

Editing and the selection can be uncontrolled with `defaultEditing` and `defaultValue`, or controlled with `editing`, `onEditingChange`, `value` and `onValueChange`. `useSelectionList` returns `editing`, `selected`, `toggle`, `selectAll` and `clear` for custom actions. Outside editing mode, the row's children receive presses as usual.

## Accessibility

- While editing, rows have the `checkbox` role and expose their `checked` state; otherwise the row wrapper is not focusable and its children are.
- The trigger exposes a `selected` state while editing.
- The bar has the `toolbar` role.
- `SelectionListCount` is a polite live region, reading `Select items` or `n selected` by default.

## Notes

- Selected rows use `bg-item-selected`; checked circles use `bg-accent` with an `on-accent` check.
- The bar uses `bg-surface-raised`, or `bg-surface-secondary` in dark mode, and is up to `max-w-md` wide.
- Animations respect the system reduce motion setting.
