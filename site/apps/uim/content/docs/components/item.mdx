`Item` is a row that renders as a `Pressable` with the `button` role when it has `onPress` or `onLongPress`, and as a plain `View` with the `listitem` role otherwise. It has three variants (`default`, `outline`, `muted`) and three sizes (`default`, `sm`, `xs`).

`ItemGroup` stacks items as a list. Its `inset` variant joins them into one rounded card with square inner corners, which suits settings screens; add `ItemSeparator` between rows to draw an inset divider.

## Usage

<Code lang="tsx" code={"import { ItemGroup, ItemSeparator, Item, ItemMedia, ItemContent, ItemTitle, ItemDescription, ItemActions, ItemHeader, ItemFooter } from \"@/components/ui/item\""} />

<Code lang="tsx" code={"<View className=\"gap-4\">\n  <Item variant=\"outline\">\n    <ItemContent>\n      <ItemTitle>Basic item</ItemTitle>\n      <ItemDescription>\n        A simple item with a title and a description.\n      </ItemDescription>\n    </ItemContent>\n    <ItemActions>\n      <Button variant=\"outline\" size=\"sm\">\n        <Text>Action</Text>\n      </Button>\n    </ItemActions>\n  </Item>\n  <Item variant=\"muted\" size=\"sm\" onPress={() => {}}>\n    <ItemMedia variant=\"icon\">\n      <Icon as={ShieldCheckIcon} />\n    </ItemMedia>\n    <ItemContent>\n      <ItemTitle>Your profile has been verified.</ItemTitle>\n    </ItemContent>\n    <ItemActions>\n      <Icon as={CaretRightIcon} className=\"size-4 text-label-secondary\" />\n    </ItemActions>\n  </Item>\n  <Item variant=\"outline\" size=\"xs\">\n    <ItemHeader>\n      <ItemTitle>Header</ItemTitle>\n      <Badge>\n        <Text>New</Text>\n      </Badge>\n    </ItemHeader>\n    <ItemContent>\n      <ItemDescription>\n        Items can carry a header and a footer.\n      </ItemDescription>\n    </ItemContent>\n    <ItemFooter>\n      <Text className=\"text-sm text-label-secondary\">Footer</Text>\n    </ItemFooter>\n  </Item>\n</View>"} />

Compose a row from `ItemMedia`, `ItemContent` (holding `ItemTitle` and `ItemDescription`) and `ItemActions`. Use `ItemHeader` and `ItemFooter` for full-width rows above or below the main content.

`ItemMedia` with `variant="icon"` sizes icons to 16 points; `variant="image"` makes a square thumbnail that shrinks with the item size. `ItemTitle` truncates to one line and `ItemDescription` to two by default; override with `numberOfLines`. Text inside `ItemActions` picks up a secondary color.

Pass `render` to render the row as another component while keeping the item styles.

## Accessibility

- `ItemGroup` has the `list` role.
- A static `Item` has the `listitem` role; an item with `onPress` or `onLongPress` has the `button` role and shows a pressed background.
- `disabled` dims the item and blocks presses.
- `ItemSeparator` is hidden from VoiceOver and TalkBack.

## Notes

- Uses `bg-surface-secondary` for inset groups and the `muted` variant, `border-separator` for `outline`, and `bg-item-pressed` for the pressed state.
- Colors follow the system appearance.
