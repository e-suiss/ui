A narrow footer for mobile-first sites: a breadcrumb for the current page, a collapsible directory of link sections and legal lines at the bottom. It keeps the same single-column layout at every width. As a server component with no state, it drops into any layout.

## Installation

### CLI

<Code lang="bash" title="Terminal" code={"npx @esuiss/ui@latest add blocks footer-compact"} />

### Manual

1. Add the pieces it builds on: [Accordion](/docs/components/accordion), [Breadcrumb](/docs/components/breadcrumb).
