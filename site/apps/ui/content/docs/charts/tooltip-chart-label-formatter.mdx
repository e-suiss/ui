Pass a `labelFormatter` to `ChartTooltipContent` and build the heading from the hovered record, which arrives in its second argument. Adjust the date format there to add the month or year if your range spans more than one month.

## Notes

The demo format shows the day number and weekday but not the month, which can be ambiguous across month boundaries.
