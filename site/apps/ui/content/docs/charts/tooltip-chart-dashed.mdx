A stacked bar chart that shows the dashed tooltip indicator, which marks each series with a dashed outline in its color. Compare it with the dot and line variants to pick the indicator that fits your design.

## Usage

<Code lang="tsx" code={"import { TooltipChartDashed } from \"@/components/charts/tooltip-chart-dashed\""} />

<Code lang="tsx" code={"<TooltipChartDashed />"} />

Set `indicator` on `ChartTooltipContent` to `dashed`; the same setting works on any chart. Replace `chartData` and the series in `chartConfig` to use your own data.

## Notes

The tooltip opens on a preset month when the chart loads; remove `defaultIndex` if it should start hidden.
