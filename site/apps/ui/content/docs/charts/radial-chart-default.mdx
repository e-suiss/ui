Concentric radial bars, one per category, each running along a gray background track. Use it as a compact, circular alternative to a bar chart for a few categories.

## Usage

<Code lang="tsx" code={"import { RadialChartDefault } from \"@/components/charts/radial-chart-default\""} />

<Code lang="tsx" code={"<RadialChartDefault />"} />

Give each record a category key, a value and a `fill` that points at its color, and add each key to `chartConfig`. Adjust `barSize` for ring thickness and `innerRadius` to open up the center.

## Notes

Arc lengths are relative to the largest value, which always closes a full circle; add a `PolarAngleAxis` with a fixed `domain` if bars should be measured against a known maximum. The first record sits on the innermost ring, where the same value looks shorter than on outer rings.
