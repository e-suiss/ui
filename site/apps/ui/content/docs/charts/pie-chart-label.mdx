A pie with each category name printed outside its slice and connected by a leader line. Use it when readers shouldn't have to match colors against a separate legend.

## Installation

### CLI

## Usage

<Code lang="tsx" code={"import { PieChartLabel } from \"@/components/charts/pie-chart-label\""} />

<Code lang="tsx" code={"<PieChartLabel />"} />

Replace `chartData` and the category entries in `chartConfig`; labels read their text from the config. To print values or percentages instead, change what the custom `label` renderer returns. Shrink `outerRadius` if long names get clipped at the edges.

## Notes

Outside labels collide when slices are thin, so keep the category count low.
