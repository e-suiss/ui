A gauge-style arc that opens at the bottom, showing a single reading with its value and rating in the center. Use it for scores with a known range, such as air quality, health scores or credit utilization.

## Usage

<Code lang="tsx" code={"import { RadialChartGauge } from \"@/components/charts/radial-chart-gauge\""} />

<Code lang="tsx" code={"<RadialChartGauge />"} />

Set the reading in `chartData` and the scale on `PolarAngleAxis` through its `domain`. Update the number and rating text in the center overlay, which are not read from the data. Change the color in `chartConfig`, or pick it from the value if the color should signal good and bad ranges.

## Notes

There is no tooltip and the center text is hard-coded, so keep it in sync with the value you pass.
