# suiss/ui

Accessible and customizable components that you copy into your apps, for React with Next.js and Vite, React Native with Expo, SwiftUI and Jetpack Compose. One design on every platform. Free. Open Source.

![suiss/ui](.github/og.png)

## By the numbers

- **170,000+ reference screenshots.** Every web state in 9 styles, light and dark, left to right and right to left, on each of 3 primitive libraries (Radix, Base UI and React Aria), plus every mobile example.
- **580+ web examples** for Next.js and Vite.
- **630+ React Native examples**, each captured on two mobile platforms.
- **190+ SwiftUI and 190+ Jetpack Compose pieces**, installed with the same CLI.
- **5 icon libraries** and **9 styles** to choose from.
- **150+ CI jobs** pass before any version ships, including fresh installs of the CLI into new projects on every platform.
