# suiss/ui

Accessible and customizable components that you copy into your apps, for React with Next.js and Vite, React Native with Expo, SwiftUI and Jetpack Compose. One design on every platform. Free. Open Source.

![suiss/ui](.github/og.png)

## By the numbers

- **170,000+ reference screenshots.** Every web state in 9 styles, light and dark, left to right and right to left, on each of 3 primitive libraries (Radix, Base UI and React Aria), plus every mobile example.
- **580+ web examples** for Next.js and Vite.
- **630+ React Native examples**, each captured on two mobile platforms.
- **190+ SwiftUI and 190+ Jetpack Compose pieces**, installed with the same CLI.
- **5 icon libraries** and **9 styles** to choose from.
- **150+ CI jobs** pass before any version ships, including fresh installs of the CLI into new projects on every platform.

## Documentation

Visit [suiss.app/ui/docs](https://suiss.app/ui/docs) to view the documentation.

- [Installation](https://suiss.app/ui/docs/installation): set up a Next.js, Vite, Expo, SwiftUI or Jetpack Compose project.
- [Components](https://suiss.app/ui/docs/components): buttons, inputs, dialogs, sheets, menus and more.
- [Patterns](https://suiss.app/ui/docs/patterns) and [Interactions](https://suiss.app/ui/docs/interactions): app shells, pickers, swipe actions and other building blocks.
- [Charts](https://suiss.app/ui/docs/charts): area, bar, line, pie, radar and radial charts.
- [Blocks](https://suiss.app/ui/docs/blocks): sign-in, settings, dashboards, inboxes and other full screens.
- [AI](https://suiss.app/ui/docs/ai): chat, reasoning, tools and sources for AI apps.
- [CLI](https://suiss.app/ui/docs/cli): add pieces to your project from the terminal.
